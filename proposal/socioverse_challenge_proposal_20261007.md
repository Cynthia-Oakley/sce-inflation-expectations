# 水上挽月｜美国居民通胀预期的社会模拟：基于 SocioVerse 的调查重建

**SocioVerse Challenge 2026 开题提案 · 赛道 A（历史重建与未来预测）**

## 一、研究问题

纽约联储消费者预期调查（SCE）是衡量美国居民通胀预期的权威月度调查，记录家庭对未来一年通胀的**点预测与概率分布**，为理解消费行为和货币政策传导提供重要依据。真实调查能够观察人群差异，但开展频率与微观资料的及时性受到资源和发布节奏限制。

我们的研究问题是：**一群具有不同社会经济特征与生活体验的家庭 Agent，能否根据价格信号和公共信息，重建与真实调查相近的通胀预期——包括预期水平、分布形态与人群差异？人群画像与信息环境各自贡献多少，这种模拟又能否用于预测下一期调查？**

本项目与 SocioVerse 的消费者信心模拟案例共享“人群 × 环境 → 行为”范式，将对象延伸至居民对未来价格的判断及其不确定性。若经过有效验证，模拟可成为传统调查的补充，提供可重复、可分解到人群、可比较不同信息情景的研究工具。

**经济学上的核心是：公共宏观环境如何经过个体经验，形成不同家庭的预期。** 食品、房租、汽油等日常价格变化及供给冲击新闻，未必被所有家庭同等感知。价格体验研究表明，购买频率和对涨价的注意会影响通胀判断；收入、教育与居住状况也可能通过消费篮子和信息理解发挥作用。因此，本项目将人口画像与差异化的信息感知连接起来，研究个体判断如何汇聚为群体分布。

SCE 的全国结果与微观资料分阶段公开，也为项目提供应用动机：经过验证的模拟有望在微观资料公开之前，提供及时的人群层面分析。历史重建利用已知资料检验微观分布的还原能力；未来预测则限定截止时点可得信息，两者分别评价。

## 二、模拟设计：P × E → B

按 SocioVerse 的核心抽象 **B = f(P, E)** 组织研究：

| 组件 | 设定 | 数据来源 |
|---|---|---|
| **P 人群** | 构建不同生活处境的家庭，分层选择核心家庭模拟并统计扩展，以人口构成与调查权重校验总体代表性 | 纽约联储 SCE 微观数据；BLS CE 消费支出微观数据 |
| **E 环境** | 双层信息环境：数据层呈现价格与就业的历史路径，事件层提供供给冲击、政策及经济新闻；研究不同家庭的信息接触与关注差异 | BLS 历史首发稿；EIA 汽油周价；纽约时报新闻档案 |
| **B 行为** | 按 SCE 问卷回答未来一年通胀点预测及区间概率，再汇总个人预期、群体分歧与月度变化 | SCE 官方问卷与方法材料 |

**人群与价格体验**：依据 SCE 构建人口画像，再按共同人口特征从消费支出调查中匹配家庭记录，合成保留消费结构差异的篮子。其假设是，相似生活处境的家庭消费分布可提供统计参考。篮子作为支出暴露代理，连接家庭画像与价格信息，用于构建个人信息视图。购买频率等接触特征另以资料支持，通过更换匹配方案与重复抽样检验合成结果的稳健性。

**居民视角的信息环境**：在共同经济背景上，依据消费结构和接触特征，为家庭配置不同侧重的价格与新闻信息。家庭结合已有经验形成和更新判断，使公共环境通过个体感知转化为预期。保持信息总体构成一致，比较按家庭背景匹配与随机分配的效果，检验这种联系能否改善对真实人群分布的还原。

**信息范围与隔离**：先利用明确声明的历史人口、环境与结果约束，检验上述联系能否还原微观结构，再以未参与构建或校准的调查信息验证。未来预测用 t 期可得资料预测 t+1 期调查，在真实结果公布前封存输入与预测。通过记录来源、发布时间和版本，保证两类任务各自的信息边界。

## 三、验证方案

- **对照真值**：以 SCE 真实问卷和官方统计为参照，检验模拟是否同时还原预期水平、分布形态、人群差异和跨期变化。个人误差用于辅助诊断，人群分歧与个人预测的不确定性分别评价。
- **基线比较**：与最后已公开一期调查、简单宏观方法及同等信息下的直接 LLM 提问比较，识别家庭 Agent 的增量价值。比较核心人群直接加权与统计扩展，检验扩展带来的代表性改善与误差。
- **消融分析**：分别检验人口差异、新闻信息和个体价格体验的作用，判断改进是否来自合理机制，而非仅将总体指标调至相近。
- **独立验证**：先用开发实验改进机制，再冻结方法，在未参与调试的时期及不同人群中检验适用性。真实与模拟概率回答采用统一计分口径，并与官方派生结果对账，评估近似算法对结论的影响。
- **历史知识边界**：模型训练资料可能覆盖目标时期。结合信息截止与模型知识诊断，分别说明回顾性重建和预测结论的证据范围，不将历史拟合直接视为事前预测能力。

## 四、数据来源与可行性基础

- **调查与评价**：[纽约联储 SCE](https://www.newyorkfed.org/microeconomics/sce) 微观数据中的年龄、收入、教育、就业、住房及地区用于构建 P，调查权重用于总体校验；真实 Q8/Q9 回答及公布统计用于结果评价。官方问卷与方法材料用于设定 B、核对计分，真实通胀答案不直接提供给 Agent。
- **消费背景**：[BLS 消费支出调查（CE）](https://www.bls.gov/cex/pumd.htm) Interview 微观数据已用于匹配家庭、合成食品、汽油和住房等支出结构；年度分组表作为分布参照。Diary 支出日记已归档，拟用于研究购买频率与价格接触，尚未作为实测注意力输入。
- **经济环境**：BLS [CPI](https://www.bls.gov/news.release/cpi.htm) 与[就业报告](https://www.bls.gov/news.release/empsit.htm)的历史首发稿提供总体及分类物价、失业率和就业变化；[EIA 汽油周价](https://www.eia.gov/petroleum/gasdiesel/)（现经 FRED 获取）补充高频能源价格，用于呈现经济背景及价格路径。
- **新闻事件**：纽约时报 Archive API 的标题、摘要与发布时间，按物价、就业和经济政策等主题筛选，为 E 提供政策与供给冲击信息。资料均保留来源和版本；汽油及新闻的历史版本证据仍需补全，未核验部分不用于严格事前预测。
- **模拟流程**：已跑通 SocioVerse 云端流程与本地真实大模型实验，完成月度人口构建、历史环境注入、问卷作答、轨迹保存、总体扩展和独立分析。基础工程链路与结果复算可行。
- **经验发现**：开发月份中，Agent 模拟的 SCE 变化趋势与真实 SCE 的趋势方向一致，但预期水平整体偏低、人群分歧不足。小规模对照中，增加家庭属性或差异化价格信息尚未稳定改善拟合。因此，后续将保留共同经济背景，把消费体验与信息接触、信念更新相连接，检验能否同时改善预期水平与群体分布。

## 五、计划、成本与风险

- **推进计划**：围绕当前水平偏低与分歧不足的问题，先以小型对照检验共同背景、个体体验和信息更新的作用。将得到支持的机制固定为研究方案，开展历史重建、独立时期验证及消融，进一步封存下一期预测并评价。
- **成本控制**：以核心家庭开展深入模拟，再通过统计扩展覆盖其他家庭，兼顾成本与人口代表性。优先用小型对照筛选机制，经独立验证后扩大规模，使投入对应可检验的研究问题。
- **可复现性**：交付符合 SocioVerse 结构的 study 研究包、运行与重算入口，保留输入、配置、轨迹、模型与成本记录，区分已有结果复算和真实模型重新生成。
- **风险与应对**：针对个体价格体验资料不足，采用有统计依据的条件合成，并比较不同分配方案对结论的影响。针对模型历史知识与信息表达可能造成的偏差，开展模型和信息形式对照，并以发布前封存的预测检验其价值，明确各项机制的适用范围。

## 六、预期贡献

- 一个可复现、可审计的“虚拟 SCE”案例，为调查型社会模拟提供经验依据与可复用组件。
- 连接人口特征、价格体验与公共信息的预期形成框架，检验哪些机制能够改善群体分布，识别不同人群与时期的适用边界。
- 区分历史重建和未来预测的信息使用与独立验证方法，为其他经济调查指标的社会模拟提供参考。
