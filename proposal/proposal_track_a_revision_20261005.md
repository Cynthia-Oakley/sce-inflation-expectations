# 水上挽月：基于家庭 Agent 的美国通胀预期重建与预测

> 2026-10-05 修订草稿，供用户审阅后合并。原 `proposal.md` 保留。本文把已完成结果、正在开发的功能和计划分别表述，不代表已提交。

## 一、研究问题与社会价值

居民对未来物价的判断影响消费、储蓄和工资决策。同一宏观环境下，不同家庭的预期往往差异很大。本项目以纽约联储消费者预期调查（SCE）的一年期通胀预期为对象，检验家庭 Agent 能否根据人口画像与经济信息生成可信的调查回答，以及这种模拟能否帮助重建群体分布和预测下一期调查。

对应比赛赛道 A 的“历史重建与未来预测”，设置两项任务：**历史重建**利用已知历史人口与环境，重建预期水平、分歧及人群差异；**未来预测**只使用 t 期截止前可得资料，预测 t+1 期 SCE 回答与统计量。这里预测的是下一期居民的通胀预期，而非下一月实际 CPI。两项任务共享问卷与计分组件，分别报告信息范围和验证结果。

## 二、SocioVerse 的 P/E/B 设定

**Population（P）**：主体为美国居民家庭，画像包括年龄、教育、收入、地区、数理能力、就业及可核实的住房状况。历史重建使用每月真实 SCE 人口框，以完整样本或预先确定的随机抽样保持构成；调查权重和抽样权重在聚合时使用。未来预测依据截止时点已公开的人口资料构建合成人口，不能使用下一期真实受访者名单、画像或权重。核心微观数据有九个月发布滞后，其历史可得性需单独记录。当前按月构建首先验证截面代表性；跨月状态与轮换机制另行验证。

**Environment（E）**：材料包含 CPI、失业率、食品、能源、住房及汽油价格的历史变化，以及与物价和经济活动有关的新闻标题与摘要。每条资料记录参考期、发布时间、来源和版本证据。历史重建列出实际使用的历史资料与截止日；未来预测仅使用预测截止前可得的信息。版本不能核实的材料单列，严格预测评价须剔除或补齐证据。宏观平均价格与个体价格感知之间的联系是待检验假设，后续以受控对照检验，避免直接指定无依据的群体响应系数。

**Behavior（B）**：家庭 Agent 独立回答 SCE 一年期点预测及十档概率问卷。概率回答保留原始值，异常记录和重试单列；由统一冻结的项目近似计分器将概率转为个人密度统计量，再用分析权重聚合。对真实和模拟问卷采用相同算法，并另报与官方计分口径的差异。真实问卷答案不进入当前模拟提示词。

## 三、实验与独立验证

历史重建评价月度水平、横截面分布、人群差异与跨月变化。如果后续使用某个官方统计量作为重建约束，该量只报告约束满足程度，以未参与校准的指标评价重建可靠性。

未来预测与最后已公开一期 SCE、简单宏观模型、同等信息下直接询问 LLM 等基线比较。所有基线也遵守同一信息截止。重点报告不同人群、地区和时期的误差，以及模拟分歧是否被压缩。

开发月采用 2021-05、2021-06。开发诊断后冻结人口、环境、提示词、模型、预算和正式评价窗口；已用于改进的结果不再称为盲测。后续分别移除人口差异或新闻信息，检验 P/E 的贡献。官方 PMI 案例为“主体状态更新—调查作答—聚合验证”提供结构参照，其企业规模与月内截止日不直接移植。

历史回放所用 LLM 的训练信息可能覆盖目标时期。因此即使输入遵守时间规则，也须披露模型参数中的时间泄漏风险；训练边界未知时按回顾模拟或受限证据的回测报告。前瞻封存实验可以提供补充证据。

## 四、已完成的进展与发现

已获取并核验多年 SCE 微观资料、核心问卷和方法材料，完成官方个人派生值到月度统计量的聚合检查，并建立统一的项目近似概率计分器。

平台规则式小试及本地首轮真实 LLM 运行已完成归档。原固定 73 人全年实验主要暴露预期水平偏低和同月分歧不足；该面板代表性不足，作为开发诊断保留。新版已扩充宏观历史与新闻摘要，其行为效果仍待真实运行检验。

新增两个月完整人口框及 300、500 人的抽样输入。离线重复抽样发现，样本规模会显著影响聚合精度，分层并不总能改善结果。按月 300 人的规则式流程已生成有效回答并核验实际 P/E 输入；这说明工程链路可用，不能作为预测准确性证据。

## 五、推进计划与可复现性

先完成开发月行为诊断和人口方案，再扩大历史重建实验；同步准备满足时点要求的预测输入和基线。开题报告在 10 月 12 日前提交，最终材料按赛事日程在 10 月 31 日前完成。

本地以官方 SocioVerse2 开源框架运行，记录模型请求名及 API 返回信息，逐条保留提示词、回答、失败、重试和用量。每轮保存输入、实际生效配置、源码快照、哈希与独立 run_id，运行产物保留原版本。预算按实际 token 用量和核实费率计算，设置请求次数与费用上限；样本规模在精度和成本检查后确定。

最终提供标准 study 目录、输入说明、运行与离线重算入口、版本与依赖记录、成本和适用边界说明。预期形成一个可独立验证的“虚拟 SCE”案例，为调查型社会模拟提供经验结果和可复用组件。
