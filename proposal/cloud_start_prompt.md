我们是 SocioVerse Challenge 2026 赛道 A 队伍“水上挽月”。拟参考 ConsumerSim 的家庭问卷模拟范式，研究美国 SCE 居民一年期通胀预期。请先协助确定一个能在云端完成的小规模研究方案，并在方案确认节点停下。

主目标拟为个人主观通胀密度均值的加权中位数；副目标为点预测中位数。问卷包括带符号点预测和十个通胀/通缩区间的概率分配，区间与计分必须按 SCE 官方问卷和方法核对，不能复用 CCI 计分或用区间中点平均冒充官方密度拟合。

P 优先采用历史可得的 SCE 人口结构或经过核验的画像样本；基础字段是年龄、教育、收入、地区、住房和就业。额外心理人格暂不加入。后续可提供字段字典及小型合成 CSV 测试上传，请先说明能否将文件实际物化为 study 人口，并显示读取行数、字段、权重与样例。不要把输入文件里的真实问卷答案或同期未公布权重带入 P。

E 优先使用平台 Event MCP 的相关宏观和历史新闻来源。请先列来源与字段，不调用默认全部来源；排除目标月 SCE 数值及复述其结果的报道。拟主实验以目标月前一个月末美国东部时间为截止，逐条区分参考期、首次发布日、抓取日与历史修订版本。未知可得性先标缺口，不自动当成合格历史输入。

请说明：
1. 哪些部分可复用现有研究，哪些需新增代码；consumer_confidence_us_backtest 是回测导入参考，不要把它的已有结果当成重新模拟。
2. 当前工作台能否支持文件人口、定制概率计分、冻结输入、导出模型/配置/原始逐人回答/完整研究包；若存在限制，列出云端生成回答、本地计分的替代路径。
