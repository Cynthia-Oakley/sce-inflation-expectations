## 来源与制作

`aggregate_data.json`只含聚合数据和来源哈希；`source_index.md`记录出处及统计解释；`background_source_receipt.json`记录新核查的官方背景。`content.md`为逐页派生文字，`delivery.json`保存交付与检查信息。真实个人记录、完整字体文件、原始模拟结果和输出均不提交Git。

制作入口（项目根运行，需已有本地数据）：

```sh
python scripts/prepare_sce_progress_report.py
python scripts/render_sce_progress_report.py
```

准备依赖pandas、numpy、matplotlib、pyarrow、fontTools，排版依赖reportlab。当前实际使用既有Base分析环境与Codex文档运行时，未安装或修改全局依赖。macOS楷体从系统TTC读取第0个简体Regular字体，文档嵌入权限fsType=8；没有将系统字体加入仓库。

- 后四评价中心MAE仍为0.6355480844个百分点，与冻结结果一致。图表展示范围不改变全尾部计分。
- 新的零API核查复用2021全年20人旧同消息对照，按12个月平均：DeepSeek/Qwen相对SCE同样本中心MAE分别0.95185/0.88351；相对t+12月份CPI同比为5.66301/5.53726。不是最新版八期P/E，也不是两模型各自递推的独立轨迹。
