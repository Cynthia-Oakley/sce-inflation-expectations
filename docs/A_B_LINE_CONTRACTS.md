## A 线：历史微观结构重建

**研究问题**：在已知历史宏观背景、人口分布及选定统计约束下，Agent 能否生成与真实调查相容的微观预期结构？

| 要素 | 内容 | 来源 |
|---|---|---|
| 已知条件（P） | 当期真实 SCE 微观画像抽样（年龄/教育/收入/地区/数学能力/就业/住房），允许使用当期人口分布与官方权重做抽样、配额与聚合校准；住房为入组回答前向沿用（记录来源月与信息年龄） | `data/raw/sce_audit_20260928/micro_2020_2024.xlsx`（经 `scripts/build_sce_population.py` 白名单提取） |
| 已知条件（E） | 历史宏观信号（当前实现 v1：BLS 首发稿 CPI 同比/环比、失业率、非农，as_of=目标月−1 月末；v2 方向按 D049：扩展为数据层=可感知价格分项+历史序列、事件层=重大供给冲击新闻，均须逐条时点合规）；允许扩展到事后整理资料与声明采用的宏观统计约束，逐项登记 | `data/raw/bls_initial_releases/`（34 份首发稿 PDF + 哈希归档）；事件层来源待定 |
| 校准目标 | 逐实验声明登记。可选项：当期 SCE 全国统计量（如 Q9 密度中位数轨迹）——**一旦用作校准目标，该统计量不得再作为独立验证** | 官方 headline（`chart.xlsx`） |
| 生成对象 | 逐人逐月 Q8 点估计 + Q9 十档密度：core = LLM Agent 直接作答；normal = 宏观约束下的微观投影（estimator 待定，须先定义再验收） | `studies/sce_inflation_expectations/` |
| 独立验证量（未用于约束的） | ① 微观：逐人 Q8/Q9 误差分布、个体不确定性（IQR）分布、横截面分歧（月内 std）、Q8–Q9 内部不一致幅度（真实参照：median +0.49 / mean +2.53pp）；② 分组：age/education/income/employment 组间差异结构与方向、新入组 vs 继续者差异；③ 跨期：逐月变化与自相关结构；④ 全国层：若当月 headline 未作约束，可作验证 | 评价层真值 `data/evaluation/sce_truth_*.json`（Q8 真值=Q8v2part2，Q8/Q9 独立掩码） |

当前定位：`sce-local-openai-20261003T055121Z-1dc7cd15`（73×12）是 **A 线原型**——只用了 P/E 白名单输入，未使用任何宏观统计约束校准，评价用全国/微观/分组三层。已识别的主要缺口：水平系统性偏低约 2pp、横截面分歧不足（模拟月内 std 0.27–0.81 vs 真实 5.5–7.5）。

## B 线：以 t 期可得信息预测 t+1 期

**研究问题**：只用 t 期已可得的信息，能否预测 t+1 期 SCE 的回答与统计量？（t→t+1 是调查期预测，不是预测实际 CPI。）

| 要素 | 内容 | 来源 |
|---|---|---|
| 输入（P） | t 期时点已可得的旧微观 frame（如 ≤M−12，须标注为可得性假设）+ 当时公开人口宏观变量外推；源记录的 reference_period/published_at/as_of 逐项登记 | 同左（滞后切片，新脚本待写） |
| 输入（E） | as_of = t 期末已发布的宏观信号（与 A 线同源归档，但只允许 ≤as_of 的稿次；v2 双层化同 D049，事件层只允许 as_of 前已发生且有公开报道证据的事件） | `data/raw/bls_initial_releases/` |
| 校准目标 / 投影参数 | 只允许 ≤t 的信息；normal 投影的估计器与参数在 t 时点确定 | 待定义 |
| 生成对象 | t+1 期逐人 Q8/Q9（core）与 normal 投影 | 同 A 线组件 |
| 独立评价指标 | **全国月度指标为主**：t+1 期加权中位数轨迹、MAE/bias/RMSE vs 官方 headline；分组与微观指标为诊断；历史月份滚动回测同属 B 线，不要求计算发生在现实中那个月 | 官方 headline + 评价层真值 |

| 封存预测（可选） | 对官方尚未发布的月份，在发布前冻结 P/E/模型/提示词并运行，连同 run_id/哈希/时间戳封存；官方公布后一次性比对。官方发布日只决定该可选验证的封存窗口，不是项目开发死线 | NY Fed 发布日历（下次 2026-10-07 11:00 ET，对应 9 月调查） |

## 两线关系与纪律

- A−B 的差值**不能**直接解释为"人口信息时效效应"：两线的输入、校准、生成对象与评价指标都不同。若要研究信息新旧的影响，另设固定 E/模型/方法的受控对照。
- 真实个体回答只进评价层；若某记录直接参与拟合/初始化，它即成为拟合信息，不能再作为独立重建证据（两线同）。
- A 线允许事后资料辅助重建，但观测日期必须保留（后观测的就业/住房不能无说明地当成过去状态）。
- 每条线每次运行登记：run_id、代码/提示词版本与哈希、输入清单、校准目标清单、执行时间；封存运行另记 information_as_of / executed_at / sealed_at / official_release_at。
