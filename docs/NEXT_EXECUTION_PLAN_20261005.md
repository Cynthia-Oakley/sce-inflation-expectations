## 1. 先检查 Population（已完成，零模型调用）

使用开发月 2021-05、2021-06 的完整 SCE 受访者记录，重复抽取 73、100、300、500 人，每种方案 200 次。比较简单随机抽样与年龄×教育×粗就业状态分层抽样；分层按各格实际人数分配，保留每格至少一人。聚合使用调查权重乘以抽样概率的倒数，人口属性和真实问卷回答分别用于选样与选样后的评价。

检查人口构成差距、真实 Q9 个人派生均值的月度加权中位数差距、四分位距差距和有效样本量。已有全年固定 73 人面板作为诊断参照。只输出汇总，不输出个人记录或模型输入。

这回答“抽样本身会造成多大偏差”，不能回答“LLM 能否模拟正确”。完整月调查样本也是有限的调查样本，不能把抽样诊断当成美国全国置信区间。此轮不定正式样本规模、不在真实答案上挑选最佳种子、不验证 normal 外推层。

入口：`scripts/check_sce_population_precision.py`。结果：`outputs/population_precision_<UTC时间>_<后缀>/summary.json`，每次新目录。正式 Population 实现继续放在 study 内；此脚本仅作离线设计检查。

**本轮已完成**：两月完整样本分别 1,234 / 1,297 人；四种人数×两种抽样设计×每种 200 次，共 3,200 次离线抽样。四项定向测试通过。

- 简单随机抽样的月度中位数平均绝对偏差：100 人为 0.560 / 0.559 个百分点；300 人为 0.275 / 0.356；500 人为 0.155 / 0.227，顺序为 2021-05 / 2021-06。
- 简单随机 300 人的绝对偏差第 95 百分位为 0.906 / 0.802 个百分点；500 人为 0.562 / 0.543。上述是重复抽样误差的分位数，不是全国参数置信区间。
- 分层 300 人的平均绝对偏差为 0.253 / 0.328，有小幅改善；分层 100 人反而为 0.658 / 0.650。覆盖小格会增加权重差异，不能把“分层更多”当作自动更准确。
