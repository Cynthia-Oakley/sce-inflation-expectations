# SCE 统一评价口径 v1

2026-10-07，依据用户授权建立。适用于新评价入口与本轮离线基线；旧实验保留原评价。方法讨论见 [设计依据](SCE_EVALUATION_BASELINES_20261007.md)，数值结果见 [60个月基线报告](SCE_BASELINE_RESULTS_20261007.md)。不改现有 Simulation 配置或 Q9 计分器。

## 1. 三种任务分别报成绩

- **历史重建、未给定 SCE 宏观结果**：主要看调查加权的人群分布 W1，配合全国中位数、分歧宽度、预设人群关系和个人不确定性。
- **历史重建、已知全国中位数**：该中位数误差只说明约束是否满足；主要看居中后的分布 W1 和未作为拟合目标的群体关系。本轮平移历史个人均值，只生成均值分布，不冒称生成了完整 Q9 问卷。
- **下一期预测**：主要看全国 Q9 的跨月 MAE，配合 RMSE、平均偏差、逐月/逐年结果；生成了人群分布的方法还要评价 W1。当前月 CPI 首发日口径另列为月中回顾模拟/即期预测参照，不混入上月末预测成绩。

Q9 个人密度均值的跨人中位数是目标；实际 CPI 是输入。Q8 作为独立副目标，不与 Q9 混算。本轮基线仅覆盖 Q9 派生均值/不确定性与全国指标，未实现 Q8 基线。

## 2. 数值口径与真值

1. 所有数值采用百分比尺度，例如 4.0 代表 4%；误差单位为百分点。
2. 人群的加权分位数采用经验加权 CDF 的左逆；不同样本数/权重的 W1 用完整加权 CDF 积分，不能直接把两个排序数组相减。月内加权，跨月等权。
3. 全国预测主表使用官方新闻稿的首发一位小数值；另报官方高精度 chart 快照真值敏感性，不能混拼。首发输入按新闻稿真实发布日期选取，不机械用上一调查月。
4. 本轮统计重建使用官方提供的 `Q9_mean/Q9_iqr`，真实与历史 donor 是同一官方派生口径。未来 Agent 分布评价采用统一冻结计分器重新处理双方原始 Q9；两种口径必须分别标版本，不直接串成一张同口径主表。
5. 国家中位数、人群均值分布的 IQR、个人 Q9 内部 IQR、同一输入重复生成的波动分别报告。
6. 真实微观权重只留在评价层或明确声明的 A 重建条件中；B 不借目标月真实人口/权重修正预测。

## 3. 有效样本与人群评价

缺失/非法/拟合不支持分别留数量，不能把没有回答的 Agent 当零，也不能只删除某一对照的不利记录。全国预测缺月直接报错，比较方法另显式取共同月份。

本轮 A 参考量按年龄×教育九类人口条件建立，源字段是文本标签，不能强转数字。donor 或被评价联合组不足20个有效样本时明确回退/不报告，保存覆盖；此门槛是工程支持规则，不是功效证明。后续增加收入、价格体验组需在实验前登记，不能看结果后选择分组。

只有声明与同一真人对应，并提供一对一标识及共同有效集，才报告逐人 MAE；合成家庭与历史 donor 分布不报告虚假逐人对应。逐人误差是辅助，不能代替群体结构评价。

Normal 借用的 donor 不是独立新增受访者。加权 ESS 只描述权重集中，不能直接当 LLM 独立样本数。

## 4. 时间、拟合与不确定性

本轮全国基线窗口为2020-01至2024-12，共60月；2018-12起已发布的SCE用于逐月扩展训练，最少12个已发布观测。ARX最少12组已公布标签和对应历史截止点特征，故覆盖较短，必须与相同月份的持续性基线比较。

- 上月末预测：截止前月末纽约时间23:59:59。
- 月中参照：截止当月上一期CPI首发日纽约时间23:59:59，符合当前开发实验的时点规则；不代表每位真人作答日。
- 仅有发布日期的 SCE 新闻，按该日结束时保守纳入，不补造具体发布时间。
- 拟合只用当前截止前发布的标签；每个训练特征仍按其原预测截止日构建。初次下载时间不当作历史发布日期。

六个月循环块、2000次配对月份 bootstrap 给出相对持续性基线的 MAE 差值区间，只是该历史时期的近似不确定性；不证明未来效果。时期非平稳、规则 Agent 仅固定 seed42，均需披露。合成画像/LLM随机性在今后相应实验中另估。

这些月份现已用于基线查看，属于回顾性参考，不称“从未看过的 Agent 测试”。将来机制选择与独立评价另做数据使用登记。本轮未按长跨度结果调换主要指标或选择最优参数。

## 5. 统一接口

公共计算：[metrics.py](../studies/sce_inflation_expectations/evaluation/metrics.py)。独立评价入口：[evaluate_sce_outputs.py](../scripts/evaluate_sce_outputs.py)，不导入 Simulation 引擎。

规范化 JSON 包：

- `kind="headline"`：`truth_series_id` 说明首发/快照，`records` 每月一条，字段 `target_month/value_pp`；模拟和真值包月份必须相同。
- `kind="population"`：另给 `scoring_version`，双方必须一致；`records` 含 `target_month/mean_pp/weight`，可加 `uncertainty_pp`。
- 人群分析在模拟包给 `group_fields` 和 `minimum_group_count`，每条记录含对应分类；稀疏组保存状态。
- 逐人辅助在模拟包显式给 `pairing="same_observed_person"`，双方每月一对一 `person_id`；不能仅因为编号相同就自动配对。
- 宏观约束在模拟包给 `constraints=["national_median"]`；其它约束需追加未拟合验证量契约，当前入口拒绝自动打分。

输入来源/截止、研究线、样本设计和费用由对应运行卡与manifest保存；统计入口不能单靠最终数值证明输入PIT合规。已有轨迹需先转换到规范包，原文件保持不动。

```sh
python scripts/evaluate_sce_outputs.py \
  --simulated <simulated_bundle.json> --observed <evaluation_bundle.json> \
  --output <new_evaluation_result.json>
```

结果按新文件保存，拒绝覆盖。更多命令与可复算范围见 [evaluation入口](../studies/sce_inflation_expectations/evaluation/README.md)。
