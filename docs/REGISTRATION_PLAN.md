# 报名与开题的最短路径

更新：2026-09-27。报名和提案是两次不同的提交。官网报名表的作品简介、指导老师为选填；不需要等指数真值审计、代码或 1–2 页提案完成才报名。

## 先确定报名所需事项（现在）

1. **队伍**：确认是单人还是 1–5 人团队、队长、联系邮箱和队伍名。每位正式成员只加入一队。无需为尚未确认的成员占名额。
2. **赛道**：选 A「历史重建与预测」。暂定问题为：能否在严格限制信息可得时点的条件下，用财务专业人士 Agent 重建调查式经济信心指标？
3. **指导老师**：报名表选填。先问魏教授是否愿意列名，并确认其赛事顾问委员身份是否涉及回避安排；未确认前留空。
4. **作品简介**：选填。可以留空；若填写，用下方的暂定描述，避免承诺已经取得数据或结果。

暂定作品简介：

> 本项目拟面向赛道 A，研究财务专业人士在宏观经济与政策信息环境中的预期形成。以“指标跟踪”清单中的 ACCA–IMA Global Economic Confidence Index 为首选候选，构建可复现的 Agent 问卷模拟，与历史指标及简单时间序列基线比较。最终目标口径和样本窗口将以官方方法、连续真值及发布时间审计结果为准。

## 随后立即完成报名链路

1. 在[赛事官网](https://socioverse.fudan-disc.com/challenge/)提交队伍报名；检查确认邮件和垃圾邮件。
2. 保存邮件中的 Challenge 邀请码，由队长用该码注册 SocioVerse2 平台账号，验证邮箱。
3. 在平台 Studies 页确认能看到 Challenge 提案入口。记录队伍名、赛道、队长、报名时间和提案入口状态，不将 GitHub 私有仓库当成赛事报名。

## 报名后、10 月 9 日提案前

1. **9 月 28–30 日**：重点审计 `ECO-0078` 是否有不少于 12 个连续季度的精确数值、问卷到指数的转换说明、调查期和发布日期；同时快速核查 `ECO-0086` 作为退路。若 ACCA 数据门槛过不了，改用有可靠真值且机制清楚的清单内目标，不因为已报名而硬做。
2. **10 月 1–3 日**：锁定一个目标、研究窗口、`as_of` 规则；做真值来源表和“上次已发布值”基线。写下为什么选它以及排除其他候选的理由。
3. **10 月 4–7 日**：完成 1–2 页提案 PDF：研究问题、赛道、P/E/B 初步设计、数据来源、时点隔离、基线、预期风险。按官方 v0.2.0 做一次离线示例运行，确认实施路径。
4. **最迟 10 月 8 日**：队长在平台提交提案并核对回执；官网硬截止为 **2026-10-09 23:59（北京时间）**。
