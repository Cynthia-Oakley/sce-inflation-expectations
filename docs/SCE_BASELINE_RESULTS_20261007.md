# 五年 SCE 基线：我们需要超过什么？

2026-10-07。**已完成真实数据的离线基线运算，不是新增 LLM 模拟。** 主窗口2020-01至2024-12、60个月，涵盖疫情、通胀上升及回落；全国预测与历史微观重建分别评价。

## 1. 先看结论

全国 SCE 有较强的跨月持续性，简单基线已经很有竞争力。后续 Agent 必须说明：相比这些方法，它提高了全国预测，还是更好地解释了群体分布/关系。当前 LLM 只有两个开发月，不能与五年平均误差直接比较并宣告胜负。

人口条件统计基线改善了年龄/教育群体关系，但对整体分布距离的改善很小。这支持继续检验群体信息体验，不能说明人口特征无用，也不能说明消费篮子机制已经有效。

## 2. 全国指标预测：60月共同窗口

以下均为全国中位数 MAE，单位**百分点**；主真值为纽约联储新闻稿首发值（一位小数）。括号前是**月中CPI发布后**，括号内是**上月末预测下一期**。

- 最后已公布一期不变：**0.240（0.322）**。
- 扩展训练的 AR(1)：**0.274（0.380）**。
- 最近12期平均：**0.787（0.871）**。
- 简单信息更新 Agent，每次新闻发布有25%更新：**0.410（0.515）**。
- 同一规则的10%/50%更新敏感性：**0.740/0.280（0.818/0.392）**。

AR(1)是拟合过去SCE延续规律的统计方法；规则Agent只模拟“有人吸收新信息、有人保留旧判断”。全部使用当时已公开SCE历史，最少12期起步，没有LLM调用。

在该回顾区间，AR(1)没有超过持续性；月中MAE差值约+0.034，六个月块bootstrap区间约[+0.012,+0.063]；上月末约+0.059，区间[+0.022,+0.101]。这不是未来表现保证，早期训练较短、时期非平稳，不能据此取消AR基线或只保留本次赢家。

### 分年差异很重要

持续性基线的月中MAE，2020–2024分别为：**0.150、0.325、0.367、0.292、0.067**。

上月末MAE分别为：**0.142、0.500、0.450、0.383、0.133**。

稳定年份很容易；2021–2022变化较大的时期更难。不能用2024的低误差掩盖变化时期，也不能只用2021的两个大变化月代表长期表现。逐月预测、误差及训练参数均已保存。

## 3. 增加价格信息，是否就能更好？

ARX使用两个特征：最后已公开SCE和最新首发CPI同比，每月仅用截止前已发布标签及当时可见特征重新拟合。

- 月中：2021-01至2024-12，48月，MAE **0.342**；**同48月**持续性为 **0.263**。
- 上月末：2021-03至2024-12，46月，MAE **0.485**；**同46月**持续性为 **0.380**。

覆盖较短是因为CPI证据与训练对数不足；不拿较短时期与60月成绩直接排名。结果不支持“加一个CPI变量就一定改善”，也不否定更合适的价格体验/更新机制。

另有“把最新CPI同比直接当作居民预期”的价格对照：月中60月MAE **1.037**；上月末59月 **1.139**。它不是专业通胀预测模型，只说明现实CPI与居民主观预期并非同一指标。不能据此证明LLM在记忆或照抄CPI。

## 4. 历史人群重建：全国数值接近还不够

这一部分明确是**A路线**：可以使用目标月人口和调查权重，上一月完整微观回答作为已知历史资料；不是B路线可实时使用的输入。官方核心微观资料有九个月发布滞后。[纽约联储FAQ](https://www.newyorkfed.org/microeconomics/sce/sce-faq)

60个月结果：

- 直接延续上一月加权回答分布：W1 **0.505**；年龄×教育分组中位数误差 **0.588**。
- 按目标月人口条件重新混合历史donor：W1 **0.504**；分组误差 **0.475**。
- 已知当月全国中位数、平移历史分布：居中W1 **0.472**；分组误差 **0.537**。
- 已知同一中位数、人口条件混合后平移：居中W1 **0.472**；分组误差 **0.463**。

W1也是百分点：可理解为把模拟分布搬成真实分布所需的平均移动量。人口条件改善了分组关系，整体分布差距没有明显缩小。已知中位数的两组中位数误差为0仅是约束满足，**不计为独立重建成功**。

这些方法只生成个人预期均值/不确定性的分布，未生成完整十档问卷，未宣称复原唯一的真人心理，也不报告逐人配对准确率。

## 5. 来源、版本与证据

- 73份2018-12至2024-12的SCE首发headline及发布日期由纽约联储新闻稿核查；其中2019-11首发为2.4%，与当前chart一位小数有差异，保留首发输入，不用新快照替换。主指标与高精度chart敏感性分开。
- 60份CPI首发稿及五年日历有观测月、发布时间、USDL版本和来源证据。直接HTTP被BLS拒绝，改用web工具取得官方归档文本；提取开头的未季调同比，核对发布日期及报告标题。没有使用FRED当前快照冒充首发值。
- 微观缓存61月（含上一年12月），73,238行，1,210行缺官方Q9派生量；原始记录Git忽略。保留文本年龄/教育标签，分别覆盖73,225/72,798行。重建分布仅用有效均值及正权重；逐月排除/回退另存。
- 官方个人派生均值聚合到chart的60月中位数，最大差约`8.9e-16`pp，仅浮点误差。这里验证的是官方派生值聚合，不是项目Q9近似拟合精确性。
- 原始网页是2026-10-07回顾下载的官方归档，不是当年实时保存的页面；记录来源版本及哈希，不声称拥有每次网页历史修改的完整记录。

### 基线方法的支持与边界

持续性/均值基线和滚动时点验证参考 [Hyndman与Athanasopoulos的预测教材](https://otexts.com/fpp3/simple-methods.html)、[时间序列验证章节](https://otexts.com/fpp3/tscv.html)。最近12期均值是本项目预设窗口变体，AR(1)/ARX为低参数OLS基线，未凭本轮结果调窗或挑系数。

规则Agent借鉴 [Carroll的信息传播结构](https://www.econ2.jhu.edu/people/ccarroll/epidemiologyqje.pdf)，但信号换成了已公开SCE，未接专业预测，更新率为事先规定的参考假设，**不是原论文的完整复现或现实月度更新率估计**。SPF原机制、经历学习、严格B人口分布预测仍待后续，不能把本轮规则版包装成这些模型已完成。

已有LLM开发E未提供过去全国SCE，而这些预测基线可使用其历史。它们是合法的成绩参照；若要解释纯算法增量，还须使LLM获得同样的信息权限。也不能将A当期人口、B旧人口的差值直接解释成模型优劣。

## 6. 验收、路径与接力

正式采用本轮run：`outputs/sce_baselines_20261007T041750Z_5973bbf9/`。

- `summary.json`：全国/重建总表、逐年指标与配对区间。
- `monthly_forecasts.csv`：全国逐月预测、as_of、最后已知SCE、参数及误差。
