## 官方计分链与实现

`Q9 十档概率 → 每人拟合连续密度 → 每人密度均值与分位数 → 用调查权重求跨人中位数`。

- 一档有正概率：在该区间设均匀分布。只有一个开放尾档时使用论文给出的 ±38 边界；公开微观表中 100% 放在 bin 1 的个人 `Q9_mean=25`、`Q9_iqr=13`，与 [12,38] 均匀分布一致。
- 两档相邻有正概率：按论文的等腰三角与锚定规则，用边界累计概率求支持区间；两档不相邻时拒绝拟合。概率不合计 100 时不静默归一化。
- 三档及以上有正概率：按论文的广义 Beta 家族，以区间边界 CDF 的平方距离做最小化；闭合支持端固定为最外层正概率区间的边界，开放尾端在 ±38 内估计。当前实现设 α、β ≥1，使用 SciPy 求解。**论文没有给出完整优化器、起点与所有约束，故这一分支是研究复现，不是纽约联储的原始计分程序。**
- `Q9_mean` 的跨人统计使用有效权重的经验中位数；Q8 点预测的插值中位数是另一口径，已有[单独聚合审计](SCE_DATA_AUDIT.md)。

## 真实数据对照（2020-01 与 2022-06）

两个月分别读取 1,317 与 1,217 条公开微观记录。计分器有效输出分别为 1,285 与 1,201 条；无效或不可拟合的回答保留状态码。以下误差单位为**百分点**，均与同一个人的官方 `Q9_mean` 比较。

- **均匀分布**：2020-01 的 165 人、2022-06 的 156 人，个人均值最大绝对误差均为 0。
- **相邻双档三角分布**：分别 241 人与 144 人，个人均值最大绝对误差均低于 0.000005。
- **广义 Beta**：分别 879 人与 901 人。个人均值绝对误差中位数分别为 0.0000015 与 0.000178，但第 95 百分位为 0.396 与 0.578，最大为 3.869 与 3.018。误差主要集中于开放尾档与正概率档中间有空档的回答。两个月闭合且连续的 Beta 档共 642 人，其中 641 人的误差 ≤0.001；开放尾与不连续档尚不能称为精确复现。
- **月度指标**：直接使用官方个人 `Q9_mean` 与 `weight` 聚合，两个月均与官方 chart 一致，误差低于浮点精度。使用本地拟合的个人均值聚合，2020-01 得 2.502452，对官方 2.495654，差 +0.006798；2022-06 得 6.786921，对官方 6.775855，差 +0.011067。**这些是计分器误差，不是 Agent 预测误差。**

可能原因：论文只给出“最小距离”原则，未公开完整优化约束；对于三档但含开放尾的情况，同时估计支持端与两个形状参数可能只由两个独立档概率约束，不能仅凭公开描述唯一确定数值解。当前不得为匹配官方字段而使用测试期真实 `Q9_mean` 训练一个隐含的后验修正，再称其事前计分。需要寻找原始统计代码、向纽约联储询问实现细节，或把带误差的 Beta 分支明确标注为近似方法。
