# SCE 评价标准与基线方案

2026-10-07。状态：**方法建议，待审；不是已冻结协议，也不是基线运行结果。** 两条研究线沿用 [A/B 研究定义](A_B_RESEARCH_DESIGN.md)，都属于比赛赛道 A。本轮零新增模拟 API，未改原实验筛查条件、计分器或运行配置。

## 1. 先说结论

全国指标、人群分布都要看；逐个人对应误差作为辅助。历史重建主要检验微观结构，下一期预测主要检验全国指标的跨月误差，同时检验预测的分布。不能只凭全国中位数接近，或者只凭回答更分散，就认定成功。

基线需要先建立，包括简单统计方法和简单规则 Agent。先完成少数可复核的基线，再补经典经济学模型；不必先搭完整宏观经济模型。

## 2. 我们究竟在比较什么

- **全国水平**：Q9 十档概率先形成每个人的密度均值，再计算跨人加权中位数。Q8 点回答单列，不能当作同一指标。纽约联储的定义见 [官方图表说明](https://www.newyorkfed.org/medialibrary/interactives/sce/sce/downloads/glossary/frbny-sce-chartglossary.pdf)。
- **人群分布**：比较不同家庭的 Q9 密度均值如何分布，包括中间位置、宽度和尾部。它是“人与人之间的分歧”。
- **个人不确定性**：一个人 Q9 密度的四分位距，说明他自己有多不确定；不同于上面的人群分歧。相同输入重复调用的波动再单列。
- **群体关系**：预先确定年龄、教育、收入等分组，检验分组水平及差距。类别定义、最小有效支持及不报告的稀疏组，在正式评价前确定；不能看结果后只挑表现好的组。
- **逐个人对应**：同一人口画像生成的回答与该真人回答之间的误差。我们并没有观测该真人的全部经历，合成篮子也不是他的真实篮子，所以这一指标不能独占重建标准。

**为什么不能只看逐人 MAE？** 如果只知道一组居民的有限特征，给所有人报该组中位数可能降低个人平均绝对误差，却抹去真实分歧。反过来，随机加噪声也可能拓宽分布，但未恢复真实群体关系。评价必须同时检查水平、分布和条件关系。

## 3. 建议的主要指标

### A：历史重建

**未使用当期 SCE 数字约束的模拟**：以每月调查加权的人群分布距离 W1 为主要量，全国中位数误差为关键配套量；另报人群 IQR、分位数、尾部比例、预设分组差距及个人不确定性。

W1 可理解为：把模拟人群的预期分布搬到真人分布，平均需要移动多少个百分点。它同时检查整体位置和形状；仅报告方差无法做到这一点。有权重时需按加权分布计算，不能沿用等人数排序相减的简化公式。

**显式采用当期宏观约束的重建**：所约束的全国数字只报告“约束满足程度”。若约束仅为全国中位数，主要看减去各自中位数后的分布距离，以及没有作为拟合目标的群体差距、个人不确定性等。若还约束了分位数或分组量，也必须从验证量中排除。未拟合的量仍来自同一调查，不声称它们在统计上彼此独立。

简单非 Agent 重建也应获得同样的宏观约束。宏观约束不能唯一恢复真实个体结构，不能把一组相容答案说成唯一真相。

### B：下一期 SCE 预测

**全国指标的跨月 MAE 为首要预测指标**：

`MAE = 各评价月 |模拟全国中位数 − 真实全国中位数| 的平均值`

单位为百分点。月内按调查/抽样权重聚合，跨月先等权平均，避免调查人数多的月份主导结论。若研究目标还包括下一期人群分布，逐月 W1 是共同主要评价，不能仅展示全国曲线。

建议正式 B 全国指数主表直接对照官方已发布 Q9 系列；同时报告“模拟与真人采用项目冻结计分器”的重算表，量化近似计分造成的差异。两张表分别标明真值、样本纳入和中位数算法；不得混拼官方系列与重算系列来挑最优成绩。A 的微观分布主表用同一冻结计分器处理真实与模拟问卷。

配套报告：RMSE（突出大错误）、平均有符号误差（是否持续低估）、逐月误差、变化方向，以及高/低通胀阶段表现。相关系数或方向一致不能代替 MAE：一直低估 1 个百分点也可能趋势很好。方向比较使用截止前最后已公开指标，持平的处理规则预先声明。

**我们预测的是下一期调查中的居民预期，不是下一期实际 CPI。** 实际 CPI 可作为输入；评价居民是否预测准未来实际通胀，是另一个需要匹配十二个月期限的问题。

### 两条线共同的辅助量

逐人加权 MAE、逐人绝对误差中位数、Q8/Q9 关系、十档回答结构、非法/算法不支持比例。逐人误差与全国曲线的跨月 MAE 名称必须区分。标准差受极端值影响，配合 IQR 和尾部检查。

全国评价使用完整月真值及其调查权重，模拟端处理 Core 抽样概率/调查权重或扩展人口权重；B 的当期真实权重只在事后评价层使用。20/48人等定额小试只能说明对应样本的表现，不直接报告全国恢复程度。配对对照采用共同有效集，另报各臂失败、算法不支持和纳入差异，避免只删掉某一臂的不利记录。涉及尾部的量补预先规定的计分/极端值敏感性，不临时裁剪来改善成绩。

首版不把所有指标加成一个任意总分，也不要求每项指标同时改善。正式卡须预设主要量和关键退化边界；若水平与分布存在取舍，如实报告。旧实验仍按各自预设筛查规则结案，不能用新标准追改为成功。

## 4. 第一批基线：先用现有资料离线建立

### 4.1 上一期不变：最基本的预测参照

下一期全国 SCE 等于截止前最后已公布一期。它回答“复杂模型是否比不更新更好”。分布版采用截止前最新可得的历史微观分布，**不能默认拿到上一月微观数据**；headline 与微观资料的发布滞后不同。若用最新公开中位数平移旧分布，另列为明确校准的变体。

### 4.2 AR(1) 与 ARX：简单时间序列

先仅用历史 SCE 预测下一期，再加入少量截止前可得的价格、就业信号作 ARX，检验外部信息的增量。参数仅在可用历史窗口估计，以滚动方式评价。这些模型输出全国指标，不能凭一条全国曲线宣称恢复个体 Q9。

### 4.3 人口条件统计模型：非 LLM 的分布参照

按人口特征从允许使用的历史调查条件分布中抽取完整 Q8/Q9 回答，保留问题之间的联合关系；稀疏类别有明确回退。后续再考虑条件分位数模型或加入 E。它回答“人口组成和历史统计关系本身能解释多少”。B 的训练微观资料遵守实际发布时间；A 使用什么历史/当期约束须明示。

若 A 使用已知全国指标校准，同样校准这个统计基线。简单平移个人均值只生成均值分布，不能冒充已生成合法完整十档问卷；各基线注明可评价的输出范围。

### 4.4 简单规则 Agent：适应性预期更新

每户保存一个信念状态，看到新价格信号后更新，例如：

`新信念 = (1 − 更新速度) × 旧信念 + 更新速度 × 本期价格信号`

共享信息与家庭价格体验可分别作信号，检验个体接触是否有增量。初值、更新速度和不确定性分布从允许使用的历史/开发资料估计，冻结后验证；不能看到目标月答案再定系数，也不能随意加噪声凑方差。

信念状态不是把该真人上月问卷答案偷偷放进 E。若需从规则信念生成 Q9，应另定义其概率密度与十档转换，并在训练资料上核验个人不确定性。仅输出单一数字的规则版本，只参加相应指标比较。

## 5. 经典经济学模型：值得补，但要按原机制实现

**优先候选：Carroll（2003）的信息传播/黏性信息模型。** 一部分居民更新至专业预测，其余保留旧预期。这直接提供“为什么不是所有人同时吸收信息”的规则基线。[作者论文](https://www.econ2.jhu.edu/people/ccarroll/epidemiologyqje.pdf)

它需要相应历史专业预测，可核查 [费城联储 SPF](https://www.philadelphiafed.org/surveys-and-data/real-time-data-research/survey-of-professional-forecasters)。SPF 为季度调查：须处理发布日期、与一年期 CPI 预期的期限匹配及月度转换。不能直接把原季度更新概率当作月度概率。若把专业预测换成 CPI，须标为本项目改编，不称原论文复刻。

**第二候选：Malmendier–Nagel 的经历学习模型。** 不同年龄的居民对自己经历过的通胀赋予不同权重，年轻人可能更受近期经历影响。它为年龄与历史价格信息的交互提供参照；需要较长历史价格序列，并核验学习参数，不能简化成年龄加一个任意偏置后称复现。[作者研究稿](https://eml.berkeley.edu/~ulrike/Papers/InflExp_44.pdf)

先做适应性规则，再完成一个经典信息更新基线，是可承受的顺序。若专业预测数据期限匹配成本高，先交规则改编并说明局限，经典原机制作为下一阶段；不因文献有名就借用其名称或参数。

## 6. 另有三种内部对照，不能代替外部基线

1. Core 直接加权 vs Normal 扩展：验扩展的增量；Normal 数量不等于新增独立 LLM 证据。
2. 同信息直接问 LLM 全国预期 vs 家庭 Agent：验人口模拟的增量。直接问答若只给全国数值，只参加全国指标比较；重复问答的波动不是居民分歧。
3. 共同 E vs 匹配个体附加信息 vs 置换附加信息：验 P/E 匹配；matched/shuffled 保持总体信息包一致。

各方法获得相同的已知信息权限和约束；特定模型另需 SPF 等额外资料时，登记信息差异，不能把收益全部归因于算法。用于解释方法增量的对照，应再提供相同额外信息的参照。

## 7. 如何评价“长期”和“有改进”

- 当前 2021-05/06 是开发月，只能做诊断，不能证明长期 MAE 或把它们当留出测试。
- 登记此前读过、计分诊断过、调参用过的月份；计分器核验月也不是整个项目从未使用的数据。
- B 采用滚动时间验证，不随机打乱个人记录作未来预测测试。过去可得数据用于估计，后续时期验证；A 的拟合信息与未拟合验证量另列。
- 希望覆盖至少一个年度及不同通胀阶段，具体窗口依历史可得性和使用登记决定；“12 个月”不是统计功效保证。不能只挑有利月份。
- 报告跨月平均与逐月结果、基线差值及不确定性。重复受访者按家庭考虑相关性，跨月结果考虑时间相关；两个月不适合做强显著性结论。
- 抽样、合成篮子分配、LLM 重复三类波动分别估计；不要把全部 Normal donor 当独立样本算很窄的区间。
- 不预设没有依据的“MAE 必须小于 0.5”门槛，不直接拿 CCI 的指数点误差与 SCE 的百分点比较。收益需相对于明确基线、符合任务目标，并在未用于选方案的时期保持。

若以后做概率预测评分，必须先定义“预测的随机变量”：Q9 是家庭对未来实际通胀的主观密度，人群答案分布是另一对象。不能直接把 Q9 密度当成预测该真人回答的密度来算 CRPS。
