# 路线 B 准备：指标修订、人口分布与输入日期

核查日：2026-10-07。离线工作已完成；正式运行配置、预算和旧实验未改，新增真实 LLM / 付费 MCP 调用为零。以下是方案建议和工程验收，不是新的预测效果结论。

## 1. 指标修订：用截止日已经公布的版本

路线 B 预测时，对每个“指标＋观测月份”，取信息截止日前**最后公开的版本**。当时还没有修订，就用初值；当时已发布修订，就可以用修订值。今天下载到的最终值，不能倒填到过去的预测输入。首发值、当时最新可见值、今天最新值需要分开保存。

路线 A 可以使用明确声明的全信息、修订后数据进行历史重建。若要进一步解释“当时居民如何形成预期”，则另外做当时版本的对照。A 全信息结果与 B 预测结果分别评价，不能将 A 的信息权限直接用于 B。

不同指标的制度不同：

- CPI-U 未季调总体和分项指数通常发布即定稿，仍有少数官方纠错。我们多数同比输入属于这个口径；不能和季调 CPI 或链式 C-CPI-U 混用。[BLS CPI FAQ](https://www.bls.gov/cpi/questions-and-answers.htm)
- 季调 CPI 会随年度季节因子重算修订此前五年。2026 年公布的重算结果不能进入 2021 年预测；季调环比尤其要记录版本。[BLS 季调说明](https://www.bls.gov/cpi/seasonal-adjustment/using-seasonally-adjusted-data.htm)
- 非农就业 CES 初值后通常有两次月度修订，此后还有年度基准调整。第三次公布并不表示永远不再修订。[BLS CES 修订制度](https://www.bls.gov/web/empsit/cesnaicsrev.htm)
- 失业率来自 CPS，不能套 CES 的两次月度修订制度。其季调历史数据会在年度重估时修订此前五年。[BLS CPS 方法](https://www.bls.gov/cps/seasonal-adjustment-methodology.htm)

### 已落地的核验

独立程序 `environment_authoring/vintages.py` 可选择 `as_of_latest` 或明确标记的 `first_release`；拒绝无时区时间、冲突版本和缺乏版本证据的记录。最早存到的修订值不会被冒称首发值。后续修订保留为新行，不覆盖原新闻稿。

实证例子：2021 年 3 月非农新增就业最初为 91.6 万（4月2日），5月7日改为77万，6月4日改为78.5万。对应4月末、5月末、6月末的输入应依次为91.6、77、78.5万。`audit_sce_vintage_examples.py` 从已验哈希的官方 PDF 解析4条初值、6条修订，并检验修改金额。

**现有 E 包仍是首发值方案。** 它保存当时可见的首发数据，是可解释的受限信息方案；目前没有收集全部年度修订，不能改称“当时最新版本的完整历史序列”。本轮新增选择程序与真实示例，没有悄悄改旧输入。例子仅覆盖2021年三份报告中的修订，不能替代全时期版本库。

接下来先补我们实际使用的失业率历史序列年度版本、CPI 季调口径和官方纠错，再生成单独的“截止日最新版本”候选。最新非农单月值在下一份报告到来前通常仍是初值；只有实际纳入历史就业时，前月修订才会直接改变该历史输入。逐项比较变化量，避免为了修订增加无关工程。汽油和新闻仍保留版本未核验标记，严格候选共同隔离。

评价对象仍是 SCE 预期：全国公布值与微观派生值各自固定来源版本。修订后 CPI 不是 SCE 的真值；评价未来实际通胀是另一个研究问题。

## 2. 人口检查：规模、权重和轮换都重要

官方当前说明约1,200名家庭户主、最多参加12个月、逐月轮换；核心微观数据滞后9个月公布。加权目标涉及年龄、教育、家庭收入和地区。对象是家庭户主，不能直接当成全体美国成年人。[SCE FAQ](https://www.newyorkfed.org/microeconomics/sce/sce-faq)、[官方方法论文](https://www.newyorkfed.org/research/epr/medialibrary/6501bd82d3bc482891b59df93e24011d.ashx)

### 本地实测

读取人口字段白名单和权重，未读取 Q8/Q9 或通胀派生答案。2017-01至2025-10共106个月、130,216条画像、17,141个受访者；单月976至1,377人，中位数1,260。最新微观月份2025-10有1,044人。因此不能假设每月恒为1,300人，也不能从旧73名持续参与者推断全国人口。

最新月的加权分布示例：

- 年龄：40岁以下27.4%、40–60岁36.6%、60岁以上36.0%。
- 学历：高中及对应官方类别33.8%、部分大学30.3%、大学34.9%，另有1.0%未知。大学组原始样本占56.9%，明显高于加权后的34.9%。
- 收入：5万美元以下41.0%、5–10万美元30.8%、10万美元以上27.5%，另有约0.7%未知。
- 地区：东北17.7%、中西部22.2%、南部37.7%、西部22.5%。
- 就业状态：就业58.5%、退休24.9%、失业类别5.2%，另有残障、家庭照料等。这里失业占家庭户主的比例，不等同于以劳动力为分母的官方失业率。

2020年以后，相邻月份受访者留存率中位数83.4%；当月不在上月样本的人占16.8%，其中既有首次出现者，也有漏答后回归者。首次在已下载文件出现约11.8%，回归约4.7%（各自中位数，不能直接相加）。首月记录左截断，不能判断真正入组日期。这些按答卷 ID 集合计算，不是招募记录；不能用“每月必换1/12”概括这些实际答卷。

加权年龄、地区变化很小；部分原因是调查本身的权重校准，不能解释成人口完全不变。收入、就业变化更明显，例如就业组占比从2020-01的64.0%降到2020-04的53.7%。住房缺失也会变化：只向同一人的过去 Q43 记录回填，报告搬家后失效；最新月约10.3%的加权人口住房类别未知。

全样本42行没有官方权重：保留在原始比例检查，排除出加权 donor，未填造权重。2020年以后权重对应的单月有效样本量中位数约738；人数不等于独立统计信息量。

### 旧画像能代表未来多少？

以“目标月减10个月”为可见画像末月，分别检验最新单月和过去12个月混合。10个月是上月末截止下对9个月发布滞后的保守假设，**不是逐月历史上网日期证明**。这些是已查看时期的分布诊断，没有看通胀答案，也不宣称盲测预测。

采用分布距离：需要挪动多少比例的人口，才能使两个分类分布一致。最新单月的平均距离：年龄约0.2%、地区0.3%、教育2.1%、收入3.5%、就业3.7%。12个月混合对就业、数理能力和住房略好，对教育略差，收入接近。没有一套窗口全面胜出。

**单项稳定不等于联合结构稳定。** 年龄×教育×收入×地区的联合分布距离约18.8%（单月）与17.8%（混合）；细胞稀疏、抽样误差和结构变化均会贡献，不能全部归因于真实人口迁移。这说明应抽整条画像并检验联合支持，不能独立随机拼接四项属性。

## 3. 路线 B 人口如何构建

先采用有现实资料支撑、能复算的朴素方案，留下改进对照：

1. **可得性**：使用 cutoff 前已经下载并存证的画像快照，或有独立公布记录的历史快照；禁止当期未公开画像、权重和答案。历史回测仅有滞后假设的月份单列。
2. **联合抽样**：按旧样本官方权重抽取整条画像，保留年龄、学历、收入、地区、数理能力、就业和住房之间的关联。不是按每项平均值捏人。
3. **两种对照**：最新可见单月为简单参照；最近12个已公开月份混合为敏感性方案，每月权重先归一化、各月等质量，防止大样本月份占据更大份额。重复受访者不会变成独立证据。
4. **Core/Normal**：来自同一套合成人口、同一合成规则。Core 简单随机抽取，维持现有统计扩展的等概率抽样前提；权重已用于合成人口抽样，不能再次乘旧调查权重。Normal 回答将由本次 Core 合法回答扩展，不能拿当期真实 SCE 回答填充。
5. **先验检验**：检查合成后的单项和联合分布、未知属性、Core稀疏组，以及人口方案/随机种子变化是否影响结论。心理属性、消费篮子仍须使用各自截止前已公布的来源，不自动把 A 的侧车搬到 B。

这种方法的支撑是调查加权经验分布和联合重抽样，不保证旧样本正好代表未来。若需要更新年龄/教育/地区目标，可用当时已公布且定义一致的 ACS 家庭户主边际校准；这一步**尚未实现**。收入和就业不能仅凭平稳假设，也不能把全国失业率强塞为家庭户主失业比例。应在开发资料估计转移规律，检查样本轮换和回答缺失，再独立验证其增益。

## 4. 输入日期修正已完成
