# 研究报告图文风格

2026-10-22用户认可的默认风格。参考成稿：[V3.2新闻分配验证](../workstreams/20261021_fullperiod/news_matching_results/index.html)；制作入口：`scripts/report_sce_news_matching.py`。用于后续实验阅读页与汇报，不要求重绘旧成稿。

## 信息顺序

1. 页首先说实验比较什么、主要收益、主要限制和当前取舍；区分“工作上采纳”和“统计验证通过”。
2. 主图聚焦中心误差、分布距离、人际差异；配直接数值、单位和真人/基线参照。
3. 接着展示逐月表现及与机制直接相关的条件分组。
4. 稀疏格、其他指标、缺失敏感性、区间、成本与复算放折叠详情；不让读者先读整页原始数字。

## 视觉规范

- 中文楷体（Kaiti SC / STKaiti / KaiTi），英文与数字Times New Roman；正文行距约1.7。
- 米白底、深色文字；常用对照色：固定参照灰`#777777`、主要候选橙`#c76800`、另一候选紫`#7437aa`、第三候选亮蓝`#0078b5`、真人/照抄黑。避免相近深蓝/深绿。
- 同一报告中同一对象保持同色；跨报告优先保持相同角色的颜色。折线同时用点形和线型区分，不能只靠颜色。
- 柱/点/线与数字结合；坐标必须有单位、好坏方向和样本范围。IQR需与真人比较，不能写成越大越好。
- 图占可读的正文宽度，表格可横向滚动，窄屏卡片改为单列；避免新闻或长标题被挤进窄列。
- 有缺失时清楚分开固定目标人群、直接两组共同样本、四组完整子样本；不同支持上的最低值不能拼成一条成绩。

## 实现方式

优先复用已有报告的配色、图形和HTML结构，读取冻结聚合缓存；本地排版调整不重跑API、不重新拟合Q9。结论与当前配置变更需同步项目记录，不靠修改图题改变原筛选结果。

## 2026-10-24用户补充：研究报告的论证与语言

- 设计先解释“为什么”：理论路径、数据证据、具体操作、控制对照与最终取舍应相连；不要仅列配置和动作。
- 分类变量的MCA碎石图只描述人口共变；选维度的移除重拟合/留出证据、覆盖约束和过采样取舍分别讲清，不能改称PCA直接选出最终变量。
- 面向未接触项目的读者，先介绍SCE及Q8/Q9题意，优先用去标识的真实答卷展示概率→密度→个人均值→人群中位数；标清月份和单人示例，不能称总体典型。
- 使用自然连贯、长短结合的中文；一段只保留必要限定，重复边界集中交代。优先用已有统计图和传导路径图说明依据，而不是增加文字密度。

- 研究报告自然段首行缩进两个汉字；当前紧凑版正文约9.6pt、图表缩小8%，保持楷体/Times New Roman和图例可读性，为后续结果留版面。
