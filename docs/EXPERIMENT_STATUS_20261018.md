# 实验复盘：已采用、保留候选与暂缓方向

更新：2026-10-18（北京时间）。根据已有冻结结果整理，新增API调用0；未更换配置、重跑模拟或重新选择参数。

## 先说结论

项目已经完成从数据、P/E输入、官方引擎模拟到Q8/Q9评价的完整流程，也找到若干局部改善。但**还没有一套新增机制，在扩大验证中稳定超过相同目标的持续性基线**。不能把不同样本中各自最好的成绩相加，称为最终模型表现。

“工作参考中已采用”表示后续实验共同沿用；“有局部收益”表示某些指标或开发月改善；“已验证成功”还需要跨时期、相同权重及基线的检验。三者不同。以下各行只与其原实验中的同批对照比较，数值不能跨行排榜。

## 一、心理匹配变差：目前能判断到哪一步？

四期各48人、两遍生成；原输入384份复用，匹配和打乱新增768份。主加权Q9群体中位数MAE为原输入0.459、匹配0.540、打乱0.459pp。匹配组个人MAE几乎不变（3.581→3.570），人际跨度略增（IQR 2.818→2.977），分布距离却略差（W1 2.505→2.564）。因此不是所有指标都恶化，也不是增加差异就等于更像真人。

**当前更值得怀疑的是“如何赋值、如何起作用”这整条链，不能据此断言心理因素不该加入。**但这只是优先排查方向，本实验尚不能把误差归因于其中某一环。

1. **匹配的是人群比例，不是本人心理。**在年龄、教育、粗收入和地区相近的外部供体中抽取整对幸福感／财务满意度，能保留供体两项之间的关系；没有观测这位SCE受访者本人的心理，也没有恢复其心理与通胀信念的真实关系。同样画像的两个人，谁更不开心、谁预期更高，我们仍不知道。
2. **2018年的状态未必代表后来。**2018 GSS分布迁移到2020—2025不同经济阶段；家庭收入定义和粗分档也有差异。191/192人月有供体支持，只证明能找到匹配记录，不证明分配正确。稀疏类型还需要放宽地区条件。
3. **两句状态文字未必实现心理传导。**模型读到“比较幸福／对财务大致满意”，不等于会像真人一样选择记忆、关注价格、理解政策和更新信念。两项一起加入，本轮也分不出各自作用；它们不是稳定人格、一般乐观或央行信任的实测值。
4. **尚未识别稳定差异。**匹配相对原输入的中心误差差为+0.081pp，按人配对重抽样的95%探索区间为[−0.108,+0.243]；匹配相对打乱的主要差异区间也包含0。改变抽到的人时，改善和恶化都仍有可能，不能说已证明心理有害、无效或匹配一定有错。这也不覆盖换月份的风险。

打乱组同样扩大人际跨度，却未改善分布；本轮尚未显示人口匹配的额外价值。打乱保留同月未加权类别数，调查加权比例可能变化，也不是纯心理因果试验。对照复用自前一批，回包指纹一致仍不能完全排除模型批次变化。

**处理：当前GSS心理标签不加入默认配置，资料与结果保留。**若重启，应优先找同一SCE人的实测状态／变化，或给出可验证的心理传导；不在这四期反复调供体种子、强写“悲观就报高通胀”。

## 五、接下来应集中到哪里

1. **个人信念的保留与更新。**上期原始回答和更早摘要已经输入，剩下的问题是如何使用。先从已有残差确认缺的是惯常高低位置、对新信息的反应还是少数大误差；新试验只改一个环节。
2. **将心理变量与具体行为连接。**优先核查SCE本人状态／风险题等现有事实能否提供增量，外部合成仅作假设。没有依据时不按年龄、性别、悲观程度直接给通胀加减分。
3. **收束验证与参赛交付。**冻结工作参考与失败清单；基线、权重、月份、许可和成本统一说明。B新参与者、人口外推和自身信念递推尚未完成，不能由十二月回访者实验替代。

新机制须另定输入、对照、评价期及预算；本文没有启动下一轮模拟。历史观察过的月份不重新称作独立盲测。当前没有可承诺的低于0.3pp最终准确度。
