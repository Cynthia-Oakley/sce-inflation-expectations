# 下一轮可直接执行的任务

更新：2026-09-27。本文件是短期任务板；完成后记录结果或从任务板移除。报名手续见 [报名与开题的最短路径](REGISTRATION_PLAN.md)，应立即办理，不以完成下列技术审计为前提。

## 1. 候选指数真值审计（最高优先级）

**输出**：依 [指数候选初筛](INDEX_SELECTION.md) 为 `ECO-0078`、`ECO-0086`、`IDX-0100` 各建一份简短审计，包含目标口径、12–24 个连续观测、每期来源 URL 与页码、数值、调查日期、发布日期及缺失/定义变化。各抽检 3 期人工读数。结论只能是：可用 / 限定范围可用 / 不可用，并写理由。

**停止条件**：若目标真值不能连续复核，或无法说明问卷到指数的映射，不进入 Agent 编码；按共同标准比较其他候选。

## 2. 平台离线验收

**输出**：`docs/platform-smoke.md`，记录官方 v0.2.0 的来源与 commit/tag、Python 环境、安装命令、`scripts/demo_offline.py` 的运行结果、study schema 与本项目预计改动点。无需 API key。

## 3. 提案草稿

**输出**：`proposal/` 下的 1–2 页草稿。先写目标和评测协议；若 G0 未通过，草稿保留可替换的目标段落，但不要写虚构的数据结果。

## 4. 外部确认

由你或队长确认队伍/邀请码/导师与回避安排；由数据贡献者确认资料使用和署名。结论填入 `docs/DECISIONS.md`，无需让技术任务停工。
