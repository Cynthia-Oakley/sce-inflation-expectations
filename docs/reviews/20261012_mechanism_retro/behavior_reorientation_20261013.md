# 项目方向复盘：把居民的行为机制纳入研究主线

2026-10-13。依据用户本轮关于历史重建、未来预测、微观评价与 `B=f(P,E)` 的讨论，核对已有实验及原始文献。本文更新既有复盘的方向建议；不是新的实验结果或冻结协议。没有新付费调用，没有修改P/E、运行配置、原回答或计分器。

## 1. 项目的目标应怎样理解

本项目要模拟居民的一年期通胀预期调查。目标是SCE回答及其聚合，不是预测下一年真实CPI；也不是以对未来CPI预测更准确来判断是否像居民。一次调查中的Q8、Q9都面向接下来12个月，连续月度目标的预测区间相互重叠。

历史重建需要同时符合两层观察：总体预期水平与居民之间的分布、群体差异及变化。若使用已知当期全国中位数作为重建条件，可以明确校准，但该中位数就不再是独立验证成绩；仍需报告原始输出和未被用于构造的微观观察。未来预测更强调事先可用信息下的样本外误差，并保留分布评价。

简单全国基线是必要参照，但不是历史微观重建任务的全部价值标准。反过来，提出微观机制不能代替证明其有效。宏观相对吻合、微观结构可信与未来预测增量，分别给证据，不用其中一个的成绩掩盖另一个。

官网当前静态页面仍可核对P/E/B总体框架；详细赛道和评分使用10月10日已经归档的动态内容及用户提供的赛道说明。本次web读取动态脚本失败，不能声称已重新逐项核验当日所有评分细则。原核查在[设计复核](../../archive/2026-10/project_design_review_20261010.md)，官网为 <https://socioverse.fudan-disc.com/challenge/>。官方未给本项目的MAE合格数值，不自行编造“必须低于某值才能参赛”的门槛。

## 2. 两周工作的得失与取舍

### 已经做成：可以保留的研究基础

- 官方框架下的本地真实LLM调查、P/E白名单、逐次提示和回包、费用估计、独立轨迹与重算。
- 真实与模型问卷共用的冻结近似Q9计分；官方Beta逐人精确复刻仍未完成。
- SCE人口和相邻问卷、BLS首发、新闻库存与筛选、合成支出侧车，能够支持机制研究。
- 全国80月、微观70月的历史统计基线；最新Agent机制没有达到同样跨度，不能混称完成长期验证。
- Core/Normal程序可以运行，但Normal复用Core答案不能创造Core中不存在的预期类型。它是节约调用的工程能力，不是修复同质化的机制。

### 有线索但尚未成功：保留央行信心和个人先验

央行信心四时期每期48人的配对试验，样本中心误差0.736→0.565pp，W1仅约改善2.3%；合成Gallup信心不是同一SCE受访者的实测态度。两组均有同一政策短讯，不能归因于增加政策新闻。

个人先验四时期每期12人的配对试验，样本中心误差1.760→1.318pp，W1 3.473→3.102pp。本人先验没有在所有指标稳定优于置换先验；同样本人际IQR仅0.974pp，真人5.502pp。上期原样延续W1 1.704pp仍明显更小。是否正确利用本人信念更新，尚未验证。

全国惯性加权只是输出层诊断。同四期全国参照本人Agent/40%历史组合/最近公开值延续MAE 0.528/0.409/0.400pp；12人非代表性、真实上期微观输入也使它不能当严格B。该加权不改变个人回答，不能当作行为机制已经恢复。

### 尚未稳定奏效：保留负结果，暂停继续堆叠

CE篮子、单品类信息路由、地区汽油/新闻匹配、Q1财务描述、详细或文字年龄经历以及模型切换，未稳定解决中心与分布的双重问题。近期全国价格有弱线索。这些试验否定的是当前表示与分配方案，不能推导为消费体验、地区或人生经历本身没有作用。

购买频率类别记录已在10月13日完成零API分类测度准备，尚未进入真实模拟；不能用支出份额试验的失败来否定频率机制。等价措辞仍仅有离线准备，未完成真实交叉验证。概率表达有诊断，尚未注入。

以上各轮的人口/时期/输入不同，只作每轮内部判断，不按绝对误差排出机制排行榜。完整证据见[原盘点](experiment_inventory.md)、[信心诊断](../../literature/sce/belief_proxies/confidence_response_diagnostic_20261012.md)、[先验记录](../../literature/sce/factual_mechanisms_20261013/prior_trial_execution_20261013.md)、[惯性试算](../../literature/sce/themes/consumersim_inertia_alignment_20261013.md)、[分类频率与面板摘要](../../literature/sce/factual_mechanisms_20261013/summary_public.json)。

## 3. 需要显式研究的f是什么

建议把当前黑箱展开为：

**P与实际接触到的E → 原有信念 → 如何解释新信息并更新 → 对结果有多确定 → 如何填写Q8/Q9 → 聚合。**

央行信心是个人属性，但它的作用要通过“是否认为政策能让涨价消退”的解释规则发挥；上期预期是状态，但它的作用要通过“保留多少、何时更新”的规则发挥。P和f不是互斥的两张变量清单。新增字段只有在模型以合适方式使用它时才有价值。

纽约联储随机信息实验发现，修订与信号强度及原有预期的精确程度相关，预期异质性同时来自信息集与处理规则。[Armantier等，SR543](https://www.newyorkfed.org/research/staff_reports/sr543.html)。它支持把f作为研究对象，不证明我们当前偏差全部由f造成，也不提供可直接移植的美国SCE更新权重。许多经济学研究已有部分解释；不能笼统将所有未解释差异都归为经济学无法理解的真实异质性。

### 第一优先：信念保留与更新

原提示把上期答案列成资料，不一定让LLM把它当成持续的本人状态。先检验模型是否在看到共同宏观信息后过度重置起点，再选择由真实面板支持的更新表达或显式更新程序。

数据基础：已核验106月、103630对有效相邻Q9；月内去中心的相邻关联约0.579，月度未加权Spearman平均约0.636。这些是描述性统计，并受相邻12个月预测窗口重叠、测量误差、选择与轮换影响；不是可直接填写为更新率的参数。当前小试真人/模型描述性斜率0.495/0.134同样不能直接作为规则。

落地比较保持P/E与起点相同：现有LLM、显式本人状态与更新说明、仅用历史训练的简单经验更新器。经验更新器也可成为混合模型的一个模块，但必须单独比较不含LLM的版本，才能说明LLM新增了什么。变化方向、幅度、先验精度和群体关系分别核验，不能只看最终中位数。

### 第二优先：概率表达和不确定性

一个人相信什么、对此多确定、如何用十档概率说出来，是三件事。现有模型在点回答Q8中也过窄，故仅改变Q9表达不能解决整个同质化问题。

[Manski与Molinari，2010](https://pubmed.ncbi.nlm.nih.gov/20368764/)和[Giustinelli等作者原文](https://molinari.economics.cornell.edu/docs/GMM_Rounding.pdf)支持概率取整在人之间不同，并可有跨期稳定性；后者也显示尾部和中间的精度不同。HRS独立概率题不同于SCE十档合计100题，比例与数值参数不能直接搬用。

候选落地：用训练月份的SCE多期原始概率识别粗略表达模式及其不确定性；先做离线映射敏感性，再比较原生表达与有依据的表达说明。个人概率细化程度不足以唯一识别“真实心理风格”，非零档少也可能源于真信念较集中。填0既可能是真正不相信该事件，也可能是近零取整，不能设统一删尾阈值。

提示可说明合法的0、表达精度或近似作答方式，但不指定必须几个非零档、必须通缩为0或必须接近全国值。若使用程序映射，保存映射前后两套概率，核验合计100、中心移动及冻结计分器的分支变化；透明标作报告模型，不把后处理冒充LLM原生输出。前景理论的决策权重不等于问卷中的主观概率，不能直接把一条概率加权曲线套到Q9。

用户10月12日曾选择暂不注入概率风格，本轮提出重新研究。当前更新为可研究的候选方向，尚未把某一风格、比例或阈值正式注入运行配置。

## 4. 评价体系如何补齐，而不事后挑指标

既有全国MAE与W1仍保留；以下是待预登记的新增诊断，不用它们把旧失败重新宣布为成功。

1. **总体水平：**Q9派生个人均值的跨人加权中位数，对齐官方或同样本真值；MAE为主，RMSE与偏差为辅。全国和12人样本不混比。约束后的宏观值与独立预测分开。
2. **整个人群：**个人中心分布的W1，辅以IQR/分位数及预设人口组。W1能比较位置与形状，不唯一确定个体身份或机制；已用宏观约束时另报居中W1。
3. **更新过程：**同人相邻日历月`delta=y_t-y_(t-1)`分布的W1，更新方向比例、变化幅度、零/小幅变化占比及对先验位置/精度的条件关系。漏访不当相邻月。区间和阈值在看新结果前固定。
4. **排序：**同月Agent与对应真人中心的秩相关、delta的秩相关；另比较真人和Agent各自的跨月排序稳定性。合成人口没有同人对应时不报逐人秩准确度。前者测是否把人排对，后者测是否保留持续性，二者不同。
5. **个人不确定性与表达：**个人Q9内部IQR、原始档数/取整/零概率及其跨人分布，Q8与Q9的差异；不强令两个中心相等。

评价要保留“本人原样延续”与“置换后延续”，以及用训练期资料构建的简单经验更新器。直接复制上期答案可能有高秩稳定性及宽分布，但delta全部为0；所以不能只凭前两项或一个相关系数宣布行为真实。

## 5. 方差分解可做，但要修正名称与识别

描述性起点是`y_it = 月份共同水平 + 个人长期偏离 + 本月剩余变动`。第一项表示一群人的共同移动，第二项表示同一人长期偏高或偏低，第三项可能同时有真实个人冲击、报告误差与模型生成波动。

“个人长期偏离”不是“个人惯性”：后者问上期改变了多少会延续到本期，需另看相邻关联或动态模型。加一个滞后项也可能与个人长期成分混淆，并受短面板和测量误差影响；不能由一次回归给三个因果贡献比例。

SCE是轮换、不平衡面板，人口进出会影响月份统计。先用完整真人资料检查覆盖、权重、漏访与入组，再采用明确假设的双向效应/方差分量模型作描述。总体取均值的加法分解也不等于headline中位数分解。只有在规定的正交/独立假设下，方差才可相加；否则须保留协方差，不能机械报三个百分比合计100。

可以优先评价共同移动和稳定个人差异；剩余变动仍用delta分布与条件关系作约束，不能全部忽略。厚尾下方差较敏感，主评价继续有W1/IQR，尾部及稳健敏感性单列。现有四个分散时期与12人小样不足估计一个稳定的模型长期分解，正式估计仍待。

## 6. 接下来按这个顺序推进

**步骤一：零API补齐行为事实。**复用完整真实面板及已有模型轨迹，完善上面的更新分布、排序、先验精度与作答习惯诊断；先清楚定位压缩发生在信念更新还是Q9报告。双向分解先出设计与覆盖验收，不在小样里硬报贡献比例。

**步骤二：用历史训练资料做一个低成本经验更新参照。**独立时期验证，区别个人长期偏移与上期状态；训练/验证按月向前划分，B训练资料还须满足当时发布可得性。未参与该机制选择的时期不能因过去看过简单汇总就称完全盲测，记录实际用途。

**步骤三：冻结少量对照输入。**先对比现有LLM与显式状态更新，保留纯经验更新器；概率表达单独对照，或在更新规则稳定后做二乘二交叉，避免一轮同时改P/E/f及问卷。心理特征与频率只在有数据及传导假设后逐项加入。语言改写作为格式稳健性检查，不作为居民差异的主要来源。

**步骤四：再申请一轮具体范围与预算。**新真实调用前登记人群、时期、主次指标、重复生成、对照、停止条件和数据发送。当前没有新增调用授权或预算申请，也没有改变已批准实验。

路线A可明确条件于真实历史起点来检验更新；未来预测不能逐月取得未公开的本人真实先验，应从可用经验初始分布出发、使用自己生成的状态，另检验1/3/6/12月误差累积。若最终采用统计状态加LLM解释的混合方式，应按实际模块陈述研究，而不是坚持所有行为都必须来自一次自由文本回答。

## 7. 本轮结论

同意将f作为下一阶段主线，P/E已有成果继续作为输入基础。研究问题收敛为：**在相同宏观环境下，原有信念、信息处理与问卷表达能否生成既符合总体水平、又具有真实持续性和变化分布的居民预期？LLM在其中增加了什么？**

成效需由独立观察和有效基线证明，不能靠人为增加方差或调总量达到。当前最有根据的下一项是先验更新；概率表达值得并列研究，但尚无证据能单独恢复人际差异。本轮仅讨论和登记计划，没有声称新机制已成功。
