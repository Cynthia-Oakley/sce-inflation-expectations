## 1. 我们现在到了哪里

**已经跑通真实 Agent 调查与评价流程，但还没有实现可信的 SCE 重建或预测。**目前主要在路线 A 的开发阶段：研究为什么 Agent 与居民回答不同，逐项检验改进机制。路线 B 的历史数据与输入准备已有进展，尚未完成严格的预测验证。

我们要模拟的是居民对未来一年的通胀预期，不是复现当期 CPI。成功需要同时检查：总体指标是否接近、不同居民之间的分歧是否合理、不同人群与时期是否成立。不能仅凭两个月的方向一致或个人误差下降就宣布成功。

### Population：画像与分层已落地，个人生活接触仍不充分

已构造真实历史画像、Core/Normal 分层及 CE 条件匹配的合成消费篮子。主实验每月300名 Core，Normal 由 Core 回答做统计扩展；小样机制实验单独运行，不能混作同一人口方案的成绩。

SCE 自身支出模块已与核心调查关联，发现篮子提供少量额外解释信息。宏观就业/收入更新人口的回测已做，但没有稳定优于现有方法，尚未升级正式 P。

主要缺口是：购物与驾车角色、购买频率、心理和信息接触差异尚未得到充分验证；“数理能力低”等标签是否产生真实的行为差异，也未完成因果对照。

### Environment：宏观与新闻已扩展，家庭体验尚在探索

现有主实验使用77条经济信号及新闻标题＋摘要；历史 E 已扩展并核验，另有延伸到2026年的路线 B 草稿。近期又加入调查月内已公布的汽油周价和乳制品广告价。

主要缺口不是单纯缺更多数据，而是如何把公共信息变成家庭实际接触的信息。当前输入仍像完整宏观简报；篮子份额不能直接代替注意力，地区平均价也不等于个人成交价。日用品、服装及生活接触证据仍待补齐。

### Simulation / Trajectory：真实流程已运行，机制效果尚未成立

本地 SocioVerse 引擎、真实 API、问卷回答、轨迹保存、费用记录和离线复算已跑通。Q8点预测与Q9十档概率均保留原始回答。

已完成300人×两个月主实验，以及篮子、财务状态、信息接触、模型比较和近期价格等小试。另有2021年12个月的旧输入模型比较，但它与当前 E 不同，且含历史回答记忆问题，不能当作最新机制的全年验证。

原生 SCE 本人篮子的真实 LLM 对照只完成准备，尚未运行；真实支出数据外发仍需明确授权，原准备包在执行前也需重新核验源码哈希。

### Analysis：可以统一复算，公平与独立验证仍待完成

Q9使用冻结的近似官方计分器，真实与模拟用同一方法；它不是官方算法的完全复刻。评价同时看总体中位数误差、群体分布、跨人分散、分组差异，并单列Q8；个人误差作为辅助。

持续性、AR(1)、ARX、规则 Agent 和人口条件分布等参照已有长期回测。与 Agent 使用同等宏观和新闻信息的比较尚未全面完成。当前机制仍主要在5、6月开发，不能据此宣布长期优于基线。

## 3. 最重要的实验结论

- **主流程：**300 Core × 2021年5、6月已运行。证明流程可执行，仍存在整体偏低和居民回答过于接近的问题。[主实验记录](CORE_NORMAL_LLM_RECEIPT_20261005.md)
- **合成篮子与财务属性：**已经试过，未带来稳定的整体改善；部分分组差异更接近真人，不能据此冻结最终机制。[篮子试验](PRICE_EXPERIENCE_PILOT_RECEIPT_20261006.md)、[财务状态试验](HOUSEHOLD_STATE_PILOT_RECEIPT_20261006.md)
- **替换模型：**Qwen在旧输入全年小样中有有限改善，但未通过预先登记的升级门槛，分布和趋势也未同步改善。暂缓扩大模型列表。[全年对照](SCE_QWEN_REUSE_RESULT_20261008.md)
- **真实篮子数据：**本地统计显示少量新增解释信息，但不足以单独解释当前大幅偏差；真实 LLM 对照尚未运行。[原生支出研究](SCE_NATIVE_SPENDING_20261009.md)
- **最新近期价格试验：**20人 × 两个月 × 四组，共160份真实回答。近期全国价格使Q9小样中位数误差略降，但不确定性范围包含无改善；Q8没有同步改善。地区汽油匹配未稳定优于随机分配，回答同质化仍明显。[最新实验及追问复核](PRICE_CONTACT_EXPERIMENT_RECEIPT_20261010.md)

这些实验的人口、输入版本和部分生成参数不同，不能直接把各次误差大小排成机制排行榜；应以每次实验内部对照为准。

## 4. 当前瓶颈

1. **总体偏差与同质化同时存在。**仅增加消费份额或换模型，没有解决“居民为什么会产生不同预期”。
2. **信息机制不够贴近生活。**完整统计表可能使模型像经济分析员作答；需要检验信息呈现、个人接触与公共背景的作用，不能先认定它们就是原因。
3. **点预测与概率回答表现不同。**Q9拟合改善不能替代Q8结果，也不能证明概率预测已校准。
4. **验证跨度与公平比较不足。**当前机制缺独立月份、重复生成与同信息基线；路线 B 还需要可得时间、人口合成与真实预测封存的完整验收。

## 5. 下一步优先顺序

1. **先用已有回答解释差距，再准备具体对照。**核对实际输入、原始概率与计分，区分总体偏低、群体差异和问卷表达问题；随后固定事实，分别检验呈现方式与问卷说明。
2. **补个人接触的现实依据。**用 CE Diary 等资料研究类别接触频率，继续利用原生 SCE 支出做本地分析；没有实测的角色与频率明确作为假设，并做敏感性检查，作为后续机制选择的依据。
3. **适时扩大时期，检查改善或失败是否稳定。**先重复生成，再到4—6个候选月份，补齐可比基线；不等待两个开发月被拟合得完美。有可迁移的帮助后再考虑更大规模，持续无改善则收束设计、核验失效范围。
4. **随后推进路线 B。**使用预测时点已可得的人口与经济信息，保留独立验证窗口；不把路线 A 的事后资料直接搬入预测。

这是工作优先级，不是新增付费运行配置或预算承诺。具体实验执行前另留输入、评价规则与运行记录。
