# 消费篮子与信息视图：真实 LLM 小试记录

核查日：2026-10-06。**已完成 200 条真实回答；当前机制未稳定改善重建效果，暂不扩大五组运行。**

## 1. 做了什么

这是赛道 A 的历史重建开发试验，不是 B 线预测，也不是全国 SCE 指标估计。2021-05 与 2021-06 各从已准备的 300 Core 中用 seed=42 抽取 20 人；每月五组使用完全相同的人口、公开事实、问卷和篮子。月间不是同一固定面板。本轮没有 Normal 扩展，没有用真实答案调高模拟水平。

五组分别为原 v2-abstract 基线、居民答题视角调整、消费篮子+视角调整、信息排序+视角调整、消费篮子+信息排序+视角调整。视角调整只是增加家庭答题说明和修改标题，并未将全部信息重写。排序保留所有公共事实和新闻，不能等同于测得了真实注意力。消费篮子为 CE donor 合成的支出背景，并非真实 SCE 家庭消费记录、个人 CPI 权重或购买频率；本轮未使用 Diary。

请求经 SocioVerse2 本地引擎发送至 `https://api.deepseek.com`，模型请求/返回均为 `deepseek-flash`；核查时官方文档将其映射为 DeepSeek-V4.1-Flash。temperature=0、关闭思考、max_tokens=1024、最多一次重试；十个运行分别设 $0.20 闸门，总上限 $2。只发送粗粒度去标识画像、合成支出份额和公共信息，真实问卷答案与调查权重未进入模型。

## 3. 看到了什么

下列数值只针对每月同一批 20 人、等权评价。Q9 指十档概率经冻结研究计分器拟合得到的个人预期均值，再取人群中位数；与官方数值算法仍可能有近似误差。IQR 是中间一半人的取值跨度，用来查看人群是否过度集中。个体 MAE 是模拟与对应真人个人派生值的平均绝对差，不是全国 headline 误差，也不是要求合成画像精确预测该个人答案。真实与模拟的 Q9 使用同一计分器。

### 2021-05

对应真人：Q9 中位数 **3.751%**，IQR **5.204 个百分点**。

- 原基线：中位数 2.983%，IQR 0.851；个体 MAE 4.362 个百分点。
- 仅答题视角：中位数 3.024%，IQR 0.223；个体 MAE 4.109 个百分点。
- 消费篮子+答题视角：中位数 2.995%，IQR 0.810；个体 MAE 4.167 个百分点。
- 排序+答题视角：中位数 2.983%，IQR 0.118；个体 MAE 4.117 个百分点。
- 篮子+排序+答题视角：中位数 3.028%，IQR 0.763；个体 MAE 4.073 个百分点。

### 2021-06

- 仅答题视角：中位数 4.158%，IQR 0.118；个体 MAE 3.741 个百分点。

- 篮子+排序+答题视角：中位数 4.051%，IQR 0.484；个体 MAE 3.684 个百分点。

### 如何解读

1. **主要瓶颈仍在：人群过度集中。** 五组的 Q9 IQR 均不到 1 个百分点，而对应真人约 5.2/5.4；消费背景没有恢复真实分歧。增加样本量能提高估计稳定性，不能自动让模型生成更多有效差异。
2. **消费篮子有响应，但收益不稳定。** 完整机制相对原基线，5 月个体 MAE 下降约 0.289 个百分点，6 月只下降约 0.002；6 月分布距离反而变差。不能据此宣布完整机制有效或最优。
3. **需要扣除共同的提示表达变化。** 相对“仅答题视角”，单加篮子的个体 MAE 在 5 月增加约 0.058、6 月下降约 0.175。原基线对新臂的差异不能全部归功于篮子。信息排序也没有一致收益。
4. **Q8 同样集中。** 原基线两月 IQR 为 0.5/0.0，完整机制为 0.3/0.3；个体 MAE 从 5.975/6.200 变为 6.000/6.275，没有改善。Q8 与 Q9 分开评价，不能强制两者一致。
5. **不把微弱差异当显著发现。** 这里只有每月 20 人，每个条件只运行一次，temperature=0 也不保证 API 完全确定；本轮不能分离随机生成差异与微小机制效应。没有显著性或全国代表性主张。

## 4. 20 人是否足够；下一步怎么做

20 人足以检查接线和发现“回答仍明显集中”，不足以确认微弱收益、稀有人群差异或全国重建精度。样本覆盖三年龄档、三收入档、四地区和不同住房/就业状态，但部分交叉类型人数很少，住房缺失也保留。应先查明机制和模型，再扩样。

- **优先：模型敏感性小试。** 冻结现有输入，用 Qwen2.5-72B / Llama 3.1-70B 的固定 provider 对照检查原基线是否也集中。更早模型同样可能见过 2021 年，不能声称消除训练记忆。见 [模型对照草案](EARLY_MODEL_COMPARISON_PLAN_20261006.md)。新增 OpenRouter 数据发送与预算需独立冻结并获授权，本轮未调用。
- **并行离线：检查环境中的专家叙述与相关性。** 消费代理、油价/食品信息和个人经历应分开；不要为了提高预测直接用真实 SCE 水平校准。当前信息集合中存在明显非经济新闻，可另设计统一相关性规则，但不追改本轮 E。
- **然后：重做机制验证。** 若修改问卷表达、信息接触或购买频率，每次变化有独立对照；价格感知如何转为预期需要理论和数据支持，不把支出份额直接当注意系数。
- **有可解释的改善后扩至每月 300 Core。** 在未参与机制开发的月份、相同抽样与冻结设计下检验；Normal 扩展另报，不能用其掩盖 Core 的偏差。正式全国评价才使用完整月人口和调查权重。
