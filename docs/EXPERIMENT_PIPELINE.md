# 共用实验流程：固定底座，替换一个机制

更新：2026-10-17。首个真实验收是[上期财务前景Q2](workstreams/20261017_financial_outlook/results.md)：768次调用完成，工程可用；该机制没有稳定拟合收益。工程验收与机制成效分开。

## 目前实际支持什么

同一人口/环境下的**单月独立、双组、直接Q8/Q9回答实验**，可配置月份、人数、重复次数、模型参数和预算。沿用官方SocioVerse2 Core、现有SCEDecision接口、原Q9拟合器与现有评价函数。不是新造一个模拟引擎，也不支持直接把此流程冒充B的连续递推。

入口：`scripts/run_sce_frozen_trial.py`，动作是prepare、dry-run、run、worker、evaluate。

## 每次新增机制需要做什么

1. 在`studies/sce_inflation_expectations/experiments/`增加小型准备适配器：提取白名单事实、生成一段输入、记录缺失与来源。当前prepare接Q2适配器，下一机制在此入口明确接入自己的适配器；没有宣称所有机制已经即插即用。
2. 用配置确定月份、样本量、重复及参数。直接复用冻结人口、E与原提示；在确定位置插入信息块，并保存完整实际消息与哈希。保留抽样概率、权重、来源、假设和信息边界。
3. 共用执行器检查协议/预算、来源与提示哈希、干跑、授权、官方API目的地。错误后停止新任务，不自动重试或覆盖旧run。只导出一次源码，不每个job重复复制整仓。
4. 共用评价器核对原回答与动作，调用原解析器/计分器/指标；真人分数直接复用冻结缓存，新模型概率向量按内容缓存。报告共同支持、失败、权重、分月结果和按人配对区间。

准备器不读取本期通胀答案；评价器在全部真实运行后才能打开真值。新增字段/目的地/预算需明确授权，已有授权不重复询问。

## 需要保留的最小核查

- 实际输入是否只改变指定机制，未来信息和真值是否隔离。
- 新增字段/缺失/月份是否符合协议，是否改了人群或权重。
- 少量新增定向测试＋每个配置单元的零API官方引擎干跑。
- 概率合法率、原始回答、实际调用量、费用、运行时间及来源哈希。
- 共用层首次变更或发现异常时做一次独立指标核对；普通候选不重复全项目审计。

旧runner、输入、回答与失败试验不重写。修改共用层要保留新的代码版本；旧结果按其源码提交和来源哈希解释，不能用新实现悄悄覆盖。

## 成果文件与耗时

每轮保留一份聚合JSON、一份简短结果说明；任务板/阅读页只提供摘要与链接。私有人月、完整提示/回包只在被忽略的本地outputs，不能直接提交GitHub。

本轮可测步骤：缓存诊断约0.28秒、材料准备0.34秒、官方引擎干跑执行窗口约4.6秒、真实API约277.5秒、评价约20.4秒。进程启动/导出与代码开发、阅读/审阅不全部包含在这些数值中，不把它们相加冒充完整端到端时间。共用层的首次开发是一次性工作；后续重点复用，不再复制一套全流程。
