# 从“指标跟踪”选目标｜初筛记录

更新：2026-09-28。**当前主线已转为用户认可的 SCE 美国居民通胀预期调研**，见 [项目方案](SCE_PROJECT_PLAN.md) 和 [数据审计](SCE_DATA_AUDIT.md)。SCE 是清单外补充目标；BIE 为附加方向。以下 9 月 27 日及更早的清单内排序作为历史记录，不再代表当前优先级。原清单来源是 `../../指标跟踪/global_index_candidates(1).csv`、`../../指标跟踪/global_economic_index_candidates(1).csv` 和相应 `methodology/<ID>/` 缓存，共 551 条候选。

## 筛选顺序

1. **属于教授提供的清单**，且统计目标能用一句话精确定义。若教授要求严格的“官方指数”，优先选名称与发布方法均明确的指数。
2. **能做 P→E→B→聚合**：目标由人的/企业或专家的回答构成，能解释“谁在回答、看见什么、如何作答”。纯文本计数、物理测量与市场价格不适合直接照搬 ConsumerSim 问卷范式。
3. **真值可回测**：连续历史值、调查期、发布日期、问卷和聚合规则可核验；公开报告不等于有可复用数值表。
4. **与既有案例区分**：避免只是把美国消费者信心换个发布机构；重视新的人群或机制，同时控制一个月内能完成的工作量。

## 四个需要审计的候选

- **ECO-0078｜ACCA–IMA Global Economic Confidence Index**：专业人群调查的**正式指数候选**，须先解决受访者构成与精确真值问题。来自会计师及财务专业人员季度调查，能形成专业人群 Agent 与财务信息环境；[ACCA 官方报告归档](https://www.accaglobal.com/policy-and-insights/report-archives/global-economic-conditions-archive.html)有历史各季报告。早期官方报告存在回答比例和指数的对应表，近期公开报告的口径延续性、权重和精确历史序列仍需核查。
- **ECO-0086｜OECD G20 Business Confidence Index**：正式月度指数，官方 [定义](https://www.oecd.org/en/data/indicators/business-confidence-index-bci.html)与数据入口较明确。主要风险是它是各地制造业调查的标准化综合指标，无法把少量企业 Agent 的回答直接等同为 G20 的 100 基准指数；需复核原始构成及是否能定义可比研究目标。
- **IDX-0100｜Ipsos What Worries the World**：确实在“指标跟踪”CSV 中，标注 `B_index_like`、`include`。因一般公众问卷和月度事件环境与 ConsumerSim 机制贴近，之前被建议为首选；但它是一组问题的比例，**不是单一官方综合指数**，且[官方页面](https://www.ipsos.com/en/what-worries-world)提示国别完整分解可索取。除非明确某国某题的连续公开序列，并确认这种调查比例符合导师的“指数”要求，否则不定题。
- **ECO-0088｜UN Tourism Confidence Index**：由旅游专家调查形成，官方 0–200 量表，领域差异性强。[官方指标说明](https://www.untourism.int/un-tourism-world-tourism-barometer-data)可查；主要风险是低频、历史数值和专家画像不易取得。

## 暂缓

- `IDX-0004` / `ECO-0089` World Sentiment Index 虽有正式月度数据，但基于 EIU 国别报告正负词评分；直接用新闻文本和 LLM 重造词频，不足以证明 Agent 调查模拟的价值。
- `IDX-0099` / `ECO-0082` Ipsos Global Consumer Confidence Index 与 ConsumerSim 的消费信心题材重合；前者在非经济清单中也被标为 `exclude_strict_economic_boundary`，不能把它当作“换领域”的优先目标。

## 9 月 27 日候选与实施需求

本轮根据“人口数据匹配、信息时点、月/季度有效样本和工程量”重新排列。建议优先核查 WWTW 美国通胀担忧比例、ACCA–IMA 信心指数，并保留 Ipsos 美国 Jobs 分指数；FAO 糖价仅作为需要市场内生机制时的另一路线。美国子序列是清单内全球项目/指数家族的范围收缩，不等于已经重建清单中的全球总值，需在最终选题时确认这一范围符合导师要求。

### A. IDX-0100｜WWTW 美国通胀担忧比例：条件性优先

- **目标与问题**：模拟美国受访者在完整议题选项中选择主要担忧，取选择 inflation 的加权比例。研究实际价格压力和议题注意力能否共同解释该比例变化。它是调查统计量，不是官方单一综合指数；导师是否接受该口径是定题条件。
- **已核验**：调查按月发布，当前官方页面说明完整国别和议题分解可索取；2020 年官方问卷明确要求从议题列表中选择三项。题目、选项和年龄范围必须按拟研究的各期再核查，不能自动把旧版沿用至全窗口。
- **目标数据**：先核查 12–24 个月美国通胀担忧的精确百分比、原始题目、全部选项、田野期、年龄与覆盖范围。理想正式窗口为 36–60 个连续月份，这是规划建议，尚未取得。报告或图表提取须人工复核；无法连续取得就淘汰，不能插值伪造真值。
- **P 数据**：ACS PUMS 或 SIPP 中与调查年龄、地区、收入、教育、就业和住房情况匹配的样本与权重；这些是公开人口代理，不是 Ipsos 原始受访者。第一版不必添加 GSS 心理属性。人口版本需符合历史研究窗口，使用静态人口的偏差需披露。
- **E 数据**：少数按发布日期截断的 CPI/食品能源价格、实际收入或工资、失业信息；固定来源和选择规则的历史新闻/政策事件。还要覆盖问卷中的主要竞争议题，不能只输入通胀新闻却要求 Agent 在完整议题中选择。
- **工程**：报告取数与时点表 → 人口抽样与加权 → 每月信息快照 → 按完整问卷进行选择 → 计算单项比例 → 留出回测。加入人口同质化、去事件信息的对照；多选题的各项比例不能强制和为 100%。
- **主要风险/工作量判断**：模拟工程中低，历史国别取数中高；最大门槛是连续真值和统计量名义。
- **来源（2026-09-27 核查）**：[当前官方页](https://www.ipsos.com/en/what-worries-world)、[2020 年问卷](https://www.ipsos.com/sites/default/files/ct/news/documents/2020-04/what-worries-the-world-april-2020-ipsos.pdf)、[ACS PUMS](https://www.census.gov/programs-surveys/acs/microdata.html)。

### B. ECO-0060｜Ipsos Jobs 分指数的美国序列：正式月度备选

- **目标与问题**：重建美国就业信心分指数，研究劳动市场总体状况与家庭就业暴露为何产生不同信心变化。必须增加并检验这一机制贡献，不能仅替换 ConsumerSim 的目标名称。
- **已核验的零散真值**：官方美国发布页中，2024-01 为 66.7、2024-02 为 62.3、2024-04 为 66.5、2024-08 为 66.2、2024-12 为 68.9；2025-05 为 60.3、2025-09 为 62.0；2026-09 为 63.5。只证明这些离散月份可取得，不代表已形成连续回测序列。2026-09 页面还公开田野期 2026-08-21 至 09-01，以及 1,000 名 18–74 岁美国受访者的范围。
- **目标数据**：连续月度 Jobs 数值、田野期、Jobs 对应题目和各答案的当前计分权重、基准与历次改版。2017 年 Ipsos 方法说明涉及 Shapley 分析得到的权重；不能用等权平均冒充官方分指数，也不能不经验证套用旧规则。
- **P 数据**：CPS/ACS 或 SIPP 的年龄、教育、就业状态、行业/职业、家庭经济情况及权重。BLS 确认 CPS 公开文件包含人口、劳动状态、地区和权重。官方当前问卷还涉及家庭/熟人时，不可把每个 Agent 都视为独立劳动者而忽略这类暴露；缺少关系信息要设明示假设并做敏感性分析。
- **E 数据**：截止时点已发布的失业率、初请失业金、职位空缺/裁员或行业就业信息，以及固定来源的裁员/招聘新闻。逐序列核对公布滞后，不能用当期尚未发布的 CPS 微观文件构造当期 Agent。
- **工程**：网页真值提取 → 问卷版本与计分器 → 劳动人口/家庭画像 → 行业相关信号分配 → 问卷回答 → 官方计分 → 同输入基线和消融。人口可先固定，避免一开始建立逐月个人就业转移系统。
- **主要风险/工作量判断**：人口与美国环境资料较有利；工程中等，但当前题目权重未核实，且消费信心题材与 ConsumerSim 接近。取不到计分规则时不能称为逐项重建，降为代理预测则研究贡献需要重新评估。
- **来源（2026-09-27 核查）**：[2024-01](https://www.ipsos.com/en-us/january-2024-lsegipsos-primary-consumer-sentiment-index)、[2024-12](https://www.ipsos.com/en-us/december-2024-lsegipsos-primary-consumer-sentiment-index)、[2025-05](https://www.ipsos.com/en-us/may-2025-lsegipsos-primary-consumer-sentiment-index)、[2025-09](https://www.ipsos.com/en-us/september-2025-lsegipsos-primary-consumer-sentiment-index)、[2026-09](https://www.ipsos.com/en-us/september-2026-lsegipsos-primary-consumer-sentiment-index)、[2017 年计分说明](https://www.ipsos.com/en-us/news-polls/global-advisor-global-consumer-confidence-july-2017)、[CPS 公开微观数据](https://www.bls.gov/cps/data/public-use-file.htm)。

### C. ECO-0078｜ACCA–IMA 全球经济信心指数：专业人群首选候选

- **目标与问题**：模拟财务专业人士对经营前景的信心变化，检验企业所处行业、规模和融资压力如何改变对同一宏观信息的反应。问卷真实对象究竟是所在组织前景还是宏观判断，按各期原题确定。
- **新增证据**：2012Q2 官方表同时提供五类回答比例和对应指数；表中数值在舍入误差内支持“更有信心比例减去更无信心比例”的净余额解释。它改善了早先“完全无公式线索”的判断，但尚不能证明 2019–2026 年题目、计分与权重不变。
- **目标数据**：多年季度精确指数及可用地区子序列、原始题目、调查日期、样本量、行业/规模/职位/地区构成、权重和口径变化。季度有效样本少，优先争取约 8–10 年同口径数据；这不是赛事硬门槛，当前未核实可得。
- **P 数据**：首先寻找 GECS 样本构成或经授权的受访者数据；其次以其公开分层构成合成人群。普通人口微观数据不能替代全球 ACCA/IMA 调查样本。只标注“CFO/会计师”而没有企业或地区结构，不足以声称代表性重建。
- **E 数据**：相关地区当时公开的经济活动、价格成本、利率/融资条件、汇率；配套贸易、监管与金融冲击事件。针对行业和融资暴露分配信息。全球目标需要相应的地区覆盖，单一区域输入不能代表全球环境。
- **工程**：季度 PDF 数值与样本结构提取 → 专业人群分层 → 地区/行业信息映射 → 信心变化回答 → 经过核验的净余额/权重聚合 → 小样本回测与权重敏感性。若缩到某一区域须先证明子序列连续且符合选题范围。
- **主要风险/工作量判断**：金融相关性和区别于 ConsumerSim 的空间较好；资料整理与人群建模工作量中高。没有连续精确真值或足够的专业样本构成时，不升为最终首选。
- **来源（2026-09-27 核查）**：[历季官方报告](https://www.accaglobal.com/policy-and-insights/report-archives/global-economic-conditions-archive.html)、[2012Q2 官方表 1，PDF 第 6 页](https://www.accaglobal.com/content/dam/acca/global/PDF-technical/global-economy/tech-ms-gec14.pdf)。

### D. ECO-0181｜FAO 糖价指数：市场机制备选，暂不进入问卷主线

- **目标与问题**：通过供求预期、库存约束和报价形成单商品价格，再映射到糖价指数，研究供给冲击后的价格调整。选择此题意味着另定市场行为研究范围。
- **已核验**：FAO 有月度历史指数文件。旧版官方 Food Outlook 将糖指数关联到 ISA 原糖价格，后者由 ICE No.11 的期货报价构成；现行合约处理、价格聚合和 2014–2016 基期规则仍应单独核实。总食品指数的五组出口权重不是糖子指数自身的公式。
- **数据**：月度糖指数；官方引用的原始报价、合约期限/换月与基期；产量、库存、消费和进出口的历史发布版本；主要产区天气、汇率、能源价格和政策。FAO/USDA 报告可作为供求资料线索，不代表所需逐期输入已齐全。
- **Agent 状态**：生产/库存能力、订单需求、资金、风险约束和预期。交易者真实心理画像通常不可得，需要依据供求与行为事实设参数并验证；公众 SIPP/GSS 无法直接解决此问题。
- **工程**：供求资料时间对齐 → 规则式市场基线 → 预算/库存约束与清算或撮合 → 有限 LLM 预期模块 → 报价到指数映射 → 价格、成交和约束共同验证。只让 LLM 报一个价格，或输入目标期官方报价机械重算，都不足以检验内生价格形成。
- **主要风险/工作量判断**：真值容易，可信市场状态与价格形成难；四者中工程量最高，当前比赛不优先。
- **来源（2026-09-27 核查）**：[FAO 官方数据](https://www.fao.org/worldfoodsituation/foodpricesindex)、[2019 Food Outlook 糖价附表](https://openknowledge.fao.org/3/ca4526en/ca4526en.pdf)、[USDA 糖供求历史报告示例](https://apps.fas.usda.gov/psdonline/circulars/2020/10/sugar.pdf)。

### 对其他早期候选的调整

- OECD G20 BCI 保留为后备：官方月度序列明确，但不同国家企业调查、人群构成、标准化和聚合需要更多工作，取数容易不能自动转化为微观重建容易。
- UN Tourism Confidence Index 暂缓：专家画像和连续低频真值仍是门槛。
- 同一候选若只有全球值、没有国别值，不得因想做单国最小版就虚构国别真值；也不得以事后回测误差决定国家或目标。

### 共用工程与验收

复用 SocioVerse2 的 study/运行框架；具体接口实施时按当前公开版本核对。前三条路线共同需要真值表、人口抽样与权重、按发布时间冻结的信息快照、结构化回答、聚合器、按时间留出的评估、基线和运行日志。宏观历史版本可核查 [ALFRED](https://alfred.stlouisfed.org/help/downloaddata)，不假定其覆盖每条输入。

先对通过数据门槛的一条路线做少数历史期的离线流程和小规模 LLM 试跑，再按抽样稳定性决定 Agent 数。首版不强求多国、完整人格拼接或大规模人口扩展；模型调用量应按“期数 × 核心 Agent 数 × 重复次数 × 实验条件数”预估，增加人口或消融前先测实际成本。全程执行 `RESEARCH_PROTOCOL.md` 的时点和测试集协议。

**本轮交接**：输出为本文件更新；已验证部分官方入口、问卷线索与离散数值；未验证连续取数、现行计分参数、完整人口匹配、数据许可及可再分发范围；下一步是优先核查 WWTW 与 ACCA 的硬门槛、同时核查 Jobs 当前公式。尚未运行模拟、选定目标或向外部机构索取资料。

## 9 月 30 日的选题门槛

优先对 IDX-0100、ECO-0078 和新增审计的 ECO-0060 抽查至少 12–24 个连续观测、公开来源、调查/发布时点、口径断点、人口匹配和可再分发性。这个数量用于查可行性，不是充分评估样本量。先用可核验性筛掉不可做的目标，再在合格目标之间比较社会科学问题与 Agent 机制。最终选择和排除理由写入 `DECISIONS.md`，避免事后按回测成绩挑题。
