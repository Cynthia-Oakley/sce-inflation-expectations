# 同信息基线与长窗口 Agent 实验

2026-10-07。状态：研究方案与零 API 准备；未冻结新实验，没有追加真实调用。此说明补充评价 v1，不覆盖旧配置、结果或 Kimi 待审批次。

**同日用户补充：暂不使用 TF-IDF，直接采用句向量。** 后续编码方式与训练/评价用途见[句向量和时间划分说明](SCE_NEWS_EMBEDDING_AND_SPLITS_20261007.md)。历史已运行基线不变；新基线与日期划分仍是待数据齐备后冻结的候选。

## 1. 本次需要修正什么

旧基线回答的是“是否胜过沿用上一期、短历史回归等简单方法”。它们仍值得保留，但不能单独支持“Agent 在同样信息下更有效”。已有基线能读取公开历史 SCE，Agent 的 E 没有这一项；Agent 又有更多价格序列和新闻、A 线当期画像。信息权限有双向差异，不能仅凭模型名或输入数量判定公平。

接下来分两张成绩单：**基础参照**保留旧持续性、AR、均值；**方法比较**使用共同输入、共同截止时点、共同目标月份。全国成绩仍以官方首发 Q9 指标为主；A 的微观结构另用同一冻结计分方法验证，不把只预测全国一个数的模型说成能重建微观结构。

## 2. 如何让信息相同

每月生成一个共享 P/E 输入包，再让不同方法从这个包读取数据：

- E 的数值、参考月、发布日期和版本完全相同，保留各条历史序列，而不是只给最新 CPI。
- 新闻使用 Agent 实际收到的同一批标题和摘要，不另换媒体或在看到答案后筛选。
- A 比较中，各方法可以访问同一当期画像、合成消费侧车与评价权重；全国统计模型可将画像转成人口比例，个体统计模型直接读取画像。只使用 E 的模型明确标为部分信息对照。
- B 另建截止前人口与环境包，不将 A 的当期人口、调查权重和作答日期拿来预测。
- 若采用公开历史 SCE 作为额外输入，两方均加入；默认同信息实验保持现有 Agent 的 E，不悄悄新增历史 SCE。历史 SCE 作为统计模型过去的训练标签，和作为当期输入特征，是两种不同用途，分别记账。
- 新闻向量、缺失值填补、标准化、降维与参数选择只能利用当前训练部分。两方的来源权限相同，不要求输入表示形式相同。

`prepare_sce_shared_environment.py` 已实现无网络导出：原信号、原新闻、广播原样保留，另生成可训练的数值列与新闻文本。当前全年为 12 月×77 数值列、每月 30 条新闻，无缺列。它只校验现有发布时间元数据；汽油月均价格有 13 条/月份使用推定发布时间或未独立核实 vintage，原有不确定性保留，不能因此升级为严格 PIT 证据。严格预测要给所有方法共同采用经补证的数据，或共同排除该部分。

产物：`outputs/sce_shared_environment_20261007T060912Z_4ef6ec3e/`，其中 `shared_environment.jsonl` 为共同 E、`manifest.json` 为输入哈希和缺口。未混入任何当期 SCE 答案、全国指标或人口 ID。原 E 未修改。

## 3. 补哪些基线，分别检验什么

ConsumerSim 原文 §6 确实列出 AR Ridge、SARIMAX Macro、News Semantic FAAR、Macro–Market–News Ridge，并有 ETS、Theta、Auto ARIMA、Prophet 等时间序列参照。我们优先借鉴覆盖的信息类型和比较逻辑，不按“列够模型个数”验收。其完整逐次参数、训练数据/运行实现仍需核对，不能把我们的适配版写成完全复刻。

**第一优先：全宏观 Ridge。** 用共享 E 的价格分项、汽油、失业率、非农及全部历史列预测当月 SCE，惩罚较大的系数以防 77 个相关变量在短月序列上过拟合。它检验“这些公共数据用常规统计模型已经能做到什么”。原小 ARX 保留，但不担任唯一宏观模型。

**第二优先：宏观＋同批新闻 Ridge。** 按用户补充意见直接用固定句向量模型编码标题＋摘要，汇总为月度向量，再在训练月份内拟合低维文本特征；不做TF-IDF。原新闻文件仍可审计，不能只用新闻篇数就称与理解新闻的 Agent 同信息强对照。须记录编码器版本、训练年代、文本长度与成本，降维仅使用过去训练月份。

**第三优先：宏观 SARIMAX。** 用相同数值 E 比较另一类时间序列方法，阶数候选限于非季节 `(1,0,0)`、`(2,0,0)`、`(1,0,1)`；短数据不同时搜索大季节网格。它与全宏观 Ridge 一起避免只挑一种统计模型。训练标签有发布滞后时，不能用未知月份的目标或假装缺口不存在；应显式保留缺失目标状态，或使用截止条件的直接多步回归适配。

**第四优先：同模型、同 E 的简单 LLM 对照。** 同一模型直接预测全国 SCE，不构造居民、不使用 Normal；另加人口汇总比例版本。与完整 Agent 的比较能区分“LLM 自带知识、新闻理解”与“微观人群设定、聚合机制”的贡献。新的真实调用另列运行卡，不在本轮执行。

**A 微观结构还需人口＋E 的统计对照。** 使用过去月份的居民画像和相同 E 训练条件分布/分位数模型，再重建当期分布；和 Agent 一样报告中位数、IQR、完整分布距离与组间关系。全国回归和微观重建分别验收。旧人口 donor 基线未使用完整 E，继续作为低信息参照。

拟实施调参范围：Ridge `alpha={0.1,1,10,100}`；新闻句向量训练内降维候选 2/4 维，统一过去窗口选型。以上为候选，不是已验证最优参数。每次重新训练仅允许截止前已公布的目标标签；宏观/新闻历史特征必须在各自原 cutoff 重建。评价按共同预测月份对齐，缺失或失败均留记录。禁止随机拆分人月或全期拟合标准化/降维。

**当前真正的准备缺口是历史 E 训练样本。** 2021 全年 E 已就绪，但尚不能用这 12 个点训练 77 列模型后在同一年报告样本外误差。现有新闻缓存主要覆盖 2020-10 至 2021-12，CPI 分项首发参考月也不连续覆盖全部训练期。需要补训练期的共同 E（建议至少 36 个月），再走滚动训练/验证；在资料未齐之前不虚构新基线成绩。2021 各月不同历史标签可得期与训练窗会使早期覆盖不足，必须报告。

## 4. Agent 的长期验证做到哪一步

已有 **73 人×2021 全年 12 月** 的旧版 LLM 实验；最新 PE v2、300 Core＋Normal 的版本仅 **2021-05/06**。前者人口为全年完访者、E 较旧，不能把它与两月新版拼成一条一致的长期成绩。

下一轮优先 **2021-01 至 12 全年同配置复跑**：当月完整人口作为 A 人口框、固定随机优先级选 Core，其余保留 Normal；prompt、模型、温度、计分、收缩参数与 E 规则不按每月效果换。逐月独立运行，沿用“不输入本人上期回答”的约定。这能检验全年拟合和动态变化；独立月运行不能证明持久记忆或社会互动。

2021 是已看过的开发/复查窗口，不称盲测。全年稳定后扩到 2022-01 至 2025-10，先补 E 再运行；这些时期的官方基线或描述统计已被查看，也不能宣称从未见过结果。机制选型另按预先声明的开发、验证、评价用途分开，不在同一月份上同时调框架和宣传最终效果。B 作为独立配置推进，不给 A 实验套上未来预测的标签。

各窗口并列全国 MAE/RMSE/偏差、每月误差和 6/12 月滚动误差；有微观真值的月份另报 IQR、完整分布距离和人口组误差。按通胀升温、缓和等阶段看误差，阶段定义在正式运行前登记。人与月份的重复均不自动视为独立样本。

## 5. Core 与 Normal 怎样缩减

**优先缩 Core，保持完整 Normal 人口框。** Normal 不消耗模拟 API；等比例缩小两层会削弱人口分布参考，却不节约更多 LLM 调用。只有要测总人口规模效应时，才另设等比例小人口实验。

没有通用的“Core 最小人数”。需分别看全国中位数的抽样波动、小群体是否有 donor、分布和尾部是否被覆盖；模型输出本身错误与抽样误差也要分开。Normal 扩展不能产生 Core 从未生成的预期类型。

本轮零 API 检查固定 75/100/150/200/300 人，每月 30 次嵌套抽样、跨月固定优先级，全年 12 月。真实受访者回答只在离线诊断中当作 Core 的理想回答，选择人时不看回答，Normal 真值只用于评价；量化抽样/统计扩展带来的损失。这不是“真实 LLM 误差”，Q9-only 有效 donor 也比正式联合 Q8/Q9 条件宽松。

已用现有两月 300 个 LLM 回答做 100/150/200/300 的 30 次嵌套下采样，没有新调用。所得结果只能代表已生成回答，不能保证未来月份或其他模型稳定。若改分层优先抽稀有组，必须同步修改抽样概率和扩展权重合同，不能套现有等概率 SRS 程序。

### 本轮实测与建议

全年理想 Core 诊断共 1,800 组抽样结果；扩展中位数平均绝对误差：75 人 0.643、100 人 0.550、150 人 0.427、200 人 0.345、300 人 0.263pp。扩展分布 W1 平均依次 1.444/1.198/0.950/0.783/0.608pp；Normal 中没有本细组 donor 的权重平均为 13.9%/10.0%/6.7%/4.8%/2.8%。300 的加权有效 Core 人数平均约 182，并非独立的 1,300 人。

真实 LLM 下采样的波动明显小：100 Core 相对原 300 Core 扩展中位数平均偏差，5 月约 0.020pp、6 月约 0.069pp；完整两月结果见下列独立产物。这个比较不读取真实 SCE，因此是稳定性而非准确率。原回答分布很窄，少量 Core 看起来稳定，不能据此判断已覆盖真人的多样性。

**建议全年主运行保持 300 Core，Normal 保留完整月人口；150/200 的人口规模敏感性从这 300 份真实回答下采样完成。** 这样优先增加时间跨度，同时不增加规模对照的模拟 API 调用。若需要迭代更快的探索版，可考虑 150/200 Core，但不把它当已证明充分的正式样本。没有预设可接受误差门槛，本轮不根据结果宣布某人数是“统计最小值”。

准确产物路径：

- 全年理想回答诊断：`outputs/sce_core_size_20261007T061115Z_ec4e8ba9/summary.json`、`draw_metrics.jsonl`、`independent_checks.json`。
- 5 月现有 LLM 回答下采样：`outputs/sce_core_size_replay_20261007T061426Z_74fe5ffd/`。
- 6 月现有 LLM 回答下采样：`outputs/sce_core_size_replay_20261007T061510Z_93b5b374/`。
- 程序：`scripts/check_sce_core_size.py` 与 `scripts/replay_sce_core_size.py`；前者不依赖引擎/计分器注册，后者复用归档拟合值并重算少量未归档 donor，未修改计分程序。后者完整干净克隆复现仍受 Kimi 待审计分批次影响，不能将本机验收写成整仓自包含。

验收：来源与人口缓存哈希同原人口构建记录相符；独立复算首个抽样的中位数与 SciPy W1 一致；21 项评价/共同 E 测试通过。没有付费服务或真实 LLM 调用。

干净本地克隆 `bd653d4` 再验：21 项测试通过，共同 E 导出文件与本机 SHA-256 完全一致，Core 规模入口无需引擎或待审计分器即可导入；完整规模数值重算仍需本地微观数据，LLM 下采样仍需上述计分依赖。回执为全年检查目录的 `clean_reproduction_receipt.json`。[浏览器结果页](SCE_FAIR_COMPARISON_20261007.html) 已通过 HTML/JavaScript 检查，三种指标和费用选择器实际执行通过；尚未做真实浏览器视觉验收。

成本按旧实验实际估算仅作量级参考：600 调用约 $0.536，平均约 $0.000894/条。全年 200 Core 约 2,400 调用、$2.15；300 Core 约 3,600 调用、$3.22。后续历史补齐、新闻长度、重试和价目变化会影响实际支出；正式运行重核费用并设置总上限，旧授权不自动覆盖全年。

## 6. 接下来的顺序与完成标准

1. **已完成**全年离线 Core 规模检查与已有 LLM 回答下采样，保留全网格和月份结果，不挑有利随机种子。
2. 补历史训练 E：宏观与新闻来源、截止、信息权限都能与 Agent 对账；先实现 Ridge，再加新闻、SARIMAX 和简单 LLM 对照。
3. 形成全年 A 新运行卡：Core 数、人口与 E 来源、模型身份、参数、费用、评价月用途均明确，干跑与实际提示预览通过后确认预算。
4. 新版全年运行完成后按共同输入/月份比较；同时报告人群分布，不能用全国拟合代替微观合理性。

原统一评价、长跨度基础基线、运行配置均保留。公开数据的小型说明可提交，个人记录、原始新闻和运行产物仍只保存在忽略目录。
