## 1. 你看到的 0.5% 从哪里来？

2021 年 1 月，同一 20 人开发样本中：

- 真人 **Q8 点预测中位数 3.0%**；DeepSeek 2.0%、Qwen 1.5%。
- 真人 **Q9 概率回答推导出的中心中位数 2.951%**；DeepSeek **0.525%**、Qwen **0.955%**。Q9 本月只取双方共同可计分的 18 人，Q8 为 20 人。
- 全国官方 Q9 约 3.047%，全国 Q8 约 4.548%。全国加权口径和小样本等权口径不是同一条真实线。

**因此，不能把“模型点预测2%”和“模型Q9中心0.5%”混成同一种回答。**真实与模拟的 Q9 均用同一冻结近似计分器；全国官方线另列作参照。

更直接的发现是原始概率：1 月这组真人分给通缩五档的概率合计中位数为 **0%**，DeepSeek 为 **37.5%**、Qwen 为 **25%**；2 月分别为 **5.5%、32%、25%**。这些数字没有经过 beta 拟合。DeepSeek 用区间中点做简单算术诊断，1 月中心约 **0.647%**，与拟合得到的 0.525% 接近，已经明显低于其点预测2%。

区间中点是假定每档内部位置的诊断，开放尾部不能精确确定；我们分别假定两侧尾部位置为12/16/20，不把它当官方计分器或精确均值。它足以说明：**偏低并非全部在计分步骤才出现，模型原始概率就含较多向下风险。**同时 Q8 不必等于 Q9 均值，真人也有两种回答差异，不能据此强行让两者相等。

## 2. 有三项实际输入/解释问题需要先修正

### 上期答案曾经进入模型：此前我的审计漏掉了

旧全年 DeepSeek 的 **803/876** 份实际消息写了 `Last month you gave a point estimate...`，全部对应上一月同一 Agent 的真实模拟点预测。此前程序只检查 `previous/prior`，漏掉 `Last month`，所以“旧全年没有发上期答案”的结论错误。本轮已修正审计入口并重算，旧运行原件不改。

Qwen 的 **220/240** 份实际提示逐字带入了 **DeepSeek 的上期答案**；其中 **161** 份与 Qwen 自己上一月答案不同。因此该对照仍可解释为“同一消息下两模型怎么回答”，**不能解释为两模型各自独立更新一整年的轨迹**。曲线接近也不能完全归为模型能力相同。此前模型选型暂缓结论可以保留，但其经验边界需要更正。

这并不自动证明记忆造成低估；需要隔离才能识别。已有新版两月独立运行没有这段答案。人可能记得先前的看法，经济学的信念惯性有依据，但不能用它直接证明居民每月准确记得自己上月填了多少。

### 旧非农就业变化漏了单位

旧全年 API 文本把非农增量写作 `245` 等数值，原始信号单位却是 **thousands**，正确含义是245,000人。遗漏出现在876份旧提示的就业行中；观察里的广播虽然有`245k`，这段广播没有补进实际 API 文本。模型可能自行猜中单位，也可能误解，我们不能量化其影响。

新版 300 人两月提示已经写成266,000等实际人数，600份共享背景文本均核对一致。**这是已确认的技术表达问题，下一轮不能沿用旧缺单位模板。**

### 同比/环比没有发现互换，但所指时期不同

旧文本明确区分 `12-month percent change, not seasonally adjusted` 与 `1-month percent change, seasonally adjusted`，数值与观察逐项相符；全年 CPI 同比还与既有首发来源表独立对账相符。1 月实际给的是：

- 2020-11 CPI 同比 **1.2%**，过去十二个月变化；
- 2020-11 CPI 环比 **0.2%**，过去一个月变化；
- 截止2020-12-31，二者都已于2020-12-10公开。

没有证据表明模型把二者当作同一个数，也没有证据表明它错误地乘了12。环比乘12或复利年化只是“同样月速度持续一年”的情景，不能直接替代未来一年预期。本轮**未重做所有就业/分项原始PDF的转录验收**，不能把API文本对账说成全量独立首发转录审计。

## 3. Monthly Comparison 用的不是我们现在完整的 E

这张全年模型对照图来自**旧版4条BLS宏观信号＋固定人口标签＋上期答案**，没有滚动分项、汽油价格、新闻摘要或合成CE篮子。不能拿它直接判断这些后续机制已经有效或无效。

较完整的 77 信号/新闻版，现有主运行只有2021年5/6月、每月300人。对其同选中真人、双方同计分/等权比较，Q9月中位数为：

- 5月：真人 **3.802%**，模拟 **2.836%**；人际IQR **4.718 → 0.797** 个百分点。
- 6月：真人 **4.382%**，模拟 **3.743%**；人际IQR **4.783 → 1.075** 个百分点。

较新的结果仍偏低、过度集中。但旧全年与新版两月同时改变了 P、截止、E、记忆和样本规模，**不能据其表面差距把改善归因于某个新增因素**。

汇总图也纳入了CE篮子/排序、Q1财务经历、个体信息接触和较早模型对照；各项只对自己的相同真人样本做差。篮子组温度0，其他主要实验0.5；不同实验不作因果排名。云端规则脚本仅验证工程流程，不并入真实LLM效果图；格式未过门的小模型不作有效性排名。

## 4. 时间滞后确实存在，但不是一种问题

**第一种：数据公布慢。**旧全年截止设为上月末，最新CPI自然属于目标月前两个月。例如模拟1月时只能看到11月CPI。1月实际CPI后来为1.4%，不是模型当时可用的数。按照这个截止没有前视，不能“修复”为提前提供未来发布值。但它也不等于真实1月全月受访者后来能接触的信息。

**第二种：官方平均价格与个人体感不一样。**居民可能已经看到某家商店涨价、汽油牌价变化，官方全国指数稍后才公布。全国月度平均既有发布时间滞后，也抹平地区、商店和购买对象差别。不能把未公布的目标月CPI伪装成当时个人体验；可考虑有历史日期证据的每周汽油、实时零售报价，或明确标为合成的个体价格体验。

**第三种：人接收、理解、记住信息也有差异。**“某项信息已经公开”不等于每个家庭都知道它，更不等于知道精确同比。当前提示把整张统计表统一送给所有 Agent，没有模拟真实接触和信任程度。

新版共同截止也与部分实际作答日不一致：5月有 **342/1234（27.7%）** 人在5月12日之前作答；6月有 **339/1297（26.1%）** 人在6月10日之前作答。同日分别14/8人，缺少小时，另列而不冒称精确时点匹配。给所有 Agent 同一截止信息，并不复刻这些早期受访者的信息集。这可能影响比较，但方向与大小未识别。

赛道A可以做利用回顾信息的重建；这是信息权限，**不意味着要把日后知道的信息说成居民当时知道的内容**。若问题是重建“居民当时怎样形成预期”，可利用历史调查日对齐E，明确回顾重建身份。B线严格按预测截止：不知道未来调查日时，用事前历史作答日期分布/固定截止方案；日期模拟不能让尚未发布的数据变得可得。

## 5. P 也有样本差异，但不是全部解释

实际发送的P为年龄、教育、收入、地区、就业、住房、Numeracy等粗背景；旧全年没有购物频率、具体支付价格、信念经历或CE篮子。固定73人里高Numeracy为58人（79.5%），大学学历41人（56.2%）；选中20人则为17人（85%）、13人（65%）。2021年1月完整真人按调查权重分别约63.2%、35.7%。

所以固定小样本不能视为全国人口。图中后半年选中真人本身也明显低于全国线，这部分差异来自样本/权重/计分口径组合，不能全部算成模型错误。

但是1月同选中真人Q9为2.951%，模型0.525/0.955%，差距仍大。**“样本不代表全国”不能解释掉同样本人群的偏低。**人口标签齐全，也不等于对应的价格接触和信念形成过程已经建好。

## 6. 哪些经济学解释值得优先检验

### 所有人看官方CPI，可能等于给所有人做了一次信息干预

Coibion–Gorodnichenko–Weber的研究通过向家庭随机提供不同通胀信息检验预期更新，支持“信息的提供方式本身会改变回答”。我们把完整、权威的CPI放在每个提示前部，**可能模拟了经过统一信息干预的人群，而非真实调查中的自然知情人群**。这是项目假设，尚未识别因果贡献。[论文](https://www.nber.org/papers/w25482)，[作者对实验的说明](https://cepr.org/voxeu/columns/monetary-policy-communications-and-their-effects-household-inflation-expectations)

先分别表达“社会中公开了什么”与“这个人实际接触了什么”。共同宏观背景不必全删，但不把每个人自动变成精通整张表的分析师；个体接触的分配需要来源和留出验证，不根据这两月真实答案反推注意力。

### 日常购买的显著性，不等于官方或CE的支出权重

D’Acunto等人的美国购物微观研究发现，价格变化的频率和幅度在预期形成中重要，不能只看支出份额。[论文原始摘要](https://www.nber.org/papers/w26237)

这支持继续研究价格体验，也解释为什么给一个CE支出篮子后模型仍可能采用全国CPI锚：篮子未表达遇到价格的频率、涨价是否显著、如何更新判断。它**不能证明本项目篮子试验失败必然由这个原因导致**。CE合成篮子可作暴露背景，不能说它已经测得某位SCE家庭的实际价格体验。

### 注意/经验学习，需要真实信念状态，而不仅是宏观表和粗年龄

Carroll研究家庭通过新闻逐渐吸收专业预测；Malmendier–Nagel研究终身通胀经历与预期差异。它们支持不完全知情、更新速度和历史经历的异质性；不支持机械复述上期问卷数字。[Carroll作者稿](https://www.econ2.jhu.edu/people/ccarroll/epidemiologyqje.pdf)，[Malmendier–Nagel作者稿：2011版，发表2016](https://eml.berkeley.edu/~ulrike/Papers/InflExp_4.pdf)

候选设计是把P中的经历/能力/接触条件，连接到E中的信号选择、可信度和更新，而不是所有家庭直接解读全部数值。理论不能替我们确定每条通道的系数；需要训练期证据、事前方案和独立时期验证。

### 问卷和呈现也属于行为模型

纽约联储随机措辞研究发现，“一般物价”与“通胀率”问法可能引发不同水平和分歧；另一项实验表明让人想起显著价格，会改变预期。官方SCE这里使用的是通胀/通缩问法，我们应保持调查含义，**不能为了抬高结果偷偷换成另一种问卷**。[措辞研究](https://www.newyorkfed.org/research/staff_reports/sr443.html)，[显著价格回想研究](https://www.newyorkfed.org/research/staff_reports/sr489.html)

原提示将Q8方向+幅度合成一个带符号数，将Q9通缩档改写成负数区间；顺序和符号核对正确，但受访者认知负担与真实问卷不完全相同。后续可忠实还原原调查流程，分别核对原始概率、个人不确定性、人际分歧和聚合中心；不是仅追着最终中位数调提示。

另外，旧1月73个回答理由中62个提到CPI，60个提到提示未写的疫情。疫情是截止前已经发生的事，**这不证明前视泄漏**；它说明日期可以唤起模型背景知识，“截至某日”约束并没有让底层知识被关闭。理由是生成的解释，不是模型内部注意力或真实因果链，不能用关键词计数证明锚定机制。

## 7. 下一步顺序：先把问题缩小，不急于付费重跑

1. **冻结可理解的诊断口径：**全国/同样本、Q8/Q9、旧/新E分开；此次更正落在记录和审计程序，不追改旧轨迹。
2. **统一下一版输入契约：**时间、发布版本、单位、调查流程，以及上期问卷答案是否进入B，都写清楚；修旧单位、明确是否保留记忆，不把两项同时变化说成单因素试验。
3. **先离线验证E能否表达体验：**区分统计公开、个人接触和个人更新；检查快速价格的历史来源、CE是否有购买频率支持、真实SCE组间模式是否一致。共同宏观背景与个人视图并存，比只让某人看一个品类更值得检验，但不是已验证优选。
4. **形成少量、针对性的机制对照后再决定实验：**先隔离问卷/概率表达与锚定，再验接触/信念更新。每次固定其他条件，不同时改模型、篮子、新闻和人口；未给新的预算或启动日期。

本轮不认为“只要补齐E就一定成功”，也不认为已经证明模型在扮演专家。**我们确认了输入与统计解释的问题，并找到原始概率这一直接差距；其余解释要作为可检验的研究方向。**
