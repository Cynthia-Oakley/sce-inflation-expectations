## 4. 5 月结果：流程通过，分布还原不足

完整月度对照使用同一冻结近似计分器对模拟与真实十档概率重新拟合。真实 Q9 可计分 1,216 人，14 人概率无效、4 人不相邻双档不支持，缺口另计；Q8 有效 1,228 人。Q8/Q9 使用各自的有效集。

- Q9 指标：Core 直接加权 **2.952%**，Normal 扩展 **2.965%**；真实全月 **4.000%**。扩展后绝对差 **1.035 个百分点**，相比 Core 的 1.048 点只略有减小。
- Q8 点预测：Core **3.505%**，扩展 **3.555%**；真实全月 **5.262%**。扩展后绝对差 **1.706 点**。
- 人群分歧：Q9 个人密度均值的跨人加权标准差，扩展 **0.585 点**、真实 **6.874 点**；Core 的个人均值范围仅约 **1.587%–4.524%**。这表示不同人的预期过于相近，不是说每个人的概率曲线内部都没有不确定性。
- 同人比较另做时间分组：300 Core 中截止后 221 人、截止前 75 人、同日时刻未知 4 人。截止后可计分 Q9 配对 214 人，个人绝对误差加权中位数 **2.373 点**；此数不同于全国指标的绝对差。

这次不能归因为某一具体部件。可以确认：人口扩展只重分配已有 Core 回答，不能补出 donor 中不存在的极端预期；增加 Normal 不足以解决目前的低分歧。尚需对 P、E 和回答方式分别做固定条件对照。

## 5. 6 月与两月对照

6 月真实 Q9 十档可计分 1,273 人，21 人概率无效、3 人不相邻双档不支持；Q8 有效 1,293 人。

- Q9 指标：Core **3.860%**，扩展 **3.858%**；真实全月同计分器 **4.802%**，绝对差 **0.944 点**。本月扩展相比直接加权略差，并无稳定增益。
- Q8 点预测：Core **4.380%**，扩展 **4.371%**；真实全月 **5.482%**，扩展绝对差 **1.111 点**。
- 人群分歧：扩展后 Q9 的跨人标准差 **0.646 点**，真实 **7.111 点**；Core 个人密度均值约 **1.692%–5.573%**。低分歧问题在两月都出现。
- 同人日期组：截止后 229 人、截止前 69 人、同日时刻未知 2 人；截止后 Q9 配对 223 人，个人绝对误差加权中位数 **2.974 点**。
- 扩展 Q9 从 2.965% 升至 3.858%，上升 **0.893 点**；真实同计分器从 4.000% 升至 4.802%，上升 **0.802 点**。方向一致，但只有两个开发月，不能据此声称动态机制或预测能力已经验证。

目前最明确的现象：**总体水平偏低，回答分布过窄；扩展不能稳定改善指标。** 保留 Core 直接加权与扩展两种结果，不只挑更接近真实值的一个。

- 模型知识截止未知，日期提示词不能消除参数内的历史知识；结果只称回顾性条件模拟。
- 当前全月对照允许 A 线回顾性信息。与早答者的个体比较不能冒称按其真实答题时点的信息模拟；日期组已分开。

- Q9 计分器是冻结近似，真实和模拟使用同一版；不声称复刻官方全部数值细节。
- 配置模板中仍有 legacy scripted `model_version`/snapshot 标签；本次真实模型、prompt、实际调用与 P/E 哈希以 `run_manifest.json` 和调用日志为准，不把模板标签当成模型身份。
