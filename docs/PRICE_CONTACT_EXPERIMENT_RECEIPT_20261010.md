# 近期价格与地域匹配：实验记录与分析

执行日期：2026-10-10。队伍：水上挽月。路线 A 回顾模拟，两个开发月。执行前方案见 [实验计划](PRICE_CONTACT_EXPERIMENT_PLAN_20261010.md)。本轮已运行，不是提示预览或规则脚本的结果。

## 结论先看

**近期价格补充有小幅改善迹象；地域匹配尚无稳定增益；回答同质化未解决。**不据此冻结最终机制或扩大人口。下一步应优先检验家庭信息的呈现和接触机制，再用独立月份复查。

这里的比较对象是本次家庭小样自己的真实回答，双方使用同一冻结近似计分器。不是全国 SCE headline，更不是全国预测准确率。

## 1. 实际做了什么

沿用已有两月各20人的诊断样本，人口由历史 SCE 白名单分档构成；消费背景使用此前 CE 条件供体合成的四类支出份额。原始ID重新映射为 `contact_001` 等；源ID联结仅留本地评价层。没有发送真实QSP5支出、问卷答案、权重或CE供体ID。

四组使用相同的画像、合成篮子、原有宏观表与标题/摘要新闻、Q8/Q9问卷：

1. **原有信息**：不加新零售价格，保留合成支出背景。
2. **近期全国价格**：增加调查月内截止点之前可得的乳制品促销报价和普通汽油全国12周记录。
3. **地区匹配**：食品不变，汽油按照家庭所在州匹配 EIA PADD 地区12周记录。
4. **地区随机分配**：同一批地区汽油序列循环置换给家庭；保留价格包集合、自己的篮子和其他输入，改变地理对应关系。

“匹配”仅是州→市场区域的可核查规则，不代表知道某人的实际驾车、购物频率或购买价格。食品采用全国报价，尚未实现个人食品匹配。各组不单通道遮罩，也没有规定必须关注高频商品、上调预期或机械年化周涨幅。

## 2. 数据与时间口径

- 5月：信息截止 `2021-05-12 23:59:59 America/New_York`；EIA 5/12归档周报表14，汽油观测止于5/10；USDA 5/7发布的零售乳制品报告。
- 6月：截止 `2021-06-10 23:59:59 America/New_York`；EIA 6/9归档周报表14，汽油观测止于6/7；USDA 6/4发布报告。
- 食品事先固定选常规半加仑牛奶、8oz碎奶酪、4–6oz希腊酸奶；保留本期/上周/去年、商店数及原始行，不根据通胀答案挑商品。报价上涨与下降都保留，没有为了提高拟合筛选涨价。
- EIA 是含税普通汽油零售价，不是原油或全部品级平均。州/PADD对应依据 EIA 官方定义，不能直接以 Census 四地区代替。
- USDA 是加权商店广告价，店铺、品牌和促销构成会变；不当作同店同品通胀。广告报价可面向发布后几天，不表示那些日期已发生消费。
- 时间证据精确到日：`available_by` 取发布日纽约末时作为保守界。食品提示中的 `published ...23:59:59` 显示的是这个界，不是恢复了精确发布钟点；后续版本应改成明确的“截至该日已公布”。EIA 日期来自官方归档路径。未独立证明下载字节与最初发布字节不可变，不声称完整初发版本认证。
- CE资料2021年9月才公开，故本轮为 A 回顾性代理，不是 B 的实时可得人口/篮子。统一月内截止也不等于每位真实受访者作答日的信息集。

官方来源、数值原行、PDF页号、哈希见 [来源台账](sources/sce_price_contact_20261010.json)。原始下载存 `data/raw/high_frequency_prices/20261010/`，5月食品稿沿用 `20261009/`。

## 3. 运行和验收

- 真实 SocioVerse 本地引擎，独立决策组件，经单向运行导出，轨迹存 DuckDB；每月每组冷启动，无上月真实答案和问卷回放记忆。
- 请求/返回模型均为 `deepseek-flash`，温度0.5、seed42、非思考模式、每份最多1024输出token、无自动重试。这是返回别名一致，不是取得不可变模型权重证明。
- 8格规则工程检查通过；5项针对性测试通过（转录、未来时间/画像隔离、置换集合、提示无源ID、评价统计口径）。规则检查没有被拿来做行为结论。
- 160次真实调用、160份格式有效回答，失败0、重试0；实际发送消息与冻结预览逐份完全一致；输入和源码哈希无漂移。
- 输入455,720 token，输出21,599 token。按公开高峰/缓存未命中输入$0.30、输出$1.20每百万token保守估算 **$0.162634**；上限$1，预留边界$0.733477。没有取供应商账单，缓存/非高峰折扣未抵扣，不能称已实付该金额。
- 5月Q9共同有效20人；6月19人，一名真实Q9原始概率不合规，从四组的Q9主比较统一排除。所有模拟Q9有效。Q8单独使用其有效样本，不强制套Q9缺失。

## 4. 结果怎样理解

主指标：从Q9十档拟合每人均值，再看这批人的中位数、整个均值分布及跨人IQR。用相同近似计分器处理真实与模拟。个人误差、Q8和个人密度IQR为辅助。

### 增加近期全国价格

- 5月Q9小样中位数误差：**0.793→0.754pp**；分布W1：**4.036→3.845pp**。
- 6月中位数误差：**2.801→2.349pp**；W1：**3.622→3.303pp**。
- 两月方向相同，但配对重采样区间都跨过0。单次随机生成和小样使变化不能视为稳定的机制效应。
- Q8没有同样改善：5月中位数误差0.5→0.8pp，6月维持0.8pp。不能只展示较有利的Q9。

### 地区匹配是否比随机匹配好

- 5月匹配组/随机组中位数误差：0.688/0.822pp；W1：3.881/3.974pp。
- 6月：2.042/2.059pp；W1：3.423/3.368pp。匹配组中位数略好，整个分布反而略差。
- 匹配比全国价格组的中位数更接近真值，但两月W1都更差。因此无法宣称“地域匹配改善了整个群体分布”。
- 5月置换后7/20、6月5/20仍属于同PADD；这是有限类别置换的实际情况，不能称人人都错配。6月没有PADD3，地区组1–10人，分组仅作描述。

### 同质化仍是主要难点

真实回答的跨人Q9均值IQR约5.20/5.42pp；地区匹配组只有0.38/0.33pp。匹配使中心略上移，却没有生成真实的居民分歧。不要把个人Q9密度的宽度和不同居民均值的分散混淆：个人可以报很宽的概率，但所有人的中心仍很接近。

原因文字仍经常出现美联储和暂时性判断；例如5月原有组19/20份回答提到Fed，匹配组14/20。这只是可见文字线索，不证明新闻锚定的因果效应。报告目前仍像宏观简报；这轮没有删除它，故结果不能否定“较自然的家庭经历输入”这个更宽的假设。

## 5. 下一步：不急着扩样

1. **同事实换呈现**：离线准备“完整统计表”与“简短共同背景＋价格接触记录”两套输入，保持价格事实、单位、时点和题目一致。把信息数量和表达效果分开，不用提示词要求预测更高。
2. **补家庭接触证据**：CE Diary用来估计类别接触频率的条件分布；真实SCE消费模块用于本地检验关联。未知购物/驾车角色作为假设抽样并做敏感性，不把州和份额直接当真实生活经历。真实QSP5外发试验仍单独待授权。
3. **先补日用品/服装的可比报价**，再看食品、汽油是否过度代表整个消费环境。没验收的数据不编造到输入。
4. 若新呈现出现同时改善中心与分布的信号，再做重复生成、独立月份和更平衡人口；同步给非Agent基线同批输入。当前不扩Core、Normal或模型数量来替代机制检验。

理论动机与识别限制沿用 [家庭价格体验综述](literature/sce/themes/household_price_experience.md) 和 [信息机制记录](literature/sce/native_spending/DATA_AND_METHOD_20261009.md)。支出、购买频率、注意力、预期形成四者仍需分别建模和验收；文献动机不等于本次机制已有效。

## 7. 用户追问复核：地域与Q8/Q9（同日，无新API）

### 地区结论只适用于本轮汽油处理

本轮仅置换汽油PADD地区序列，食品仍全国报价，水电燃气没有进入处理。结论应收窄为“两个开发月小样未发现稳定的汽油地域匹配增益”，不能据此说所有地方价格不重要，也不能归因于未测试的水电支出。

用户提出支出份额、变动幅度和时期可能限制作用，作为待验证假设保留。BLS CE 2021年支出、2023年9月公布的跨年表：平均总支出$66,928，电$1,551、天然气$447、水及其他公共服务$695，加总约占4.02%；包含电话的广义utilities/fuels/public services约6.31%。汽油/其他燃料/机油约3.21%。[官方表](https://www.bls.gov/cex/tables/calendar-year/mean/ce-all-multi-year-2021-2022.pdf)与计算见来源台账。这是平均金额之比，不是SCE样本的个人份额、CPI权重或注意力权重，后发资料只用于事后描述。

地区差异还包括房租、食品、汽油，不能限定为公用事业；没有唯一官方“地区相关支出比例”。验收需要依次看类别支出/接触差异、地区涨幅差异、独立时期。水电还需供应商服务区域和费率组，州标签不够。

现有12周汽油记录的PADD涨幅范围：5月窗口约9.9%–25.5%，6月约3.1%–8.7%，并非都很小，但各地区上涨方向一致。全国共同上涨信息可能解释了许多响应，地域增量较少是候选解释，未因果识别。五大地区均值也不能代表加油站价格、实际驾车或购买频率。

下一步保留地域接口，比较全国冲击、局部供给冲击、公用事业调价等不同窗口；先审计价格变化的地域差异再扩展匹配，不由这一小样决定永久取消或全面加入地域。

### 点预测与概率回答的差别

Q8直接给一个未来12个月通胀数；Q9给十档概率，从拟合密度提取个人均值，再取人群中位数。这次改善的是Q9派生中心的拟合，不是证明概率区间覆盖率或概率校准改善。另一个“区间”——配对重采样区间——描述统计不确定性，与Q9个人信念不同。

原有信息→近期全国价格：

- 5月Q8真实小样中位数4.0%，模拟3.5→3.2%，误差0.5→0.8pp；Q9真实派生中位数3.751%，模拟2.958→2.997%，误差0.793→0.754pp。
- 6月Q8真实中位数5.0%，模拟4.2→4.2%，误差保持0.8pp；Q9真实派生中位数6.093%，模拟3.292→3.743%，误差2.801→2.349pp。
- Q8有效人数两月20，Q9为20/19。不同口径的误差不直接互比；6月点预测中位数不变，但20人中12人的点预测改变，5月16人改变。

纽约联储[方法说明](https://libertystreeteconomics.newyorkfed.org/2013/12/introducing-the-frbny-survey-of-consumer-expectations-measuring-price-inflation-expectations/)指出，单一数值可能代表受访者的均值、中位数或众数，不能强制等于密度均值。概率重新分配可以改变Q9中心，而点回答仍锚在典型数字；本轮尚未识别这种心理机制。随机生成、中位数聚合、概率曲线拟合非线性也可能影响两种指标。

原始回答复查：全国价格组“通胀至少4%”概率均值5月30.25→32.15%、6月37.30→37.75%。这是粗概率变化，不能单凭它解释全部密度均值变化或认定尾部是原因。后续同人核对点回答、原始概率、拟合分支及Q8/Q9差距；保留两个指标，不强制相等，不因Q9有利就取消Q8。

补算存 `analysis/q8_q9_response_followup.json`；冻结输入、运行配置、计分器、原始回答未改，新增付费调用0。
