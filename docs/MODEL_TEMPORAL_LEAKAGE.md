# 历史 SCE 模拟的模型时间泄漏协议

更新：2026-09-30。研究问题：**2026 年调用的 LLM 可能在训练中见过 2021 年、甚至目标月之后的经济数据和 SCE 结果。限制外部 E 的 `as_of` 不能清除模型参数中的事后知识。**此风险直接决定论文能否使用“事前预测”表述。

## 两条独立的时间边界

1. **显式输入的时点**：P、E、检索文本、历史目标值均须在目标 `as_of` 前公开且有当时版本。BLS 首发新闻稿解决了本次两月 E 的一部分，不能替代模型时间边界。
2. **模型自身的时点**：模拟决策模型的预训练、指令微调、后续更新、工具调用和系统上下文可能包含 `as_of` 后的信息。要声称严格事前预测，必须证明这些来源对每个目标月都未跨越对应的 `as_of`；只写“请假装身处 2021 年”或去掉年份均不能证明。

此外，**研究助手构建模型的事后知识**是另一层风险：它可能在 2026 年编写 `model.py` 时把已知的 2021 年结果、月份模式或调参经验写进 scripted/LLM 规则。因此代码、prompt、常数、开发/测试切分和选择过程也要审计；即使 B 当次不调用 LLM，事后设计仍不能冒称当时可运行的预测器。

## 当前项目的真实状态

- **v2 两月试验**：`decision_ref=sce_inflation_expectations.scripted_b`，平台和 40 条原始回答均标为 `deterministic-scripted-v1`；`model.py` 已取回并核对哈希，决策代码没有 LLM 调用。这个运行是工程流程试验，不存在“模拟 LLM 预训练记住 2021 年”的这一条通道。代码读取传入的 CPI 同比/失业率并能重演全部 40 条回答；实际云端观察仍待取回。代码把两个月、`as_of` 和 `0.55` 等规则在事后写定，系数来源未说明，不能据此报告无前视的预测效果。
- **托管研究助手**：负责讨论和编写 study 的模型身份、训练截止及更新信息尚未知；它的成本计入 Agent 平面，不能与模拟 B 的模型混为一谈。
- **未来真实 LLM B**：尚未选择或调用具体基础模型。`model_version=deterministic-scripted-v1` 是规则版本，不是基础模型名，也没有可推断的知识截止。模型身份、提供方、固定修订/别名、训练与后训练截止、工具权限均标为 `unknown`，不得虚构。

## 真实 LLM 运行前的登记门槛

在任何真实 B 运行前，保存 `simulation.json` 中的 `decision_ref/decision_args/llm_kind/model`、实际解析的提供方/端点/模型 ID 与可固定的修订或响应 fingerprint、模型卡中的训练截止（预训练与后训练分开，无法取得就写 `unknown`）、调用日期、工具/检索/浏览权限、完整系统与用户 prompt、温度/种子、输出原文、费用。托管研究助手身份另记，不能以助手 UI 名称替代 B 的模型 ID。向平台索取元数据即可，**本步骤不授权真实 LLM 运行**。

若任一影响 B 的模型训练/更新时点晚于目标 `as_of`，或平台无法提供足以判断的资料，则 2021 年 LLM 结果列为**回顾性条件模拟／潜在模型先验污染**，可以分析机制敏感性，但不作为“严格事前预测准确率”主结论。即使模型卡给出截止，也不等于逐条证明语料无泄漏；需要说明证据等级。

## 三种结果等级与可用主张

- **A｜规则式工程试验**：本次 v2 所属。可报告 P/E/B 管线、时点检查、问卷结构、可复算性；不能报告真实 LLM 预测能力。
- **B｜历史 LLM 回顾性模拟**：2021 年目标但 LLM 截止较晚或未知。必须标记模型时间污染风险；可以比较固定模型在不同 E/P 条件下的反应，不能把 2021 年拟合精度视为事前预测证据。零 E、打乱 E、隐藏日期、询问已知结果、同输入直接 LLM 等诊断只能发现或估计风险，不能证明风险不存在。不得用其测试期成绩继续选 prompt/模型。
- **C｜时间上可辩护的事前试验**：使用可核实且在每个 `as_of` 前冻结的模型权重及后训练版本，关闭越界工具；或在目标调查结果尚未公布时冻结完整方案、生成并封存预测，公布后再一次性评价。后者是前瞻性 shadow forecast，模型须在预测前固定且记录实际可用信息。若无法实现 C，论文应以 A/B 为主并明确局限，不使用严格事前预测表述。

## 对照与论文写法

在开发月预先规定：固定 P/E 的“不给历史 E”、真实 E、置换或错月 E；相同输入的直接 LLM；截止时点最后已公布 SCE 的简单基线。比较 LLM 对 E 的增量和对日期提示的敏感性，记录其自发提及 `as_of` 后事实的比例。日期隐藏只能做敏感性诊断，因为宏观数值本身也可能暴露年份。未来若有前瞻月份，优先用封存的未公布结果做关键外部检验。

建议论文明确区分：**“输入信息遵守历史时点”**、**“模型参数也遵守历史时点”**、**“实际发布前封存的预测”**。三者不是同义词；目前只对部分显式 E 与规则式回答取得证据。

## 依据

- [SocioVerse：LLM 接入与干跑](https://socioverse.fudan-disc.com/docs/zh/guides/llm-clients/)：`decide_batch` 可用规则或 LLM，配置来自 `decision_args.model` 或 `SV_LLM_MODEL`，工作流助手和模拟 LLM 使用不同的凭据/通道。
- [Ding 等，2026，时间约束提示的局限](https://arxiv.org/abs/2605.14636)：历史提示可降低但不能证明消除后见信息使用。
- [Yan 等，2026，DatedGPT](https://arxiv.org/abs/2603.11838)：研究时间截止模型用于控制回测前视偏差。
- [Gao 等，2026，LLM 预测中的前视诊断](https://arxiv.org/abs/2512.23847)：说明已实现结果的模型记忆可污染回测，并提出诊断方法。

## 附：候选模拟模型的可用性与截止日期核查（2026-10-01，Kimi）

背景：模拟 B 的模型须在"训练截止尽量早于目标月"与"服务仍可用"之间取舍。当日公开信息核查（非合同保证，签约前复核）：

- **OpenAI 老模型正在批量停服**：GPT-3.5-Turbo 已定 2026-10-23 停服（同日还有 GPT-4/GPT-4 Turbo/o1/o3-mini/o4-mini）；GPT-4o 已于 2026-02-13 从 ChatGPT 退役，`chatgpt-4o-latest` 于 2026-02-17 从 API 移除；Azure 侧 gpt-4o 2024-05-13/2024-08-06 已于 2026-03-31 退役。**用 OpenAI 老模型做 2021 回放的路线基本不可行。**（来源：OpenAI 弃用页与社区公告，2026-04/05 更新）
- **开源权重模型不存在"停服"问题**（权重可下载自托管，第三方托管也多）：DeepSeek-V3 原版（2024-12 发布，训练截止约 2024 年中，平台 user_pool 别名已有 deepseek-v3）、Qwen2.5-72B-Instruct（Fireworks/Together 等 2026 年仍在售，平台别名已有 qwen2.5-72B-Instruct）、Llama 3 70B（截止 2023-12，更早）。权重可固定版本=可复现性最好。
- **含义**：对 2021 目标月，所有现实可用的模型都在"窗内"（见正文前视协议）；真正的窗外测试只能用 2023 年底前截止的权重模型（如 Llama 3 70B）或前瞻封存未公布月份。ConsumerSim 的截止标注错误（精读笔记§6.3）提示：**我们必须在论文里给出模型 snapshot ID 与截止日期的可核查出处**，窗口内/外对比分析可作为差异化贡献。
