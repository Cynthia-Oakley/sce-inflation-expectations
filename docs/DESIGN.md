# SCE 项目设计总纲（DESIGN）

> 版本：v1 草案，2026-10-19，Kimi 起草，待用户与 Codex 评审。
> 本文是项目设计的**唯一总纲入口**：十分钟读懂"研究什么、怎么设计、当前到哪一步"。
> 各专题细节以被引用的专题文档为准；本文与其他文档冲突时，以更新日期的正式决策（`DECISIONS.md`）为准并回写本文。

## 1. 一句话

在严格控制信息可得时点的条件下，用 LLM Agent 模拟美国 SCE（纽约联储消费者预期调查）受访者对**未来 12 个月通胀**的回答，检验能否重建历史微观预期结构、并预测未来调查统计量。赛道：SocioVerse Challenge 2026 **赛道 A**。队伍：**水上挽月**。

## 2. 研究对象与目标变量

- **调查**：SCE（Survey of Consumer Expectations），纽约联储月度调查，每月约 1,300 名轮换 panel 受访者。
- **目标题目**：
  - **Q8**：未来 12 个月通胀点预期（百分比数值）。
  - **Q9**：未来 12 个月通胀落入十个区间的**主观概率分布**（十档密度）。
- **真值**：SCE 公开微观数据（滞后约一年）+ 官方 headline 汇总值。真值只进评价层，绝不进入 Agent 输入。
- **主指标**：逐人 Q9 拟合密度均值 → 样本/加权跨月中位数 MAE（单位：个百分点 pp）。
  - 真人密度拟合与模型密度拟合使用**同一冻结近似计分器**（`studies/sce_inflation_expectations/scoring/sce_q9_frozen.py`），这是项目内近似算法，不称为官方完整复刻；差异口径见 `docs/BETA_AND_KIMI_REVIEW_20261001.md`。
- **当前目标**：12 期主口径 MAE < **0.20pp** 且**优于持续性基线**（照抄最近可得值）。未达成前不得以开发月局部最好成绩代替。

## 3. 两条研究线（A/B 契约摘要）

完整契约见 `docs/A_B_LINE_CONTRACTS.md` 与 `docs/A_B_RESEARCH_DESIGN.md`。

| | **A 线：历史微观结构重建** | **B 线：以 t 期信息预测 t+1 期** |
|---|---|---|
| 研究问题 | 已知当期人口分布与宏观背景，能否生成与真实调查相容的微观预期结构？ | 只用 t 期已可得信息，能否预测 t+1 期 SCE 回答与统计量？ |
| P（人口） | 当期真实 SCE 微观画像抽样（年龄/教育/收入/地区/数理/就业/住房），允许用当期人口分布与官方权重做抽样与聚合校准 | t 期时点已公布的旧微观数据（约 ≤M−12）+ 当时公开人口宏观变量外推 |
| E（环境） | as_of = 目标月−1 月末的时点合规信息；允许事后整理资料，逐项登记 | 同 A 线来源，但只允许 ≤t 期末已发布的稿次（PIT 严格） |
| 主评价 | 微观三层：逐人误差、分组结构、跨期变化；全国层仅在没有用作校准时可验证 | **全国月度指标为主**：加权中位数轨迹 MAE/bias/RMSE |
| 现状 | **当前主线**，所有实验均属此线 | 未实现：缺信念连续递推、新入组初始化、误差积累验证 |

纪律：A−B 差值不能直接解释为"信息时效效应"；真实个体回答一旦参与拟合/初始化即丧失独立验证资格。

## 4. 当前参考配置（截至 2026-10-19）

细节与历史版本见 `docs/CURRENT_SIMULATION_CONFIGURATION.md`。**"参考配置"表示各模块已集成，不表示单项已验证有效；这不是冻结的最终配置。**

- **P**：SCE 实际回访者画像（年龄组、教育、收入档、地区/州、住房、就业、数理 High/Low 标签）+ 合成 CE 四类支出占比 + 合成美联储信心（后两者为合成分布，非实测）。
- **E**：时点合规的历史价格/就业/汽油序列、滚动趋势、筛选后 NYT 新闻与政策短讯（当前共同新闻 3 条 + 个人新闻 5 条，个人新闻 50% 随机 + 50% 相关加权）；发布时间标记区分早已公开/后来公开/同日不确定。
- **B（行为）**：本人真实上期 Q8/Q9 及更早问卷摘要作为既有信念输入，直接填写本期 Q8 与十档 Q9。
- **运行**：官方 SocioVerse2 引擎（`socioverse2_repo`）+ 本地文件 P/E + DeepSeek 官方 Flash，temperature 0.5，关闭思考，无自动重试；原始调用与轨迹全量保存，真人与模型用同一冻结计分器。

## 5. 评价口径与基线

- **三层评估**：微观（逐人 Q8/Q9 误差、个体 IQR、横截面分歧）、分组（人口组间差异结构）、全国（加权中位数轨迹）。
- **关键基线**：持续性基线（照抄上期/最近公开值）。任何机制必须在相同样本、相同权重、相同月份下与其比较。
- **已确认的核心短板**：模拟回答**过度集中**——12 期跨人 IQR 模型 2.42 vs 真人 5.06；分布距离 W1 模型 2.43 vs 照抄 0.87。中心误差之外，分歧结构未恢复。

## 6. 当前状态（截至 2026-10-19）

- 12 期 × 192 人 × 两遍扩大验证（4608 请求，约 $5.2）：**主口径 MAE 0.459pp，持续性基线 0.239pp**；对完整 SCE 波次 0.376 / 0.213。**尚未超过基线，距离 0.20pp 目标未达。**
- 已试机制与取舍见台账 `docs/EXPERIMENT_STATUS_20261018.md`：心理状态、财务事实、认知实答、新闻量/新闻分配等均有局部得失，**无一项稳定升级默认**。
- 当前主攻方向：① 个人信念的保留与更新机制；② 采购角色/价格体验（ATUS 匹配已备，待运行）。

## 7. 工程架构

- **主仓库**（本仓库 `socioverse_challenge/`）：SCE 源码唯一维护地，study 在 `studies/sce_inflation_expectations/`。
- **官方仓**（`../socioverse2_repo/`）：官方引擎宿主，上游核心只读；本仓库向其**单向导出**运行副本并记录哈希，不养第二份源码。
- **共用试验管线**（`docs/EXPERIMENT_PIPELINE.md`）：入口 `scripts/run_sce_frozen_trial.py`，动作 prepare → dry-run → run → worker → evaluate；冻结人口/E/提示词复用，新机制只需在 `experiments/` 加适配器；真值缓存与旧回答按指纹复用，不重复付费。
- **产物纪律**：`outputs/` 按 run_id 保留、禁止覆盖、不进 git；私有数据（人月、完整提示/回包）只在本地忽略目录。

## 8. 研究纪律（不可由 Agent 自行变更）

1. 不改研究目标、as_of、测试切分、数据口径；真值与未来信息白名单隔离（`docs/RESEARCH_PROTOCOL.md`）。
2. E 只用结构化数值/标题，禁用 LLM 转述；PIT 用首发稿 vintage，逐项登记 observed_at/published_at/as_of。
3. 真实 LLM 调用前先跑通确定性离线流程与引擎干跑；付费批次需用户明确授权范围与上限。
4. 配置（提示词、temperature、计分器）在开发期调试后冻结；任何变更记版本并整窗重跑；已看过的月份不再称独立盲测。
5. 决策变更追加 `docs/DECISIONS.md`；任务状态只在 `docs/NEXT_ACTIONS.md`；日程只在 `docs/ROADMAP.md`。
