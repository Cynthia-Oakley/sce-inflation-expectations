## 目的与范围

比较不同模拟模型能否在连续月份中同时重建总体通胀预期、人群差异和分布。首段采用**2021-01至12**：已有全年E，能够与此前5/6月衔接，覆盖通胀上升过程。2021仍是已经查看过数据的A路线开发验证年，不是独立盲测，也不能排除模型记忆。完成后再登记2022等跨阶段窗口，不用这一年的最优模型直接冒称普遍最优。

## 统一概率纠错规则

此前99%/101%等错误不能直接归一化后冒称模型回答。本轮四模型统一使用新协议，原实验保留：

1. 首次调用使用原问卷，合格回答立即保存。
2. 若十档数字均可读、范围合格但总和错误，最多反馈一次，只要求修正概率分配，总和为100，同时必须保持Q8点预测原值；不提供真人答案或新的经济信息。
3. 若格式不可读，最多用原消息重试一次；仍失败则记录缺失，不能换人或无限重试。纠错不保证经济意义完全不变，另报告首次合格率、纠错后合格率和概率变化。
4. 每模型前10案例至少9份合法，否则暂停该模型；这是格式工程门槛，不是拟合优劣筛选。以后不按看到的误差修改提示词。

不将旧20人小试结果拼入新全年系列。本卡计划每模型每案例新生成一次有效回答；同输入旧5/6月回答可另作重复生成诊断，不混同同一次年度生成。

## 评价顺序

1. 总体：逐月加权中位数误差，全年等月权重MAE、RMSE、带符号偏差，6/12月滚动误差与变化方向。微观拟合以冻结近似计分器处理双方Q9，官方全国首发headline另列，不能混成同一真值版本。
2. 人群：固定年龄、教育、收入、就业分组，检查组内中位数和组间差距；不足20个有效Core支持的组标稀疏，不用大量Normal掩盖支持不足。
3. 分布：人际IQR、尾部覆盖、加权分布距离；个人内部的不确定性另外报告。
4. 个体：仅对真实画像有对应关系的Core作辅助误差，不给统计扩展Normal编造一对一真人误差。

失败案例、拟合失败、Normal借用支持和共同月份覆盖一并报告。按完整12个月比较，不能只挑模型有利月份；未跑完模型不列全年排名。全年一次生成仍不能单独估计所有月份的LLM波动，之后另登记重复生成/跨年确认。A人口同当前真实人口，不能据此声称B预测有效。
