# 研究定义与项目边界

更新：2026-09-26。状态：**候选问题，尚未完成数据可行性验证**。

## 研究问题

在严格控制信息可得时点的条件下，模拟不同人群面对当时新闻与环境信号的问卷回答，能否改善某一月度调查统计量的历史重建或事前预测？如果改善，主要出现在哪些时期与人群；如果没有，是否仍能给出可解释的行为诊断？

这一问题对应 Challenge **赛道 A**。ConsumerSim 提供可迁移的机制参照，但本研究的目标、数据、问卷和验证必须重新定义。不能把更换目标名称视作研究贡献。

## 两个项目

- **A｜2026 年 10 月的比赛 study**：单一明确调查统计量；完成数据审计、简单基线、P/E/B 原型、留出回测、消融、复现包和报告。
- **B｜金融交易 Agent 平台**：另行立项。价格形成、撮合、交易者互动和收益评价不属于 A 的近期范围。A 可沉淀时点数据、实验记录与可复现经验供以后参考。

## 当前候选与关键修正

`IDX-0100` 是 Ipsos *What Worries the World* **调查项目**，而非一条具有统一数值定义的指数。其官方页面称调查每月覆盖 30 国约 20,000 人；各国各类担忧的完整分解数据“可索取”。因此先选一个国家与一条明确统计量，例如“认为国家朝正确方向发展的受访者比例”；只有在确认连续历史数值、问卷文字、田野日期和允许使用范围后才定题。国别须按数据完整性及事先声明的社会科学理由选择，不能根据测试误差挑选。

旧资料里两个 CSV 实际为 **180 + 371 = 551 条候选记录**；`methodology/` 当前是 **539 个目录**，其中 **498 个有 `methodology.md`**。这些不是同一个分母。它们提供候选与方法学线索，不能替代真值历史序列。

若 WWTW 不能形成可核对的连续序列，优先重新比较问卷型目标与数据可用性；`ECO-0086` OECD G20 企业信心只是一个待检验备选，需重新论证企业 Agent 的人群来源和行为映射，不能自动切换。

## 最小可交付

1. 一个清楚命名的目标变量、国家、单位、问卷口径、田野期与预测截止时点。
2. 可审计的真值表与输入来源清单；至少一个完全遵守时点边界的简单基线。
3. 一个按官方 `studies/<study>/` 布局组织、可离线确定性运行的 P/E/B study。
4. 留出期结果、误差与不确定性、关键消融、模型调用与成本记录。
5. 4–8 页报告、研究包、≤5 分钟演示与复现声明。

## 不将推测写成事实

- “赛事需要我们的案例”“组内希望借比赛做平台测试”等是背景推测，不作为项目需求。
- Ipsos 历史报告公开，不等于国别月度机器可读序列或微观受访者数据公开。
- 新闻导致单月大幅变化是选题动机，不保证 Agent 比持续性基线好。
- SocioVerse2 官方案例的演示结果不等于 ConsumerSim 全量研究结果，也不证明迁移后会有效。
