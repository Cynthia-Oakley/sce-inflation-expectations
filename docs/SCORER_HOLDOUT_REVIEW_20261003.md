# Q9 新月份复查与冻结建议

2026-10-03，Codex。**建议冻结候选版为项目统一的近似密度计分方法，建议名称 `sce_q9_approx_v1`。** 本轮只做对照与建议，尚未替换生产模块。

## 复查设计与证据边界

先写入 [运行前方案](SCORER_HOLDOUT_PLAN_20261003.md)，固定 2020-04、2021-10、2022-12 三个月与选择条件，再运行既有两版算法。原计分器直接调用；候选仅调用既定 `relaxed_tail_skip_zero` 分支，无新调参。两版源码运行前后哈希一致。

既有拟合诊断产物只涉及 2020-01、2022-06。本次“新”指未参与个人拟合诊断，不表示整个数据文件从未被看过；60 月官方聚合和部分 P/E 核验以前已做。滚动面板也不保证受访者独立。本次是**计分器选择验证集**，选择后不能再称独立最终测试。没有读取 Agent 输出或用 Agent 预测效果选算法，2023–2024 候选测试期未用于本次比较。

## 主要结果

三个整月共 **3,741 条问卷，2,784 条 Beta 回答**。以下均为“原版 → 候选”，误差单位为百分点：

- Beta 个人均值误差≤0.001：**2,004/2,784（71.98%）→2,424/2,784（87.07%）**。
- 平均绝对误差（MAE）：**0.074535 → 0.046990，降低约 37.0%**。
- 绝对误差 p95：**0.379187 → 0.312204**。
- 最大个人均值误差：**10.905559 → 3.574332**；候选仍有较大个体误差，不能称精确官方复现。
- IQR MAE：**0.118290 → 0.067569**；p95：0.544577 → 0.458117。三项个人分位数的总体 MAE 均下降。

分月 Beta 均值 MAE 与≤0.001比例：

- **2020-04（957 条）**：0.057784 → 0.044714；75.65% → 89.76%。
- **2021-10（967 条）**：0.094345 → 0.048660；67.84% → 84.07%。
- **2022-12（860 条）**：0.070899 → 0.047646；72.56% → 87.44%。

排除旧诊断月份中已经出现的相同十档向量后，还剩 **1,802 条 Beta 回答**：MAE 0.087163 → 0.034333，p95 0.413592 → 0.250947，≤0.001比例 70.20% → 88.73%。改善并非仅来自重复的旧答案；这仍不是严格的独立受访者或外部数据集验证。

两版全部记录的状态分布相同，均有 **3,679 条可计分**，均匀/双档分支未变，无候选新增失败或非法数值。其余 62 条为缺失/不合法概率 49 条、两档不相邻 10 条、三角支持越界 3 条；这些限制如实保留，不为提高覆盖率临时修改。

## 月度指标：拟合误差与样本纳入差分开报告

在两版与官方字段**共同有效且权重为正**的样本上，密度均值的加权中位数绝对误差：

- 2020-04：**0.037971 → 0.000000588**（1,272 人）。
- 2021-10：**0.046622 → 0.031337**（1,263 人）。
- 2022-12：**0.063771 → 0.014686**（1,142 人；另有两条可计分记录不具正权重）。

候选结果相对官方 chart 的有符号差分别为 **−0.000000588、+0.018757、+0.014686**。直接用官方个人派生值和官方权重聚合，三个整月都与 chart 一致到浮点精度。

2021-10 官方可聚合 1,266 人，本项目两版均为 1,263 人，少三条三角支持越界记录；官方共同样本中位数比官方全样本低 0.012579。因此这一月的 chart 差 0.018757 并不等于纯拟合误差 0.031337，两项部分抵消。不能混用两种口径宣称更准。

## 必须保留的折中

**候选并非每个子组都更好。** 开放尾、连续正概率档子组共 1,666 条：

- ≤0.001比例改善：59.84% → 79.23%。
- MAE 略增：**0.070380 → 0.071814**，约增加 2.0%。
- p95 恶化：**0.383234 → 0.480912**，约增加 25.5%。

这表示更多回答接近官方，但该子组剩余偏差较大的回答并未普遍改善。不能只报总体准确比例；未来研究尾部/不确定性异质性时，须保留该分组误差说明。

另外：候选 2,784 次 Beta 求解均报告成功，但有 **171 条数值 Jacobian 秩不足**、**190 条开放支持缩入名义尾档**。前者是解识别风险标记，不是 171 个精确不可识别定理；后者是候选已知近似约定，会使部分受访概率与连续密度不完全一致。此次分位数 CDF 反演残差最大 3.59e-13，未发现新增数值有效性问题。

## 为什么仍建议冻结候选

预设的八项可执行判定全部通过：无新增失败/非法输出、总体 MAE/p95 改善、达标比例不降、各月 MAE 不明显恶化、IQR 不明显恶化、月度共同样本聚合不明显恶化，以及新十档向量子样本没有双重退步。

本项目优先关心个人密度均值与月度聚合，三个月这些主要指标均改善。开放连续子组的 p95 退步是需要披露的代价，尚不足以否定主目标上的总体改善。本结论是预设规则下的工程取舍，没有显著性检验或“所有未来月份必然改善”的保证。不按分组临时混合两个计分器，也不再用这三个月寻找第三版参数。

## 给 Kimi 的冻结与集成要求

1. 建议版本名 `sce_q9_approx_v1`，明确标注“项目近似指标”，不命名 NYFed official。它是原版的概率校验/均匀/三角分支，加既定候选 Beta 分支（含 brentq 分位数），不是仅改三行边界而保留旧分位数路径。
2. Beta 规则：跳过中间零档对应 CDF 拟合点；α/β 下界 1.001、上界 200；开放端外限±38、内限按候选代码；尾起点±20，形状起点 (1.1,1.1)/(2,2)/(5,5)，固定最低损失解选择；least_squares 的 ftol/xtol/gtol=1e-11、max_nfev=1200；brentq xtol=1e-13。精确边界表达式以冻结哈希的代码为准。
3. 在 study 的 scoring 内实现完整接口，生产模块不要依赖 `scripts/diagnose_sce_beta.py` 或读取官方标签。保留原版本或可追溯提交；新增版本变更记录。候选诊断字段保留到评价日志，不能静默丢掉失败/秩不足/支持缩入信息。
4. 移植完成后，对本次封存输入/结果做逐行等价验收（均值与分位数绝对差≤1e-8，状态和覆盖严格相同）。这一步是工程迁移核验，不再是新月份验证。依赖版本改变时也须重做数值等价核验。
5. 同一冻结版同时处理真实十档与模拟十档。真实问卷权重和模拟人口设计权重分别使用其合理口径，不把官方个体权重直接赋给合成人群。模拟误差优先对比同计分器的真实问卷指标，同时另报与官方 headline 的差。
6. 不为拟合更好静默删除开放尾个体，不对候选加常数校正，不按月切换算法。新增方法变体或真正修复需新版本和新验证计划。

本轮没有修改 `scoring/sce_q9.py`、既有候选脚本或真实 LLM 配置；没有模型/MCP调用。此报告是采用建议，Kimi 的生产集成仍待执行。
