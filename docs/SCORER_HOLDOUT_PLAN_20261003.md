## 指标和预先确定的建议规则

主要目标为个人密度均值。误差单位为百分点；逐人指标使用共同有效样本，月度聚合使用官方权重。至少报告：

1. Beta 分支总体与分月的 MAE、中位绝对误差、p95、最大误差、≤0.001 比例；开放/闭合 × 连续/有空档分层。
2. 均匀/三角分支一致性、两版覆盖率及失败状态。
3. IQR 和三项分位数误差；候选求解状态、秩不足、尾支持缩入情况及分位数 CDF 反演残差。
4. 月度两版加权中位数、官方个人字段在共同样本上的加权中位数、官方全部有效样本及 chart。拆分拟合差与样本纳入差，不用 headline 反向调参。

以下规则全部满足，建议冻结候选为项目近似计分器：

- 候选没有额外失败、非有限值、逆序分位数或超出支持端的均值；未改分支一致。
- 共同 Beta 样本总体 MAE 和 p95 均低于原版，≤0.001 比例不低于原版。
- 任一单月 Beta MAE 不恶化超过 10%；总体 IQR MAE 不恶化超过 10%。
- 任一月共同样本月度中位数绝对误差的恶化不超过 0.05 个百分点。

10% 和 0.05 是本次预先声明的工程选择容忍度，不是官方标准。新十档向量子样本用于检验改善是否只来自旧答案重复；若该子样本 MAE/p95 同时恶化，暂不建议候选。其他极端值/分组差异如实披露。

若规则不满足，建议暂保留原版并标明缺陷，或明确列出需要用户权衡的冲突；不得在看完结果后改规则、换月份或加第三种候选来获取“通过”。本轮是选型验证集；选择后不能把它当最终独立测试集。
