# SCE 研究与评测协议（正式实验前冻结）

> **2026-10-03 用户澄清（D048，优先于下文旧版）**：[两线研究定义](A_B_RESEARCH_DESIGN.md)。A 线用已知信息重建历史微观结构，可以使用当期人口及声明采用的宏观约束；B 线用 t 期可得信息预测 t+1 调查。下文“当时可得/禁止当期结果/封存”等限制仅适用于 B 线预测输入，不能全部套用 A 线。A 线需区分拟合约束和独立验证量。时间划分与最新计分状态分别以 D045c、D044 为准。

更新：2026-09-28。研究方向已确定；以下是待冻结设计，不代表已完成实验。方法解释见 [SCE 方案](SCE_PROJECT_PLAN.md)，日期见 [ROADMAP](ROADMAP.md)，冻结记录见 [DECISIONS](DECISIONS.md)。本版替代旧协议中的 WWTW/ACCA 候选示例。

## 1. 目标与预测时点（旧版，B 线适用）

- 人群与频率：美国 SCE 所定义的 household heads，月度调查；合成样本不自动等同于一般美国成年人。
- 拟主目标：一年期通胀预期，个人概率密度均值的跨人加权中位数；副目标：点预测的加权中位数。统计值单位为百分比，预测误差为百分点。
- 主实验建议：对目标月 t，信息截止为 t−1 月末 23:59:59，时区 `America/New_York`。实际实现需处理夏令时并保存带时区时间，不能全年写固定 UTC 偏移。
- 月底发布前 nowcast、按真实作答日回放是分别标注的附加实验；不与月初预测混报。只有日期的输入需要预先确定保守可得规则，不把当日午夜当作已知发布时间。
- 完整 Q9 概率拟合未验收；不能用区间中点近似冒充官方 headline。若改用点预测主线，先追加目标变更及理由，再做该目标正式评测。

## 2. 数据契约与隔离

真值表至少含 `target_id, geography, reference_period, question, value, unit, fieldwork_start, fieldwork_end, release_at, source_url, source_version, extraction_method`。新增或修订版本分开存，不静默覆盖。最新修订真值可作明确标注的评价标准，历史输入仍必须遵守当时可得版本。

输入记录至少含 `signal_id, value_or_text, reference_period, observed_at, published_at, ingested_at, vintage, source_url, source_version, as_of, availability_rule`。观测日、发布时间、抓取日和版本日期是不同概念；回测只接纳当时已发布且当时确实存在的版本。未知可得日先隔离，不靠“调查月加九个月”或 MCP 月份参数推断。

B 线 P 来源也要满足历史可得性；不得使用尚未发布的同期画像、权重或问卷答案。画像只按过去记录向后填补，不用未来访次倒填；多人月抽样要避免同一人重复计权。若使用同期真实 P 做事后条件重建，独立标注并评价。

物理分层：`data/processed/` 是声明的输入/校准资料，`data/evaluation/` 是评价资料。运行时按分支设字段白名单。B 线不纳入待预测期 SCE 结果及复述报道；A 线允许声明使用已知宏观结果作重建约束，但这些量不再充当独立验证真值。两线均记录资料的实际用途，禁止把答案复制冒称独立验证。

## 3. 时间切分与最低对照

候选窗口为 2020–2024：2020–2021 开发、2022 验证、2023–2024 连续测试；仍须按数据可得性冻结。已查看微观数据以核验计分，需如实披露；此类对账不用于选择测试表现最好的算法。

最低对照包括：

1. `as_of` 时最后公布的目标值，不能机械用 t−1 月；需要时增加按历史可得数据拟合的 AR/线性宏观基线。
2. 接受同一 E 的单次直接 LLM 聚合预测，检验多 Agent 是否有附加价值。
3. 历史人口组统计加简单宏观更新规则。
4. 同质 P / 异质 P 消融，以及基础 E / 增加价格暴露或新闻的比较；校准只在开发/验证期拟合。

模型、prompt、人口数、参数、重试规则和校准只在开发/验证期选择。正式测试前固定配置和代码版本；发现缺陷另留版本及修复理由，不覆盖原结果或删掉不利月份。

## 4. P/E/B 与计分

- P：先历史可得固定加权人口；ACS/CPS/CE 按明确机制与缺口补充。SIPP/GSS 非前置条件。
- E：先价格、劳动市场与政策信号；服务或自行下载统一经过版本/发布时间核验。新闻是增量实验，不以任意注意力权重替代证据。
- B：先确定性规则贯通，再生成带符号点预测与十区间概率。校验范围、单位和总和；有限修复请求并记录失败，不静默大幅归一化。真实单个人的主观概率不等于模型重复调用的波动。
- 计分：Q9 回答 → 个人密度派生量 → 跨人加权聚合；点预测独立计分。现有 60 个月对账只验证跨人聚合，未完成全部个人密度复现。
- 可记录 Agent 过去模拟的状态；不拿未公布的真实个人回答更新记忆。外生历史宏观环境下的跨月状态不构成内生价格形成。

## 5. 评价与结论范围

主要指标 MAE/RMSE，单位百分点，附逐月误差和相对基线差值。群体/分歧/不确定性指标作为预先定义的诊断；没有受访者一一对应关系时不报告虚假的个人匹配准确率。考虑月份数较少及轮换面板依赖，避免把人月数当独立预测样本数。

历史 prompt 无法删除模型预训练知识；**历史输入的 `as_of` 合格不等于模型参数也合格**。真实 LLM 运行前须登记实际模拟模型 ID/固定版本、训练及后训练截止、工具权限与 prompt；研究助手的模型身份另记。若截止晚于目标 `as_of` 或未知，将 2021 年 LLM 结果列为回顾性条件模拟，不报告为严格事前预测。无 E、错月 E、隐藏日期和结果回忆等只用于诊断，不能证明无泄漏。可核实的历史时间快照模型或事前封存的未公布月份预测才可能支撑更强主张。详细门槛见[模型时间泄漏协议](MODEL_TEMPORAL_LEAKAGE.md)。未来 CPI 可用于预期偏差分析，但目标真值是调查预期。模拟消融的差异不直接解释为现实因果效应。

## 6. 冻结与复现验收

正式测试前冻结：目标/问卷/计分版本、P 来源与人口数、E 来源与可得规则、时间切分、实际解析的模型 ID/修订及时间边界、prompt、工具权限、对照/消融、主要指标、随机种子、总预算。无法取得模型时间证据时，先调整结论类别，不假装已消除前视偏差。

每次运行保存 commit/dirty 状态、配置和数据哈希、模型与 prompt、调用量/费用、输出与失败记录。真正达到以下条件才宣告 study 可复现：

- 同一离线输入与种子可重跑；未来或未知可得时间被拒绝；B 无同期真值。
- 所有对照使用一致的测试月份和信息边界。
- 提供经过运行验证的无密钥入口，区分干跑、封存响应重算和真实 LLM 再生成。
- 从提交包能重现报告主要统计，不依赖本机绝对路径或未声明的外部资料库。

**运行证据链附加协议（2026-10-02 起，v3 换行差异教训）：**

- 运行前封存将执行源码的 SHA-256；行为函数在运行开始即计算自身 `__file__` 的源码哈希并写入 `run_manifest`（自报哈希），使"持久化源码 ≠ 实际执行源码"可直接检出。
- 落盘文件与取回文件之间的任何格式转换（换行、编码、压缩、base64）必须随归档记录；未记录的转换按缺口标注，不宣称证据链闭合。
- 平台自身轨迹库（如 `trajectory/panel_live.jsonl`）是独立于行为函数 sidecar 的证据来源，每次运行取回并与 sidecar 交叉核对内容一致性。
