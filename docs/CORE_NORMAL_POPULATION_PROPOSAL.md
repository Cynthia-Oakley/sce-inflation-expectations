# Core/Normal 人口方案（待复审稿）

2026-10-03，Kimi 起草；状态：**待用户拍板与 Codex 复审，未冻结**。依据：[POPULATION_WAVE_STATS](../studies/sce_inflation_expectations/reports/POPULATION_WAVE_STATS.md)（逐期微观统计，可复算脚本 `scripts/analyze_sce_wave_stats.py`）与 D045/D046。

## 1. 设计原则

- 主人口与 **SCE 每期真实调查人口的分布对齐**（D046），不再以"严格全年 panel"为主人口（73 人版保留为稳健性对照）。
- 参照 ConsumerSim 分两层：**core = LLM Agent 模拟**；**normal = 不调 LLM 的统计投影**，把 core 的结果外推到全样本。
- 实测依据（POPULATION_WAVE_STATS）：分层价值排序 employment(组间中位数差 6.3pp) > education > income > age，region/numeracy 仅配额校验；**结构可外推、水平不可外推**（水平须锚定当月公布数据）；同一受访者相邻月预期自相关 0.597；人口分布 12 个月漂移处"轻微"上沿（income/employment 需按年校准）。

## 2. Core 层（LLM Agent）

- **规模 500 人**（500×12 = 6,000 调用，DeepSeek 峰时估 $2.1 含重试余量；备选 300 人 ≈ $1.3）。并发后约 1 小时。
- **抽样**：2021 年 2,990 名真实受访者并集内，按 **education × employment × age 分层配额**（目标分布 = 全样本逐月平均构成），region 配额校验；seed 固定、来源哈希、分布对照写入 meta（沿用 build_sce_population.py 契约，扩充分层模式）。
- **每个 Agent 对应真实 userid，全年固定模拟 12 个月**：跨月持续性由"上月回答"机制承载（自相关 0.597 支持）；**在册月份可逐人对真值**（A 线独有锐度）。
- 轮换处理的取舍：真实 SCE 每月 10–14% 为新进入者（无上月回答），固定 core 全员有先验——对聚合的影响为二阶，作为局限性注记；如需可增设"新进入者"子组（首月无 prior）做稳健性。

## 3. Normal 层（统计投影，不调 LLM）

- 把 core 各层格子（education × employment × age）的当月回答分布，**逐月投影到全样本人口联合分布**：后分层/raking 到当月真实边际，向 core 格贝叶斯收缩；**水平由当月 core 与公布数据锚定**（"结构可外推、水平不可外推"的工程化）。
- 产出"虚拟全样本"月度估计（中位数、分布、分组差），与官方 headline 直接可比；与 core 原始聚合分表呈现，可分解"core 直接聚合 vs 投影后"的差异。
- 实现为评价层脚本（不进入任何 Agent 输入）；输入 = core 轨迹 + 评价层真值边际。

## 4. 逐月人口调整问题（用户提问的正式回答）

**Agent 池不逐月调整，投影层逐月校准。** 理由：SocioVerse2 的核心抽象就是固定人口池的纵向面板（B = f(P, E)，persistent agent ids）——固定 core 是方法原生形态，也保住"上月回答"的连续性；真实调查逐月构成变化由 normal 投影层的**逐月边际校准**吸收（后分层目标每月更新），这与真实面板调查用权重处理构成变化同构。逐月重抽 Agent 池的"截面复刻"变体会丢弃面板连续性，只作为稳健性臂候选，不进主线。B 线按统计结论**按年校准** income/employment，其余维度 12 个月内复用。

## 5. 评价三层（主窗口，微观级）

1. 逐人逐月：core 在册月的模拟 vs 真实回答（点预期误差、密度均值误差）；
2. 分层人群差异：按分层维度的组间差是否复现（方向与量级）；
3. 全国聚合：normal 投影后 vs 官方 headline（加权中位数、官方派生均值），统一用 D044 冻结计分器，官方差异另报。
