1. **个人更新：完成已有候选，检验中心与更新。** 直接报本期Q8/Q9，与报相对本人上期的改动、再由程序恢复答案比较；相同P/E、先验和预测窗口。已有转换器和191对草稿，先补缺失分支、独立入口与合法率检查。格式变化未必有效，不预设更新必须小，也不重试已经失败的固定加权。
2. **认知与概率表达：把真人发现变成可检验输入。** 区分两件事：High/Low与具体答法比较，检验细信息增量；原题+本人实际作答与忠实转述比较，检验呈现方式。后两者保留相同题意、数字和本人回答，不附标准答案、对错反馈或固定认知偏差。重点看个人不确定性和尾部表达，同时保留中心/W1/更新指标。
3. **价格体验与财务情境：同步准备，付费验证后排。** 先修正新匹配候选的回访收入/家庭更新，限时补跨年CE并记录失败。供体条件与价格颗粒度要一起审查。Q1自报财务变差是另一个独立情境候选；其关联不直接变成通胀加分，A/B的可得性分开。频率、财务和认知不同时全加。
4. **持续性与事件理解：保留为有条件的备用。** 研究同样的价格和政策事实，为何有人认为会持续、有人认为会消退。先找调查支持的理解方式及人口关联；没有可靠分配依据时仅做机制情景，不自称代表美国人口比例。若前两项已耗尽探索窗口，本项留作后续研究。
5. **验证与B路线：每个候选最终都要面对。** 除群体中心，统一评价跨人分布、个人变化和不确定性；同一月份/样本/信息比较简单基线。B先核查相邻月输入，尝试自己的状态递推，区分一次预测与误差累积。
