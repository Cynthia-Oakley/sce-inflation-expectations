# 近期价格与家庭环境匹配：开发试验

## 问题与顺序

当前模拟偏低且分布过窄。本轮只检验两个问题：补充调查月内已经公开的零售价格是否有帮助；按家庭所在州匹配汽油市场是否优于随机分配。尚不把支出占比当作购买频率，也不指定居民必须上调预期。

## 冻结设计

- 路线 A 回顾模拟；2021-05/06，两月各沿用已有 20 人小样，月内各组逐人配对。
- 四组：原有 E；原有 E＋近期全国价格；原有 E＋近期食品及所在 PADD 汽油；相同地区价格集合随机分配给家庭。
- 所有组使用相同人口、相同 CE 合成支出占比、相同原有宏观/新闻信息、相同问卷。原有统计表暂保留，以便单独检验新增价格；本轮没有检验“删除完整统计表”。
- 食品固定选择常规半加仑牛奶、8oz 碎奶酪、4–6oz 希腊酸奶，均记录本期、上周、去年价格和样本商店数。它们是广告促销价格，不是同店同品跟踪，也不是全体食品指数。
- 汽油取 EIA 归档周报表14的普通汽油含税零售价格，使用截至 5/10、6/7 的12周记录。州→PADD 按 EIA 地区定义确定；地区均值是地域代理，不是受访者实际加油记录。
- 随机组置换整条地区汽油序列，集合不变；记录同州区间无法改变的分配比例，不谎称人人都错配。
- 模型 `deepseek-flash`，temperature=0.5，seed=42，每份最多1024输出token，不自动重试，最多160次真实调用，总上限$1、单格上限$0.12。运行前核实当前价格及实际输入成本边界。

## 执行与记录

1. 官方 PDF 下载、哈希、确定性解析；发布日期只精确到日时，以当日纽约时间末作为保守可得界，不将抓取日当作发布时间。
2. 建立隔离输入、逐份预览，清除源ID/真实答案/权重，冻结源码与输入；确定性 SocioVerse 流程验证通过后才调用 API。
3. API 仅向 DeepSeek 官方发送已获准的去标识人口分档、合成 CE 占比和公开经济资料；不发送真实 QSP5 支出、受访者ID或通胀答案。先前真实篮子试验继续单独等待授权。
4. 逐格记录真实请求、响应、模型标识、token、费用、失败情况，保留原始结果；任何失败停止，不为凑齐结果改变提示或参数。
5. 运行后才读取真值，使用冻结计分器比较 Q9 个人均值分布的中位数误差、W1、IQR差及分组误差；Q8与个人MAE为补充。配对重采样只描述这个小样，不代表重复生成的不确定性。
