# 长跨度实验运行卡草案

2026-10-07。仅用于下一轮讨论和开发交接，**不是已授权的新执行配置**；本轮不运行模型、不切换旧配置、不冻结新测试期。

## 1. 目的与范围

分别检验：A 已知信息下的历史重建能否同时解释总体水平、人群差异及分布；B 在截止前信息下能否预测下一月 SCE。结果分开报告，输入版本由[人口和修订准备报告](SCE_B_READINESS_AND_VINTAGES_20261007.md)约束。

候选跨度为2021-01至2026-08（68个月）：2021年已有重复开发诊断，2022年以后涵盖高通胀和回落，2026年涵盖近期。A 的当期微观人口/分组评价目前最多至2025-10；之后只能在 B 全国公布指标上评价。2026-09/10已有 E 草案，没有本轮已核验的全国结果，不能先填写效果。以上是数据范围建议，尚未批准正式测试窗口。

## 2. 训练、开发和评价

- 非 Agent 回归训练建议从最早有共同 E、且过去 SCE 标签可得的月份开始；不能只有2021年12点拟合后声称长期样本外。每次预测只能拟合当次 cutoff 前已公布的标签和对应历史输入，参数选择限制在训练期内。
- 2021-05/06及所有已经查看过的实验月份继续标开发；已有长跨度基线/人口诊断也已查看，不能改叫全新盲测。
- 参数和机制确定后，冻结连续后续评价窗；新公布月份单独留作前瞻评价。已知历史的滚动回测与真正未见未来分别命名。
- 资料年份不同不等于自动完成训练/验证/测试分割；应落盘逐月登记哪些数据曾参与诊断、哪个标签何时可得。

## 3. P / E / B 候选

**A 人口**：每月完整真实画像，答案和评价权重在模型外；Core来自该月全部画像，Normal同规则。**B 人口**：此前已公开的加权联合画像重抽样，单月与12月混合对照；旧画像可得性未独立证明的历史月份单列。当前已物化2026-10例子，历史各月人口尚未接成长期包。

每月300 Core 为当前规模参照（来自已有统计扩展开发检查），不是已证明的最低规模。人口总量采用明确的参考规模，不能用合成总量制造独立样本量。150/200 Core敏感性尽量复用同月已有回答，但须采用正确的入样率和适合该抽样设计的扩展方法。月度横截面先验收，长期记忆/人口轮换另模块，避免 ID 重用冒充持续家庭。

**E**：B上月末 cutoff；每个指标保留自身日期，首发版本和截止日最新版本分包。当前首发包可作为受限信息对照；最新版本包须先补实际修订来源。完整汽油/新闻版本不明时，BLS-only严格候选和完整敏感性分别运行，不能称完整包已严格合规。A 全信息包单独声明其观察窗。

**B**：候选日期提示 `sce-q8-q9-v3-dated-abstract-v1`；Q8/Q9与冻结计分器不变。沿用温度0.5作为控制参照，模型使用API实际精确标识。更换早期Qwen/LLaMA是独立对照，不能同时改 P、E、温度后把差异归因于模型。

消费/心理侧车在 B 中须重新证明截止前已公布，不直接复用 A 的后验代理。人口替换与日期提示先做独立对照，再组合；本轮候选未验证能缩小系统性低估或增加合理异质性。

## 4. 公平基线与评价

Agent和回归共享同一逐月宏观 E、新闻记录及修订版本。输入缺月和滞后年龄显式编码；数值插补、缩放、模型调参只看训练。新闻当前不强行设计单一正负情绪因子；先保留同宏观基线，并将是否使用新闻明示为比较限制。同模型直接预测、无画像 Agent 作为后续独立对照，新增费用另算。

主要报告：共同月份的全国 SCE 加权口径 MAE、RMSE、带符号偏差；逐月与6/12月滚动误差，高通胀/回落/近期阶段切片；相对持续性和匹配宏观基线的改善。A有微观时再报告分布距离、分组中位数、尾部覆盖、跨月变化。不可把合成家庭和真实家庭随机一一配对算逐人预测误差。

官方全国 headline 与本地冻结近似计分重建的统计量分开对账；A/B均需总体拟合，已给定的宏观约束不能再算独立成功证据。失败回答、Normal回退、人口未知值和输入缺月均报告。

## 5. 费用和执行门槛

一次300 Core月＝300个合法问卷请求，Normal统计扩展不新增 LLM 调用；重试、消融与多模型额外累计。既有600调用估价约$0.536，是旧输入/模型下的历史参照。68个月共20,400基础调用，线性外推约$18.24；**新提示长度与最新模型价格会改变费用，这不是报价或新预算**。

实际费用：所有成功/失败的可计费尝试，逐条累加输入token×输入价＋输出token×输出价；缓存价另列。运行前先离线测提示长度，再做获授权的小批试跑取得实际usage，据此设置单月和整轮上限；不得沿用旧两月$2授权启动长实验。

执行前必须完成：

1. B人口、逐月E与Core/Normal元数据的独立打包入口，白名单干跑和哈希；当前P候选不是完整长期入口。
2. 逐月来源/版本、可得性假设、训练与评价用途登记；年度修订覆盖缺口共同隔离或显式首发对照。
3. 固定一个模型、人口方案、提示版本和计分目标；代码及依赖模块一起记录哈希，不能只哈希 model.py。
4. 同信息基线输入对账、费用卡与数据发送范围确认；已有授权只覆盖此前具体实验。

初步通过后再逐批扩展；每批生成唯一 run_id、输入/提示/原始回答/usage/费用/失败记录。保存旧实验，新版本不可与旧73人或旧 E 两月结果拼成长期序列。
