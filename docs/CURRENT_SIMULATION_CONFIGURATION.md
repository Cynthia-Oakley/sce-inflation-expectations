# 当前模拟配置与可报告误差

更新：2026-10-17（北京时间）。本页是已实现配置及证据的清单；未产生新模拟、未选择最终参赛模型。新增API调用0。

## 一、当前共同使用的配置

最近的财务对照已实际同时使用下列内容，不是把各次试验的改善率相加得到：

- **Population：** SCE实际回访者的年龄组、教育、收入档、地区/州、住房、就业及High/Low数理标签。另有合成CE四类支出占比和依据过去Gallup分布合成的美联储信心；两者不是真人实测支出或信心。
- **Environment：** 按截止点组织的历史价格/就业/汽油等资料、滚动趋势、筛选后的NYT新闻与政策短讯。现配置共同新闻3条、个人新闻5条，个人新闻延续50%随机加50%相关加权；发布时间标记区分早已公开、后来公开及同日不确定。
- **Behavior：** 本人真实上期Q8/Q9及更早问卷均值/次数摘要作为既有信念，允许保持或调整；直接填写本期Q8及十档Q9，不使用失败的概率差值输出。
- **运行：** 官方SocioVerse2引擎、本地文件P/E、DeepSeek官方Flash、温度0.5、关闭思考、无自动重试；保存原始调用和轨迹，真人与模型Q9原始十档同一冻结近似计分器。

共同使用表示它们已集成在工作参考输入中，不表示每个模块都已通过独立验证或能证明单独改善。用户认可的局部进展保留，原试验未过综合门槛的事实也保留。当前不是一套已经冻结的最终获胜配置。

## 二、目前保留哪些候选

1. **家庭财务事实：** 在共同配置上增加本人本期/上期Q1年度财务自评。最新真实三组已执行，中心改善，个人和分布未同步改善，保留候选；额外家庭视角句无清楚收益。
2. **具体数理/金融题：** 所有人加入本人早期七题实答，原认知实验中心0.736→0.652pp，个人概率宽度及整体微观结构未稳定改善；尚未叠加新Q1财务事实。
3. **仅低组加题：** 原回答事后组合，等权中心0.638，但两套加权均不保持，不优先升级；不是新独立试验。

## 三、最新实际合跑版本的误差是多少

最新财务试验：2020-04、2021-05、2021-11、2022-03各24人，三组各两遍。Q9共同92人月，四个真人十档缺失/不可计分；每种配置184条共同生成。以下是同批配对、等人权重、等月份/生成遍数汇总。

| 配置 | Q9样本中位数MAE | 个人Q9均值MAE | 跨人分布W1 |
| --- | ---: | ---: | ---: |
| 共同参考配置 | 0.637465 | 3.352486 | 2.391920 |
| 共同配置＋财务事实 | 0.502189 | 3.532571 | 2.463766 |
| 财务事实＋家庭视角句 | 0.658098 | 3.481234 | 2.472724 |
| 同样本照抄本人上期Q9 | 0.736860 | 3.569867 | 1.777365 |

**可以报告的局部成绩：共同配置＋财务事实，样本总体Q9中位数MAE约0.50个百分点。** 同批参考配置0.637，改善约21%。个人均值MAE仍约3.53，W1约2.46，人际IQR约2.74而真人5.56。宏观中心和微观结构不能互相替代。

辅助使用既有抽样/调查权重时，共同参考中心0.656941、财务事实0.446675、视角0.714004；同样对模型和真人加权。它也支持财务事实的中心改善方向，但不产生全国代表性，更不把0.45和0.50拼成统一准确度区间。

主个人均值MAE的事实−参考差+0.180085，探索性95%区间[−0.031715,+0.417147]；中心点值下降仍不足以通过预先确定的综合继续门槛。Q8是单独的点预期题，最新三组样本中位数MAE均0.7375，没有同样改善。

## 四、误差口径与适用范围

- Q9每人拟合密度均值，再取样本跨人中位数；每月/每次生成先算绝对误差，再等权平均。0.50指这个样本中心误差，目标仍是居民下一年预期，而非未来实际CPI的误差。
- 这是四个开发月的条件历史重建，既用了真实本人过去回答，也用了真实当期画像/财务自评，不是全年全国SCE预测MAE，也不是B路线自主连续预测。
- 原认知/财务试验同样参考提示、同样24人，重生成的参考误差分别0.736和0.637；因此单批点值会波动，不能承诺0.50为稳定上限。
- 数理题与财务事实的完整联合版本未运行，不能把0.652、0.502等单项结果继续相加/相乘推出联合误差。

## 五、较长窗口的参照

10/14已完成八期96人的旧架构试验。冻结规则后的四个评价期，含本人历史的LLM中心MAE0.636、W1 3.161；同样本照抄本人上期0.156、W1 0.691。新时间标记、直接格式及Q1等后续候选还没有在这一完整范围统一验证，不能用新四开发月0.50与旧四评价期0.156直接比较胜负。

所以现阶段已有可运行组合和局部中心进展，最新版本的长跨度表现及B递推成绩仍待验证。下一步先确定一套主配置和一套必要对照，锁定权重、未用于选择的月份与费用，再做统一验证。
