## 1. 共同模型、接口与评价

- 主模型：OpenRouter→固定SiliconFlow FP8，`deepseek/deepseek-v3.2`；温度0.5，关闭思考，JSON对象，最多1,024输出token。Flash、Qwen和平台MCP是历史对照，不是当前主模型。
- 直接填写Q8点预期和十档Q9概率；结构模板不提供数值示例。不使用Q9变化值答题接口。合法非负且总和大于0的完整十档按冻结规则等比例归一化；缺档、截断、传输失败分别记录，不按拟合成绩重抽。
- 正式生产后端为官方Core离线验收后的本地冻结消息适配器；逐条原始回包/意图/费用留档、固定供应商、无自动回退。技术补跑、冷却和停止条件按每批授权，不能把所有批次概括成同一重试规则。
- 全国Q9：逐人连续密度均值→设计加权中位数→对官方首发按月份等权算MAE/RMSE（pp）。微观另用同支持、同权重、同近似算法；Q8单列。公开历史持续性和“照抄本人上期”是不同支持的基线。
- A T0与早期共享截止不同；B的P/先验与个人环境也不同步，不能把全部结果称严格同一as_of预测。模型知识与历史文本版本边界继续披露。
