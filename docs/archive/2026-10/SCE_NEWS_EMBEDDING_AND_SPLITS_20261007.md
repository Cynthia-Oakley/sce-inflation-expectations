# 新闻句向量与基线训练／评价用途

**同日最新用户调整：先补E，高阶新闻基线暂缓。** 768维直接月度回归不适合本项目样本量；一维正负情绪也不等同通胀方向。下文MPNet/PCA和示例日期是历史候选，未实施或冻结，不再是下一项任务。见[当前资料补齐入口](../../SCE_ENVIRONMENT_EXTENSION_20261007.md)与[ConsumerSim新闻披露核查](../../literature/sce/news_baselines/CONSUMERSIM_NEWS_BASELINES_20261007.md)。已有AR/ARX仍使用按可得历史逐月训练，并非下文示例三段划分。

2026-10-07。用户决定暂不使用 TF-IDF，直接采用句向量。本文说明实现候选和时间划分，不宣布模型已下载、基线已训练或新测试期已冻结。零 API，未修改既有运行配置。

## 1. 编码方式：推荐先本地，API 可替代

候选为固定版 `sentence-transformers/all-mpnet-base-v2`：面向英文句子/短段落，输出768维。它是文本编码器，不是负责模拟居民作答的模型，不需要我们再训练大型BERT。模型可下载到本机，以CPU先小批验收；是否用Mac的GPU加速取决于实际依赖兼容，尚未测试。当前每月仅30条标题＋摘要，优先本机验证，不先租云服务器。若速度或内存不足，可换同一权重的云端运行，不同时换编码器来冒称仅换部署方式。

另一条路线是 OpenRouter 的 `/embeddings`，它有独立的 embedding 模型目录，区别于 Llama/Qwen 的聊天接口。支持的是平台当时可用的特定模型，不保证本地MPNet候选也在其中。执行前核对模型、provider、费用与数据发送范围；本轮未发送新闻、未读取密钥或生成付费向量。

本地存储建议：模型权重 `data/raw/news_embedding_models/<model>/<revision>/`；向量 `data/processed/news_embeddings/<build_id>/`。这些路径当前只是规划，尚未创建。记录实际不可变revision、下载哈希、模型卡、许可、tokenizer、最大文本长度、截断/分块规则、推理库和设备。

本地固定权重便于复算、没有逐条API账单，但不自动消除训练知识风险。编码器也应记录训练年代和语料；未披露精确截止时就记录未知，不能因它只输出向量便称严格历史无泄漏。

来源：[Sentence Transformers预训练模型](https://www.sbert.net/docs/sentence_transformer/pretrained_models.html)、[MPNet官方模型卡](https://huggingface.co/sentence-transformers/all-mpnet-base-v2)、[OpenRouter Embeddings接口](https://openrouter.ai/docs/api/reference/embeddings)。

## 2. 新闻如何进入回归

流程：**同一批标题＋摘要 → 每篇固定句向量 → 每月汇总 → 训练内降维 → 与共享宏观列一起回归**。

初版候选按当月已选新闻等权汇总向量，附新闻条数与摘要缺失/截断标记；不按测试期效果重新加权、筛选报道。等权汇总会压平少数冲击新闻，是需要检查的表示限制，不声称与LLM的语义处理完全等价。后续如果按新闻类别汇总，类别定义和权重也应先在开发期确定。

MPNet默认超过384 word pieces会截断，因此先审计每篇标题＋摘要长度，不能直接把整个月新闻拼接成一条超长输入。过长文本用明确分块与篇内汇总规则；记录被保留的信息。普通文本摘要预计无需大规模分块，但尚未跑tokenizer验收。

固定编码器不利用本项目SCE标签，可以逐篇编码并缓存所有月份；允许缓存不代表允许用测试月份拟合PCA。月向量的标准化、PCA、回归系数与参数选择必须限制在训练或过去验证月份，评价月份仅调用已拟合变换。候选PCA维数2/4，不将768个新闻维度直接塞进短月样本回归。

全国回归的独立观测单位是月。一个月300 Core回答不会变成300个独立宏观训练样本；同时观察几十个居民也不能补足仅12个全国目标月份的样本量。

## 3. 训练、验证、评价怎么分

先分清用途：

- **训练**：估计回归系数、标准化与降维。
- **验证**：在后来的过去月份上选Ridge惩罚/PCA维度等，选择后冻结。
- **评价**：不根据它的误差改变编码、新闻选择、参数网格或框架。

可研究的时间顺序示例：2017–2019初始训练，2020验证，2021起作后续样本外回测。**这是例子，不是已冻结日期，也不是这些E已经齐备。** 若评价从2021-01开始，必须先补该窗口之前的宏观/新闻E及已发布SCE标签；资料不足则报覆盖不足，不能用2022以后的数据训练再倒回去预测2021。

滚动执行时，预测目标月M前只读取as_of之前已公布的目标标签；历史训练特征在各自原as_of物化。第一次预测完成并保存后，等该目标答案公开，才允许在后续月份的重新训练中加入它。该月原预测不重写。没有“全是训练集”：每条被报告的误差都来自当时尚未用于训练的目标。

严格留出评价可选两种协议，执行前选定并封存：

1. **冻结训练集的整段留出**：验证后固定系数和变换，整段评价不更新，检验跨时期迁移。
2. **滚动重新训练的样本外评价**：框架/参数选择规则固定，系数与训练内变换按已公布过去数据更新，检验更贴近实际工作的月度预测。此时过去的评价月后来进入训练是合法的，但不能据其误差临时挑新模型或改方案。

初版建议以第二种为主，第一种作敏感性分析，区分二者，不选择较漂亮的一张成绩单。可调参数初版先在前置验证期选择后固定，不在每个评价月临时搜索更有利网格。

既有AR/ARX已经按可得历史滚动估计；当期真值不参与当次拟合。尚未实现的新闻/全宏观基线要采用上述明确验证程序。此前查过2021–2026的官方基线和部分模拟结果，所以“回归训练外预测”不等于“整个项目从未见过的盲测”。后续机制最终验证须另行声明；已有月份继续用于公开标记的历史回测。

A历史重建可以做明确标注的全期描述拟合，但它不能充当独立准确率证据；若提供当前宏观结果作约束，拟合该约束是达成输入要求。B必须遵守截止前训练和输入规则。本文新监督基线比较默认评价目标均不进入该次拟合。

来源：[时间序列滚动验证](https://otexts.com/fpp3/tscv.html)、本项目[评价契约](../../SCE_EVALUATION_CONTRACT_V1.md)。

## 4. ConsumerSim哪些模型可借鉴

原文§6列出的回归／外部信息模型包括：AR Ridge（三期历史）、Expectations Regression、News Semantic FAAR Proxy、SARIMAX Macro、Prophet Macro、Macro–Market–News Ridge、Macro Stable Ridge。其News Semantic FAAR明确用新闻语义特征；Macro–Market–News Ridge包含新闻派生变量。还有ETS、Theta、Auto ARIMA、Prophet单变量、滚动均值等其他时间序列参照。

原文说明使用截止时点可得信息，并要求可调参数按时间设置验证。但目前核对的正文没有给出足以逐条复刻其新闻编码器、每个基线完整参数及逐月训练清单的材料。论文明确的2024上半年校准用于行为惯性权重，不能直接说它是全部回归基线共同的训练／测试划分。

对SCE优先借鉴：全宏观Ridge、宏观＋句向量Ridge、新闻因子＋AR、宏观SARIMAX。AR或历史SCE特征版仅在该输入也对Agent开放的比较中用于方法归因；否则标为额外信息参照。模型名称借鉴不等于原实现复刻；新闻语义模型用我们的固定编码器和明确时间合同实现。

来源：[ConsumerSim §6/§9/§11](https://arxiv.org/html/2606.30395v1)。
