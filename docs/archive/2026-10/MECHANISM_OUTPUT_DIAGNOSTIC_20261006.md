# 两月 LLM 输出格式与分布诊断

日期：2026-10-06。范围：对 2021-05 与 2021-06 两次 A 线回顾性条件模拟做零 API 原始答案审计。这里记录的是输出形态，不识别形成这些形态的原因，也不构成事前预测验证。

## 数据与口径

按 [两月运行收据](../../CORE_NORMAL_LLM_RECEIPT_20261005.md) 定位原始调用、Core 答案、人口权重与评价真值。逐条解析每月 300 个 `llm_calls.jsonl` 原始 JSON，并与扩展归档中的 `core_answers_original.jsonl` 比较；两月均为 300/300 完全一致。评价真人答案取同一 `agent_id` 映射的 `userid`；交集须同时满足生成与真人 Q8 有效、生成与真人 Q9 十档概率可由项目冻结计分器计分、调查权重大于零。共同有效人数为 5 月 291、6 月 293；对应加权有效样本量约 185.9、181.9。以下对照只代表这些 Core 匹配者，不是全月人口估计。

Q8 以原始 `point_pct` 对照真人 `Q8v2part2`。Q9 的人际分布以同一冻结近似计分器重算个人十档密度均值；Q9 形状诊断则直接比较十档向量。该计分器是项目的冻结研究近似，不是 NY Fed 官方个人计分器。加权分位数使用加权中点 CDF 插值，并对 Core 与真人完全相同地计算；尾部比例按共同有效样本的调查权重计算。

可复核的聚合机器摘要：`outputs/mechanism_diagnostic_20261006/summary.json`（Git 忽略目录，只含聚合结果及输入 SHA-256）。计算脚本已持久归档：`outputs/mechanism_diagnostic_20261006/analysis_script.py`；与临时原稿 `/private/tmp/mechanism_output_diagnostic_20261006.py` 字节一致。摘要记录两月 run_id、来源路径、调用/解析答案逐条一致检查、冻结计分器哈希以及收据、理由词频记录和评价脚本的哈希。

## Q8 数值格式

- 300 条 Core 中，5 月只有 8 个不同数值，94.0% 落在 0.5 的倍数网格；36.0% 是整数，6.3% 可被 5 整除，0% 可被 10 整除。众数为 3.5（135 条）和 3.0（80 条）。
- 6 月只有 9 个不同数值，86.3% 落在 0.5 网格；12.3% 是整数，3.0% 可被 5 整除，0% 可被 10 整除。众数为 4.5（151 条）和 3.5（70 条）。
- 同一共同有效样本内，真人 Q8 有 95.5%/95.6% 为整数，44.3%/45.7% 可被 5 整除，21.0%/20.1% 可被 10 整除；两月各有 43 个不同真人数值。因而模型主要问题不是简单地把答案四舍五入到 5 或 10，而是回答支持点很少、数值集中在少数半百分点位置，且与 SCE 整数响应格式不同。格式/精度约束本身应与信息机制分开验收。

## Q9 十档形状与完整模板重复

在同一共同有效匹配样本中，Core 几乎每人都给十档中的 8–10 档正概率：5 月分别为 22、120、149 人；6 月分别为 47、87、159 人。人均非零档数加权均值为 9.39、9.42（加权中位数 9.42、9.49）。真人十档相对稀疏：非零档数不超过 5 的分别为 224/291（77.0%）与 221/293（75.4%）；加权均值为 4.78、4.55（加权中位数 4.15、3.83）。

Core 每人的最大单档质量中位数为 30.8%、30.3%，最高两档合计质量中位数为 55.7%、57.2%；真人对应为 50.6%、51.3% 和 78.9%、81.9%。这说明生成的单人 Q9 向量较为铺开。它与“人际 Q9 均值分布过窄”是两个方向不同的现象：不能把人内密度形状和人际预期分歧当成同一个方差问题。

按十个原始数值完全相同定义一个 Q9 概率模板。共同有效 Core 中，5 月 161 种模板，59.5% 的回答属于出现至少两次的模板，重复模板每种保留首条后的冗余占 44.7%，最大模板出现 32 次；6 月为 141 种、62.1%、51.9%、31 次。共同样本真人 Q9 分别有 230/236 种模板，进入重复模板组的答题占 30.2%/27.0%，最大模板出现 12 次。虽然完整 JSON 回答（包括 Q8 和理由）每月各有 299 个不同哈希，完整重复只占一对；主要重复发生在 Q9 向量层，不等于整条理由与 Q8 也照抄。

## 同一批匹配者的加权 Q8/Q9 分布

下列数字均是每月同一共同有效样本内的 Core 与真人对照；分位数格式为 `P05 / P10 / P50 / P90 / P95`，单位为百分点。中位数附近和中间 80% 区间之外，同时列出尾部权重占比。完整 P01–P99、均值、标准差及其余尾部切点见机器摘要。

- **2021-05 Q8：** Core 分位数约 `2.87 / 2.95 / 3.51 / 4.94 / 5.27`；真人为 `0.80 / 1.77 / 5.59 / 23.78 / 29.56`。IQR 为 0.99 对 8.77；Core `Q8 < 0` 为 0%、`Q8 ≥ 10` 为 0%，真人分别为 3.9%、37.0%。
- **2021-06 Q8：** Core 约 `3.25 / 3.51 / 4.37 / 4.95 / 5.53`；真人为 `1.38 / 1.97 / 5.70 / 25.46 / 43.24`。IQR 为 0.64 对 10.52；Core `< 0`/`≥ 10` 均为 0%，真人为 3.9%/38.2%。共同匹配样本的真人 Q8 范围为 −50 至 80，Core 范围为 3.0 至 6.0。
- **2021-05 Q9 个人密度均值：** Core 为 `1.84 / 2.09 / 2.95 / 3.45 / 3.85`；真人为 `−0.08 / 0.21 / 4.00 / 12.82 / 22.06`。IQR 为 0.82 对 5.80；Core `< 0`/`≥ 5`/`≥ 10` 权重占比为 0%/0%/0%，真人为 8.4%/42.6%/17.0%。
- **2021-06 Q9 个人密度均值：** Core 为 `2.90 / 2.97 / 3.86 / 4.52 / 4.67`；真人为 `−1.37 / 0.19 / 5.52 / 15.80 / 23.62`。IQR 为 0.98 对 7.42；Core `< 0`/`≥ 5`/`≥ 10` 为 0%/2.6%/0%，真人为 7.9%/50.6%/25.6%。

这组同人比较复现了两类差距：Q8/Q9 水平偏低，且两种问卷指标的跨人分布和尾部显著窄于同一批真人。真人 Q8 的极端回答拉高了均值，所以这里主要用加权分位数、IQR 和固定阈值尾部描述，避免只看均值或标准差。共同样本未见绝对值超过 100 的 Q8；这不推断全月未匹配者也没有异常值。

## 理由文本中出现的主题

每月 300 条生成理由按大小写不敏感正则做重叠词项计数；与此前保存的理由词频复核相符。5 月/6 月提到 `temporary/transitory` 为 205/83 条，`base effect` 为 186/189 条，宽口径 `Fed/federal reserve/target` 为 229/108 条。更窄的字面“2%”出现 264/24 条；明确写出 “inflation target”、Fed 与 target 同句或类似政策目标短语为 4/15 条。提到 CPI 的有 221/127 条；失业率为 1/0 条，非农/就业报告为 0/0 条；油气、能源、食品、房租等家庭价格项为 266/272 条。绝大多数理由含百分数/利率数字，但仅数字出现不说明它引用了哪条 E。

这些计数只描述模型输出的解释文字。它们不能证明模型实际依据了某个输入、不能说明理由生成与 Q8/Q9 的因果方向，也不能区分共同 E、模型训练中的历史知识或事后合理化。提到 CPI 也不等于模型使用了正确发布值；因此理由词频不作为机制验收指标。现有 BLS 简报数值在理由文本中的字面匹配极少，也不能据此断定模型没有读到相关信息。

## 对机制验收的直接影响

主 Agent 于 2026-10-06 交接：四臂 `expression_shared`、`basket_shared`、`focus_only`、`basket_focus` 已实现；据交接说明，四臂保留同一 77 条信号与 30 条新闻，只改变表达、消费篮子显示和顺序，并基于官方 CE 2020Q4 侧车（5,205 行中 5,203 行可用）为两月各建 300 个画像。以上设计与侧车未在本次零 API 诊断中独立复核，名称也不足以确定各臂之间的具体处理对比；验收前应从 run metadata 逐臂核对实际可见内容、随机种子、画像 ID 和输出 schema。

1. **以配对四臂比较离散度与分布形状，而非只看标准差。** 若每臂均使用相同 300 个 P、77+30 相同事实，按相同 ID/调查权重比较 Q8 中位数、IQR、P10–P90、P05/P95、尾部质量和问卷支持点；Q9 同时报个人密度均值的人群分布/尾部，以及个人向量的非零档数、最大档、最高两档质量和完整向量模板重复率。Q8/Q9 边际各用本题有效掩码；联合 Q8/Q9 关系只在共同有效样本上算。四臂中标准差升高本身不算成功，必须看到预先指定的分布距离/分位数/尾部更接近真人，且没有让水平或 Q9 题内形状变坏。
2. **把回答格式作为独立对照。** 这次观察到的 Q8 半百分点网格和少数数值支持点，以及 Q9 大量完整向量复用，都可能来自输出规则或生成习惯。若四臂共同采用某一输出 schema，保持它们完全一致；若要比较自由数字与 SCE 整数 Q8/十档 Q9 格式，单列格式实验，不要和消费篮子或焦点处理一起改变。
3. **重复模板不能按独立新样本计数。** 机制对照仍按固定画像配对；重复 API 调用只估技术抽样噪声，模板相同不能被解释为不同受访者的独立共识。若报告模拟区间，显示按完整 Q9 模板聚类后的敏感性。若某臂只提高标准差、但完整 Q9 向量仍高比例复用、尾部和分位数没有改善，不接受该臂为成功机制。
4. **理由不做因果操纵检查。** 以 Q8/Q9 数值与分布作为主结果；理由只保留为解释文本审计，并标出与输入事实不符或无法追溯的陈述。消费篮子对照若改变了实际显示的事实，应据逐臂记录确认处理；仅改变排列/措辞不能证明模型使用了相关家庭暴露。
5. **分开生成噪声与人际异质性。** 完全相同 P/E/提示的重复调用估计 API 技术波动；不同 P 的差异只有在预先定义、来源可靠的家庭暴露或经验变量下才可作机制解释。temperature 不代表经济机制。模型知识截止仍未知，不把回顾性理由或输出变化包装为严格事前结果。

这两个月只能建立描述性基线，不能确认共享 E 导致回答收敛、人口画像无法解释异质性，或理由中的临时性/政策目标词语解释了回答。模型知识截止仍未知；实际 CPI 可以另作实现值对照，不能替代 SCE 主观预期作为真值。

## 独立实现审查（2026-10-06）

静态只读检查 `price_experience.py`、`experience_mechanism.py`、`build_sce_price_experience.py`、`run_sce_local.py`，并追踪到 `model.py` 的环境观察和 LLM 决策入口；未调用 API，也未改生产代码。本节审查实现路径，不代表四臂已实际运行或行为效果已验证。

1. **CE donor 被明确作为合成代理呈现。** 每份篮子从一个联合 CE 消费单元抽取并按画像字段匹配；提示词说明它来自另一个 CE 消费单元、不是受访者当月的实测购物、收据或购买频率，也不推断其开车/购物角色。份额分母包含缴费/退休金等支出，不是 CPI 篮子；提示词还说明现金住房支出与 CPI 租金等价项有差别。因此代码没有把 donor 说成该 SCE 受访者的真实个人消费。
2. **四臂实际复用相同的基础问卷和公共事实集合。** 机制提示词深拷贝同一 v2-abstract 提示，仅在相同的 Q8 点预测/Q9 十档问题之前添加共同表达框架和处理内容；篮子文本只在相应两臂出现。`budget_salience` 按篮子相关性重排已有趋势线/新闻，不增删公共项；离线构建器还对各臂的公共事实账本哈希作相等检查。表达框架和显示内容属于设计中的处理差异，焦点臂也改变事实顺序。
3. **真实 LLM 路径会读取处理，scripted 路径会静默忽略。** OpenAI 决策入口在 `sce-q8-q9-experience-v1` 下调用 `build_mechanism_messages`，并将臂标识、机制哈希、事实账本哈希写入回答元数据。相反，`--llm scripted` 的决策只读信号和收入档，既不读 `price_experience`，也不调用机制提示词；CLI 的机制/提示词配对拒绝检查目前只对 OpenAI 生效。因此用 scripted 模式携带 `--mechanism` 可以生成带机制观察的运行，却不会让回答受处理影响，不能用来验收处理效果。
4. **时间和真值边界有明确保护，也保留回顾性限制。** 配置仅接受 `A_historical_reconstruction`；运行时检查公共信号和新闻的发布日期不晚于环境 `as_of`，并检查体验包目标月及画像哈希。侧车生成器只读画像、CE 支出和环境公开价格信号，没有读 SCE Q8/Q9 真值或未来实际 CPI；机制环境也不注入前月调查回答。不过 CE 来源记录明确为“当前下载副本、非原始发布版本”和“仅回顾性代理、非 PIT 认证”；传入的 `public_release_date` 被记入来源元数据，但实现没有将其与每个目标月的 `as_of` 比较。故该篮子只支持 A 线回顾性处理对照，不能声称在历史截止日已可获得；模型自身知识截止未知的限制也仍在。

本次实现审查无阻塞性的“输入未接入”问题：使用 OpenAI 与 experience prompt 时，篮子/焦点状态进入构造后提示词；需避免把 scripted 结果误当作机制检验。尚未发起四臂 LLM 运行，提示构造检查不证明模型实际使用了篮子信息。

主 Agent 后续已按审查意见增加两项保护：规则式运行打印并持久记录只验接线；直接使用真实 provider 时，含机制的 Observation 若配了旧提示词会在 API 前拒绝。相关回归测试通过，仍没有真实机制行为结果。
