# 模型成本与群体评价补充（2026-10-08）

## 本次回答的问题

本页补充既有模型小试，零新增LLM/付费MCP调用，不改模型、P、E或运行配置。原实验见[SCE_MODEL_FOLLOWUP_20261008](../../SCE_MODEL_FOLLOWUP_20261008.md)。费用和群体评价独立复算，不能用没跑完模型的较低总花费判断性价比。

## 1. 哪个模型便宜

统一假设每份问卷2500输入token、150输出token。这接近此次问卷长度，但不同模型对同一文字的token数不同，实际输出长度也不同。单次费用为“输入token×输入价＋输出token×输出价”；价格单位为每百万token美元。

- **Llama3.1-8B：**输入$0.02、输出$0.04；每次$0.000056，1000次**$0.056**。[OpenRouter/DeepInfra价格](https://openrouter.ai/meta-llama/llama-3.1-8b-instruct)。
- **Llama3.3-70B：**输入$0.10、输出$0.32；每次$0.000298，1000次**$0.298**。[OpenRouter/DeepInfra Turbo价格](https://openrouter.ai/meta-llama/llama-3.3-70b-instruct)。
- **Qwen2.5-72B：**输入$0.36、输出$0.40；每次$0.000960，1000次**$0.960**。[OpenRouter/DeepInfra价格](https://openrouter.ai/qwen/qwen-2.5-72b-instruct)。
- **Llama3.1-70B：**输入$0.40、输出$0.40；每次$0.001060，1000次**$1.060**。[OpenRouter/DeepInfra Turbo价格](https://openrouter.ai/meta-llama/llama-3.1-70b-instruct)。
- **DeepSeek参考：**按10月5日本地账本配置的输入$0.30、输出$1.20估算，1000次**$0.930**。这是旧配置假设，不能冒充本次核实的当前官方价格或账单；实际回包只标`deepseek-flash`，未独立确认权重版本。

四个OpenRouter价格在本次调用中封存，并于10月8日与官方模型页指定provider重新核对。上述统一估算不含格式重试、HTTP错误、缓存优惠、购买额度手续费和税费，真实运行预算仍须预留。两个完整OpenRouter实验的实际API回包费用：Qwen40有效问卷$0.03831376；旧Llama40有效问卷$0.0414368（41次请求含一次重试），Qwen本次API回包费用约低7.5%。

**当前便宜程度不等于研究适用程度。** 8B最便宜，3.3-70B的基础价也明显低于旧70B；但前者只有1份、后者只有4份有效问卷，格式及服务问题尚未解决，不能宣称已有可用的便宜替代品。共同工作量下Qwen与旧配置DeepSeek成本接近，成本本身无需成为本轮选型主因。

## 2. Qwen个人误差到底更大还是更小

这里的“个人误差”是同一个真实画像对应的模型Q9派生均值与真人Q9派生均值之差的绝对值，再平均。真人和模型用同一冻结近似计分器；单位为百分点。

- **2021-05：**Qwen MAE **2.479**，DeepSeek **2.911**，旧Llama **2.421**。Qwen优于DeepSeek，略差于旧Llama。
- **2021-06：**Qwen MAE **3.544**，DeepSeek **2.965**，旧Llama **3.084**。Qwen比另外两者更差。

所以不能笼统说Qwen个人误差更小。每个人的画像未记录所有经历、信息接触和即时判断；给出人口属性也不等于能够还原那个人的一次回答。因此逐人误差是辅助诊断，不能单独作为社会模拟的成败标准，也不是毫无意义。

## 3. 改看总体和分组，结论如何

### 样本总体：中位数误差

先分别对模型和真人的个人Q9派生均值取中位数，再计算两者差距。共同有效样本5月18人、6月19人，均等权。结果如下：

- **5月：**DeepSeek **0.998**、旧Llama **0.375**、Qwen **0.668**个百分点。
- **6月：**DeepSeek **1.401**、旧Llama **2.538**、Qwen **3.318**个百分点。
- **两月误差等权平均：**DeepSeek **1.200**、旧Llama **1.456**、Qwen **1.993**个百分点。

因此改看总体，仍是Qwen5月改善、6月变差；本次两月平均更差。以上是该20人抽样的总体，不是全国SCE误差：尚未完整Core/Normal扩展、使用全国权重，也未与官方全国统计量完成同口径对照。

### 分组：年龄组中位数误差

用已有年龄组（40岁以下、40—60岁、60岁以上），分别算组内中位数误差，再按该组有效样本数加权。所有年龄组均有5—8人，5/6月覆盖全部18/19个共同有效样本；这里的加权是样本数量加权，不是官方调查权重。

- **5月：**DeepSeek **0.675**、旧Llama **0.501**、Qwen **0.481**个百分点。
- **6月：**DeepSeek **1.855**、旧Llama **2.586**、Qwen **2.985**个百分点。

分组仍未得到千问稳定更好的证据。具体组之间有差异，例如6月40—60岁组Qwen更接近，但其他年龄组较差；不能挑其中一个改善组作结论。教育、收入、数感、就业分组也已保存复算，只展示至少5个有效样本的组，其余报覆盖缺口。年龄组汇总是既有字段的探索诊断，不据此事后挑选未来主指标或模型。

### 分布：避免总体正确却“人人一个答案”

旧Llama5月总体中位数最接近，但两月回答的月内IQR都约0.036pp，真人约2.405/3.670pp。它不能据此被评为优秀微观重建。Qwen分散度改善，但水平和6月趋势仍有明显问题。分布距离（W1，越小越好）5月为DeepSeek2.178、旧Llama2.279、Qwen2.036；6月为2.405、2.927、3.093pp。

## 4. 随机性与下一步

本次用固定种子做10000次逐月配对重抽样，仅用于已封存回答的抽样诊断。Qwen减DeepSeek的总体中位数误差差值，其95%百分位区间5月为[-0.901, 0.192]、6月[-0.307, 2.412]pp，均跨零，小样本不足以稳定判定模型优劣。这不是LLM重新生成的随机性估计，也不是全国调查设计下的置信区间；相邻两月还使用了不同的人。

**两个月少，不能直接归因于P/E。** 当前还混合了画像抽样、模型生成、问卷理解、提示词及居民信息感知方式等因素。共同P/E能比较这次模型替换的结果，但不足以识别到底哪一环节导致偏差。

后续评价的建议顺序：

1. 总体：完整人口及适当权重下的月度指标误差，按登记的长窗口计算MAE，并同时看系统偏高/偏低与趋势。
2. 分组：预先固定年龄、教育、收入等分组，看各组中位数和组间差距；避免只拟合一个全国数。
3. 分布：月内IQR、分位数、分布距离，防止所有Agent给出同一种答案。
4. 逐人误差：保留辅助诊断，不要求合成Agent精确猜中某个真人的单次回答。

先统一格式纠错协议，再冻结同P/E下的重复生成与至少12个月模型对照。重复生成分离LLM波动，跨月实验检验阶段稳定性，人口规模先沿项目已有抽样损失评估决定；不因成本低就擅自扩大。P/E机制实验另设单项对照，不同时改模型、人口与环境。本轮未冻结新窗口/预算，也未新增调用。
