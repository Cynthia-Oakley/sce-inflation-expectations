# Core/Normal 开发任务与接力计划

2026-10-05。用户同意开始下一步：参考 ConsumerSim 的 Core/Normal，为 SCE 构建保留完整人口的低调用成本方案。当前属于 A 线历史重建开发，不改正式配置、不冻结预测线。

## 本轮目标

完整当月 P → 已有随机抽样 Core → 同人口组统计扩展 Normal → 全人口加权汇总。保留 Core 的联合 Q8/Q9 回答，不把每组人都变成一个均值，也不把所有人的十档概率先平均再计分。

## 实施顺序

1. 在 study 内新增 `core_normal.py`：按年龄×教育×粗就业建立回答分布；小格向其他相近格收缩，没有支持时明确回退；选样与扩展不读取 Normal 的真实回答。输出组支持、借用比例和人口覆盖。
2. 新增 `scripts/expand_sce_core_normal.py`：消费已结束的 Core 运行、同月完整人口和评价权重，输出统计扩展回答与确定性积分汇总。原模拟轨迹保留；Normal 明确标记统计生成。
3. 新增 `scripts/check_sce_core_normal.py`：用开发月真实回答作离线抽样/扩展诊断，检验统计层能否保留已知分布。它不是 LLM 实验；参数只作预先列出的敏感性检查，不据真实结果挑最佳种子或宣布模型效果。
4. 测试人口角色、联合回答保留、权重、无支持小格、无效 Core、固定种子和真值隔离；用已存规则式 Core 轨迹实际贯通。
5. 记录结果、路径、参数和局限，更新任务板，明确下一轮真实 LLM 的候选范围与待授权事项。

## 方法边界

- 300/500 是候选 LLM Core 人数；总人口仍是当月完整调查框 1,234/1,297 人。
- 第一版是有限回答分布的经验收缩/后分层适配，不宣称完整复刻 ConsumerSim 的模型或正式贝叶斯后验。
- 扩展利用 Core 当月回答和目标人口属性/权重；本版不使用当月 SCE 预期值校正水平。
- 组内借用 Core 的完整回答作为一个联合样本；单个 Normal 的结果是模拟填补，不能声称恢复其真实个人心理。
- 正式参数、规模和跨月记忆待后续验证。本版按月独立；B 线尚须单独提供截止前可得 P/权重合同。
- Kimi 10-03 待审文件只读，不提交或还原。新实现与生成产物独立保存。
- 本轮先离线，付费 LLM 为 0。此前 DeepSeek 启动被自动审批拒绝，明确的数据发送与预算授权仍待用户答复，不绕过拒绝。
