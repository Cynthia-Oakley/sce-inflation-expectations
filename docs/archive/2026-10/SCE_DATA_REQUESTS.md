# 学校数据库获取清单：SCE 项目

更新：2026-09-28。目的：补齐公开数据版本的历史新闻与时点证据。**SCE 本身免费公开，核心原文件已经取得；无需先购买人口库或搜索全部经济指标。**

同日补充：先按 [SocioVerse MCP 核查](SOCIOVERSE_MCP_AND_PMI.md) 验收平台的 FRED/BLS/NYT 历史接口。学校可先确认新闻库权限并取少量样例，完整批量获取范围按 MCP 实际缺口决定；不重复建设已可复用的数据管线。MCP 的观测月份截断仍需补充实际发布日期与历史版本验证。

2026-09-29 澄清：以下优先级指“需要用户协调学校资源的事项”。项目整体最优先的是 [T00 数据审查](../../SCE_DATA_AUDIT.md) 中的历史人口与核心环境；它们以公开来源取证为主，由 Agent 推进。学校新闻权限/少量样例可同步准备，不要求先全量取数。

## 第一优先级：可用于研究的美国历史新闻

建议先向学校确认 LSEG/Reuters、Factiva 或其他可用新闻库的实际订阅范围。LSEG 官方说明其新闻档案提供历史和 point-in-time 新闻，但学校是否有相应产品、导出与模型处理权限尚不清楚。[LSEG 产品说明](https://www.lseg.com/en/data-analytics/financial-news-services/machine-readable-news)

- **范围**：美国英文经济新闻；开发/正式研究拟用 2020–2024 年，最好向前覆盖 2017–2019 年以供人口基期和机制设计。另取 2025–2026 是扩展，无需一开始下载。
- **主题**：通胀、消费价格、食品、汽油/能源、租金/住房、工资/就业、FOMC 与货币政策、供应链与关税。最终检索式事先确定，不能依据某月 SCE 的升降反向筛新闻。
- **先拿样例**：一个普通月份和一个冲击月份，各导出约 20–50 篇，确认格式和时间元数据后再扩大。来源与筛选条件要一致。
- **优先字段**：稳定文章 ID、标题、原始来源、正文或可用摘要、首次发布时间与时区、更新时间、版本/更正标识、主题标签、URL、导出日期和完整检索式。
- **资料形式**：CSV/JSON/文本优于逐篇截图；保留原始导出说明。若只有 PDF，需要标题、来源、时间和正文可逐条关联。
- **需要问清的权限**：批量导出/文本研究、项目内部保存、提交第三方模型 API 处理、派生结果与原文再分发。数据库可阅读不自动意味着这些用途均被许可；取得学校实际条款即可，不必推测。

可向图书馆使用的需求描述：

> 我计划做一个学术比赛项目，模拟美国居民的通胀预期，需要 2020–2024 年美国经济新闻以及首次发布时间、更新版本、来源和文章 ID。希望先导出少量样例，随后按固定检索式批量获取。请问现有订阅是否支持这种学术文本分析、数据导出与模型 API 处理？如果不支持，是否有允许上述用途的研究版新闻档案？

本文件只是可复制的咨询草稿，未发送给任何人。

## 第二优先级：历史版本与发布日

- 宏观数据：CPI 总体/核心/食品/能源/住房、工资、失业率、利率、汽油价格。要保留 reference period、实际发布日期和当时版本；只导出一列最新修订值并不满足回测。
- 公开优先：BLS/EIA/Fed 官方历史发布、[ALFRED](https://alfred.stlouisfed.org/)。学校 Bloomberg/LSEG/Haver/CEIC 等仅在能补充缺口时使用，并确认具体系列与版本功能。
- SCE 历史公开微观文件/发布记录：重点寻找 2017–2019 年人口基期文件的可得性证据、2019 年末以前已公开的版本、后续实际更新日。当前文件里有历史年份，不代表其当前所有字段和修订当时已发布。
- 对于缺少历史 vintage 的资料，在清单里标记“仅最新版本”；不要补写虚构的发布日期。

## 第三优先级：额外人口及消费暴露

这些多数已有公共入口，不应成为学校数据库工作的主要负担。

1. [CE 分组支出表/微观数据](https://www.bls.gov/cex/pumd.htm)：食品、交通能源、住房支出，及收入、年龄、住房等分组。先分组表，后微观；保存调查年与发布年。
2. [ACS PUMS](https://www.census.gov/programs-surveys/acs/microdata.html)：人口和住房校准；选 household reference person 时核对其与 SCE household head 的口径。
3. [CPS](https://www.bls.gov/cps/data/public-use-file.htm)：就业结构更新的备选；官方月度失业率足以支持第一版环境。
4. [SIPP](https://www.census.gov/programs-surveys/sipp/data/datasets.html)：仅在需要更细资产、收入来源、家庭经济状态时取。文件标称年度、访谈年度、参考年度、发布年度必须分开。
5. GSS：仅在确定了明确的态度机制与变量映射后取；不为增加 persona 文字丰富度而强行加入。抽样对象和年份与 SCE 不同，不能直接连接为同一人的记录。

## 企业方向：顺带记录，暂不作为主线依赖

[Atlanta Fed BIE](https://www.atlantafed.org/research-and-data/surveys/business-inflation-expectations)调查企业未来单位成本；它与企业售价计划、居民预期总体通胀是不同变量。官方页面提供匿名微观数据申请入口，取得时间和条件待机构答复。需要行业、规模、成本暴露、问卷版本、单位成本分布、权重及发布时间。尚未替用户提交申请。

## 收到数据时保留什么

每个文件配一个说明：来源、检索式/系列代码、日期范围、时区、导出时间、版本定义、字段说明、使用条款、是否允许第三方模型处理。受限资料放 `data/restricted/`；公开原始资料放 `data/raw/`。两处均被 Git 忽略，仓库保留清单、处理脚本和允许分享的结果。

如果学校新闻库暂时拿不到，最小项目仍可用官方价格/就业发布及 FOMC 文本推进；新闻增量效果作为扩展实验，而不是报名的前置条件。
