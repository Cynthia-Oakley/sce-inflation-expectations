# 两份指数候选清单：分类、分布与生成机制

核查日：2026-09-27。以下数量由 `../../指标跟踪/global_index_candidates(1).csv` 和 `../../指标跟踪/global_economic_index_candidates(1).csv` 逐行重算；两份旧报告用于理解原筛选规则。**551 是候选记录数，不是去重后的独立指数数**；VIX、Ipsos CCI 等可能跨表或以不同名称出现。`source_agent` / `source_file` 说明资料经过多份调研整合，不能仅由文件确认每一条分类是否由师兄本人手工完成。

## 原清单实际按什么分

- 非经济表（`IDX-`，180 条）：先按 `broad_category` 分 18 个主题，再用 `tier` 区分常规重复发布指数、类指数数据源、待核查边界、纯经济边界、低频机构指数；`selection_status` 给出纳入、低频纳入、待复核或排除。筛选重视全球/跨国覆盖、重复更新、官方来源/数据入口，并有意排除纯金融、价格和宏观经济序列。依据：`NONE_GLOBAL_ECONOMIC_INDEX_REPORT(1).md` 第一、五节。
- 经济表（`ECO-`，371 条）：按 `category` 分 33 个主题，用 `indicator_type` 标注 `recurring_statistic`、`official_index`、`market_benchmark`、`forecast`、`survey`、`data_platform`、`prediction_market`；`status` 是纳入或待复核。筛选强调经济主题、全球/跨国或有全球影响力的例外、可核验的周期更新和至少一个公开入口。依据：`PURE_GLOBAL_ECONOMIC_INDEX_REPORT(1).md` 第一节。
- 两表的“纳入”是**资料清单筛选**，不是“可以通过 Agent 问卷重建”或“适合本次比赛”的评分。`indicator_type` 也不等于生成机制：例如问卷形成的 OECD 企业信心指数被标为 `official_index`，不一定标为 `survey`。

## 对本项目更有用的第二层分类（新提出，尚未逐条标注）

1. **回答聚合**：人/企业/专家接收信息，回答固定问题，再加权成指数。例：`ECO-0078` ACCA–IMA 信心、`ECO-0086` OECD 企业信心。最贴近 ConsumerSim；首要门槛是问卷、精确真值、权重和发布日期。
2. **成交或报价聚合**：Agent 形成订单/报价，交易机制形成价格，再按固定公式变成指数。例：`ECO-0315` VIX、`ECO-0334` CME CF Bitcoin Reference Rate、`ECO-0181` FAO Sugar Price Index。需要区分“用已知成交机械重算指数”和“让 Agent 内生形成成交/报价”；只有后者检验市场机制。
3. **混合输入复合**：部分输入来自市场交易，部分来自新闻、关注度等外部来源。例：`ECO-0340` Crypto Fear & Greed。即使模拟价格和成交量，仍不能声称完整指数内生生成。
4. **文本/事件/物理/行政统计**：文本计数、事件数据库、卫星/气候测量或官方统计；可能适合事件生成或信息传播研究，但不宜直接套用问卷 Agent。

## 市场型候选的相对工作量（概念核查，尚非选题决定）

- **`ECO-0334` CME CF Bitcoin Reference Rate：最窄的纯成交基准。** CME 定义为一个 BTC/USD 现货市场、一天一小时成交，分为 12 个五分钟区间，每区间取成交量加权中位价，再等权平均。可先以单市场的规则式/少量 LLM Agent 和撮合器验证价格生成，再加交易所维度。它是**参考价格基准**，若教授严格要求“指数”，须确认是否接受；清单标为 `review`、完整数据部分付费，未通过数据门槛。来源：[CME 官方方法](https://www.cmegroup.com/articles/faqs/cme-cf-cryptocurrency-benchmarks-faq.hideRightRail.hideHeader.hideSubnav.hideFooter.html?hideFooter=y&hideHeader=y)。
- **`ECO-0181` FAO Sugar Price Index：单商品价格指数。** FAO 公开月度真值及历史 CSV；交易来源是国际糖价，模拟可限制为生产者/贸易商/买家/做市商围绕糖价形成报价，比 VIX 的多行权价期权市场窄。准确重现官方值仍需核对现行原始报价、基期和许可，不能用一个模拟现货价冒充官方糖指数。来源：[FAO 官方指数与数据](https://www.fao.org/worldfoodsituation/foodpricesindex)。
- **`ECO-0340` Crypto Fear & Greed：较易做混合机制，但不完全内生。** 官方列出波动率 25%、量价动量 25%、社交媒体 15%、市占率 10%、搜索趋势 10%，问卷 15% 当前暂停；虽有历史 API，组成项的数据和归一化仍需核查。来源：[Alternative.me 官方方法与 API](https://alternative.me/crypto/fear-and-greed-index/)。
- **`ECO-0315` VIX：高复杂度。** 官方使用两个期限、多行权价 SPX/SPXW 期权的报价和利率；只生成标普 500 现货价格或已实现波动率无法计算真实 VIX。公开日度 VIX 真值易取，完整历史期权计算输入另有数据产品。来源：[Cboe 官方方法](https://cdn.cboe.com/api/global/us_indices/governance/Volatility_Index_Methodology_Cboe_Volatility_Index.pdf)、[历史值](https://www.cboe.com/tradable_products/vix/vix_historical_data)。

## 选题时要分开的三个门槛

1. **指标资格**：确实在清单内、目标是单一可命名序列、导师接受其口径。
2. **数据资格**：连续真实值、构成方法、原始输入和公布时点可审计；许可允许比赛研究包复现。
3. **机制资格**：Agent 的行动确实参与形成被比较的量；评测不能只靠把真实当期价格喂回模拟。

目前最稳妥的比赛路线仍是先审计回答聚合型指标；市场型路线值得保留作对照和未来金融交易 Agent 平台选题。市场型并非一定要重建“整个金融市场”：可以限制为一个资产、一个撮合机制和明示的外生环境，但对真实指数的解释范围也相应受限。
