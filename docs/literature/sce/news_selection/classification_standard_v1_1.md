# 新闻分类标准 v1.1：审核后的澄清

日期：2026-10-11。范围：美国普通居民对未来12个月总体物价的判断。状态：候选标准，未改生产筛选器；由两个开发月形成，独立月份尚未验收。[首审标准v1](rubric_v1.md)保留，不追改首审标签。

## 一、四种处理方式

1. **核心候选消息（include）**：实际价格变化、具体商品供给/成本变化、美联储行动，或有说话者归属的物价原因/持续性判断。适合存入核心价格新闻库，但不代表每个家庭都会看到。
2. **经济背景（context_only）**：就业、收入、救济、经济困难、产业创新等真实背景；摘要没有足够的价格联系或新的物价机制。允许存入背景库，按研究需要使用，不能当作没有价值而全部删除。
3. **需查正文（needs_fulltext）**：主议题有明确的潜在价格联系，但摘要不足以判断机制、时间或对象；进入待核队列，不自动给模拟居民。
4. **本研究新闻池排除（exclude）**：无关词面匹配、泛化政治口号等没有具体经济信息的内容，或者外国政策未显示美国联系。原文仍保留在资料层，不等于它在所有研究问题中都无用。

不需要新闻同时提供消费者价格数字：**明确的汽车减产/增产可以是供给消息**。但不能替原文推导“必然涨价/降价”。

## 二、这次审核后必须明确的六个边界

- **供应数量不等于科技创新。**福特减产、GM增产有具体生产进展；芯片初创融资、成立游说联盟没有证明一年内新增产能。后两者先作背景，若要升级，再查建设/投产证据。
- **工资和福利变化不自动等于通胀。**青少年工资、承包商最低工资、取消救济可作收入/劳动背景；摘要明确讨论工资引发价格上涨时，才属于直接的物价解释。这里是保守的核心消息门槛，不否定工资和财政的经济学作用。
- **明确的背景无需都追正文。**芯片创新的主内容已经清楚，可标背景；厨房装修困难、风电障碍、政府与Fed关于恢复的分歧，若要理解其价格及一年期意义，现摘要仍不足，本轮列三篇待核。
- **同事件不等于重复文章。**同日报道与直播摘述可作重复候选；Fed声明、政策评论、分歧讨论可以互补。汽油抢购与管线恢复也是互补的进展，不能仅因共同主题全部删成一篇。
- **相似词义须分开。**商铺租金不是住宅房租；家庭食品匮乏不是市场食品供给短缺；原油/钢铁批发价不是家庭支付价；通胀放缓不是价格下降。没有原文支持时，不生成方向标签或数值推断。
- **地区与期限要保留。**东南部加油站、纽约商铺、联邦承包商等局部消息不能泛化为所有美国居民。欧洲央行消息没有明示美国联系时，当前美国价格新闻池排除；国际能源、贸易与全球商品供给有明确对象/传导时可纳入，不能把所有国外消息一律排除。

## 三、内容标签与事实归属

沿用v1八种主题，允许多选；主类唯一，避免把多标签比例相加当新闻总数。事实、机构行动、预测、评论分别标注；不要把“某人认为”写成“事实证明”。

方向需要区分四件事：价格水平、通胀率、供给数量、政策利率。最终审核文件中的 `explicit_price_direction` 与 `direction_note` 仅作文字审核，不作为回归因子或通胀数值。本轮没有完整制作按上述四对象拆开的数值数据集，不能称它已经可用于新闻基线。

## 四、筛选流程与呈现

宽泛栏目/词组召回 → 标题摘要语义分类 → 模糊项查正文/人工复核 → 按事件与日期整理 → 构造家庭视图。

关键词只找候选，必须明确完整词、合法词形及语境；词频和A1版面可作排序信息，不是自动纳入理由。也不能只凭句向量相似度作最终判定。每个入选/排除决定保留原文证据与理由；无支持就填未知。

公共库保存多种解释和原始来源；家庭视图只呈现实际研究假设下可能接触的部分，保留来源、日期、对象和限定。同一事实不要改写为统一专家结论。报道频度可另记，但当前筛选后的条数不能代表真实媒体曝光强度；家庭曝光数量/信任分配也没有被本轮测得。

不能人为使涨价和降价消息各半、不能按哪个方向更拟合SCE来挑新闻。不要求所有核心消息都写明未来一年：短期供应冲击也可能影响一年期判断，但其后续推断属于居民行为，不能由分类器代答。

## 五、时间、版本与后续验收

时间门由程序根据已保存的发布时间与实验截止点执行；LLM不能从URL日期或自己的知识补造历史版本。本文60条日期均不晚于原截止日，但精确发布时刻/当时摘要字节版本仍未核验，全部保留 `unverified_archive_snapshot`。语义合格不等于可用于严格预测路线B。

这60条来自旧筛选后的开发输入：只检查了选入质量，没检查漏选；两个月有9篇重复，更不是60篇独立文章。后续从同截止范围内未入选文章抽样查漏，使用独立月份检查新分类器，并对正文待核项单独验收。模型之间的19/20一致不是相对于人类真值的准确率。

本轮以短摘要判断适切性，没有验证新闻曝光、认知反应或拟合改善。新规则必须另存版本，所有对照使用同一新闻库；只修新闻质量时，不同时加入信心/消费篮子新机制，以便解释改变来自哪里。
