# 新闻筛选试验：先扩候选，再判断内容

日期：2026-10-11。目的：检查v1.2入口与DeepSeek打标是否能补充合理新闻，以及会引入多少无关/次要背景。**没有运行新的SCE模拟，尚未证明预测误差改善。**

## 1. 结论先说

**组合方案能继续做，但不能把扩大后的候选全部送给居民。**两个开发窗口，新入口留下679、644篇候选，分别占可读文章的12.1%、12.1%；9月独立检查是422篇，占10.7%。公共库的后续筛选空间足够，不必在关键词阶段就截到30篇。

**旧30篇主体仍然相关，改进的价值主要是补漏和改善覆盖。**同一套新标准下，DeepSeek将5月旧列表的28篇、6月26篇、9月26篇列为主要候选。新增材料补到家庭储蓄消费、汽车供给与购车优惠、住房保险、学生债务和财政政策等。但扩大的经济栏目也带入许多公司盈利、上市、收购以及无实质经济内容的文章，需要内容打标后再筛。

**打标仍有需要统一的边界。**六个定向复核案例包括：通用汽车实际增产被标成次要背景；英国央行报道的keep标签与“非美国居民处境”的理由相冲突；英国国内燃油短缺与全球能源消息边界模糊。部分消费电子价格信息也容易因公司名称被归为次要背景。原标签保留，复核意见另存，不冒充人类金标准。

## 2. 实验怎样做

- 沿用两个旧开发实验的日期级窗口：2021-04至05-12、2021-05至06-10。旧新闻快照和旧研究配置原样保留。这是旧UTC日期字段比较，不是新设精确纽约时点协议。
- 加入2021-09整月，作为未参与此前新闻诊断的独立方法检查。它不对应新增Simulation/as_of，也与开发窗口长度不同，不直接比较原始数量。
- 各窗口分成互斥五层：旧入选30篇全部；仅新规则找到30篇；两规则都找到但旧未入选30篇；仅旧规则找到15篇；两规则均未找到15篇。非全量层使用固定种子的简单随机抽样。
- 合计360条窗口记录、347篇去重文章。跨窗口同一文本只打标一次，分类输入不含月份、旧规则结果、抽样层、SCE真值、人口或模拟结果。
- 使用DeepSeek官方API的`deepseek-flash`，temperature=0、关闭thinking、8篇一批、最多2400输出token。temperature=0用于固定分类流程，没有改Simulation的temperature=0.5。API回传模型名均为`deepseek-flash`；V4.1-Flash对应关系来自[官方当前说明](https://api-docs.deepseek.com/quick_start/pricing/)，不是响应中提供了独立checkpoint日期。
- 用户明确授权本批公开新闻、$0.25上限、不自动重试。实际共44批，没有重复调用。历史文本vintage仍为`unverified_archive_snapshot`，语义标签不提升历史可得性结论。

## 3. 观察到的漏斗

为避免把抽样估计混成实际计数，分两层报告。

### 确定性计数

- **5月窗口：**日期内6,186条文档 → 5,616篇有文字的去重文章 → 旧规则385篇候选／新规则679篇候选；旧最终输入30篇。
- **6月窗口：**日期内5,735条文档 → 5,311篇文章 → 旧394篇／新644篇；旧最终输入30篇。
- **9月整月：**4,482条文档 → 3,927篇文章 → 旧277篇／新422篇；旧规则在该月选30篇供方法对照，不代表曾运行9月模拟。

新旧候选是两条并行分支，不是385篇再筛成679篇。新规则保留各旧30篇中的28篇。它去掉书籍发货、食品过敏法、诉讼中的waged等明确词面误入；9月也漏掉含单数`home price`的加州住房内容，证明仍需检查遗漏。

### 模型打标与抽样估计

347篇独立样本得到159主要候选、65次要背景、122排除、1待查。这个样本故意加大旧入选与规则差异检查，**不能直接拿159/347当全库保留率**。

按各抽样层的实际大小加权，新候选池的“主要候选＋次要背景”建议比例约为5月77%、6月82%、9月68%；其中主要候选约37%、34%、35%。这些是模型建议的抽样估计，背景仍需控制份额；不是人类分类准确率，也不是SCE预测性能。不要据此强制固定篇数、主题配额或涨跌比例。

两规则均未找到的每月样本只有15篇，仍漏材料的估计很不稳定，不报告全库召回率。9月抽样发现学校餐食短缺未被新词典找到；词典对象覆盖和常见单复数形式需要继续检查。

## 4. 格式错误、成本和复核

- 首批因引用超过12词停下；第22批因原样回显输入字段停下。保留v1/v2记录，分别在v2/v3继续未调用批次，没有重发已调用批次。
- 对22条长引用，只在核实原始长引用连续出自同篇原文后截取前12词；对2条多余回显，只删除与输入完全相同的标题/摘要等字段。没有修改ID、分类、主题、地区、理由或原新闻；原回包和逐项处理记录留本地。
- 347篇最终标签均从44份原始响应重新校验：ID、枚举、证据连续性和唯一性通过。机器格式通过不等于语义正确；[六例定向复核](selection_trial_targeted_review_20261011.json)单列待调整点。
- API返回累计74,258输入token、28,878输出token；按高峰无缓存价格保守估计$0.056931。按本次周日空闲时段和返回缓存token计算约$0.025229。都是token/公开费率估计，不是账户账单，未超过$0.25上限。费率依据：[DeepSeek官方价目](https://api-docs.deepseek.com/quick_start/pricing/)，2026-10-11核查。
- 8项针对词边界、价格表达、字段隔离、跨文章引用和格式处理的测试通过。原始新闻、旧选择代码、旧E快照和15份用户/Kimi待审文件哈希未变。

## 5. 下一步只作少量明确修正

1. 补常见单复数及食品供给对象：例如`home price`、学校餐食/食堂供给。不能只扩宽所有词，继续保留误入检查。
2. 统一打标边界：生产与零售价格信息按实质内容判断；外国地方经济消息与全球能源贸易分开，标签与理由必须一致。
3. 在新的候选版本中整理同一事件的重复与进展，形成约50篇公共库，再检查其生活价格、供给、就业消费和政策覆盖。50是待检验工程预算，不是每户阅读量。
4. 下一次检查另选未参与调整的月份；9月已经被看过，今后用于改进依据，不能继续称“未看过的测试月”。
5. 公共库通过检查后，再制作家庭视图并讨论Simulation。当前新闻标签改善不能解释已有总体偏差，更不能当作拟合改善结果。

本轮不改生产规则或正式E，也不再扩大付费调用。新方案先作为可检查候选保留。
