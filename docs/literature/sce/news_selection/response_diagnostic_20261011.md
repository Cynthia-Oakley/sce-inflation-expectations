# 新闻实验之后：回答为何集中，下一步检验什么

核查日：2026-10-11。已完成零 API 复查和下一轮输入原型；未产生新模拟或新费用。当前新闻库、50/50分配、旧配置、全部原始回答均保留。

## 1. 现在最值得检验的是“怎样从事实形成一年期看法”

旧实验已经让不同家庭收到不同新闻，但所有人仍拿到相同的官方价格、就业和12个月历史序列。模型经常把这些信息解释成“当前通胀较高，但基数效应和供应问题会缓解”，然后报一个略低于当前CPI的数字。

这提供了一个明确的下一步：保持P/E相同，只改变居民原有的“涨价会持续多久”的看法，看看模型是否能形成不同回答。它目前是可检验假说，不是已找出的根本原因；不能把理由文字当成模型内部注意力、训练记忆或因果证据。

## 2. 从原始回答确认了什么

范围：5月48人、6月48人，每人共享/随机/相关加权三种新闻条件，共288份回答。每月合计144份是同48人的三种条件，不能算144名独立受访者。

**第一，集中发生在计分之前。**5月有93/144份直接回答3.5%；6月有98/144份直接回答4.5%。实际输入的最新CPI同比是4.2%和5.0%。问卷输出模板用数值占位符，没有给3.5%或4.5%的示例答案。两个月的点预测都集中在比当前CPI略低的位置，但仅凭这种对应不能识别锚定因果。

**第二，模型普遍给很多可能性留了概率。**5月模型填非零概率的区间数中位数为9，6月为10；同批有效真人均为4。288份模型回答全部给了负通胀区间一定概率，两月通缩概率中位数分别15%和11%；真人分别31/46、33/48人把通缩概率填为0，两月中位数均为0。5月两份真人概率无效，仅在需要合法概率的比较中剔除。

这不等于“任何通缩概率都不合理”，也不能把所有真人都说成不相信通缩。当前可确认的是回答分布的形状差异。宽广的个人概率分布，与不同居民的预期中心很相近，可以同时存在；前者是个人不确定性，后者是人群分歧。

**第三，缓解叙述很常见。**5月105/144、6月82/144份理由使用了`base effect(s)`；所有实际送入的新闻文字均未直接出现这个词组。5月提到该词组的回答中位数3.5%，未提到的4.5%；6月两类均4.5%。这是共同出现关系，且人口特征也可能同时影响用词和回答。

价格历史本身可能支持基数效应的推断；新闻也可能换一种说法。因此，“没有这个词组”不表示完全没有相关信息，更不能据此断定模型作弊、幻觉或记住了未来。通缩的相关词组在这288份短理由中均未出现，也不能证明模型没考虑尾部风险——它只被要求给一两句理由。

**第四，不能把Q8与Q9之间的差直接当作故障。**逐份点预测减去同计分器得到的个人密度均值，中位差为：模型5月0.55、6月0.45个百分点；同批有效真人为0.17、0.77个百分点。6月真人差距反而更大。官方研究也解释，点预测可能代表不同人的不同中心概念，不能强行设为概率均值。[纽约联储的问卷测量说明](https://www.newyorkfed.org/newsevents/speeches/2014/mca140624)

较宽的负侧概率会参与决定密度均值，但这里没有做“去掉负侧概率”的反事实，不能声称它解释了多少总体误差。正式Q9仍沿用冻结计分器，不截断通缩、不事后拉齐Q8。

## 3. 输入和问卷核查

- 288份问卷部分逐字相同，都明确下一年/未来12个月。未发现把一年期问题写成下个月问题；当前同比、环比在实际文本中分别标为相较上年和该月变化，没有发现两者互换。本轮核查的是发送内容及一致性，没有重新转录全部BLS原表。
- 原提示已经允许每档0—100，并要求合计100，没有要求十档都大于0。遍布概率不是程序硬性要求。
- 原提示压缩了官方Q8“先选通胀或通缩，再报幅度”的结构；Q9用负数区间表达通缩；Q8/Q9在一次JSON回复中产生。它们是测量形式差异，尚未识别各自影响，不应悄悄改完后把全部效果算在信念机制上。[官方问卷第7—8页](https://www.newyorkfed.org/medialibrary/interactives/sce/sce/downloads/data/frbny-sce-survey-core-module-public-questionnaire.pdf)
- 发现一处表达需纠正：全国CPI `shelter` 被写成`rent and shelter`。该指数包含业主等值租金等住房成本，不等于某个租户的租金。新原型各组统一改为“全国住房成本指数，不是你自己的租金”，数字不变，旧运行原样保留。[BLS口径](https://www.bls.gov/cpi/factsheets/owners-equivalent-rent-and-rent.htm)

目前更合理的判断是：**输入给了较完整的统计信息，但没有识别每位居民会怎样解释未来。模型可能用了一套较相似的解释习惯；概率回答的表达习惯又进一步影响Q9。**两者需要分开检验。

## 4. 为什么选持续性看法作为下一候选

纽约联储的SCE专题研究直接调查过居民是否认为价格大涨后会回落，并发现这种看法与中长期通缩预期有关。它支持研究“同样涨价，有人认为暂时、有人认为持续”，但论文主要涉及中长期预期，不能直接推成2021年一年期的分配规则或因果系数。[Staff Report 1037，2023年修订版](https://www.newyorkfed.org/medialibrary/media/research/staff_reports/sr1037.pdf)

2023年的另一份SCE专题也发现居民用供应链和货币政策等解释未来通胀变化。这说明形成预期不仅需要价格数值，也涉及对原因和持续性的判断；它不提供每位2021年居民的信念。[纽约联储专题](https://libertystreeteconomics.newyorkfed.org/2023/08/consumers-perspectives-on-the-recent-movements-in-inflation-expectations/)

现有公开专题资料缺少可直接匹配本项目P的联合微观数据，所以先做三种**同一个人的假设情景**，不按年龄、收入或教育武断分配。原来的CE价格体验路线保留；下一轮不同时改新闻数量、篮子、心理属性和问卷。

1. **不加看法：**保留原来的画像和全部信息，作为参照。
2. **原本认为会缓解：**接触当前消息前，倾向于认为日常商品的快速涨价会在下一年放缓；信息可以改变该看法。
3. **原本认为会持续：**接触当前消息前，倾向于认为快速涨价会延续至下一年；信息同样可以改变该看法。

两种新增情景都说明：这是原有印象，不是已知未来；涨幅下降不等于价格回到旧水平。两组只改同一句话中的持续性内容，其余提示一致。不指定预期高低数字、不强制消除负概率、不输入真人通胀答案。

主要比较第3和第2组，它们的提示结构相同；第1组只是额外参照，因为是否加一段文字本身也可能影响回答。即使两组方向符合设定，也只能通过“模型能响应这种条件”的第一关，不能证明机制贴近真人，更不能挑选更接近SCE的一组当全国人口。

完整英文段落、月份登记与判据见[下一轮准备说明](persistence_probe_plan_20261011.md)。
