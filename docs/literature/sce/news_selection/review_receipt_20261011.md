# 现有新闻审核：哪些适合居民一年期物价判断？

2026-10-11；水上挽月 / SCE。研究辅助审核已完成，没有改变旧新闻、截止点、运行配置或真实模拟结果。

## 1. 审核了什么？

2021年5、6月300人主实验实际收到的NYT新闻，各30条。60个“文章—目标月”记录，对应51篇独立文章，9篇在两月复用。实际保存的新闻日期范围分别为4月2日—5月12日、5月2日—6月10日；不要称它们是完整自然月新闻或真实个人曝光记录。

读取两个已保存的 environment_effective.json，核对与上轮来源哈希一致；另逐条检查600份已保存请求及其prompt哈希，确认每个月的30个标题/摘要全部实际进入该月300份请求。没有向审核者提供画像、真人通胀答案或模拟结果，没有新增API。两名Luna分别首审；第三名对每月随机10篇盲复审；主Agent先独立读完60条保存初判，后裁决。原标签保留。模型助审参考不等于真人专家金标准。

## 2. 结果

最终候选：**26条核心价格消息、26条经济背景、3条需要正文、5条在当前美国价格新闻池排除。**5月分别15/12/1/2；6月11/14/2/3。

核心消息的单一主类为：供给/成本14条、物价持续性及解释5条、货币政策3条、价格报道4条。这是按60个文章月记录统计，重复文章也按每月出现计数；不是新闻总体比例或人口曝光概率。

**新闻库的问题超出了两处关键词误中。**就业、福利、产业创新等有用背景与核心价格消息混在一起；芯片题材和政策解释较多，直接对应家庭日常购买的消息较少。核心价格报道主要是汽车售价与CPI，汽油消息则在供给类。新闻中没有清楚的食品、日用品、服装、水电燃气或住宅租金变化报道；这只指当前新闻子集，不代表整套E缺少相关统计指标。

**当前每月300人确实收到同一批30条完整新闻。**这还不是按家庭接触构造的信息视图。分类质量、每个家庭会看到什么、看到后如何理解，须分开研究；本轮没有验证同一新闻包导致了回答同质化。

## 3. 五条排除与三条待核

排除：书籍因作者指控停止发货；食品过敏原标识法；纽约市长竞选攻防仅顺带提复苏；记者诉讼（waged误中wage）；欧洲央行政策未明示美国联系。最后一条是研究对象范围判断，不是说所有外国或政治新闻都无用。

待查正文：厨房装修因供应链/劳动短缺而更复杂；拜登和Fed称经济恢复在轨道上的分歧；风电发展遇到的障碍。分别须核查费用/延期和家庭可得性、具体物价判断、成本/投产时间与一年期关系。摘要不足，本轮没有声称已经读过正文或找到其缺失证据。

## 4. 分歧告诉我们什么？

20篇盲复审的决定与首审一致19篇；分歧是纽约竞选报道应为背景还是排除。它衡量同模型、同标准下的审核一致性，不能写成95%分类准确率。主Agent最终改了首审的6个决定，并保留理由。

最重要的澄清：GM明确增产可以是核心供给进展，不需要报价；芯片创新与产业游说没有证明实际增产，先作背景；同一篇创新报道跨两月应保持同一语义处理。最低工资/青少年工资没有明确价格联系时先作背景，工资引发通胀的明确讨论则纳入。审核方向不是只收涨价消息，GM供给缓解也保留。

两组重点疑似重复：5月7日芯片创新报道与其摘要条目（两月均有）；5月7日就业救济争论与其摘要条目（5月）。Fed三篇同日文章及汽油抢购/管线重启是互补信息，不能仅因共同事件当重复删除。本轮没有实质合并，报道频度也没有被解释成真实曝光强度。

## 5. 方法与效用边界

推荐“宽泛召回—语义分类—争议复核—事件整理—家庭视图”。[v1.1标准](classification_standard_v1_1.md)与[未来LLM提示词](llm_label_prompt_v1_1.md)可供下一步使用；DeepSeek尚未调用或做分类质量比较，其他工具也未接入。

既有经济研究支持居民有限注意、新闻选择的不对称，以及居民对供应链/政策的解释：[Fed有限注意](https://www.federalreserve.gov/econresdata/notes/feds-notes/2016/limited-attention-and-inflation-expectations-of-households-20161019.html)、[SF Fed新闻选择](https://www.frbsf.org/research-and-insights/publications/working-papers/2024/10/news-selection-and-household-inflation-expectations/)（该文当前核读摘要）、[NY Fed原因解释调查](https://libertystreeteconomics.newyorkfed.org/2023/08/consumers-perspectives-on-the-recent-movements-in-inflation-expectations/)。它们不提供本项目每人该看几条、信任系数是多少或哪组筛选必然降低误差的参数。

发布日期层面60条均不晚于原月中截止日；但精确时间和当时摘要的原始版本尚未核验，60条仍标 unverified_archive_snapshot，不能自动进入严格路线B。不能从URL年月日推造发布时间。当前只审核已有入选新闻，漏选尚未检查；也没证明新闻质量问题导致了整体模拟误差。

## 6. 下一步与准确路径

1. 核查三篇待定正文，以及两组重复候选；保留内容互补和来源分歧。
2. 从相同截止范围内未入选新闻抽样查漏，特别关注日常价格、能源/住房政策与供给新进展；随后用独立月份验收分类标准。
3. 用户/领域研究者确认参考标签后，再比较DeepSeek语义分类与旧关键词的错误类型和成本。任何真实付费调用另留运行卡；本轮仅形成候选提示词。
4. 新闻质量修正单独版本化；全部对照采用相同公共库，再检验家庭视图。不能同时改变信心/篮子机制后把结果归因于筛选。
