# NYT 原始库存与未入选新闻检查

核查日：2026-10-11。目的：确认本地是否还保留筛选前的数据，并判断先改筛选是否有现实基础。结果仅来自本地文件；本轮没有读取密钥、调用 NYT API 或运行新的模拟。

## 1. 先说结论

**原始库存保留着，而且足够支持我们先改筛选。**本地有2019-12至2026-09连续82个月的API返回，340,252条文档元数据。其中310,987条的类型是文章，其余包括多媒体、互动页面等。82份月文件约1.09 GB；文件哈希、文档数和API返回的 `meta.hits` 都与本地记录一致。这里的“完整”指保存了这些API返回，不是证明包含NYT网站上的所有内容。

**每月30条只是送进旧实验的选择结果。**没有单独维护一个“垃圾箱”，但未入选文章仍在原始月JSON里，可以根据文章链接/ID和选择记录重新区分。两个开发月原来收到的标题、摘要、事件ID和顺序已完整离线复算一致。

**两种漏选渠道都存在。**关键词未覆盖某些表达；同时，已被规则发现的报道还会因数量预算而落选。未入选库存里确实有经济恢复、家庭支出、价格和供给方面的材料。因此暂时不切换新闻源是合理的。我们尚未比较NYT与其他媒体的总体覆盖，也不能把现有模拟偏差归因于新闻筛选。

## 3. 旧筛选怎样把库存压到30条

月初筛大致经过以下步骤：

1. 只考虑类型为文章的记录，按链接去重。
2. 在标题、摘要和snippet中找关键词，同时检查是否属于印刷版A1头版。
3. 优先保留“头版＋强关键词”，这层不封顶；其余先选命中强关键词的文章，再考虑一般经济背景头版和其他头版。
4. 后三层填到30条。命中不同关键词更多的文章优先；数量相同时，更新的报道优先。

在已保存台账的15个月内，旧规则发现4,376条去重候选，但只选450条。候选并不等于已经确认的经济相关新闻。164条来自“头版＋强关键词”，另286条来自其他版面的强关键词报道。一般背景头版和普通头版没有进入这15个月的台账，因为前两层已经占满名额。

构建两个开发月的E时，还会把上月已选30条和本月截止日前已选30条合并，再用同类排序压缩。**因此一篇报道可以先通过初筛，再在合并时被挤掉。**原代码及其参数本轮没有修改。

代码证据：`scripts/build_nyt_events.py:171`起的分类、`:209`起的月筛选；`scripts/build_sce_environment_v2.py:91`起的合并、`:154`起的截止前筛选、`:436`起的实际接入。另见扩展入口 `scripts/extend_sce_environment_sources.py` 和 `scripts/build_sce_available_environment.py`。

## 4. 两个开发月实际有多少未入选材料

以下沿用旧实验日期级截止，不改变研究窗口，也不把UTC日期过滤冒称精确纽约时点过滤。

- **2021-05目标月：**2021-04档案与2021-05截至5月12日的记录共6,186条。570条不是文章；5,231条未被原关键词/头版规则召回；325条在月初筛预算中落选，30条在两月合并时落选；最终30条进入模型。
- **2021-06目标月：**2021-05档案与2021-06截至6月10日的记录共5,735条。424条不是文章；4,917条未被原规则召回；334条在月初筛预算中落选，30条在合并时落选；最终30条进入模型。

这些只是程序步骤计数。“未入选5,231条”不等于“漏了5,231条有用新闻”：其中很多是体育、文艺、个人故事等正常应排除的内容。

## 5. 抽查了什么，发现了什么

每个目标月抽60条，每类随机20条：已被旧规则发现但因预算落选；规则未发现、但由商业栏目或家庭消费词辅助找出的文章；其余规则未发现的文章。固定种子为42＋目标月。商业/家庭词层有意加大检查力度，**不能用此样本比例估计全库漏选率**。

两名GPT-6 Luna分别审核一月，仅看到新闻元数据，没有看到真人SCE答案、Agent回答或拟合表现。按用户最新偏好，就业、消费、政策等经济背景不必写明通胀传导才能作为候选。

120篇独立文章中，模型建议37篇作为经济相关候选、81篇排除、2篇暂不确定。37篇里，17篇是在月预算中落选，20篇是原规则未召回。主Agent检查了120条的ID、证据摘录和处理步骤，并复核重要候选及7个定向例子；**没有将全120篇独立重标，也没有把模型建议当作人类金标准**。

更有价值的发现是具体文章：

- **肉类加工厂停产：**2021-06抽查的`202106_35`报道美国JBS牛肉工厂停产，部分猪肉和禽肉工厂也受影响。它没有命中旧词表；这是我们需要的食品供给消息，不代表已经测得食品涨价。
- **管道停运与汽油价格：**`202106_30`摘要明确转述分析师判断，长时间停运可能推高美国东海岸加油价格。旧规则没有识别“prices at the pump”这种表达。这是风险判断，不能改写为汽油已经涨价；同一管道事件的其他报道已在旧输入中，补充时应先处理重复与进展关系。
- **消费恢复与房租援助：**定向检查找到零售消费恢复、租房援助加速等报道。它们曾通过初筛，却在两月合并中落选。可以作为消费和政策背景；租房援助不是住宅租金涨幅。
- **邮政计划涨价：**定向检查发现一篇拟提高邮票价格的报道没有被规则发现。“increase prices”没有匹配词表中的“price increase”。它证明固定短语会漏掉真实价格消息，但邮政不是高频消费主项，不应因容易识别就给予很大权重。

模型也把公司上市、科技公司盈利等判断为可保留背景。按本项目目的，它们最多作少量背景，不应压过生活成本、就业与消费报道。我们没有按“哪条更能拟合SCE”选择新闻。

## 6. 下一步保持简单

1. **扩大候选入口。**在现有关键词之外利用商业、经济和生活支出相关栏目，以及价格变化、家庭消费和生产停运的常见表达。仅用于找候选，不把一个词或一个栏目当作入选证明。
2. **清理明显误入。**处理`wage`误中`waged`、食品店枪击因`grocery`命中等情况。允许少量边缘经济背景，不逐篇追求完美精确度。
3. **调整选择依据。**先看文章在讲什么和是否补充了新的信息，再整理同一事件的重复与更新。关键词数量和头版只能作辅助，不能一直决定谁占据名额。
4. **在相同窗口准备一个候选版本。**保留旧E，比较两份新闻是否覆盖生活价格、供给、就业消费、政策和未来走势解释。主题检查不是硬性均分配额，不人为把涨价/降价各分一半。
5. **再用其他月份检查。**先验证方法能否持续找到合理新闻，之后才讨论批量分类接口和新的模拟。公共新闻库改善与家庭接触视图是两件事，仍需要分别检验。

这里落实的是库存盘点和抽查，还没有修改生产筛选器、正式E、提示词或运行预算。若后续使用DeepSeek等外部接口批量分类，应另登记样本、费用上限与质量检查；本次Luna助审使用会话额度，没有调用项目的付费接口。
