# 新闻筛选与呈现

目的：让美国居民一年期通胀预期模拟使用有依据、可检查的新闻信息。这里维护语义审核和候选分类方法，不存放运行配置。

## 用户确认的推进方向（2026-10-11，新闻分配尚未实现）

- **关键词负责宽松粗筛，LLM负责按明确背景和规则精筛。**不为少数争议案例增加关键词特例，只修普遍适用的明显词形错误和类别遗漏。精筛保留编号、格式及少量语义抽查，重点统一提示词定义，不追求逐篇人工裁决或零误筛。原v1.2规则、提示词及响应不覆盖，后续修改另留版本。
- **内容合格不等于每个人都会看到。**159篇`keep`是跨三个窗口的候选，先按各自日期窗口整理同一事件的重复和新进展；65篇背景可少量留用。尚未形成新每月清单，公共库约50篇仍是候选规模，不是每个家庭的阅读数量。
- **分别处理新闻的重要程度与个人接触。**影响较广的生活价格、就业及政策事件可作共同背景候选；具体新闻按主题、地区及家庭消费、住房等已有特征增加被选中概率，同时保留随机接触，避免租客只能看房租或低收入者只能看食品。画像与阅读偏好的对应关系是机制假设，不是已测得的真实阅读记录；不从人口特征猜政治立场或政策信任。
- **按用户随后确认，共同背景以实际总头版A1为准。**从存档中同时满足`print_section=A`和`print_page=1`的文章抽取，财经版B1不当作总头版；共同层不再按通胀相关性精筛，以免因调查主题倒推居民关注内容。版面缺失保留为未知，不让LLM猜头版。所有Agent共用抽取的共同层是第一轮机制假设，A1不等于每位美国居民真实读过。
- **先做离线示例，再登记真实模拟。**离线样例采用共同3条＋个人5条（仅示例，不是已冻结条数或真实注意力参数），展示不同画像收到的原标题、摘要及必要原文片段。用固定种子及主题、地区、画像规则生成个人选择，保留新闻编号和选择依据。全部遵守各线现有信息窗口；语义标签不能修复未知历史文本版本。随后比较同条数的统一、随机及按P分配视图，先看接触差异是否形成，再看总体与分组误差；不用真实SCE答案挑选新闻或调分配。

较早的`information_exposure.py`试验路由价格且关闭新闻；本轮新闻分配另在`news_exposure_demo.py`离线实现，未接入正式Simulation。正式E/模型/计分配置保持历史版本，未来真实调用另按具体输入、接收方及预算确认。

## 头版共同背景＋个人随机接触：离线实现（最新版v2）

- 输入仍是此前5/6月开发日期窗口；没有改变A/B研究口径或截止点。A1候选分别244/235篇，含政治、国际、疫情与经济等主题，不限定通胀新闻。每窗从A1候选固定种子随机抽3条，所有示例家庭共用；不是每位居民读完窗口全部头版。
- 个人库取既有347篇打标中、位于该窗且`keep`、没有明确A1记录的主要候选，两个窗口各49篇。版面未知的25/23篇保留未知，可作个人候选，不冒充确认过的非头版。它仍是抽样库，不能称最终完整精筛结果；`background`本轮保留在原标签中，未纳入个人示例。
- 3种完全合成家庭×2个窗口×相关性权重0/0.3/0.6，共18组输入。每次不放回抽5条个人新闻；默认选择概率=70%均匀分布＋30%按家庭相关性加权的分布，匹配项权重2、不匹配项权重1。每抽走一条重新计算概率，所有余下候选都有正概率。这里30%是分布混合系数，不是保证30%所选新闻相关。纯随机与加权版本复用同一组随机数。
- 租房、自有住房、食品/汽油/公用事业支出和就业仅用于建立演示关联。三个家庭的份额与分组阈值均为人为示例，不来自真实CE/SCE，也未按模拟误差调参。已有精筛文章的简短主题词仅用于分配，不修改关键词粗筛或重新判定语义；工资单复数等统一词形显式覆盖，油价/燃料消息是驾车背景关联，不等同居民支付的汽油价格。
- 阅读页新增“从公共新闻库到每个家庭看到的消息”：可切换月份、家庭及权重，展开原标题、摘要、必要原片段，以及可用于未来模拟的新闻原文。输入文本不发送分类理由、匹配分数、随机数或真实SCE答案，也不添加“你必须更关注某商品”的指令。现在只生成新闻部分，不是完整P/E/B提示或引擎轨迹。
- [验收记录](exposure_demo_acceptance_20261011.json)：9项定向测试、18组原文/日期/版面/无重复/共同层一致/正概率检查，以及18种页面筛选组合通过；旧60/120/360条阅读记录保持。浏览器视觉渲染未独立验收，不将程序筛选检查表述为截图验收。15份待审文件及原v1.2筛选/打标来源哈希不变，新增API与Simulation均0。

**路径：**[本地阅读页](news_review_20261011.html#news-exposure-demo)／[可提交的统计与来源哈希](exposure_demo_summary_20261011.json)。完整原文与合成家庭视图留本地`outputs/sce_news_exposure_demo_20261011_v2/household_views.json`；同目录有候选库、配置/源码快照、此前页面备份、筛选检查。v1是首轮内部草稿，v2补统一分配词形与显式替换前版本的哈希保护；两版均无真实调用，旧输出保留。

**复现：**`python3 scripts/prepare_sce_news_exposure_demo.py --out outputs/<新目录>`，默认只离线生成文件、不联网。修改已有阅读页需显式传`--update-html <路径>`；已有演示还需`--prior-demo <上一版本目录>`，先核对页面哈希，发现其他编辑则停止。

**尚需解决：**扩充完整粗筛候选的精筛覆盖，按事件减少重复、保留新进展；核查窗口内头版取样数量与时间覆盖、NYT单一媒体代理的适用边界，再登记实际P的统一/随机/加权同条数对照。默认比例和每人条数不因这18组样例而冻结，更未证明拟合改善。纸版实际刊载日与历史文本版本未独立核验；目前只沿用UTC日期级回顾窗口，B路线不能将未来才确认的版面记录当作截止前可得证据。

**资料来源：**本地NYT Archive四月/五月/六月缓存及旧打标回包；[NYT官方Archive说明](https://github.com/nytimes/public_api_specs/blob/master/archive_api/archive_api.md)确认接口提供逐月文章元数据。A1的实际字段覆盖与数量来自本地文件核查，真实家庭阅读率没有观测数据，本轮不补造。

两名Luna分别首审30篇；第三名Luna对随机20篇盲复审；主Agent在读取子Agent结果前读完60篇并保存初判，之后裁决分歧。**这是模型辅助候选审核，不是人类标注金标准。**60条输入对应51篇独立文章，9篇跨月复用，未改任何旧E或模拟输出。

原始新闻和三份Luna输出仅在本地 `outputs/sce_news_review_20261011_v1/`。研究标签、短证据摘录及汇总可随仓库保存；完整摘要不进Git。HTML含本地存档摘要，也仅留本地：它便于核查输入，但不是公开发布包。
