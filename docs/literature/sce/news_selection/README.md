# 新闻筛选与呈现

目的：让美国居民一年期通胀预期模拟使用有依据、可检查的新闻信息。这里维护语义审核和候选分类方法，不存放运行配置。

## 本轮成果（2026-10-11）

- **最新：[规则＋DeepSeek试验报告](selection_trial_20261011.md)**／[观察到的漏斗与加权估计](selection_trial_summary_20261011.json)／[360条窗口标签](selection_trial_labels_20261011.json)／[六例定向复核](selection_trial_targeted_review_20261011.json)。347篇独立文章、44批、无重试；5/6月＋9月方法检查，未运行新Simulation。新候选占可读文章约12.1%、12.1%、10.7%，有补漏也有公司背景拥挤；原始标签及格式处理保留。规则/提示词草案中的“未运行”是写稿时状态，本文链接的报告为最新状态，原文件保留用于按哈希复算。
- [关键词机制v1.2](keyword_recall_v1_2.md)／[打标提示词v1.2](llm_label_prompt_v1_2.md)：按用户要求明确候选入口、四类处理、六类主题与实际输入输出格式。可供下一次试标，尚未接入API或修改正式E。
- [原始库存与未入选检查](inventory_audit_20261011.md)：82个月、34万条元数据；两开发月120篇未入选抽查，已证明存在有价值的漏选候选。
- [更宽松的候选标准v1.2](classification_standard_v1_2.md)：按用户最新偏好保留经济背景，先处理明显误入与主题拥挤；尚未改生产规则。
- [库存数据与哈希](inventory_summary_20261011.json)／[未入选抽查汇总](unselected_sample_summary_20261011.json)／[未入选候选标签](unselected_sample_labels_20261011.json)：便于离线核查与后续接力。

- [历史候选标准v1.1](classification_standard_v1_1.md)：保留此前价格消息、经济背景、待核正文和排除项的审核口径。
- [历史LLM提示词v1.1](llm_label_prompt_v1_1.md)：保留旧草案，下一次试标使用上面的v1.2；两版均未接入API或生产流程。
- [标签JSON](review_labels_20261011.json)／[标签CSV](review_labels_20261011.csv)：60行有理由、有来源的审核结果；未附完整原摘要。
- [原始审核标准](rubric_v1.md)／[来源与哈希](review_manifest_20261011.json)：保留如何审、依据什么输入、之后澄清了哪些边界。

两名Luna分别首审30篇；第三名Luna对随机20篇盲复审；主Agent在读取子Agent结果前读完60篇并保存初判，之后裁决分歧。**这是模型辅助候选审核，不是人类标注金标准。**60条输入对应51篇独立文章，9篇跨月复用，未改任何旧E或模拟输出。

原始新闻和三份Luna输出仅在本地 `outputs/sce_news_review_20261011_v1/`。研究标签、短证据摘录及汇总可随仓库保存；完整摘要不进Git。HTML含本地存档摘要，也仅留本地：它便于核查输入，但不是公开发布包。

## 下一步

已完成v1.2同窗口候选与首轮真实打标。下一步补明确词形/食品供给对象遗漏，统一实际增产/零售价格及国外地方消息的分类边界，先整理重复与新进展再形成公共库。9月已参与复核，下次检查换未参与调整的月份。此前三篇待核正文仍保留为待办，本次未读取正文。参考标签需由用户或领域研究者进一步确认，不能把模型建议当准确率。

DeepSeek首轮已调用并留下完整费用估计与响应审计；未比较其他分类服务。只做分类不等于能恢复家庭曝光或信任：公共新闻库、家庭看到的消息和行为反应仍须分别检验。原先120篇库存诊断和60篇旧输入审核保持历史记录，不与本轮新标准混算。
