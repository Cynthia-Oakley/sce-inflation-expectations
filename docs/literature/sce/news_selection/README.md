# 新闻筛选与呈现

目的：让美国居民一年期通胀预期模拟使用有依据、可检查的新闻信息。这里维护语义审核和候选分类方法，不存放运行配置。

## 用户确认的推进方向（2026-10-11，新闻分配尚未实现）

- **关键词负责宽松粗筛，LLM负责按明确背景和规则精筛。**不为少数争议案例增加关键词特例，只修普遍适用的明显词形错误和类别遗漏。精筛保留编号、格式及少量语义抽查，重点统一提示词定义，不追求逐篇人工裁决或零误筛。原v1.2规则、提示词及响应不覆盖，后续修改另留版本。
- **内容合格不等于每个人都会看到。**159篇`keep`是跨三个窗口的候选，先按各自日期窗口整理同一事件的重复和新进展；65篇背景可少量留用。尚未形成新每月清单，公共库约50篇仍是候选规模，不是每个家庭的阅读数量。
- **分别处理新闻的重要程度与个人接触。**影响较广的生活价格、就业及政策事件可作共同背景候选；具体新闻按主题、地区及家庭消费、住房等已有特征增加被选中概率，同时保留随机接触，避免租客只能看房租或低收入者只能看食品。画像与阅读偏好的对应关系是机制假设，不是已测得的真实阅读记录；不从人口特征猜政治立场或政策信任。
- **头版仅作为显著程度的辅助证据。**重要新闻对所有Agent可见可作第一轮简化对照，不能因此声称每位真人都读过；没有头版或传播证据的文章，不让LLM凭常识补造传播范围。共同背景和家庭差异可以并存。
- **先做离线示例，再登记真实模拟。**可先示例共同3条＋个人5条（仅示例，不是已冻结条数或真实注意力参数），展示不同画像收到的原标题、摘要及必要原文片段。用固定种子及主题、地区、画像规则生成个人选择，保留新闻编号和选择依据。全部遵守各线现有信息窗口；语义标签不能修复未知历史文本版本。随后比较同条数的统一、随机及按P分配视图，先看接触差异是否形成，再看总体与分组误差；不用真实SCE答案挑选新闻或调分配。

现有`information_exposure.py`试验路由的是价格信息，且明确关闭新闻，不能称新闻分配已经落地。本次只明确设计，不修改正式E/Simulation、不触发新API。未来真实调用另按具体输入、接收方及预算确认。

- [原始审核标准](rubric_v1.md)／[来源与哈希](review_manifest_20261011.json)：保留如何审、依据什么输入、之后澄清了哪些边界。

两名Luna分别首审30篇；第三名Luna对随机20篇盲复审；主Agent在读取子Agent结果前读完60篇并保存初判，之后裁决分歧。**这是模型辅助候选审核，不是人类标注金标准。**60条输入对应51篇独立文章，9篇跨月复用，未改任何旧E或模拟输出。

原始新闻和三份Luna输出仅在本地 `outputs/sce_news_review_20261011_v1/`。研究标签、短证据摘录及汇总可随仓库保存；完整摘要不进Git。HTML含本地存档摘要，也仅留本地：它便于核查输入，但不是公开发布包。

## 下一步

已完成v1.2同窗口候选与首轮真实打标。按上方用户确认方向保持宽松粗筛，明确精筛的背景定义，再整理重复与新进展、形成公共库，准备共同背景＋个人新闻的离线示例。9月已参与复核，下次检查换未参与调整的月份。此前三篇待核正文仍保留为待办，本次未读取正文。定向复核只用于改清规则，不把模型建议当准确率，也不以少数案例堆砌关键词特例。

DeepSeek首轮已调用并留下完整费用估计与响应审计；未比较其他分类服务。只做分类不等于能恢复家庭曝光或信任：公共新闻库、家庭看到的消息和行为反应仍须分别检验。原先120篇库存诊断和60篇旧输入审核保持历史记录，不与本轮新标准混算。
