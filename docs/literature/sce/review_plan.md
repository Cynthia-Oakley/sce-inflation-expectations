# 文献调研与整合计划

日期：2026-10-05。阶段：真实模型开发实验已跑通，行为有效性尚未验证；开题报告已获用户基本认可。

执行状态：首轮调研、交叉核对、综述与方案已完成，成果见 [README](README.md)。以下保留原计划供接力检查，不表示这些材料仍待创建。运行实施尚未启动。

## 目标与核心问题

解释两个开发月中“总体预期偏低、家庭回答过于相似”的候选来源，寻找可测试的经济学机制。研究对象仍是 SCE 主观通胀预期，实际 CPI 不充当调查真值。

1. 家庭怎样从日常价格、经验与新闻形成预期？为什么不同于宏观分析者？
2. 人口标签如何连接消费篮子、购买频率、住房/通勤、信息接触，而不是任意增加噪声？
3. 共享 E 与差异化 E 怎样组织？怎样区分输入、表达、模型先验和统计扩展造成的问题？
4. Agent 模拟怎样接受分布、人群、时间及独立基线验证，而非只调齐全国中位数？
5. ConsumerSim 与 SocioVerse 案例提供哪些可复用结构，哪些机制不能直接搬到 SCE？

## 分工与允许写入范围

- 子任务一：经济学预期形成；仅写 `themes/expectation_formation.md`、`sources/expectation_formation.json` 及对应原文下载目录。
- 子任务二：家庭价格体验；仅写 `themes/household_price_experience.md`、`sources/household_price_experience.json` 及对应原文下载目录。
- 子任务三：Agent × 经济学；仅写 `themes/agent_simulation.md`、`sources/agent_simulation.json` 及对应原文下载目录。
- 主 Agent：官方案例/ConsumerSim核对、统一目录、综述、方案、证据交叉核验与任务板整合。子任务不改运行源码/配置、任务板、决策或开题报告，不 commit。

简单资料检索与定向综述使用 GPT-6 Luna Max；方法比较由适合的子 Agent 独立分析。三项并行，主 Agent 同步核对官方案例。保留用户未过目的旧修改，只用明确文件清单保存本轮成果。

## 证据要求

- 优先作者公开全文、央行工作论文、期刊/机构官方论文页、论文与代码原仓库；必须实际检索并打开，不能凭记忆拼引文。
- 重点阅读机制、识别/实验设计、样本和局限；每条核心结论给来源链接与页码/章节。摘要阅读只能支持摘要内结论。
- 区分实证因果结果、观察相关性、理论假设与我们拟采用的机制；论文在某样本成立不等于本项目已成立。
- 来源 JSON：`id/title/authors/year/source_url/open_access_url/source_type/access_level/evidence_locations/findings/limitations/project_use/checked_on`；`access_level` 区分全文、摘要、官方案例描述、源码。
- 每个主题精选约 5–7 篇，核心 2–3 篇深入阅读；不以数量替代质量。重复论文允许引用，但主综述按同一文献识别。
- 可公开下载的核心全文保存本地并记录 URL、SHA-256、获取状态；下载受阻则保留可用原文链接，不能将检索摘要冒充全文。

## 整合与验收

1. 统一主题笔记与来源记录，复核最直接支撑设计的文献与官方案例。
2. 写一份有主线的中文综述：已知机制 → 当前项目缺口 → 可验证假设，不堆论文摘要。
3. 写研究方案：先做零 API 的输入/输出与分布诊断，再设计固定 P/E 的机制对照；每项列变量来源、实现位置、对照、评价、风险和停止条件。
4. 给出阅读优先级与下一步交接。不新增真实 LLM/MCP 付费调用，不改已有实验配置、不从正式留出结果反向调参。
5. 检查路径/JSON/链接、保护旧未提交批次，明确范围提交与备份。本轮方案是待审方法建议，不视为新的冻结参数。
