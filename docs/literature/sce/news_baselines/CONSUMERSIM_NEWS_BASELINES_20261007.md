# ConsumerSim 新闻基线的披露边界

核查日：2026-10-07。核查对象为 ConsumerSim 论文 arXiv:2606.30395v1（2026-06-29 版本）§6、§9、§10及表1、表5。本文只记录该版本正文明确写出的内容；没有把本项目的实现候选补成论文方法。

## 核查结论

论文确实报告两种含新闻的预测基线：**News Semantic FAAR Proxy** 与 **Macro + Market + News Ridge**。前者把经济新闻文本的语义特征压缩成紧凑代理特征，再与自回归信息共同预测月度 CCI；后者将宏观、金融市场和新闻派生特征放入 Ridge 回归。论文没有披露足以复刻新闻处理流水线的细节。尤其没有给出编码器名称/版本、文章文本字段与长度处理、逐篇到月度的聚合公式、降维算法与维数，或两个模型各自的完整超参数和逐月训练清单。

## 原文明确披露

| 项目 | News Semantic FAAR Proxy | Macro + Market + News Ridge |
|---|---|---|
| 新闻语义 | 从经济新闻文本提取语义特征；语义新闻信号被压成紧凑代理特征，再与自回归信息合用预测月度 CCI。 | 纳入新闻派生特征；列举的特征含经济新闻强度。文中未称该模型使用 FAAR 的语义特征压缩流程。 |
| 其他输入 | 自回归信息；正文没有列出所用滞后阶数或 FAAR 的完整公式。 | 宏观指标、金融市场变量及新闻派生特征；例子包括劳动力、通胀、利率、股票市场变动、风险情绪和经济新闻强度。 |
| 回归/正则化 | “factor-augmented autoregressive”代理基线；未给出具体因子提取或回归设定。 | Ridge 回归；论文称用于处理相关预测变量并限制过拟合。未给出惩罚参数。 |
| 评价区间/表1结果 | §6 称美国 baseline evaluation 使用 2014-01 至 2026-03 的月度 Michigan CCI；但表1标题称各区域报告评价覆盖 2020-01 至 2026-03（75个月）。表1美国列报告 MAE 4.02、RMSE 5.63、Pearson 0.9378、Spearman 0.9331。 | 同左。表1美国列报告 MAE 6.21、RMSE 14.40、Pearson 0.7215、Spearman 0.8758。表1结果只按表注所述的 2020-01 至 2026-03 标记；正文未解释与 §6 日期范围的差异。 |

论文 §6 与表1对美国时间范围的文字存在未解释差异：§6 写 2014-01 至 2026-03，表1注写 2020-01 至 2026-03。本文不推断前者是训练期或后者是测试期。§9 规定，可调超参数按时间顺序调节，调参只使用预测日期之前的信息；基线总体只用预测月份之前或当时可得的信息。§10 的三个月美国后截止检查进一步说明，宏观、市场、调查和新闻输入截到对应月度调查 cutoff；目标月官方 CCI 及之后实现的结果不提供给响应核。该段明确说明的是 ConsumerSim 信息环境处理和比较时间规则，不能据此推断两种回归基线各自都采用了同一特定新闻清单或特定发布时间数据库。

## 论文未披露，不能补写为已知方法

- **编码器**：未指明 embedding/语言模型、版本、训练语料或训练知识截止日期；也没有说使用哪种词向量或新闻情感模型。
- **文本构造**：未说明使用标题、摘要、全文或其他字段；未说明分词、截断、分块、去重、新闻来源筛选或逐篇编码规则。
- **月度聚合**：确认目标与预测频率是月度，并称为月度 CCI 预测；没有写文章向量如何形成月特征（例如求均值、求和、按时间衰减、情感统计或类别分组）。因此不能把“按月平均句向量”归于论文。
- **降维**：FAAR 的“compact proxy features”只说明特征被压缩/简化为紧凑代理，没有指定 PCA、因子分析、因子数量、拟合样本或是否在每个训练窗重估。不能把 PCA 当成已披露实现。Macro–Market–News Ridge 的文字也未单独说明是否加入高维语义向量或采用同一压缩方式。
- **拟合与验证清单**：时间序列信息隔离原则和“仅用预测日前信息调参”有披露；具体到这两种基线，论文没有给出训练起点、验证月份、滚动/扩展窗方式、Ridge alpha 网格、特征标准化规则、FAAR 阶数/因子选择流程或逐月拟合日志。不能把 ConsumerSim 惯性权重在 2024-01 至 2024-06 的校准窗说成这两种基线共同的验证集；论文把该窗口用于 §4.6 的行为惯性校准。
- **新闻信息截止证据**：论文描述按相关月度 survey cutoff 截断新闻等输入，并称修订序列不能早于公开日进入周度诊断；没有公布上述回归基线逐条新闻的发布日期表、数据快照/vintage 或可核验的新闻—预测月份映射。论文给出了规则，未给出可供外部逐条重演的证据包。

## 对本项目的借鉴范围

可以据此称“参考 ConsumerSim 的新闻语义 FAAR / 宏观市场新闻 Ridge 基线类别”，也可将它们作为方法参照。若在 SCE 实现中采用固定句编码器、月内等权汇总、训练内 PCA 和按日期滚动 Ridge，应标为**本项目对论文概念描述的具体化实现**，而非 ConsumerSim 原实现或完整复现。需单独记录编码器及版本、文章字段/截断、月聚合、变换拟合窗、参数选择期、预测 cutoff 和历史发布时间证据。

本项目已经写明的 MPNet 候选、按月汇总、候选 PCA 及时间划分均属于本项目方案，尚未下载模型或训练新基线，见[本项目新闻句向量与训练/评价说明](../../../SCE_NEWS_EMBEDDING_AND_SPLITS_20261007.md)。
