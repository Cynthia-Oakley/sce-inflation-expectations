# 心理与家庭状态模块：实施建议

2026-10-06 · draft。本文件给下一位开发 Agent 使用；尚未实现、未冻结，不授权新的模型或付费 MCP 调用。

## 目标与模块边界

目标是检验有依据的家庭状态或合成心理属性能否改善 SCE 回答分布。按模块分别推进，不把幸福、信任、数理和消费体验一次全部加入。现有消费篮子、问卷、计分器和环境保留；新增信息只有白名单字段进入 persona 文本。行为方向交给待验证的模型，不写“悲观加几个百分点”等规则。

## 工作包 1：已有字段离线审计（第一优先级）

输入为现有 SCE 微观表、原问卷和数据字典；来源与候选字段覆盖见 [数据审查](data_feasibility.md)。

- 数据线已检查当前本地微观文件：2021-05 有1234人，Q1全覆盖、Q2为1233；2021-06 有1297人，Q1全覆盖、Q2为1296。衍生 `_NUM_CAT` 与主要人口分组全覆盖；原始 QNUM 题、健康/风险题主要只问新入组者，约153或162–163条。完整核验见数据稿，不能把未问缺失当作零值。
- 继续核实 Q1、NUM 的分类方向、缺失代码、跨月变化与可使用日期。NUM 的原始题与整理后分组不能互相冒充；上述计数是当前文件观察，不证明2021历史可得。
- Q1 是过去一年财务变好/变差的自报；按原有序档保存。它不是情绪诊断或客观收入变化。
- Q2 的未来财务预期另列为同调查信念代理，默认不加入主模拟。A 若要使用，单列“代理辅助重建”实验；B 不用当期未公开 Q1/Q2。
- Q45b、QRA1/QRA2 暂列后续候选，核实缺失与题目覆盖后再讨论。
- 评价层报告分组样本数、加权预期分布及不确定性；年龄、收入、教育等相关因素共同列出。关联不作因果结论。
- 开发月已用于方案研究。其他月份一旦打开用于诊断即登记为诊断数据，不再冒充独立留出。

建议新增程序 `scripts/audit_sce_household_state.py`；生成带 run_id 的 `outputs/sce_household_state_audit_<run_id>/`，只输出诊断和来源，不修改既有 population。

## 工作包 2：外部联合 donor 小包

候选首选 GSS 2018 的 HAPPY＋SATFIN 探索模块，是否可用以原始微观共同支持审计为准，不因代码本列有字段便认定全部行共同测量。首版不跨年混池、不把 TRUST 解释为央行信任、不把 FINALTER 解释成未来乐观。若数据线发现角色/缺失导致严重不足，先报告结果再选 SHED 财务状态替代模块；它也不能冒称幸福量表。

建议原始位置 `data/raw/psychological/gss/2018/<download_snapshot>/`；清洗产物 `data/interim/psychological/gss2018_<run_id>/`。均不提交个体记录。可版本保存的来源、字段映射及审查报告放在本研究目录 `sources/` 和 `docs/`。

清洗需保留：donor 本地键、调查波次、权重、年龄、教育、家庭收入、可比地区/就业/住房、HAPPY/SATFIN 原始类别、缺失类型。先统一成年人/家庭收入单位等定义；不把来源没有的匹配字段人为补成真实值。权重采用该波次和模块的官方建议，不能盲用另一年的权重名。

B 线还需历史公开版本证明。公开公告只证明曾发布，不证明当前文件哈希当时存在；找不到旧版本时，先做 A 探索，B 来源资格保持未通过。

## 工作包 3：透明的条件分配

建议合成算法放 `studies/sce_inflation_expectations/psychological_profiles.py`，`scripts/build_sce_psychological_profiles.py` 仅作辅助入口；写新的 sidecar，不覆盖 P。

1. 以核实的共同字段形成粗匹配单元。年龄、教育与可比家庭收入为候选；具体分组和稀疏门槛先依据支持审计决定，不能把 CE 的阈值直接搬来。
2. 在支持单元按 donor 调查权重抽整行 HAPPY＋SATFIN；不分别抽取两题，不用组平均代替类别。
3. 预先登记回退顺序，保留实际使用层级；关键条件仍不支持时值为 unknown，不全国随机兜底。
4. 固定项目种子与跨月人员键。若两月保持相同幸福/满意，标记 held_constant_synthetic_proxy；这是省成本设计假设，不是证明它们长期稳定。新增人员独立分配。
5. 对 Core/Normal 使用相同规则；调试阶段的心理 donor 池不依据真实 Q8/Q9 回答挑选。
6. 开发阶段建议先做 5 套独立分配，以观察敏感性；数量只是起点，不保证推断充分，也不自动构成统计学的 proper multiple imputation。

建议输出字段：`agent_id`、`source_survey`、`source_wave`、`source_hash`、`donor_local_id`、`assignment_seed`、`draw_id`、`match_fields`、`fallback_tier`、`support_status`、`effective_donor_n`、`attribute_values`、`observed_or_synthetic`、`temporal_assumption`、`line_eligibility`。模型仅接收白名单题义和值，不接收 donor ID、权重、目标答案或评价标签。

## 工作包 4：进入模拟前的检查

必查共同支持覆盖、原始与带权 donor 数、有效样本量、最大权重、donor 复用、回退占比、未知比例。检查 HAPPY/SATFIN 联合表及年龄/教育/收入组内分布；给 donor 留出真实字段作预测检查。

源调查内部留出只能证明在来源内部的匹配表现，不能证明迁移到 SCE 的真实性。CE 与心理来源没有共同个体时，跨域关系未识别；不按对目标答案的拟合结果选择配对方式。

检查跨月键和 Core/Normal 相同规则；确认侧车没有自动改变 Normal 估计器。条件支持不足时报告失败或缩减模块，不以扩大方差作为验收标准。

## 工作包 5：之后的行为实验（本轮不执行）

建立三组：现有基线；同位置同格式的心理未知控制；有来源的心理字段。三组共用相同 P/E、消费篮子、prompt 其余部分、模型、解码和计分版本。新增文字长度可尽量匹配，但等长不能保证语义或注意力影响相同；仍需审阅实际提示。可追加打乱映射诊断，但它不是最终 population。

先明确拟检验的一个模块和主要指标，不同时切模型。多次同输入生成测模型波动，多套 donor 分配测合成敏感性，分开报告。按 source 支持、效应波动与预算决定样本量，暂不把 20 或 300 人定为本模块功效保证。

主要结果看全国水平、个人预期均值的分布距离/IQR、概率尾部和个人不确定性、群体关系。仅误差下降或 IQR 变大不够；不能从合成 donor 推断真实人的因果效应。独立评价月份和容许退化标准应在看结果前确定。

## 拟议交付顺序

第一步交 SCE 字段审计；第二步交一个 donor 包与支持报告；第三步交多套侧车与提示预览；第四步提交新实验卡与预算。当前只完成文献和方法准备，尚无心理侧车、适配器或新模拟结果。源细节、统计假设与缺口见 [理论](theory_review.md)、[数据](data_feasibility.md)、[合成方法](synthesis_methods.md)。
