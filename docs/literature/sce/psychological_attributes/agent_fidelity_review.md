# “模型像专家”解释：已有证据与检验边界

核查日：2026-10-06。这是本次心理属性研究的补充笔记；不修改已冻结实验。

## 1. 当前能说什么

已有五组试验的回答过于集中，并且总体水平仍偏离真人。理由像宏观分析、答案圆整、大家使用相似概率模板，都不能单独证明模型准确地模拟了专业预测者；当前输入提供共同的宏观简报、模型自身先验、问卷理解与生成模板可能同时起作用。

因此，“较强模型把普通人答题变成专业预测”是可检验解释，不是已经识别的原因。引入心理属性不能替代模型对照，也不能靠加入“悲观”标签直接规定高通胀答案。

## 2. LLM 文献确实提供了警示，但领域不同

- **Aher et al. (2023)，ICML，§1/§5。** 四类人类实验中，数值常识的群体估计出现回答过度准确、过度相似的扭曲；这支持检查模型是否带入超出角色的信息能力。研究不是通胀调查，不能用其结果证明本项目误差的具体来源。[论文](https://proceedings.mlr.press/v202/aher23a.html)。阅读：官方 PDF 正文相关章节；已有本地原文复用，不重复下载。
- **Bisbee et al. (2024)，Political Analysis，§§2–4。** ANES 画像条件化的政治态度模拟可接近真实均值，但回答方差更小，部分关系不符、措辞与时间更新敏感。它表明增加人口标签和模拟人数并不保证分布忠实；不提供 SCE 心理属性的效应量。[论文](https://doi.org/10.1017/pan.2024.5)。阅读：官方摘要和已有本地正文笔记复核。
- **Gao et al. (2025)，作者预印本 v3，§Results/Demographic Personas。** 11–20 money request game 中，角色、语言和少量示例会显著改变响应；加入 143 位真人的人口画像也没有恢复真实分布。这里引用的是可读的作者 v3，不能冒称已逐字审阅期刊最终版。[作者版本](https://arxiv.org/html/2410.19599v3)。阅读：正文角色、人口画像和 few-shot 部分。

这些证据建议预先固定文本、模型和检验方式；新增心理信息是否改善 SCE，要在 SCE 自身另做验证。

## 3. ConsumerSim 可借的内容与尚缺的细节

[ConsumerSim v1](https://arxiv.org/html/2606.30395v1) §4.2.1 将 GSS 条件分配的心理社会属性列入分层画像；§4.4 要求按消费者生活处境答题。§2.5/Table 4 的消融移除的是整个 Hierarchical Persona Substrate，并非单独幸福度或乐观模块。因此该结果不识别某个心理属性的独立贡献。

我们可借条件分配和模块对照思路，但要自己核实 GSS 具体变量、同年同人联合支持及匹配方法。论文列出的“未来乐观”不能自动映射成某个名字相近的 GSS 财务变量。

## 4. 最小检验含义

1. 保留当前模型/原始文本作为已有基线；较早模型在同 P/E 下单独比较，不同时增添心理属性。
2. 心理层加入时保留原人口和消费篮子，比较有来源的条件分配与同格式的属性打乱对照；后者诊断映射作用，不作为最终模型。
3. 完全相同输入的重复生成用于估计技术波动；不同心理分配种子的变化用于估计合成不确定性，两者不混成真人差异。
4. 主要看独立月份的分布和群体关系改善；不能以“回答更分散”或 reason 提到情绪为充分证据。
