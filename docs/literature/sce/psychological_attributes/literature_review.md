# 心理属性是否值得加入 SCE：整合综述

2026-10-06。三名 GPT-6 Luna Max 分别研究理论、数据和合成方法；主 Agent 交叉核对并整合。本文是研究建议，不是已验证的机制或冻结参数。

## 1. 我们希望解决什么

当前试验的问题有两个：整体预测仍偏低，不同家庭的回答过于接近。补充心理信息的目的，是检验家庭处境和信息理解能否解释这些差异。成功标准是与真人的分布及群体关系更一致；仅把回答拉散或提高全国中位数，不足以证明机制有效。

这里要区分三个量：一个人给出的未来通胀概率有多宽；不同人的预期均值有多分散；相同画像重复调用模型有多不稳定。心理变量可能影响其中一项，不能把三者互换。

## 2. 理论上，什么最值得先做

**第一，近期家庭财务经历。** 丹麦调查与行政资料联结研究发现，家庭收入变化和通胀预期存在较强关系，提出生活事件会改变被唤起的价格记忆。这支持研究近期家庭处境，不等于证明稳定的幸福或悲观人格造成高通胀预期。[原论文](https://doi.org/10.1093/qje/qjag032)。SCE 已有过去一年家庭财务变化 Q1，值得先做离线关系检查。

**第二，看到什么、相信什么。** 全球调查和央行研究支持信息来源、机构信任与预期之间的关系。但信任的影响取决于信息内容和政策背景；美国证据也显示党派信任差异解释不了全部通胀预期差距。[全球研究摘要](https://www.nber.org/papers/w35511)、[ECB 研究](https://www.ecb.europa.eu/pub/pdf/scpwps/ecb.wp2375~2bac6e6836.en.pdf)、[美国反例](https://www.nber.org/papers/w33684)。因此不能给“低信任”画像直接加一个固定通胀数值。

**第三，数理和金融理解。** 直接调查发现客观金融素养和答题差异相关，主观金融自信并不具有同样证据。[调查研究](https://doi.org/10.1111/j.1745-6606.2010.01174.x)。项目已有 numeracy 分组，应先核实它目前是否被模型实际使用、缺失是否正确处理；它不是需要另造的乐观标签。

**一般幸福和财务满意度可以探索，但暂不作为主解释。** 本轮未找到足以把一般幸福单独认定为美国 SCE 一年期预期原因的证据。另有文献研究的是通胀经历影响幸福，方向不能反过来引用。[反向路径研究](https://doi.org/10.1016/j.econlet.2023.111434)。HAPPY、SATFIN 都是当时的自报状态；不能把它们当成稳定人格。

## 3. ConsumerSim 提供什么参照

ConsumerSim 从 GSS 的条件分布为人口画像补充心理社会属性。这说明条件合成是一条可借鉴的技术路线。论文没有披露每个构念的全部字段映射、条件单元和缺失处理，消融移除的也是整个人口层；不能据此证明幸福或乐观单独有效。[论文 §4.2.1、§2.5](https://arxiv.org/html/2606.30395v1)。

本项目应保留可检查的原始题义。例如一般人际信任不是信任美联储；过去财务变化不是未来乐观；当前财务满意不是客观资产余额。不能因字段名称近似就合并。

## 4. 可用数据的路线

先使用已有 SCE 的明确字段做 A 线离线检查，再考虑外部心理 donor。完整字段、年份、缺失覆盖、权重和下载核查见 [data_feasibility.md](data_feasibility.md)。

- **SCE：** Q1 是过去家庭财务变化；Q2 是未来财务预期。Q2 与目标通胀预期同属当期信念，默认不加入干净的主模拟；若 A 线另做代理辅助重建，需要明确标注。两者都不是一般幸福或人格量表。当前文件中两月 Q1 全覆盖、衍生数理分组全覆盖；原始健康/风险/数理题则有大量因未到提问时点造成的缺失，不能直接全量入模。
- **GSS：** HAPPY 与 SATFIN 的原题和有序分类已确认，可作为探索性联合 donor 候选；必须检查同一波次、同一行的共同观测和匹配支持。不能用分别公布的全国比例伪造两题联合分布。
- **SHED：** 更适合家庭财务处境、收支与应急能力，而不是完整心理人格。年份和公开日期需要逐项核查，报告公开日不能自动替代微观文件公开日。
- **HRS/MIDUS 等：** 可提供更丰富量表，但年龄覆盖、年份、获取程序与 SCE 适配增加成本，暂不作首版主来源。

外部调查通常面向成年人，SCE 的调查对象和财务角色并不完全相同；收入档、家庭单位、就业和地区也不能不经对照就匹配。相同人口标签不证明心理关系可以无损迁移。

## 5. 怎样合成，才不只是随机贴标签

首版建议按可比年龄、教育、家庭收入等变量找相似 donor，使用源调查权重抽取**同一位 donor 的整组属性**。保留原始有序类别，同时记录来源、年份、匹配层级和随机种子。匹配单元太稀时按预先约定逐级放宽；无支持则保留未知。方法及伪代码见 [synthesis_methods.md](synthesis_methods.md)。

这种方法保留了 donor 调查内观察到的组合，却没有找出 SCE 真人的实际心理状态。CE 与 GSS 分别匹配到同一个家庭，也没有恢复现实中的“消费结构—心理”关系；除非有共同观测资料，否则这是模型假设。[Eurostat 统计匹配研究](https://ec.europa.eu/eurostat/documents/3888793/7882299/KS-TC-16-026-EN-N.pdf)。重复分配可检查敏感性，不能修复缺失关系的识别。

## 6. A/B 与 Core/Normal 的边界

A 是历史重建，可明确使用当期已观察人口和家庭状态；若使用同期信念代理或已知总体约束，需要单独标注，评价不重复使用同一约束作为独立证据。B 是事前预测，只能使用 as_of 前有公开版本证据的资料，不能使用当期尚未公开的 SCE 画像、权重和 Q1/Q2。

GSS 2018 有 2019-03-19 的官方公开公告，但今天下载的修订文件并不自动成为 2021 年可见版本。[NORC 发布记录](https://www.norc.org/research/library/results-of-the-2018-general-social-survey-now-available-to-the-p.html)。研究参考可以使用较新文献；预测输入资料需另外审查，两者不要混淆。

Core 与 Normal 可以用同一套条件合成规则。当前 Normal 扩展并没有使用新心理字段，因此侧车生成后也不能宣称 Normal 已接入；先在 Core 上检验，再独立审核扩展估计方法。

## 7. 建议推进顺序

1. 先做已有 SCE 字段覆盖及关系诊断：Q1、NUM 等；Q8/Q9 始终留在评价侧，不用于 donor 匹配。
2. 下载并清洗一个明确波次的 GSS 联合 donor 小包；优先检查 HAPPY＋SATFIN，而不是一次塞入一串未核实人格变量。
3. 离线生成多套分配，检查共同支持、权重、稀疏回退和组内组合；若不能通过这些检查，停止进入模型实验。
4. 再提交同 P/E、同模型的对照运行卡，先检验一个模块；正式评价使用预先选定的独立月份。2021-05/06 已用过，不能再当作独立验证。

**结论：**理论上优先家庭近期经历和信息处理；数据上先用已有 SCE，外部 GSS 幸福/满意作为探索项。当前已完成调研方案，尚未建立心理 donor 合成器，也未新增模拟调用。
