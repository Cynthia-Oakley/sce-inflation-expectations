## 交叉核对中作出的更正

1. A 历史重建可以明确使用后验画像或约束；B 预测才必须限制截止前可得信息。未把 A 全部改为严格事前预测。约束量与独立评价量分开。
2. Johannsen 的固定篮子指数与拟议加权对数代理不同；CE 消费单元不能逐人联结 SCE，Diary 与 Interview 也不能按同一 CU 拼接。
3. 购物/驾驶角色可在有外部联合资料时条件概率合成，但不能由性别或就业确定赋值；合成分配不是实测行为。
4. Core/Normal 的群体回答分布不等于个人 Q9 密度；混合主观密度的方差不等于未来实际 CPI 方差。Q8、Q9 边际与配对评价分别选择有效样本。
5. ConsumerSim 论文效果含校准；新公开仓库是 clean rewrite，残差校准与论文混合公式不同，其 `observed_at` 过滤不能证明发布时间或 vintage。已归档参考代码但没有导入执行。
6. 原文首页复核纠正了作者名单与稿件日期：Argyle 文的 Ethan C. Busby、Homo Silicus 的 Apostolos Filippas / Benjamin S. Manning、Aher 文的 Gati Aher / Rosa I. Arriaga、Armantier 文的 Scott Nelson；`InflExp_4.pdf` 是 2011 年 3 月稿，不能标作 2013 年修订版。发表年与所读版本日期分开。

## 接力的具体任务

先执行不调用 API 的机制准备包：已有回答圆整/概率模板与稳健分布诊断 → SCE–CE 共同字段、历史版本与条件样本核查 → 同人同事实的表达样例 → 明确对照、主要指标、独立月份、重复策略与预算的运行卡。

优先保留当前标题＋摘要基线，先做同事实的表达对照；随后再考虑合成价格体验与个体观察视图。不要同时更换模型、人口、温度、新闻与记忆，不能靠加噪声或统一抬高预期宣布改善。

尚缺：若依赖摘要/预览论文的详细系数，须补阅读全文；个人购物角色及实际单位价格的公开配对资料不足；训练知识的历史泄露仍无法靠限制 E 消除。现有研究只提出竞争假设，没有证明本项目的偏低、过窄由哪个原因造成。
