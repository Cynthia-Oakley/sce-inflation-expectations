# 从家庭价格体验到通胀预期：SCE 项目的文献综述

2026-10-05。第一轮定向综述；全文阅读、摘要阅读和官方案例分别登记在 `sources/`。本文服务研究设计，不表示下面的机制已在本项目得到验证。

## 1. 我们要模拟的不是“会预测 CPI 的经济学家”

SCE 问的是居民对未来一年总体物价的判断。这个判断既可能来自新闻和官方统计，也可能来自最近的购物、房租、汽油、过往价格经历以及对信息的理解。同一 CPI 报告，可以被不同家庭以不同方式使用。

项目预测线是预测“下个月 SCE 居民会怎样回答”，回答内容才是其对未来一年的通胀预期。这与直接预测下一年实际 CPI 是两个目标，评价真值也不同。

历史重建线允许明确使用后验人口资料或已知宏观统计约束，检验的是未被约束的微观结构；未来预测线则限定截止前可得资料。二者共享问卷和评价工具，但不能共用一个未经说明的信息边界。当前开发实验保持历史发布稿 E；本综述没有要求把重建线一律改成事前预测。

项目已有两个开发月的基本流程，但回答总体偏低、不同家庭过于相似。至少有几种解释：真实人口覆盖不足；所有人获得同一宏观简报；生活经历没有进入观察；模型倾向专业或平均化回答；统计扩展使差异收缩。文献帮助提出区分这些解释的实验，不能替我们宣布原因已经找到。[项目已有结果](../../CORE_NORMAL_LLM_RECEIPT_20261005.md)。

## 2. 第一条文献主线：经验怎样进入预期

家庭不是每月清空记忆后从所有历史资料重新计算最优预测。经验学习研究将个人生命历程中的通胀与预期联系起来；近期经验、年龄及实际经历的历史相互作用。因此，年龄既是人口标签，也可能代表经验窗口。[Malmendier 与 Nagel 的作者工作稿](https://eml.berkeley.edu/~ulrike/Papers/InflExp_4.pdf)；所读稿首页日期为 2011 年 3 月，期刊发表于 2016 年，详细识别与版本说明见 [预期形成笔记](themes/expectation_formation.md)。

本项目可研究“看到同一近期价格涨幅，家庭如何判断其持续性”。但十二个月价格序列无法还原终身经验，年龄本身也不决定某人的信念。**生活经历不等于记得上一张问卷的数字**；当前不默认恢复上月答案注入。

## 3. 第二条主线：消费权重不等于注意权重

价格体验研究把个体问卷与实际消费篮子联系起来，强调频繁购买商品和涨价的显著性。一个支出金额不大的频购商品，可能比很少交易的大额项目更容易影响总体物价判断。因此，单纯再加更多全国指标，不一定补上个人感知。[D’Acunto、Malmendier、Ospina、Weber 的作者稿](https://eml.berkeley.edu/~ulrike/Papers/paper_DMOW.pdf)。

对 P/E 的合理连接是：生活处境 → 购买/接触渠道 → 可见价格 → 总体预期，而非“收入低，所以强制报高通胀”。人口条件可能通过消费篮子、信息理解、经济压力和经验共同作用；不能由模型的人口响应弱推断真实居民的收入教育无关。

外部消费资料可以帮助估计群体消费与体验，但不能让我们知道某个 SCE 居民究竟买过什么。BLS Consumer Expenditure 的支出记录、全国分项价格、个人实际单位价格是三种资料，不能混用。联合分布、时间版本和分配假设必须记录。[价格体验与数据笔记](themes/household_price_experience.md)。

Johannsen 的美联储研究提供了一条公开数据参照：用 CE 消费篮子与 CPI 分项构造价格暴露，再比较人口组的预期。这比直接要求真实收据更可操作，但不是同一个人的消费与 SCE 回答配对；拟采用的加权对数变化也只是简化代理，并非已复现其固定篮子指数。[FEDS 原文](https://www.federalreserve.gov/econresdata/feds/2014/files/201489pap.pdf)。

## 4. 第三条主线：公开信息不会自动被所有人吸收

有限注意、信息传播和信息干预研究提醒我们：信息的存在、接触、理解和更新是不同环节。居民可能很少主动读取政策报告；一次清晰的信息供给也可能改变其判断。相同事实的措辞、来源与框架，可能影响被理解的内容。[主题证据与局限](themes/expectation_formation.md)。

因此，共享 E 应当是可审计的公共事实库；Agent 实际观察可以是由可解释的接触规则产生的视图。这样我们才能区别“新闻库缺信息”和“每个家庭看见、使用的信息不合理”。需要比较同信息表达、不同信息接触；不能同时改一切再将收益归给注意机制。

当前模型反复使用“暂时性、基数效应、政策目标”叙述。E 自身也含这类观点，不能单凭输出理由归因于预训练记忆；它同样不证明模型真正采用了该决策机制。应通过受控对照观察回答变化，而不是把理由文本当因果解释。

## 5. 第四条主线：LLM 调查模拟需要检验整个分布

早期 silicon samples 研究说明人口条件可以改善某些任务上的群体拟合；后续研究也发现，合成问卷即使总体方向相近，变异、变量关系与不同人群的表现仍可能失真。[Argyle 等的期刊原文页](https://doi.org/10.1017/pan.2023.2)、[Bisbee 等的期刊原文](https://www.cambridge.org/core/journals/political-analysis/article/synthetic-replacements-for-human-survey-data-the-perils-of-large-language-models/B92267DC26195C7F36E63EA04A47D2FE)。这些是政治调查研究，支持评价原则，不能直接证明通胀机制。

丰富访谈或自报资料支撑的个体模拟，也不等于几个年龄收入标签就能恢复个体判断。提升温度能产生不同答案，但这种生成随机性未必对应居民差异；补幸福度或人格也需明确资料、联合分配和增量检验。[Agent 方法笔记](themes/agent_simulation.md)。

评价应同时观察全国水平、人群间分布、组间关系、个人 Q9 不确定性及跨期变化。**个人分布宽、人群意见不同、同一模型重复调用不稳定，是三个不同概念。** Q8 与 Q9 的差异也可能是调查行为，应保存并验证，而不是强制一致。

调查回答还可能圆整、集中于少数概率档或出现极端值。当前真实分歧很大，不意味着这些变异全部来自消费体验；应先比较回答形式、稳健分位数和完整尾部，再解释经济机制。不能简单加噪声来模仿标准差，也不能为使模型看起来更准而事后删除真实尾部。

## 6. Core/Normal 的作用与边界

ConsumerSim 用核心人群产生回答，按人群结构进行贝叶斯扩展，并另做惯性校准。本项目可以借这种分工，但不能混淆统计语义：CCI 的正/中/负属于回答类别，SCE 十档概率属于每个人的主观预测分布。先平均十档再拟合“代表居民”，通常不能替代逐人计分后聚合。[ConsumerSim §4.2–4.6](https://arxiv.org/html/2606.30395v1)。

统计扩展能改善人口构成或处理小组不稳定，无法从低且窄的 Core 中凭空创造新的真实行为信息。已有扩展未稳定优于 Core 直接加权，正说明两者应并列保留。校准、人口代表性和经济学机制是不同的收益来源，须逐层报告。

## 7. SocioVerse 案例提供的是可检验结构

PMI 的参考意义是把主体状态更新与问卷作答分开；SCE 可以在公共事实与回答之间研究价格体验和持续性判断。混合舆论提醒我们检查普通规则侧是否压缩分布；汽车市场案例则提示已知统计量参与校准时应标成重建，不能用同一约束量证明预测准确。[案例核对及原文定位](themes/socioverse_cases.md)。

平台 Path A/B/C 是工程接入方式，与本项目历史重建/未来预测的两条研究路线不同。案例人数、企业时点、问卷计分和参数并非当前 SCE 的默认要求。

## 8. 本项目目前最值得做的三件事

1. **先检验表达，不急着扩大人口**：同一批 P/E，比较宏观简报与易读居民表达。不得增加暗示目标值的指令。
2. **再补有依据的体验**：先核对可用字段，再构建食品、燃油、住房等接触差异；通过独立对照判断能否恢复群体关系。
3. **最后才讨论校准和长期状态**：原始、扩展、校准结果分别报告；在新时期验证，不按开发月误差不断挑参数。

具体执行、对照、数据缺口和停止条件见 [研究设计方案](research_design.md)。这轮文献为现有开题提供支撑，不要求重写开题，也不自动触发新 Simulation。
