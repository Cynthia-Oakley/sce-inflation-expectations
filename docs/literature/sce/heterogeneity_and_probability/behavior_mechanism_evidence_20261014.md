# 行为机制落地：SCE控制变量检查与购买频率准备

2026-10-14。新增API调用0，费用0；没有改旧实验、运行配置或冻结计分器。阅读：[图表与简明解释](../../../workstreams/20261013_behavior/codex_expansion_diagnostic_20261014.html#behavior-mechanism-evidence)。

## 1. 我们的数据支持哪些判断？

用2017-01至2025-10的106个月、130,216条真实受访者月记录检查。控制调查月份、年龄组、教育、收入、数理能力、地区、就业和性别；性别只从本人当月或以前的Q33取得，不用未来答案补过去。主要Q9分析实际包含119,761条记录、15,465个不同受访者。

这里比较的是**控制其他字段后的平均差异**，不是全国中位数变化，也不是对人群应回答多少的规定。

- **性别确实有关，但Q8和Q9很不一样。** 女性比男性的Q8点预期平均高2.115pp；Q9个人密度均值高0.431pp，95%区间[0.199,0.662]。不能把“女性高2pp”同时用于两个问题。
- **数理能力主要对应不确定性。** Low相对High的Q9均值差−0.031pp，区间跨0；个人密度IQR宽2.275pp，[2.030,2.520]。Q8点预期差却为+2.677pp。给低数理能力者统一加高预期，可能作用错了位置。
- **收入、教育有条件关联。** 低收入相对高收入的Q9均值高0.611pp；高中教育相对大学高0.386pp。其背后可能是接触、资源、知识或其他差异，当前回归不能分辨具体中介。
- **年龄值得保留，关系随时期变化。** 全跨度60岁以上相对40岁以下的Q9均值差+0.551pp，但2024、2025年的控制后平均差为负。它不等同于之前的组中位数统计；均值还受分布尾部影响，不能据此给老年人指定固定悲观程度。
- **本人过去信念是更强的可观测线索。** 在相同的96,683条有效相邻回访记录上，上述人口变量对同月个体差异的解释比例约1.25%；加上本人上期Q9均值后约32.77%。上期系数0.557，[0.534,0.580]；对当期/上期两端各按月缩到1%—99%分位数的敏感性检查为0.582。不能把它直接称为人的心理更新权重，也不能把32.77%解读成因果贡献。

这些结果支持“人口特征分别影响接触、判断和不确定性”的方向。它们没有证明购买频率就是性别效应的全部来源；当前核心数据没有真实家庭购物责任和商品购买频率。

## 2. 模型丢失个人差异的证据

复用八期已有回答，保留各方法同一有效生成支持，先将同人同月可用生成取平均，得到756个完整人月。平均生成只是这次诊断，不替代原来的逐遍正式评价。

在每个月内看“上期高的人，这期是否仍相对高”：真人的关系斜率为0.273—0.844，LLM自行更新为0.141—0.368，不给本人历史为−0.022—0.024。年龄、收入、数理能力各组都观察到模型相对真人保留较少上期位置。它与差异被压缩的现象一致，不能唯一确定是提示措辞、信息配置还是模型本身导致。

方差恒等式也逐月核验：本期方差＝上期方差＋更新方差＋2×上期与更新的协方差。模型的更新往往抵消个人原有位置；多加入随机扰动或加宽概率区间，不会自动修复这种抵消。恒等式解释算术来源，不是心理机制的因果证明。

## 3. 对五点建议的具体处理

### 购买频率：现在已有分类数据，提示也要明确作用

已从原CE Diary重新读取、按官方类别映射补出2,835个家庭周、1,440个家庭的分类购买日数。食品在家消费、外食、家务用品及服务、个人护理用品及服务分别保留每周0—7天、缺失和支持状态；各类别日集合的并集全部复现旧总日数。一天多条记录仍只算一天。

下一步匹配整条频率向量；先核对共同画像字段和价格类别对应，再进入模拟。当前源是2020Q4的已修订数据，只是回顾性代理，不默认适合早期B预测；一个家庭两周也不能当两个独立家庭。零记录与不完整日码不冒充真实零购买。

新的提示明确表达：“更频繁购买的类别，其价格变化对你的物价印象有更大的影响。”保留判断持续性的步骤。先比较**同一频率数据，有无这条作用说明**；再比较匹配与置换。这样能看清数据字段本身是否有效、明确机制是否有效、人口匹配是否有增量。

### 原有信念：把身份说清楚，允许不变

实际八期提示没有“不要照抄”，只说明这些是过去问卷中报过的预期。旧v1里的“可自由修改”也没有进入本次v2路径。已准备单独增加的说明：

> 上次问卷记录的是你自己的信念，是你当前判断的起点。依据新信息决定保留或调整；回答不变是允许的。预测窗口向前移动一个月，调整幅度没有固定规定。

候选位置紧接本人历史之后、问卷之前；离线已验证移除新增块后全文恢复原提示，原始先验、P/E和Q8/Q9逐字保留。没有硬规定照抄比例，没有把“允许不变”写成“必须不变”。当前只是候选，对照运行才能确认效果。

### f与Events：应当共同决定被唤起的联想

可以把过程理解为：**某个事件出现 → 与个人已有经历产生联系 → 想起一种影响过程 → 修正原有信念。** Andre等的研究同时支持事件提示与个人经历相关联想，不能把居民永久分成只懂成本或只懂需求两类。[原研究](https://www.econ.ku.dk/cebi/publikationer/journals/SubjModelsRevision.pdf)

首先对同人随机交叉分配不同联想提示，检验LLM能否响应，这是实验分组。若要构造代表性人口，则需外部调查中**给定事件、年龄/教育等条件下的理解类型分布**；只有总体比例不足以证明个体匹配。未获得这些资料前，不把随机比例说成美国居民真实比例。相同人的长期背景保持，事件可以改变当期先被想到的过程。

### 年龄与性别：保留传导机制，避免固定标签

年龄进入“经历—记忆—事件联想”，不是固定提高答案。此前历史数字版/文字版无改善，只否定那两种实现尚未证明有效；新的候选应检查当前油价或政策事件是否真的唤起相关过去经历，不再仅堆历史文字。

女性差异通过购物分工传导有一手研究支持；原论文也发现共同购物时性别差距较小。其机制是购物责任和价格接触，不能给所有女性一律更高频率。[原研究](https://www.nber.org/papers/w26837)。当前CE侧车没有经核对的个人购物责任，SCE性别也尚未进入现有模拟P；此项统计不能宣称已经实现性别→频率匹配。

### 控制变量分析：作为设计依据，保留识别边界

用调查权重，每个月权重总量统一；吸收月度共同因素，对同一个人的重复回答按人聚类计算区间。没有加入个人固定效应，因此人口组系数仍可能混入个人稳定的未观测差异；上期系数也包含测量误差与持久差异。

月度共同因素吸收后，这套回归不能估计同月共同CPI、利率或事件的平均影响。后续要检查事件×人群的不同反应，需另接同口径E时间序列并设计互动项。当前也没有足够观测直接检验购买责任或记忆中介；简单模型未复现某个结果，不代表推翻文献。

本轮完整画像分析排除了未知性别/其他控制字段和非正权重，仍可能有缺失选择；没有重建完整调查设计的方差。Q8沿用有限且绝对值≤100的清理口径，不断言其他值必然都是填写错误。全跨度结果只作描述；若后续用数据估计行为类型、分配概率或更新参数，须在单独训练期拟合并另做验证。
