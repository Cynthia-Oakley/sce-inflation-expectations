# 年龄经历进入P：数据、事件与组合方案

2026-10-12。设计讨论，未接入模拟、未改变P/E或运行配置。补充[已有年龄结果](age_reporting_followup_20261012.md)。

## 1. 我们并非只能取得三档年龄，但也不能恢复精确人生轨迹

目前正式Persona仅传三档年龄。原始SCE另有Q32，记录新入组时的自报年龄。年龄组三档不能精确反推年龄；有Q32时，应取原始回答，而不是用组中点猜。

本次核查最近四时期实验的192条居民月记录：

- 19条能找到同月Q32。
- 168条能找到此前1—11个月的Q32。
- 5条只有13个月前的Q32，需要单独核查随访与身份连续性。

同月是该次回答时的自报年龄；回访者缺生日，通常只能推断当期年龄的窄范围。例如入组时自报65岁，数月后的年龄可为65或66岁。入组年份Y、年龄a对应的出生年候选通常为Y−a−1或Y−a；不能把一个任意选择的年份称为真实出生年。

上述192条不必然是192个不同人。完整来源与边界见[年龄来源汇总](age_source_followup_20261012.json)。逐人年龄来源及推断区间仅保存在`outputs/sce_age_source_followup_20261012_v1/age_sources_private.json`，没有加入P或发给模型。

**路线A：** 允许使用已声明的当期历史画像，继续审计原始Q32及时间关联。**路线B：** 取截止前已经公开的人口资料，合成年龄与出生年代，随时间保持同人连续；合成年龄可以明确设定，但不叫作恢复当期真实受访者的年龄。

年龄还不能证明出生地、移民史、家庭购物、接触政策或记住某次事件。全国通胀历史是年代背景代理，不能自动变成个人亲历。原始调查年龄也未得到独立身份资料验证。

## 2. 三种方式都可行，各自回答不同问题

### 数据型

保存从指定起点至截止点的CPI历史，优点是透明、方便核查和计算。候选来源是[BLS历史CPI表](https://www.bls.gov/cpi/tables/supplemental-files/home.htm)。优先考虑同一口径的CPI-U未季调数据，但仍核版本和历史可得性，不把当前下载版本自动视为过去版本。

“每年同比”需要定义清楚：全年平均指数相对上一年，和当年12月相对上年12月，是不同口径。当年尚未结束时，不能补入未来全年值；不完整年度不默认插值。

**进入模型的方式：** 完整年序列保留在数据层；首轮可用简短阶段统计或少量代表性数字。直接给几十年表格也可以作实验对照，但它可能让模型按经济研究者的方法运算，而不是模拟普通居民的记忆。

### 事件型

保存通胀、油价与利率政策的重要阶段或事件，按发生时间、可得来源及个人当时年龄匹配。候选原始来源包括[Federal Reserve History](https://www.federalreservehistory.org/essays/great-inflation)。

只取中性事实，不把“政策失败”“某次政策必然导致未来通胀”等事后评价直接写成居民信念。事件发生在出生后不等于被记住；当前自有住房也不能证明过去曾经历某次房贷利率冲击。

**进入模型的方式：** 少量有来源的阶段描述。首先作为可经历的共同背景，不默认每人懂政策传导、经历过失业或形成某种央行信任。没有事件注意力数据时，应标明暴露/记忆是假设。

### 组合型——优先建议，尚未冻结

底层保存完整价格历史与中性事件库；输入用若干阶段摘要、少量价格数字和少量相关事件。数字帮助约束叙述，事件提供持续性与政策转折的背景。

第一版不增加一套人格、不指定个人未来通胀率、不写长传记。阶段数量、数字数量、记忆起点与权重尚未冻结。与纯数据或纯事件相比，这种组合改变了信息集合，因此不能把结果差异全部归因于“文字呈现更好”。

## 3. 6岁、成年还是出生：怎样选择

[Malmendier与Nagel](https://eml.berkeley.edu/~ulrike/Papers/InflExp_44.pdf)的作者稿建立随年龄变化的经历学习规则，以出生之前的信息不计入个人经历为边界；它不是对“6岁起能记住年度CPI”这个命题的验证。

因此，6岁可作为童年环境代理的候选起点，18岁可作为成年消费阶段的研究约定；两者都不称官方阈值或最优起点。童年物价可以经家庭环境影响认知，也不能据此断言儿童关注官方利率。

先看相邻出生年及不同起点会使经历摘要变化多少。如果很稳定，保留区间即可；若遇到关键事件边界，保存多种可能背景，做敏感性。不要为拟合当前SCE而挑一个最好的出生年或记忆起点。

## 4. P/E分工

- **历史E/数据层：** CPI、利率与公开事件本身，包含观察期、公布时间与来源。
- **P：** 年龄/出生年代来源，以及按这些来源构造的长期经历摘要。明确它是个人记忆的代理，不是观察到的真实记忆。
- **本月E：** 该居民当前的家庭价格与新闻视图，保持原先匹配规则。
- **B：** 在这些输入下回答一年期问题，不通过提示强制指定持续性、情绪或概率取整习惯。

## 5. 建议的准备顺序

1. 完成年龄来源、生日区间和5条较旧来源核查，保存侧车，不直接改正式P。
2. 为既定截止点归档长期价格与事件来源，核口径、修订和未完成年度。
3. 先生成组合摘要草稿，保留数字型、事件型为候选；登记缺失及美国长期居住等假设。
4. 另做同一事实集合的数字/文字表达检查，区分信息差异与形式差异。
5. 准备原P/E、共同历史背景、年龄对应背景的配对输入。若增加新历史指标，同信息基线也应能使用相应信息。
6. 核验完整提示，另登记测试用途、月份、种子与具体预算后才真实调用。
