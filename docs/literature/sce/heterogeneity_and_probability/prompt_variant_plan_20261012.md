# 年龄经历与等价提示：候选落地方式

2026-10-12。草案；尚未构造历史经历数据包、接入P/B或批准真实调用。补充[年龄与概率实测](age_reporting_followup_20261012.md)。

## 一、提示分成固定部分与个人部分

保持官方一年期问卷含义、十档顺序、模型、温度0.5与计分方式一致。

**个人部分：** 已核查的年龄组；若有依据，增加年龄/出生年代范围；再加短的历史物价经历摘要。模型看到自然语言，审计文件另存每条摘要的来源、口径、截止点与合成状态。

**固定部分：** 该居民原有画像、家庭价格视图、新闻视图、调查问题与输出格式。不因为测试经历模块而同时改变新闻50/50、政府/央行信心、价格窗口或报告精度。

Core和Normal应采用同一套年龄/经历合成原则；只有Core通过模型提示回答。Normal的统计投影若仍只读旧人口字段，新经历不会自动生效，接入时要另核其映射并记录覆盖范围。

## 二、经历如何生成

1. 从入组Q32与调查年月构造出生年份区间；若只知年龄组，保留年代范围或按有来源的年龄分布抽样，不能默认所有人位于组中点。
2. 补全国长期价格历史，并核定采用同一口径的水平/同比指标。只截取目标信息截止前的阶段，不让“全年2021物价走势”进入年初2021。
3. 区分从出生开始的环境暴露、从成年开始的消费经历。论文的学习规则与本项目简化摘要分别记录，不能把二者称为完全相同。
4. 先用透明的固定窗口摘要；若进一步估计衰减/更新参数，训练和选参仅在预先规定的开发范围，不根据被评价月份选最合意的记忆长度。
5. 不向模型预填个人未来预期值，也不把真实Q9均值、精度类型或零档数写入P。历史宏观经历不是过去问卷答案。

## 三、呈现示例

**下面是形式示例，不是已经由数据算出的个人经历：**

> 你属于60岁以上的年龄组。你的长期价格环境摘要包括〔依据该年代数据得到的阶段〕，最近的价格变化是〔该居民已有价格视图〕。结合自己的长期经验，以及这次实际接触到的信息，判断未来12个月物价怎样变化。长期经验没有规定一个正确答案。

最终填入阶段必须由数据生成，不靠语言模型自由补人生故事。这里的“长期经验”是合成代理，不能在论文中写成观察到的真人信念。模型的训练知识泄漏问题仍然存在，补经历并不解决它。

## 四、三种等价表达模板

共享占位字段：`age_group_text`、`experience_summary`、`personal_environment`；每组实际填入内容必须相同。

- **形式A：** “你的年龄组是〔age_group_text〕。你的长期价格经历背景如下：〔experience_summary〕。你近期接触到的信息如下：〔personal_environment〕。”
- **形式B：** “你是一位〔age_group_text〕的居民。长期价格经历背景：〔experience_summary〕。近期接触的信息：〔personal_environment〕。”
- **形式C：** “居民画像：年龄〔age_group_text〕。长期价格背景〔experience_summary〕；近期所见信息〔personal_environment〕。”

之后附同一官方问卷及输出约束。模板不添加“更焦虑”“更乐观”“不擅长计算”之类新属性，也不改概率题提示。这三种形式是格式稳健性候选，不是三种人格。

先在配对测试中让同一人分别看到三种形式，检查差异；如果后续采用一种形式，则按预先规则固定，不按真实SCE拟合效果给每个人选模板。若确有选择多个模板的理由，也需固定个人模板种子并跨月保持，不以每月重抽制造人际差异。

## 五、怎样区分有依据的经历作用与措辞作用

先做经历主对照：

1. 原P/E，保留已有年龄标签。
2. 原P/E＋所有人相同的历史价格背景。
3. 原P/E＋与个人年龄范围对应的经历摘要。

第一与第二组区分增加历史信息的作用；第二与第三组区分不同经历匹配的候选作用。各组信息量、长度与用语强度要尽量相当；如果原事实集合不同，不能宣称“只变了匹配”。可另加同一组经历摘要在人群中固定置换，保持总体信息库存不变；置换并非知道了真人的正确经历，只是对年龄代理匹配的对照。

措辞变化另做小样配对稳健性检查，避免一次形成大量全交叉配置。模板导致的波动、同模板重复生成波动、个人属性导致的差异分别报告。更有价值的结果是：人口匹配的作用稳定，超过措辞噪声，并改善群体/分组拟合；不是三种模板答得不同就算成功。

## 六、如果将来真正做SFT

SFT需要用输入—示范回答训练模型权重；它并不等于换几句话。届时要明确训练模型的可得性、训练资料、是否使用真实历史问卷、保护范围、成本与样本外评价。训练月与评价月必须分开；更新权重的模型应与原模型在相同P/E下比较。

当前可以先完成输入模板与机制验证。简单的格式示例也可能锚定数字；不要用含某个特定通胀值的少量示范，悄悄把该数字当普遍预期。只有稳定证明提示不足、且有合适训练数据时，再讨论权重训练。
