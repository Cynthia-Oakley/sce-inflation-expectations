# 下一步讨论方案：经历、解释与作答分开验证

日期：2026-10-12。状态：研究草案，未冻结新月份、人口数、参数、预算；不修改旧实验，不启动新API调用。

## 1. 整体框架

**P：过去经历与相对稳定的个人特征 → 匹配E：此人接触到的价格/新闻 → B：理解未来12个月 → B：填Q8/Q9 → 统一计分与评价。**

已有央行信心、消费篮子、新闻50/50配置与结果保留。此轮的目标是补充一个可区分的机制，不同时加入多个心理标签，更不直接要求模型“答案分散一些”。

## 2. 优先方案一：长期通胀经历

### 解决什么

当前P有人口标签，却缺少居民长期经历的物价环境。所有人看到相似的近期统计表，可能使用相似的判断方式。这是待检验解释，不能仅凭输出相似认定原因。

### 如何构造

1. 审计SCE可用年龄字段。如果正式输入只有年龄组，先保留出生年范围；需要具体年龄时，用有来源的人口年龄分布抽样并保存不确定性，不把组中点冒充真实年龄。
2. 取得对应年代至信息截止点的美国通胀历史，保留统计口径、发布/修订来源。路线B只使用截止前已可获得的信息；年代价格是全国经历代理，不是受访者真实购买记录。
3. 准备短的“物价经历说明”：经历过哪些阶段、此前与近期涨幅是否差异明显。先不把全部几十年统计表重新塞给每个人，也不预填一个未来通胀数字。
4. 若构造加权记忆，区分忠实复刻论文学习规则与本项目简化代理。先登记公式、起始年龄、衰减范围及敏感性；未核验的参数不从论文猜数，也不按当前测试月误差选最好的值。
5. 同一合成居民跨月保留同一年龄/年代经历；只增加时间推进带来的信息。没有记录时不编造失业、债务、战争亲历等故事。

### 提示呈现示例

以下仅是**模板，不是已计算出的真人记录**：

> 你的年龄对应的生活阶段，经历过〔数据支持的物价环境〕。过去〔指定时间段〕与最近的涨幅〔关系描述〕。这些是你长期生活环境的代理，并不意味着你熟悉所有官方统计。结合你实际接触的家庭价格与消息，回答未来12个月的问题。

应避免“因为你年长，所以预计高通胀”之类预设答案的句子。最终模板还需检验是否把一般居民变成使用几十年宏观数据的专家。

### 需要的准备与局限

主要工程是年龄口径、长历史CPI来源与短描述构造；可行性较高，但当前尚未补齐历史序列。生命周期经历只能解释部分差异，同龄人的不同经历、迁移和个人购物仍未知。额外信息量也可能影响结果，因此要有同信息对照。

### 离线与后续对照

- 原P/E；原P/E＋所有人相同的历史背景；原P/E＋年龄对应的历史背景。前两组用于分辨“多给了历史信息”和“经历与个人相匹配”。
- 另检查相同年龄代理在不同月份的稳定性，以及跨年龄组差异是否符合现实数据；不以年龄组必然单调作为验收。

三组方案尚未产生提示包或接入引擎。不能称可运行。

## 3. 优先方案二：概率作答习惯

### 解决什么

模型几乎总为很多档位留概率，而真人常集中在少数档。我们要判断是预期本身不同，还是表达精度不同；“非零档少”不等于“个人很确定”。

### 先做零API核查

1. 在预先划定的历史开发样本中，统计Q9概率是否集中于1/5/10等倍数、零档数、尾部概率、跨月稳定性，并按numeracy分组。
2. 分析时不把“刚好是5的倍数”直接认定为取整类型；精确值也可能落在倍数上。按文献把可行精度保留为范围或候选类型。
3. 比较同人的Q8取整与Q9精度，但不视为相同机制。分布题有合计100约束，和论文的单个概率题不同。
4. 将已有模型原回答做**独立的机械敏感性分析**：不同报告精度会改变多少中心、宽度及计分器拟合分支？保留原输出；这种加工只回答计量影响，不作为新的真人模拟结果。

分配报告习惯时，只从训练/开发资料估计条件分布；路线B另核历史发布时点。被评价当月的真实Q9、非零档数、真实个人不确定性不能变成该人的P标签。若历史证据不足以支持“低numeracy一定粗报”，保留未知或做明确的情景对照，不自行规定该关系。

### 两条可能的实现

**提示方式：** 先检查原提示是否已允许0。现有诊断确认原提示允许0，因此重复说“可以填0”只是语义检验，不是新增人口机制。更进一步的粗/细报告习惯只能在历史数据支持下分配，并对同一人保持相对稳定；不能要求所有人给某几个档位0。

**明确的报告步骤：** 保留模型的原始判断，另外输出按指定报告习惯填写的问卷。该方式能区分信念与表达，但多一步输出不等于成功识别了人的真实信念，合计100处理及额外成本需要验收。

### 可用于讨论的中性澄清

> 问题是未来12个月价格水平的变化。涨幅降低但价格仍上涨，与价格下跌是两种不同情况。按自己的判断分配概率，合计100%；无需为了填满表格给每档正概率。点回答与概率分布不必被强制设为同一个中心。

这段不指定未来涨幅、零概率比例或居民必然偏差。使用时仍须与原官方题意逐项对账，作为独立对照；不能混入主提示后不留版本。

### 验收重点

同时看原始档位形状与冻结计分后的结果。概率取整会改变拟合分支，不能为消除尾部而修改计分器。只让零档变多，却使全国中心或人际分布更差，不算成功。

## 4. 后备方案：有数据依据的人格画像

UAS1目录已确认有人格、numeracy与人口部分。先取得合法访问，检查同人有效记录、计分方式、权重、年份与年龄/收入/教育共同支持；没通过不能先按假想正态分布造五种人格。

若合成，使用同一来源的整行个人记录作参考，保留性格之间及与numeracy的联合关系。再依据共同人口特征匹配SCE，公开标为统计合成。跨调查匹配不能恢复未观测的“SCE真实人格—通胀回答”关系，也不能将它和独立CE/Gallup抽样拼起来就称为真实联合分布。

先验证一种与信息解释有明确关系的构造。大五人格、幸福感、风险偏好、政策信心分别命名，不把它们互换。奥地利研究提供候选关系，不能替代美国验证。

Core与Normal采用相同的画像构造原则；若Normal仍由只读旧人口字段的统计投影产生答案，新属性不会自动影响它。接入前必须核查这条路径，不能只改善Core后宣称整个人口机制已更新。

## 5. 如何区分真实差异与模型随机性

- 同一个人的P/E固定，多次生成：估计模型本身的波动。
- 同义措辞但事实不变：估计格式影响；保留档位身份、问卷含义，不用新措辞制造居民。
- 只改变一个有依据的个人属性，措辞和E保持：检查模型是否持续响应。
- 判断真实拟合：整体中心、分布距离、人际差异、个人不确定性的分布和分组误差一起看。不是方差越大越好。

主温度先保持原0.5；不以升温替代人格。重复生成与人口合成种子分别记录，以免把采样误差、分配误差和模型随机性混在一起。

## 6. 准备顺序与判断门槛

1. **当前已完成：** 文献与数据入口核查、讨论草案、原文归档。
2. **下一步零API：** 原SCE报告精度/跨月稳定性分析；年龄与长历史价格数据可得性审计。开发区间由现有划分确认，不能默默换测试期。
3. **然后讨论选择：** 优先一个机制，写清字段与来源、原输入与新增输入、预期改变、失败判据；只准备输入。
4. **再登记验证：** 选择未用于该机制调整的月份、额外分配种子与重复生成。已有四时期结果看过，不能称新盲测；若没有全项目未见时期，应明确仅为本机制留出检验。
5. **最后才真实调用：** 完整提示验收、预算与数据范围确认后开展。继续使用原计分器，并保存无效回答与全部生成，不按当期SCE误差拒绝采样。

继续研究的最低要求是：对应机制能稳定改变它所针对的现象，并在留出时期维持；同时不明显恶化总体与分布拟合。通过后再扩大人口/月份。任何具体百分点阈值应在看新结果前登记，目前没有承诺必然改善的幅度。

若报告习惯改善了概率形状，却没改善预期中心，说明它解决的是问卷表达问题，下一轮仍应研究信息理解与持续性；若人格提示只增加随机性，应保留负结果并停止堆字段。这些结果同样能说明当前Agent模拟的适用边界。
