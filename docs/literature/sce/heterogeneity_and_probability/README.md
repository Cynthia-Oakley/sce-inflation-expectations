## 先看结论

同一个模型收到相似信息，容易给出相似答案。要改善它，需要补足有现实依据的差异，并检查这些差异是否改变了回答。随机换几个词或者提高温度，主要增加生成波动，不能自动代表不同居民。

这次找到三类相关证据：

- **生活经历：** 人会利用自己经历过的通胀形成预期，年轻人与年长者对近期冲击的反应也可能不同。
- **人格与信息理解：** 新的通胀调查研究发现大五人格能解释部分人口特征之外的差异；但来自奥地利，不能直接移植其系数。美国UAS有对应调查，是候选数据源，尚未取得微观文件。
- **概率表达：** 真人存在不同的取整习惯，0%有时代表很小的概率。这个差别可能影响Q9，却不一定意味着他们对未来物价的看法完全不同。

建议先准备**长期通胀经历**与**概率作答习惯**两个独立方案，人格模块在数据支持核验后再决定。改善总指标、居民之间的差异以及个人不确定性，是三个需要同时观察的目标。
