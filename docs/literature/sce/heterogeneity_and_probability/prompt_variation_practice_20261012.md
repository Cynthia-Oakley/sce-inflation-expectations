# 等价措辞与结构变体：参考实践及本项目用法

2026-10-12。只研究和预设模板；无新付费调用。官方问卷、P/E事实、50/50新闻、既有央行信心模块、模型与温度不变。

## 1. 找到的可借鉴实践

### T0 / P3 / PromptSource：数据和模板分开

[T0论文](https://arxiv.org/html/2110.08207v3)将同一任务的数据用多个模板表达并用于训练；[作者PromptSource工具](https://github.com/bigscience-workshop/promptsource)将提示保存为结构化模板，再把同一数据实例填进去。

**借鉴：** 我们保留一份规范P/E事实，使用独立模板渲染，不让每个模板另写一套事实。**边界：** T0实际做了训练；我们仅借用模板组织方式。其结果不证明在SCE推理时换模板会增加真实居民差异。

### FormatSpread：少量有规则的变化，报告敏感性

[Sclar等，ICLR2024](https://arxiv.org/html/2310.11324v2)用明确的格式规则构造含义相同的提示，再估计不同格式下的表现范围。论文特意将严格格式变化与更自由的改写区分。

**借鉴：** 先检查列表、段落、少量中性同义句是否导致过大波动；报告范围而不是只展示最好模板。**边界：** 我们拟做少数预设模板的配对检查，尚未复刻作者的采样/估计算法。严格语义等价不能只靠我们给模板起了“等价”名字。

### 拒绝采样微调：筛选标准要符合目标

[Llama2 §3.2.3](https://arxiv.org/abs/2307.09288)生成候选回答，用奖励模型筛选，再更新权重。

**可借鉴的流程：** 先准备候选模板，再按“事实没有变、问卷没有变、没有加入未测态度、输出约束一致”筛掉不合格模板，冻结留下的集合。这个是模板质量控制，不称已实施RFT。

不能以“更接近被评价月SCE”或“分散程度更像真人”为奖励筛选回答，再报告为独立模拟。候选答案按目标筛选通常会改变输出分布，不能把它当作自然居民多样性的来源。

### 有来源的自我报告：背景的真实性更重要

[Park等2026修订稿](https://arxiv.org/abs/2411.10109v3)使用真实访谈、结构化调查或组合构建个人Agent。它支持研究更丰富且有来源的背景；不支持从粗人口标签自由编造人生故事。研究任务不是SCE，不能移植其准确度承诺。

## 2. 对当前项目更合适的方案

先设三种**背景说明**：中性书面、简洁日常表达、清晰列表。问卷原文不改，输出JSON不改；数字、日期、单位、政策信心强度和消息原文仍保持一致。

初始候选见[prompt_template_candidates_20261012.json](prompt_template_candidates_20261012.json)。它是文档级草案，不是有效Simulation配置。句型为英文，对齐美国问卷与当前提示语言。

例如只改“下面是你的家庭画像及可见信息”的说法；同一画像和E直接填入同样的内容。结构候选仅改变段落标题和分隔，首次保持各部分顺序一致，不同时检验位置效应。

**不允许混入的变化：**

- “通胀下降”改成“物价下降”。
- 把同比写成环比，把未来12个月写成下个月。
- 把全国统计改写成“你家实际经历了这个涨幅”。
- 新增“你更犹豫/悲观/确定/不会算概率”，或暗示应该填更多0。
- 把原政策信心标签加强、弱化，或改成对所有政府部门的信任。

“生活化”只改表达，不改变信息类别或认知能力。某种口吻若隐含了态度，应归为新行为假设，另有数据依据后再讨论；当前不加入。

## 3. 核验与最小检查

1. 用规范字段生成P/E；保存事实集合哈希。三模板的字段和值完全一致。
2. 问卷、原新闻与输出约束作为锁定文本块，逐字核对；校验占位字段无缺失、重复或顺序混乱。
3. 人工审核几份完整实际提示；字符哈希只能证明文本是否相同，不能证明不同文本语义相同。必要时未来另申请小额语义审查，不现在付费。
4. 候选从6—12个已有画像开始，同一P/E分别用三模板，各生成两次。人数、时期和预算尚未冻结、未授权，不立即进入大规模全交叉实验。
5. 同一模板两次生成度量模型波动；同一人三模板度量格式敏感性；不同人的P/E差别另看。模板副本不是新居民，不能增加人口样本量。

后续如果采用多个模板，个人模板ID应固定并跨月一致；分配比例也只是实验约定，不能假称测得美国人的表达风格分布。主实验暂时继续原模板，候选先做配对敏感性验证。

## 4. 不把改写当作同质化的直接解药

语义相同的模板可能使回答变动，但不能自动说明输出更接近真人。若模板作用大于人口/经历作用，优先处理格式不稳；若作用很小，则把它记录为稳健性结果，继续研究P/E匹配与信息理解。

不同模板的概率也不默认平均成主答案：平均会改变原始回答形状，可能进一步平滑或掩盖分歧。若以后需要集成，应另声明它估计什么，与逐居民模拟区分。

用户本次决定暂不新增概率报告风格提示；该决定不要求删除此前保留的数理能力、央行信心或其它已授权P字段。当前没有改变运行配置、问卷或计分器。
