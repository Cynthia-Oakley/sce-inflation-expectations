# 个人经济经历：从平均值改为时代与价格轨迹

2026-10-12。按用户七点意见修订。当前是可重算的离线输入草案，没有新增真实LLM、付费MCP调用或正式配置切换。

## 1. 实验先做重要的比较

主试移除“只补年龄细节”组；暂不运行年龄细化或措辞附加试验。保留原输入、共同时代背景、年龄对应时代背景三组。沿用四个已用开发时期、每期12人和相同抽样，不重新挑效果好的居民；两次生成的候选请求数从384降为288。文本变长，不能据此声称费用也下降25%。

年龄、时代库和压缩方式都会改变信息；三组对比不能单独识别年龄精细程度或纯匹配的因果作用。样本用于筛查机制，不能证明全国重建成功。新付费运行仍需具体预算与发送范围确认。

## 2. 理论为什么支持这次修改

**经历学习：** [Malmendier与Nagel作者稿](https://eml.berkeley.edu/~ulrike/Papers/InflExp_44.pdf)认为不同代际经历的通胀水平和持续性不同，因而形成不同预期；年轻人的短历史通常使其对近期意外更敏感。这不是“越老越悲观”的固定规则，也不能只用长期均值代表持续性。

**当前信息唤起旧经历：** [Gennaioli等《How Inflation Expectations De-Anchor》](https://www.nber.org/papers/w32633)使用SCE和密歇根调查，发现当前通胀与过去经历的数值相似性可能引起选择性回忆。[本次读的作者稿](https://shleifer.scholars.harvard.edu/sites/g/files/omnuum10626/files/shleifer/files/inflation_june24-1.pdf)首页为2024-06-24，阅读重点为第3—10、15—19及24—27页。它也研究点预测和概率区间回答的差别，但本项目当前不强制注入概率报告行为。

这支持提供上升、反复、见顶和回落的路径。“俄乌战争/油价冲击使人联想到70年代”是一个合理的扩展假设；该文直接验证的是通胀数值和时间背景的相似性，不是某场战争必然引发某种个人记忆。第一版提供可供联想的历史背景，不命令模型把两段历史等同，更不指定未来会持续几个月。

**心理学的边界：** [Koppel与Berntsen研究](https://pubmed.ncbi.nlm.nih.gov/25529327/)显示回忆分布随提示方式及事件类型改变；重要公共事件的突出性不能简单套用个人回忆的青年高峰。因此暂不强制给“青少年经历”最高权重。

## 3. 6岁、10岁、12岁和16岁怎么处理

[John（1999）的消费者社会化综述](https://www.sfu.ca/media-lab/cmns320_06/readings/roedder_john_consumer_socialization.pdf)指出，价格理解随成长发展；8—9岁儿童已有一些价格知识，但价格注意仍有限。其阶段划分约为3—7、7—11、11—16岁，并强调个体差异和边界重叠。本次检查原文第3—4、13页。

选择性记忆论文的实证部分从16岁构造季度通胀经历。这是论文的建模约定，不能说人到16岁才开始感知物价；文中的季度年化涨幅也不同于我们提供的月度同比轨迹，本项目不是其算法复刻。

程序同时准备6、10、12、16岁四套候选。6岁继续保留用户原设定，10/12岁用于检验更成熟的购物感知，16岁提供文献约定的参照。尚未选择最佳值或启动这些对比的API调用。

缺生日时，使用两个可能出生年份，选“两个候选都已越过起始生日后的首个完整日历年”，即较晚出生年＋起始年龄＋1。只声称近似年龄范围；不挑一个更能拟合真实SCE的出生年份。这个保守日历规则与旧版不同，已单独记录，不是实测记忆起点。

## 4. 生活阶段的影响分两层

一层是**接触物价**：童年更可能经家庭购物接触，成年更可能直接承担支出。[购物价格研究](https://eml.berkeley.edu/~ulrike/Papers/paper_DMOW.pdf)支持关注购买接触，而不是把支出份额直接当注意力。

另一层是**记忆被想起**：童年购物少不等于旧经历不会留下强印象；近期性、早期印象和当前相似线索可能同时重要。不能直接推出成年人记忆权重一定高于儿童记忆。

第一版仅标童年、青少年、成年及近似年龄，不编造个人买房/失业/购物分工，也不注入数值权重。程序有可选“童年通过家庭购物接触”的短句，但主试关闭，留给独立的后续检查。成年“几乎全部购物靠自己”不作为人人都成立的设定。

## 5. 程序如何自动生成

以前的摘要也是程序批量生成；本次修订的是过于粗糙的摘要规则。

1. **取年龄来源和当时版本CPI。** 只读原年龄侧车、冻结P/E提示与ALFRED历史版本；不读真实Q8/Q9或SCE指标来选择内容。
2. **对应公共时代库。** 战后、70年代大通胀、80年代通胀回落、90年代/2000年代相对稳定、金融危机、危机后、疫情及之后。边界是研究用分段，不把总统时代当成单一通胀原因。
3. **截取可能经历的年份。** 早于起点或晚于当前历史截止的内容排除；只用上一完整年度以前的历史。本月E仍是原来的信息。
4. **计算价格轨迹。** 每月指数除以上年同月指数减1，得到12个月同比；不使用长区间均值或将环比误作同比。保留起点、终点、最高/最低点和较大的年度转折，按固定规则最多8个节点。
5. **附上有出处的时代背景。** 例如油价冲击、衰退、政策调整、供应链受阻；事实要与可经历时段重叠且已完成。原文来源及核查日期单独保存。所有人共享同一库，不逐人为其写传记。
6. **记录持续与回落。** 辅助说明同比达到5%的连续月份、峰值后首次低于5%的月份；跨时代边界连续计算，不因章节结束就声称冲击结束。5%是描述阈值，不是心理定律。没有观察到回落时写“历史中尚未出现”，不补未来结局。
7. **套用固定句式。** 年代＋近似人生阶段＋背景＋价格节点＋已发生的回落；方法、来源、居住史缺口等留在研究侧车。模型开头仅有一句短指标说明，保留“涨幅下降不等于物价下降”的必要含义。

尚未加入按当前新闻自动重排历史案例的“回忆概率”。初版把对应经历给模型，检验它是否利用当前E形成合理类比；如不足，再单独研究近期性/相似性检索。不能把提供了背景称为已模拟出真人记忆。

## 6. 示例会有什么变化

75岁示意居民可见：70年代油价冲击与滞胀背景，CPI同比从较低水平升到1974年末约12.3%，1976年末回到约4.9%，又在1980年3月升到约14.8%；其后首次低于5%是在1982年11月。这样能够保留反复和较慢回落的经验。

25岁示意居民的金融危机背景则包括：2008年7月约5.6%，2008年末约0.1%，2009年7月约-2.1%；其后回升。它不再被压成“童年平均2.32%”。这些是全国历史的背景代理，不是被调查者真实记得的数字，也不是对当期战争/衰退结果的预测。
