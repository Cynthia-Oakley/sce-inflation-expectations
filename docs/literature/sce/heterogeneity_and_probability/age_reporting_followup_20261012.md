# 年龄、概率表达与提示变化：已有数据的实测回答

日期：2026-10-12。零新增API；没有改P/E、模拟配置或冻结计分器。完整公开统计见[汇总](age_reporting_summary_20261012.json)，可视图见[原阅读页新增区](../news_selection/news_review_20261011.html#age-reporting-followup)。

## 1. 年龄确实值得研究，但关系会随时期改变

范围是本地已取得的2017-01至2025-10，106个月、130,216条受访者月记录。年龄、官方个人Q9均值与正权重共同有效127,793条；不是13万名互相独立的人。使用官方提供的个人密度均值、原月度调查权重和三种官方年龄组，未将年龄组编码冒充精确年龄。

逐年比较的是**每个月年龄组加权中位数，再对该年的月份取平均**。2025只有1—10月，不是官方发布的年度SCE指数。几个有代表性的结果：

- **2021：** 40岁以下3.83%，40—60岁4.44%，60岁以上5.13%。
- **2024：** 三组分别3.01%、3.07%、2.99%，差距很小。
- **2025年1—10月：** 三组分别3.41%、3.26%、3.23%，年长组略低。

全106个月中，年龄组中位数最大与最小之间的距离平均约0.74个百分点。60岁以上减40岁以下的差距平均约+0.65，但约17%的月份方向相反。把各年龄组教育构成统一为同一参考分布后，平均差距约+0.62；这项描述性检查说明教育构成并没有解释掉全部差距，不等于已控制所有因素。

**对设计的意义：** 年龄有信息，但不能写成“年长者总是更担心通胀”。它更适合与所经历的物价阶段、近期变化共同考虑。这也符合[Malmendier与Nagel的经历学习研究](https://eml.berkeley.edu/~ulrike/Papers/InflExp_44.pdf)。不过同组内的个人预期中间50%跨度仍约4.69—5.03个百分点，明显大于组间中位数差距；只添加年龄经历不能保证解决全部同质化。

本次是描述性研究。年龄、出生年代与调查时期彼此联系，也与收入、健康、资产和信息接触相关，不能据此宣称找到了生活经历的独立因果作用。全跨度统计已看过，不称独立盲测，更不据本次差距给模型答案直接加减分。

## 2. 怎样把年龄/经历放进P

建议采用**人口字段＋短经历摘要**，而不是编一篇人生传记：

1. 保留目前真实可核查的年龄组。
2. 若找到同一个人的入组年龄Q32，依据入组时间保留年龄/出生年范围；没有生日时，不能把出生年份写成精确事实。
3. 结合信息截止点之前的历史价格，为该年代生成简短的物价经历背景。全国价格只是经历代理，不能称真实家庭购物史。
4. 摘要描述经历过什么环境，不规定应预测多少，不编造失业、收入冲击、移民、战争亲历等个人事件。
5. 同一人的合成属性跨月保持一致，增加新经历时留版本，不每个月重新抽一套性格。

官方问卷Q32只问新加入者。本次Q32当行有效15,830条；若允许查找同一人在此前12个月内已回答的Q32，123,257条记录存在年龄来源（约94.7%）。这是**可得性计数**，尚未逐人构造生日/年龄区间，也不表示正式P已更新。路线B仍需先从当时已发布的人口资料构造合成居民，不能取目标月未公开的真实入组年龄。[官方问卷](https://www.newyorkfed.org/medialibrary/interactives/sce/sce/downloads/data/frbny-sce-survey-core-module-public-questionnaire.pdf)

实际模板与对照方法见[提示方案](prompt_variant_plan_20261012.md)。短叙述是信息载体，后面的经历计算与来源才是依据；文字变多本身不能证明经历机制有效。

## 3. 概率表达会不会影响最终指标

### 先区分两种中位数

SCE总体一年期指标的流程是：**十档概率→个人密度→个人均值→跨人中位数**。个人曲线的50%分位数是另一个量。这两者都会受到概率变化影响，不能混称。[纽约联储官方FAQ](https://www.newyorkfed.org/microeconomics/sce/sce-faq)

### 数学上没有“自然抵消”的保证

先用固定区间代表值做简单说明。若概率误差是δ，个人均值改变为各区间代表值乘上相应概率误差后加总。概率必须合计100，所以各δ加总为0；但正误差和负误差落在不同的通胀区间，通常不会在均值上抵消。

即便个人误差在人群中平均为0，中位数也不保证不变。例如三个人原来为1%、2%、5%，分别变化−0.1、−0.1、+0.2个百分点，平均变化为0，但中位数从2%变成1.9%。SCE还要做非线性曲线拟合，因此更不能仅凭“随机误差”断言可忽略。

### 用已有模型答案做了机械敏感性检查

沿用四时期、两组、两次生成的768份原记录；原先合计99%的1份继续排除，767份有效问卷均保留。只改变概率表达，再用**项目冻结的近似计分器**重新计分，不调用模型，不修改任何原回答。

- **5%倍数、保持总和100：** 16个实验单元的群体中位数绝对移动平均0.182、最大0.374个百分点。
- **10%倍数、保持总和100：** 平均移动0.493、最大0.974个百分点。
- **原始每档条件无偏的5%随机取整：** 单次固定种子下平均移动0.107、最大0.282个百分点。这不是多种子平均，也不能据它认定拟合结果存在特定期望偏差。

作为辅助，用同样本调查权重加总，5%确定性取整的平均绝对移动为0.184个百分点，结论相近。若问的是每个人曲线的中位数，5%确定性情景中的个人绝对移动中位数按单元平均约0.117个百分点，也不是零。

5%确定性情景中14/16单元向上移动，不能说“上下自然抵消”。本批没有从beta切换到triangle/uniform的家族变化，但仍出现影响：同一家族内部的支持范围、约束点和参数拟合也会变化。该检查不能指出哪种取整最真实，不能把向上移动当作值得选择它的理由，也不是官方NY Fed算法的再运行。

### 是随机特征，还是与人口特征相关

128,244条十档概率与权重有效的真实记录中，按每月权重归一化后，全跨度约80.3%的问卷所有档位落在5%倍数上，47.6%落在10%倍数上。**落在网格上只是作答形状，不等于已经识别出取整习惯。** 真实信念集中、题目加总约束也可能导致这些数字。

相邻月同人的网格类型约66.9%保持一致；按两期类型边际分布算的偶然一致约37.3%，kappa约0.47。它有个人持续性，不能只视为每月独立随机噪声；但变化也不少，而且可能混合了信念变化与表达变化。

人口关联存在，却没有简单的“数理能力低就一定粗报”：高/低numeracy的5%网格占比分别81.7%/77.8%，10%网格占比分别46.2%/49.9%。控制月份、年龄、教育、收入后，低numeracy与5%网格占比低约3.26个百分点相关。七个人口类别参数在月份内仅解释约0.76%的该二元作答形状变异；不能据人口标签可靠指定个人风格。

调整模型的完整样本126,724条，剔除了空字符串和未知类别；人员聚类区间仅作观察性诊断，不是官方复杂调查设计区间。没有把上述模型训练成P生成器。

### 是否可以暂缓注入

**可以暂缓强制注入，但不能写成已证明影响很小。** 当前检查显示影响足以改变对改进幅度的判断；然而我们尚不知道真实居民适用哪种报告机制。建议继续保留模型原生概率为主结果，将报告精度敏感性列为重要测量限制与附录检查。暂不统一取整、不删除通缩尾部、不按真实答案选择取整参数。

只有取得可信的报告习惯分布，并在留出验证中确认改善了原始问卷形状和最终分布，才考虑将其作为B机制。数学说明与可复跑口径见文末。

## 4. 轻微提示变化怎样落地

轻微改写本身不是SFT；SFT还要更新权重。但我们可以在不训练模型的情况下，做两类清楚区分的提示变化：

- **有事实差异：** 不同居民的年龄与价格经历不同，使用有来源的对应摘要；这是P的候选扩展。
- **只有措辞差异：** 相同事实用三种等价句型表达，问卷、档位、信息和输出格式完全一样；这是对措辞敏感性的检查。

如果只是换句型就产生很大变化，这说明格式影响较大，不代表居民差异被成功模拟。建议先生成固定模板，由同一合成居民跨月沿用；验证真实属性的作用是否大于措辞和生成随机性。完整模板与落地步骤见[提示方案](prompt_variant_plan_20261012.md)。

## 数学补充

把概率写为0—1的向量p，取整后是p+δ，并有Σδ=0。固定代表值c的线性均值误差为：

`Δμ = Σ c_j δ_j`。

因为Σδ=0，存在界：`|Δμ| ≤ (max(c)−min(c)) × ||δ||_1 / 2`。该界针对固定代表值/固定支持，不是对SCE动态参数拟合的误差承诺。官方总体指标为`M = weighted_median(g(p_i))`，g代表个人密度拟合后均值；`E[δ | p]=0`不能推出`E[g(p+δ)−g(p)]=0`，也不能保证总体中位数不动。

若每个人的计分误差都能被同一个ε界住，使用同一权重的中位数移动最多ε。但少量较大的个人误差、接近排序中间的共同方向变化，都不能仅凭平均误差小排除。

对个人密度中位数q，固定且光滑的密度下，小扰动近似为`Δq ≈ −ΔF(q) / f(q)`。中心附近密度较低时，CDF的小变化也可能带来较大分位数变化；当拟合支持或家族改变时，该局部近似不再足够。

随机情景使用保持合计的成对随机取整：每步对两个未完成档位增加/减少相同质量，两种方向的概率令各档位条件期望保持不变。它只用于区分原始概率无偏与非线性计分，不是假定真人采用这种算法。
