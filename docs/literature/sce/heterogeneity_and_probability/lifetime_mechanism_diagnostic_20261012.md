# 个人通胀经历为何没有改善：输入、回答与未来 CPI 的离线核查

2026-10-12。用户要求解释失败原因、P/E 的缺口和潜在训练记忆。本轮没有新增模型调用，没有修改模拟配置或计分器。下面将观察、解释和拟议改动分开；四个时期、每期12人的结果是开发诊断，不代表全国。

## 1. 已经看清的变化

沿用文字版试验的同期三组和两次生成，Q9同人同次共同有效93组配对，涉及最多48个人月；两次生成不是增加了一倍真人样本。Q8共同有效96组。三组Q9样本中心误差仍为原输入0.534、数字经历0.879、文字经历0.742个百分点。

新增核查发现：

- 相比原输入，数字经历下个人Q9密度均值平均下降0.531个百分点，93组中68组下降；文字经历平均下降0.365，63组下降。变化偏向共同下移。
- Q8直接点回答平均只下降0.119与0.121个百分点。因此，新增经历影响了概率分配，不能把全部差距解释成点预测下调。
- 原始Q9给“通胀至少8%”的平均概率由20.74%降至数字版15.74%、文字版18.57%；数字版主要增加了0—4%档的概率。这是在计分之前已经发生的变化，不是单由beta拟合产生的现象。
- 跨人预期均值的中间50%跨度：真人4.100，原输入0.786，数字0.481，文字0.563个百分点。这是人与人之间的差别，不能与一个人所报概率区间的宽度混为一谈。
- 同月12人的全国统计块逐字相同，包含当前CPI、失业/就业、分类价格及六条12月序列；新闻和画像虽不同，这一共同信息块一直保留。48个人月中8条住房状态未知；合成篮子只分食品、汽油、现金住房、其他，“其他”占比在31.1%—88.8%之间。

已有理由中，原/数字/文字三组96条分别有84/85/88条出现回落、放缓等宽泛词汇。它说明回落叙述在原输入中已经很普遍；不能用词频证明经历导致了回落，更不能把模型理由当真实推理过程。

## 2. 最值得检验的原因

**我们把经历做成了阅读材料，尚未实现经历如何形成并更新信念。** 所有人收到完整宏观信息，加上一段包含危机、回落、政策反应的经济史，可能共同增强“通胀会回归正常”的判断。这是与回答变化相容的假说，还没有被本试验识别为原因。文字版同时改变篇幅、数值精度与年龄提示；历史块放在问卷前，位置效应也尚未单独识别。

经历理论要求的不只是“读过什么”。Malmendier与Nagel的模型用个人经历更新对通胀水平和持续性的判断，近期经历权重随年龄变化；文献并不要求所有老人都更悲观。[作者稿](https://eml.berkeley.edu/~ulrike/Papers/InflExp_44.pdf)

Gennaioli等的选择性记忆模型进一步说明：当前情景可以唤起相似的旧经历，而非每次均匀回顾完整历史。对战争新闻唤起1970年代经历的具体实现仍是项目假设，不能称论文直接验证了这个提示词。[NBER论文](https://www.nber.org/papers/w32633)

**公开信息库与居民信息集尚未充分分开。** 当前模拟接近在答卷之前给所有人做了一次宏观信息说明。真实居民的知识、关注点及接触时点并不一致。新闻50/50分配只处理了新闻接触，未处理共同统计表的接触差异。宏观信息应继续完整保存以便审计，但传给某个人的内容应由其可核查或有依据的合成接触机制决定。

**同质化也属于B的检验问题。** 即使不同人收到了不同资料，同一语言模型仍可能用相同的经济解释给出相近答案。人口标签本身不保证产生与真人相同的行为差异；提高temperature或随意改写不能证明复现了人群异质性。

## 3. 每类变量应承担什么作用

不是每个字段都必须显著影响答案；其作用应有数据支持、允许随时期改变。

1. **年龄和生活经历：** 约束可能经历的时代、近期信息相对既往经历的新颖程度、可能被唤起的记忆。不能直接设成“老年通胀预期加若干点”。本项目106个月数据中，2021年老组较高，2024年趋同，2025年1—10月方向略反；同年龄组内差异仍很大。
2. **收入、就业、家庭结构：** 用于构造支出结构、预算压力、工作和生活接触。收入档不等于近期收入冲击，就业状态不等于失业恐惧。若要加入近期冲击，须有实测字段或明确的条件分布，不凭标签编造生活事件。
3. **住房、通勤、购物责任、购买频率：** 决定实际接触哪些价格、多久接触一次，以及租约更新等事件何时发生。当前合成支出占比不提供这些信息。可以用CE及其他调查做联合匹配，但不能声称恢复了SCE个人真实账单。购买频率与金额权重不同，相关实证支持用接触频率研究预期形成。[D’Acunto等作者论文](https://eml.berkeley.edu/~ulrike/Papers/paper_DMOW.pdf)
4. **地区和州：** 只有接入对应地区价格、合同或政策变化时才成为明确的暴露变量；仅写州名主要依赖模型自行联想。地区差异本身不是保证改善的变量。
5. **教育、数理能力和经济知识：** 分别涉及信息理解、数字/概率表达与经济概念，不应合成一个“聪明程度”。本项目既有核查发现数理能力与Q8、个人不确定性关联较强，Q9中心的差异较不稳定；不应要求所有指标沿同方向变化。
6. **美联储信心、政府信心：** 可能影响如何解释政策消息、是否相信冲击会持续。现有Fed标签是合成分配，测量的是对主席做正确经济决策的信心，不能等同于“相信通胀会在一年内回到2%”。政府信任、政策知晓程度与央行信任需分开；不同变量的联合分布尚未充分掌握。
7. **价格、新闻、政策信息E：** 价格事实给出发生了什么；新闻提供可能的原因和未来情景；政策声明给出当时的意图与判断。公开存在、被看见、被理解、被相信是不同环节。相同事实可有不同解释，但不能为了增大差异而随意改造事实。
8. **问卷理解与概率表达B：** 需要分别评价Q8点回答、原始Q9十档和密度派生值。继续遵守用户的决定，暂不强制注入粗报、取整或零概率行为。问卷措辞会改变真人关注的对象，因此也不能为追求更大离散程度而把SCE“通胀率”问题换成“你个人的支出涨幅”。[纽约联储措辞实验](https://www.newyorkfed.org/medialibrary/media/research/staff_reports/sr443.pdf)

尚缺而值得优先核查的，是个人价格感知、购物接触、持续性判断与信息理解；性格、政治态度、社会关系等可列次要候选。目前没有证据说明再添一个性格标签就能解决问题。

## 4. 怎样合理引入差异

建议先建立可检验的链条：**家庭处境 → 实际接触的信息 → 感受到的变化 → 对持续时间和政策效果的判断 → Q8/Q9回答**。

例如租房家庭能否遇到涨租，取决于是否续租和租约信息；有汽油支出不等于一定负责加油。先构造有来源的接触，再让模型作答，比直接写“你更关注某项”更容易检验。但合成接触仍是代理，需要对分配的不确定性作敏感性分析。

已有真人数据可用于估计训练期的条件分布：同年龄/收入家庭中有哪些不同支出与感知，差异跨月是否稳定。应尽量联合分配相关属性，并让同一人的稳定特征跨月延续，不能分别独立抽取所有标签。没有联合数据时，明确使用的条件独立假设。

如果仅靠提示仍不能复现，应允许一部分信念更新由经验学习或统计模型显式实现，LLM负责解释所接触的情景和完成问卷。这样属于经过数据校准的混合Agent，需要报告参数估计过程，并与不使用LLM的同信息模型比较。不能先从目标月真实答案抽一个预期，再让LLM为它编解释。

人群真实性至少包括：分组中心、组内离散、跨月方向、同一人的持续性。只匹配总体中位数，或只把总体方差拉大，都不足以支持微观结构可靠。评价时要与简单人口条件分布基线比较，并使用未参与本轮机制选择的月份；既有全跨度探索看过的数据不能宣称完全盲测。

## 5. 模型是否记住了一年后的真实CPI

风险成立，但当前数据不足以定性。输入文件满足时间限制，与模型训练知识满足时间限制，是两件不同的事。禁止联网、写“只知道某日以前信息”不能删除权重内的知识。相关方法论文将训练数据泄漏列为预测研究的关键识别条件。[Ludwig等](https://www.nber.org/system/files/working_papers/w33344/w33344.pdf)

这次对照采用“调查月向后12个月的CPI同比”，不使用下一自然年的全年平均：

- 2022-03问卷对应2023-03实际CPI **5.0%**，于2023-04-12发布。[BLS](https://www.bls.gov/news.release/archives/cpi_04122023.htm)
- 2022-09对应2023-09 **3.7%**，于2023-10-12发布。[BLS](https://www.bls.gov/news.release/archives/cpi_10122023.htm)
- 2023-03对应2024-03 **3.5%**，于2024-04-10发布。[BLS](https://www.bls.gov/news.release/archives/cpi_04102024.htm)
- 2024-03对应2025-03 **2.4%**，于2025-04-10发布。[BLS](https://www.bls.gov/news.release/archives/cpi_04102025.htm)

2023-03确实值得检查：数字版Q9样本中心两遍平均3.79%，文字4.02%，原输入4.33%；都比该小样本真人6.03%更接近未来CPI3.5%。但数字版的直接Q8中心约4.54%，并不是照报3.5%。2022-09三组Q9则约6.15%、5.37%、5.78%，均明显高于未来CPI3.7%。不能据部分接近就断言背诵，也不能用另一些偏差排除局部记忆。

需要区分至少三种解释：读取了未来历史知识；依据当时已知的政策/价格合理预测回落；在长期低通胀或政策目标上收缩。四个时期的相关性无法区分它们，模型理由也不能完成这个区分。

可执行的检验顺序：

1. 本次已完成零API时期对齐和回答核查。以后如扩展到旧全年记录，应单独报告旧P/E口径，不混成同一实验。
2. 小样同事实对照：保留实际日期；去掉能识别年代的绝对日期/人物/事件名称、保留相对时间；在匿名情景中改变价格路径。匿名或反事实只是诊断，不是无泄漏证明，也不是历史重建成绩。
3. 独立记忆探针询问未来数值，仅用于测试是否能回忆。答对说明有能力，不证明正常模拟实际用了；答错也不能排除记忆。
4. 更有力的检验：固定可核验的旧权重版本，在其发布后、当时尚未发生的时期测试，并与同P/E的当前模型比较；前瞻模拟在真实SCE公布前封存。旧模型能力差异仍需控制，单一训练截止标签不充分。

路线A可继续报告后验重建及知识污染限制；要主张严格路线B预测，需相应的信息与模型时间隔离。本轮只完成第1项，没有新增记忆探针或付费实验。

## 6. 下一步顺序

先核查可用的人体感价格/经济感知字段及其训练期分布，整理变量—机制—数据证据；同时准备日期识别小样对照。随后选择一个明确机制做输入对照，优先比较完整共同统计表与有依据的个人信息视图，保持问卷、P和其余E一致。经历模块先保留为候选，不继续加长历史叙述。

具体调用数、月份、估计/验证划分与预算仍需另登记。本次发现不能作为立即扩大模拟或用旧剩余预算自动续跑的理由。
