# 外部观点复核：怎样把行为机制加入SCE模拟

2026-10-14。状态：文献复核及候选方案；没有修改冻结运行，没有新增API调用。候选提示见[草案](behavior_prompt_candidates_20261014.json)，一手文献索引见[来源](behavior_prompt_sources_20261014.json)。阅读入口是[扩大实验页新增区](../../../workstreams/20261013_behavior/codex_expansion_diagnostic_20261014.html#behavior-mechanism-review)。

## 1. 哪些观点有用，哪些要收紧

**最有用的路径是：接触到价格变化 → 形成自己的物价印象 → 判断变化会持续多久 → 调整原有预期。** 这比“多放几个价格指数”更接近需要模拟的过程。但不能把整篇总结中的因素顺序当成已得到统一验证的贡献排名。

- **价格感知与购买频率有直接支持。** D’Acunto等用美国购物扫描数据发现，杂货价格变化的影响与购买频率相关，涨价比同幅降价更显眼。它不意味着全部商品、全部家庭的支出占比都不重要。[作者稿](https://eml.berkeley.edu/~ulrike/Papers/paper_DMOW.pdf)
- **“感知通胀”不是官方CPI。** 德国BOP-HH随机信息试验支持感知影响未来预期，且也发现对5年、10年预期的影响。不能把短期与长期划成互不相干的两套驱动，更不能把过去CPI当作每个人已经感知到的通胀。[Bundesbank DP17/2023](https://www.bundesbank.de/resource/blob/902668/365682610f6c37a512c5905f66f8f285/mL/2023-06-30-dkp-17-data.pdf)
- **接触多与反应强是两件事。** 所引用的英国食品研究为2025年论文，原版4月25日、现版5月。研究发现食品重要，也区分了支出暴露与信念敏感性；较高收入家庭可能对食品更敏感。因此不能由“低收入食品份额高”自动推出更大的预期调整。[BoE WP1125](https://www.bankofengland.co.uk/-/media/boe/files/working-paper/2025/food-prices-matter-most-sensitive-household-inflation-expectations.pdf)
- **年龄关系随历史阶段变化。** Malmendier与Nagel的论文正式发表于2016年；较年轻人近期经历占比大，并不推出老年人永远报得更高。本项目SCE描述统计中，2021年年长组更高，2025年1—10月年长组反而略低。[经历学习作者稿](https://eml.berkeley.edu/~ulrike/Papers/InflExp_44.pdf)；[已有SCE统计](age_reporting_followup_20261012.md)
- **人口规律不能直接变成固定答案规则。** “年龄普遍U型”“女性固定高2pp”“低收入固定高3pp”“资产带来低预期”的范围与识别依据不足。例如克利夫兰联储的间接提问中教育方向与SCE相反，问法本身就会影响结果。[官方研究](https://www.clevelandfed.org/publications/economic-commentary/2022/ec-202203-indirect-consumer-inflation-expectations)
- **中国宏观回归不能直接移植。** 原文未给出可核对的中国研究出处；利率固定滞后2—3季度、M2贡献排序、汇率不显著等，暂不纳入美国SCE参数或人口分配。不能由这些陈述给每个居民指定共同的政策反应。

## 2. 对我们最关键的新启发：同样的信息，可能有不同的理解

Andre等对美国居民与专家的调查发现，即便给出可比信息，人们对加息等冲击的判断仍不同。居民会联想到企业融资成本，也会联想到需求下降；研究的随机提示实验支持“先想到哪个传导过程”会影响判断。这为研究f提供了比笼统人格标签更直接的依据。[作者稿](https://www.econ.ku.dk/cebi/publikationer/journals/SubjModelsRevision.pdf)

但这不是SCE逐月Q9试验，不能照搬文中比例给我们的居民分型。提示可以作为受控的思考方式实验；尚不能声称每个SCE受访者的真实思考类型已经被观测。关于信息更新迟缓，[Carroll的信息传播模型](https://www.nber.org/papers/w8695)提供相关依据；[Mankiw与Reis的粘性信息模型](https://www.nber.org/papers/w8290)主要研究价格设定，不能直接给出SCE居民的更新概率。

## 3. 如何加入计划：沿用原主线，补两个具体机制

### 第一优先：弄清模型为什么没有保住个人原有信念

先完成八期已有结果的离线拆解：同月公共变化、个人上期位置、个人调整；按年龄、收入、数理能力核查。现有固定规则后四期中，模型跨人IQR为1.565pp，真人为5.545pp；本人历史有用，但仍明显压缩差异。这是我们已有的直接问题，不能用外部观点替代检查。[本轮结果](../../../workstreams/20261013_behavior/codex_expanded_results_20261014.md)

可用过去问卷估计“较稳定/经常改变”的经验模式，作为候选代理。不得用本期答案定义类型；过去改动也包含测量和表达噪声，不能把经验相关性称为已识别的人类更新机制。首次受访者从历史训练资料的条件联合分布初始化，不能凭空指定固定比例。B路线使用自己的模拟信念，并另查误差累积。

### 第二优先：把购买频率做成有数据支持的价格接触线索

现有CE Diary已经解析了全部品类合计的购物出现日数，但还没有按商品类别完成频率向量，也没有接入真实模拟。因此这个方向仍值得试，与此前“放入支出篮子”不同。[实现核查](../../../reviews/20261012_mechanism_retro/prompt_frequency_audit.md)

先按食品、日用品、个人护理等类别补每周记录日数，并检查缺失和人口字段支持，再在共有且可靠的画像字段上抽取整条供体向量，保留联合结构与匹配回退。不把记录日数称为交易次数、注意力或全年习惯，也不把另一户数据说成真实SCE家庭经历。A可用回顾代理；B必须另验当时可得的CE年份与版本。

候选对照为：当前输入、条件匹配接触线索、同批线索随机置换。匹配与置换组使用同一行为提示。这样能区分“多一句购物提示是否有用”和“分配给这个人是否有用”。仅增加方差不算通过。

### 第三优先：单独检验价格或政策的理解方式

可以用“先关注企业成本”和“先关注需求变化”两种短提示做同人的交叉试验，保持P/E事实、先验、问卷和输出格式一致。先判断模型对这些提示是否真的有反应；人口分配需再找联合数据支持。目前不按年龄、收入强行指定理解类型。

这项先作为机制预检；不与购买频率、人格、概率取整一次捆绑。个人通胀经历已试过的数值版和文字版未改善，不重复扩写同一历史故事。概率填法保留为表达问题，不能用机械取整的改善宣称恢复了个人思考方式。

## 4. 提示词可以用，但要满足三件事

1. **写过程，有证据。** 示例：“你通常先通过经常购买的商品形成物价印象，再判断这些变化是否会延续到未来12个月。” 不写“低收入，所以预期更高”，也不预填新的预测值。
2. **分配有来源。** 购物接触用Diary的合成代理；个人惯性用截至上期的资料；缺乏真实联合分布的理解风格先随机交叉，明确是实验条件。人口关联只决定概率，不决定每个人必然怎样想。
3. **效果要检查。** 同事实下的提示是否改变输出、匹配是否优于置换、中心误差/跨人W1/更新W1是否共同改善，都要记录。理由文字只辅助解释，不能代替因果证据。提示影响LLM只证明这个模拟器可操控，不自动证明还原了人类机制。

下一轮仍用既有冻结计分器，Q9跨人中位数为主要中心指标，Q8单列；保留过去信息基线、分组误差和失败覆盖。先做零API拆解与频率数据补充，再选一个机制登记提示、月份、种子和预算。已经查看过的八期可用于开发诊断，不能再称改进方案的独立测试。
