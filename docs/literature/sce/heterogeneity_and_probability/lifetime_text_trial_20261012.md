# 个人通胀经历：详细数字与简要文字的对照

2026-10-12。用户在看到上一轮负结果后要求只保留文字及趋势再试，并明确“可以按照原有的模拟预算”；本轮沿用已说明的DeepSeek官方发送范围、零重试与新增$1.50上限，不复用上一轮费用账本。

## 设计先冻结

- 同四时期（2022-03、2022-09、2023-03、2024-03）、同每期12人、同模型`deepseek-flash`、温度0.5，各生成两次。
- 三组：原输入、年龄对应详细数字历史、年龄对应简要文字历史；288次请求。数字版同时重跑，上一轮数据只作背景，不混合为同期对照。
- 当前P、新闻50/50、合成CE、Fed信心、问卷、价格E、年龄6岁起点与时代范围保持。仅历史背景的表示改变。
- 文字版保留年代、人生阶段、原有事件背景、同比涨幅上升/反复/回落与定性持续描述；不显示CPI百分比、政策利率/目标数值、月度节点、月份计数及精确年龄范围。年代仍保留，是历史定位，不是预测锚点。
- 文字由原时代卡片确定性生成，不另调LLM总结，不读SCE答案，不根据拟合筛选措辞。
- 连续高通胀段已结束：满12月描述较持久、最多6月描述相对短暂、中间描述持续一段时间；这只是冻结的语言映射，不是心理参数。起点未知不声称短暂，历史末端仍持续就明确尚未观察到结束。
- 不注入“老人应更悲观”、记忆权重、概率取整或预测必须回归某数的指令。

## 判断标准

主要比较文字减数字：同批人、同遍生成、同冻结计分器的Q9中心误差、W1分布距离及人际IQR差距。原输入是必要的第二参照，避免只是比失败版本稍好便宣布成功。Q8、个人不确定性和通缩概率为辅助。

表示改善门槛：两遍平均中心误差/W1均低于数字版，且每遍至少3/4时期同时改善。整体候选门槛还要求对原输入满足同样条件；均不自动升级正式配置。12人各年龄组4人，只作开发诊断。两遍分开报告、四时期等权；bootstrap只描述固定输入条件的小样本波动。

这不是只删除数字的完美实验：篇幅、月度精度、精确年龄提示和压缩方式也改变，最多能判断“简要文字表示”是否比“详细数字表示”更有用。四时期仍为已用开发时期，不声称独立测试或严格路线B。

## 真实结果：中心有局部改善，整体门槛未过

24个单元、288次请求全部完成，连接错误0、自动重试0；287份模拟Q9有效，2024-03文字版第二遍1份合计99%，保留不补发。2023-03另有1份真实调查概率不合格，不进入两遍Q9配对；各单元共同可评分11—12人。模拟Q9错误不抹去仍合法的Q8。费用按高峰未命中价自记$0.231522，低于本轮独立$1.50上限；不是厂商账单。

比较**本轮同期三组**，而非将旧一轮控制结果拼接进来。四时期等权、两遍平均的Q9样本中心绝对误差：

- 原输入：0.534pp。
- 数字版经历：0.879pp。
- 文字版经历：0.742pp。

文字相对数字下降0.137pp、约15.6%，两遍各自中心误差均下降（0.885→0.735、0.874→0.750）；但仍高于原输入。主要改善在2022-09（0.745→0.334pp）和2023-03（2.235→2.007pp）；2022-03略差、2024-03更差，所以不是所有时期都改善。

分布W1平均：原输入2.881、数字3.191、文字3.089pp。文字对数字第一遍略变差（3.131→3.158），第二遍变好（3.252→3.020），未形成两遍一致改善；每遍同时改善中心/W1的时期数只有1/4、2/4，表示改善门槛未过。对原输入两遍均为0/4同时改善，整体升级门槛亦未过。

人际IQR均值：真人4.100、原输入0.786、数字0.481、文字0.563pp。文字比数字稍有分散，仍比原输入更集中，远小于真人。这里IQR是不同人的预期跨度，不是单个人给出的概率区间宽度。Q8中心误差数字0.677、文字0.676pp，几乎没有改善。

8个时期×生成的文字减数字中心误差bootstrap区间均包含0，12人样本不能确立统计显著优势。原输入本轮0.534与旧轮0.624不同，也提醒我们必须保留同期重跑和有效样本说明，不靠跨轮均值判定成功。

## 如何使用这条证据

简要文字对Q9中心的改善是一个有限线索，支持保留该表示作为候选。它没有证明数字是偏差的主要原因，更没有证明已经模拟了真人的经济记忆；篇幅、价格幅度、时间粒度和年龄提示同时变化，不能把全部差异归为“去掉百分比”。

保留新旧两种生成器和全部轨迹，正式P/B不升级；不马上扩大样本或继续付费改措辞。下一步零API比较同人的三组原回答，检查文字版何时减轻了过早回落判断、何时反而加强；分开看Q8与Q9、年龄组和央行信心，理由仅作线索。再决定是否让当前信息检索少量相关经历，或显式表示通胀持续性信念，并登记独立时期验证。新的付费实验另明确授权范围，当前余额不视为自动续跑许可。
