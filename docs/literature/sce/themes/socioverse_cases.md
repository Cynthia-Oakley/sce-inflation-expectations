# SocioVerse 案例与 ConsumerSim：可以借什么，不能直接搬什么

核查：2026-10-05。来源状态见 [来源目录](../sources/socioverse_cases.json)。论文、平台演示、公开改写代码分开看；本轮未运行任何参考案例。

## 1. ConsumerSim：借机制拆分，避免只借规模

[论文 v1](https://arxiv.org/html/2606.30395v1)，重点 §4.2–4.6、§3.5、Appendix F：人口来自微观资料；补充属性按条件分布分配；环境的经济信号通过个体暴露与注意发挥不同作用；核心人群生成回答后再扩展；全国输出另含上一期指标的惯性校准。**论文公布的整体效果包含这些模块，不能直接当成未经校准的 LLM 回答效果。**

对本项目的三项设计启发（项目推论）：

- 分别保存“Core 回答”“统计扩展结果”“校准结果”，逐层比较，才能知道改进来自哪里。
- 将人格或乐观倾向按条件资料分配，不能独立随机贴标签后声称忠实恢复真实心理。SCE 首先研究价格体验，心理属性后置。
- Q9 是一位居民的未来通胀概率；ConsumerSim 的正/中/负是调查回答类别。不能把它的三分类贝叶斯扩展直接套成 Q9 官方计分，也不能把群体平均十档分布当成每个人的密度。

这里的家庭是调查回答者，不是让所有人共同交易来生成 CPI。信息感知与回答可以研究，供需价格形成不自动变成当前项目范围。

## 2. 平台消费者信心示例：借信息轴与审计结构

[官方文档](https://socioverse.fudan-disc.com/docs/zh/examples/consumer-confidence/)，P/E/B、结果与 Grounding 各节。演示让同一目标月、固定人群在多个信息截止日重新作答。它展示了“信息变了，回答怎样变”，不是跨月行为必然可信的证明。随附小型演示自身披露绝对水平未校准、部分指标被时点筛除。

项目可借：同一 P、同一目标，单独改变可见信息；在 Trajectory 中保存实际观察与来源；分别标记 sourced、proxy、assumed。我们的改进实验应从冻结的输入生成新版本，不能覆盖旧结果。

## 3. PMI：先更新主体状态，再回答问卷

[SocioVerse2 技术报告 v1](https://arxiv.org/html/2609.24911v1)，§5.4.2、Appendix A.7。企业端把外部信号转成经营状态，再模拟采购经理作答；开发、校准、留出检验分开，并有机械决策对照。该报告的结果与消融并不支持“增加任何模块都会变好”。

**迁移到 SCE 的提议**：公共价格记录 → 家庭接触到的价格变化及持续性判断 → SCE 回答。中间状态可以是有来源的价格经历、信息接触与预期持久性判断；不是必须存上个月真实/模拟回答，更不能凭空指定家庭的经营状态。先做同信息的呈现对照，再考虑跨月状态；企业时间安排、扩散指数和参数不搬到家庭问卷。

报告声称的模型知识截止与服务商可核验的模型版本不是同一个证据。本项目仍需独立记录自己的模型身份与预测封存边界。

## 4. 混合舆论：规则侧可能收缩分布

[官方文档](https://socioverse.fudan-disc.com/docs/zh/examples/hisim-roe/)，两条行为路径、结果节。LLM 核心与普通规则人群共享轨迹，但更新机制不同；导入参考与可运行模板也不同。

项目启发：除了总体结果，要分别观察 Core 与 Normal 的分布。我们的 Normal 是统计填补，不能写成一个已经得到经验支持的居民互动模型。暂不增加社交网络；若未来加入传播，需另找接触频率与信息扩散的依据，单独消融。

## 5. 汽车市场与经典模型：校准和机制必须各有对照

[技术报告](https://arxiv.org/html/2609.24911v1) §5.4.3、Appendix A.8 的汽车市场结果包含真实注册份额的事后校准，作者明确称重建；§5.2.1 比较规则与 LLM 的行为机制。项目应同样区分约束/校准所使用的量与独立评价的量：用全国中位数约束重建时，不能再用这个中位数贴合证明微观结构正确。

推荐增加不调用 LLM 的简易经验/规则模型作参照。它若达到相同效果，仍是有意义的边界发现；不能以复杂性代替增量价值。

## 6. 重要更新：ConsumerSim 现在有公开核心改写仓库

本轮从平台文档核实到 [ConsumerSim 核心仓库](https://github.com/RunRiotComeOn/ConsumerSim-Consumer-Confidence-Forecast)。README 明确称 clean rewrite，公开人口、信息、预测、贝叶斯聚合及残差校准模块；**早期材料“只有外壳、引擎不公开”不再足以描述当前资源**。

它也不是原论文的完整复现凭证：README 排除了论文对照、消融、下游任务和验证；默认 local predictor 是规则演示。源码 `debias.py` 用上一月预测残差修正，与论文的上一月真值混合公式不同，应分别引用。`information.py` 的指标过滤读取 `observed_at` 日期，不能替我们证明官方发布时间和历史版本；其新闻相关性与情绪由上游提供，也没有自动解决我们的筛选问题。

本轮只归档公开 README 与上述两个文件；未导入本仓库、未更换研究实现。下一步若借算法，先读固定版本和数据契约，独立检验，不凭仓库名字声称同论文算法。

## 7. 下一步优先级

1. 学 ConsumerSim 分离人口、信息、回答、扩展和校准的比较方式。
2. 学 PMI 的中间状态思路，先做家庭价格感知的最小试验。
3. 学官方版本与 Grounding 记录，让每个假设和真实来源有区别。
4. 暂不开展企业、汽车或网络传播模拟；当前材料服务同一个 SCE 目标。
