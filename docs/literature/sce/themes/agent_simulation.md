# LLM Agent 模拟：从画像忠实度到 SCE 分布验证

核查日：2026-10-05。范围：LLM 作为经济实验/调查受访者、个体预测、分布校准与外推。来源和逐篇阅读位置见 [agent_simulation.json](../sources/agent_simulation.json)。核心全文阅读：Argyle et al.、Bisbee et al.、Park et al.；其余四篇针对经济实验外推、行为分布抽样和不确定性校准作重点章节阅读。

## 当前结果说明什么

两月 600 次 LLM 调用均返回可计分答案，但这只证明生成流程有效。Q9 加权指标比同计分器真实 SCE 低约 1 个百分点，同时模拟受访者之间的 Q9 个人密度均值标准差约为 0.6 个百分点，而真实数据约为 7 个百分点：这是两个不同缺口，分别是水平偏差和跨人分歧不足。5 月扩展后 Q9 为 2.965% 对真实 4.000%，跨人标准差为 0.585 对 6.874 个百分点；6 月是 3.858% 对 4.802%，标准差为 0.646 对 7.111 个百分点。Core/Normal 的 Normal 从 Core donor 抽取整份 Q8/Q9 联合回答；它能补全人口映射，不能把 donor 中没有的信息变成独立观察，因此也没有稳定修复这两个缺口。[两月运行记录](../../../CORE_NORMAL_LLM_RECEIPT_20261005.md)、[Core/Normal 验收](../../../CORE_NORMAL_ACCEPTANCE_20261005.md)

不能仅凭这些结果认定共同 E 是原因。共同的宏观简报可能压窄回答；画像中没有实测家庭价格暴露也可能让不同生活处境无法转成不同信号；模型先验或表达模板也可能造成类似结果。仅两个开发月、每个画像只调用一次，不能将跨画像差异拆成经济机制、个体反应和同提示抽样噪声。

## 文献共同指向的检验原则

**平均值接近，不等于模拟出调查分布。** [Bisbee et al. (2024)](https://doi.org/10.1017/pan.2024.5) 用真实 ANES 受访者特征构建 persona，发现 ChatGPT 生成的群体平均温度计分数与调查接近，但模拟回答方差偏小，许多回归系数和真实调查不同；轻微改写提示词及同一模型三个月后的更新也会显著改变结果（期刊 pp. 401–416，§§2–4）。这直接说明扩大合成样本会让模型输出的标准误变小，却可能让对真实人群的置信度虚高。此结果来自早期 ChatGPT 与政治态度题，不是 SCE 的效果量，但它与本项目的“均值差约 1 点、分歧差约 6 点”是同类诊断问题。

[Argyle et al. (2023)](https://doi.org/10.1017/pan.2023.2) 提出“算法忠实度”：同一 GPT-3 在适当画像条件下可对应不同群体响应分布，并用代表性调查画像、多个态度指标与群体关系作检验（§§3–7，全文 PDF pp. 4–15）。这与 Bisbee 并不矛盾：条件化确实可能恢复某些群体差异，但“写入人口标签”本身不保证目标领域的忠实度。Argyle 明确说其结果不等于能模拟某个具体个人或保证每条回答连贯；研究对象集中在美国政治与公共意见，不能直接证明人口标签足以生成通胀预期异质性。

[Park et al. (2024；现版 2026)](https://arxiv.org/abs/2411.10109) 展示了更强输入能提升个体预测：1,052 名美国样本接受约两小时、平均约 6,491 词访谈，并完成结构化调查；对未用于建 Agent 的 GSS 条目，受访者自述 Agent 的准确率达到本人两周重测一致性的 82%–86%，人口学画像 Agent 为 74%（现版 PDF pp. 1–3、9）。这个结果不能转述成“1,000 个只给人口属性的 Agent 就能模拟个人”。论文明确指出，它评价的是逐人准确度，没有证明样本内态度相关结构被复现；单一模型家族、英语样本和访谈输入也是边界（PDF pp. 9–10）。访谈还提供了 SCE 当前画像没有的经历、消费和约束信息。对本项目更相关的启示是：先测新增的、有来源的家庭价格体验信息是否改善留出表现，不能把更细的合成文字描述当作机制。

经济实验文献补充了如何校准与外推。[Horton, Filippas & Manning 的 Homo Silicus](https://www.nber.org/papers/w31122) 将 LLM 当作可执行的理论代理，并展示用自利、公平厌恶、效率等可解释代理类型，在已知博弈中校准混合比例，再去未参与校准的两阶段博弈检验（作者公开版本 §2.2.1、PDF pp. 12–14）。这是“校准域与外推域分开”的好例子，不是 SCE 通胀机制的实证证据。[Aher et al. (2023)](https://proceedings.mlr.press/v202/aher23a.html) 的 Turing Experiment 用既有真人实验检验多名模拟受访者：四项经典任务中三项复现主要发现，一项出现“过度准确”扭曲，LLM 受试者比真实人更常给出正确答案（§§3–5，PDF pp. 1–2）。因此要预先列出目标行为和可能扭曲，不能把像人或复现均值当作普遍保真。

分布采样和估计不确定性需要分别处理。[Gu et al. (2024)](https://arxiv.org/abs/2404.09043) 直接让多个模型从明确分布生成序列，发现模型能辨认概率分布，却经常不能按其抽样；借助 Python 随机数工具可改善明确分布抽样，对复杂隐含行为分布仍弱（PDF §§3–5，pp. 3–8）。论文把 temperature 设为 0.9 以增加文本/行为序列多样性，但多样并不等于匹配目标分布。temperature 是 token 抽样参数，不是家庭形成预期的经济机制；本项目比较经济输入时应固定它，必要的技术噪声复测另列。

[Huang, Wu & Wang (2025；作者现版 2026-06)](https://arxiv.org/abs/2502.17773) 提出基于相似真人题目校准模拟样本量的置信集方法：合成样本太大，区间会围绕偏差的合成均值变得过窄；太小则区间过宽。它需要一组有真实标签的相似题目，并依赖题目可交换、真人与模拟样本独立等假设（现版 PDF §2.2、pp. 4–7）。这是“模拟人数不等于有效真人样本量”的方法参照，不是仅靠 600 条回答就能校正 SCE。该文为预印本；当前实验例子以学生二元题目为主，不能不经扩展就用于 SCE 调查权重、十档概率向量和 Q8/Q9 联合分布。

## 把 Q8、Q9 和三种不确定性分开

每份回答必须保留成同一行的 Q8 与 Q9，而非先独立汇总后再拼接。Q8 是受访者的点预测；当前 SCE 文件中方向码为涨/跌两类，没有“持平”第三码。Q9 则是同一受访者把 100% 主观概率分配到十个未来通胀区间。Q8、Q9 各自的边际分布使用各自的有效答题集与调查权重；只有需要把两题配对起来的联合统计才使用共同有效样本。

- Q8 点预测的加权均值、中位数、分位数及涨/跌比例。
- 每个人 Q9 十档概率向量的加权平均（人群平均主观密度），以及按冻结计分器从个人密度导出的预期均值分布。
- 人内 Q9 密度宽度与人际分歧分开报告。对个体 i，Q9 的十档向量描述该人对未来通胀结果的主观不确定性；各人 Q9 密度均值之间的加权方差描述人际预期分歧。若将每人的主观密度按调查权重混合成一条人群密度，则这条混合密度的方差可分解为人内主观方差的加权平均与人际均值的加权方差之和；它是人群主观密度的统计分解，不代表未来实际通胀结果的客观方差。区间代表值与开放尾部处理须遵守项目同一冻结计分器。
- 配对联合统计：Q8 点预测与该人 Q9 密度均值的加权秩相关；按 Q9 均值分位组报告 Q8 涨/跌比例；再并列二者边际分布与联合分布距离。若同一人 ID 确实对应真实调查记录，A 线可附报 Core 的配对误差；Normal donor 扩展行不是 donor 本人的预测，不作逐人准确率。

模拟回答间的标准差还不是上述任一项。它可能混合了不同画像、共享 E、模型生成随机性和调用版本差异。只有对完全相同的 P/E/prompt 重复调用，才能估计固定输入下的生成噪声；这仍不代表受访者之间的真实分歧。模型自身不确定性、提示词/版本敏感性也不能由 temperature 或回答里的自我解释估计。

ConsumerSim 一类论文中的 positive/neutral/negative 是**受访者跨人类别回答的分布**；实现上可以用硬分类计数，也可以把每名 Agent 对三类的软概率累计成 soft counts。SCE Q9 是**每个人内部的未来结果概率分布**，每人有十个概率分量且总和为 100%；随后再跨人、按调查权重汇总。二者的概率对象和聚合层次不同，不能把前者的三类 soft-count 或同一个 Dirichlet 多项式解释直接套到 Q9。若要用 Dirichlet 表示个人十档概率的组成结构，那是另一个模型；其层级、权重及人内/人际方差含义都须单独说明。

## 可执行的下一轮比较与留出

1. **先用现有记录做零调用诊断。** 锁定两月各自的 P、共同 E、prompt、输出和有效性掩码；按调查权重重算 Q8/Q9 边际与联合指标，检查输出是否随已有的人口/生活条件标签分层，列出 Q9 均值和个人密度宽度的差异。Normal 的有效 donor 集中度作为诊断量，不把扩展行数当作有效样本量。现有 5/6 月已被查看，继续作为开发基线，不能事后称为独立留出。

2. **机制对照固定总信息。** 如果能为画像补充有来源的购买篮子或价格暴露，再以同一批画像和相同数字、顺序、模型、prompt 结构做配对比较：共同宏观简报；相同事实加与画像相关、可核查的家庭暴露视图；人口属性/生活体验单独消融。保持事实数量与提示长度尽量相同，避免把“新增数据量”和“个性化措辞”混为一项。如果当前 P 没有可测的家庭暴露，就先不虚构曝光强度或把收入、教育任意映射成涨价敏感度。

3. **建立留出与基线。** 预先固定一个尚未用于提示/参数选择的 SCE 目标期；留出其中真实 Q8/Q9 及派生分布，只用目标期允许的人口字段和已声明的 E 进入 B。比较人口加权的上期 SCE 分布/简单宏观基线、同一 E 的单次直接 LLM 汇总、异质 P 下的 Agent Core、Core/Normal 扩展。分别报告总体偏差、Q8/Q9 加权分布距离、跨人分歧差、联合统计，不只挑全国中位数。校准只能在开发期拟合，留出只评一次；按人 ID 重采样并保留跨月重复关系，月份数少时不能把 600 次 API 调用当 600 个独立时间样本。

4. **历史污染和解释文本的界限。** 当前模型训练/更新截止未知，2026 年模型重放 2021 年只能叫回顾性条件模拟，不能因外部 E 遵守发布日期就称严格事前预测。删日期、换日期、打乱展示顺序或询问模型是否记得结果，最多是敏感性诊断；没有变化不能证明无记忆。API 返回的 reason 是生成文本，不是已识别的内部因果过程；本项目 5/6 月 E 本身就含“通胀暂时”观点，reason 中暂时性、基数效应词频不能区分它来自 E、模型历史先验或事后合理化。最强外部检验是冻结实际模型版本和 P/E/prompt，在 SCE 答案公开前生成并封存新月份结果；若模型知识边界未知，则仍明确标记该限制。

## 停止条件

- 新增 Agent/Normal 只扩大行数或降低 Monte Carlo 误差，却没有在预注册的独立留出上改善 Q8/Q9 加权边际和联合分布、分歧及相对简单基线的表现：停止扩样，保留直接加权 Core。
- 个性化版本只把标准差推高，却使留出分布、组间模式或 Q8/Q9 配对更差：不接受“方差更像”作为成功，停止该变体。
- 画像缺少可核实的家庭价格暴露、不同 E 同时改了事实与文风，或模型/版本无法固定：停止机制性因果表述；只报告描述性敏感性。
- 留出结果不能改善预先设定的最小有意义差异，或不确定区间仍覆盖“无改进”：不增加调用/收缩强度搜索，不据这批已看过的两月调参。进入更强结论前另设预先封存的目标期和新版本。

现阶段可支持的是“600 条有效输出仍有水平偏低与跨人分歧严重不足；Core/Normal 未提供独立信息”。尚不能支持“共享 E 导致收敛”“人口属性无法区分通胀预期”或“解释文本揭示因果机制”。实际 CPI 可另作预期与实现值的描述性比较，不能替代 SCE 对主观预期的调查真值。
