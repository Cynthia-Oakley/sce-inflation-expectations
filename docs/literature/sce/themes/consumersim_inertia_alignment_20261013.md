# ConsumerSim惯性加权：原文核查与SCE借鉴方案

2026-10-13。用户询问历史指标与Sim输出的加权是否存在，以及适用于A重建还是B预测。本轮仅核查和提出方案；不改运行配置、不选SCE权重、不新增API。

## 原文事实

[ConsumerSim v1 §4.6](https://arxiv.org/html/2606.30395v1#S4.SS6)使用`aligned_t = lambda * observed_(t-1) + (1-lambda) * behavior_t`；锚是上一月真实CCI，不是本月答案。论文称其为Behavioral Inertia Alignment。美国权重0.4，EU27 0.6，日本0.7。附录§11在2024-01至06用0至1、间隔0.1的网格按RMSE选权重，之后固定。§3.5亦承认个体行为有效性仍待研究。

核查[arXiv版本记录](https://arxiv.org/abs/2606.30395)：本轮可见仅v1，提交2026-06-29。原有文献记录同样指出论文整体效果含校准，不等于纯LLM回答效果。公开clean rewrite的`debias.py`是上期残差修正，与论文混合公式不同，勿混用。

## A和B如何区分（本项目判断）

- A历史重建可以利用历史结果作惯性锚，也可以明确利用已知当期宏观结果约束重建；被用于构造的量不再作独立验证。需要保留未经校准的总体误差，并检验未约束的分布、人群与时期。论文采用2024上半年定参，此参数用于更早年份属于回顾性校准，不能将那段成绩等同于当时可实施的实时预测。
- B预测可以用这类公式，但锚必须在预测截止前已公布，权重也须由此前数据确定。近期SCE宏观指标和本人t-1微观回答不是同一可得性：公开headline通常比微观早得多。不能默认目标月前一期SCE已经发布，需按现有发布台账选最近可见值。多月连续预测拿不到未来真实锚，须递推模拟/组合状态，并报告误差累积；不能声称论文的逐月真值锚方案直接解决长期自由演化。

## 可行的SCE方案草案

先从每人的Q9依法拟合个人密度、计算个人均值并聚合出模拟全国中位数，再在独立输出层作`combined = lambda * latest_published_SCE + (1-lambda) * simulated_SCE`。不要把全国标量与当前12人年龄平衡小样本中位数混成同口径评价；同样本历史基线和全国公开基线分开。

这个混合输出是“组合后的全国预测”，不是导出个人Q9天然聚合的headline。不反写原始问卷，不能因全国数字更准就声称个体行为、分布宽度或概率表达被修复。统一加减常数也不会改变人际IQR。

最小对照：纯Agent、最近公开SCE直接延续、历史＋Agent组合；另复用AR/ARX作统计参照。若同时引入个人先验，保留有/无个人先验及有/无全国校准四种结果，避免把两个惯性来源的作用混到一起。

权重应在事先登记的早期开发/验证阶段选择并冻结，后续月份评价；不按四个已看过的小样时期挑权重再报测试效果，也不照搬CCI的0.4。若最佳权重接近1，组合几乎等于历史延续，须检验Agent是否贡献了可重复的增量信号。目标全国预测的主指标仍MAE，RMSE/偏差/变化方向辅助，原始微观结构另按统一契约评价。

## 项目方向

用户澄清扩大人数主要是稳健性检验，这与本方案兼容。可以并行保留“微观机制改善”与“宏观组合预测”两层目标，分别说明成效；校准属于可研究的方法，不要求所有预测准确度都由未经校准的LLM承担。拟采用参数、窗口、具体运行均未冻结。下一项可以整理同口径的既有全国模拟与公开SCE发布值，先离线验证组合是否超过历史延续；当前新版只有四期12人小样，不直接称全国有效预测。
