# 一年期通胀预期：价格变化会持续多久、政策与消息是否可信

2026-10-10，针对用户关于新闻、结构因素、乐观与政府信任的讨论。性质：初步证据核查与候选机制，不是已经验证的模型改进。来源和阅读范围见 [sources/persistence_policy_trust_20261010.json](../sources/persistence_policy_trust_20261010.json)。

## 1. 最值得补的连接

SCE问的是从调查时点起未来12个月总体物价的涨幅。经济学中通常仍称一年期为短期预期；它可以同时受近期价格、长期经历和政策判断影响，不能因此默认居民都主要依赖结构因素。

用户的提醒补上了一个关键问题：**家庭看到涨价后，认为它会继续多久？** 近期价格只说明已发生的变化；原有信念、对涨价原因的理解和对政策是否有效的判断，才可能帮助居民推想未来一年。不同居民对同样事实可以作出不同解释。

一个可讨论的例子：食品近期上涨，有人认为是暂时供应受阻、之后恢复；另有人认为生产成本和工资会持续增加。两人可以知道同样的价格，却报告不同的一年期预期。此例是项目假说，不是对真实SCE受访者的测量。

## 2. 与本项目直接相关的研究

### 居民确实会考虑政策与供应链，但关注程度随时期变化

纽约联储2023年的SCE专题调查发现，居民将供应链因素列为此前通胀上升的重要原因，部分居民把美联储政策与供应链改善视为未来一年通胀回落的重要因素。调查为原因评分，不能证明这些解释对每个人预期的因果效果，也不能回填为2021年居民当时的信念。[纽约联储原文](https://libertystreeteconomics.newyorkfed.org/2023/08/consumers-perspectives-on-the-recent-movements-in-inflation-expectations/)

### 不能把专业经济学传导机制默认赋给居民

2026年工作论文用大规模美国家庭调查和随机信息处理研究利率理解；摘要报告，部分家庭把加息与更高通胀联系起来，而非标准模型的抑制通胀方向。样本中的这种结果提示我们检验居民怎样解释利率；不能把“加息一定让Agent降低预期”写成统一规则。本次核验到官方摘要，没有复核全文细节。[NBER工作论文35127](https://www.nber.org/papers/w35127)

### 政治分歧与通胀预期有关，但不能固定编码为某党永远预期较高

Binder等对疫情时期的研究摘要报告，不同党派的预期锚定及对价格冲击的敏感性存在差异。这支持按时期研究政治因素，不支持用某党标签为每个居民赋一个固定偏移；观察性关系和模型反事实也不等于新闻源的随机因果影响。本次核验到官方摘要与发表记录。[NBER工作论文32650／2024年发表版本](https://www.nber.org/papers/w32650)

### 央行信任、政府信任、政治认同应分别记录

2025年工作论文发现，央行信任的党派差异不能单独解释通胀预期分歧；2025年的观察也与早期政党格局不同。因此，不能把这些属性合成一个“信心”分数。本次阅读限于官方摘要。[NBER工作论文33684](https://www.nber.org/papers/w33684)

一般幸福或乐观对美国居民一年期通胀回答的独立作用，目前项目文献仍缺直接可移植依据；经济前景乐观也可能代表更强需求，未必意味着更低通胀。既有证据与边界见 [心理属性复核](../psychological_attributes/theory_review.md)。

## 3. NYT、Fox与新闻问题怎样处理

Pew的2019年调查与2025年调查均显示，NYT的使用者/信任者更偏民主党，Fox受众更偏共和党。2025年报告明确说明研究的是受众，并未评定新闻内容的政治倾向。**受众构成不能直接证明当前选中的经济新闻存在何种偏差。** 政治新闻来源也不完全等于居民取得物价信息的来源。[2019调查结果，2020年发布](https://www.pewresearch.org/short-reads/2020/04/01/americans-main-sources-for-political-news-vary-by-party-and-age/)、[2025报告](https://www.pewresearch.org/journalism/2025/06/10/the-political-gap-in-americans-news-sources/)

本项目目前可以确认的缺口是：所有Agent共同阅读同一批NYT标题和摘要；尚未测量他们真实选择哪些媒体、相信哪些说法。已有一份2021年5月实际输入包含多条关于通胀暂时性、美联储耐心、供应链修复的叙述，也含担忧持续通胀的内容。它们可能形成共同解释框架，但本次没有统计全样本的叙事占比，也未识别它们是否导致偏低。

研究时要分清四件事：某事件是否被报道、报道如何解释它、居民是否接触、居民是否相信。直接将NYT换为Fox会同时改变多项，难以判断哪一项起作用。混合媒体也不能自动代表全国居民。

优先本地检查已有新闻：把同一事件的重复条目归并，登记价格事实、对原因/持续性的说法、说话者与来源。先核验关键说法在当时是否已出现，明确政策承诺和已经实施的行动。需要补充时，先查美联储、政府或相关机构的原始发布；这些是公共信息的参考，不意味着所有居民都看到了。

未来若加入多媒体，需要同一时期的可归档文章和历史接触分布。2019资料可以作为2021合成接触的候选参考，但不能视作其实际分布；2025资料不直接用于B路线2021输入。重建A如采用事后分布，也须另说明条件和敏感性。

## 4. P、E、B可以怎样进一步设计

- **P：**区分个人生活处境、原有通胀看法、消息接触与信任。个人财务乐观、对总体经济乐观、对央行信任和政治认同分别处理。没有观测到的属性标为合成，保留分配的不确定性。
- **E：**同时保留生活价格经历和可能影响未来的公开事件，如供应链变化、政策行动、能源供给和贸易措施。宏观影响方向与幅度不应由研究者预先写成居民必须接受的结论。
- **B：**检验居民是否把某变化看作暂时或持续、怎样理解原因、愿意相信哪种来源，再形成未来12个月回答。可以保留简短理由帮助诊断；LLM自述理由本身不能证明真实计算过程或现实因果。

“原有看法”不等于必须逐字提供上月个人答案。若采用此前真实SCE分布初始化，需明确这是引入了历史预期信息，另给基线同等权限，并在开发资料确定规则后验证。否则应把它作为独立的合成状态机制，不能悄悄借真实答案修正水平。

## 5. 数据可行性与当前边界

本次对本地核心问卷做英文关键词检索：未检出trust、Democrat、Republican、political、confidence等词；这只是一项初筛，不证明所有SCE模块或微观字段都没有相关信息。下一步仍须核对变量字典和专题模块，不能据此给现有画像补上实测党派或信任标签。

可能的数据路径按优先级为：

1. **已有资料可直接推进：**审查2021年5、6月实际新闻与模型理由，复用长期经历、信息处理、心理属性综述；不新增API。
2. **公共政策记录：**当期FOMC声明、目标与行动，以及能源/贸易官方发布，保存日期和版本，先用于检查E的叙事是否遗漏或重复。
3. **专题调查与外部调查：**SCE原因解释专题、Pew新闻使用资料、论文对应的调查。先查是否提供可下载微观数据、题目是否一致、能否同时观察画像与信任；目前没有完成这些数据的下载、个体匹配或联合分布验收。

人口条件匹配只能生成“与画像相容的合成属性”，不能恢复某个真实受访者的信任。地区投票率不能当个人党派，党派也不能确定媒体接触或信任。

## 6. 接入原计划的顺序

本专题补入 [Sol清单03的机制依据](../../../sol_execution_checklist_20261010.md)，不启动新实验：

1. 在清单01诊断中，增加对当前新闻“暂时性／持续性／政策有效性”叙述的本地核查；区分信息缺失、重复曝光和不同理解。
2. 清单03第一轮仍先分开检验同事实表达与问卷。若诊断显示原版已经包含结构消息，就不以“缺利率或政策”作为未经核验的解释。
3. 第二轮候选优先检验“同样价格事实，不同的持续性判断或信息信任如何影响回答”。先用明示的合成情景测试模型响应；只有明确现实分布依据后，才讨论全国重建是否改善。合成情景不能直接当现实拟合成绩。
4. 新闻源替换与政治标签后置。需要同事件文本、接触/信任的可比依据及独立月份评价；不能因为样本均值较接近就宣布媒体偏差解释成立。

首选研究问题是：**当价格事实相同，哪些居民相信涨价会持续，哪些相信它会缓解；我们的模型能否呈现这种有依据的差异？** 这与消费篮子研究互补，不替代日常价格体验，也不承诺可以修复目前的总体偏差。

本次只完成文献/来源初核与本地输入抽查，未运行新的机制模拟或下载上述外部微观数据。问卷与输入文件哈希见来源记录；15份待审文件保持原样。
