# 文献驱动的 SCE 改进方案

2026-10-05。状态：**方法建议，尚未执行或冻结新实验参数**。开题报告维持当前版本；已有两月实验作为开发基线，不覆盖。

## 1. 一句话主线

把“人口标签＋同一份宏观简报”逐步改为：**生活处境 → 接触到的价格与消息 → 对未来价格的判断 → 问卷回答 → 群体分布**。

不是预先规定某类人应该报多高；先验证这条机制能否改善独立观察到的差异。经济学依据见 [价格体验](themes/household_price_experience.md) 与 [预期形成](themes/expectation_formation.md)，方法边界见 [Agent 模拟](themes/agent_simulation.md)，框架借鉴见 [平台案例](themes/socioverse_cases.md)。

**两线分别声明输入。** A 历史重建可使用后验同期画像和明确的统计约束；使用过的约束量不再作为独立效果证据。B 未来预测限定截止前已公开资料，并封存输出。以下最小机制试验沿用当前 A 线人口与历史发布稿 E，不注入同期真实回答，也不把这种干净的开发设计规定为全部重建研究的唯一形式。

## 2. 先把三种误差分开

1. **人口/抽样误差**：Core 覆盖哪些人，是否缺少某些人群，权重是否正确。利用已有抽样检查，不靠增加 LLM 调用回答这个问题。
2. **回答误差**：相同真实人口和允许的 E 下，模型的预期偏低、过于集中。新文献主要服务此处。
3. **扩展/计分误差**：Normal 的信息来自 Core；个人十档拟合还有近似。两者单独报告，不能将扩展人数当新增独立观察。

开发月统一 E 的截止点晚于部分真实作答日，个人比较继续按日期分组，并报告与全月口径的差异；不把任何组的更好结果挑为全国效果。总体标准差还可能受尾部影响，因此同时看四分位距、主要区间和极端回答，不把“std 到 7”设成训练目标。

## 3. P：先补有解释力的体验变量

**保留实测字段**：年龄、教育、收入、地区、就业、租住/自有住房。它们既服务代表性，也可通过消费处境和信息理解影响预期。

**候选补充**：食品支出份额、在家/外出食品构成、车辆与汽油支出、住房支出、日常购买频率、信息接触。先查 SCE 原始表的非目标字段，再查 BLS Consumer Expenditure 等公开资料。没有实测购物者身份，就不把“女性=买菜者”“就业=驾车者”写成事实。

外部资料与 SCE 无法逐人联结时，先估计有相应样本支持的条件分布，再多次分配合成体验；保留相关关系与缺失标记，报告分配不确定性。若只有组均值，就明确它是群体代理，不冒称个人消费篮子；不用相互独立的边际抽样拼出不存在的联合画像。

拟议记录分三类：`observed`（原资料观测）、`estimated_proxy`（统计代理）、`synthetic_assumption`（合成假设）。这些只是候选字段语义，不表示现有 schema 已接受。

幸福度、人格、政治倾向列为后置扩展，先找到条件资料与通胀判断的增量证据，不以扩大方差为唯一理由加入。

## 4. E：公共事实库和个体观察分开

公共 E 继续保存价格序列与新闻的原始时点证据。新建“观察视图”负责决定一个家庭接触哪些记录、以什么形式看到；它引用原信号 ID，不复制维护第二份宏观事实。

- 同一分项价格不等于个人实际支出涨幅；来源只有全国分项时标明代理。
- 数据数量与居民感知不是一回事。食品/燃油/租金体验优先有证据地呈现；非农、政策措辞等保留为可消融公共信息，不假设所有人全读懂。
- 新闻先按事前规则排除弱相关词义，再考虑来源、主题、更新与持久性；头版可作为关注代理，不能作为每个人实际阅读证据。
- 不默认加入上个月自己的答案。生活价格经历与当前信念状态不同于逐字记忆上一张问卷；年龄对应的终身经验也不能用十二个月宏观序列冒充。

## 5. B：第一轮只做最小对照

### 试验一：信息相同，改变表达方式

基线沿用当前标题＋摘要输入。对照使用同一批事实、数值、时间、新闻与次序，改成易读的居民表达；不添加虚构的生活事件，不写“应高于 CPI”“应报得更分散”。保留当前模型和解码参数，才能检验表达方式的作用。

问题：当前回答是否主要表现为宏观分析者的判断？评价原始 Core，不让统计扩展遮住变化。需要检查两臂转换是否误删或添加信息；若有变化，不能只归因于表达。

### 试验二：有来源的价格体验与观察视图

试验一完成后再考虑 2×2 对照：有/无体验补充 × 共享/个体观察视图。同一批核心画像、同一公共事实库和问卷，使用预先固定的体验分配与呈现规则。

选择少量有共同支持的人群和价格渠道先做；不一次同时改人口规模、模型、温度、新闻筛选和跨月状态。个体视图有意改变可见信息，应明确这是信息接触机制，不伪称纯措辞实验。对不同视图的长度与事实覆盖登记，必要时补同长度的共享视图对照。

问题：预期变化是否与有关价格暴露发生有方向的联系，而非所有家庭一起抬高？理论不要求每个人方向相同，短期价格冲击对一年预期的持续性判断需要单独检验。

尤其不能预设“加入食品或汽油就能修复偏低”：某月食品价格可能低于总体涨幅，家庭也可能认为能源冲击很短暂。体验机制必须按当时真实环境检验，不能把价格渠道当作将全国预期调高的旋钮。

### 后置试验

- 信息干预：构建内部一致的情景，比较同人不同允许信息的更新；模型中的响应不是现实政策的因果效果。
- 日期线索：保持数值和信息，比较明确日历/相对时间，仅作参数知识敏感性诊断。新闻仍可能泄露年份；结果不能证明模型忘记了历史。
- 跨月状态：找到经验/学习规则的来源后另做。先不恢复旧答案自动注入，不把问卷作答当真实价格形成反馈。

## 6. Analysis：评价什么才算有进展

所有臂先看 **未经校准的 Core 直接加权**，再同一规则扩展，两层并列。联合保留 Q8 与十档 Q9，分别用同一冻结计分口径处理模拟和真实回答。

核心评价包括：月度中位数偏差；加权分布距离及分位数；人群差异；个人 Q9 不确定性；Q8/Q9 内部关系；无效/圆整/极端回答；成本和运行波动。分布距离可用一维加权 Wasserstein 距离，直观含义是把一条预测分布搬成真实分布平均要移动多少个百分点。正式主要/次要指标待设计卡确定，不能看结果后换主指标。

重要区分：每个人 Q9 概率散布较宽，不等于人群的平均预期更不同；同一画像重复生成的波动也不等于真实人群异质性。

基线至少保留最后已公开的 SCE、简单宏观/经验模型、同信息的直接大模型问答、Core 直接加权。前一月指标能否用于预测，由其真实发布日期决定，不因文件里有 t−1 行就视为可用。

**开发筛选条件（待定具体阈值）**：信息语义无误、真实答案未进入 B、联合回答有效；分布或人群指标有稳定收益，不仅全国中位数接近；收益大于重复运行的随机波动。冻结选择后，再在未参与选择的时期评价。使用调查受访者重抽样与运行重复分别描述抽样和模型生成不确定性，不将 Normal 当独立样本使区间虚窄。

**停止/降级条件**：只有总体偏移、无群体改善；结果依赖某次合成分配；组支持不足；把复杂模块换为规则后效果相同；只在开发月有效。出现这些情况保留负结果，不不断调到全国数字吻合。

## 7. 校准单独走一条线

若原始模拟仍系统性偏低，可以研究基于已公开历史数据的校准或与简单模型的组合，作为独立版本，不能隐藏在 prompt 或 Normal 里。

- 历史重建：明确哪些已知统计量作为约束；独立评价未约束的分布、人群和时期。
- 未来预测：只使用截止前已公布的资料拟合；与同信息的持久性基线比较，样本外冻结。
- 同时报告校准前后；中位数整体修正不会自动恢复个体差异；不通过任意平移十档概率声称获得官方密度。

## 8. 交接实施顺序

**下一项可开工：零 API 的机制准备包。**

1. 对已保存回答补圆整/概率模板/分位数和 E 引用诊断；复用既有权重与真值审计。
2. 核查 SCE 与 CE 的体验字段及可得版本，输出字段映射、条件样本支持、缺口和合成假设。
3. 整理新闻词义与信号表达规范，制作同人同信息的两版输入样例，不调用模型。
4. 写试验一运行卡：固定模型/P/E/问卷、臂定义、重复策略、主要指标、独立月份与预算；用户可审阅具体样例。
5. 之后才进入新付费 Simulation；冻结有效设计后推进跨期验证、再建设预测线。

预计实现位置仍是本 study 的 `population/`、`environment/`、`model.py` 与 `evaluation/`；新字段和 prompt 使用新版本，原实验输入和输出不覆盖。本轮不改这些代码，不触碰用户未审旧批次。
