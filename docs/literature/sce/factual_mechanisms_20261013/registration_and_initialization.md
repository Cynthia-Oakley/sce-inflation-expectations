# 上期状态、新入组者与数据账户

2026-10-13核查。回答用户三项问题；没有注册账户、签署协议或发送邮件，没有下载人格微观或新增模拟。

## 上期信念的来源

当前新版机制实验按月独立，规范先验尚未接入。建议先做A线机制诊断：原输入/真实上期本人信念/同库存置换；另有不调用LLM的真实上期原样延续基线。这个实验研究“有真实起点时如何更新”，不能称独立完整重建。

正式连续模拟由自己的上期模拟状态向下滚动。A允许披露一个真实历史起点；B只能从截止前可得的经验分布初始化。逐月真实上期条件与只在开始时初始化的自由滚动是两种实验，分别报告。原先旧全年消息含前期模拟答案，但未完成上述规范对照。

工程需区分真实首次参加SCE与只是首次被本轮Core抽中。对连续模拟可用已实现的stable_priority_srs从每月完整人口框架选Core，使已有Core尽量延续，保留每人状态；它不要求人口全为返回者交集。退出/进入仍按每月设计处理。被新抽到但历史已在Normal的人，其统计生成状态必须标明来源，不能称此前真实LLM回答；完全无模拟历史者再初始化。当前独立月度运行不能凭空补出此前状态。

新入组者使用过去已观测入组样本、人口共同字段下的经验分布初始化；需原tenure标记确认真入组，不能把数据文件的第一行当首次调查。样本支持不足保持未知；抽样概率来自数据，初始化以后沿用本人生成状态，不每月重新抽。

## 新入组者的财务变化

新入组并不意味着没有生活历史。已有Q1直接回顾过去12个月，可以保留当期原义；这是回顾状态，不是精确发生在本月的冲击。没有之前就业/收入记录时，Diff标为unknown，不能填0或推断未变化。从第二次有相邻观测起计算状态变化；漏访不能当一月差分。收入档变化不称精确收入增长。A用允许的观察；B用合成状态及已公开信息，真实t期记录仍只进评价。

## 费用与注册

UAS注册免费；普通数据访问还需本人签署Data User Agreement，启用前由提供方审核。[官方免费说明](https://covid19pulse.usc.edu/)。在[研究用户注册页](https://uasdata.usc.edu/index.php?pid=Create+new+account&type=3)填写学校邮箱、真实姓名、Fudan University等实际信息，建立临时账户，按页面办理相应协议。不是报名调查受访者。不能替用户承诺协议，也不需要向Agent提供密码。

MIDUS/NACDA公开文件免费，且不要求学校购买ICPSR会员。[官方费用说明](https://www.icpsr.umich.edu/sites/nacda/posts/shared/how-do-i-access-the-data-is-it-free)。可直接用[MIDUS portal注册](https://midus.colectica.org/Account/Register)，或按[ICPSR Researcher Passport步骤](https://www.icpsr.umich.edu/sites/icpsr/posts/shared/log-in-or-create-account)用学校邮箱开户、验证并补资料。首批只需MIDUS2主调查与自填问卷的人格/乐观字段及字典，不申请基因等受限项目。账号与具体数据协议均由本人办理。

## 必须先确认AI使用路径

UAS现行页面明确限制微观交给AI及AI编辑器索引；允许的汇总可支持研究。MIDUS注册页亦限制公共/不保障保密与不留存的外部AI上传，并要求发布表格满足其披露规则。注册不意味着获得直接给Codex、Kimi或Simulation API读微观的许可。下一步先写只依赖码本的统计程序，用户在隔离位置运行，分享允许的群体汇总；合成输出的具体使用按协议核准。此条修正此前“取得数据后直接让Agent做逐行donor”的设想，费用不是唯一准入条件。
