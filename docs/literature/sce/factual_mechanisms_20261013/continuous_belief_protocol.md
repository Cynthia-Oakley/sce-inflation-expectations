# 连续信念模拟：先防止把误差滚大

2026-10-13方案草案。记录用户同意的方向：B线可使用自己上个月的信念，但须监测误差累积；无历史者可以赋予有经验依据的合成初始信念。本轮没有改运行配置、没有准备已获预算的真实调用。

## 两个实验分开回答不同问题

**A线条件更新诊断：** 对确有日历相邻记录的返回者，允许把真实t-1信念作为已披露起点，t回答只用于评价。它研究“起点给对时，能否合理更新”。每个月给真实起点属于条件诊断，不能和自由滚动结果混报。真实问卷发送API需要新的明确范围许可。

**B线自由滚动：** 起点只用预测时已经公开的历史数据生成；以后只用自己的模拟信念。不能每月偷偷用真人回答纠偏。人口、新闻、宏观、总体SCE初始化参考均服从预测起点的公开日；当前MIDUS2025新增权重不能直接进入2021年B回测。

## 初始信念如何分配

先核查真实入组标识，区分首次参加SCE、第一次被抽为Core、因资料缺失暂时接不上上月三种情况。共同人口字段下的历史真入组样本可用于形成经验分布；样本不足逐级退到更粗但有支持的分组，仍不足则未知。一次抽取同一人的信念中心、分散程度或原始概率向量，保留它们的联合关系；不分别随意随机。

如果用已经公开的总体SCE更新过时的初始化分布，这是额外假设，应与不移动分布的版本做敏感性比较，不能直接宣布其为真实当月微观。

Core和Normal遵循同一初始化与状态来源规则。Normal如果采用统计投影，注明它的状态由统计方法产生；不称此前有真实LLM回答。新成为Core但此前有模拟状态的人继续该状态，没有记录才初始化。

## 最小对照

- 现有独立回答：每月同版P/E、无原有信念。
- 连续回答：同版P/E，加入本人上期模拟信念，只初始化一次。
- 免费延续基线：初始信念不更新。

第一轮先固定人口机制与E，不同时增加人格、购买频率或新的记忆噪声。新版与旧全年不同PE的结果分开；旧Qwen继承DeepSeek历史答案的实验不能代替本次自身滚动。

## 如何发现误差累积

按连续运行1、3、6、12个日历月分别报告总体Q9中心MAE及有方向的偏差，并列每月原值，不只给全段平均。Q8另报。再看个人更新幅度、群体分布距离、人际IQR、个人不确定性、不同人群及返回/新入组者差别。评价层才读取真实答案和当期真实调查权重。

总体可跨12个月评价。按通常12次月度参与的设计，同人一般最多提供11次相邻变化；漏访与扩展参与另列。不能强求每人有12次变化，也不能只挑全程返回者冒充完整人口。B的预测人口权重与评价中真实权重各自记录，不将后者倒流成预测输入。

**数据核查补充（2026-10-13）：** 上述12个月是通常的官方设计描述，不能当作实测文件的绝对上限。当前106月数据有893条tenure13—16记录；tenure随实际作答次数加一，漏访会拉长日历跨度。首轮先验实验另列这些扩展记录，后续解释或作敏感性分析，不把正常漏访误标为不一致。完整核查见[先验准备记录](prior_preparation_receipt.md)。

误差持续同向扩大、越来越集中、或反复照抄先验，是需要停下诊断的信号；不规定人为“每月回归真实值”来遮掉问题。可先做有限的单步更新诊断，再决定是否需要修正信息理解或记忆表示。

## 真实实验前还缺什么

1. 校验tenure/入组字段与历史公开时间，选定有支持的初始化库存。
2. 实现明确的state来源、同ID延续、漏访/退出与新入组处理；目前这是方案，不是已接入功能。
3. 登记未用于调参的时期、种子、目标和具体API预算，再输出完整提示预览与离线轨迹。
4. 用同一人群、同一E、同一模型/温度对照，不以先验条件实验的好成绩代替B预测。

当前优先把初始化与人格的事实来源做好；此草案不自动授权或启动一轮新模拟。
