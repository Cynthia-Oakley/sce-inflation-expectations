# 信息窗口、新闻数量与先验表示：讨论记录

2026-10-13。用户提出三个后续比较方向；本页记录候选设计，不冻结参数、不修改现有288份输入，不产生API调用。

## 1. 最近价格走势

当前提示列出六类指标最近12次月度发布。数据窗口不等于居民能够准确回忆的月份数，也不由问卷的12个月预测期限必然决定。用户提出比较6个月与12个月；这是待验证假设，不能直接断言人只能记住6个月。

后续保持同一人、最新值、信息截止点、预测期限和其他输入，只改变历史长度。原始数值序列与简短趋势描述是另一项独立比较，不能同时改变后归因于窗口长短。

## 2. 每人3篇共同加5篇个人新闻

早期实验确实给每人同一组30篇新闻。后来的新闻接触实验改成3篇共同A1新闻加5篇个人新闻：控制各组信息条数，检验共同背景、随机接触与画像加权接触的差别。新闻库仍可有数百篇，8是单人收到的条数。

有限接触及提示长度是设置的实验理由；没有真实阅读记录证明8条最合理，也没有新闻数量对照证明优于30条。它不是用户明确指定的条数。后续可比较8与更多新闻（例如16，仅为候选），固定库、筛选标准、截止点和抽样规则；单列条数、主题覆盖与重复信息量，不能用条数替代信息充分性。

## 3. 完整上期Q9与摘要

当前A线诊断使用同一真人上个月的Q8和完整Q9十档概率，不是Agent此前生成的回答；未输入本期真实答案。B连续模拟应在初始化后使用自身生成的上一期信念；新人已有历史联合Q8/Q9分配候选，尚未接入运行。

完整概率保留中心、个人不确定性、偏斜及通缩尾部，可能帮助维持真实差异；但明确展示所有上期概率也是一种完整提醒，不能等同于自然回忆。改善可能来自直接延续，所以需与“原样延续上期回答”的免费基线比较，并检查更新幅度和分布，而不是只看总体误差。

摘要比较建议至少保留个人预期中心和个人不确定性，而不是只给一个中位数。个人拟合密度均值、个人拟合密度中位数、各区间中点和跨人中位数是不同对象；项目主指标是个人密度均值的跨人中位数。摘要使用哪一种必须显式登记，摘要格式不改变最终计分口径。完整概率与摘要组保持相同上期Q8及其他P/E，仅改变上期Q9表示。

## 推进顺序

先完成已准备的无先验／本人先验／置换先验对照，判断本人信念是否带来更新价值。再逐项测试先验表示、历史长度及新闻数量，避免一次改变三项而无法解释。具体规模和顺序仍可讨论；新的付费调用另登记范围与预算，尤其需明确真实上期问卷的外发。
