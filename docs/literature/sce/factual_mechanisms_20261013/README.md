## 1. 原有信念：先从同一人的上期记录入手

官方SCE轮换面板最多跟踪个人12个月，适合研究个人如何改变回答。[官方说明](https://www.newyorkfed.org/microeconomics/sce/sce-faq)。上期Q9是“上期对未来12个月的自报分布”，是原有信念的代理，不是完整心理状态，也不证明本人记得上期填写的数字。相邻两题预测窗口重叠11个月，所以持续性不能全部归因于记忆。

本轮用已验收106月数据，在同一ID内严格匹配相邻日历月，跳过漏访间隔，不跨人、不补缺。130,216条人月中有17,141个不同ID；找到106,351对相邻记录，其中103,630对Q9个人均值有效。2021-05有1,038/1,234人能接上月，2021-06为1,070/1,297，约84.1%和82.5%。

扣除各月共同水平、每月等权后的个人Q9相关系数约0.579；不加权月内秩相关的月均值约0.636，也支持其并非只由极端数字驱动。个人不确定性相邻相关约0.749。相关只是描述证据，不是“学习权重”，不能把0.579直接写成模型的更新系数。

同一批有效返回者中，用本人的上期均值直接预测本期，跨月等权个人MAE约2.829pp；统一用该批人的上期中位数为所有人预测，约3.712pp。两个比较都没有LLM，均属于A线诊断，使用本期评价权重；不是全国headline误差、不是严格事前预测，也没有解决本期信息怎样更新信念。各年均有个人历史的增量关联，但尚未做个人效应与稳定报告习惯的识别。

### 两条路线怎样使用

**A线先做有真实起点的更新实验。** 对返回者，取t-1真实Q8/Q9作为起点，t的真实回答只用于评价。可先只呈现“此前大致预期”及不确定性，后续单独比较精确分布与较粗信念摘要，不能凭当期拟合挑表示。精确地提醒原回答是一种信息干预，不自动等于自然回忆；该差别须写在实验解释中。

三组候选：原输入；加入本人上期信念；加入同月同库存置换的上期信念。三组人口、当前E与问卷一致。另保留不调用LLM的“本人上期答案原样延续”基线。重点评价t-1到t的变化方向、变化幅度、分布和群组差异；如果模型仅重复原回答，水平更近也不能称完成了更新机制。置换对照检验个人联结的增量，不是替真实居民随机编信念。

随后可做自由滚动：只在开始月用真实起点，后续使用自己的模拟状态，不逐月重新给真人答案。它能检验误差是否累积，不能与每月用真实前期答案的结果混报。旧全年实验虽曾给前期答案，但没有规范的这组三臂，也有跨模型继承，因此不能替代本次设计。

新加入、无上期记录的居民另作一层：从过去已观测入组样本、按人口共同字段建立经验分布；缺支持时保留未知。把返回者交集作为机制样本，不把它冒充完整当月人口。之后再验证入组/退出与Core/Normal的统计扩展。

**B线不能直接用真实t-1微观答案。** 公开微观有约9个月时滞；居民本人有信念，研究者当时未必能观测。可从截止前已公开的历史微观联合分布初始化合成信念，适当参考已经公布的总体SCE，并把分布平移/更新假设明确登记；后续用模型自身状态更新。这里的抽样有现实经验分布依据，却仍是合成代理。已有新闻、宏观、画像与初始化都须按自己的公开日审计。

纽约联储已有用同人三个月变化研究更新的实证，可以借鉴其控制共同月份和地区条件的思路；我们不能把其观察相关直接当因果或固定系数。[原研究](https://libertystreeteconomics.newyorkfed.org/2016/08/how-do-people-revise-their-inflation-expectations/)

## 2. 购买频率：本轮已落地分类购买日

从现有2020Q4 Diary EXPD与同周FMLD，按原字典映射生成以下类别的0—7日出现集合：居家食品、外食、家庭用品/服务、个人护理用品/服务；另保留其他和未知类别。原映射包含服务，不能把它们全称为高频日用品。本轮只计算正金额、PUB_FLAG=2、有效日码与D/E/T标志；记录无正支出、部分日支持和错误金额。

2,835条家庭周的分类日集合并集，全部与原始已验收总日集合对上。居家食品有2,239条完整正支出日记录，外食1,737条，家庭用品/服务1,329条，个人护理753条。在这些有完整正记录的周内，带权购买日中位数分别约2、2、1、1；不是全美家庭的长期购买频率。食品两周都完整且正支出的同户有936户，两周日数差的中位数1日；个人护理只有151户。不能拿这一周的零记录认定长期不关注，也不能把只保留双周正购买者的稳定性外推到全样本。

下一步分两个层次：先估计群组的类别接触分布，再做个人合成。Diary内按年龄、教育、收入和住房等共同字段匹配整条周记录或整户双周记录，保留各类之间的联合关系；周权重与户聚类分别处理。不能把已有Interview消费篮子donor与Diary按编号接成一个家庭，也不承诺不同样本间未观测的“金额—频率”关系真实。收入字段、调查单位和共同分箱还需专项核验，本轮尚未产出SCE的频率persona。

BLS说明Diary记录两周，主要适合较小、较频繁的开支。论文扫描购买次数/数量与本代理测度不同。[官方数据指南](https://www.bls.gov/cex/pumd-getting-started-guide.htm)。当前2020Q4为后续修正版本，只支持披露的A线探索，未通过2021-05/06的B历史版本验收。

候选验证应先在同E中仅加频率代理，检查模型是否有反应；再独立改变价格接触抽样。比较条件匹配与同库存置换，信息量保持相近。频率影响接触机会，不规定预测一定提高，更不把商品CPI按频率相乘后当成居民必须回答的值。

## 3. 个人经历改为近期财务处境：先测状态变化

已有Q1是“目前相较12个月前的家庭财务状况”，此前加一句Q1未稳定改善，不能把同一句话换个模块名后当新方案。更有增量的切入口是同一人的Q1变化、就业状态转变、家庭收入档变化，并在先验信念给定时，检查它们是否与预期更新、价格注意的差异相关。

Q1相邻变化是滚动自报变化，不能精确推断某月真实财务冲击；收入档变化不是精确收入增长，就业多选变化不自动是一次失业事件。先登记真实可见状态，例如“过去一年自报财务较差，上期为差不多”；没有记录就不写医疗、裁员或欠款原因。近期的情绪也不能由Q1直接当作实测。

落地候选：把事实状态放进个人状态块；先研究其与本人原有信念、当前价格信息的交互。若进一步用状态改变被唤起的经历/价格线索，应另作明确的注意或回忆情景对照，与单纯状态句比较，不能把规定出来的情绪反应称为已识别的人类机制。模型理由只作响应线索。

现阶段先做离线“相邻Q1/就业变化与Q9更新”的关联核查，并控制月份与此前预期；这里尚未完成新的状态转移全量分析。A可披露用当期状态，B需截止前实测/合成状态及来源。研究路径有理论依据，新的提示和参数仍待验证。
