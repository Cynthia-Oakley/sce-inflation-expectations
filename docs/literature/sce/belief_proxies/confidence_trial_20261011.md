# 四个时期的央行信心实验

2026-10-11｜水上挽月｜实际提示已固定，八次规则干跑通过；真实API预算确认待回复。

## 这次要回答什么

当居民看到相同的价格、新闻和政策信息时，加入其对美联储主席的信心，能否让一年期通胀回答更接近SCE？先检验这种提示是否有稳定作用，再决定是否继续研究心理属性。不是预先要求高信心者报低通胀，也不把模型变化直接当作真人机制。

## 两组怎样比较

- 月份：2022-03、2022-09、2023-03、2024-03，沿用各月原定信息截止点。这是路线A的历史机制研究。
- 每月同48名真实调查者的去标识画像，两组保持相同人口、合成CE篮子、77条价格/经济信号、共同3篇头版与个人5篇新闻。个人新闻仍为50%均匀与50%相关加权的抽样分布混合。
- 不加信心组：提供上述信息与原Q8/Q9问卷。
- 加信心组：在问卷前仅增加一句对美联储主席经济决策的信心描述，来源为截止前最新已公布Gallup波次的全国分布。没有观点者不编造态度，其两组提示完全相同。
- 每种输入独立生成两次，共768份回答；重复编号不是模型可控随机种子。两次新闻和信心分配相同，所以能检查生成波动，尚不能检验换新闻样本的波动。
- 模型沿用DeepSeek官方`deepseek-flash`，温度0.5、非思考模式、最多1024输出token、无自动重试；不同时更换模型或计分器。

## 为什么两组都加入政策短讯

原新闻抽取中，四个月仅14/48、48/48、30/48、17/48名样本的新闻文字提到美联储或货币政策；提及也不等于完整传达政策行动。因此这轮两组均提供同一段、三句话的美联储历史声明摘要，内容为当时利率行动、通胀判断和政策意图。先研究收到同一政策消息后怎样理解它，避免只加一个信心标签而没有可解释的政策信息。

这是控制信息接触的实验安排，不代表现实中所有居民都读过声明；它也使本轮和旧两月实验无法作单变量比较。政策目标、政策判断与实际未来结果明确区分，长期2%目标不是一年后实现2%的保证。四份官方来源与历史版本限制沿用[覆盖方案](coverage_plan_20261011.md)。

## 运行与评价先固定什么

192对实际提示已逐字检查：去掉新增信心句子后两组完全相同；真实ID、调查权重、当期通胀回答和真实支出不进入提示。独立行为组件沿用现有SocioVerse2引擎、原始回包/轨迹和费用记录。八个月份×组的规则干跑只验证输入到轨迹的通路，不评价拟合。

主要看三件事：Q9群体中心误差、人群分布距离、人际差异的偏差。每次生成分别报告，四个月等权汇总；同月两组只比较双方均有效的相同人员。Q8点回答、个人不确定性、原始通缩概率、年龄/住房/数理能力分组作为补充。权重只用于评价侧的辅助统计，不给Agent；另看完整调查总体与48人样本的差别，区分人口抽样和回答机制的误差。调查日期只用于评价侧分组，不宣称每位真人已看到共同截止点的所有信息。

真实十档回答与模拟十档回答均使用已有冻结近似计分器。完整调查参考另外列官方微观派生值，明确其与项目近似计分的口径差异。逐人误差是辅助诊断，不能当作个人反事实的真实性证明。

继续研究的预设门槛：两次生成中，Q9群体中心误差与分布距离的四月均值都下降，并且各自至少三个月同时改善。达标也只作为候选，不自动升级正式P；未达标照实保留结果，不在这四个月上继续筛选参数。配对人员重抽样区间仅描述固定新闻/信心下的样本不确定性，不覆盖时期和新闻分配的不确定性。

## 成本和操作状态

19项定向检查、八次规则干跑通过。768份实际提示按[官方较高费率](https://api-docs.deepseek.com/quick_start/pricing/)与最大输出量预留约$2.280414，16个运行各有独立上限，总预算建议$2.50。真实用量与无用量失败的保守预留逐次保存；它们不是供应商账单。已发送具体数据范围和预算确认，收到明确答复后才执行本批API。

连接错误后保留本单元调用证据并停止后续单元；不自动重发。所有旧结果、50/50参数、计分器和15份待审文件保留。

## 主要局限

信心是年度成年人调查比例合成，不是SCE受访者实际态度，更不是直接测量“相信央行抗通胀”。四个波次映射已有5—11个月时差，未按人口特征估计联合分布。2024-03的48人随机分配没有“很大信心”样本，不据此解释该类人群。

CE2020Q4跨年代表性、汽油历史版本、NYT历史文本与纸版日期仍有未核验部分。四个时期并非全项目盲测、48人不是全国样本；本轮不能直接宣布完成路线B未来预测，也不包含Normal人口投影或居民之间互动。

## 文件与接力入口

- 冻结准备包：`outputs/sce_confidence_trial_20261011_v1/`，完整消息、两组运行配置、来源哈希、规则干跑记录、人员关联表均在此；含画像的文件仅本地。
- 真实运行入口：`scripts/run_sce_confidence_trial.py run --folder outputs/sce_confidence_trial_20261011_v1 --approval-note '用户实际授权原话'`。不能重复启动已有运行；无预算确认不能添加执行参数。
- 原始轨迹/调用：`outputs/local_runs/<run_id>/`。
- 独立评价参考：`data/evaluation/sce_confidence_reference_20261011_v1/`，从官方原始工作簿提取，绝不被Simulation读取。
- 分析入口：`scripts/analyze_sce_confidence_trial.py analyze --trial outputs/sce_confidence_trial_20261011_v1 --truth data/evaluation/sce_confidence_reference_20261011_v1 --out outputs/sce_confidence_analysis_20261011_v1`。
