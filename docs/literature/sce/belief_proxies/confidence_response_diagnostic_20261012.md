# 央行信心实验之后：模型目前像什么，问题在哪里

2026-10-12｜四个调查月，每月同48人，两组各生成两次｜只复查已有回答，无新API费用。

## 1. 先保留有用的部分

按用户本轮意见，保留央行信心机制的代码、输入、来源、两组配置与全部结果，作为后续研究可选模块。原试验不覆盖、不重新调参，也不把合成信心说成SCE受访者实测态度。

Q9群体中心绝对误差的八个单元平均从0.736降到0.565个百分点，少了0.171个百分点，相对下降23.3%。这是相对同一批真人样本的中心误差，不是全国指标误差，也不是预测未来实际CPI的误差。两组都看到了相同政策短讯，只有一组增加个人信心句子；本轮不能单独证明“加入央行新闻”的效果。

人群分布距离仅改善约2.3%。因此，新的线索是：信心描述有助于调整回答中心，但尚未重建整个人群的不同看法。

## 2. 两种“分散”，必须分开

**不同人之间的差异**：甲认为未来通胀约2%，乙认为约7%。这里问“大家想法是否不同”。本轮模型中间一半人的Q9中心只相差约0.72个百分点，真人约5.78。仍然太像。

**一个人自己的不确定性**：甲觉得2%最有可能，但也可能0%或5%。这里问“一个人对自己的答案有多确定”。本轮典型个人概率曲线的中间50%宽度，单元平均为模型4.30、真人3.59个百分点。2022-09差距较大（约5.09对3.43）；2024-03模型约2.90、真人约3.20，已经接近且略窄。

因此，“个人区间一直比真人宽”不成立。更稳定的差别是：真人有人很确定，有人很不确定；模型连不确定程度都很相似。个人不确定程度在人群间的中间50%跨度，模型约0.40、真人约4.25个百分点。

上述指标均为八个单元分别算出后等权平均，同一人重复生成不会算成两个真人。不用“平均概率曲线很宽”代替“人群中心差异很大”。

## 3. 十档概率还有什么不同

真人每人的非零概率档数中位数，各月均为4；模型通常为8—10。程序允许填0，未要求每档大于0。

共同有效样本中，约59%的真人将通缩概率填为0；模型为0%。模型普遍给价格下跌留一小段概率，真人则是多数填0、少数填得很高。四个时期的平均通缩概率，模型约9.04%、真人约14.82%，所以不能笼统说模型总是高估通缩。

2024-03的典型回答差异仍明显：通缩概率中位数模型15%、真人约3%；但平均概率约15.65%对14.69%，其实接近。这里主要缺少的是不同人的差别，而不仅是平均概率的高低。不把通缩概率直接删掉，也不要求所有真人更集中。

## 4. 点回答与概率回答为什么可能不同

一个已存模型例子（2024-03第一次生成，加信心组首个共同有效匿名记录）：点回答2.8%；Q9十档从高通胀到高通缩依次为1、3、12、34、30、12、5、2、1、0%，近似拟合后的个人中心约1.71%。其理由是通胀正在缓解，下一年会继续略降。理由没有直接解释为何给通缩20%的概率；这是待查线索，不能证明模型混淆“涨幅下降”与“价格下跌”。

模型2024-03逐人“点回答减概率中心”的中位差，两次平均约0.88个百分点，真人约0.02。2022-09则不同，模型约−0.11、真人约−0.41；不是所有月同一种差别。

点回答不必等于概率均值。纽约联储指出，人可能报告其概率分布中的不同中心概念；不能为了拟合而硬把Q8和Q9设成一样。[官方测量说明](https://www.newyorkfed.org/newsevents/speeches/2014/mca140624)

**修正原阅读页一句话**：不是“Q8总体比Q9更接近真人”。本轮四月平均中心误差，Q8加信心组约0.787，Q9约0.565个百分点；2024-03的Q8更接近，但2022-03反而更差。原始数值未改，仅修正过于宽泛的文字。

## 5. “改善区间包含0”是什么意思

先在这48人上观察到改善，再从这48人的配对记录中反复重抽，检查样本组成变化时这个改善有多稳定。

例如2022-03第一次生成，加入信心后的误差少了约0.135个百分点；人员重抽样的95%区间，从误差减少0.563到增加0.292。这个范围经过“没有改善也没有变差”的0，所以当前样本不能排除没有稳定改善。

不是“真实效果等于0”，也不是“实验白做”。应保留作为正向线索，补跨时期与独立生成验证。8个区间中7个跨0；两次生成仍是同一批人。这些区间不包含换新闻抽样、换信心分配或新时期的不确定性。

## 6. 原因与下一步：先区分四层

### 信息接触：大家看得过于完整、相似？

实际消息给每个人相同的六组12个月历史序列、当前价格和就业统计、三条政策短讯，再加不同新闻和合成支出份额。不同新闻不等于不同价格经历，支出份额也不等于购物频率或注意力。

纽约联储价格信息实验发现，统一提供信息后，人群预期会向中心收敛；原有认知与信息更新存在差异。[研究原文](https://www.newyorkfed.org/medialibrary/media/research/staff_reports/sr543.pdf) 这支持检查共同信息过强的可能性，但不能据此断言本模型的同质化已由信息表导致。

下一步候选：在相同底层事实下，对比“完整统计表”和“有限共同背景＋不同家庭接触的价格线索”，分别检验中心和人群差异。不是随意给家庭添加涨价数字，也不是按效果删掉不利消息。

### 解释：同一价格变化，大家都认为会缓解？

模型理由频繁提到缓解、降温、涨幅回落。但理由是回答之后生成的文字，简单关键词也有误判，不能作为行为因果证据。合成信心目前能改变中心，类别与中心变化却不是每月单调对应；没有证据建立“信心高必定报低通胀”的固定规则。

下一步先核查已经准备的持续性对照原型及其数据依据。另设计同事实下对政策有效性或涨价持续性的单一变化，保留无新增信念组，避免同时改E、P和问卷。

### 作答：同样的想法，是否用了不同的概率表达习惯？

现有问卷已允许0，却出现几乎人人铺开8—10档的模式。这可能是模型通用回答习惯，也可能是未来风险判断较相似；两者尚未分开。

候选对照只澄清：0是合法回答、涨幅回落不等于价格下跌、所问为接下来12个月的价格涨幅。不指定概率数量、不强制变窄、不要求点值等于均值。看澄清能否改善真实十档形状与中心；若无作用，再研究有数据依据的概率报告习惯。

### 计分：连续曲线是否放大了原始回答差异？

冻结近似计分器对真人与模型统一使用，尾部和稀疏档的处理仍有误差。原始非零档数、零通缩比例的差异无需拟合即可观察，不能全归为计分器问题。后续只在评价层补尾部/计分敏感性，不修改或覆盖冻结结果。

**建议顺序**：保留信心模块 → 先审定概率语义澄清和价格感知对照的离线输入 → 登记尚未用于调整的时期、新闻种子及评价门槛 → 新预算确认后，分开检验两个机制。当前没有启动任何新付费实验。
