# 扩到四个新月份：数据准备与政策信心方案

2026-10-11｜水上挽月｜已开始本地准备，新增付费调用为0。

## 1. 当前结论

**人口、价格序列和新闻原文都已有覆盖；新版新闻分类和正式运行接入尚未完成。**这次先做路线A的历史机制试验。利用当月真实画像，不代表当时已拿到画像，不能直接叫路线B预测。

四个候选月已从已有文件整理成独立输入，保留整月人口和固定种子42的48人样本：

- 2022-03：完整人口1273人；价格信号77条；新闻窗口5224篇，粗筛653篇待分类。
- 2022-09：完整人口1271人；价格信号77条；新闻窗口5087篇，粗筛611篇待分类。
- 2023-03：完整人口1254人；价格信号77条；新闻窗口4718篇，粗筛524篇待分类。
- 2024-03：完整人口1120人；价格信号77条；新闻窗口5085篇，粗筛490篇待分类。

整月画像的年龄、教育、收入档、地区、州、数理能力、就业、可沿用住房标签均有覆盖；住房仍只是入组答案的历史沿用，并非每月重新测量。抽样不读取当月通胀答案。权重和调查日期仅存评价侧文件。

这些月份覆盖不同经济阶段，能检查机制是否只适合原来的2021年5/6月。**它们不是整个项目从未见过的盲测月**：真实统计和基线曾被查看。48人也只是机制小试，不能据此宣布恢复全国指数。

## 2. 需要补什么数据

不重抓SCE、BLS与NYT大库存。四个新窗口的2278篇粗筛候选尚无旧标签可复用，已按原v1.2分类提示准备285批公开新闻输入，每批最多8篇，**没有发送**。头版继续按真实记录的A1版面作共同背景；个人新闻待精筛后沿用50%均匀、50%相关加权及同条数规则。不同日期对同一事件的报道继续保留。

新闻窗口为上一日历月起点到原定纽约时间截止点，现以带时区的线上发表时间核查。它更精确地区分UTC与纽约日期；不改变各月截止点，也不能证明文章历史文本或纸版刊载日。新月份两组必须用相同新闻输入，不能将新月份与旧两月之差解释为信心效果。

现有77条中有13条汽油历史特征沿用当前快照，发布日期含保守假设；其余BLS来源来自已验收首发稿管线。它们可带局限用于A，但**完整E未获得严格历史版本认证**。

固定的CE2020Q4供体库已给192名样本生成四类合成篮子，5203个合格供体，保留完整向量和匹配退让记录。这是为控制既有机制而暂时复用旧篮子；**2020消费关系跨到2024是否稳定尚未验证**。将来扩规模时可补较新的CE，当前不同时改变篮子和信心，以免无法解释变化来源。没有生成购买频率或公用事业份额。

## 3. 央行、政府信息如何加入

### 公开政策消息属于E

已下载四份截止前的美联储声明，整理了利率行动、通胀判断和政策意图的简短事实草案：

- 2022-03对应2022-01-26声明。
- 2022-09对应2022-07-27声明。
- 2023-03对应2023-02-01声明。
- 2024-03对应2024-01-31声明。

来源为[2022年1月](https://www.federalreserve.gov/newsevents/pressreleases/monetary20220126a.htm)、[2022年7月](https://www.federalreserve.gov/newsevents/pressreleases/monetary20220727a.htm)、[2023年2月](https://www.federalreserve.gov/newsevents/pressreleases/monetary20230201a.htm)、[2024年1月](https://www.federalreserve.gov/newsevents/pressreleases/monetary20240131a.htm)官方声明。

已公开不等于每个居民都读过声明。首先检查精筛后的新闻是否已传达政策行动；需要补信息时用简短新闻/事实，不默认给所有人完整声明。美联储的2%长期目标不能写成对未来12个月实现2%的保证。政府的补贴、关税、税费等政策事实也可走同一事件流程，按公布与实施时间分别记录。

**增加政策事实本身是一项信息处理；研究信心时，两组的政策事实和接触安排必须相同。**因此不在同一个组里同时加政策卡与信心、再将改善全部归因于信心。

### 居民信心属于P

Gallup有真实参考，但测的是“对美联储主席为经济做出正确决策/建议的信心”，不是直接测“相信央行能抗通胀”。先保留这一较窄含义，在题目前增加一句看法，**不要求模型据此报更高或更低的通胀**。

按截止点使用此前最近已公布的调查，而非按年份机械配：

- 2022-03采用2021年4月波次，2021-04-26公布。
- 2022-09采用2022年4月波次，2022-05-02公布。
- 2023-03仍采用2022年4月波次；2023年波次此时尚未发生。
- 2024-03采用2023年4月波次，2023-05-09公布。

全国五档原始比例：2021为12/43/17/17/11，2022为8/35/26/22/10，2023为4/32/26/28/9。因四舍五入，后两年合计101/99，按各自合计归一化，不依据SCE答案调整。来源为[2021问卷与分组表](https://news.gallup.com/file/poll/348980/210426Economy.pdf)、[2022原报道表格](https://news.gallup.com/poll/392306/confidence-economic-leaders-flagging.aspx)、[2023问卷与分组表](https://news.gallup.com/file/poll/505484/230510ConfidenceLeaders.pdf)。2022全国数据由当年网页直接核对，而非仅从后来报告倒推。

**第一轮跨月候选按全国分布抽取信心，不声称按家庭特征正确匹配。**同一家庭用固定随机数；没有观点者不编造政治态度。教育条件匹配的旧2021方案仍保留：2023也有教育交叉表但未转录，2022当前来源没有同口径教育表，不能将2021教育关联不加说明地延续到所有年份。

年度调查的看法在三个3月窗口已约陈旧11个月，2022-09约5个月。只能把它作为合成先验与敏感性参考，不能称当月真实信心。Gallup成年人也不等于SCE家庭户主。政府信任与央行信心的相关性没有已验收联合数据，因此先分别研究，不默认两者独立。

## 4. 接下来按什么顺序做

1. **补新闻分类**：复用原粗筛/精筛标准，不再调整原两月参数。实际调用前核查当前价格、生成受预算约束的运行包，再确认新预算。
2. **固定两组实际输入**：每月同48人、同CE篮子、同77信号、同头版与个人新闻，一组不加信心、一组加上述合成信心。只改这一句话。公开政策卡暂为备选，两组若用则同时用。原模型、温度0.5、Q8/Q9及冻结计分器不同时调整。
3. **重复与验证**：候选每种输入生成两次，共4×48×2×2=768份回答；这是待审方案，不是当前已授权调用。模型未必支持可控随机种子，记录重复编号和实际回包，不假称固定了生成随机性。新闻固定主种子104729，备用130363先作离线接触敏感性检查；信心分配固定42，备用1042只作离线分布检查。
4. **运行接入与干跑**：注册独立行为入口，保存实际消息、来源和费用日志。当前只有材料与候选信心文字，**没有完成真实LLM行为入口或最终提示**。月包中的simulation.json仅为旧scripted准备模板，不能当正式运行配置。
5. **评价后再决定升级**：同月同人有效Q9样本与两组共用权重，先比较Q9个人中心的群体中位数误差、人群分布距离和跨人差异；Q8、个人不确定性、通缩概率及分组误差同步报告。也另列对完整调查总体的偏差，区别人口抽样误差与模型误差。共同截止点不是每个人真实作答时间，利用评价侧调查日期另报截止日前/后人群的误差，不假称所有人都已接触同一信息。小组置信区间过宽时明确不下结论。

若只改变了模型回答却没有改善真实分布，记为模型对信心标签敏感；不升级正式P。如果结果稳定改善，再扩月份与人口、检查更接近当时的信心和消费分布。不能只把中心推高或强制制造方差作为成功。

## 5. 难度与尚需判断

公开政策归档与加入短文本：工程难度低，本轮已准备。信心字段接入：工程难度低到中等，沿用现有消息与账务路径即可。**难点是数据解释与分配证据**：年度时效、成年人到家庭户主的迁移、信心与人口/政治属性的联合关系、模型是否真正改变对政策的解释。

这项试验用于辨认一条机制，不替代个人价格体验的主线，也不能保证消除当前总体偏低与同质化。四个新月可以增加时期覆盖，尚不能解决全国代表性或严格路线B可得性。
