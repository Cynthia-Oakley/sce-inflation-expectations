# Numeracy 是否在真人和 Agent 中起作用？

核查日：2026-10-08。**只复算已有数据，新增 API/MCP 调用为 0；不改 P/E/B、提示词、计分器或运行配置。**

## 1. 直接结论

**Numeracy 有现实依据，现有模拟也呈现差异；但“提示词中的高/低标签本身导致差异”还没被证明。**

- 真人中，低 Numeracy 最稳定的特点是：点预测更高、对未来通胀更不确定、个人预测误差更大。
- Agent 中，低 Numeracy 组也报得更高、概率分布更宽，但差异幅度较小。不能说现有提示词完全没有反应。
- 尤其要区分问卷两种回答：真人低/高组的 **Q8 点预测**明显不同，**Q9 概率回答算出的预期中心**却几乎没有稳定的组间偏移。Numeracy 更适合解释不确定性与回答方式，不能简单设成“低 Numeracy 就多加几个百分点”。

## 2. Numeracy 到底是什么

这不是我们随意赋予的性格。SCE 用五道数理/金融知识题分类，答对至少四道为 High。本轮对原始五题完整且有类别的 **8,494 条记录**复算，全部与官方标签一致；不完整题组不自行评分。其他波次可以沿用入组时的官方类别，不能把题目当月缺失理解为低能力。

实际归档提示词是：`Your score on the survey's numeracy assessment was high/low.` 两次既有真实实验的 **600 份实际请求**，标签均与对应人口、官方类别一致，提示及回答哈希全部通过核验。

文字标签不会把底层 LLM 的计算能力切换成另一个等级；它可能改变角色扮演、信心或概率分配。我们需要验证它改变了哪些行为。纽约联储研究也把 Numeracy 与金融知识联系起来，并发现高 Numeracy 人群的不确定性更低、对极端通胀/通缩分配的概率更少；不能将其等同于 IQ。[官方研究及分类说明](https://www.newyorkfed.org/medialibrary/media/research/staff_reports/sr949.pdf)

## 3. 真人数据：五年都出现什么关系

范围为 2020-01—2024-12：71,976 条受访者—月份记录；排除 16 条缺失/非正调查权重后为 **71,960 条、9,747 位不同受访者**，其中 High 50,185 条、Low 21,769 条、类别缺失 6 条。不同月份有重复受访者，不是七万位独立的人。

逐月在各组内使用官方调查权重，再把月度差异等权平均。下列“差”均为 **Low 减 High**，单位为百分点；不是全国 headline，也不是两组全部记录混在一起求差。

- **Q8 点预测的组内中位数：平均高 3.00；60/60 月都更高。**
- **Q9 个人不确定性（各人密度四分位距）的组内中位数：平均高 3.35；60/60 月都更高。**这里衡量一个人认为未来可能落在多宽的范围，不是人际回答的分散度。
- **Q9 个人密度均值的组内中位数：平均仅高 0.0013；32 月更高、27 月更低、1 月相同。**没有类似 Q8 的稳定水平偏移。

把月份、年龄、教育、收入、地区放进描述性加权回归后，Low 仍关联于：Q8 均值高 1.63、个人不确定性均值高 2.42，而 Q9 密度均值仅高 0.13。这个回归说明差异不全由已控制的特征解释；不是因果识别，未报显著性或独立样本检验。

## 4. 偏离 CPI 与预测误差分别检查

SCE 问的是**未来十二个月通胀预期**，不是“现在官方 CPI 是多少”。[官方问卷](https://www.newyorkfed.org/medialibrary/interactives/sce/sce/downloads/data/frbny-sce-survey-core-module-public-questionnaire.pdf)

本轮使用本地已核验的 BLS 首发 CPI-U 总体未季调同比记录，分别做两个评价：

1. 与调查所在月份 CPI 同比的距离：只是事后检查是否更远离当时通胀，不能叫预测错误；该数值未必在受访当天已经公布。Low 组的绝对距离中位数，Q8 月均高 4.41、Q9 月均高 1.29。
2. 与 **t+12 月实际 CPI 同比**的距离：近似对应从 t 月到 t+12 月的实际通胀，才是未来误差。Low 组的个人绝对误差中位数，Q8 月均高 **3.47**、Q9 月均高 **0.88**；**59/59 个可评价月份都更大**。2024-10 缺少 2025-10 CPI 基准，保留缺失、不插值。

未来 CPI 只在评价层使用。月度 CPI 是按整月近似问卷的十二个月期限，并非每个家庭的实际篮子涨幅；误差差异也不能全部归因为数理能力。总体结论是：**本地真实数据支持 Numeracy 与预测表现有关，而不只是更接近当期 CPI。**

## 5. Agent 数据：两个月 600 份已有回答

复用 2021-05/06 原有每月 300 人、温度 0.5 的 DeepSeek 实验，同一选中样本中的真人与 Agent 并排比较。按各问题有效回答取共同样本，等权；双方 Q9 用同一冻结近似计分器，避免把官方拟合与本地拟合差异误判成模型差异。

- **5 月：**选中 High 213 人、Low 87 人。真人 Q8 组中位数为 **4.0 / 7.0**，Agent 为 **3.5 / 4.5**（High / Low）。真人个人不确定性中位数为 **2.88 / 4.65**，Agent 为 **3.65 / 4.41**。
- **6 月：**选中 High 211 人、Low 89 人。真人 Q8 为 **5.0 / 7.0**，Agent 为 **4.2 / 4.5**。真人个人不确定性为 **2.95 / 4.14**，Agent 为 **4.37 / 4.77**。
- Q8 共同有效人数为 297/300；Q9 为 292/293。各组人数、拟合缺失和调查权重敏感性均在摘要中；没有把缺失结果补成零。
- 控制年龄、教育、收入和地区后，Agent 的 Low 标签仍关联于 Q8 均值高 **1.04 / 0.52**、不确定性均值高 **0.66 / 0.52**（5/6 月）。但两组还有未控制差异，仍不能据此认定标签的独立作用。

这两个月模拟整体低估了后来实现的高通胀，Low 组报得较高，反而更接近后来 CPI。这个方向与真人误差关系不同，**不能把它解读成模拟出了“低数理能力反而预测更准”的现实规律。**

## 6. 对项目的处理建议

**保留 Numeracy，暂不根据它机械上调/下调预期中心。**先把它当作与个人不确定性、概率使用和回答精度有关的待验证输入；它无法单独解释我们整体回答过窄、水平偏低的问题。

下一项建议是一个变量的配对检验：完全固定同一人的其他 P 和同一份 E，仅分别写 High、Low、删去 Numeracy 三种提示，保持模型/温度不变，并做重复生成。分别检查点预测、概率分布宽度、人际分散度及回答有效率。这样才能识别标签作用，也能区分标签效应与生成随机性；**本轮未准备或运行这项新付费实验。**

若标签检验不足，再研究怎样把数理能力转成有文献与数据支持的信息理解/信心机制。不要故意制造计算错误，也不要按照测试期真实答案反推提示词；概率总和检查仍然保留。
