# SCE 基线怎么学习，以及最新数据评价到哪里

2026-10-07。根据用户要求，将原60月参照扩展到当前可核验数据上限。旧run和旧报告保留；本轮仍是离线统计回测，没有新增LLM/MCP调用，没有调整模拟模型、提示词或计分器。

## 1. 为什么全国指标取中位数

我们对齐的是纽约联储的一年期通胀预期headline。流程是：个人Q9十档概率→拟合个人概率密度→个人密度均值→调查加权的跨人中位数。**个人层面是均值，全国层面是中位数**，不能把两层混为一谈，也不能用Q8直接点回答替代Q9 headline。

纽约联储选择中位数，是因为它对极端回答更稳健；其调查并不为了发布headline而删除或封顶这些极端回答。部分其它SCE变量采用平均值，所以不是整个SCE都只报中位数。[官方FAQ的统计定义与理由](https://www.newyorkfed.org/microeconomics/sce/sce-faq)、[官方Chart Guide](https://www.newyorkfed.org/medialibrary/interactives/sce/sce/downloads/glossary/frbny-sce-chartglossary.pdf)。本项目微观分布评价仍报告均值、宽度和尾部，不因headline采用中位数就丢掉这些信息。

## 3. 四种方法的实际实现

### AR(1)：从历史SCE学习延续规律

拟合 `本期SCE = a + b × 上一期SCE + 误差`。只有截距a和延续系数b，通过普通最小二乘从已公布历史的相邻月份估计。每个目标月重新拟合，最少12个已公开观测；不固定成永远不变的系数。

预测时从最后已公布月份出发。若最后已公布是t−1，递推一次；若是t−2，递推两次。真实发布时间决定步数，不能默认永远有上个月的值。例如2021-06-10，5月SCE尚未发布，最后已知仍是4月，必须走两步。

### ARX：再学习价格信息如何关联下一份调查

本实现是按截止点直接预测目标调查的回归：`目标月SCE = a + b × 截止时最后已公布SCE + c × 截止时最新首发CPI同比`。a/b/c由最小二乘估计。它是低参数统计参照，没有新闻、人口画像或消费篮子，也没有LLM。

训练每一条历史样本时，SCE与CPI特征都按**那条样本原来的预测截止点**构建；训练标签必须在本次预测截止前已公布。不是用现在完整的CPI表回填历史特征。最少12组已公布标签/特征对，因此全国ARX没有覆盖全部80月：月中67月、上月末66月。短窗口的误差只能与同月份基线比较。

### 规则Agent：设定信息更新行为，不训练更新率

建立1,300个等权虚拟居民，全部从最早可用SCE值开始。每有一份新的公开SCE发布，每位居民独立以固定概率更新为新信号，否则保留旧判断。最后取居民判断的中位数。seed42固定随机更新轨迹。

25%是预先设定的参照假设；10%/50%同时作为敏感性结果，不依据本次误差挑选“最佳率”。**这个更新率不是从真人数据训练出的**，每位居民也没有完整Q9概率曲线。信号是公开SCE，不是专业通胀预测；它仅借鉴Carroll的信息传播结构，不是其原模型的完整复刻，更不是ConsumerSim的Normal贝叶斯算法。

### 人口条件分布：用历史真人分布作统计参照

从上一调查月的官方个人预期均值出发，按年龄三类×教育三类分组。保留每组内完整加权分布，再按当期人口框的各组权重占比重新混合。某组有效donor少于20人时回退到全体历史分布；回退组另存，不暗中补造答案。

这是利用历史数据估计条件分布，**没有像AR那样优化一组回归系数**。也不是给每个合成居民匹配同一个真人、预测其唯一答案。输出是个人预期均值/不确定性的分布，不是完整十档问卷。

当期预期数值不用于估计无宏观约束版的组内历史分布；当期人口构成是明确的A输入，当期实际答案用于评价。另有“已知当期全国中位数”版本，把模拟均值分布整体平移到该中位数；全国中位数误差为零只验证约束，独立成绩来自其它分布和群体量。这里上一月微观回答属于A回顾重建材料，**不能把该方法当前成绩叫作B实时预测**。

## 4. 训练、验证、测试到底怎么分

本轮不是随机把全部月份按70%/30%拆开，也不是一次训练完就预测五年。采用逐月扩展历史的回测：

1. 固定目标调查月及预测截止点。
2. 只取截止前公布的数据拟合AR/ARX；规则Agent使用此前公开信号；A条件分布使用已声明的上一月历史微观材料。
3. 生成该月预测/重建，再与该月真实观测比较。
4. 下一月向前移动，允许已公布的旧目标成为新的训练资料。当前目标及未来答案始终不进入预测拟合。

AR(1)历史从2018-12开始；上月末预测2020-01时，最后已公布是2019-11，正好12个历史观测。ARX受CPI历史及12组训练对门槛限制，月中首月2021-01，上月末首月2021-03。规则率、人口分组和支持门槛均未在评价区间上优化。

**这叫滚动样本外回测，但本轮没有单独用于选参数的验证集，也不是对完全未看过时期的独立盲测。** 2025/2026结果现在也已成为基线参照；不能日后把它们包装成无人看过的Agent测试。若后续需要调参，应先划定开发/验证窗口，再把独立评价期留给最终固定的Agent；未来尚未公布的调查还可做真正前瞻封存。方法说明参考[时间序列滚动验证](https://otexts.com/fpp3/tscv.html)。
