# 路线 B 的就业与收入人口更新：具体实施方案

日期：2026-10-08。本文保留最初实施方案；**数据补齐和扩展回测现已完成，正式人口接线未启用**，最新以[执行结果与路径](SCE_MACRO_PROFILE_EXTENSION_RECEIPT_20261008.md)为准。新增就业变量未稳定超过既有失业率模型，收入更新总体未超过旧画像，因此先保留数据、继续检验机制。下文“尚未完成”描述的是方案制定时状态。

## 1. “人口比例改善”到底指什么

这里预测的是当月 SCE 调查人群的画像分布：多少比例就业、带失业标签、处在低/中/高收入档。它不是预测每个真实受访者是否失业，也不是直接预测通胀。

例如以 1,000 个 Agent 为目标：旧资料中有 600 人就业，更新模型预期当月应有 620 人就业，抽样时就增加就业画像被抽中的概率。这个例子只是解释，不是实测预测值。收入同理：更新三个收入档在模拟人口中的比例，仍从真实旧画像的联合记录抽样，保留年龄、教育、收入和就业之间的关联。Core/Normal 的角色差别在行为计算方式，二者来自同一更新后的人口总体。

“改善”必须指这种比例更接近后来公布的真实 SCE 画像分布；在验证前只能称“人口更新”。之后还需另验通胀回答是否随之改善。

## 2. 具体补哪些东西

### 就业：先补两项，再验是否需要更多

- **就业人口比**：就业人数占 16 岁及以上非机构平民人口的比例；BLS CPS 月度就业报告表 A-1，季调序列 LNS12300000。作用：比失业率更接近“人口中有多少人就业”。
- **劳动参与率**：就业或正在找工作者占同一人口的比例；同表 A-1，季调序列 LNS11300000。作用：识别退出劳动力市场的变化，避免把“失业率下降”一律当作“更多人就业”。
- **已有对照**：失业率 LNS14000000、非农就业变化继续保留。初步结果没有显示多加非农等变量更好，因此不先堆更多指标。
- **后续可选**：若总体关系仍弱，考虑少量年龄组的就业人口比或参与率，再按 SCE 已知年龄结构加权。样本/历史期数不足时不拟合很多小组。

就业人口比 = 劳动参与率 × (1 − 失业率)，单位换算后成立；三项信息高度重叠。先比较“失业率变化”“就业人口比变化”“就业人口比＋参与率变化”这三个小模型，不把三项当成独立信息一起塞进回归。

它们来自同一月度发布，但 16 岁以上全人口与 SCE 家庭决策者仍有不同口径。因此学的是两者历史变化的映射，不直接把宏观比例当成 SCE 目标比例。[BLS 定义](https://www.bls.gov/cps/definitions.htm)、[就业报告 A-1](https://www.bls.gov/news.release/empsit.t01.htm)。

### 收入：先用工资和税前总收入的变化

- **平均周薪（优先）/平均时薪（替代）**：BLS 就业报告表 B-3 的私人非农全体雇员，季调序列 CES0500000011 / CES0500000003。周薪同时反映工时，时薪只反映每小时报酬；平均值也会受行业/岗位构成改变影响。
- **工资与薪金总额**：BEA 月度 Personal Income and Outlays / NIPA 表 2.6 的 wages and salaries；用于刻画全国劳动收入变化。
- **名义个人总收入**：同一 BEA 发布的 personal income；包括工资、经营/资产收入及转移收入。可补工资之外的渠道，但宏观总量不能识别所有收入档的变化。

先用其中 1–2 个变化指标，比较“只加工资”与“加工资＋总收入”。SCE 的收入问题是家庭全部成员过去 12 个月税前总收入档，因此使用名义收入及过去 12 个月窗口的变化，而不是直接拿当月工资或税后可支配收入填档。BEA 月度金额采用季调年率时，需先按单位转换再累计窗口，不能把年率逐月直接相加当作家庭收入。[BLS B-3](https://www.bls.gov/news.release/empsit.t19.htm)、[BEA 收入口径](https://www.bea.gov/resources/learning-center/what-to-know-income-saving)。

收入分档先沿用已有画像的低/中/高三组与 unknown，不增设许多小档。unknown 单独保留/评价，不假装知道缺失家庭收入。还要比较 SCE 原始与加权收入分布：官方权重会校准收入，比例变化可能部分来自校准口径，不能全部解释为经济变化。

## 3. 数据怎么补、从哪里补

优先复用已下载的 BLS 就业首发 PDF 与历史 HTML，转录 A-1、B-3 的对应观测列并交叉核验；补 BEA 历史发布稿。当前序列 API 可辅助核对定义，但不能替代历史版本证据。

每条记录保存 measure、value、unit、reference_period、published_at、source_url、source_version/vintage、retrieved_at 和文件哈希。预测月只用截止日前最新已公开的版本；这是既定 B 口径。年度修订、人口控制口径变更和缺月要记录。历史资料若仍只有首发值，单列首发回测，不称已完成“截至当时最新版本”回测。

补齐目标：与现有人口 2017-01..2025-10 对齐，另补构造滞后/12 月收入窗口所需的更早宏观资料；前期资料不足就明确缩短共同评价区间。最新年份仅用于可得性准备，尚无微观真值的月份不评价。

拟存储在独立候选目录 `data/raw/sce_macro_population/`（原件）和 `outputs/sce_macro_population_extended_<new_run_id>/`（转录、按时点特征、预测与评价）；均为后续目录，本文不声称已下载。数值转录用确定性脚本，不用 LLM 阅读大量 PDF。

## 4. 回测怎么做

1. **先查口径**：每月 SCE 加权就业/收入比例为主要目标，原始样本比例作敏感性对照；调查轮换和权重校准的变化与宏观变化分别记录。
2. **重建当时可见资料**：每个预测月按既定上月末截止选宏观版本、旧 SCE 人口和可训练标签。历史微观上线日期缺证时仍采用 t−10 的保守假设并显式标注，不能冒充已验证发布日期。
3. **逐月滚动训练**：使用此前已公开的 SCE 分布学习更新关系，至少 24 个可用月；不使用预测月的真实画像。预测的是旧画像以来比例的变化，先用简单回归、固定惩罚的小型回归，不搜索大量参数。
4. **比较对照**：沿用最近旧画像、过去 12 月平均、不加宏观的历史变化更新、宏观更新。各方法必须使用同一组评价月份。
5. **看多种误差**：主要看每类占比的 MAE（百分点）；同时看 RMSE、偏高/偏低、整体分布距离及年龄×就业/收入联合结构。逐月结果完整保存，再汇总滚动 12 月和经济阶段，不只展示一个总体平均。
6. **接入门槛**：新增指标若不能稳定优于简单对照，就不接入。收入回测先做新候选，不根据刚看过的 37 月反复挑参数；新增选择需要独立留出的验证/确认区间。具体新窗口先登记，不擅自改原项目封存期。

## 5. 接入人口以及预期效果

初步 37 月回测就业占比 MAE 已从 1.466pp 降到 1.323pp，但失业标签占比没有改善。期望新增就业人口比/参与率能更好区分“就业增长”和“退出劳动力市场”，收入更新能使画像对名义工资/收入变化更及时；**不预设一定降到某个误差，也不保证改善通胀模拟**。

通过验证后，再把预测的比例用于旧真实 SCE 联合画像的抽样权重更新；约束年龄、教育、地区等稳定结构，检查有效样本量、极端权重和没有真实画像支持的类型。按月抽样误差与宏观预测误差分开报告，不独立随机改掉一个人的收入/就业。

最后使用固定 E、模型、提示词和 Core/Normal 算法，对比旧 P 与更新 P 的通胀模拟。这样才能知道这项人口工程有没有传导到最终研究目标。当前仅完成初步就业比例回测，收入、扩展指标、人口权重更新与这轮行为对照均未完成。
