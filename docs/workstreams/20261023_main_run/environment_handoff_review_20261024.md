## 修正1：汽油的数值历史版本尚未证实

Kimi脚本将`graph/fredgraph.csv`附带`realtime_start/realtime_end`后取得的数值与当前缓存相同，解释为首发版本一致。这里未证明图表下载端点执行了这些API参数。

本次只做2次免费公开下载的反向检查：同一条2025-06-02观测，当信息版本区间设为2018-01-01至2018-01-01时，仍返回`2025-06-02,3.127`，与不带版本参数的当前下载完全相同。这个结果不能证明2018年已知2025年数值，因而原请求不能作为有效首发版本证据。

[FRED正式观测API](https://fred.stlouisfed.org/docs/api/fred/series_observations.html)明确区分观测日期与实时信息日期；本次不据图表CSV的同值响应认证历史vintage。还应注意：版本日期区间与固定单日vintage也不等同，返回数值须连同实际版本元数据保存。

处理：**保留发布日期规则取证，将数值版本降为待核，严格B暂不接纳汽油美元/加仑序列。**另存11月`monthly_readiness_reviewed.json`，不改原报告/原证据/任何冻结环境。后续补真正ALFRED版本或同期EIA数值归档；不能把BLS汽油同比冒称同一价格变量。A线历史重建继续按已披露的版本限制执行，不受此修正阻断。
