更新：2026-10-23。**这是零API准备与待审运行方案，不是付费授权或模拟成绩。**当前按用户“差异不大则采用512人”的偏好准备；没有启动82月旧包，也没有以Normal代替LLM。

2026-10-24用户阅读版：[项目机制与运行说明](../../project_guide.html)。七项关注内容分别展开，含同类匹配、P/E时间边界、两层拟合、问卷与指标、真实时间切分及运行存档；用户审阅后再讨论启动。

## 1. 512人与全员模拟的区别

每月完整微观样本平均约1,199人。全员模拟让每个人都由LLM回答；512人方案从各类受访者中抽样，由权重恢复各类人在全体中的比例。两者模拟方法相同，主要差别是抽样精度、稀少人群支持和成本。512人约使用全员43%的调用，节省约57%。

已有82月、两个固定分配种子的**真人抽样检查**中，512人的加权中位数相对完整真人波次的平均绝对偏移约0.098pp；月份平均偏移的90%分位约0.216pp，最大约0.449pp。平均W1约0.243pp。这是人群抽样误差，**不是LLM的预测误差，也不是保证未来误差不超过此值**。两个种子不足以构成精确置信区间。

本次最终固定名单另做了不改变抽样的检查：Q9平均绝对偏移**0.107pp**、RMSE0.158pp、最大单月**0.676pp（2023-02）**，平均W1为0.250pp；Q8中位数平均偏移0.154pp、最大1.000pp。这里的最大值是单个固定名单，前面的0.449是两个种子的月份平均偏移，二者不是同一统计量。完整数据在隔离评价的`sampling_offset_summary.json`，这些值不用于换种子。

因此建议512人用于主运行，完整真人波次保留作第二套评价参照。不为了事后好成绩更换抽样种子。分组分析显示每格N与有效样本量；小格不作精确排序。若完整结果表明某些结论依赖样本规模，再选择少数月份补未模拟者，而不是现在直接把所有月份扩大到全员。

## 2. 本次准备的范围

- **历史重建候选包：2019-01至2025-10，共82月，每月512人、生成一次，41,984次请求。**这替代旧六格执行包；月份与最终预算仍须在运行前明确确认。
- 2019年提供疫情前常态对照，随后覆盖疫情、通胀上行/高位/回落以及2025年政策变化。它是研究窗口选择理由，不是因为某段拟合更好而选取。
- **2025-11至2026-09另11月：P/E文件已齐，但尚不具备同样的真实当期微观结构。**其历史可得版本、合成初始状态与评测条件单独登记，不能直接拼成93月严格预测结果。
- 所有月份独立初始化。保留同一受访者的本地匿名身份，但不把上一月模型输出自动传给下一月；自主信念递推实验已后置。
- 每月分别分层抽样，因此512人的名单可能变化；“身份保留”不等于强制每月使用同一512人。当前更新评价是本期模型相对本人真实过去的变化，不冒充一条完整模型人生轨迹。

## 3. 人口如何抽样、权重如何使用

采用**学历3×数理2×年龄3×收入3＝54格，任一维未知的另入未知池**。就业、住房、州/地区等仍进入个人画像；不因为没有作为网格坐标就被删除。

每个非空格尽量分配至少8个名额，小于8人的格取全体；剩余额度按人口质量分配。格内用固定种子20261023、月份和本地身份产生稳定随机排序，无放回抽取。抽样不读取当期通胀回答。入选概率为π=n格/N格。

先算设计权重d=w/π，再在格内校准：

`aᵢ = dᵢ × 该格全体原调查权重之和 / 该格入选者设计权重之和`

这使各格的总人口质量与完整框架一致。个人可以代表非整数个人口质量；中位数由所有个人的加权经验CDF达到50%的位置取得，**不平均各格中位数**。先计算个人Q9密度隐含均值，再计算跨人的加权中位数。

源数据98,382个人月中有30条原始权重缺失/无效，原记录保持原样；它们不进入正权重抽样框，也不补成1。该支持限制单列。校准恢复格比例，不能保证格内预期或总体中位数无偏。54格在512人下仍有弱支持，不能把54格全视为独立精确估计。

## 4. 每位LLM收到什么

**人口P：**年龄组、学历、收入档、就业、住房、数理标签、地区/州；合成CE支出占比、美联储信心与食品采购角色。真实调查权重和入选概率留在本地评价侧，不发给模型。采购角色是基于既有家庭结构/年龄迁移的合成状态，不当作SCE已观测的真实采购身份。

支出/角色迁移仍沿用既有固定外部样本（CE 2020、ATUS 2022），不是各目标月的真实家庭账本。它们是研究中估计的合成分配规则；例如应用到2019年时，不能将其说成2019年当时已公开的真实个人信息。

**环境E：**截止日以前的公开价格、食品价格、新闻和政策。随机新闻量在完整月度人口框架上分配，再取入选者：约50%看3篇、29.17%看8篇、20.83%看20篇，实际按人数取整；3篇共同新闻，余量为个人新闻。主题继续沿用50%均匀＋50%关联的既有机制。抽样后的平均新闻量无需刚好8篇。

**实际投喂范围澄清：**当前冻结模板沿采购价格视图，用`procurement_price_views.transform_prompt`移除了完整CPI、就业、汽油与滚动趋势数表；直接数值背景为在家食品总体及角色可见食品类别。宏观信息仍可能通过新闻或政策事实出现。环境JSON的存档广度不等于每位模型的提示内容，本说明没有改变现有模板。

同月受访者使用统一环境截止日，不按本期真实作答日期逐人调整。真人分散在当月答卷，可能看到截止日以后的新闻，因此当前重建存在调查日与共同信息窗口的近似；这里不声称复刻了每人真实看到的全部信息。

**信念状态：**本人严格更早的Q8点预期、Q9完整十档概率，以及可用的真实历史密度均值摘要。文字说明这些是过去形成的信念、本期允许维持或修改，不规定固定更新幅度。本期直接填Q8与Q9，不使用变化值输出。

**不加入：**当期真人通胀答案、原始ID、权重、真实作答日期、性别、Q1/Q2、GSS/MIDUS心理资料、原始ATUS记录。不叠加已暂缓的心理/数理实答/频率强调等实验模块。时间标签只表示公开信息早于/晚于/与既往参考日同日不确定，不宣称人实际看过。

## 5. 新人及缺失历史如何处理

- 有合法本人近期历史时保留本人回答，不用合成值覆盖；Q8/Q9分字段判断。
- 缺失者优先从相邻上月、再从最近三个月的匿名相似受访者中匹配供体。年龄/学历/收入等匹配有分层回退；不拿2021年供体直接当2025年起点。
- 新人从历史首次受访者池、回访缺失者从历史回访者池抽取；格太稀疏时，按年龄＋学历＋收入→年龄＋收入→年龄→相应新/老池整体回退，先满足近月约束，再扩到三个月。至少5名供体且权重ESS至少3；不满足时明确报错，不静默借多年以前数据。
- Q8/Q9同时缺失时尽量保留供体联合答卷，不把点预期与概率任意拼接；合成起点明确标注，不虚构本人真实答题次数。
- 仅对合成供体概率施加有限倾斜，目标是与允许使用的**过去总体信念**及同设计抽样容差接近；不修改保留的本人实答，不使用本期真值选供体或种子。
- 本包75月原已在过去容差内、7月通过有限调整进入容差；这只是初始化检查，不是本期拟合效果。

现有新人小试已证明接口能执行，没有证明新人分布拟合成功。缺失先验不可直接观测，这一限制将保留。新人也由LLM回答；当前没有Core＋Normal代答。

## 6. 模型与执行

固定OpenRouter→SiliconFlow FP8→DeepSeek V3.2；温度0.5、关闭思考、JSON、最多1024输出token。保留无数值的输出结构示例。Q9十档有限、非负且总和为正时允许等比例归一化，原答与修正标记同时保留。

官方Core负责离线验线；真实批次由本项目并发队列调用同一模型适配器。程序逐月自动推进，不需要Agent手动启动每个小包。先32次、最多8并发做格式检查，至少31份可用后升到最多64并发；不按拟合成绩修改配置。

无自动重试或供应商回退。HTTP/供应商/预算错误，或连续连接失败触发既定停止规则；收齐在途请求。失败槽保留，后续只有从未发送的位置可在明确批准后续跑。输出不合法时，主口径按字段保留其初始化状态，并另报真实可用输出敏感性、失败率和归一化率。

## 7. 评测与组合指标

三个目标分开：

1. 同一批入选真人：主要看模型是否重现所给家庭。
2. 完整微观波次：把抽样组成误差计入整体重建表现。
3. 官方全国headline：另行比较；官方密度实现与本项目冻结近似算法的差异明确披露。

Q9主要报告月度中位数MAE和跨人W1，辅以RMSE/偏差、跨人IQR、个人误差和秩相关；Q8独立评价。所有人报告总体W1；真正拥有相邻上月实答者另报局部W1、更新W1和照抄本人上期。合成上期不充当真实个人变化。

宏观组合为`(1−α)×截止前最近已公布的全国值＋α×本期模拟中位数`，α限制0至1、无截距；拟权2019—2022，后段2023—2025评价，MAE主、MSE敏感性，同时保留未组合模型和持续性基线。已参与开发或被查看的月份需披露，后段不称完全盲测。全国基线已按实际环境截止日登记，新闻稿同日且缺精确时间者保守排除；不把“上月指标”默认当作截止前已公布。

人口网格筛选也使用过历史全窗微观统计，所以本批属于开发后的全窗检验；后段只是组合权重不再拟合的时间段，不能仅因α在早期拟合就将它称为整个机制从未接触的独立测试集。真正未公布目标的验证需另留时间封存。

2026-10-23已阅读[kimi_recent_availability_20261023.md](../20261023_core_normal/kimi_recent_availability_20261023.md)及审计入口，未复跑数据审计。其11月全国基线参考月/发布日期与本项目已登记表逐项一致。报告的零违规表示环境JSON内已填写的时间戳不晚于截止日，不能代替历史版本认证：每月13条汽油信号仍为当前FRED快照，部分发布日期为规则推算；NYT标题/摘要仍有当前文本版本不确定性。审计覆盖物化环境的每月30条新闻事件，不单凭此认证最终抽样新闻全集。
