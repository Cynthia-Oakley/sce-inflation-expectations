空间足够。四个最终任务的 **66,822 个请求位置都有完整冻结输入，67,147 条已封存调用记录全部能对上输入哈希**，未发现输入遗失。月度链根月另复用 B 的 512 个状态，因此包内有效状态数为 67,334；不能把状态、请求位置和物理调用记录混为一谈。

可以优先补入模型实际看见的人口画像、合成属性、历史信念、数值价格、政策材料、问卷与输出结构，以及生成参数和原始提示哈希。批量新闻文字的再分发许可尚未确认；A 的个人截止日能反推出真实作答日，也不宜随脱敏逐人记录一起公开。两项采用明确占位槽，不偷偷删除后仍称“原始完整 Prompt”。

有 **1,343 份周度 Prompt 没有新增新闻摘录**，其余部分的来源与脱敏边界已核查，可作为优先纳入的完整输入候选。它们逐字保留原 Prompt，可与包内答卷对接。这里“没有新增新闻”不等于没有价格、政策或历史信念。

## 哪些可以补，依据是什么

**自行编写的提示机制与代码。**人口描述结构、匹配/路由说明、先验呈现、输出 JSON 要求和运行配置可以提供。问卷部分属于改编 SCE 的问项，附纽约联储声明，不能把官方问卷当成本项目独创。

**SCE 派生的人口与历史字段。**使用包内已重编号的家庭键，保留粗粒度画像与生成时使用的严格更早信念，不导出原始受访者 ID、真实作答日、身份对应表或供体对应表。纽约联储[使用条款](https://www.newyorkfed.org/privacy/termsofuse)允许按其条件使用、分发和改编相关数据/问项；保留来源、修改和非背书声明。公开数据有来源许可，不意味着可忽略重新识别风险。

**价格及合成属性。**BLS 数值与 CE/ATUS 派生的合成分配可附来源提供；[BLS 使用说明](https://www.bls.gov/bls/linksite.htm)说明其出版物通常为公有领域，另有版权的图片等除外。采购角色、支出份额、美联储信心是赋予模拟家庭的合成属性，不能说成这些家庭本人的实测值；不导出 ATUS/CE/Gallup 的原始受访者映射、整份第三方文章或 PDF。

**政策文字。**实际提示含有美联储官方声明摘录，不能一概称为本项目自行撰写的摘要。已核来源目录的政策 URL 均指向 Federal Reserve Board 官网；按其[使用说明](https://www.federalreserve.gov/disclaimer.htm)，相应官网资料通常可使用并应注明来源，另有标注或第三方材料除外。候选层单列这一来源依据，补充首次候选清单较简略的 `rights_basis`。

**NYT 新闻。**其官方 [Archive API 说明](https://github.com/nytimes/public_api_specs/blob/master/archive_api/archive_api.md)要求遵守 API 条款和署名规则；API 可下载不等于获得批量转交文字的许可。本轮未取得可确认的整批再分发依据，因此暂不装入标题、摘要和片段。这不是断言所有分享均违法。`developer.nytimes.com/tou` 与 attribution 页面返回了仅含前端壳的页面，HTTP 200 不记作已读到法律条文。

## 脱敏与忠实复现的处理

使用现有 v09 的匿名编号，与既有答卷保持对接。私人键表只在本机投影时用于查找，不写入候选；程序不读取 API Key。全体原始 Prompt 未检出源受访者编号、邮件地址、密钥样式或本机绝对路径；投影后再做同样扫描及逐项结构检查。这是可重复的检查证据，不是绝对匿名性的保证。

A 的真实个人截止日采用隐私保护处理：它由完成日减一天得到，直接保留会恢复真实完成日期。遮蔽时不改原输入，只另存投影；B/月度链的合成日期和周度的公共截止日不属于同一类真实个人日期。

所有 66,822 个投影在私有内存中恢复原槽位后，都与原始消息完全一致。发布文件不包含恢复值。后续若评委合法取得相应新闻或获得授权，可以按槽位恢复并比对原消息哈希；用替代新闻或合成日期则是另一个输入条件，不能称逐字再生成原实验。

## 评委能做到什么

1. **不需要 Key：**原包已有逐答卷、原始模型回复和数值复算；候选层再提供实际输入结构、可分享分块与完整样本。
2. **使用自己的 Key：**完整样本可尝试一次条件再生成。已实现并离线验收便携入口；无自动重试或供应商回退，不保存 Key。尚未真实联网测试，不保证未来路由、价格或服务可用，也不保证随机输出与历史答卷逐字一致。
3. **重新跑完整历史：**还需要解决新闻文字和 A 日期的恢复/替代规则，随后打包重渲染与批量入口，不能声称只凭当前 ZIP 和一个 Key 已能重跑所有历史输入。
4. **重新跑递推链：**此处冻结的后月/后周输入引用的是历史运行的模拟前态。原样重发只复现该条件的一步；新的自主递推必须传入新的上一期输出。不能拿封存前态冒充一条新链。完整链另需根状态、重校准事件、时间规则及新闻访问方案。

因此下一版宜分为“0 Key 数值复算”“自备 Key 完整样本”“有条件的全量重建”三个入口，分别写明范围；不把新闻/日期占位模板接到联网默认入口。
