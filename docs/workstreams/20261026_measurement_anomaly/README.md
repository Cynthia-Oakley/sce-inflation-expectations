## 可以直接纳入报告的计分声明

全国预测以纽约联储官方首发SCE指标作为外部目标，微观问卷评价则对真人和模型统一使用冻结近似密度计分器。官方个人Q9密度均值配合原调查权重和现有经验CDF中位数，可对全部82个月复现高精度chart，浮点差约1.5e-16pp；汇总层已对齐。对同一批真人记录、同一权重，只替换个人密度均值，月度中位数平均绝对差为0.013272pp，2021年为0.023813pp。全部真人近似重算全国值与官方首发值的平均差为0.026928pp，还包含有效支持样本及公布精度/版本差。MAE不是线性可加量，不能把后者除以模型MAE认作计分原因的百分比；原Core改为同算法真人目标后MAE从0.298407变为0.289976pp，是目标口径敏感性。2021同算法对照反为0.586643，高于官方目标0.577424pp，因此计分差无法解释该年的大幅低估。

## 官方方法与可应用部分

- 官网2017方法附录B/C与FAQ已重新核查，来源记录在`docs/sources/sce_scoring_method_evidence_20261026.json`。
- 均匀/相邻双档三角/广义Beta的分支和主要支持规则已公开；当前冻结计分不是最早原始版，而是10月3日计分留出检验后选定的Beta改进版。
- 仍未在本次核查材料和定向搜索中找到官方完整生产拟合代码。Beta优化器细节、约束、初值和多解规则不能由公开原则唯一补齐；独立研究者的R实现不能冒称官方源码。
- 官方附录B的加权Cox中分布插值已另实现并测试，按相同值合并概率质量，不改原模块。但它用于本批Q9会使官方字段对chart误差从浮点精度变为0.003068pp，不作为Q9替换；主要针对取整/分组回答的插值不能混用。
- 共同有效真人记录96,655条，冻结计分对官方个人均值加权MAE0.031042pp；均匀0、双档约5.1e-7、闭合Beta0.000380、开放Beta0.066195。微观拟合剩余差主要集中在开放尾，不应全称“小数误差”。

## 误差的可核验分解

保存逐月完整带符号链：本地全部有效真人中位数→双方共同支持的本地中位数→共同支持的官方个人均值中位数→官方全部有效样本中位数→chart→首发值。全82月的五段平均绝对差为0.000320、0.013272、0.003421、近0、0.023147pp，它们可以抵消，不能相加认作误差份额。chart与首发81/82月按一位小数一致；2019-11保留精度/版本差，未擅自改写。

对原Core，e=S−O=(S−H)+(H−O)。MSE精确分解为0.172325=0.166643+0.001521+0.004161（最后一项为交叉项），残差小于1e-15。后两项包含整条测量桥接，不能单称“纯Beta算法误差”。MAE换目标净变化0.008431pp约为原MAE的2.8%，但不是因果归因。2021该变化为−0.009219pp，测量差反而部分掩盖低估。

## 2021年专项：方法与结果

固定用2019—2020的24个调查月校准；前18月拟合、后6月选择正则强度，再用全部24月重估。最后一个训练月2020-12的标签2021-01-11才公开，初次拟合在2021-01-13首期截止前，不称“2020年底已完成拟合”。状态CPI≥4%和特征家族沿上轮声明，未根据2021成绩改变。比较全年固定系数与逐月扩展窗口重估，后者仅用当时真实已公开的SCE标签；正则强度仍为首期选择。2019—2020没有高CPI状态，相关列不能估计，记录为未识别，而不是推断真实效应为零。

2021全年MAE：官方持续性0.325000；原Core0.577424、扩展0.565315；固定系数CPI＋扩展模拟0.427537，扩展窗口CPI无模拟0.290460，CPI＋扩展模拟0.276722；含状态的无模拟控制0.288468、含状态与扩展模拟交叉0.274024。相对持续性下降15.7%，同结构加入模拟增量约0.014444pp。并列全部预设家族，不据排名宣布已确认最优。

收益主要在下半年：联合扩展窗口MAE上半年0.401572/持续性0.400000，下半年0.146475/持续性0.250000。直到2021-07才有两条已公开的高CPI状态训练样本。2021-06截止6/10时5月SCE尚未6/14发布，训练只到4月；2021-12截止12/10时11月SCE尚未发布，训练只到10月。全过程保存可得性审计。

三个月块MAE差区间约[-0.1424,+0.0199]，跨零。支持保留动态统计校准候选，不支持“提前预测了异常上涨”或稳定胜出。A机制与模型知识本已涉及这些历史、个人日期模型与共享宏观截止也不同，故系数的时间隔离不等于端到端严格事前预测。该方法是宏观统计后处理，不是重新生成LLM回答或个人信念连续递推。下一步若考虑采用，须保持规则复查2022及其他年份，不继续按2021调参。
