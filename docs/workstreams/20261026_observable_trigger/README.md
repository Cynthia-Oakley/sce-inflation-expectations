# 用差分、可观察触发器和交叉项修正模拟指标

2026-10-26。回应用户希望用“异常上涨信号”触发修正的设想。只使用已有月级聚合数据，0新增API、0密度拟合；不改变正式A/B的输入、答卷、评分或配置。原报告v05和研究包v02保留。本轮图文见[结果与折线](results_v2/index.html)。v2移动图例并补充原始模拟行及非线性增量解释，分析结果不变，v1保留。

## 设计与边界

采用已有月末公平对照数据：官方全国Q9首发值y、截止前已公布的CPI首发同比π、已有Core＋Normal（τ固定8）模拟全国值S。逐行验证月末公开SCE锚等于上个调查月首发值，才把y减锚解释为真正一阶差分。2019-01仅形成滞后，所有家族均用2019-02—2020-12的23期初始训练，2021-01—2025-10共58期评价。不能把不同训练行数的新旧成绩当成纯变量消融。

触发器D＝1(Δπ超过训练期75%分位数)。初始23期确定的阈值为0.2pp，有5个触发月，之后不更新；内层选择正则强度时，阈值仅用前17期，随后6期验证，避免阈值使用验证段。α候选0、0.1、1、10、100，验证MAE最小、并列取更强正则。各家族分别按同一程序选参。

Δπ是连续两次已发布CPI同比之差，包含基期效应，不能称识别的结构冲击；D不使用本月SCE真值，也不使用“2021年”标签。原先CPI≥4%状态在初始训练中没有支持，这次换成训练中出现过的可观察价格变化，但5个事件仍很少。

并列8个家族：水平宏观/加模拟、差分宏观/加模拟、差分＋触发宏观/加模拟交叉、正向价格项宏观/加模拟及正向修正。每个家族都报告固定初始系数和仅用已公布历史逐月重估两种版本。没有ARIMA残差过程、季节差分、个人信念递推或新LLM运行。

温和正向修正额外使用D×max(Δπ−ΔS,0)，该项及max(Δπ,0)系数非负；其他系数自由。两种变化同为pp但经济含义不同，其差值只是修正函数的假设，不能解释为识别的认知缺口。此组同时引入模拟变化与非线性修正，所以相对简单宏观控制的增量不能进一步分解成纯模拟贡献、非线性函数贡献或触发状态贡献。方向约束也不保证整个预测高于持续性。

## 结果与解释

- 触发交叉＋模拟：固定系数2021上半年MAE0.197508、全年0.306698；逐月更新上半年0.175528、下半年0.387369、全年0.281448。持续性同段为0.300000/0.200000/0.250000。异常初期有改善，但后期过冲，不能称2021全年修复。
- 温和正向修正＋模拟：更新版2021为0.239757，2022为0.374430，后34月0.167530，全58月0.225280；对应持续性0.250000/0.383333/0.176471/0.234483。固定系数2021为0.278924、全58月0.249573，仍差于持续性。
- 同规则宏观控制：差分全58月0.234918→加模拟0.226626；正向项控制0.232629→加模拟与修正0.225280。自由触发交叉全年2021反而从宏观控制0.240332恶化到0.281448。完整家族保留，不能只选择最有利窗口或只和持续性比较。
- 区间为按月3月区块重抽样2000次；差分与温和修正全58月的条件配对区间不跨零，但未处理多模型比较，也不包括看过历史弱点后提出新模型的选择不确定性，不称独立显著预测贡献。

本轮是已查看2021及后期后的探索。时间过滤能防止系数直接用未来标签，却不能把已观察历史变成新盲测；月末敏感性也不等于认证严格B预测。新模型只后处理全国Q9，没有改善个人Q8、W1/IQR的证据。不根据本轮排名更换正式配置，不新增年份哑变量或继续按2021成绩挑阈值。

方法参考：[Hyndman与Athanasopoulos的干预变量与时序回归](https://otexts.com/fpp3/regression.html#intervention-variables)。该方法支持写法，不证明具体阈值或经济机制。
