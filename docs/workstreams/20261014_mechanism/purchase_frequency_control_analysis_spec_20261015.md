# 购买频率与误差：离线控制变量诊断方案

2026-10-15；真实实验完成、总体结果已知后的探索分析，不冒称运行前预登记。新增API为0，不修改原回答、配置或计分。

## 分析对象

使用现有四期、每期48人的两组两遍回答，连接同人的合成CE四类日数、类别价格和原有P/先验/支出/信心。回归单位为人月：先对两次生成取平均，避免把重复生成当独立人。个体绝对误差用两次绝对误差的平均，不用“平均回答的绝对误差”替代。

主对照是作用说明组减数据组的同人差值；同人的人口、新闻、价格、先验输入完全相同。历史C到数据组的差值只作描述，无法消除同时新增价格和跨批次的混杂。没有无频率同期组，控制变量无法补造该反事实。

## 预先固定的诊断

1. 输入差异：四类频率的支持/相关、月内和月间差异。计算透明的四类价格接触代理：日数加权的类别同比平均，分析其月内/月间方差；该值不是本人真实感知通胀、不是个人CPI，不进模拟。
2. 个体回归：真实Q9、两组Q9预测/绝对误差、两组Q8绝对误差，以及同人两组的预测/误差差值、Q9与Q8之差的变化。四类日数同时进入，联合检验，完整报告，不挑一个类别讲故事。
3. 控制集：月份固定效应、上期Q9中心、上期Q8（缺失用上期Q9填充并列标记）、上期概率IQR、历史均值/次数；年龄、收入、教育、地区、住房、数理能力、就业；合成CE支出占比（四项去一项避免共线）及Fed信心。就业在数据读取前按有工作/休假、退休、其他非就业三组归并；不把其他非就业称为失业。州不展开50组。完整画像回归对缺失教育/住房采用完整案例，明确样本损失。
4. 比较完整与简化控制集：简化集仅月份、上期信念/历史；两者在同一完整案例样本比较，并另列全可用样本简化敏感性。用HC3异方差稳健区间；不按只有4个的月份聚类宣称可靠全国推断。频率联合检验的主模型p值做BH校正，不以单个未校正系数定结论。
5. 解释模型是否更服从共同价格、较少保留先验：看先验位置系数和同人说明组差值的关系，辅助以价格代理；只作关联与相容性证据，不声称识别心理中介。
6. Q8/Q9差别：逐月逐遍做精确恒等分解：Q9中心有符号误差＝Q8中心有符号误差＋模型与真人“Q9中心减Q8中心”的差。绝对误差不能直接作加法。另列负通胀概率及个人点预测与密度均值的差，不能把拟合均值称为个人中位数。

## 边界与交付

192人月中Q9真值不能计分者不强填；回归、Q8可用集与原376条共同支持分别报数。所有回归是描述性、样本量有限；频率是合成供体变量，不能将其与真人误差的系数当成购物行为因果效应。若同人输入相同，差分消去其固定背景，不消除频率与未观测处理反应之间的关系。

输出独立忽略目录：来源哈希、人月中间表（私有）、模型/区间/敏感性/数学分解聚合结果和图。阅读入口沿用当前HTML，结果与下一步写入项目记录，源程序可离线复算。出现假设未支持的结果也报告，不按观察结果重分样本或调参。

**拟合前的数据检查补充：**上期Q8仅1个缺失，用单例缺失指示变量会产生满杠杆观测，使HC3区间不稳定。因此主回归采用画像和上期Q8完整案例；同样本简化回归用于比较控制集。全可用样本的简化敏感性不含上期Q8和缺失画像控制，仍保留上期Q9、概率区间、历史均值/可得标记及次数。原始误差评价与描述图不按回归完整案例删人。
