# 下一步准备：个人信念如何更新，购买频率如何匹配

2026-10-15。本轮完成离线诊断、独立候选转换器与输入草稿、四季度匹配原型。**没有新模拟、没有付费API、没有改变正式模型或运行配置。**候选未冻结为主机制。

## 一、先说最重要的发现

**只保留每个人原来的高低位置，能让分布更像真人，却不能自动修复总体中心或个人更新。**

我们复用八期既有回答，先做一个透明的拆解：每个人沿用上期中心，再一起加上“LLM本月群体中位数−同批人上期中位数”。当前真人答案只用于算误差，不用于预测、供体选择或调参。

在此前的后四评价月：

- LLM原答案：中心误差0.636pp，跨人分布距离3.161pp，个人变化分布距离1.625pp。
- 保留个人位置、只接LLM共同变化：中心误差仍0.636pp，跨人距离降到1.093pp，变化距离反而升到3.026pp。
- 照抄上期：对应0.156／0.691／2.770pp，仍比上述组合更好地保住中心和横截面分布。

这不是新胜出模型，也不是一次新的Q9模拟。它只是**中心数值的离线替代方案**，没有生成十档概率、没有重新拟合密度，不能用于报告不确定性或通缩概率。所有月份此前已看过，属于探索诊断，不是新增盲测。前四开发月方向相同，精确结果见聚合记录。

### 从统计上怎样理解？

记个人上期中心为b，本月LLM群体中心为m。替代值是 `b + m − median(b)`。加同一个数保留原IQR和排序，同时使群体中位数等于m。因此中心误差不变是数学恒等式，不是实验证明LLM中心正确；改善横截面分布继承了真实上期信息，也不是LLM新发现了身份差异。浮点近似并列可能使秩统计出现极小差异，不解释为身份增量。

真正难点是：**大家共同要往哪走，以及不同人分别要改多少。**两件事不能被“把分布拉宽”代替。这里的中位数是同样本个人Q9派生密度均值的等权跨人中位数，不是Q8，也不是全国官方加权发布值。

## 二、下一候选：让模型报“改动”，程序还原答案

已有候选只是提醒模型重视上期信念；这次草稿改变回答的对象：

1. P、E、真实上期Q8/Q9、历史摘要和问卷的预测窗口均保持相同。
2. 对照仍直接生成本期Q8和十档概率。
3. 新格式先报Q8相对上期改变多少个百分点，再报十档概率分别增加/减少多少**概率百分点**。
4. 程序把改动加回各自上期答案，之后仍交给原冻结计分器。十档改动之和必须为0、恢复后的概率必须在0—100；不裁剪、不归一化，不暗中修复答案。

例如：原Q8为3%，`point_revision_pp=1`恢复为4%。原某档概率20%，该档`q9_revision_pp=5`恢复为25%，不是预测通胀涨到8%。这个区别已写进英文提示。

**它不强迫小幅更新，也不规定保持多少历史。**任意合法的新Q8/Q9都可转为这种差值形式。其作用需要实测：模型可能更清楚地使用个人起点，也可能过度不动或更容易算错概率。文献支持“先验与新信息共同形成判断”，并不保证这个回答格式会成功。

### 已落地到什么程度？

- 独立转换器已实现，未注册到正式provider或旧runner。
- 四个开发月192个既有输入中，191份已生成完整新旧提示对；两者P/E/上期记录/问题前缀逐字保留。
- 1人上期Q8缺失，尚未定义直接报Q8的回退路径，没有用Q9均值伪造其Q8；正式样本不能默默把这个人删掉。
- 11项定向检查涵盖中位数平移、收入边界、家庭记录失效、完整向量置换、概率改动恢复及非法概率拒绝。

提示尾部核心意思是：“上次回答是当时形成的判断。预测窗口已前移一个月；判断新信息是否需要改变它。保持、上调、下调都允许，不规定幅度。”不加入用户已反对的“不要机械外推”句子，也不要求所有人向同一中心靠拢。

### 真正运行前还要完成

1. 接入独立入口和原冻结计分器，补上期Q8缺失的明确分支，验证实际发送消息及非法输出停点。
2. 做同日期、同预测窗口、同信息的重复询问检查：没有新信息时是否无故大改。它不同于正常跨月窗口前移，不能混为一组。
3. 冻结同人、同月的直接格式/改动格式两组及重复种子、有效率和三项评价。旧回答可作描述参考；若模型版本或批次不同，不能称严格同期控制。
4. 开发结果只用来检查机制；另登记未参与调整的月份验证。具体调用数、数据发送范围和预算准备完成后再列运行卡，本轮未申请新调用。

这一步属于A路线给定本人上期真实回答的条件重建。B路线要沿用模型自己生成的上期状态；新参与者与误差累积仍是另一个待办。

## 三、购买频率：四季度联合匹配原型已做好

来源仍是本地官方CE Diary 2020年全年文件。包含5,269个消费单元、9,737个完整家庭周，其中582周四类均有统计支持但记录为0；不把未知日数当0，也不再删除这些有支持的全零周。

匹配优先保留粗收入、年龄，再保留家庭规模（1人/2人/3人及以上）、细收入、住房、地区、教育。供体不足25户或有效户数不足15时，按登记的次序放宽条件；先抽家庭、再抽该家庭一周，四类日数整组转移。季度先按家庭权重归一后等权汇合，这是敏感性供体池，不是官方年度CE估计量。

原192人的结果：

- 粗收入、年龄192人全保留；家庭规模可用182人、均保留；细收入可用192人、保留183人。
- 家庭资料缺失1人、记录后搬家9人，均不强行推断家庭规模。
- 住房保留138/179、地区57/192、教育8/191。**新增约束会牺牲其他条件，原型不能称全面优于原匹配。**当前优先级依据变量可比性与供体支持设定，未看SCE当期答案选择。
- 修正10万美元收入边界；CE五次插补均值与SCE自报收入仍有误差。家庭边界也只近似相同。未把SCE“自己的未成年子女”冒充CE“所有未成年成员”。资产、采购责任、性别继续不推断。

原型还生成了逐月整组置换版本：同月频率向量分布完全一样，但不再属于原分配的那个人。相同数值向量仍可能出现，不要求人为把每个人都换成不同数值。

### 数据还缺什么？

2019、2021、2022年官方公开ZIP本轮均HTTP403，失败清单已保存，没有假装下载成功。故当前原型不能称目标期对齐，更不能称路线B严格历史可得。需要补跨年文件、核对当年字典及发布/修订版本，再按目标月选择已完成且可用的季度。2020疫情及采集变化与季节效应无法在单年内分开。

未来频率三组应固定相同P、新价格、新闻与先验，仅改变：无频率／条件匹配频率／整组置换频率。暂不加旧“多关注高频商品、再判断持续性”的混合说明，避免同时改两个机制。先把这个候选做干净，不与信念改动格式一起变。

## 四、理论给我们的方向

随机信息实验显示，相同信息确会缩小分歧；另一类情境研究又显示，相同事实可因人们联想到的传导渠道不同而产生不同判断。因此当前差距既可能来自信息太完整/太共同，也可能来自理解方式。下一轮隔离信念更新格式，之后再单独检验成本/需求/持续性线索，不把解释类型任意当作人口真实比例。
