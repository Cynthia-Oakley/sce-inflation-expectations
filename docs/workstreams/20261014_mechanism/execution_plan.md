## 第一项：明确本人信念的地位（先做）

**要回答的问题：**把“过去的一次回答”明确说成“你当前信念的起点”，能否减少模型对个人差异的压缩？

已完成：现有提示核查、明确先验提示块、完整样例、文字一致性检查、独立入口、16个离线单元、用户授权、768次真实调用与配对评价。

本项原定六步均已完成：

1. 接入独立实验入口，保留原提示与新提示两组；旧运行入口、配置、回答不覆盖。
2. 选定开发样本、重复生成及后续验证月份。现有八期可供开发诊断；新规则不能在看完评价结果后再调整。
3. 封存完整P/E/先验/问卷。两组仅差先验作用说明，不能同时改变新闻、购买频率或模型。
4. 离线跑通，核查实际发送内容、失败处理、输出与费用上限，给用户一张具体运行卡。
5. 用户确认本批范围及预算后真实执行，保存原始回答、费用和失败记录。
6. 与原提示、上期延续、过去个人锚比较，记录有效、无增量或有代价的结果。

**开始模拟的条件：**独立入口与干跑通过，完整配置/样本/评价规则已封存，新增调用范围和预算已明确。

**主要评价：**Q9群体中心误差、跨人分布W1、个人更新分布W1；辅看上期位置的保留程度、IQR和秩相关，Q8另列。接近上期延续但不再合理更新，仍不能称整体成功。数值门槛与允许的取舍须调用前登记，不沿用结果后挑选标准。

**实测处理：**跨人W1降低约11%，IQR有所恢复，中心MAE没有改善；按原筛选不升级，原提示仍为下一项共同基准。完整记录见[先验对照](anchor_role_results_20261014.md)。不再微调措辞重复跑同四期。

## 第二项：购买频率影响价格感知（准备可与第一项同步）

**要回答的问题：**有购买频率数据和明确的注意力说明，是否比只给支出占比更接近居民？

已完成：2,835个家庭周的分类购买日数，支持/缺失状态和来源检查，明确频率作用的提示块。

待做：

1. 核对SCE与CE共有的年龄、收入、教育、住房、地区等字段，逐项确认口径和缺失，确认哪些真的能匹配。
2. 建立整条分类频率向量的条件供体抽样，保存池大小、抽样权重、匹配回退和固定种子。两周属于同一家庭，不当成独立家庭。
3. 将购买类别对应到E价格。食品、家务用品及服务、个人护理等不硬套同一个指数；缺少合适价格时先补来源或明确代理。
4. 生成匿名居民的完整输入样例。购买日数不是购物次数、全年习惯或本人真实经历；缺失不填成零。
5. 准备同一频率数据“有/无明确作用说明”的对照；若有增量，再比较条件匹配与随机置换。

**开始频率模拟的条件：**字段匹配、供体和价格类别可追溯，真实消息通过离线检查，新的提示/样本/评价/预算已封存。先验第一项的结果决定下一项采用哪份基准提示，并明确记录；不同时改多个机制。

**主要评价：**中心与分布误差、更新误差，以及匹配相对置换的增量。只有回答更分散、只在一个时期改善，均不足以升级主机制。

## 第三项：Events触发经历与联想（保留，随后做）

**要回答的问题：**当期油价或政策事件能否唤起不同个人的相关经历，形成不同判断？

待做：

1. 从已有新闻和政策材料选定有明确内容、日期的事件，核对与历史经历的可解释联系。
2. 查外部调查中“具体事件下的理解类型”及其人口关联。若只有总体比例，不声称已经得到个体匹配依据。
3. 重做年龄—记忆候选：保留出生/年龄范围，描述相关历史阶段与走势；不能把年龄代理说成真实个人亲历。
4. 先做同人随机交叉提示，检验联想说明是否起作用；有联合数据后才讨论代表性人口的类型分配。长期背景保持，事件可改变当期先想到的过程。
5. 单独登记实验。不能因旧历史叙述未改善就删除记忆方向，也不把旧输入原样扩大再跑。

## 第四项：有效后才合并、扩大

先验或频率候选在开发中显示可解释的改善后，再登记未用于选择提示的时期及额外种子；已有真人全跨度描述分析不能用于独立测试期的参数拟合。

随后验证机制能否共同工作，检查各时期和人群的代价。仍须与同信息基线比较；记录宏观中心、跨人分布与个人更新三者的取舍。

目前这些试验是A路线回访者的条件诊断。B路线另需用自己的模拟历史连续推进、给新加入者初始化信念，并检查误差累积；A的真实个人上期答案不能直接当成实时B输入。

## 方向调整与暂缓项

主线转为先验表达与购买频率。本轮不启动换模型、同时添加人格/概率取整、重新跑原来八期或无依据的随机扰动。

“保留个人位置＋单独估计公共更新”的程序方案保留作后备。若先验提示仍不能保留个人位置，则再比较这个程序方案；未经实测不能说它必然优于LLM。
