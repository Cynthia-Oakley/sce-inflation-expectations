# 个人信念更新：直接回答与报告改动的开发小试

2026-10-15。**384次真实调用已完成，无连接错误、无重试；按高峰token价记约$0.434（非供应商账单）。候选未通过，不采用完整十档改动格式。**详见[结果与解释](revision_format_results_20261015.md)。以下保留准备与原评价约定。

## 为什么做？

已有模拟经常把不同居民原有的高低判断拉近。只在提示里强调先验，或机械混合过去与新答案，未解决总体中心与个人更新的取舍。本轮问一个更窄的问题：**同样的个人起点和环境，要求模型报告“改动”，会不会比直接重答更好地使用个人历史？**

它是回答方式实验，不是新经济学结构已被证明。任何合法的绝对Q8/Q9都能改写成差值，故没有人为规定更新幅度或分布宽度；但表达方式仍可能改变锚定、计算负担与概率分配，需要实测。

## 实验配置与对照

- 四个已有开发月：2020-04、2021-05、2021-11、2022-03，涵盖不同环境。均此前看过，不称新留出测试。
- 每月从原冻结48人中，按预设种子、不看本期答案随机抽24人，合计96个人月；不是全国代表性新样本，也不是96个独立月份。
- 两组各生成两次，共384请求。两次保持相同消息，用于观察生成变化；不是“人没有获得新消息时应不更新”的现实因果实验。引擎种子不等于API确定性种子。
- 直接组：报本期Q8点预期及Q9十档概率。
- 改动组：报Q8相对本人上期增加/减少多少通胀百分点，及各档概率增加/减少多少概率百分点；程序加回原值，再用原冻结计分器评分。
- 两组人口、环境、本人上期Q8/Q9、历史摘要、问卷预测窗口和共同起点说明一致。只改变输出表示；不是与早先批次的不同提示混在一起比较。
- 沿用原信息时点标签、价格/新闻、政策、合成CE支出占比与合成美联储信心；不加入新的购买频率、认知原题、财务Q1或性别。
- 样本1人上期Q8缺失：两组均直接报其本期Q8，改动组仍报告Q9变化。不用Q9均值假造上期Q8，不删掉此人。

## 模型、费用与授权

DeepSeek官方API `api.deepseek.com`，`deepseek-flash`，官方当前标示DeepSeek-V4.1-Flash；温度0.5、关闭思考、每次最多1024输出tokens、无自动重试。别名并非固定权重，运行保留返回模型标识、指纹及实际消息。

按[官方价格页](https://api-docs.deepseek.com/quick_start/pricing/)2026-10-15核查的高峰未缓存输入$0.30/百万tokens、输出$1.20/百万tokens作保守记账。规划估计约$0.459（假设约4字节/输入token、300输出tokens，并非报价）；按输入UTF-8字节+256及最大输出预留约$1.786，分单元预算合计不超过用户已批准的**$2**。

用户通过具体确认卡明确授权目的地、真实上期问卷和画像范围。授权记录：`revision_format_authorization_20261015.json`。不发送原始ID、权重、本期答案、实际调查日、性别、MIDUS。预算和用量为本地记录，不当作供应商账单。

## 已完成的工程核查

- 9项定向检查通过：原信息/共同指令保持、缺失分支、大幅改动可表示、非法概率不修复、原回包留存、恢复值进入Action、非法回答不重试。

- 新provider、入口和评价独立保存；没有改旧模型、旧输入或冻结计分器。运行副本从唯一源码单向导出。

## 怎样评价？

原先已用的三项仍并列：所选人群Q9中心中位数误差、跨人分布W1、个人更新分布W1；另看Q8、个人不确定性、通缩全零比例、历史位置保留及非法率。

小试继续判据：改动组减直接组，跨人W1按月内人配对的95%上界小于0；中心MAE与更新W1点值不恶化；新增可评分比例至少99%。沿用局部候选判据，**不是项目成功标准**，更不要求分布越宽越好。若有局部改善但未达条件，记录为线索，不自动升级。

两次生成按人配对保留；四个月等权，另列月份重抽敏感性和原调查权重辅助结果。区间条件于这四个已选月份，不能推广成全国可靠因果结论。真值与过去信息基线仅在离线评价读取；选样、提示与转换不读取本期答案。

这是**历史重建A的回访者条件诊断**：采用真人上期信念及回顾合成画像。B路线需要沿用模拟者自己的上期状态并处理新加入者，不能据此宣称完成。
