# 人口信息回顾：有哪些，已用哪些，怎样转成机制？

核查日2026-10-15。核对本地官方问卷44页、公开核心微观文件、目前人口/提示/新闻及频率匹配代码；只作本地清点，没有新增API、外发字段或运行配置变更。

## 一、“实现新回答方式”不等于已经让模型用它回答

上一轮的准确状态是：**新格式转换器、校验及191对输入草稿已实现，尚无新格式的真实模型回答。**

例如：给程序上期点预测3%，再给一个人工写好的测试返回“改动+0.5个百分点”，程序恢复3.5%。十档概率同样相加恢复并检查合法性。这个测试证明程序能处理这种格式，不能证明LLM会更重视个人信念、更准确或更有差异。

旧八期回答被复用来做数学拆解，也没有重新调用模型。因此上轮费用0与完成本地开发并不矛盾；但若把“新的回答方式已实现”理解成“模型已按新方式模拟成功”，就是表述不够准确。后续真实行为检验仍未运行。

## 二、数据里究竟有些什么？

本次数量以2020-01—2024-12显式筛选的71,976个人月、60个月为分母。首次入组题往往只在第一次填写，不能把其每月空白视为“没有这个特征”；同人回填只能向后，并记录来源期。229列中还包含大量调查答案和派生指标，不是229个人口变量。

### 1. 基础人口与生活阶段

- 年龄：`Q32`首次实际年龄、`_AGE_CAT`年龄组。现用粗组，实际年龄可以补生活阶段；仍无精确生日。此前个人时代经历试验未显示稳定改善。
- 性别：`Q33`，问卷女/男两类；不是从姓名或其他特征推断。191/192个所选人月有严格早于目标月的本人记录。当前正式模拟未纳入，不因此直接规定女性预期更高。
- 族裔与族群：`Q34`、`Q35_1..6`，有真实记录，当前未纳入。先用于描述代表性和误差，不先把它们变成主观判断规则。
- 教育：`Q36`九类（含“其他”）与`_EDU_CAT`三粗组。当前使用三粗组；所选192人历史Q36均可追溯。学历是类别，不宜把1—9当连续能力分数。
- 婚姻/同居：入组`Q38`、回访`DQ38`；当前未作为独立状态使用。
- 家庭成员：入组`Q45new_1..9`、变化后`D2new_1..9`，含配偶、不同年龄子女、父母、亲属、非亲属、独居。新频率原型只做了粗家庭规模，更新链仍待补。

### 2. 收入、工作、住房与本地处境

- 收入：入组`Q47`、回访`D6`，11档过去12个月税前家庭总收入；当前主画像用`_HH_INC_CAT`三粗档。收入不是净财富，也不是精确当月工资。
- 工作：`Q10_1..10`是多选，区分全职、兼职、想工作但没工作、临时停工、病假、残障、退休、学生、家庭事务等；当前合并成一个较粗状态。`Q11`工作数量、`Q12new`雇员/自雇、`Q37`在职时长、`DSAME`换工作/新就业，可补个人冲击，尚未系统接入。
- 配偶工作：`HH2_1..11`与`DHH2_1..11`；目前未用，能帮助区分家庭收入来源和配偶失业冲击。不能只看受访者本人就业。
- 住房：`Q43`租/自有/其他、`Q43a`住宅在谁名下、`Q44`其他住宅；目前主要用住房身份。它们没有给出完整房产净值或家庭资产负债表。
- 地理与居住经历：`_STATE`、`_REGION_CAT`、`_COMMUTING_ZONE`，以及`Q41`本住宅居住年数、`Q42`本州居住年数、`D3`搬家。现用州/大区和搬家保护，未用居住时长；不把公开地理组冒称精确地址。

### 3. 与认知和行为更直接相关的资料

- 数理/金融知识：`QNUM1/2/3/5/6`五题与`_NUM_CAT`高/低，另有`QNUM8/9`购买力与金融知识题。后两题不在当前官方高/低分类五题中。当前只传高/低一句话；已有分组诊断，但没有证明这句话的独立因果效果。
- 财务决策分工：`Q46`从他人决定到共同决定、自己决定，181/192有历史回答；它不是“谁买菜”。独居等跳题也不能一律解释为随机缺失。
- 风险偏好：`QRA1`财务风险、`QRA2`一般生活风险，192/192有历史回答。2020—2024实际数据均出现1—7，问卷文字写1—7、图示却只列到5，接入前应留存此口径问题。更敢冒险不等于认为通胀更高，偏好不能直接当概率判断。
- 健康：`Q45b`五档自评健康，192/192有历史回答；当前未用。可以作为医疗接触的候选代理，不自动推算真实医疗支出或价格。
- 经济处境感受：`Q1`过去12个月家庭财务变好/变差；已有独立研究和心理属性试验，并非从未注意，但不在当前八项核心画像中。它不是一般幸福度或稳定人格。

### 4. 有记录，但不能直接冒充人口特征

`Q2`未来财务状况、未来就业/收入预期、`C4`食品/油价/租金等预期，本身也是居民当期的信念/调查回答。可以研究其与通胀预期的联合形成，不能把它们当客观价格或免费已知P加入独立预测。`Q48`调查兴趣是在答题后问的，也不是外生、稳定的注意力参数。

核心文件中没有直接测量每个人的购物次数/常去商店价格、新闻阅读记录、央行信任、一般乐观人格、宗教信仰。不能由相近题目或列名自行补造；扩展调查需另查。

## 三、当前真正用了多少？

当前主P白名单是八项：年龄组、教育组、粗收入档、大区、州、住房、就业、数理能力。`_persona_sentence`中的教育和Numeracy主要仍是文字标签。

但不能说所有P都只“提一嘴”：收入/年龄/住房/地区/教育还参与CE供体匹配；住房、就业、合成支出参与个人新闻抽样；住房/地区在价格体验候选中也有作用。教育匹配在供体稀疏时频繁被放宽；Numeracy尚未形成独立、经验证的信息理解/更新/报告机制。

合成CE篮子、合成美联储信心、本人真实上期Q8/Q9，是不同来源的附加信息，不是核心SCE直接观测的三个人口字段。新旧实验的实际输入仍以各自冻结包为准，不把候选全部说成已上线。

## 四、本轮发现一个比“再加标签”更优先的数据缺口

目前细分供体原型主要取入组`Q47/Q45new`，但问卷另有回访更新：

- 所选192人月中166个的最新历史细收入来自`D6`，比入组记录新；其中69个细档与入组值不同。
- 18个在目标月前报过家庭构成变化（`D1=2`），有对应完整`D2new`；仅用搬家标记无法覆盖新生儿、成年子女离家等变化。
- 6个在历史中报过换雇主或此前未就业等状态（`DSAME=3/4`）；这个数量只是覆盖，不是冲击造成预期改变的证据。

**需要先补“入组状态→回访更新”的读取链，再冻结更细匹配。**这不证明既有所有人口画像错误：旧模拟用官方粗分类；直接受影响的是刚准备、未进入LLM的新细分原型。69个细档变化也不意味着69个跨了粗收入组，本轮尚未做该比较。

最新收入仍是滚动12个月总收入档，变化可能来自边界跨越、报告/家庭变化，不可直接叫工资冲击。家庭更新只在已报告变化时有完整状态；其他缺失不能自动认证“完全没变”。

## 五、怎样把特征真正转成机制？

### 第一层：决定接触什么信息

**收入、家庭规模/子女、住房、本人及配偶工作 → 生活约束与采购结构 → 相应的CE供体、品类与个人新闻。**先用可比的实际字段匹配，保持篮子与频率整组相关结构。不是给收入低的人直接加2个百分点。

### 第二层：决定如何理解信息

**教育、数理/金融知识 → 信息理解、渠道选择、对供需/政策的解释 → 信念更新。**这是需要验证的机制假说，不能默认高学历必看联储、低学历必不懂统计。可用控制同P/E的情景对照，分别测试宏观统计与日常价格体验的作用，再检查学历/数理组是否出现与真人相符的差异；不任意设置70%/30%行为类型比例。

### 第三层：决定如何表达不确定性

**Numeracy及本人过去答题习惯 → 信心、概率尾部和使用精度 → Q9表达。**本地2020—2024数据的低/高Numeracy组，Q8中位数月均差3.00pp，个人不确定性差3.35pp，但Q9密度均值中位数月均差仅0.0013pp。不能把“低Numeracy”实现成机械提高Q9中心。

一个有依据的候选是：有本人历史时优先使用其真实过去不确定性与表达习惯；新参与者用训练期中条件分布初始化，再检验更新。它仍需独立验证，已有机械取整未解决异质性，不能换名再宣称有效。也不通过故意算错或破坏概率和来模拟低数理能力。

纽约联储研究在SCE中也报告，教育、Numeracy与个人不确定性/尾部有关，并讨论不同群体可能把同一疫情理解为需求或供给冲击。这支持区分理解渠道与概率表达；相关性不等于固定因果规则。[官方研究§8](https://www.newyorkfed.org/medialibrary/media/research/staff_reports/sr949.pdf)

风险偏好、健康、性别等先做数据关联与传导核验，不同时全加。性别尤其不能直接替代采购责任；若没有对应中介资料，应先作为误差分组与敏感性检查。

## 六、下一步安排

1. 保留新回答格式的独立准备；它还没有真实效果结论。
2. 给新频率匹配修正`Q47/D6`、`Q45/D2`更新链，保留旧快照；明确收入/家庭定义与来源期。
3. 单独登记教育/Numeracy的候选作用、可观察验证指标和训练/验证时期，不与回答格式同时改动。
4. 先验或新人口字段在A路线可作条件诊断；B路线依赖可得历史、合成/递推状态，不能取得真实当月问卷后称未来预测。
