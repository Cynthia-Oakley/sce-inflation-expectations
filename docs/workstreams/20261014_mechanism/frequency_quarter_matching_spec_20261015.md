# 多季度与匹配核查：离线范围

2026-10-15。用户要求核查购买频率是否受单季度采样和家庭匹配影响。本轮只分析现有CE 2020年Q1—Q4及既有192份合成分配，不读当期SCE答案，不调用API、不修改已运行输入。

1. 用每季度有效官方字典重建四类记录日数；复现原Q4可用家庭/周数和向量。比较四季度原供体分布，以及固定收入—年龄条件下对同一192画像的标准化分布。
2. 保留原匹配优先级、最小25家庭/有效数15，比较Q4与全年供体的匹配支持、条件放宽和分布。全年仅作等季度总质量的回顾性混合，不称官方年度估计或预测时可得资料。
3. 给定供体和画像，200个抽样种子检查原192人频率均值是否罕见。它只衡量供体抽取随机性，不衡量真实模型误差，不冒称调查抽样置信区间。
4. 分别报告未知/缺失和四类均无正记录的周。后者加入敏感性分布，不能把无明细或未知日码补成零。
5. 核对收入字段、住房代码及实际分档匹配；检查五套收入插补是否跨分档。资产只按有无真实共同字段判断，不能把住房身份当净资产。当前白名单未使用家庭规模、子女和购物责任，列为缺口，不直接增加输入。

交付：新study分析模块/薄入口、忽略目录私有供体及聚合结果、原阅读页新增解释、任务清单/交接更新。只提交程序和聚合资料，保护既有15份待审改动；本轮无新模拟结论。

追加字段可得性检查：只读SCE原始工作簿的人口列，清点Q44/Q45/Q46/Q47及收入编码对应、核对已缓存问卷；不读通胀答案、不作个人回填。收入分档边界差异登记为新候选修正，不改旧匹配器。
