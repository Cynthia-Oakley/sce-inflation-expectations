# 人口历史覆盖、年龄与购买频率

2026-10-15。新增API调用0、费用0，旧画像/提示/运行配置未改。本轮只读人口字段和已有CE记录，不读当期通胀答案。

## 1. 所选192人有没有更细的真实资料？

连接原样本的身份侧表，追溯2017—2019及2020—2024原始文件。每个字段只允许使用严格早于目标月的本人有效记录，不能用本期或未来记录补缺。

- 首次参与时的实际年龄Q32：192/192。
- 11档家庭收入Q47：192/192；转为粗档后，192人均与原本期画像的粗收入档相符。
- 可解析的家庭构成Q45：191/192，其中9人在记录后有搬家记录。搬家不一定改变家庭人数，但旧记录不能未经核查就当作现况。
- 是否拥有其他住宅Q44：192/192；它不是净资产。
- 家庭财务决策分工Q46：181/192；它不是实际购物责任。

这些记录距目标月1—11个月，中位数5个月，均不超过12个月。它们是“本人已观察到的历史特征”，不是本期重访实测值。收入未跨粗档也不证明细档或实际收入没变；家庭成员可在不搬家的情况下变化。

年龄可以从首次实报年龄与经过月份推算当前年龄范围；没有生日，不把推算值当精确生日或准确出生年。已有年龄粗组仍保留，不需要为了更细分组立即增加付费实验。

Q45解析排除非亲属室友，独居选项只作标志，不能算一名额外成员；完整缺项不填0。有非亲属共同消费的CE消费单元与SCE家庭边界仍可能不同。

本轮没有把新字段加入匹配器，更未把它们发给模型。A回顾重建可以检验这些真实历史资料；B仍须处理微观资料的发布滞后和合成人口初始化，不能因记录月份较早就称当时公开。

## 2. 年龄与购买频率确实有关，但不是所有类别都一样

使用2020四季有完整支持的家庭周，包括四类均无正记录的周；缺失频率继续排除。完整控制样本9,525个周、5,154个消费单元。先按家庭、再按其周分配权重，四季度源质量各四分之一；同户两周的误差按消费单元聚类。

两种描述回归都控制季度、收入档、住房、地区、教育：第一种只看这些条件，第二种再控制家庭人数和未成年子女数。八个年龄联合检验作BH校正。线性回归用于条件均值关联，不用作新的频率生成器，也不解释为年龄的因果作用。

控制家庭构成后，相对40岁以下：

- 40—60岁：在家食品每周约多0.307个记录日，95%区间[0.202,0.412]；60岁以上约多0.291，[0.182,0.400]。
- 60岁以上：外食约少0.564天，[−0.723,−0.406]；40—60岁差异较弱且区间跨0。
- 家务用品：40—60岁约多0.106天，60岁以上约多0.149天。
- 个人护理用品：控制家庭构成后，年龄联合差异没有清晰证据；不能把年龄机制推广到所有商品。

在家食品、外食、家务用品的年龄联合差异经八项校正后仍有统计证据。这只说明CE中年龄值得保留；年龄、代际、疫情参与和其他生活方式不能由这一年资料完全分离。家庭构成可能处在年龄的传导路径上，加入控制改变了研究问题，不是自动识别中介。

**当前原匹配已经为192人全部保留年龄粗组。** 因而新证据支持继续保留/细化年龄与生活阶段，而不能解释此前两组的负效果，或承诺再加入年龄标签就会改善SCE拟合。

## 3. 应怎样利用？

下一候选可以优先尝试细收入、家庭规模/有无未成年子女与年龄共同匹配，而不是独立给每人多加标签。先处理记录时间、搬家/缺失、10万美元收入边界及供体池稀疏问题；保留回退规则和多季度不确定性。没有共同净资产或真实购物责任时继续标未知。

改进匹配属于输入基础建设；主机制仍要单独检验“原有信念怎样被新信息改变”和“判断怎样表达为Q9概率”。不能从人口关联跳到解释LLM处理效应。
