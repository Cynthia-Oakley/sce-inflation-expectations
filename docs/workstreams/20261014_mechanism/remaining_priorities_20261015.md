# 频率实验之后：还有什么值得推进？

2026-10-15；本次整理不改变冻结实验与判据，没有新付费调用。“优先”表示问题与现有差距更直接，不等于已证明能降低误差。

**最新落实与时间建议：**已完成[70个月真人字段关联分析](population_association_results_20261015.md)，细学历/具体答法主要对应个人不确定性，财务变化主要对应预期位置，风险/Q46不宜硬编码。此前[共同变化诊断、改动格式草稿和匹配原型](belief_update_and_matching_preparation_20261015.md)继续保留。建议先准备“更新格式”“认知输入”两项独立小试，价格匹配同步离线补缺，持续性/事件理解作为备用；时间安排统一见[ROADMAP最新节](../../ROADMAP.md)。跨年CE仍HTTP403。以下旧优先级保留推理，不据序号机械执行；最新完成状态以任务板为准。

## 我们现在最需要解决什么？

一是总体中心仍不稳定，常落后于简单过去信息基线；二是模型把不同居民的原有高低位置拉近；三是十档概率与真人表达不同。人口匹配更精细有价值，但不能让所有问题都归到缺少画像变量。

## 1. 第一优先：保留个人位置，单独估计新信息带来的更新

**尚未完成：**把公共月度变化、个人原有位置、个人特有更新分开建模并独立验证。目前一次自由回答仍把这三件事混在一起。

**依据：**本人历史明显改善结果；模型条件下对个人历史高低的保留仍弱于真人。过去信息基线保留宽度但不产生足够更新，LLM有时较接近更新分布却压窄横截面，两者的取舍值得分开研究。

**具体交付：**先离线登记一个分开更新的候选，让共同变化不自动覆盖个人位置；复用已有LLM回答检验信号质量，再准备真正不同的输入/输出方式。比较无LLM的同结构版本，说明模型究竟增加了什么。

**重要边界：**固定加权混合已经试过，八期开发选择新信息权重0，未通过。下一步不能只是换几个权重重做旧试验；新方案也不能通过真实当期中位数偷补预测成绩。A若明确用真实宏观总量校准，则该总量不再是独立验证指标。

## 2. 第二优先：价格上涨为何会持续或消退？

**尚未完成：**将频率注意力与持续性判断分开做同人对照；根据调查数据而非任意比例分配事件理解方式。

**依据：**近期价格涨幅不等于未来12个月涨幅。央行信息候选曾有改善迹象；频率处理段又混入持续性要求，现有结果没有单独辨认哪一项改变了回答。

**具体交付：**固定P/E事实和个人起点，只改变一种信息解释方式。先准备一个能区分需求变化、成本冲击及暂时性变化的输入；用现有调查/文献支持分配，或明确标为实验情景，不冒称美国人口真实比例。

**希望改善：**主要是共同中心和各月更新方向，而不仅是把答案变散。事件触发记忆可以在这里检验；旧时代背景整段叙述未奏效，不重复原样堆历史。

## 3. 第三优先：Q8判断如何表达为Q9概率？

**尚未完成：**区分概率表达的形状、个人不确定性与预期水平，检验哪一部分导致Q9中心偏移。

**依据：**Q8的小幅改善不一定传到Q9；真人与模型的零通缩比例差距大，但模型的中央区间未必更宽。这些是不同问题。

**具体交付：**基于真实历史训练期的Q8/Q9关系，设计报告层诊断，保留原始回答与任何变换后的两套结果；独立时期比较中心、W1和不确定性。不强迫Q8等于Q9均值，也不强迫所有人给0通缩。

**重要边界：**个人历史取整映射已经验证过，主要改善形式，未显示清晰身份增量。不能把再取整一遍当成新的异质性机制。没有证据前，不把报告层放在信念更新之前。

## 4. 同步但限时：改善人口匹配

**已完成的新依据：**原192人细收入/年龄历史覆盖192、家庭构成191；CE年龄与在家食品、外食、家务用品日数有关。多季度减少教育/地区条件放宽。

**未完成：**处理历史记录的新旧/搬家，结合年龄、细收入、家庭规模建立新供体候选，补非疫情及实验年份；修正收入边界，核查支持和回退。资产和购物责任继续保留未知。

它提高输入可信度，可能改善人群差异，但原匹配已保留收入/年龄粗组，不能把它视为系统性误差的已知答案。本项不先触发新的LLM大批次。

## 5. 最终必须完成：更广验证与路线B连续模拟

**未完成：**新规则登记后在不用于调整的月份/种子验证；代表性人口与新参与者；让模拟者使用自己的过去回答连续运行，检查1/3/6/12月误差积累。

同时登记同信息基线、模型身份与历史知识/日期提示的敏感性。当前真实本人上期答案是A条件重建输入，不能逐月取得后宣称B预测。

扩大验证是检验可推广性，不保证提高拟合。新调用在实际输入、范围和预算明确后再执行。

## 暂缓什么？

- 继续横向更换许多基础模型：已有小试差别有限，当前先定位共同失败。
- 任意人格比例、宗教标签或随机措辞扰动：缺少可靠条件分布和传导验证，方差变大不等于更像真人。
- 重新做已完成的概率取整或反复微调同四个月提示：保留阴性结果，避免把开发月当考试反复练习。

人格/乐观、近期财务冲击、社交传播仍是候选库，不是已否定的因素。优先补“可观察、可对应、能区分机制”的变量，下一次实验每次只改变一个主要环节。
