# V3.2新闻数量与主题分配：执行方案

2026-10-22。开始离线准备；新增真实调用须另确认范围及预算。旧结果和旧失败策略不改。本文件是本轮分析约定，输入准备会记录其哈希。

## 1. 本轮要回答的问题

此前Flash试验中，随机新闻量略优于固定8篇，人口匹配没有可靠胜过随机。这不表示人口与关注无关：当前外部调查测的是一般经济新闻兴趣，人口预测力较弱，也没有本人实际阅读记录。现在模型已确定V3.2，需要检验该分配规则在新模型和食品价格视图下是否仍有帮助。

将“接触多少”与“接触什么”分别检验。主题对照有必要：目前50%均匀＋50%相关抽样是实际配置，但未证明身份匹配的独立价值。这里检验LLM输入机制，不估计真人阅读新闻的因果效应。

## 2. 四组具体怎么设置

- **固定8篇：**3篇共同头版＋5篇个人新闻；全部提示逐字复用已运行的V3.2输入。
- **随机新闻量：**每96人中48人3篇、28人8篇、20人20篇；192人对应96/56/40。共同头版保持3篇，个人新闻相应0/5/17篇。名额随机分给家庭。
- **人口匹配新闻量：**相同名额，按已有外部六档经济新闻兴趣模型分配，输入仅年龄、学历、收入和地区；先得到条件概率，再保留个体随机性，不按学历硬分高低。沿用旧算法和名额，不重新按SCE误差训练。
- **随机新闻量＋均匀主题：**每个人篇数与随机组完全相同；个人新闻取消相关加权，均匀抽取。采用相同随机数序列减少额外抽样噪声。该比较只改变主题抽取政策，不改新闻数量。

前三组个人新闻继续按既有50/50概率混合、相关项2倍抽取。主题相关性仍由住房、就业和合成CE食品/汽油份额决定；这些是代理，不称本人已测阅读偏好。不把采购角色直接等同财经关注，也不新增性别、驾驶、人格或政治流派推断。

随机/人口数量组保持相同人数名额，选第一个满足既定输入平衡的置换：设计加权篇数、新闻字节及提示字节差不超过1%，粗主题占比差不超过2个百分点，最多4096次。只看输入，不看模型回答或真人目标。这个随机组是**带平衡约束的随机分配**。

均匀主题组会改变新闻文字及主题构成，可能带来长度变化；本轮会披露，不称等语义信息量。3篇组没有个人新闻，因此主题对照在那里按设计无差异，另报告8/20篇人群的结果。

## 3. 月份、样本和复用

为立即开展研究并避免等待全时段新闻，采用已完成V3.2的八个原始人群，不依结果重新抽样：

- 2020-09、2021-09、2022-06、2025-03：各96人。
- 2025-04、06、08、10：各192人。

共1152个人月，四组各生成两遍，对应9216个比较位置。四个2025新月份此前没有用于新闻数量机制选择，但已经看过模型选择成绩；不称完全盲测。较早月份用于跨环境复验，近期月份作为机制迁移检查。月份各自等权、生成遍数等权；每月内用相同设计权重，另分别报告两段时期，不将不同人数解释为相同精度。

这调整了此前“六个月均192人”的准备建议：保留所有现成V3.2人群和回答，扩到八个月，不为补足旧月份人数重新构造人口、采购角色和价格视图。Kimi准备中的其他新月份留给连续主运行，不由本轮成绩决定替换月份。

固定8篇逐人逐遍匹配旧调用，必须人员、月份、提示全文/哈希、模型、供应商、温度、参数均一致。原失败也保留，不借本轮把失败重发。不同组若同一人同一遍完整提示相同，只调用一次，其他比较位置引用同一原答；因此“比较位置数”大于“新增请求数”，共享结果不当独立重复。

本轮分配种子固定20261022；两遍生成只衡量LLM随机性。其他分配种子可先零API检查输入支持，但不能据此声称新回答已对分配种子稳健。若有清晰信号，最终连续运行前须按预定第二种子确认；不根据本轮挑表现最好的种子或名额。

## 4. 固定的其他输入与信息边界

沿V3.2已运行输入：同一去标识SCE人口、合成CE支出与美联储信心、食品采购角色和可见价格、公开价格/政策、本人真实上期Q8/Q9及更早均值/次数。仅替换新闻块，并按接收者上期作答日重算新新闻的“此前/后来/同日不明”标签；不发送实际作答日。

共同头版由A1版面决定，3篇各组相同；个人池沿已有精筛keep标签和相同窗口。相同文章不重复展示；不按事件相似度删除不同日期的报道，跨月记录保留。只用当月截止前公开的资料；未知历史文字版本不能因此变成严格事前输入。

本轮是有真实过去信念的A线条件重建。外部关注数据及合成人口变量的迁移有误差；模型训练知识未能完全核实，不能由本次结果排除记忆问题。

## 5. 运行与缺失处理

- 模型固定`deepseek/deepseek-v3.2`，OpenRouter→SiliconFlow FP8；温度0.5、JSON、关闭思考、最多1024输出token，直接填写Q8/Q9。
- 复用官方Core逐单元干跑及既有逐请求队列；一个启动命令自动执行和评价，不手工逐包启动。8并发技术段，随后最多16并发。
- 前32个**新增**请求只检验接口/格式，至少31个经已授权比例归一化后可用则继续；不用拟合成绩决定是否继续。
- 每个新的唯一请求最多尝试一次。无自动重试、无供应商回退，旧失败不补发。孤立网络失败保留，致命错误或连续三次瞬时错误则停止。账本保存原答、失败、费用和去密参数。
- Q9仅对有限、非负且合计为正的十档概率等比例归一化，原答保留；负数、缺档等不修补。Q8独立判定，不因Q9失败删除合法Q8。
- **固定人群的运行结果：**目标人群先冻结。缺失/密度拟合失败，明确使用其已给出的上期Q9及对应派生量；Q8缺失才单独用上期Q8。后备单列，不伪装为新LLM回答。
- **实际输出对照：**同时披露所有组/两遍共同可评价结果、各对照双方支持、每遍结果及覆盖；基线跟随同一支持，不能用删掉若干人的基线提升作进步。

本轮预设每组可用和可计分覆盖至少95%才作机制筛选；低于则只作描述。95%是本轮工程容忍量，配合固定人群后备防止缺失改变目标，不追认旧试验通过，也不等于有统计功效保证。旧99%协议保留原判定。

## 6. 评价、分组和取舍

主比较为人口数量对随机数量；另两项登记比较为随机数量对固定8篇，以及均匀主题对相同数量的相关主题。三项是开发对照，不以其中最低MAE宣布独立成功。

先报告固定人群结果与实际共同支持结果，再看：群体Q9中心MAE/RMSE、跨人均值分布W1、更新分布W1、跨人IQR及距真人的差距。Q8单列。与本人上期照抄、固定历史锚分清；全国上期SCE组合另按固定较早窗口拟权，本轮不按测试月份拟最优权重。

逐月、每遍及删一月检查必须披露。按学历×就业六格、年龄、收入、上期信念水平和本轮新闻量分组；稀疏格N<10或ESS<10标记描述性不足，不据小格挑参数。以上均在已有评价cases/公共统计模块和面板适配中完成，不重写分位数/W1。

**本轮筛选规则：**候选相对对应对照，在固定人群下平均W1下降、至少5/8个月W1不增、两遍总体W1方向均不恶化；中心MAE增加不超过0.05pp，并披露变化W1/IQR的代价。实际共同支持若明显反向则不升级。该规则是有限时间内的开发筛选，不是经济理论阈值或正式统计显著性。配对区间按家庭聚类、固定这八个月，不能推广成全时期区间。

主题比较另报有个人新闻的家庭；随机量与固定8篇比较的是整项分配政策，平均条数虽未加权为8，设计加权平均可能不同。它不能识别纯粹“方差”作用。

如无清晰收益，保留固定8篇并结束该分支。如有信号，先按同一规则第二分配种子验证；不重新搜索心理、历史、温度、模型或名额。当前人数与结果也不等于新入组者或连续递推已经验证。
