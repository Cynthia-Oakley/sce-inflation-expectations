## 2. 分层评价与时间用途

- **有同期微观真值：**评价全调查者的加权中心、W1、分组、新/老参与者和更新；原回访者条件实验作为机制诊断保留。
- **微观缺失的近期段至2026-09：**用截止前已公开的旧微观结构、宏观边际与合成状态运行，以全国SCE及实际公开摘要评价。没有真实对应微观，就不声称已验证个人W1、排序或Delta；不能拿合成真值评价合成输出。
- 按时点回测逐月选当时已发布来源，不用今天最新文件统一倒填历史。目标月SCE结果只进评价；组合只用截止前最近已公开值。2026-09已经发布，现在运行不是新的事前封存预测。
