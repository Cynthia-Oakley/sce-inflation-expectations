## 结论与具体分类

在八类可用人口特征构成的126套三维/四维候选中，按开发期预测、框架支持和复杂度约定，推荐**学历三档×数理两档×性别两档，共12格，未知另池**：

- 学历：`_EDU_CAT`的High School / Some College / College，沿现有高中及以下／部分大学教育／大学及以上映射。
- 数理：官方High / Low，不重新定义数理阈值。
- 性别：公开问卷Male / Female；只作观察性分组，不解释为因果或假定某一性别必然怎样回答。
- 若需第四维，收入Under 50k / 50k to 100k / Over 100k可形成36细格，但应作为需部分汇聚的条件层，不能要求所有细格独立估计。

这不是唯一近优方案。学历×数理×收入、数理×收入×年龄等也接近开发最优；推荐12格主要是在信息与小格支持之间取舍。放宽支持约定后可能选择四维，详敏感性。年龄、收入、就业、住房、地区仍保留在个人画像和条件分析中，不因未成为硬分层而删除。

## 方法：冗余、用途和支持分别判断

1. 八个候选：学历、数理、收入、年龄、就业四类、性别、住房、地区。就业四类为在职（含休假）、失业、退休、其他未在职；不将退休和失业直接合并。现学历×在职二类六格另作基准。
2. 用每月调查权重归一化的Cramer V看分类关联，吸收月份后的虚拟变量整块调整GVIF看共线性。不给类别编号后直接PCA，不按单个相关阈值机械删变量。
3. 加权MCA只用于描述人口特征X的共变与碎石图；原始总惯量为2.0，符合完整分类指示矩阵恒等式。它不是问卷Y的解释力或选择主维度的充分依据。
4. 监督比较用四个领域：Q9个人均值、个人密度IQR、零通缩填法、个人均值CDF的九个固定阈值。四领域标准化月内损失等权；共同月份水平在评价中移除，衡量月内异质性，不预测全国月度公共成分。
5. 分类变量按整块纳入/移除，使用固定微小数值岭与同支持加权模型。去掉一项后重新拟合，可比较相关变量的独有预测信息；不是普通打乱变量后造成不合理组合的边际重要性。
6. 从56套三维、70套四维中，先要求开发期平均至少90%人口质量处于框架N≥20、权重ESS≥10的格，再在距最优一个区块自助标准误内优先少格。六个月日历块300次重抽；约定透明但不是功效或确认性检验。
7. 第一阶段加总式模型可能漏掉交互，因此对固定四套短名单追加同月联合格分布留出：256/512真人Core、两种抽样种子、四折受访者，同一Core用于各网格；强度8主检查，0/24敏感性。完整答卷供体原子积分，不把平均概率复制给所有Normal。

## 主要读数

**相关性未支持机械删维度。**年龄—就业的调查加权Cramer V为0.475，学历—数理0.317，数理—收入0.311，学历—收入0.287；整块调整GVIF约1.007—1.186，没有明显严重共线性证据。学历和数理相关，但各自保留条件增量。

**综合结构信息改善主要在概率宽度与表达。**旧六格→推荐12格的四领域平均月内预测改善：开发2.160%→4.449%，2023—2024为2.403%→4.346%，2025为2.584%→4.951%。这些是相对无人口差异参照的标准化损失改善，不是全国MAE，不是通胀率百分点，也不是直接解释了相同比例的全部个人行为。

开发期个人密度IQR的预测改善6.945%→14.476%，零通缩填法−0.139%→1.176%，均值CDF1.075%→1.448%；个人均值0.760%→0.695%，略低。2025的个人均值月内预测仍弱且为负。不能称四领域帕累托改善或全国拟合达标；本人既有信念等动态状态仍需单独保留。

**细分代价明确。**12格在82月有效权重框架中的平均强支持质量98.12%，收入四维36格71.42%；前者新人子池中仅56.17%质量处于至少10个新人的格，后者23.33%。新人分池仍必须适度汇聚。规划256 Core时投影格内ESS≥10的人口质量约95.37%／25.54%，但这是名额/权重近似，不是实际抽样或功效。

**联合格留出有支持，也有局限。**在256真人Core、强度8条件下，旧六格／12格／收入四维的开发综合改善约0.93%／2.78%／2.45%；2023—2024约0.91%／2.27%／2.35%；2025约1.78%／3.63%／3.76%。12格与36格的W1改善很小、部分设置反向。不收缩时四维明显过拟合；12格约28%预测质量借父池、36格约49%。这些真人Core只作统计可行性参考，不能替代LLM验证或当作未来预测成绩。

## 敏感性与不确定性

- 支持门槛90%→95%仍推荐12格；降到85%时转为数理×收入×年龄×性别四维。不存在由数据证明的唯一分法，第四层需要结合借用信息的强度和实际Core预算。
- 开发期配对综合改善约2.289个标准化损失百分点，描述性区块区间约1.933—2.625；它未消除候选搜索与既有数据查看的乐观偏差，不作为确认性成功门槛。
- Q8独立检查保留原值；原始最高10000使平方损失不稳定。±100只作敏感性，开发月内R²旧六格2.201%、12格4.101%、收入四维4.632%；原值开发R²都接近零。没有据截尾Q8重新选择主网格，也不改项目Q8清洗或统计。
- 结论依赖可用八特征、结果领域权重、加总模型和支持约定；未搜索全部家庭结构/心理/风险变量，也未证明因果机制或LLM能吸纳这些差异。

## 过采样后四维如何接入

### 1. 对原建议的修正

2026-10-23用户指出，覆盖应是约束，可以用长尾过采样与降权换取更多维度。这一意见成立。原筛选要求90%权重处在N≥20且权重ESS≥10的原始框架格，适用于希望多数格直接有强支持的方案；允许小格部分汇聚后，它不能继续作为排除四维的唯一硬门槛。原126候选分数及筛选记录保留，不事后修改旧协议，也不再把12格写成最终优选。

[ConsumerSim §4.2.2与§4.5.1](https://arxiv.org/html/2606.30395v1#S4.SS2.SSS2)明确采用稀少/行为相关格过采样，再用人口权重汇总；美国Core为5,000。该文没有给出可直接移植的逐格保底名额。我们可以继承抽样/权重思路，不能把自己选择的名额或收缩强度称为论文原参数。

**下一阶段优先评估学历3×数理2×年龄3×收入3＝54个已知画像格，未知另池。**性别等其他变量继续保留在个体P、扩展条件与误差分析中；这不是认为性别无效，也不是证明54格一定优于36格。这样同时保留用户关心的年龄与收入，且已有整块共线性诊断没有支持机械删除二者。已有开发/时间检查综合改善为4.917%/5.413%/5.471%，是旧加总式模型的月内结构评分；不是54格过采样的LLM成绩。

### 2. 具体抽样与权重

1. 每月先确定可用人口框架、各格人数N_g与调查权重之和M_g。目标人口比例W_g=M_g/ΣM_g，不读取本期通胀答案。A线使用既定历史画像条件；严格B线的目标比例只能来自截止日可得P，不能借未来发布的当期SCE微观资料。
2. 每个非空格先分配min(m,N_g)人；其余名额按M_g分配，并受N_g上限约束。小格可以过采样到全取，不能反复复制同一人来填人数。当前是保底加比例分配，不声称方差最优；不按当期误差挑格。
3. 格内按固定种子无放回随机选人，实际抽中概率π_i=n_g/N_g。设计权重d_i=w_i/π_i。已有月度准备已经实现这一原则，但格键仍固定为旧六格。
4. 为使有限样本中每格的汇总比例**精确**回到目标，再做格内比率校准：a_i=W_g d_i/Σ_{j∈Core_g}d_j。于是Σ_{i∈Core_g}a_i=W_g。仅用w/π在原权重不等时不保证每次抽样恰好复原格质量；二者分别记录，不能混叫一个权重。
5. 示例：真实占比2%的画像，在Core中故意占10%；最终汇总仍只占2%。这是校正抽样设计，不是根据拟合成绩调整人口占比。已实现的适配器返回原权重、π、设计权重、校准权重，均留在本地，不写进LLM角色提示。

### 3. 本次零API检查的实际结果

新结果为`outputs/sce_grid_oversampling_20261023_v2/`。只读取人口/权重列，没有载入当前或历史Q8/Q9。82月原框架98,382人月，其中有效正权重98,352；30个缺失/无效权重记录明示排除出**本次加权抽样检查**，不补1，也不据此从生产P里删除人。未知画像质量仍放独立池。

对12格、36格、54格，分别以256人保底4、384人保底6、512人保底8检查，并各用4个固定抽样种子实际抽取；这些是人口抽样检查，不是LLM生成次数。

**54格在三种名额方案下，82个月全部可分配；每次抽样的各格质量都恢复至目标比例，数值误差低于1e−12。**这是有效权重框架（含未知池）所有非空格的代表性，不是证明全国所有潜在画像已观测，也不是证明每格独立估计准确。

- 256 Core／保底4：每月保底总名额193—214，其余42—63名额按人口质量分配；平均总体校准权重ESS约204.6。
- 384 Core／保底6：保底总名额279—312；平均总体校准权重ESS约315.4。
- 512 Core／保底8：保底总名额357—400；平均总体校准权重ESS约424.9。

**应区分两种覆盖。**上述人口质量的代表性覆盖为100%；原框架中N≥20且ESS≥10的强支持质量仍只有57.19%，不会被过采样改变。512人方案中，实际抽取后格内ESS≥10覆盖的已知人口质量平均约60.03%（256/384人约7.22%/21.79%）。这不是说其余人口未进入模拟，而是这些格不能只靠自己的少量Core独立估计完整分布。上述ESS只描述抽样权重，并未包括LLM偏差或Normal共用供体的不确定性。

### 4. 与Core＋Normal的衔接

**最新实现见[Core＋Normal落地](../20261023_core_normal/index.html)：采用“Core按原人口质量保留本人答卷＋只对Normal/明确缺失字段作预测”的有限人口版本。下面全格分布估计保留为初始规划对照；它不再是当前实现的默认汇总。两种写法都不得重复加Core人口质量。**

细格保留完整四维分类；估计不足时，对答卷联合分布作部分汇聚，保留年龄、收入主效应并收缩信息不足的交互。具体父池/先验与强度仍须用开发期留出验证；已有“全局其他格父池”仅是早期诊断，不能直接当成熟生产模型。新人/回访者还需要分别条件化，不要求把小新人池硬切成54个互不借用信息的独立估计。

扩展单位应是完整Q8＋Q9联合答卷，而不是把平均十档概率复制给所有Normal。全国先合成各格分布F=Σ_g W_g F_g，再从F计算中位数；不能把各格中位数直接加权平均。如果按全部人口W_g合成F，不再额外把Core用w/π加一遍；另一种“Core保留本人＋只扩Normal”实现须明确拆分质量，避免双重计数。

过采样改善稀有格的Core信息量；部分汇聚控制小格噪声；人口权重校准保持代表性。三者不能相互替代。原始框架仅两个人的格，最多贡献两位不同居民，不能因模拟多遍就声称有十位居民的信息。格式/连接失败也不允许偷偷改π或假定缺失随机，需单独披露并按预定规则处理。

## 加权中位数与Core＋Normal汇总方案

2026-10-23用户要求先说明方案，不启动新实验。以下是与现有主Q9口径一致的规划；生产Normal尚未接入。

后续本地落地已完成，可复用扩展CLI和离线验证见[最新图文](../20261023_core_normal/index.html)；已实现Core保留、Normal积分。主运行接线/小试尚未完成，旧全格预测规划保留追溯，不据此启动API。

### 权重改变代表的人口份额，不改变预测值

可以把0.5或0.25理解为“相对于权重1的答卷，代表半份或四分之一份人口质量”。实际权重是连续的正数，也可能大于1；统一乘一个常数不改变加权中位数。它既不是模型自信程度，也不是把一个人的8%预测乘成2%，更不是把其Q9十档合计改成25%。每人的概率答卷仍按原合法性/归一化规则处理。

主Q9沿用现有两层口径：先由每份十档概率计算**个人拟合密度均值**x_i，再对这些个人值取跨人加权中位数。不是先将所有人的十档概率平均后再求一个主观密度中位数。Q8另外保留既有并列值折叠后的中分布插值口径，不在本规划中静默更改。

### 先组合分布，再找累计人口的一半

1. 由合法时间边界下的P确定每格人口占比W_g。Core按过采样方案选取；沿π与格内校准计算非负权重a_i，所有格合计为1、每格合计W_g。权重只由人口与抽样设计决定，不按本期真值或误差调整。
2. 只有Core时，将所有x_i从小到大排列，累计a_i，第一次达到50%的个人值就是主Q9加权中位数。等价定义：F(x)=Σ_i a_i 1{x_i≤x}，m=inf{x:F(x)≥0.5}。使用现有evaluation/metrics.py::quantile(...,.5)，不另造一套分位数算法。
3. 进入Core＋Normal后，先以Core和预先规定的收缩方法估计每格**跨人完整答卷分布**，由每个答卷导出其个人值，得到F_g。全国分布F(x)=Σ_g W_g F_g(x)，然后仍按累计50%取中位数。主指标优先直接积分答卷原子的权重，不为了凑Normal人数反复随机生成再计算中心，避免额外蒙特卡洛抖动。微观展示需要的Normal逐人抽样另外固定种子，不能冒称恢复个人真实信念。
4. 这一方案把Core作为估计整格人口分布的证据；W_g已包括整格人口，不能把Core额外加到全国分布里。若将来选择“Core保留本人＋只扩Normal”，必须改成明确拆分Core/Normal人口质量的另一实现，不混用两种汇总。

简例：五份个人值依次2%、3%、4%、8%、9%，权重依次1、1、1、0.25、0.25。总质量3.5，一半为1.75：累计到2%为1，到3%为2，因此加权中位数为3%；原等权中位数为4%。把所有权重乘4，成为4、4、4、1、1，结果仍为3%。变化来自8%和9%这两份答卷代表的人口减少，而不是它们的预测数值被缩小。

### 验证顺序及局限

- 先做确定性汇总检查：权重统一缩放不改变主Q9中位数；整数权重与复制等价；原值不变、每格质量正确、Core/Normal不重复计算；并列/恰好50%的情形按既有左逆CDF约定处理。
- 再按既定开发期做人群留出，用同一原始人口目标比较旧分层与54格过采样＋收缩。重点比较总体中位数MAE、W1和组内分布，不根据测试期真值调人口权重。后期已看数据只作时间稳定性检查，不重新称独立盲测。
- 对中位数的抽样波动，用分层抽样/扩展整条流程重算区间；Normal人数不计入新增独立样本，复用供体的依赖保留。
- 正确计权只保证人口比例的处理正确，不保证中位数更准确。累计质量恰好接近50%的附近可能对小幅权重变化敏感，需要随最终Core预算评估。
- 人口权重与宏观惯性组合权重是不同层：先得到当期加权中位数m_sim,t，再按另行冻结的λ构造λ m_real,t−1＋(1−λ)m_sim,t。不能将人口权重或λ按当期真实指标倒推。
