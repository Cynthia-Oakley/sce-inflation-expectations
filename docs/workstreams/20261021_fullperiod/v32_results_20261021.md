## 1. 结论与取舍

**V3.2值得进入连续月份主运行的模型候选。**同一人口、历史、环境和提示下，四个月的群体中心MAE与跨人W1均优于Qwen，跨人差异更接近真人，高先验人群不再被大幅压低。满足本轮预先规定的开发信号：可用/可计分率≥99%、W1差区间上界<0、平均变化W1不劣。

这不是最终独立验证：月份都已用于开发，Qwen控制为旧回答，托管实现与模型一起变化，完整训练/后训练截止未固定。当前12期旧参考配置与成绩不改写；不宣布全国误差已稳定低于0.3pp。后续应冻结最终配置与验证用途，结合Kimi补齐的P/E尽快运行连续月份，不继续漫无目的增加模型。

## 2. 配置和可比性

- 四期：2020-09、2021-09、2022-06、2025-03；各96个真实回访者，每人两次生成。
- 新模型：OpenRouter→固定SiliconFlow FP8的`deepseek/deepseek-v3.2`，温度0.5、JSON、关闭思考、1024输出上限、4并发，无自动重试或供应商回退。
- 对照：复用DeepInfra FP8 Qwen2.5-72B的768份旧回答。768项完整提示逐字核对，P、食品背景、合成采购角色、8篇新闻、本人真实上期Q8/Q9及更早摘要、时间标签完全相同。
- 全部768次新请求完成，0接口错误；实际回包均SiliconFlow且reasoning token为0。十档原始概率均合法且无归一化，已有Qwen沿用同一既定归一化政策。
- V3.2有767份可派生Q9连续密度统计，1份按冻结方法无法计分，不补造；另有真人不可用记录。主比较381共同个人月、379人，Q8为384个人月；每月双方同人同权重，两遍不算双倍人数。

**这里Qwen的0.792是同四期、同381个人月重新计算的数值，不能拿旧六期的0.634替代。V3.2也不能直接与旧12期DeepSeek Flash的0.459作纯模型胜负比较。**六项主汇总与原评价器的设计权重统计逐一核对，误差小于1e-8。

## 3. 主结果：Qwen → V3.2，括号为同支持照抄本人上期

- Q9群体中位数MAE：**0.792 → 0.349pp**（0.502），下降55.9%；相对照抄点值低30.5%。
- 群体中位数RMSE：**0.939 → 0.403pp**（0.529）。
- 跨人分布W1：**2.534 → 1.392pp**（0.996），下降45.1%，但仍落后于照抄。
- 跨人IQR：**3.217 → 4.553pp**，真人4.845；差距缩小，不能把越宽直接当越好。
- 个人Q9预期MAE：**3.486 → 3.024pp**（2.785），改善但仍不及照抄。
- 变化分布W1：**1.878 → 1.786pp**（2.785），总体小幅改善，不是每个月都改善。
- Q8群体中位数MAE：**1.500 → 1.275pp**；Q8与Q9支持及定义不同，单独报告。

Q9主中心是“个人十档拟合密度均值→跨人设计加权中位数”，再对月/遍等权计MAE，不是个人密度中位数，也不混入Q8或未来实际CPI。

逐月中心MAE／W1，顺序为Qwen→V3.2：

- 2020-09：0.464→0.384／0.935→0.556。
- 2021-09：1.536→0.612／2.907→1.734。
- 2022-06：0.238→0.095／2.953→1.672。
- 2025-03：0.929→0.305／3.344→1.606。

W1差−1.142pp，按人聚类、固定四个月的95%区间为[−1.424,−0.513]。中心MAE差−0.443pp，区间[−0.708,+0.012]仍跨0；点值改善明显，不等于已证明中心稳定改善。两次生成的方向一致；原始概率均合法的364个人月上，W1仍2.658→1.463、MAE仍0.893→0.420。

**对照抄的优势仍依赖时期。**去掉2022-06，V3.2中心MAE0.433，照抄0.439，差约0.005pp；2021-09和2025-03中心仍不及照抄。不能因为全四期平均0.349就重演“已稳定胜过基线”的判断。

## 4. 改善来自哪些结构

上期预期≥8%的96个人月，真人本期组均值**11.825%**，Qwen为**7.470%**，V3.2为**11.514%**。上期4—8%组，真人5.613%，Qwen5.192%，V3.2为5.611%。这与更好保留私人既有信念、减少共同背景对高预期人群的压缩一致，但没有单独识别模型内部因果机制。

低于2%的先验组仍有代价：真人0.958%，Qwen1.090%，V3.2为0.247%，组均值反而更偏低。对真实变化较大的个人，模型保持不变的加权比例由38.9%升至51.5%（“不变”按±0.5pp），表明更强惯性也可能漏掉需要更新的人。不是所有条件指标的帕累托改进。

概率表达也更接近：通缩各档全填0的加权人数占比从28.3%升至49.6%，真人56.7%；个人内部密度IQR均值由4.25增至4.70pp，真人6.37pp。后一项表示本人不确定性，与跨人IQR不同。

两次生成间个人Q9平均绝对差为Qwen0.689、V3.2为0.633pp，相关0.905→0.933；人内生成方差约1.229→1.260pp²，没有相应大幅扩大。这与较稳定的人际差异增长一致，不能把两遍描述性分解当精确随机效应模型。
