# V3.2新闻数量与主题分配：结果和下一步

2026-10-22。已完成全部获批的3658次新增请求及评价。图文入口：[新闻分配验证](news_matching_results/index.html)；准备前锁定的[方案](news_matching_plan_20261022.md)保留原样。

## 1. 这轮做了什么

比较固定8篇、随机3/8/20篇、按人口相关概率分配数量、同随机数量但均匀抽取主题。除此之外，每个家庭的人口信息、价格/食品采购角色、过去信念、政策、问卷和模型参数完全相同。

采用八个已运行V3.2的原始人群：2020-09、2021-09、2022-06、2025-03各96人，2025-04/06/08/10各192人；共1152个人月，各两遍。四组9216个比较位置，经精确复用旧答/相同提示后仅新增3658次API请求。该复用会产生共享回答，不能当9216次不同生成或更多真实家庭。

模型固定OpenRouter→SiliconFlow FP8的DeepSeek V3.2，温度0.5、关闭思考、JSON、最多1024输出token。32次技术检查全部通过后最多16并发。各月与各遍等权；月内使用设计权重。

- **固定8篇：**Q9中心MAE **0.231**，RMSE0.305，跨人W1 **1.200**，变化W1 2.008，跨人IQR4.381。
- **随机新闻量：**MAE **0.205**，RMSE0.258，W1 **1.200**，变化W1 1.964，IQR4.316。
- **人口匹配数量：**MAE **0.235**，RMSE0.304，W1 **1.169**，变化W1 1.985，IQR4.358。
- **随机量＋均匀主题：**MAE **0.199**，RMSE0.252，W1 **1.211**，变化W1 1.955，IQR4.156。

单位为百分点。Q9中心是每人十档拟合密度均值的跨人加权中位数，不是Q8，也不是官方全国headline。本轮不是最终宏观加权组合；没有按本轮目标拟合最优组合权重。

**积极发现：**在这八期固定人群口径下，V3.2四种输入的中心误差都低于照抄；随机量还使个人MAE由3.116降至2.991、变化W1由2.008降至1.964。应记录这些进步。

## 3. 如何区分工作采纳与分布验证

### 数量随机化：中心的收益对支持和生成遍数敏感

随机量相对固定8篇，固定人群平均MAE下降0.026pp，约11%。但第一遍改善0.054pp，第二遍反而增加0.002pp；W1两遍差分别+0.058和−0.057pp。它不是稳定的微观分布改善。

**直接比较随机量与固定8篇时，优先看这两组两遍都有可用回答的1116个人月：**MAE **0.273→0.260**，RMSE **0.338→0.309**，个人MAE **3.107→2.986**，变化W1 **2.005→1.964**，跨人W1 **1.206→1.208**。中心与个人误差仍有小幅收益，W1接近不变。这些数都已在原聚合缓存中，本次未重新计算或筛选样本。

四组和两遍都完整时剩1106个人月，固定8篇/随机量MAE为0.262/0.286，排序反转。但这是额外排除另外两组缺失家庭的子样本，只作缺失敏感性检查；此前将它作为否定两组直接收益的主要理由过于保守。该子样本上的95%区间仍同时容许改善和变差，不能当作无收益的证明。

**2026-10-22取舍更新：**随机数量的收益尚不足以宣称稳定改善微观结构，但可作为后续工作配置。主口径中心MAE约降11%，个人误差和变化W1也下降，跨人W1仅差+0.00022pp，不能因这个几乎为零的差值自动否决。原预登记的分布筛选仍记未通过，工作采纳是另行、透明的工程取舍，不事后改门槛。限制保留：只有一个分配种子，第二遍中心近乎持平，近期2025四期MAE 0.108→0.124，不能称全面或稳定改善。

### 人口数量匹配：小幅W1收益主要由一个月份支持

人口匹配比随机的W1平均低0.032pp，两遍方向均改善，但只有4/8个月不增；删除2025-04后，差转为+0.006pp。实际共同支持的W1差区间约[−0.090,+0.064]pp。

不能说人口与财经关注无关。该结果只限制当前“外部六档经济新闻兴趣→四类人口代理→3/8/20名额”的具体合成规则。来源测的是一般经济兴趣，不是本人阅读篇数；先前外部留出预测增益也较弱。

### 主题相关性：目前没有删除它的证据

相同随机数量下改为均匀主题，MAE平均少0.007pp，W1多0.011pp，IQR少0.159pp；新2025四个月的W1均变差。实际共同支持的W1差区间约[−0.024,+0.062]pp。

这些变化不足以断言相关抽取已被证明有效，但不支持为了0.007pp的点估计收益取消当前规则。未运行的“人口数量＋均匀主题”不能把两项最优数字直接拼起来。

Q8点预期须另看：四组群体中位数MAE约1.03—1.11pp，仍高于相同Q8支持的照抄上期0.50pp；不能将Q9中心的进展推广为所有回答都优于基线。

三项对照均未满足原开发筛选。不因结果改变名额、月份、种子或成功指标，也不把描述性区间当跨时间的因果证据。

## 4. 更具体的机制线索：差距集中在同类旧信念者内部

四种新闻设计对不同旧信念组的平均回答改动很小：

- 上期≥8%的组，真人平均从14.45降到11.63；固定8篇降到12.42，随机量12.39、人口量12.42、均匀主题12.30。
- 上期＜2%的组，真人从−1.60升到0.78；四种模型平均仍约−0.12至−0.08。

在本轮V3.2中，这两端组平均更新反而比真人不足，不能机械沿用旧Flash“把个人信念过度拉向公共中心”的解释。模型、条件和时期均须区分。

补做一项**事后描述诊断，不进入筛选或校准**：沿既有`advisor_diagnostics.variance_parts`，按上期四档分组、每月每遍使用相同设计权重分解：

`总方差 = 上期预期组之间的方差 + 每组内部方差的加权平均`。

- 真人：总方差50.08 = 组间16.87＋组内33.21。
- 固定8篇：33.00 = 组间21.18＋组内11.81。
- 随机数量：33.32 = 组间21.17＋组内12.16。
- 人口数量：33.86 = 组间21.36＋组内12.50。

单位pp²；先月内分解再对八月/两遍平均，不是将重复回答当更多家庭。聚合证据：[方差补充](news_matching_results/prior_variance_supplement.json)。

**含义：**模型在四类旧信念组之间并不缺差异，甚至比真人更分开；主要缺口在同一档内部。新闻数量分配让组内方差只增加约0.3—0.7pp²，远小于约21pp²的差距。这有助于解释为什么平均中位数可改善，微观结构却几乎不动。

该分解不识别具体缺失变量。宽的旧信念档内部还有精确旧值、历史轨迹、人口和个人冲击差异，不能把所有组内方差都称为“当月随机冲击”，也不能靠随意加噪声补足。
