# 给Kimi：新闻之外的并行任务

目的：复用已交付的全时段coverage、三个P/E样例与既有分层分析，补齐连续运行依赖；不新开一套人口模型或统计框架。当前主模型已定V3.2，Codex负责最终配置、模型运行、跨月状态接线及评价/宏观组合。Kimi负责以下数据与规则交付，最终冻结由Codex整合。日程只见[ROADMAP](../../ROADMAP.md)。

## 优先级1：完整人群与新入组资料，从样例变成逐月可用

这是比新增人口回归更直接的运行依赖，沿[kimi_data_contract_v2](kimi_data_contract_v2.md)，不要重做已完成的tenure核查或样例验收。

- 为每月交完整候选框架、稳定匿名ID、真实新入组/连续回访/间断/左边界/未知；另列是否新进Core，两个概念分开。
- 对已有合成起始信念方法交可复用规则与逐人来源：供体严格早于目标月、匹配字段/回退、供体池数、种子、Q8/Q9整对。不能读本人本期答案选供体，也不能称供体值为本人真实上月回答。
- 近期无微观段交人口快照及各字段来源/公开可得性，模拟上期信念留待Codex运行后回填。不能把同一2025-10资料自动认定在所有近期截止点已公开；A回顾可用与严格B用途分开标记。
- 先满足最后新闻试验候选2020-09、2022-06、2024-10、2025-05/07/09及连续验收2025-05至07，再继续全量；若缺口影响时点，先明确缺文件，不虚构ready。

交付：复用原八类文件的逐月物化目录、coverage更新版及短README。保留旧件，新版区分“源已下载/输入可组装/已组装/严格时点合格”。无需调用Sim API。

## 优先级2：网格覆盖与全量抽样建议

已有[六格草案](../20261019_advisor_followup/stratification_draft.md)可直接续做：三档学历×在职/未在职，未知单独列。未在职内部仍保留失业、退休、家务等原始状态，不能当同一经济身份。六格是候选，尚非用户冻结的最优划分。

先做支持，不再用模型误差选择“哪个格最好”：

1. 每月完整框架输出每格N、调查加权占比和ESS；另外检查年龄/收入/地区及新老参与比例。无微观近期段标合成框架，不称真实全调查分布。
2. 基于每月512个不同Core的准备建议，给最低覆盖＋余量按人口质量分配的具体名额、缺格/极小格回退；最低数有理由，不机械复用旧192人的12人下限。
3. 保留现有年龄×收入抽样的支持汇总作参照，但不再同时研发多个新网格；说明六格改善了哪些覆盖、牺牲哪些精度。
4. 提供稳定抽样方案及其可计算纳入概率，记录框架N、抽中n、π与原调查权重/π；联合跨月选择如不能保持简单π，不套用格内SRS公式。保持个人匿名ID，区分调查轮换与计算子样本的进出。
5. 不把每格压成一个代表人，不把Normal复制数算独立Core。未知与稀疏明确展示，不强行求每格精确效应。

交付：`population_grid_support.json`、`core_allocation_proposal.json`及简明说明，可放Kimi的新输出目录。先交规则/抽样摘要供整合，不改原真实实验的人口、权重或冻结manifest。最后新闻机制比较仍保持同人抽样；只有最终全量协议确定后才启用新的抽样设计，不能把换人群与换新闻同时当纯机制效果。

## 优先级3：月份波动/经济阶段标签与真值表

需要分清两类标签：

### A. 事后评价标签：居民预期实际变化多大

使用同一版本的官方一年期SCE全国目标序列，逐月列本期、上期、带符号变化及绝对变化。可分小/中/大变化、上升/下降；阈值先按固定参考期规则确定，再沿用全时段，不按模型胜负调阈值或挑“冲击月”。Q8和Q9目标如分别分组，series_id与含义分开，不能混入未来实际CPI当SCE真值。

这些标签是解释模型误差和持续性基线何时失效的评价信息，可以用当期真值；**绝不能作为同月Agent输入、新闻配给或组合权重的事前选择开关**。所有月份都保留。单组只有少数月份时明确支持不足，不夸大显著性。

### B. 截止时点可知的环境标签：当时出现什么变化

用已有首发资料，记录可得的CPI水平/近期加速减速、食品/能源冲击、政策/关税事件、异常发布/停摆。每项带reference_period/published_at/vintage/as_of；不以事后SCE涨跌倒推“居民当时一定感到冲击”。如果后续需要按环境调整机制，只能采用这一类可得信息，并另行预登记。

交付：`month_regimes.csv`和`regime_definition.json`，明确两类用途、阈值参考期、系列/版本/获取时间与缺失。先做描述和事件出处，不重新估计一整套模型。与现有全国基线/真值缓存保持同源；Codex再将模型结果按这些固定标签接入统一面板。

## 有余力再做：来源与最终包清单补齐

复用已有sources/manifest，汇总每类输入的许可/发布范围、历史版本证据、去标识与是否可随研究包发布；不能核实的标未知，未知历史版本不能冒充严格事前合格。不逐篇新闻重查许可、不再做一次全量数据审计，不碰已经冻结的旧运行。

## 文件边界与交付方式

- 新实现沿项目study模块与轻入口；新输出用独立run_id，工作说明放本workstream。不要把P/E/真值/研究报告再次并到一个脚本。
- 不修改Codex的模型/运行队列/计分器/评价口径/组合器、旧冻结运行、公共决策和配置文件；接口变化在README列明后整合，避免双方同时维护。
- 每包只需索引、配置、关键汇总、必要离线检查与已知缺口，不要求长报告或重复模型调用。新增取数/打标若超出当前明确授权范围，仍需先报范围/预算；本文不是新增付费许可。
- 完成哪个包先交哪个，不等所有任务齐再同步；主要阻塞先报，避免覆盖完成状态。Codex只作接口和关键读数检查，不重新复算整套历史研究。
