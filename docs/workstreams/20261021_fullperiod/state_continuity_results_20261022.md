# 个人信念三月接续：结果与解释

2026-10-22完成。[图文阅读页](state_continuity_results_v2/index.html) · [运行卡](state_continuity_run_card_20261022.md)

## 一句话结论

**自主接续可以运行，但每月接自己的回答会进一步压缩个人差异。总体中位数接近，不能替代微观结构验证。**本轮不把自主链宣布为已验证的B线，也不据此重启提示词搜索。

## 本轮研究的环节与判断边界

研究问题是：不给模型每月补充真人最新的历史回答，能否持续模拟同一个居民？它检查P中动态信念与回答机制f之间的连接；E、当月画像和问卷保持相同。三个调查月每次都回答未来12个月预期，与预测三个月的实际CPI不同。

对照同时替换历史来源、历史摘要和相关的信息先后标签，检验的是整套接续方法。它不是对真人的随机干预，没有识别真实居民的心理更新系数。新入组者的分组差距也不能直接归咎于初始化算法，因为本轮没有比较不同初始化方案。

IQR变小本身不一定错误，真人分歧也随月变化。主要判断来自同一个月的真人与参照组：自主链的W1、个人误差和排序同步变差。这里是个人预期中心的跨人分布，不能等同每个人十档概率的不确定性。

对于没有本人历史的新入组者，应优先评价同类群体的分布和总体水平。合成起点不是对其真实信念的直接测量，逐人精确命中不是与有真实上期回答者完全对等的信息条件。两遍生成也不增加真人数量或独立月份。

## 设计与实际执行

2025年5/6/7月各96人、288个人月、120名不同受访者，71人三个月均入选。每月读取此前真人历史，与初始化后只读取自己上次模拟回答比较；两组P/E和问卷相同，各生成两遍。首次进入本次模拟与首次参加SCE分别标注，新入组用严格更早供体的合成起点。

共享初始化后912次唯一请求、1152逻辑位置。原段672次因连续连接错误停止，用户call_fa8e9f14a82b4a93b51ee8da188518f3明确批准只补240个未发送位置；续段64并发，旧5次失败不重发。合并API报告$0.608667，含未知计费失败保守$0.624385/$5，两段实际调用时间合计326.7秒；原段峰值128、续段峰值64，0自动重试/供应商回退。不是整个开发用时。

模型为OpenRouter→固定SiliconFlow FP8的DeepSeek V3.2，温度0.5、关闭思考、JSON、最多1024输出token。336条递推依赖逐条匹配前次输出，912唯一请求与两段不重叠校验通过。用户的原授权为call_71602b921cfc416b871de5fe52a858ed；所有原账本和源码快照保留。

## 主要读数

主口径用真实调查权重/抽样入选概率，在月内计算后对三个月、两遍等权。Q9为个人十档密度均值的跨人中位数，独立于Q8。真人Q9可计算281个人月，Q8为288；失败明确保留该组自己的输入状态，不伪装新回答。

- **Q9中心MAE：**真人历史组0.4206 → 自主链0.4040pp；RMSE 0.5147 → 0.5086pp。幅度很小，第一遍MAE改善0.0379pp、第二遍反而增加0.0048pp，不能称稳定的中心收益。
- **跨人W1：**1.5999 → 2.0608pp，两个生成重复均变差。
- **个人密度均值MAE：**3.1880 → 3.4234pp；个人秩相关约0.527 → 0.418。
- **跨人IQR：**3.2187 → 2.5561pp，同人群真人5.1141pp；两种模型都低估差异，自主链更明显。
- **变化W1：**1.3987 → 1.4846pp；此项仅在有真实相邻上月Q9者中计算。
- **Q8中心MAE：**0.8000 → 0.7167pp，但Q8个人MAE8.3909 → 8.4296pp，跨人W1也从6.7728升至7.2658pp。不能只取中心数字宣布全面改善。

实际可用回答的两组、两遍共同人群为275个Q9个人月；对应中心MAE0.4051 → 0.3612、W1 1.6796 → 2.0534。微观退步方向与主口径一致，不能用各口径最低值拼成绩。

## “误差累积”具体表现在哪里

5月两组起点共享，表现必然相同。6月两组中心MAE为0.3597/0.3241，7月0.0982/0.0841；没有观察到中心误差逐月爆炸。

问题在相对分布差距：自主链与真人历史组的W1差，5月为0，6月+0.5391，7月+0.8433pp。两组W1绝对值都下降，不能把它说成所有误差都在逐月增加。

连续三月入选的71人也有差距：自主链IQR 3.7232 → 2.9850 → 2.4906，真人历史组3.7232 → 3.3292 → 3.9016。各月题目有效性不同，进一步限制三个月Q9始终有效的同一批68人后，自主IQR仍为3.7232 → 3.0468 → 2.4906。这个事后支持敏感性说明：收缩不只是换人或无效答案造成；它不是新的预登记机制检验。

一种与证据相容的解释是，每轮回答都向共同信息暗示的水平收缩；把这份已收缩的回答交给下一轮，会反复施加收缩。真人仍有模型没有充分模拟的个人经历、记忆和独立判断。这里只是解释假设，没有识别心理更新系数，也不能据IQR差直接校准个人噪声。

## 新入组者是另一项具体缺口

相邻月回访者子样本236个人月，真人历史组中心MAE仅0.0938pp；完整新老混合人群为0.4206pp。不同人群的误差差额不能当可加的“贡献率”，但足以提醒：此前回访者的好成绩不能直接推广到全体居民。

真实新入组者仅16/13/5人。5月真人新入组者中位数约10%，模型约3.58%；6月两者约3.02%/3.14%；7月约7.35%/3.54%。新入组者并非每月都偏高，7月尤其稀疏。其平均跨人IQR真人约9.18pp、模型约2.00pp，显示初始化加模型回答的组合仍难保留宽分布。

5月、6月、7月分配的合成起始信念中位数约4.82%、8.37%、4.37%，模型均落到约3%—3.6%。这说明问题不能仅归为供体起点太低；模型如何吸收起点、供体的时期/人群匹配和缺少本人经历都可能有关，当前对照无法分清各自贡献。

## 基线与边界

- 280个“可计算旧信念”共同个人月：真人历史/自主链/保留旧信念的中心MAE分别0.4206/0.4087/0.6651pp；W1分别1.6029/2.0698/1.1392pp。模型中心更接近，旧信念分布更接近，不能只选一种指标叙述。
- 仅限真正有相邻上月实答的234个Q9个人月：中心MAE约0.0938/0.0848/0.5632pp，W1约1.1751/1.6839/1.2993pp。该支持与上面的新老混合群体不同，不能把这两个基线数字混用。
- 这不是全国官方SCE的误差。年龄等当期画像采用A历史重建条件，E截止沿月中规则；训练知识风险未消失。短链能揭示漂移，不能建立长期B线预测有效性。
- 三个月、120人、两遍生成；月份固定，重复生成不增加人口样本。没有报告时间泛化显著性或用结果重新配供体。
