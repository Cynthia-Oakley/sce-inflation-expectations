# 新入组者初始化与主线剩余工作

更新：2026-10-22。按用户最新安排：**先完成全时段正常历史重建和未来预测；自主信念递推后置为扩展、讨论或展望，不以递推W1达标作为主线前置门槛。**本页不授权新API调用。

## 1. 没有本人历史，当前怎么模拟？

下面先说明2025年5/6/7月已执行实验的旧方案。**新的近期供体方案现已实现并完成离线检查，见2A—2C；旧批次输入不回改，全量尚未接入。**

1. 先区分真实首次参加SCE、间断回访、仅首次进入本项目模拟，以及数据左边界导致的“观察不到历史”。这些情况不都等于新人。
2. 有本人过去记录时优先使用本人最近合法字段。Q8/Q9独立检查；缺一项不删人，也不抹掉另一项有效本人信息。
3. 没有本人历史时，从目标月之前的首次受访者中选择合格供体。已有匹配顺序为年龄×学历×收入；不足时依次放宽为年龄×收入、年龄、总体池，并记录使用了哪一级。
4. 用固定随机种子抽取一份真实存在的联合Q8点预期与Q9十档概率；两项均缺时保留整对，避免给所有新人统一均值，也避免独立抽两个不相容的回答。合法性未通过的供体按过去合格池补足。
5. 提示明确写作“分配的合成起始信念”，注明来源时期，不称本人上个月真的这样回答；没有本人的历史均值/次数时不编造。其余人口、新闻、价格和问卷沿主配置。

相似人口供体提供的是**同类人的可能信念**，不是对该受访者本人真实信念的观测。新人的主要验证目标应包括群体水平与条件分布，不仅是逐人的预测误差。

实现位置：`scripts/build_sce_fullperiod_sample_data.py`的build_donor_pool/draw_donor，三月合法性/分字段处理为`studies/sce_inflation_expectations/experiments/state_continuity_inputs.py`的resolve_person/draw_legal_donor。现代码不在本次优先级调整中修改，旧运行不重跑。

## 2. 哪些细节还没解决？

- **供体时期：**现有规则保证早于目标月，但默认可在较长历史池中选人，尚未充分约束距离目标月多远、是否处于相近通胀环境。不能把“早于本期”当成“适合本期”。
- **匹配支持与代表性：**检查三项匹配的候选数量、回退比例、供体重复使用及调查权重处理。人口网格用于抽样覆盖，供体匹配用于生成初始信念，两者分别登记。
- **分布是否被保留：**过去供体、分配后的合成起点、模型最终回答分别比较。当前新人差距无法只归因于供体算法，因为模型还可能压缩输入差异。
- **验证规则：**时间窗口、回退和分组在下一次真实生成前固定；不按目标月个人答案选供体，不用新人本期中位数反向调起点。已有三个月只作开发诊断。

这些先做零API检查；最低要求是来源、合法性、支持和评价清楚，不要求先把新人微观误差或递推W1优化到理想水平才启动主运行。

## 2A. 供体近期性与上期总体一致性：离线实现已完成

用户提出的方向合理：合成的是目标月之前的起始信念，供体时间应尽量近，并检查合成后是否仍反映最近的总体信念。**新实现为`population/entry_initialization.py`，2026-10-22零API预检完成；它不改旧初始化器，不表示全量协议或严格B输入已冻结。**

### 时间与来源

- A离线实现优先上月，按年龄×学历×收入→年龄×收入→年龄→总体放宽匹配；要求至少5个候选且供体有效样本量至少3。上月全部层级都不足时扩展至最近3个月，仍不足则报缺口，不再自动借更早年份。保护值随新运行卡登记，不按本期误差调整。
- 本人近3个月合法实答分字段保留原值/原日期；超过3个月的实答保留为较旧记忆，近期起点另分配并明确标为合成，不冒充本人上月作答。真实新人与回访缺失者分用历史新人/回访供体，左边界身份不明另标。该新规则仍待接全量；旧批次不改。
- 严格未来预测受微观发布滞后限制，不能假设有上月微观。只能用截止前最新公开的微观保留人口/信念差异，再结合最近已公开总体构造近期合成起点；需要记录来源年龄和合成更新，不能冒充近期实答。合成回访者和合成新人分池处理。

### 约束的对象与边界

目标是合成后的**上期起始信念**在可观测总体水平上，与可比的上期真实总体大致一致；不使用目标月答案约束本期输出。Q8/Q9分别对齐各自口径。A若能取得上期全体微观，用同一冻结计分方法构造参照；B若只有已公开headline，只能约束该统计量，不能声称全分布已知。

这是软约束，不能要求当前样本投影的旧信念与上月全国调查精确相等：两期人员、权重与人群结构有变化，抽样也有误差；新入组者此前信念未被观测。少量合成位置未必足以修正其余固定真实记录造成的全部差异。

### 已实现的可执行方法

1. 固定保留的近月本人实答和评价权重，不改写真实记录；更早原记录单独保留日期，不当上月。
2. 以近期、同类人的调查权重和人口匹配得到初始供体抽取概率，保留Q8/Q9整对。
3. 仅在需要时调整合成部分的抽取概率，供体仍在各人的原匹配池中，联合Q8/Q9不变。以Q8/Q9各自的过去中位数容差[L,U]约束F(L-)≤0.5≤F(U)，允许残余违反而不强改本人实答；概率相对原概率限于1/4至4倍。此上限限制相对倾斜，不是单供体使用次数的绝对上限，复用另外报告。
4. 离线容差用上月波次均匀抽行、再按原调查权重计算中位数的250次重抽样得到；这是固定过去波次下的采样波动带，不是全国调查设计置信区间。最终六格抽样冻结后，容差应按同一抽样设计登记。候选支持不足、约束不可行或与真实记录冲突时保留缺口，不硬凑。
5. 同时输出校准前后中位数、可获得的分位数/分布指标、匹配回退、供体年龄、权重集中度；只有中位数约束时明确其不能保证方差、尾部或条件分布一致。
6. 将“直接保留校准后的起点”列为不经过LLM的基线，另与公开总体持续性比较，区分校准本身与模型新信息的贡献。校准不等于识别居民的真实更新机制。

原始调查权重缺失者保留并初始化，但不以默认1参与加权校准/统计；缺失数量与支持单列。供体权重只进入抽取概率一次，不再继承到接收者权重。校准作用于概率定义的混合分布，有限随机分配不保证每次都严格在容差内，所以另报100个分配种子的敏感性。

## 2C. 本轮零API检查结果（2026-10-22）

- **旧时期问题确实存在：**原96人输入中，5/6/7月的合成供体字段时距中位数为46/42/27个月，最远93/93/94个月。合法过去并不等于足够近期；旧结果保留，但后续不再按全历史池静默抽取。
- **近期支持通常足够：**2019-01—2025-10共82期、11,746个真实新人个人月。上月合法联合供体每期84—172人；年龄×学历×收入的候选少于5人占31.9%，放宽年龄×收入后为2.0%。这是原题合法性与数量覆盖，不等于82期都已运行完整初始化/ESS检查。
- **六个完整离线单元：**2025-05/06/07各96人及512人SRS支持检查；需合成者分别16/14/6和73/64/51，包含真实新人及少量回访缺失/过旧字段。全部从相邻上月取得供体，最小候选数5、最小供体ESS约4.63，无需扩至3个月。
- **总体无需强行校准：**六单元的原始近期概率混合均已在上期采样波动带内，优化没有追加概率倾斜。512人Q9上期参考/补齐起点为3.728/3.635、3.200/3.635、3.010/3.261%，差距0.09—0.43pp。不能把容差合格说成完全一样。
- **分布仍需另看：**512人起点对上期总体W1为0.344/0.496/0.562pp；这些是初始信念与过去总体的距离，**不是本期模型W1或拟合改善**。中位数合格不保证尾部或完整分布相同。
- **有限抽取与权重：**100个分配种子下，512人6月Q9有96%分配落入容差，其余单元100%；不是100轮模型模拟。7月512人中1人原始权重缺失，保留输入但加权统计仅511人，未填默认1。最大单供体复用5次；不是强行给新人统一均值。
- **验证：**11项定向测试覆盖时点拒绝、匹配回退、权重只用一次、字段保留、过旧记忆、联合可重复抽取、概率约束、不可行披露和缺失权重。无新API、无新模型回答；不能据此宣称新人的本期预测已变好。

## 2B. 总体、真实回访者与变化W1并列报告

- **总体本期W1：**所有本期可评价居民，比较模型和真人的本期预期分布。它不需要上月回答，因此新人加入不使指标失去数学含义；它评价全体重建，但混合初始化与更新两类难度。
- **真实回访者局部W1：**只在本人相邻上月和本期Q9均可评价者中，比较本期模型与真人分布。固定同一组人、权重和失败规则，并与照抄其真实上期比较。Q8按自身合法性独立定义。
- **变化W1：**上述有真实相邻上期者的预期变化分布；合成或较旧记录不能冒充真实上月来算真人变化。
- 新入组/间断者可单列当期W1和样本量，稀疏组仅作描述。总体W1不是各分组W1的简单加权平均，不能直接用二者差额作贡献分解。

三月缓存中已有真实相邻上月口径：Q9 234个人月，无需新API。总体281PM的W1为1.600/2.061，局部234PM为1.175/1.684（真人历史/自主链）；只在各自固定人群内比较模型，不跨人群拼接最优成绩。

## 3. 历史重建与未来预测需要分别处理

**本轮接入已完成：**正常重建的三月512样例现已沿既有提示/采购角色/E和官方引擎接通，1536工程动作、无新增LLM回答；六格设计容差、实际π/权重、保留起点基线及评价recipe落盘。推广完整月份仍取决于P/E物化，不能把接入样例当全量就绪。详[主运行接入收据与下一步](monthly_reconstruction_readiness_20261022.md)。

**A历史重建：**回访者允许使用已登记的真实历史条件；无本人历史者使用合成起点。每月正常重建不要求连续继承此前模型输出。

**未来预测：**微观资料有发布滞后，即便是真实回访者，预测时也可能拿不到其上个月个人答卷。必须按截止日筛选已公布旧微观、公开人口边际和历史信念分布，构造该目标月的合成人群及起点；宏观组合可使用截止前最后公开的SCE总体指标。

未来合成人群也要保留新入组/回访的区别：合成新人参考过去首次受访者，合成回访者参考截止前可得的同类历史状态，不能因为近期微观都不可得就把所有人当新人。资料的观测时期早于目标，不等于当时已经公开，发布时点需另外核准。

因此主线可以准备**按目标月独立构造人口与起点、生成当期回答的一步预测**，无需等待长链自主递推成功。该具体输入/初始化/封存方式仍须冻结并接入，不能把概念方案写成已实现；目标月画像、未公开个人回答或目标SCE结果都不能借来补齐。

自主连续模拟保留既有代码与三月结果，待全跨度正常重建和未来预测完成后再决定是否扩展展示。它与严格时间边界是两件事：递推后置，不取消未来预测的可得性和封存要求。
