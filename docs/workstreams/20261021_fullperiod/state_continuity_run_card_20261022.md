## 1. 目的与对照

检验模型在没有每月真人答案补充的情况下，能否保留个人差异，以及误差会不会逐月累积。

- **真人历史组：**每月使用此前可用的本人真实Q8/Q9；缺失字段用已登记的更早来源补足。
- **模拟历史组：**首次进入本次模拟时与对照同起点，以后只接自己上次模拟回答。若中间没有入选，回来时保留上次模拟状态，不用新的真人回答刷新。
- 两组的当月人口画像、新闻、价格、采购角色和其他提示相同，只改变信念来源及相应的信息先后标签。每组生成两遍；两遍不共享回答。
- 共同初始化的两个组可共享同一次回答，后续依赖分别保留。技术段只看格式，不看拟合成绩。

这是A线的短期接续诊断。人口画像采用历史重建条件，环境截止沿现有月中规则，不能称为严格事前预测。

## 2. 人群与信息

2025年5、6、7月，每月96人，共288个人月、120名不同受访者；71人三个月均入选。按交付的固定随机优先数取样，边际入选概率为96/N，评价采用真实调查权重除以该概率。最终512人六格方案不在本轮偷偷替换。

真实首次入SCE者分别16/13/5人；这与首次进入本项目模拟不同。新入组或缺失历史字段的起点来自严格更早匿名受访者的合格供体，合成来源明确标注，不冒称本人实测。

新闻采用已选定的随机3/8/20篇：每月48/28/20人，平均8篇；保留3条共同新闻与个人部分的50%均匀、50%相关抽取。数量分配不按人口变量加权。保留既有食品价格/采购角色视图。

外发仅含：去标识人口分组、合成CE支出占比/美联储信心/食品采购角色、公开历史环境、真实或合成的起始信念、随后自身模拟状态，以及由此前作答日派生的信息先后标签。**不发送原始ID、调查权重、本期真人答案、实际作答日期、Q1/Q2或第三方原始个人记录。**本地真实答案只供独立评价程序使用。

## 4. 评价口径

同时报告固定真人有效人群的运行结果，以及两组、两遍实际可用回答的共同人群。模型失败后使用输入状态的部分单独计数，不当成新回答。

主报告采用设计权重，等人权重为敏感性。Q9先用原有冻结方法从十档概率派生个人密度均值，再计算人群中位数；Q8独立评价。

- 人群中心MAE/RMSE、个人误差、跨人W1、跨月变化W1、跨人IQR。
- 分月、分遍、新入组/回访、首次进入模拟/持续/间断，以及连续三月71人。
- “保留当月可用旧状态”包含已注明的合成起点，不能称全部为照抄本人上期。真正相邻上月实答另作基线，使用独立的可计算共同人群。
- 若少数合法历史概率无法派生密度统计，保留原状态并披露相应基线覆盖，不能删除后不说明。实际7个本期Q9不可计算，Q8仍完整288个人月；这是评价支持情况，不用于改名单。
- 仅三个月，不报告时间泛化结论、不凭单个均值宣布机制成功。重点判断是否存在逐月漂移，以及下一步A线与自主递推是否需要分开运行。
