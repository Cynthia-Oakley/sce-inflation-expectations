# 个人常态的跨期检查：大偏差缩小，中心与分布未同步改善

2026-10-17。新增API调用0，未修改默认模拟配置或冻结计分器。本轮是既有十二期的事后时间顺序诊断，不是独立盲测或新的LLM回答。

## 设计

沿用共同2,284个回访者人月和两遍生成，共4,568条评价记录。历史均值严格排除上个月；没有更早有效回答的271人月回退为上月值，不删掉。其余人也不因历史短而排除。

两种时间切分：先用2020—2021四期估计，固定评价后八期；另逐年前推，用当年之前的月份估计当年的规则。系数只在训练期按个人加权MSE估计，非负、合计为1，不加截距。评价仍同时报告个人MAE/RMSE、样本中位数MAE、跨人W1与更新分布W1。

对照包括照抄上月、原Simulation、只用更早均值，以及三种训练得到的组合：上月＋历史、上月＋Sim、上月＋历史＋Sim。两遍分别评价再等权平均；不当成两倍真人样本。每月沿用设计与调查权重、月间等权。

历史使用未取整的冻结派生均值，原提示中摘要显示一位小数；因此这是历史预测信息的程序参照，不是同文字输入的提示词效果检验。仅预测个人Q9分布的均值，没有生成新的十档概率，也没有拟合新的个人密度。

## 逐年前推后八期的结果

以下目标是**同一批回访者的真实Q9个人均值及其分布**，不是官方全国首发指标。中心数字不与此前全国加权的0.220pp混用。

- 照抄上月：个人MAE **2.862**、个人RMSE **5.750**；样本中位数MAE **0.196**、跨人W1 **0.802**。
- 上月＋更早个人均值：个人MAE **2.950**、RMSE **5.258**；中位数MAE **0.494**、跨人W1 **1.168**。
- 上月＋Sim：个人MAE **3.101**、RMSE **5.364**；中位数MAE **0.256**、跨人W1 **1.729**。
- 上月＋更早均值＋Sim：个人MAE **3.043**、RMSE **5.244**；中位数MAE **0.327**、跨人W1 **1.670**。
- 原Simulation：个人MAE **3.516**、RMSE **5.986**；中位数MAE **0.431**、跨人W1 **2.556**。

相对照抄，上月＋历史的个人RMSE约下降8.6%，MAE却约增加3.1%，中心与跨人分布变差。相对上月＋Sim，再加历史使个人MAE约下降1.8%、RMSE下降2.2%、跨人W1下降3.4%，但中心误差从0.256升至0.327。早四期固定规则、后八期评价也呈现相同方向的主要取舍。所有分期完整保存，没有只挑较好的年份。

## 统计与机制解释

MSE更重视极端偏离；训练规则会把部分人拉回过去平均，从而减轻大额误差，但也可能移动整个群体的中位数。个人MAE、宏观中心和分布W1的最优规则并不相同，不能由R²增加推出这些指标必然一起改善。

同样，过去均值中的信息可能反映稳定信念，也可能反映暂时偏离后的回归或填答噪声。当前计算没有识别心理原因。更早均值还混合不同月份的经济环境和预测窗口，不等于纯粹、固定的个人性格。

这支持“历史中有可利用的信息”，但不支持把固定回归权重写成所有人的真实行为。组合后人际宽度有变化，也部分直接继承了真人过去回答的差异，不能当作LLM自主恢复了异质性。

八个测试月都是此前已看过的时期，没有足够月份支持一般化显著性结论。本轮不报告置信区间，不升级默认机制；下一项按既定顺序检查上期Q2，而非继续在这些月份调历史权重。
