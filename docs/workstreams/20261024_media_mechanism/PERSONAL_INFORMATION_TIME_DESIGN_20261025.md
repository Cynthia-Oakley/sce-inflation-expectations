# 个人信息日期：方法核实、可行性与候选设计

2026-10-25。用户指出共同月中截止不能代表全月受访者，本轮只核查事实和工程接口；0新增API，未改变旧Q3、A82、B11或交叉草稿的截止日。本页是候选设计，不是执行协议。

## 1. 调查实施与字段含义已核实

纽约联储《An Overview of the Survey of Consumer Expectations》3.2节说明：通常约在每月2、11、20日对三批受访者发邀请，回答收集到月底；日期分布有邀请和提醒后的波峰，而不是均匀分布。该说明发表于2017年，具体2021月份另外用本地实际日期验证，不假定历史邀请日程在各年逐字不变。

- [官方方法说明，3.2节](https://www.newyorkfed.org/medialibrary/media/research/epr/2017/epr_2017_survey-consumer-expectations_armantier.pdf)
- [官方公开问卷的Survey_date定义](https://www.newyorkfed.org/medialibrary/Interactives/sce/sce/downloads/data/FRBNY-SCE-Survey-Core-Module-Public-Questionnaire.pdf?sc_lang=en)：记录完成问卷的日期；跨日填写时记录完成日。它不是精确到小时的回答时刻。

本地2021-06全波1297人：339人在6月10日前完成，8人在当天，950人在之后完成（73.25%）。七期实验所选96人：28人在之前、0人在当天、68人在之后（70.83%）。因此共同6月10日截面对较晚作答者确有信息截断，同时也可能把6月10日的信息给了较早作答者。

不能由此认定2021低估主要由截止造成。需要新模拟识别误差变化；只读日期元数据能证明错位，不能测算反事实MAE。

## 2. 目前日期资料可用程度

读取现有SCE源的`date / userid / survey_date`三列，不读取当前Q8/Q9；用来源匿名ID映射连接原七期名单，不把评价层局部userid别名误当原始userid。

672份所选个人月均有完成日期，其中671份在标称月份内。2022-06有1份完成日期记为2022-07-01；原字段不改，是否时区边界未核，需单列。主配对可共同排除此记录，敏感性再比较保留原共同截止或按真实日期前一日并封顶目标月末，不能看误差后选择更有利处理。

完整机器证据：`outputs/sce_respondent_timing_readiness_20261025_v2/summary.json`。最终图与交互源：`response_timing_readiness_v3/`（图例移至图外；数据与v2一致）。各月完整源波次与所选名单的日号频率、截止前/同日/之后/跨标称月计数分别记录；原2026-10-08诊断的1297/339/8/950闭式对账通过。

## 3. 首选方向：A线按真实完成日重建信息

有真实日期时不额外随机。对每个代理设一个本地`information_cutoff`：

1. 只依据该人的完成日期，不依据本期通胀答案。
2. 因没有小时，候选主口径取完成日前一日纽约时间23:59:59；这是保守项目约定，不声称精确还原其时区/作答时刻。当天结束可另列日内边界敏感性，不用随机小时伪装精确。
3. 新闻窗口起点先保留原“上月1日”，只改变终点；不同时改成滚动30天或增加时效权重。
4. 对新闻、CPI/食品价格、其他实际送入提示的统计、政策及信心波次统一按各自发布时间筛选。只改新闻、却保留尚未公布的食品数据或政策，会留下新的时间不一致。
5. 重要新闻从该人截止前的池中重新选择，同一日的代理可共享共同3篇；不同日期不再强求同一共同新闻。四档人数及其分配、CPI权重、个性主题抽样流保持原规则。
6. 更新提示的截止说明和相对上期信息先后标签；检查本人既有信念的实际记录日不晚于本期作答日。原始实际日期留本地，外发日期/派生截止范围需在新API授权中明确。

例如6月8日完成者，候选信息终点是6月7日，不得到6月10日发布的5月CPI；6月23日完成者可得到6月22日前已公布资料，包括6月10日CPI、6月16日政策和随后新闻。仍不使用7月才公布的6月CPI。

这改善的是时间条件的真实性，不保证MAE一定下降。较早作答者的信息会减少，较晚作答者的信息会增加；净效应取决于当月冲击和模型如何理解。

## 4. 随机分布只用于日期未知者

A线已有日期，无需再合成随机日期。新代理或近期B日期未知时，优先从截止前可得的历史完成日期分布抽样，固定种子；用经验日号/批次混合分布，不默认连续均匀、正态或三批精确各占三分之一。月长、节假日和回访节奏需要明确映射；先用简单有来源的总体分布，后续再看是否需要与上期完成日期/回访状态条件化。

严格B若在某一全局日期D封存，代理的信息不能越过D。即便模拟到某人在月底才作答，也不能读取D之后真实发生的新闻。到月底持续纳入已发生资料属于滚动即时预测或回顾重建，需分开标注，不能冒称月中已经知道的预测。

“什么时候完成问卷”与“关注多少信息”是两个维度：作答日决定资料可得边界，四档新闻量决定边界内的接触广度。随机日期不能替代注意力机制。

需要新增的接线：

- 按“月份×截止日”缓存日期合格新闻池、统计发布快照、食品视图和政策，加载原档案一次，不为96人重复读整份文件。
- 对新纳入的后半月文章核查主题/警示标签覆盖。完整原档案在本地，不代表本批新增窗口的全部语义标签已经齐全；需按缺口清单决定是否补标签。
- 重渲染提示后逐项验收：发表/发布日不晚于个人截止、未公布价格不进入、SCE目标泄漏过滤保留、新闻数不变或明确报短缺、上期信念日期合法、非时间机制未变化。

不需要重写LLM引擎、W1/IQR/MAE或整个人口抽样。每个人仍只调用既定一遍/两遍，不需每天回答一遍，因此不把费用乘30。准确请求复用与预算待新提示生成后计算。

## 6. 建议最小实验与警示实验的关系

先以已采纳Q3为机制，比较原共同月中截止与个人真实日期；警示关闭，其他输入与七期名单保持。旧Q3回答复用，新日期组最多7×96×2＝1344位置（扣共同支持异常与精确重复后的新请求数另算）。仅离线改日期不能获得新回答，拟合效果仍需授权后的真实模拟。

若希望同时检验警示，构成清楚的2×2：

- 共同月中截止＋Q3：已有。
- 共同月中截止＋Q3＋警示：原X_CA草稿，924新请求。
- 个人日期＋Q3：待准备。
- 个人日期＋Q3＋警示：待准备。

先做一个时间组最省；四组齐全才能判断时间对齐是否改变警示的收益。不把新增截止和警示同时修改后，仅与旧Q3比较就把效果归因于其中一项。优先级先看七期及2021 MAE、其他期和最大误差，再辅助W1/IQR；本页不自动改变运行范围、预算或原始截止。
