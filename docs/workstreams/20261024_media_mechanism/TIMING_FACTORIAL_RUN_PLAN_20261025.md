## 研究问题与比较关系

本轮把“信息何时可得”和“可得信息中更容易接触哪些内容”分开。旧月中截面对较早作答者可能给了尚未发布资料，对较晚作答者又截掉后半月资料。个人截止取实际完成日前一日纽约时间23:59:59；这是没有小时字段时的保守操作约定，不能称精确还原真人注意到了什么。

全部组保留既有人口、先验、食品采购角色、四档4/8/16/32篇及CPI相关度1.5倍。新闻窗口起点仍为上月1日，不额外改变记忆长度。

- **O0：旧Q3原始参照。**完全复用旧Q3的实际回答，不重新生成。
- **C0：旧共同截止，修正共同新闻先后标签。**资料内容与旧Q3相同，仅修正General news的相对公开时间行。
- **C1：C0再加警示权重2倍。**与C0相比，只改变个人新闻抽取中的警示权重。
- **T0：个人日期截止，不加警示权重。**新闻、可见食品统计、政策及信心波次一起按发布时间选择。
- **T1：T0再加警示权重2倍。**在个人可得池内改变抽取概率，不把未可得新闻加进来。

主要时间对照是T0与C0；警示的额外贡献分别看T1与T0、C1与C0；C0与O0单独说明实现修复的影响。不能仅比较T1与O0就把全部变化归因于时间或警示。

警示2倍、CPI1.5倍作用于抽样中“相关加权的一半”的未归一化分数；另一半仍均匀抽取。因此它们不等于实际接触概率直接翻倍，也不是由本样本估计得到的人类因果参数。持续性标签本轮保存作内容描述，不额外新增持续性权重。

## 评价与取舍

先看同支持的Q9群体中心MAE，月份及遍次等权；同时单列2021三个样本月、其余四期、逐月偏差、最大误差、两遍和删月敏感性。2021三个样本月不是完整2021年的结果。再看W1、跨人IQR及Q8独立指标。照抄本人真实上期只能在有真实相邻记录的人群上作同支持比较，不能把它与所有人群的模型MAE混在一起。

O0与四组共同有效支持、每对实验共同支持及带照抄基线支持分别列出，避免一个组的缺失改变所有排序。原始Q9不改，合法非负概率按已登记规则比例归一化；缺键、负概率、截断、传输失败保持缺失，不按拟合成绩补答。

七期均已参与此前诊断，属于探索性机制对照。即使改善也不能称独立时间验证，更不能预先保证今晚全时间段结果达到某个MAE。选择配置时同时呈现核心收益和其他时期代价，不按每月挑选最好组拼接成绩。
