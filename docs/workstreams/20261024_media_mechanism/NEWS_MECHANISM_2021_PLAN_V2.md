# 跨时期新闻机制计划 v2：四档容量优先

2026-10-25，Kimi 负责新闻机制；Codex 负责主线报告与路线 B。本文保留四档容量优先和七个月设计的演变记录。**数量档、主警示权重与补标范围现以 `NEWS_MECHANISM_PLAN_V3.md` 为准。尚未冻结、未授权、未产生新增采集或模拟。**

## 1. R0 是什么，为什么先做它

R0 是“只修复重要新闻路由”的对照组。

旧机制把 A1 头版限制在共同三篇的随机抽签中，又不允许 A1 进入个人新闻，导致 2021-06、2022-06 的 CPI 当日重要稿件实际零曝光。R0 不改变人口、信念、价格、政策、模型或平均新闻量，只把选择规则改为：

- 共同三篇优先选择美国国内、标题直接涉及通胀的 A1 文章，并覆盖最新 CPI 发布日报道；
- 合格 A1 通胀文章也可以进入个人新闻池。

R0 不是未改动的原始基准；**A82 才是旧机制参照**。A82→R0 用来估计重要新闻路由的增量。R0 可以成为这一比较的对照，因为除文章选择规则外，其他输入保持不变。

但用户指出“容量可能限制其他机制”是成立的。因此 R0 不再作为所有后续机制的共同基准：在 R0 之后先建立四档容量组 Q0，其他改动都与 Q0 比较。

## 2. 四档容量：3 / 8 / 16 / 32

新四档采用等名额实验分配，每档 25%：

| 总新闻篇数 | 共同新闻 | 个人新闻 | 每 96 人名额 |
|---|---:|---:|---:|
| 3 | 3 | 0 | 24 |
| 8 | 3 | 5 | 24 |
| 16 | 3 | 13 | 24 |
| 32 | 3 | 29 | 24 |

平均总篇数为 **14.75**，明显高于旧 3/8/20 的 8。等名额是为了让每个剂量组都有足够的诊断样本，不声称真人的新闻接触呈四等分分布。

原 3/8/20 档保留在 R0，使 **R0→Q0** 能单独估计“容量扩大＋四档分配”的整体增量。后续各组全部使用同一四档，不再把扩容放在机制链最后。

## 4. 警示权重为什么改成 1.5

目前没有通用的“负面新闻被注意概率是正面的几倍”。不同研究测量的是不同构念：

- **新闻选择：**Trussler & Soroka（2014）的自由阅读实验中，负面/正面选择比例约 **1.24**，部分子群体约 **1.5**；样本小且是政治新闻。[论文](https://www.cpsa-acsp.ca/papers-2013/Trussler-Soroka.pdf)
- **标题点击：**Robertson 等（2023）基于 Upworthy 随机 A/B 试验，平均长度标题每多一个负面词，CTR 相对提高约 **2.3%**，不是整体两倍。[论文](https://www.nature.com/articles/s41562-023-01538-4)
- **社交分享：**Watson 等（2024）估计负面文章的分享计数约为非负面的 **1.91 倍**；这是传播放大，包含平台与转发机制，不是个体注意概率。[论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC11405697/)
- **生理注意：**Soroka 等（2019）发现负面新闻引起更强生理唤起，但不能换算成选择概率倍数。[论文](https://www.pnas.org/doi/10.1073/pnas.1908369116)
- **通胀领域：**Kmetz 等发现不利和有利通胀新闻对预期差的符号不同；Binder 等发现正向 CPI 意外后的预期响应更强。两者支持不对称性，但都没有给出注意权重倍数。[Kmetz 等](https://fraser.stlouisfed.org/files/docs/historical/frbsf/frbsf_let/frbsf_let_20221114.pdf) · [Binder 等](https://www.nber.org/papers/w34088)

因此主实验采用 **1.5**：它是透明的温和曝光代理，接近直接选择证据及其中较强子群体的上限，不声称是已估计的真人参数。**2.0 只保留为可选敏感性上界**，依据是最接近 1.91 的分享放大，不进入首批，也不写成“研究证实负面注意是两倍”。

CPI 配比的 1.5 同样是实验剂量，不是从文献估计的常数；运行前冻结，不按误差继续搜索 1.2、1.8、2.0 等参数。

## 5. 跨时期七个月

选择 2021 年 3 个月，之前和之后各 2 个月，共 7 个月：

| 时期 | 月份 | 作用 |
|---|---|---|
| 2021 之前 | 2019-05 | 疫情前低通胀常态参照 |
|  | 2020-09 | 疫情与重启阶段；已有新闻实验参照 |
| 2021 核心 | 2021-06 | 通胀加速；食品 0.7% 对总体 CPI 5.0%，信息背离大 |
|  | 2021-09 | 高通胀持续；食品 3.0% 对总体 CPI 5.3%，背离缩小 |
|  | 2021-12 | 年末高通胀与政策叙事变化 |
| 2021 之后 | 2022-06 | 通胀峰值附近 |
|  | 2023-12 | 通胀回落阶段 |

这比只看 2021-06 更能判断机制是否只在特定冲击期有效，也避免用全年平均掩盖前、中、后的差异。

这些月份均已在 A82 中被看过，因此扩大月份增强的是**机制诊断的参考价值**，不会自动变成独立时间外验证。正式结论仍标为探索性。

## 6. 现有新闻数据到底有哪些

### 已有本地 NYT 原始归档

`data/raw/nyt_archive/` 已有 **2018-12 至 2026-09** 的逐月 JSON 和元数据，共 94 个月；标签、候选池和实际提示均已接入既有实验。七个月不需要重新下载 NYT 全量数据，只需按原 `as_of` 和标签重建各组新闻流。

### 已有外部媒体小样

当前有 60 篇外部候选：

- 2021-05/06：30 篇；
- 2022-05/06：30 篇；
- Fox Business 40、Fox News 9、NYPost 11；
- 每个月各排除 1 篇 SCE 预期调查报道后，合格池为每月 29 篇。

这些只是两个小窗口的小样，不是跨时期外部新闻库。Q2 需要为另外五个窗口补 Fox；NYPost 不进入新增自动采集，已有含 NYPost 的旧包也不直接冒充 Fox-only 新配置。

### 没有的数据

目前没有可直接用于本项目的完整社交媒体/KOL 历史新闻库。Watson 仓库只有文章特征和 URL，没有标题或正文，也不能补这个缺口。

## 8. 调用规模、评价与停止规则

每月 96 人、五个新组、两遍、七个月：

`7 × 5 × 96 × 2 = 6,720 次物理调用上限`

A82 原始单次生成只作同月、同 agent_id、同权重的旧机制参照，不虚构第二个旧生成遍数。新两遍分别报告，不能当成更多独立家庭。

四档高容量会增加提示长度，旧 $8 预算帽不再适用。待七个月提示生成后，用同一价格公式给出估算成本和保守预算帽，再取得用户授权。

评价顺序：

1. signed bias：2021 低估是否收窄；
2. 全国 Q9 中心 MAE；Q8 单列；
3. 跨人 W1、IQR；
4. 按前/中/后时期、先验高低、四档新闻量和是否收到 Fox 文章分层；
5. 逐月、逐遍并列，不用总平均掩盖反转。

停止规则：

- 四档容量没有收益，不继续加更多篇数。
- 警示或 CPI 加权只增加波动，不继续搜索更强权重。
- Fox 没有增量，不扩大媒体名单或调整 25%。
- 只在少数时期有效就如实报告时期异质性，不追加参数追求全时期显著。
- 只有方向与分布代价均可接受的单一候选，才讨论后续独立验证和正式采纳。
