# 全流程框架图：文字设计稿

2026-10-27。用于作者讨论论文逻辑，并指导论文框架图和视频分镜。按作者确认已完成[框架图初版](overview_figure_v1/index.html)，提供可编辑PPT、SVG、论文PDF及PNG；本稿保留设计依据，尚未修改Kimi的论文或任何研究配置/结果，0 API。

## 1. 图与全文共同回答什么

**研究问题：在真实调查与信息条件的约束下，生成式家庭代理能否重建居民的通胀预期；这种重建在全国中心、家庭分歧和动态更新三个层面是否一致？**

研究对象是SCE一年期通胀预期答卷；实际CPI是环境信号及宏观对照变量，不是主模拟的目标答案。Q8与Q9都面向未来12个月。

全文建议沿五个问题组织：

1. **为什么做：**全国曲线接近并不充分，还要检查家庭分歧与跨期稳定性。调查提供共同问卷、人口框架和历史回答，使这些问题可被检验。
2. **为什么这样设计：**有限注意、生活价格体验与信念持续性提示，应当区分“有什么信息”“接触什么信息”和“以什么原有判断理解信息”。理论支持设计方向，具体数量和倍数由项目对照检验，不称理论估计参数。
3. **怎样变成可执行模拟：**人口抽样和先验初始化→时间筛选与差异化信息分配→统一问卷回答→统一计分与人口加权。每一个箭头对应可检查的输入或计算。
4. **证据支持到哪里：**A历史重建和B近期回顾性模拟分别评价；中心改进、人际分歧不足、组合局部有益同时成立。Normal处理规模表示，不能修复所有判断偏差。
5. **由此还能做什么：**月度自主递推检查漂移，周度发布后校准探索高频更新，下游检验观察经济用途。它们提供不同用途与边界的证据，不合成一个“总体准确率”。

论文的论证方向是“问题→理论与经验依据→机制→多层证据→适用边界与用途”。框架图主要承担机制与检验结构，结果图承担具体效果。

## 2. 一图流的主干：五个模块

工作标题：**调查约束下的家庭通胀预期模拟与跨层验证**。

### 模块一：构造家庭与原有信念（P）

回答“模拟谁、从什么判断出发”。

- 人口框架：年龄、学历、收入、数理等；54格分层抽样，小格过采样后恢复人口质量。原512人规模属于月度主任务；周度另为300户，图中不要统一标成全路径512人。
- A历史重建：当月真实框架；本人严格更早回答优先，缺历史时使用近期匿名联合供体。
- B近期模拟：按已登记可得性规则选择较早框架与匿名供体，以已公开历史全国SCE校准合成先验。不是目标月真实个人名单或真实个人上期答卷。
- 个人先验保留Q8/Q9联合信息及历史摘要，不能画成每个人都收到同一个全国数值。

**图面短标签：**“家庭画像＋既有信念”“54格／分层抽样与校准”“真实历史或合成起点”。

### 模块二：形成家庭可见的信息（E）

回答“这个家庭在作答时能看到什么”。

- 新闻、食品价格、政策等先按时间资格筛选，再按接触量、主题相关性或采购角色形成个人信息包。
- 新闻叙事与生活价格是两条并列通道。购物价格的角色匹配是已实现的操作化，不在图上宣称已证明其独立因果收益。
- 当前主机制：随机四档4/8/16/32篇，CPI相关度倍数1.5，警示权重1。篇数异质性不能画成“高学历必然多看新闻”；警示权重1表示不额外加权。
- A：实际完成日前一日纽约日末；B：合成作答日前一日与原月全局截止取较早者。B的P及先验按全局截止准备，个人日期只进一步限制E，不能画成全输入逐人严格实时认证。

**图面短标签：**“时点筛选→个人信息包”“新闻叙事／生活价格”“差异化接触”。具体时间规则和参数可放图注或正文。

### 模块三：生成问卷行为（B）

回答“家庭如何把原有判断与新信息转成答卷”。

- P和个人E共同输入DeepSeek V3.2，模型按同一问卷作答；不指定所有家庭统一的更新幅度。
- 输出分成Q8点预期、Q9十档概率两个端口。Q9概率经合法性检查，满足允许条件的总和偏差等比例归一化；异常、修复与后备显式登记。
- 官方P/E/B中的B指Behavior；个人信念是P中的状态与行为更新对象，图中不再把B另解为Belief。
- 模型版本、温度0.5、固定供应商等放小标签或图注；完整JSON、理由文本和运行容错不占主图。

**图面短标签：**“家庭代理作答”“Q8：点预期”“Q9：十档概率”。

### 模块四：转换为分布与全国指标

回答“答卷怎样回到SCE的评价尺度”。

- Q9：十档概率→冻结近似算法的连续密度→个人密度均值→跨人加权中位数。个人均值与全国中位数必须分清。
- Q8：个人点预期→跨人加权中位数，独立报告；不经过Q9密度转换。
- 跨人分布同时保留，用于A的微观结构评价。权重只进入统计和评价，不作为模型输入。
- 当前论文以直接LLM Core为主，统计扩展另报。Core经校准已能代表全人口质量；不画成“512人未覆盖其余人口，因此中位数无效”。

**图面短标签：**“概率→个人密度均值”“人口加权→全国模拟指标”“保留跨人分布”。

### 模块五：与真实调查和强基线分层比较

回答“哪里接近、哪里仍有差距”。

- 全国中心：官方首发SCE，MAE/RMSE及偏差；比较公开历史持续性，并列冻结组合和公平宏观基线。
- 微观结构：A的共同合法支持、相同计分器与权重下比较W1、跨人IQR和个人更新；跨人IQR与个人主观密度IQR分开。B及周度缺少近期真人微观真值，不画成同样通过了微观检验。
- 动态：另行实施的月度自主链与周度校准链，观察漂移、方向和月度末预定周点误差；动态两臂人口和更新制度不同，不给出单机制因果箭头。

**图面短标签：**“全国中心”“家庭分歧（A）”“动态稳定性／高频信号”。

## 3. 支路：保留位置，避免误接成一条流水线

### 统计扩展支路

从Core答卷引出“Core＋Normal：格内经验分布＋邻格收缩，τ=8”，接回相应加权统计端；保留“Core原始”与“扩展后”两种结果。A恢复实际调查规模，B采用约定1300代理。它不新增独立LLM判断，月度和周度链未接Normal。

### 输出组合支路

从“全国模拟指标”与“已公开历史SCE”各引一条线，形成“冻结凸组合”；再送评价。原始模拟直接进入评价的通道仍保留。历史全国值还可进入B合成起点及周度发布后校准，这些用途应分别标记，不是同一操作。

### 时间更新支路

用小型插图说明两种已实现制度：月度自主链将自身模拟状态传入下月；周度链在公开SCE发布之间传状态，发布后重校准。常规A/B主运行不能一律画成连续递推。若半页版过密，此支路移为视频第二张展开图，主图只留“月度／周度拓展”。

### 下游用途支路

从月度指标引向“同结构经济预测：信贷等”，注明完整多结局比较。该箭头不从周度曲线发出；不在主方法图写胜出百分比。

## 4. 三条贯穿约束怎样入图

1. **理论与数据依据：**顶部细带放“有限注意／生活价格体验／信念持续性”；网格旁的小标签放“候选维度与冗余检查”。不用将理论画成已识别的因果模块。
2. **真值隔离：**目标期SCE答卷与全国真值单独进入评价区；只有已公开历史值可进入合格的初始化和组合通道。相邻时间的两个SCE箱必须分别写“历史公开值”和“目标期真值”。
3. **可追溯：**底部一行“冻结配置·种子·输入时点·原始回包／修复·费用·复算入口”。这条带表示工程记录，不意味着全文或所有微观数据可公开分发。

箭头语义需统一：实线表示数据/计算依赖；虚线回环仅表示适用动态实验的状态传递；外围虚框表示可选统计处理或探索拓展。不同类型同时用文字或线型区分，避免只靠颜色。

## 5. 半页图与视频怎样共用

“半页”先按**跨正文宽、约占半页高度**理解；如果最终双栏排版，用跨双栏宽度。不是先把完整框架缩成半栏小图。最终尺寸以实际PDF可读性为准。

- 论文版：中间横向五模块；P/E可上下排后汇入模型；顶部理论细带、下部简短验证/支路。最多两项主要可选支路完整展开，其余以“动态与用途拓展”小框或图注交代。Q9十档边界、Beta分支、τ公式、所有实验和结果数字移正文/专图。
- 视频版：复用同一组矢量对象，先展示总览，再依次放大“家庭与先验→信息包→作答与统计→验证”，最后展开周度/下游。缩放与分步出现由PPT或剪辑完成，标签保持与论文一致。
- 优先腾出或合并现稿第4页的既有信息路径示意；全流程图承接其中两条信息通道。真实Q9示例图继续解释概率与密度，避免再增加一张内容重复的大图。论文页数是否满足需后续渲染验证，当前不直接插页。

## 6. 制作方式建议

**最终母版采用可编辑矢量，优先PPT形状/连接线，或用SVG程序绘制。**理由是模块、箭头、术语与数字后续仍需校对；编辑对象可以复用为视频的逐步展开。

生成图片如需使用，可用于探索构图或视觉意象，再按确认的文字结构重建正式矢量图。本任务先交文字稿，不调用图片生成服务，不决定具体图像模型版本。无论制作工具为何，学术信息和依赖关系由本稿与冻结配置约束。

图内以流程方框、少量简单图标、概率柱形/密度曲线示意为主；蓝/橙/灰黑兼顾对比，避免复杂装饰。示意曲线需注明示意；若放真实答卷只能用已获准匿名示例。
