## 两项事实边界

**采购责任与购买频率不同。**冻结的主提示按采购责任提供食品细分类价格；CE Diary购买天数的频率描述曾进入开发期实验，但未纳入当前A T0主提示。图内明确“购买频率：开发期已检验，主配置未采用”，不能画成新增的主输入。

**已准备的宏观资料不等于全部进入最终提示。**食品CPI总项/分项在主提示中；完整的总体CPI、能源、就业和汽油数表在采购价格对照的共同底座中移除。新闻本身仍可能包含这些经济消息，宏观序列也用于其他统计对照。图的资料范围说明保留这一区别，不把“CPI相关度1.5倍新闻抽样”混称为数值CPI乘1.5。

核对依据：`procurement_price_views.py`的`transform_prompt`、`behavior_prompt_blocks.py`的频率实验块、`full_a_personal_inputs.py`的最终信息替换，以及2019-01/2021-06/2025-10冻结提示抽查。仅公开模块出现次数和文件哈希，不包含个人提示、答卷、身份或权重。
