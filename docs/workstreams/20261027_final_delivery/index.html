SCE项目最终交付框架（讨论稿）

2026-10-27 · 面向“水上挽月”最终报告、研究包与演示视频 本稿安排论证与材料，不是最终论文正文，不改变冻结配置或已有结果。周度已完成47周，现补入完整11个月证据；按用户意见突出可用的正向发现，其余结果正文简述、研究包完整披露。未新增API调用，未修改冻结程序。

先看这一页：建议怎样讲这个项目

建议把作品定位为：以真实家庭调查为约束、以经济学机制为依据，对居民通胀预期开展总体—微观—动态验证的生成式社会模拟研究。

推荐题目：《居民通胀预期的生成式社会模拟：信息接触、信念更新与跨时期验证》。如需强调学科问题，副标题可用“基于纽约联储SCE的经验研究”。不使用“精准预测”“全面超越”“还原人类认知”等超出证据的标题。

最应让评委记住的三个问题：

  1. **同样面对物价和公共消息，为什么家庭会形成不同预期？**用既有信念、信息接触和人口异质性组织P/E/B，而不是让一个模型直接猜全国指数。
  2. **总体曲线接近时，微观行为是否也接近？**用概率问卷、同支持分布、更新行为和异常年份检验；我们发现中心拟合、个人差异与动态稳定性并不等价。
  3. **模拟在真实历史值之外增加了什么？**用持续性、相同信息时点的宏观模型、冻结组合及下游检验回答。现有证据支持有限、依赖任务的信息增量，尚未建立普遍预测优势。

整份交付应形成一条论证链：**社会科学问题 → 理论所指向的机制 → 数据中的操作化 → 有对照的实验与取舍 → 全时段检验 → 有边界的应用与复现。**实验数量和工程规模放在这条链上解释，评委才能看见这些工作解决了什么问题。

建议保留现有八页上限，重新分配篇幅。将旧稿中独立的问卷、网格、2021诊断页面压缩整合，腾出空间容纳最新B、Core＋Normal、月度递推、周度与下游研究。周度和下游属于拓展证据；无论结果正负，主报告都可以成立。

1. 从赛事标准确定内容优先级

本日重新获取赛事官网及其动态正文，正文SHA-256与10月24日记录一致。官网要求4—8页中英文PDF（含图表）、不超过5分钟的MP4、按studies格式组织的可复现实验材料及一命令入口；截止时间为2026-10-31 23:59，北京时间。未查到参考文献可排除在页数之外的例外，按全部计入8页安排。

官网五项评分及本项目对应的呈现重点：

  • **问题价值与创新，25分：**说明“居民如何形成预期”及调查微观结构为何值得模拟；明确预测居民预期与预测实际CPI的区别。
  • **方法与设计严谨性，25分：**交代P/E/B、理论依据、时点边界、合理基线、匹配/打乱及消融；展现“为什么采用、为什么没有采用”。
  • **结果与理论贡献，20分：**用真实数据支持发现，解释成功和失败的适用条件；无需把每项实验都包装为成功。
  • **复现与工程，20分且为门槛：**提供可执行study、固定来源和参数、成本账本、真值隔离与明确的复现范围。
  • **呈现和拓展，10分：**一眼看清研究问题、证据层级及可进一步使用的场景。

这不是对个别评委个人偏好的猜测。我们依据公开标准和组委会给本队的五项反馈安排材料。赛道A重视人群分布、动态变化、不同群体与时期的误差及适用边界，恰好可以承接本项目最扎实的证据。

2. 贡献应如何分层

2.1 第一层：可检验的社会模拟设计

把家庭的历史信念、人口背景、生活价格和新闻接触组织为可追踪输入；以原问卷为行为输出，再按调查口径聚合。人口网格依据回答异质性的监督分析、变量冗余和抽样支持选择；信息接触将公共可得性与个人暴露区分开。

贡献强度：这是可复用、可核验的研究设计。不要声称54格、贝叶斯扩展、历史加权组合本身是首次发明。ConsumerSim是方法参照；本项目的增量在于SCE概率答卷与真实微观数据的联合检验、时间资格与误差结构审查。

2.2 第二层：中心、分歧与更新的经验边界

全时段揭示了小样本良好拟合未必外推到2021等异常时期；改善新闻与信息日期配置可以降低部分中心误差，但未充分恢复同类家庭内部的分歧。官方计分桥接表明，主要失败不能简单归咎于密度算法差异。自主递推又揭示了路径平滑与误差漂移可以同时发生。

贡献强度：这些是本模型、数据和配置下的经验发现，给生成式社会模拟提出更严格的评价要求；不能外推成“所有LLM都如此”，也不能把模拟中的输入效应直接解释为现实中的因果机制。

2.3 第三层：有限增量与可使用的研究工具

模拟和历史SCE的组合、宏观公平对照、下游信贷回测共同检验增量用途。结果较好的窗口和结果较弱的窗口同列；周度研究检验月度调查发布之间的信息更新能力，当前不预写提前预警成功。

贡献强度：具有应用线索的模拟测量工具与研究原型。技术上可运行、局部有预测增量、现实机制得到验证，是三个不同层次，分别给证据。

3. 三项交付承担不同职责

**研究报告回答“研究问题是什么、为什么这样设计、证据支持什么”。**保留足够方法让读者判断结论是否成立。关键负向结果、时间边界和基线不能只藏在附件。

**研究包回答“这项结论从什么数据与程序得到，如何复查”。**完整实验清单、逐月逐组数值、参数敏感性、数据许可、运行日志与复算入口放在这里。它承担研究深度和工作量的可审计展示。

**视频回答“这项研究如何实际工作，最值得记住的发现是什么”。**真实演示一个安全的study流程、重算主图、解释一个收益与一个限制，不逐页朗读论文，也不假装现场重新生成数万次API回答。

三者使用同一套研究问题、配置名称、结果编号和版本。报告中的每张图都能在包内找到数据、脚本和复算范围；视频中的数字与报告完全一致。

5. 怎样把一个月的实验展示成研究判断

研究包可为所有实验建完整索引；正文只选能解释最终选择与边界的代表。每条写成“提出的假设—改变了什么—对照怎么设—观察到了什么—因此采取什么决定”。

家族一：既有信念与表达

包括本人历史/更早常态摘要、直接填写与Q8变化值、温度实验。说明状态的重要性、Q8和Q9合法性不同、生成随机性不等于真实个体异质性。旧Q8变化值局部有收益但未形成稳定整体改进，保留直接填写。不要称过去常态对应了已识别的心理参数。

家族二：认知、财务与心理匹配

包括数理标签/原题实答/文字转述、Q1/Q2、GSS心理匹配/打乱及更新波次。展示我们曾检验“增添画像能否恢复异质性”，而非只做更长提示。匹配结果不稳健，提示代理变量未恢复真实联合关系、文本影响也可能失真；不能据此否定心理因素在现实中的作用。

家族三：新闻接触与信息时间

包括固定/随机/人口关联数量、主题匹配、CPI相关度、警示权重、来源、共同/个人截止。正文选同输入可比较的代表与最终T0设计；其余在包内逐组呈现。文献支持注意力差异，4/8/16/32及1.5仍是实验参数，不是直接估计出的真实阅读次数或认知权重。

家族四：生活价格与采购角色

将CE支出、ATUS采购角色和价格暴露拆开解释，匹配与打乱用于检验身份分配是否额外有用。机制具有理论合理性但经验支持有限，保留为配置背景与限制，不能称每项输入都被独立验证有效。

家族五：模型能力、扩样与计分

同输入Qwen/V3.2对照支持模型选择；公开模型名称不保证训练污染不存在。54格抽样与权重确保人口质量的明确表示，Core＋Normal检验成本—近似误差取舍。官方计分桥接把测量偏差与模拟偏差区分开。这组是研究严谨性的重要证据。

家族六：宏观校准、动态与用途

简单组合、宏观公平对照、可观察触发器、递推、周度与下游，检验已有模拟序列能否提供新信息。宏观后处理不改个人答案；不能把组合MAE下降说成LLM的微观行为已改善，也不能把生成理由中的词频当作机制因果证据。

**建议用一张研究决策图展示工作量：**六个问题家族，每个标“进入参考配置/局部信号/暂不采用/拓展”，连接到实际证据编号。所有不同人群、模型或月份的数值只做各自配对比较，不能画成一路不断上升的伪消融阶梯。

6. 主结果的证据账本与易误读处

6.1 可以进入正文的核心事实

  • **A全期和2021：**同名单旧MAE0.317508，新Core0.298407；2021原旧0.822126，新0.577424。全期改善有限、部分年份变差；新版仍未胜过公开历史参照。来源：新版A。
  • **人口扩展：**A真实总规模98,382行，τ8后MAE0.301422；B为设定1300户/期的合成规模，MAE0.346169。A实际调查总数与B设定人数不能混称。来源：A扩展、B扩展。
  • **微观差距：**同支持W1与IQR的改善不随中心同步；相邻回访者的真实上期基线很强。来源：新版A。
  • **测量差异：**个人密度算法替换的月中位数差0.013272pp，全流程首发桥接0.026928pp，不足以解释2021失败。来源：计分核对。
  • **组合的有限增量：**A原共享截止下后34月扩展组合MAE0.184980，参照0.194118；B最新扩展组合0.143964，参照0.172727。MAE目标选择λ＝0、不同截止敏感性与区间跨零一并交代。来源：组合、公平宏观对照。
  • **月度自主链：**后10月MAE0.305751、参照0.190；2026年5—8月偏高加剧，9月有所回落，并非单调爆炸。来源：封存聚合、阅读页。
  • **周度原始增量：**完整11个月主MAE0.151581/持续性0.172727、RMSE0.188942/0.211058，冻结组合MAE0.156409；仅5/11月误差更低，9月低估0.402459pp。未经输出组合，但有公开历史值先验校准；无Normal。来源：完整周度结果。
  • **下游用途：**原始模拟替代官方SCE的信贷1/2/3月RMSE改善3.55%/8.17%/1.69%；最终组合仅3/12项改善，信贷三个期的最强简单参照仍为历史均值。来源：Kimi下游记录。

6.2 不能作为标题数字使用的结果

  • 2021下半年MAE0.1465不是2021全年；更公平月末宏观对照下同类收益显著缩小，不能写“修复异常时期预测”。
  • 0.298与0.301保留三位小数及差值0.003，不利用首位数字制造研究结论变化。
  • 原始模型与官方SCE的下游比较，不代表超过历史均值/持续性/AR，也不等于在“官方＋控制变量”之上新增模拟的增量。
  • 不把82月人口行数当宏观回归样本量；不把Normal行数、周点数、预测期重叠行数当独立观测。
  • 不把A/B并排画成同一套连续个人状态。拼接时间轴只作阅读辅助，边界、初始化和信息制度必须标清。
