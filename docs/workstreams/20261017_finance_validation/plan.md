# 家庭财务事实：跨月份验证

日期：2026-10-17（北京时间）。本页记录运行前方案；准备与干跑不产生真实API费用。具体调用需本批授权，状态见 preparation_receipt.json。

## 要回答的问题

此前四个开发月，加入家庭财务自评后，样本Q9中位数误差从0.637降至0.502个百分点，但个人误差和跨人分布没有同步改善。这轮检验这项**总体中心的局部进展能否出现在另外几个月**，不再修改财务提示，也不混入新的数理题、购买频率或更新指导。

## 如何比较

- 月份：2022-06、2023-06、2024-10、2025-09，覆盖高通胀及之后的不同阶段。它们是旧八期实验的后四个月，P/E及新闻已备齐。
- 每月48人，同一人同时进入两组，每组生成两遍，共768次请求。重复生成不是新增受访者。
- 参考组：当前共同配置，包含人口画像、合成CE支出、美联储信心、历史经济新闻和政策、本人上期Q8/Q9及更早摘要、信息发布时间标记，直接填写本期问卷。
- 财务组：在完全相同输入上，仅增加本人本期与上期Q1财务自评。逐字沿用先前financial_facts块，不增加家庭视角指导句。
- Q1问的是家庭财务状况**相较一年前**如何，不能将两期类别变化写成当月收入下降或失业事件。

## 人口与权重先固定

从各月旧实验的96人随机样本中，按High/Low数理组比例抽48人；固定种子20261017，不能按本期通胀答案、财务自评或误差筛人。分配分别为37/11、31/17、32/16、35/13，没有沿用旧24人的低组过量抽样。

评价主口径使用调查权重与两阶段抽样权重；模型与真人同样本、同权重。每月/每次生成先计算加权中位数误差，再对8个单元等权平均。等人权重只作单独敏感性结果，不在看结果后换主口径。48人的加权有效样本约30—34，不能声称全国代表性。

## 评价与判断

1. 主看Q9样本中位数MAE，检查财务组相对参考组是否下降，并逐月报告。
2. 同时看个人Q9均值MAE、跨人W1、个人变化W1、人际IQR及个人概率宽度；Q8点预期单独报告。
3. 同样本、同权重计算照抄本人上期和固定的个人历史锚基线，不再与另一时期的全国MAE拼比。
4. 中心平均误差下降且至少三个月不恶化，仅记为“总体中心的跨月筛选通过”。个人MAE或W1变差仍须标出，不能升级为全面有效。
5. 按人保留两遍和跨月记录的配对重抽样区间仅作探索。只有四个选定月份，不因有768条回答就声称对所有月份都显著。
6. 真人本期十档缺失和模型无效分开统计；共同可评分支持比较，不替换缺失/极端真人来改善结果。

## 研究边界

这四个月未参与当前Q1措辞调整，但此前已看过旧框架模拟、整体SCE关联分析，因此不能称全项目完全独立盲测。新输入准备不读取本期Q8/Q9；真值只在冻结运行之后由评价层读取。

本轮仍为路线A条件历史重建：真实当期画像/Q1和真实本人上期回答是明确的辅助条件。不是路线B事前预测，也不是模拟家庭连续运行后形成自己的先验。既有新闻、汽油和合成信心复用不自动获得严格历史版本认证。
