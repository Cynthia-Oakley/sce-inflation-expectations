## 完成了什么

2025-11—2026-09共11个月，每月512 Core＋788 Normal＝1300；总计14,300行，其中5632份实际LLM回答，8668份统计Normal。来源为`sce_recent_b_sampled_terminal_20261026_v1`，输出为`outputs/sce_recent_b_core_normal_20261026_v1/`。

1300是声明的合成人口规模。近期真实名单/人数/人口边际未知，扩展沿用旧源框架与54格及缺失画像细分信息，不能称补出了本月实际受访者。Normal不是新增独立模型证据，也不能拿其抽样答卷当同一家庭的真实连续信念。

## 怎样分配人口质量

设每格既有校准代表质量为M，抽中的Core原始来源质量为C。Core保留各自原始来源质量；Normal只承担M−C，再把全体质量统一缩放至1300。不会把放大的Core代表权重与完整Normal人口再相加一次。

新增788行按剩余质量分配，各个有剩余质量的格至少一行；行权重不要求为1。已完整抽中的格不虚构Normal。这样小格过采样的Core仍按人口质量汇总，缺失年龄/学历等保持缺失，不造完整画像。

**Core/Normal的行数比例不等于人口权重比例。**本批Core保留约58.7%—64.0%的旧框架质量，剩余由Normal承担。1300改为1200只改变行数及统一尺度，归一化后的精确CDF不因人为选的人数变化；该不变性有单元测试，不能靠改人数凑误差。

## Normal的答卷分布

直接复用A线加权经验贝叶斯式完整答卷扩展器，τ固定为8，绑定A早期LLM留出选择文件，不按B真值搜索。每格的条件分布由同格Core答卷经验分布与邻格经验先验混合，权重为格内有效样本量与τ；邻格从同一入组池、其他格中选择已知坐标匹配最多者。B近期入组类型未知，全部明确记unknown，不伪造新老身份。

未知画像坐标不作匹配证据。继承的是完整Q8＋十档Q9答卷，不能把各供体概率平均成一张标准答卷再说恢复了异质性。本方法是带设计权重的经验贝叶斯式/伪Dirichlet近似，不宣称精确复制ConsumerSim或推断了真实新人先验。

总体统计接口输出**精确后验均值的原子CDF**，保留Core质量，只对剩余质量按条件分布积分。另以固定种子20261026抽出788份Normal答卷作为人口行展示/检查；主指标不随这些随机抽签结果漂移，也不直接取1300行的未加权中位数。

## 输入隔离与产物

先核对原冻结来源、主批/补批不可改写账本，将每个Core有效字段与真实原始响应重建结果逐项匹配，再从既有评分缓存投影出仅含本批模型向量的评分表。没有打开近期真人问卷、全国目标值或重新拟合Q9密度。τ只引用既有A选参，未训练任何B系数。

每月目录包含：

- `frame_private.json`：1300个代理的分析质量和四维画像。
- `core_model_answers_private.json`：512份已核验模型答卷。
- `atoms_private.json`：精确扩展CDF的带质量完整答卷原子。
- `expanded_population_private.jsonl`：1300行人口，区分Core实际LLM和统计Normal、画像/答卷供体及固定种子抽样用途。

根目录`protocol.json`、`summary.json`、`manifest.json`绑定参数/来源/行数；`acceptance.json`为独立质量与字段来源核查。新增7项边界测试＋18项共用扩展测试通过：质量守恒、Core不重复、零剩余格不造人、unknown不填、大小缩放不改CDF、抽样可复现。11个月逐行核对Core原答、Normal完整供体与总质量，原B冻结283绑定未变。
