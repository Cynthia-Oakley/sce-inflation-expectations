# 真人与模型差距：文献机制、时期背景与下一步

核查：2026-10-18。范围为已完成的12期A条件回访者重建；本轮只读既有结果与公开资料，新增付费调用0。本文复用既有文献，再核验关键原始来源。来源、版本、成功与失败访问见[核查记录](source_notes.json)。

## 1. 当前证据要求解释什么

全12月，Q9同样本中心MAE为模型0.459、照抄上期0.239个百分点；模型个人均值的人际IQR约2.424，真人5.055；扣除月份共同水平后，对上期信念的全12月平均描述性斜率为模型0.359、真人0.598。新增8月，所有通缩档均填0的比例为模型7.0%、真人54.6%。后三者分别涉及**人际差异的保留、跨期变化、概率报告方式**，不能由一个总体均值指标替代。数字沿用[冻结结果](../20261017_reference_scaleup/results.md)及其汇总；2.424/5.055为全12月，不与新增8月IQR混用。

模型在部分2020/2021/2025月份偏低，在2022年6/12月等时期偏高，故统一上调或下调不能解决差距。增加P/E尚未稳定改善，也不能推出这些资料无用：合成字段可能没有恢复真人的联合分布，LLM也可能没有按对应机制使用它们。

## 2. 文献支持的机制，以及已有数据能检验什么

### 共同信息吸收过多，个人既有差异保留不足

Armantier等的随机信息实验发现，新信息使预期向中心收敛，修订随信号强度增大、随先验精度增大而减小。它直接支持“共享信息可能收窄分布”，但没有证明本项目收窄就是它造成的。[纽约联储原文与摘要，SR543，2013年修订](https://www.newyorkfed.org/research/staff_reports/sr543.html)。

其正文还报告，信息处理组仍有40.15%—52.83%不修订一年期点预测。这为“保持和更新并存”提供直接证据，但这里是同次调查的告知前后，不是SCE跨月不变率；消息已知、不相关、先验精确或取整都可能导致不改，不能全部归为不关注。[原文PDF第14页，§3、Table 1讨论及脚注13](https://www.newyorkfed.org/medialibrary/media/research/staff_reports/sr543.pdf)。

Carroll的新闻扩散模型、Coibion–Gorodnichenko的信息刚性框架支持吸收迟缓的候选：有些人没有获取新信息，有些人获取后仍把它当作有噪声的信号。前者可表现为少数较大更新与较多不变，后者可表现为普遍但较小的连续修订；调查取整也会制造“不变”，因此这两个指纹不能单独识别模型。[Carroll作者稿](https://www.econ2.jhu.edu/people/ccarroll/epidemiologyqje.pdf)；[CG2015官方摘要](https://www.aeaweb.org/articles?id=10.1257/aer.20110306)。本轮没有复现其估计，不能把本项目0.598当作应写入提示的心理参数。

**现有数据检验：** 在每个月内，固定上期信念分位组，比较真人和模型的更新方向、绝对幅度、不变率及跨人排序；同时用原始十档向量的完全不变与拟合均值的小变动阈值，避免把拟合误差当更新。检查高先验者是否被模型系统性拉低、低先验者是否被系统性拉高。若这种收缩在Q8与Q9都存在，更支持信念处理层面的缺口；若主要出现在Q9拟合均值，需先查概率报告与拟合。以同人两遍差异估计生成不稳定性，不能把两遍当两个人。

**尚不能识别：** 共享宏观信息是否被过度使用、本人旧状态是否被忽视、未观测私人信息是否缺失，都可产生相似收缩。当前模拟已经看过本人先验和更早摘要，不能把它当作“只由新信息形成的独立预测”，也不能根据模型减先验的相关性估计真人学习率。

### 价格经历、注意与信息学习会随环境变化

Malmendier–Nagel将长期通胀经历与信念差异联系起来；D’Acunto等使用个人购买和价格记录，发现购买频率比支出份额更贴近预期中的价格权重，且涨价和降价不对称。长期经历、实际购物暴露和上一张问卷的数字是不同对象。[MN作者2013稿](https://eml.berkeley.edu/~ulrike/Papers/InflExp_44.pdf)；[DMOW作者2020稿，摘要及引言](https://eml.berkeley.edu/~ulrike/Papers/paper_DMOW.pdf)。

Weber等跨时期随机信息实验发现，高通胀环境中受访者更了解通胀，对额外给定信息的反应较小。它支持注意随环境变化；不能由跨时期比较单独识别是主动学习、媒体供给还是二者共同变化。[NBER w31485，2024-02修订摘要](https://www.nber.org/papers/w31485)。因此，“低通胀不关注，高通胀更关注”不等于“高通胀必须有更大更新”：已经知道消息的人，对重复信息反而少改。

**现有数据检验：** 看更新和压缩是否随下节的环境阶段改变；分开记录公共总量、分类价格、个人合成暴露，而非用一个“信息多寡”分数。只有12个预选月时，这仍是描述，不宜拟合复杂阶段×人群模型再宣称稳健。

**缺口：** CE供体不是SCE本人，支出份额不是购买责任或回忆到的价格；同一收入年龄组内仍可有大量差异。没有同人价格、采购角色、知识或注意测量，无法确认缺的是体验还是吸收。已有频率、经历或心理提示的阴性结果只约束其具体实现，不否定原论文机制；继续堆标签的优先级较低。

### 问卷表达、取整与零概率可能放大Q9差距

Giustinelli–Manski–Molinari在HRS多道概率题中发现，报告精度有个人差异且跨期较稳定，尾部与中间区域的取整习惯也不同。它支持研究个人报告方式；HRS单个0—100概率题与SCE十档合计100题不同，不能直接搬用人群比例或统一5%取整规则。[作者原文，摘要、§2—4](https://molinari.economics.cornell.edu/docs/GMM_Rounding_Paper_Final.pdf)。

**现有数据检验：** 按人和月统计非零档数、5/10倍数堆积、最大一/两档的质量、所有通缩档为0，以及这些习惯在本人历史中的持续性；按数理/教育组比较，并记录足够样本和有效权重。再把Q8人际分布、Q9原始向量和Q9拟合均值/个人不确定性并列，分辨“信念都接近”与“报告得太平滑”。

**尚不能识别：** 通缩档填0可能是真正排除通缩，也可能将小概率圆成0。真人零通缩多并不等于真人平均通缩概率更低；少数有通缩尾部的人可以承载很大质量。单凭零值或稀疏档数不能恢复潜在信念，统一删小概率也可能改变个人均值和总量中心。需要同人追问或有验证的报告模型。

**已有反证约束：** 项目已经做过本人历史填法的机械映射和打乱对照，零概率/刻度更像真人，但人际IQR几乎未恢复，本人身份增量很小。故概率填法应保留为误差来源诊断，不再列为主要新改进方向。[既有映射结果](../20261013_behavior/codex_mapping_results.md)。

### 一年期滚动窗口本身会产生持续性

相邻月问的都是“未来12个月”，但窗口重叠11个月，目标仍前移了一个月。因而本期减上期既含新信息，也含窗口变化和报告噪声。不能把全部变化解释为固定目标下的贝叶斯修订；照抄基线强也不等于居民没有学习。该边界沿用[既有更新设计](../../literature/sce/belief_updating/evidence_and_design_20261015.md)。

若要估计纯信息更新，需要固定终点的重复预测，或对月度预期路径作额外、可检验的假设。现有每月一个一年期回答不足以唯一分离这些部分。

## 3. 十二期环境：按截点可见资料解释

以下分期仅帮助描述，未按误差挑月，也不新增“好月/坏月”筛选。CPI为**当时最新首发、未经季调的过去12个月同比**，是环境信息，不是未来一年SCE答案。日期为冻结E截点（纽约时间当日末）；原始SCE作答可能早于该截点，故仍需沿用既有逐人时间标签，不能声称人人当时都看到发布稿。本轮重读12份本地BLS首发PDF，并在线核对5份关键CPI与3份联储声明，哈希见JSON。

**疫情冲击与低通胀：202003、202009。**

- 202003截点03-11：最新是2020-02同比2.3%。03-03联储已因疫情风险降息；03-15的零利率决定尚未发生。可以提出疫情风险与已有价格信号分歧的假设，不能加入后来封锁、失业或降息结果来解释模型应该怎样答。[BLS首发](https://www.bls.gov/news.release/archives/cpi_03112020.htm)；[03-03联储声明](https://www.federalreserve.gov/newsevents/pressreleases/monetary20200303a.htm)。
- 202009截点09-11：最新2020-08同比1.3%；低总量通胀与个人分类价格体验可能并存。不能由低CPI推断所有家庭预期都应接近1.3%。[BLS首发](https://www.bls.gov/news.release/archives/cpi_09112020.htm)。

**通胀上行与早期转折：202103、202109、202206。**

- 202103截点03-10：最新2021-02同比1.7%，不能把随后全年的通胀上升当作已知。该月适合检查模型是否使用后见宏观叙事，而非先断定它应上调。[BLS首发](https://www.bls.gov/news.release/archives/cpi_03102021.htm)。
- 202109截点09-14：最新2021-08同比5.3%；可见的07-28联储声明仍将上升主要归为暂时因素。高当前价格信号与暂时性叙事之间存在张力。模型若偏低，可能过重采用后者，但需同事实、单一叙事干预才可验证。[BLS首发](https://www.bls.gov/news.release/archives/cpi_09142021.htm)；[联储声明](https://www.federalreserve.gov/newsevents/pressreleases/monetary20210728a.htm)。
- 202206截点06-10：最新2022-05同比8.6%，住房、汽油和食品是当月主要贡献项。不能使用07-13才发布的6月9.1%，也不能提前加入06-15政策结果。高现值不意味着家庭未来一年预期必须等于8.6%。[BLS首发](https://www.bls.gov/news.release/archives/cpi_06102022.htm)。

**从高位回落：202212、202306、202312。**

- 202212截点12-13：最新2022-11同比7.1%，较此前高位回落，但住房仍是当月主要推动项；“整体降温”和“生活价格仍涨”可以并存。12-14联储决定在截点后。[BLS首发](https://www.bls.gov/news.release/archives/cpi_12132022.htm)。
- 202306截点06-13：最新2023-05同比4.0%，能源同比下降、食品仍上涨。若模型对所有人作相近下调，需查是否忽略这种分类差异；不将后来6月数据或06-14政策结果提前。[BLS首发](https://www.bls.gov/news.release/archives/cpi_06132023.htm)。
- 202312截点12-12：最新2023-11同比3.1%，住房上涨抵消汽油下降的一部分。12-13之后的政策信息不能进入本期解释模型输入的依据。[BLS首发](https://www.bls.gov/news.release/archives/cpi_12122023.htm)。

**较近期与回落反复：202404、202410、202503、202509。**

- 202404截点04-10：最新2024-03同比3.5%，高于前月3.2%，住房与汽油合计贡献过半月度涨幅。不能把2023年以来的回落延伸成单调趋势。[BLS首发](https://www.bls.gov/news.release/archives/cpi_04102024.htm)。
- 202410截点10-10：最新2024-09同比2.4%。较低涨速不等于价格水平回到疫情前，不能从“通胀回落”直接推断生活压力消失。[BLS首发](https://www.bls.gov/news.release/archives/cpi_10102024.htm)。
- 202503截点03-12：最新2025-02同比2.8%。仅凭该数不能将本期预期变化归因于某一政策事件；需要该事件截止前文本、居民暴露与事前理解证据。[BLS首发](https://www.bls.gov/news.release/archives/cpi_03122025.htm)。
- 202509截点09-11：最新2025-08同比2.9%，较前月2.7%上升；可见的07-30联储声明称通胀仍略高、前景不确定性仍高。不能提前加入09-17政策决定。[BLS首发](https://www.bls.gov/news.release/archives/cpi_09112025.htm)；[联储声明](https://www.federalreserve.gov/newsevents/pressreleases/monetary20250730a.htm)。

这些背景只能说明哪些机制值得查，不能替12个点构造因果解释。月份共同冲击、阶段、媒体与政策叙事高度重合。冻结模型的训练历史也未独立核实；历史标签不能消除模型可能拥有的后续知识。此A重建不能升级为严格事前B预测。

## 4. 最多两项优先机制与扩样门槛

**优先一：从独立历史面板估计个体保持/更新混合，再检验公共信息吸收。** 先用现有轨迹完成上期分位组×更新方向、幅度、不变率与Q8/Q9一致性检查。已有“明确本人起点”、时间说明、U1、历史前推和差值格式试验须作为约束；不把同类措辞再包装成新机制。可新增的是从真实连续面板估计“本期保持的概率”和“发生更新时的条件幅度/方向”，保留近零、上调、下调的不同质量。先比较原始向量完全不变及不同小变动阈值，避免将报告取整识别成隐含心理状态；只用截止前的本人历史、画像与可见E预测状态，不得用本期真人是否稳定来分配模型。

这项估计需在独立开发期完成，并在未参与调整的月份冻结检验；若按人分配稳定倾向，还需足够长的同人历史、对短历史的收缩和明确回退。它改变的是个体状态/转移分布，区别于已有线性history修正、总体aggregate blend或提示语指导。只有同时改善中心、个人误差、更新分布与人际分布，才值得升级；改善一个指标时保留取舍。

若要因果检验LLM是否过度吸收公共信息，再做同P/旧状态/问卷、随机有无一条明确已发布事实的窄对照。它识别LLM信息响应；恢复真人注意分布仍需同人知识/注意/媒体接触测量。未取得这些数据时，随机暴露比例只作敏感性实验。文献未证明高注意力必然导致“过度更新”，本文不作此断言。

**优先二：先做新旧信息与价格概念的低成本消歧检查。** 从已有输入与回复查三组区分：价格水平仍高与涨速回落、过去同比/当月环比与未来12个月预期、本人上次作答前已公布与此后才公布的信息。用源数值和时间戳复核可疑句子，避免仅靠理由文本认定模型理解。若没有明确混淆证据，停止这一方向；若有，再准备只简化这些标签和去除重复事实的最小对照，保持价格事实、本人先验和官方问卷题意不变。该项首先是零API审计，未必需要大付费实验，也不将过去CPI当作应输出的未来预期。

**何时扩人数：** 当前192人已显示系统性差异，先完成零API诊断。只有某个预设群体人数/有效权重不足，或同一机制的配对效果仍被抽样波动遮住时，才定向扩人；先用现有嵌套48/96/192敏感性估计所需精度。不能用反复换seed寻找好结果。

**何时扩月份：** 当前12月均已见过结果，继续用它们调机制只能称开发。机制和主要指标固定后，扩到未参与选择/调整的连续或事先分层月份，比同12月盲目增加人数更能检验跨环境有效性。各阶段都保留，分报新时期、中心、分布和更新；若进入B，另做按截点可得资料、合成初始状态和连续递推的检验。本轮不指定未经授权的新调用人数、月份或预算。

## 5. 本轮证据边界与交接

上述归因为竞争假设，尚未识别的包括：缺失私人经历、合成供体误差、真实注意/学习、模型内部知识、问卷理解、报告习惯、生成随机性、拟合近似和回访者选择。回归残差不是“缺失心理因素”的份额；低数理/教育组差也不是该属性的因果效应。理由文本可定位可疑联想，不能当内部推理或中介的直接证据。
