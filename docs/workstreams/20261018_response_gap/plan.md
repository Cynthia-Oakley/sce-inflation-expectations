## 要回答的问题

1. 哪些月份、哪些人口组的预期水平和变化幅度偏差较大？
2. 模型是整体一起偏移，还是压缩了原本存在的个人差异？
3. 同一人在真人和模型中如何保留上期信念、如何响应新增信息？
4. 问卷理解、概率填法、输入时点是否有可核查的技术问题？
5. 哪些机制值得继续检验，现有证据是否需要扩样？

## 输入与统计约定

- 主输入：`outputs/sce_reference_validation_evaluation_20261017_v1/{summary.json,cases_private.json}`；实际输入与回复来自对应已封存的 trial/local_runs。
- 12个预选月：2020-03/09、2021-03/09、2022-06/12、2023-06/12、2024-04/10、2025-03/09。每月192名合格回访者、两遍生成。
- 复用已冻结的Q9拟合；不重新拟合，不改真值或原始结果。Q9中心为个人拟合均值的加权中位数；Q8单列。
- 保留主评价的调查权重÷入样概率，逐月归一化、月份等权；生成重复不算新增受访者。
- 主指标按两遍分别计算再平均；两遍均值仅用于个人层面的探索性回归与配对图。
- 按年龄、教育、收入、数理、地区、住房、就业分组；每月单组少于10人只报告人数，不报告误差。有效样本量一并披露。
- 真人更新的稳定/上调/下调分组仅用于事后诊断，禁止据此挑选模型、设置未来策略。阈值做预先列明的敏感性检查。
- 所有月份均已看过结果，本次是探索性诊断，不是新盲测；回访样本也不自动代表全国。

## 分工与交付

- 数值线：逐月、分组、先验保留、更新方向与幅度；只读旧结果，新增独立分析模块。
- 回复线：核对实际消息的同比/环比/预测期和先验表达；可复现抽样审阅回复。理由文字只能作为线索。
- 文献线：复用并核验原始经济学文献与关键月份背景，列出可区分的机制假设。
- 主代理：补控制变量分析、概率填法分解、图表和现有阅读页，汇总下一步决定，更新任务板。

公共资料只保存聚合结果；逐人配对、原始回复及真实ID保留在忽略的 `outputs/` 中。旧快照及15项保护文件不动。

## 完成标准
