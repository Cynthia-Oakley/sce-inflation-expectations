# 数理能力与金融知识：三组输入对照

2026-10-16；开发预检。**真实批次与评价已完成，576份全部有效、估算$0.691，详细输入暂不升级。最新结果见[完整实验记录](results.md)。** 研究包准备与离线验收不产生模型费用；真实调用另以匹配本批数据范围、协议哈希和费用上限的授权记录为准。

## 这次想回答什么

原输入只有High/Low标签，模型可能没有据此改变信息理解或概率分配。我们检查：给它更具体的本人历史答题证据，是否比一个标签更有用；相同证据以原题或文字转述呈现，是否产生不同结果。已有70个月真人分析支持优先观察个人不确定性及通缩尾部，而不是预设答错一道题就提高通胀预期。

## 三组如何区分

1. **label_only：原标签。** 保留现有高／低数理能力标签，不增加题目。
2. **question_answer：原题与本人作答。** 标签仍保留，增加五道数理题、购买力题和风险分散题的官方英文题干与本人历史原答。
3. **faithful_paraphrase：同内容文字转述。** 标签、题目事实、数值、条件、选择题全部选项、本人答案及来源月与第二组相同，只改题干的句式。

第一组与后两组比较的是**细答信息包的增量**，还包括两道不计入原High/Low的金融知识题；不能解释为纯措辞效果。第二、三组才隔离呈现方式。三组均不提供标准答案、纠错反馈、对错标签、强制认知偏差或“故意算错”的指令。

## 样本与其余配置

- 四个已有开发月：2020-04、2021-05、2021-11、2022-03；不冒称新的独立验证期。
- 每月从既有48人名单中分层抽24人：14名High、10名Low。旧均匀子样本在前三月各只有3名Low，已作为零API工程预检存档，不作为正式批次。
- 三组同人配对，每组两次生成；4×24×3×2=576次请求、24个引擎运行单元。两次生成不是两位不同的人。
- 保留相同P/E、新闻、政策、合成CE支出占比、合成美联储信心、真实本人上期Q8/Q9与更早摘要、信息截止和预测窗口。没有增加购买频率、当期财务Q1、性别或其他机制。
- 沿用直接填写本期Q8/Q9的绝对回答格式；不使用已经失败的十档概率差值格式。
- DeepSeek官方API，deepseek-flash、temperature=0.5、关闭思考、max_tokens=1024、无自动重试。模型别名不等于已核实的训练截止日。
- 用官方SocioVerse2引擎与DuckDB轨迹；每月独立一步，属于A条件历史重建，不是B连续递推。

低组过度抽样是为了覆盖认知差异。主分析为同样本、等月配对；辅助权重为原调查权重乘以名单内分层抽样概率的倒数。两者都不据此宣称全国代表性。

## 数据如何准备与隔离

仅从本人早于目标月的记录读取QNUM1/2/3/5/6/8/9，保留实际错误数值、原始选项和来源哈希。不用本期答题记录、不向过去回填、不把空白当答错。准备时只读取历史答题、原名单和原P/E；当期Q8/Q9真值只在独立评价层读取。

题干来自本地归档的[纽约联储公开核心问卷](https://www.newyorkfed.org/medialibrary/interactives/sce/sce/downloads/data/frbny-sce-survey-core-module-public-questionnaire.pdf)第25—26页，已与本地PDF核对；题目目录与七项字段白名单随准备包保存。此处“个人先前作答”不证明这些微观资料当时已公开，所以不升级为严格B输入。

## 怎样判断效果

主要问题是个人概率分布是否更贴近真人，而不是单纯把答案变宽。

- 主指标：个人Q9密度IQR与真人的配对绝对误差；真人和模型十档回答均使用同一个冻结计分器，官方派生值另作核对。主要形式对比为转述组减原题组。
- 同时报总体Q9中心误差、跨人分布W1、跨月更新W1、个人Q9均值误差、Q8点回答、零通缩比例与十档概率差异。
- 每次生成分别计分，再对月份和重复次数等权汇总；不先混合两份概率，制造一个不存在的受访者。
- 区间按受访者整簇抽样，同一人跨月和两次生成一并保留。只有四个月，区间是这些时期条件下的探索性诊断。
- 三组两次均可评分的人月进入共同支持；同时报告被排除人数和全部请求中的失败。任一组合法率或可评分率低于99%，准确度仅作选择后描述。

对“详细输入相对标签”的继续研究门槛：IQR误差改善的探索区间上界低于0，且总体中心误差和跨人W1点值不恶化、每组合法／可评分率均至少99%。门槛用于决定是否值得扩大，不等于项目成功；主要形式对比及两项细信息对比均报告，不挑最好的一项冒称确认性结论。

## 已知局限

原题本身包含1%、2%等数字，也可能形成数字锚定。即使有变化，也不能直接说模型具备了真人的数理能力或金融知识机制。High/Low和细答包的信息量不同；个人密度拟合还继承近似计分器误差。真人关联不等于因果，提示有效也不等于因果机制得到识别。

## 执行与文件

准备入口：`scripts/run_sce_cognition_trial.py prepare --folder outputs/<新目录>`；离线验收：同入口`dry-run`；真实执行：同入口`run`，必须有匹配具体范围和费用的授权及全单元离线收据。

当前正式准备包：`outputs/sce_cognition_trial_20261016_v4/`。v1为旧均匀名单预检，v2为分层及覆盖预检，v3补充十档真值证据，均未真实调用；v4复用v2已核验历史记录，核对本人链接和原文件哈希，增加统一计分与原始十档评价口径，避免重复解析工作簿。所有旧包保留，不运行其付费入口。个人输入、预览、历史答案及完整轨迹保持本地忽略，不进入Git。代码、方法、费用卡和无个人记录的聚合结果可按明确清单保存。

准备v4的缓存复用方式为`cognition_preparation.prepare(out, history_cache=<v2目录>)`；普通入口不传缓存时从固定原文件读取，抽样与提示相同。预算按[DeepSeek官方价格页](https://api-docs.deepseek.com/quick_start/pricing/)的Flash高峰无缓存输入$0.30/百万token、输出$1.20/百万token估算，核查日2026-10-16。576次预计约$0.73，保守预留$2.83，拟上限$3；估算不是账单，运行还受逐单元费用及总调用数限制。

后续评价入口：`scripts/analyze_sce_cognition_trial.py --folder <准备包> --out outputs/<新评价目录>`。旧实验、受保护计分器和人口文件不变。
