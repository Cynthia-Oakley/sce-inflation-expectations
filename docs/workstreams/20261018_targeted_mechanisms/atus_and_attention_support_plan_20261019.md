# ATUS采购角色与信息接触：本轮支持检验

2026-10-19。用户要求重试下载并继续差异化信息匹配研究。已通过同源浏览器下载官方2016/2022/2023年EH、基本受访者、CPS配套压缩包及问卷/字典；禁止执行压缩包内第三方统计代码。此前看过2023采购角色的无权重边际计数、已看旧模拟结果，因此本轮为开发研究，不是盲测。

## 本轮不做什么

不新增付费API/Sim回答，不改现有P/E提示及运行配置，不向SCE个体分配角色。不同信息量方向继续保留；旧的人口匹配阴性不能直接否定方向。

## 采购角色检验

- 先核三个文件一对一连接：EH与基本受访者按TUCASEID/TULINENO；CPS仅取本人TULINENO=1。不把CPS全部家庭成员当成新的受访者。
- 主描述限18岁以上，使用EH权重EUFINLWGT；未知/拒答不当作不购物。2016三档与2022/2023五档分开，不强行转换同尺度。
- 报告各年角色加权比例，并按年龄、收入、教育、劳动状态、家庭人数、有无孩子和性别描述。性别只是待研究的实测人口字段，不等同采购角色；不会自动外发或加入旧模型。
- 主预测检验使用2022训练、2023评价的五档角色，固定条件频率模型：每格加权角色分布按n/(n+20)收缩至训练总体比例。20为本次事前固定的平滑强度，不按结果调。
- 固定比较：总体比例；年龄/教育/收入/地区四项；再加劳动状态；再加家庭人数/有无孩子；角色相关组合（年龄、家庭人数、有无孩子、性别）。比较加权对数损失、Brier、顺序概率评分；不根据SCE当前答案选择机制。
- 正式迁移前另核家庭/消费单元口径、CPS与ATUS记录间隔、缺失与插补、SCE本人历史覆盖和输入权限。此处只能验证外部角色能否预测，不能声称这些SCE人实际承担何种角色。

## 新闻匹配检验

Andre原问卷新增核实的`know_news_pi`与`know_news_u`，分别直接问过去三个月跟进美国通胀率、失业率新闻的频率，五档为从不、每月一次、每月两次、每周、每天。它们比六档“通常关注全国经济新闻”更贴近统计资料接触，但仍不是篇数记录。

- 同一外部家庭样本分别检验一般关注六档、通胀频率五档和失业频率五档。沿原固定C=1模型、五折×42/43/44，无调参。
- 固定比较总体率、共同四项P、共同四项加劳动状态；另将经济课程列为不能直接迁移的诊断，检查缺少直接信息动机/知识字段的可能性。SCE学历不能替代经济课程。
- 劳动状态只按原题做粗合并：在职/自雇、找工作失业、非劳动/其他、缺失；不把答题时长字段当作经济工作经验或关注时间。
- 报告三种接触题的同人联合计数，保留新闻兴趣与统计关注可能不同这一点；不直接换成3/8/20/40篇，不向SCE分配这些新标签。

## 版本、成本与后续

下载留URL、时间、SHA和HTTP Last-Modified；2023文件当前Last-Modified为2026，不能当2023首发历史版本。A可作为明确标记的外部结构参考，严格B仍须核版本与可得性，不悄悄填入。

产物为原始来源目录、独立支持分析及聚合/阅读页。若证据支持下一轮：新闻总量、公开统计接触、生活价格角色分别设计；先解决旧分析的调查加权信息量不齐，再登记新模拟与预算。不能用最优种子或试验误差反推“谁关注多少”。

## 结果后补充的拆分检查

看到角色相关组合的总体收益后，追加只看年龄/家庭构成、只看年龄/性别、完整角色组合及再加劳动状态的比较；仍固定2022→2023和20个样本的平滑强度。复用本轮已清洗供体，不重跑新闻交叉验证、不读SCE真值。这是结果后的解释性拆分，不称新增独立验证，不按哪套最好就修改正式模拟。
