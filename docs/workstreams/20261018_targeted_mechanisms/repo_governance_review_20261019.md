## 结论

认同统一设计入口、历史材料分层、脚本索引及渐进复用的方向。建议修改下列细节后分步执行；不按文件名、日期或“30天无文档引用”批量归档。整理的目的，是让下一轮研究更容易接手和复算，根目录文件数量不作为验收目标。

## 一、总纲先校正，再作为统一入口

1. **区分研究契约与当前实验。** A线允许声明采用的事后信息或宏观约束；不能把某轮实际采用的E截止点写成A线永久定义。D048与`A_B_RESEARCH_DESIGN.md`明确了这一点。B线继续要求全部预测输入在截止前可得。
2. **修正实际信息截止。** 总纲第3节写“目标月−1月末”，但D050已改为目标月CPI首发日结束时；现有开发实验不能被描述成上月末预测。旧产物保留各自原口径。
3. **精确限定“真值不进输入”。** 本期目标Q8/Q9仅供评价；当前A条件模拟确实输入本人真实上期Q8/Q9和更早摘要。因此不能笼统说真实回答绝不进输入，也不能把这些实验称为B线自主递推。
4. **写清主统计量。** 每人Q9拟合密度均值 → 每月跨人加权中位数 → 与同支持真人月度中位数比较 → 对月份及生成遍数等权平均绝对误差。不是“跨月中位数”。该样本成绩与完整全国波次成绩分别报告。
5. **说明当前新闻内容。** 现有输入使用标题与摘要，去除重复文本；总纲第8节“E只用结构化数值/标题”沿用了旧表述。保留来源文本与禁止无依据改写是两件事。
6. **权威性按批准状态与适用范围判断。** 不能仅以决策日期新旧覆盖协议；未批准草案、历史决策及已被后续用户授权改变的规则需标明状态。当前`A_B_LINE_CONTRACTS.md`仍为未提交草案，旧D049b与现行真实上期信念输入也有冲突，应在总纲明确指向当前契约及配置，不能让读者自行猜测。

12期主结果0.459/照抄0.239的保留是正确的。六期随机新闻量候选可加一行链接与限定，不替换十二期成绩。总纲概括结果，数字与配置的完整证据仍只在专题权威页维护，避免重复更新多份长正文。

## 二、对归档清单的调整

- **根目录保留：** 建议额外保留`SCE_EVALUATION_CONTRACT_V1.md`，或留下稳定入口。它规定加权分位数、W1、Q8/Q9口径与时间边界，不能按“SCE_EVALUATION_*”一概归档。保留`current_todo.html`：生成器直接写此路径，用户也在持续使用。
- **方法专题：** 本轮先保留原位，在DESIGN的文档地图分类。`docs/specs/`可作为后续新规范的位置；旧文件需逐份确认状态和依赖后再迁移，不将旧研究草案全部包装成当前规范。
- **历史计划与阅读页：** 先列明确清单，区分仅供阅读、程序输入、冻结证据。未冻结的一次性历史文档可批量整理，但同步检查入站链接、被移动文件内部的相对链接及图片资源。已有阅读页路径尽量稳定。
- **程序读取的文档不能仅改链接：** 例如`experiments/psychological_state.py`仍直接读取`docs/PSYCHOLOGICAL_PROFILES_ACCEPTANCE_20261006.md`。移动它会影响准备流程；`git mv`不会自动修复运行路径。
- **冻结证据留原状：** 运行manifest可能记录文档、源码的路径和哈希。最近新闻试验manifest就登记了运行计划和入口源码。优先将冻结材料保留原位、从索引标记为历史；不要改旧manifest来迁就整理。
- **NEXT/HANDOFF压缩：** 两者目前约10.5万/8.0万字符，应优先收束。顶部仅留当前结论、运行状态、授权状态、下一步与证据链接；旧“正在运行/待授权”段落移入注明失效的交接快照。不要每周再生成一套重复结论。

## 三、脚本复用的采纳范围

1. 同意先补`scripts/README.md`，标出运行、评价、数据准备、一次性分析入口及对应workstream。
2. 同意新实现复用共享统计；**先用已有`evaluation/metrics.py`等模块**，缺少什么再补小函数。暂不另建包揽真值装载与全部统计的`analysis_utils.py`，以免出现第二个共享标准。真值读取与输入准备保持边界。
3. 不同重抽样方式不能仅因都叫“区间”而合并：按人聚类、按月成块、对不同生成遍数的处理依赖实验设计。共用时接口必须显式记录这些选择；旧冻结实现与数值保持原样。
4. 脚本归档后置。除文档，还要检查Python导入、测试、配置、资源清单和冻结manifest。例如`evaluation/news_breadth_readout.py`直接导入`scripts/report_sce_information_exposure.py`，并非所有report脚本都是可随意搬走的一次性入口。
5. 取消“30天未被文档引用即归档”的自动规则，改为待检查候选。没有引用也可能是独立复算入口。先保留脚本原位、索引标历史，通常已足以改善导航。

4. 只有改变公共Python接口时，才扩大相关回归验证。不得因整理重跑真实API、重拟合旧结果或改写历史证据。

执行人不必固定为Kimi；由当时可用的一位Agent完成整批修改，另一位只查具体移动清单和受影响入口，避免重复全仓审计。
