# 差异化新闻数量：执行前方案（2026-10-19）

状态：用户同意试验方向；本轮具体数据发送与新增预算尚未批准。先准备输入和官方引擎干跑，真实调用为0。此文写于新回答生成前，登记后不根据本轮效果改规则。

## 1. 研究问题

让不同家庭接触不同数量的新闻，是否比人人看8篇更接近真实SCE？如果数量分配与人口特征相关，是否又比随机分配更有效？这两个问题分开比较。

外部依据是Andre等研究复现包的经济新闻关注六档回答；用年龄、教育、收入和地区估计关注档的条件概率。共同人口变量的外部交叉验证改善很小，因此按概率抽取，不规定高学历者必然多看新闻。协议沿用已经准备好的分配种子20261019，不按SCE误差挑种子。

## 2. 三组配置

- 共同对照：每人8篇。
- 随机分配：每月48人3篇、28人8篇、20人20篇，随机分配名额。
- 人口匹配：同样名额，依据外部关注概率和固定随机数分配。

三组都是每月96人、平均8篇。3篇是共同头版背景；8/20篇另加5/17篇个人新闻。篇数是实验水平，不能解释为美国人的实测阅读量。暂不加入40篇，以复用已有输入并控制实验规模。

购物角色和新闻广度是两个独立待检机制。本轮只检验新闻广度，原价格统计、主题匹配规则、CE占比、央行信心、政策、个人上期Q8/Q9和更早历史摘要、问卷全部沿用。此次不加入ATUS角色、Q1/Q2、心理、金融题或新的Event资料。

## 3. 时间与样本

六期：2020-09、2021-09、2022-06、2023-12、2024-10、2025-03，每期原96名回访者，沿用原分层入样概率及调查设计权重。三组各生成两遍，6×96×3×2＝3456请求、36个引擎单元。

这些月份已参与开发，不能称为未见过的独立验证。2021外部关注资料用于2020是历史重建假设；真实本人先验也是A线条件，不能称严格事前B预测或全国代表人口模拟。得到候选后才另登记未参与调整的验证月份。

## 4. 公平对照与复用

从原已核查的3/8/20篇完整提示中，按本次名额选取该家庭对应的整份输入；保留原新闻正文、日期、公开先后标签、50/50相关抽取、同一事实来源。无需重抓新闻、重新打标或再次生成时间标签。

随机组保留名额总数，并用输入而非真值约束调查加权信息量：新闻篇数、新闻文字字节数和完整提示字节数与匹配组相差不超过1%；六种已有路由主题的加权占比差不超过2个百分点。固定种子后至多4096个随机置换，取第一个达标者，不选误差最小者；若失败则停止并记录，不悄悄放宽。字节数只是token代理；粗主题平衡不能保证语义信息完全等量。

固定8篇组是运行同期新回答，避免将模型别名变化混入机制差异。重复利用旧输入、新闻标签和引擎；旧模拟结果仅作历史参照，不冒充本轮同期对照。

## 5. 评价与判据

主比较是人口匹配相对随机分配，次比较为两者分别相对固定8篇。主指标沿用个人Q9拟合密度均值的群体加权中位数MAE，另报W1、人际IQR、变化分布距离、个人误差、Q8及漏动/错动率，并与同支持照抄上期、个人历史锚基线比较。

初筛要求：匹配相对随机的中位数MAE和W1同时下降，至少4/6个月中位数误差不增；同时报告逐月、两遍、留一月敏感性和家庭聚类区间。若仅随机分配优于固定8篇，应归为信息数量分布收益，不能说人口匹配有效。即使初筛通过，也不自动升级主机制。

无效回答原样保留，不自动重试；共同支持按全部三组和两遍取交集，披露覆盖率。两遍是生成重复，不是新增真人样本；家庭聚类区间只针对选定六个月，不能代表跨时期确定性。分配种子仅一个，本轮不识别分配种子稳健性。

## 6. 运行与费用

复用 `run_sce_frozen_trial.py` 的官方SocioVerse2引擎、轨迹审计和 `evaluate`，新增代码只负责分配输入。DeepSeek官方 `deepseek-flash`，温度0.5，关闭思考，最多1024输出token，无自动重试；记录返回模型与指纹。

2026-10-19核查的[官方价格](https://api-docs.deepseek.com/quick_start/pricing/)仍为Flash-1017，高峰无缓存输入/输出每百万$0.30/$1.20，预算按此保守计算。预计数由完整输入字节和每份300输出token估算；硬上限拟$16，具体预计额与保守预留由准备回执给出。仅准备不产生模型费用，真实批次需按AGENTS.md第11条明确本批范围、目的地和预算。
