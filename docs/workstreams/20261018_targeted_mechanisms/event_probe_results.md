## 2. 四个来源分别有什么问题

- **USTR：**2025年3月返回10条示例，混有无日期页面、领导介绍和3月31日的后发报告。只有3月3日贸易政策议程、3月12日欧盟报复性关税声明通过日期初筛；已另存官方页面。另两期返回零条，不能解释为当时没有贸易事件。事件计数不作为经济指标使用。
- **Google Trends：**2025年3月只有整月均值/极值，没有逐日数据，无法截到3月12日；另两期虽然顶层成功，实际没有热度观测，上游返回429。缺失不能补成零，也不据此分配个人关注比例。
- **Household Pulse：**2020/2022报错；2025请求却返回2024年的汇总，缺调查周期、采集区间、分母和权重。旧年份可能有背景价值，但当前无法解释这些汇总值，暂不进入P或E。[Census官方](https://www.census.gov/data/developers/data-sets/hps.html)区分2020—2023与2024后的两套接口，进一步定位需服务端信息，不能仅凭回包认定故障原因。
- **FRED/UMCSENT：**三期有数值，但无发布日/初终值标记。核对密歇根大学原发布稿后，确定这些恰好都是截止日之后的终值，不能放进原冻结E。

## 3. 终值和当时已公开的版本，差别是实质性的

**2020-09：**实验截止9月11日。MCP给9月终值80.4，但原稿发布于10月2日；9月初值也要到9月18日。可参考的是8月28日公布的8月终值74.1。[8月原稿](https://data.sca.isr.umich.edu/fetchdoc.php?docid=65950)、[9月终稿](https://data.sca.isr.umich.edu/fetchdoc.php?docid=66156)。

**2022-06：**实验截止6月10日。MCP给终值50.0，原稿6月24日发布；6月10日已公布的初值为50.2。原稿只有日期，未编造具体钟点；当前截止为纽约时间日末，按发布日上界检查通过。[初稿](https://data.sca.isr.umich.edu/fetchdoc.php?docid=70216)、[终稿](https://data.sca.isr.umich.edu/fetchdoc.php?docid=70332)。

**2025-03：**实验截止3月12日。MCP给3月终值57.0，原稿3月28日发布；当时最新终稿是2月21日公布的2月值64.7。其中同时公布了1月权重的小幅修正，使用时须保留“2月21日版本”，不能冒充1月首发。[2月原稿](https://data.sca.isr.umich.edu/fetchdoc.php?docid=78142)、[3月终稿](https://data.sca.isr.umich.edu/fetchdoc.php?docid=78363)。

以上是全国消费者情绪指数，**不是SCE通胀预期，也不是某个家庭的心理测量**。原稿中的一年期通胀预期是另一项点预测统计，也不等于本项目Q9个人密度均值的群体中位数。

## 4. 对我们真正有启发的信息

原始调查说明，“对经济悲观”和“预期价格下跌”不能简单画等号。

- **2020年：**居民可以认为经济处境很差，同时期待经济从停摆中恢复；特定商品涨价与总体需求疲弱可以并存。
- **2022年：**汽油和供给短缺引起关注，居民担心收入跟不上价格，同时担心未来经济转弱。低信心不等于预期低通胀。
- **2025年：**居民担忧关税导致尚未发生的涨价，提前考虑购买耐用品；这种前瞻担忧可以出现在已公布CPI尚未明显变化时。

这些是当时另一项调查的群体背景，不能替每个SCE家庭编造观点。但它为下一次E改动提供了更具体的内容：**除已公布的价格涨幅，还呈现居民当时正在担心什么、政策处于什么阶段**，而非只给一个乐观/悲观标签。

## 5. 与旧输入相比，新增的是什么

已检查旧十二期正式输入中三期各192份提示。2025-03已有189份提到关税、43份提到报复措施；不能说之前完全遗漏关税。只有6份提到Michigan、2份含consumer sentiment，且这只是字符串检查，不是完整语义判定。

本轮新增的是明确日期的独立消费者调查报告，以及政策原始页面的来源/状态记录。是否只是重复了NYT已有含义，仍须在下一组实际输入中逐条核对。**不能把新增来源、增加字数等同新增有效信息。**旧正式E完全未改。
