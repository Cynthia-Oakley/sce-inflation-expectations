# 个人常态与共同水平：同样本方向诊断

2026-10-18。用户同意先推进既有诊断，并研究新闻接触量、经济解释方式和提示词变体。本文在计算前固定口径，但十二期已经查看，**不是盲测预登记**。本轮不调用付费接口，不改旧输入、运行配置、计分器或回答。

## 本轮完成范围

1. 在既有十二期2,284个共同有效回访人月上，比较真人和两遍模型的更新方向；只有2期以上历史者可计算较早常态。
2. 个人较早常态严格去掉t−1：由冻结输入中历史均值、次数和上期值恢复，避免拿包含上期的均值直接解释回归。
3. 公共参照分开：截止前最新CPI同比（不同预测期限，仅作方向参照）；同月其他Agent的加权中位数（评价后描述，绝不输入下一轮）。不能把两者都称为正确答案。
4. 重点看“个人常态方向”与“公共参照方向”相反且均相距超过0.5pp的人；分组只用过去状态和参照，不用本期真人结果选人。统计保持/沿个人方向/沿公共方向及到锚距离是否缩小。
5. 单独报告方向相同者：在这些人身上，朝两种参照移动无法区分机制。冲突组结果也不是随机识别的公共信息因果效应。
6. 同控制的描述回归只估个人历史关联；月份固定效应下CPI差距与先验代数共线，明确验证并禁止宣称独立CPI心理权重。检查较长历史、原信念0—10%及逐年剔除；不因此挑选主结果。

## 评价与交付

主实验的MAE保持逐遍计算；画像同时报告两遍均值及逐遍敏感性。阈值0.5pp，另查0.25/1pp。主权重调查权重÷入样概率，月内归一；跨月先等权再条件于子组。缺历史者保留原总人数与原主指标，不伪造个人常态。

结果用于选择“状态估计”或“信息接触/解释”中的一个候选，不直接改模型。先核查外部调查是否真能支持接触差异和解释渠道的条件分布；篇数、注意和理解不是同一量。任何无实测支持的数量档位或提示词扰动先标实验处理，不能冒充真人属性。新真实模拟另冻结范围和预算。

输出：独立分析模块和入口、必要数学验证、小型聚合摘要/科学图；在原阅读页新增一节，完整个人记录留忽略的outputs。15项保护文件不动。
