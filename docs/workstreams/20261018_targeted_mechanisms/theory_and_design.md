# 从具体差距到P/E改动：三条可证伪的机制

2026-10-18。性质：探索性证据映射与候选输入设计，未实施新模拟。复用上一轮文献与[十二期诊断](../20261018_response_gap/results.md)，只补核五项一手研究。本文不改旧文档、运行配置、回答或计分器，不调用Event MCP或付费接口；MCP实际资料由主代理核验后再接入。

## 先固定目前真正需要解释的观察

- 不只是“总体没预测准”：真人基本稳定的740个人月中，真人平均绝对变化0.117pp，模型2.553pp；约59%模型回答移出0.5pp稳定范围。但真人明显变化者，模型平均又改得不够。不能把所有人统称为过度更新。
- 不只是Q9表达：同支持Q8的人际IQR为真人7.275、模型1.650pp。Q9拟合与机械取整不足以解释共同压缩。
- 不只是先验没传入：全部实际消息有本人过去答卷及常态；固定病例中存在将“不寻常”先验向公共水平拉回的文字，也有同输入保持先验的反例。
- 不只是某个人口标签缺失：控制月份、历史和其他画像后，低数理的水平关联在模型中并未消失。不能给低数理、低收入或财务较差者统一增加预期。

这些分组有本期真人答案参与，只能定位问题，不能据此决定未来谁应保持。以上数字的口径、权重及阈值敏感性均沿用旧诊断，不在本文另做估计。

## 假设一：原有个人信念与公共信息冲突，被当作需要专家纠正的偏差

**因果链假说。** 本人原先信念与共享统计/政策叙事相距较远 → LLM把公共资料视为更权威的判断依据，将个人状态当作应纠正的异常 → 不同个人向共同水平收拢 → 稳定者改得过多、原有排序被压缩。链条中的“专家纠正”是对可观察行为的命名假说，尚未识别模型心理或内部目标。

**文献对应。** Armantier等随机告知实验发现，新信息使预期向中心收敛，反应取决于信号和先验精度；信息处理组也有40.15%—52.83%不改一年期点预测。它支持“共同信息与个人状态冲突会产生异质响应”，并不证明本项目收缩源于专家纠正。[SR543原文，PDF第14页、§3及Table 1讨论](https://www.newyorkfed.org/medialibrary/media/research/staff_reports/sr543.pdf)。

**项目可测变量与数据指纹。**

1. 用上期Q8、完整Q9、个人既往常态/变动习惯，以及上期主观不确定性描述个人状态；用公共资料发布日期相对本人上次答题日、消息是否重复、政策话语是目标还是事实描述E。
2. 检查模型的修正是否指向公共水平，且随“上期信念－公共价格信号”的距离增大；是否连真人稳定者也如此。这个距离只是冲突代理：过去CPI与未来一年预期不是同一个预测目标。
3. 将原始向量完全不变、数值小变动及明显修正分别报告；比较Q8和Q9、同人两遍稳定性。若只有理由写“回到正常”而数值无对应变化，不支持此指纹。
4. 月份固定效应下，“上期信念－同月CPI”与上期信念代数共线，不能将该系数冒称独立公共信息权重。需要公共资料随机显隐或其他受控变化，才能区分信号效应与先验均值回归。

**竞争解释。** 公共信息确实有用，真人旧答案含噪声或取整，个人私人经历未观测，生成随机性，以及历史窗口前移，都能产生部分相同现象。真人比模型更分散不代表每一份旧信念都应被保存；不能以保留方差替代准确度。

**具体P/E调整及对照。** 先对E做数据层面的“同事件去重＋事实/观点分离”：同一个CPI首发不因滚动序列、最新摘要和多篇新闻出现三次就算三条独立证据；政策目标、官员预测、已经发生的动作分别保存原文来源及时间。P继续保留原有个人状态，不新增“要坚持自己”的句子。

先冻结同一事实集合，比较原E与去重E，检验重复展示是否加强向公共水平收缩；再单独比较有/无一条来源明确的政策解读，数值事实与问卷保持相同。前者检验重复暴露，后者检验解释性叙事，不能一次一起改后归因。若没有冲突距离×展示方式的差异，或只统一平移中心，专家纠正假说的证据减弱。已有anchor、时间说明、U1、历史线性组合与差值格式不能算作这项新对照。

## 假设二：家庭压力改变事件的个人含义；现有合成情绪没恢复这条连接

**因果链假说。** 同一个价格/就业事件 → 经本人已有家庭处境、工作风险和支出暴露过滤 → 更容易想起“物价挤压购买力”或“失业/需求变弱”中的一条 → 对未来价格和就业作出不同判断。压力可能引起更高的物价担忧，也可能引起更低的需求预期，不能预设统一通胀方向。

**文献对应。** Kuchler–Zafar用美国同人面板发现，亲历失业者对全国未来失业更悲观，支持个人经历外推到总体判断的渠道。它研究住房和失业预期，**没有证明个人失业会提高通胀预期**；就业变化也不是随机分配。[纽约联储SR748原始摘要](https://www.newyorkfed.org/research/staff_reports/sr748.html)；[2019年正式论文](https://doi.org/10.1111/jofi.12819)。

Andre等在同信息的美国情境中发现，不同人想起不同的成本/需求传导；情境线索可以改变联想和预测，既往经历与联想相关。随机线索支持注意渠道的因果效应，经历关联本身仍非随机。[2022年原文，§2.4、§4及Table 4—5](https://academic.oup.com/restud/article/89/6/2958/6531988)。

**项目可测变量与数据指纹。**

1. 优先本人截止前实际状态：Q1过去一年财务变化、Q2未来家庭财务判断、就业状态及其转变；失业/求职概率仅在核准原题、字段、跳题与历史可得性后使用。主观失业风险与已发生失业分开，Q1也不是已测收入冲击。
2. 风险偏好不能直接充当注意力或悲观程度。CE篮子是合成价格暴露，不是本人购物经历；没有本人行业/雇主信息就保持未知，不按收入猜关税就业暴露。
3. 重点查**本人过去状态×后续具体事件**是否解释真人和模型的差异。例如财务恶化者在食品价格事件中是否更多强调购买力，而有就业损失经历者在贸易事件中是否更多关注工作。方向需要由数据判断，不能预先把“较差处境”编码成高报。
4. 检验条件关联能否在控制过去信念/常态后、按时间前推到另一时期保持；再看是否对应误差、稳定率、Q8/Q9一致性或尾部。短理由只帮助找候选，不是已观测的心理中介。

**已有结果的约束。** Q1实际试验的中心收益跨月未保持；上期Q2加入后中心MAE约0.4591→0.4593，个人及分布未改善。风险偏好已有离线增量检验，心理匹配也做过实际对照，不能作为全新字段重启。现有结果只允许继续问“同人处境与事件暴露的连接是否缺失”，不支持再把相同五档/七档标签换成较长情绪描述。[实验台账](../../EXPERIMENT_STATUS_20261018.md)；[Q2结果](../20261017_financial_outlook/results.md)。

**竞争解释。** 财务担忧可能是高通胀预期的结果，也可能与其共同受未观测冲击影响；低收入可同时关联篮子、认知、流动性和选择性报告。即使有状态×事件关联，也不能直接解释为心理因果。

**具体P/E调整及对照。** 候选新增的是**可核验的同人暴露记录**，例如本人过去就业转变/风险与特定行业冲击的真实联结，或本人记录的支出受压类别，带日期和未知标记。不是再加“你感到担忧”。先离线检验这些联结在新时期是否有增量；只有通过，才比较“相同P边际、真实联结”与“保持边际的打乱联结”，E完全相同。若只有外部聚合或无同人行业数据，暂不声称构造好了个人暴露；可做明示合成情境的机制敏感性，但不能汇报为真人重建改善。

## 假设三：关税等结构事件有多条渠道，统一宏观解释掩盖个人差异

**因果链假说。** 同一关税事件可同时涉及进口终端品成本、生产投入、国内保护、出口报复与不确定性 → 人们依其实际接触、工作/消费暴露和来源信任，先想到不同渠道 → 有人更关注未来价格上行，有人更关注工作或需求下降，也有人认为政策会保护就业。净通胀影响和持续性不由“事件是好是坏”直接决定。

**文献对应。** Flaaen–Pierce分析美国2018—2019制造业关税，发现进口保护的就业收益被投入成本和报复渠道抵消，较高暴露行业的就业相对下降、生产者价格相对上升。这提供美国数据中双通道并存的例子；它不是消费者信念实验，不能将行业估计移植为2025年每位居民的反应系数，也不能把生产者价格替代CPI。[联储FEDS 2019-086原文页](https://www.federalreserve.gov/econres/feds/disentangling-the-effects-of-the-2018-2019-tariffs-on-a-globally-connected-us-manufacturing-sector.htm)。Andre等支持相同事实下的渠道理解异质性，但其四类冲击不是关税实验。

**政治、制度和政策信任须分开。** 信任美联储控制通胀、信任现任政府经济政策、党派认同、对某一关税措施的支持，是不同变量。Binder等美国2025年研究摘要显示，共和党人对Fed信任较低却也有较低通胀预期，Fed信任不足以解释党派差距；开放回答突出关税和总统本人。不能据此给某党固定通胀偏移。[NBER w33684，2025-04官方摘要](https://www.nber.org/papers/w33684)。该研究4月公开，不能回填为2025-03-12居民可见资料；它只为现在的研究设计提供依据。已有合成Fed信心也不能再包装为新P。

**项目可测变量与预测指纹。**

- E区分宣布、实际生效、暂停/撤销及不确定方案，按本人作答时点判断是否已公开；记录受影响商品/投入/市场，而非只给“关税增加”标题。价格、就业/需求、政策回应分别有事实来源，未知幅度留空。
- P只有实测或有支持的暴露才与E连接。可核验的商品支出暴露、行业/雇主、媒体接触、政策信任各自存储；合成供体与实测字段明确区别。民族、党派、收入不确定性不应被无依据补成渠道标签。
- 预期指纹是同事件下不同暴露产生不同反应，且价格风险与就业/需求担忧可并存；不是所有人一起向CPI靠拢。如果新输入只造成统一升降，或仅多写了渠道词而数值/群体梯度未变，不算恢复异质性。
- 2025-03既有固定病例的两遍回复已经出现价格上行和增长下行两种解释，故不能断言旧E完全缺关税；应核查哪条事件事实缺失、哪条渠道被遗漏或共同采用。[原回复审计](../20261018_response_gap/reply_audit.md)。

**竞争解释。** 不同人可能读了不同新闻、对政策持续性判断不同，或存在党派表达与模型生成变化；两遍理由不同不是同一个真人有两种真实心理。观察到关税月份误差大，也不能由少数月份剥离其他同步政策与宏观变化。

**具体E调整及对照。** 把MCP得到的原始事件转成带来源的事件记录：`event_id`、宣布/生效/变更时间、当时政策状态、涉及对象/类别、已经发生的价格与就业事实、原说话者的预测/承诺及不确定性。将事实与预测分开；不写“你应因此提高通胀/降低就业”。冻结同一事件后，单独比较旧摘要与经核对补齐的事件事实；再作价格事实/就业事实的单项消融，保留完整原始事实档案。不同时增加心理标签和渠道说明，以免无法知道增量来自何处。

## Event MCP三类资料怎样进入，怎样不能进入

**National confidence：** 先查指数到底衡量什么、调查对象、题目组成、参考期、发布时间和修订；只作共同E或分组环境。它不是个人Fed信任、家庭乐观或本人Q2。如果指数包含通胀/就业预期，须披露与目标构念的重叠，不能称独立心理解释。月度共同值无法自行恢复同月人际差异。

**Google Trends：** 是抽样、匿名、聚合并按查询时空归一化的相对搜索兴趣，0—100不是关注该事件的人口比例；不同地区同值也不代表搜索次数相同。[Google官方说明](https://support.google.com/trends/answer/4365533?hl=en)。固定国家/地区、关键词或主题、语言、时间窗、频率、搜索类别和抓取版本；不能把不同窗口各自归一的曲线直接拼接。全国峰值仅支持当时公共关注升高的候选，不能说每个Agent看过消息。个体差异需本人媒体/知识测量，或在独立资料估计并标为合成的接触概率；不能按低收入、低数理自动指定低注意。地区代理也只在地理可比、样本支持时使用，仍非本人搜索记录。

**Household pressure / pulse：** 在确认题意、总体、分组、权重和可得日期后，可作该时期/地区/群体的压力发生率或变化。不能把群体均值赋给每个家庭并称本人心理，也不能把同时变化的压力与通胀预期当因果。若MCP只有聚合指标，P保持缺失，E记聚合来源；不由这些指标编造工作丢失、党派或信任。所得的个人联结强度须另有联合微观支持。

三类资料都须先核验MCP覆盖美国及具体历史月份，连接响应/缓存日期不等于原始发布日期。本文件未核验接口响应，不声称现已获得上述字段。2025年的后来材料或2026年总结可以帮助研究解释，不能作为2025年3/9月历史输入。

## 近期仅排序两项输入改动

**第一：做E的事件事实补齐、去重及时间版本整理。** 利用现有资料和主代理MCP结果，先产出每条候选事件“旧E已含什么—实际缺什么—何时可见”的清单。优先核查2025关税与2023-12食品语义；旧E已经完整的事实不再添加。分别测试重复公共信号与新增双通道事实，保留本人的既有状态。它直接针对专家式收缩和统一事件解释，无需先杜撰个人情绪。

**第二：有数据门槛的P×E暴露连接。** 先用本人历史就业/财务处境与可核验事件检查条件关联及跨期预测；Q1/Q2/风险偏好本身不再作“新字段”。只有同人暴露支持充分且离线前推有增量，才准备真实连接/打乱连接的输入对照。若只有national confidence、Trends或pulse聚合，暂留E环境，不升级个人P。

两项都不规定保持概率或通胀修正系数，不以多写几句提醒代替数据改动。现12月都已看过；开发期拟合、选择事实或设计对照后，必须冻结并在新的预定月份检验，且保留同样本照抄、已有history方案及原配置。同时考核中心、个人误差、更新方向/幅度、人际分布与尾部；本期真人稳定/上调/下调分组不得输入未来策略。增加人数只解决支持与精度，不修复缺失联结。
