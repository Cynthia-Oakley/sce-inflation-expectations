# 既有回答的个人更新分配检查：执行前固定规则

2026-10-19。用户要求继续。六组结果已看，因此这是**开发后的零API机制诊断，不是独立验证**。不重跑模型、计分或拟合新的参数，不把选择旧回答称为LLM重新回答。

问题：完整资料减少漏动、精简资料减少错动，能否用本人严格过去的更新习惯来区分两类响应？固定新闻8篇，只使用已生成的完整/精简两种回答，保留各自两遍。

1. 复用已完成的逐年前推保持概率`outputs/sce_retention_predictability_20261018_v2/predictions_private.parquet`，只投影userid/month/history。模型只用过去年份训练、个人严格滞后特征；不读该缓存中的本期标签、真值、权重或其他预测。
2. 固定阈值0.5（通常的等代价二分类阈值），不扫描阈值。预测保持概率≥0.5用精简回答，否则用完整回答；缺预测时使用完整回答并明确计数。不是对“真实阅读量”的测量，也不是学习到的最优社会行为规则。
3. 同月将这份选择向量打乱20次，种子20261019..20261038；每次同一人两遍用同一选择，保持每月选精简的人数。权重不参与打乱，故另报告匹配/打乱后的加权精简占比，不能把差异全部解释为身份作用。
4. 使用原六组/两遍共同567人月及原设计权重，比较原完整、全部精简、按过去分配，以及20种打乱分配的中位数MAE、个人MAE、W1、变化W1、人际宽度、错动/漏动。月份和重复等权，不改变真值支持。
5. 这些月份已看，选择规则不是随机信息实验；外部保持预测的目标来自原官方派生均值，和当前冻结近似拟合存在少量口径差异。没有阈值优选、没有独立增量或严格B声明；结果不自动升级。

如没有稳定收益，不立刻支付新模拟；保留个人更新的诊断价值，转向更具体的信号方向/幅度和状态依赖机制。
