# ATUS—SCE匹配与个人信息视图：本轮实施约定

2026-10-19。目标：把外部采购分工与SCE本人严格过去的人口、家庭构成对齐，准备可审计的信息分配原型。不调用付费接口，不修改旧实验和正式配置，不读取本期通胀答案，不以拟合误差选择分配。

## 本轮范围与事先约定

1. 核六期既有输入：2020-09、2021-09、2022-06、2023-12、2024-10、2025-03，各96人。仅投影身份、月份、年龄、家庭构成及其更新题；本期与未来行不参与任何人的状态构造。
2. Q45new/D2new八类同住者加本人形成“全住所人数”，另存剔除非亲属的旧家庭人数，不能混用。Q45的未成年子女只是全户未成年人的下界；若其他亲属或非亲属可能有未成年人且没有已知子女，儿童状态记未知，不自动判无儿童。
3. D1回访“家庭相同”明确排除非亲属，因此不能确认室友数未变。D1报告变化但缺完整D2、搬家却没有更新记录等分别标记；旧记录保留来源年月与陈旧度，不伪装当前确知。
4. 原型主角色模型使用已清洗ATUS 2022五档采购责任，作为A线外部结构假设；2020/2021不能称当时已可得。2016三档作为独立敏感性候选，不强行拼成同一种题。严格B待原始版本和可得日核实。
5. 条件分布先用年龄、全住所人数、有无未成年人；未知维度边际化，即用供体中已知维度相同者，不把unknown当no。小格按原固定n/(n+20)向总体加权比例收缩。保留同人固定随机分位，跨重复不换角色；这只是保持合成身份，不证明角色真值。
6. 额外查看收入、教育、地区加入后在固定2022→2023切分的概率评分与稀疏性，仅作已看过测试年的探索诊断，不声称新的独立测试。不因“看起来相关”就强制精确收入匹配。
7. 新闻广度与采购责任分开。按已有外部六档关注概率及固定个人随机数排序，暂保留每月48人3篇、28人8篇、20人20篇的预算可比设计；这是实验名额，不是美国人口的阅读篇数分布。采购角色只提供食品主题概率倾向，不决定总阅读量，不替代数理能力。
8. 保留原3篇A1共同背景和50%随机/50%相关抽取。个人新闻按同一排序取前缀，篇数差异不另换一套新闻；保留跨日期重复报道。租房/住房主题沿用已知住房信息，不从房主身份推出驾驶，亦不从CE家庭支出推出本人采购责任。
9. 信息分三部分：新闻；最新公开宏观摘要/完整历史表候选；个人生活价格候选。采购角色只调整食品信息细分候选，不自动赋予完整官方统计。所有价格继续保留同比/环比、参考月、首发日、单位及来源，不把全国指数写成个人收据或当月已实现涨幅。
10. 对照准备“匹配分配/同月打乱”，两者保留未加权名额，并要求调查加权平均篇数及食品细分条数相差不超过1%。最多4096个预定随机候选，取首个满足平衡者；不能按SCE拟合效果选择打乱种子，不能做到就报告失败。

## 交付与验收

本地私有输出：历史状态、供体支持、三固定分配种子、匹配/打乱的信息视图，以及不含ID的样例。公开只保存聚合与方法说明。验证重点为日期隔离、家庭口径、未知处理、同人随机数稳定、原始事实保持、截止时间与数量平衡。既有Q8/Q9回答和先验机制保持原样，不生成新的回答、不重新拟合密度。

理论依据：D’Acunto等[JPE 2021](https://doi.org/10.1086/713192)支持价格接触频率/涨价显著性；[PNAS 2021](https://doi.org/10.1073/pnas.2008534118)支持购物分工与预期差异的联系；[USDA ATUS说明](https://www.ers.usda.gov/data-products/eating-and-health-module-atus/documentation)说明原题、家庭收入和购物形式。以上不识别本项目的篇数、信息条数或SCE个人角色；这些属于待检验的操作化。
