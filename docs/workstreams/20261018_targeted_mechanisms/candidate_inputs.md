# 候选P/E调整：每一项对应哪条观察

日期：2026-10-18。状态：输入与对照设计，未改正式配置、未新增Simulation。当前不把保持概率或通胀加减分硬写进模型。

## 一、先检验“完整公共资料造成额外信息干预”

**数据观察。** 真人保持时，模型更容易改写远离公共CPI、主观分布较宽的原有信念；模型和真人对本人历史的保留程度也不同。当前每个模型实际看到完整的共同价格/就业统计、六条12月序列、八篇新闻、三项政策和39条时间标签。虽然文字写着“公开不等于读过”，这些数据事实上已经展示给每个模型。

**经济学解释。** 信息实验发现，共同数值信息可以使不同居民的预期收敛，先验精度影响反应。但真实居民是否接触、理解或已经知道这些信号并不相同。现设计可能更接近“给所有人补了一堂宏观课之后作答”，而非自然条件下的问卷。这个解释有文献依据，尚未由本项目识别因果。

**先做一个可区分的E对照。**

1. P、本人原始Q8/Q9、历史摘要、模型、问卷保持相同。
2. 对照保留原E展示。
3. 候选把同一事实只清楚呈现一次，并分成原有背景、上次作答后新公布信息；完整证据留后台。保留同比/环比、来源及“公开不代表本人知道”的区别，不给应当如何更新的指令。
4. 去重键只限同一来源版本、指标、观察期、单位和值的确切重复；不同日期的同事件新闻、关税生效/暂停等后续更新全部保留，遵守用户“不删时间重复新闻”的要求。
5. 若需要进一步识别资料暴露，再对宏观统计表的展示强度作单独随机对照。此时它检验LLM的信息响应，暂不声称随机比例等于美国居民的真实注意分布。

**判据。** 先看原有信念离公共信号较远的群体是否减少不必要收缩，同时看真实变化者是否更能跟上、中心/W1是否改善。只产生统一中心平移，不足以支持恢复了个人机制。所有条件在新输入生成前冻结，不按本期真人稳定状态选择使用哪个版本。

**P需要补什么。** 若能从本人既往记录观察到稳定性、变化习惯和填答精度，可列为带记录数的历史状态；短历史保持未知。不由低数理、低收入直接推断“不读新闻”。财务决策分工Q46可能是金融信息接触的代理，不是购物责任或宏观注意力的实测值，须另验题意、跳题与条件关联后才决定是否采用。

## 二、用具体事件与家庭处境连接，检验是否遗漏了消息的个人含义

**数据观察。** 真正明显改变的受访者中，有不少模型基本不动；Q1/Q2等单项标签试验没有保持稳定收益。2025年3月实际回复已提到关税，却有价格上行和需求下行两种解释，不能把问题说成“完全没给关税新闻”。

**经济学解释。** 同一贸易事件可以同时提高进口成本、挤压家庭购买力，并影响工作与需求。个人经历可能决定先想到哪条渠道。对联邦政府的政策支持、美联储信任、一般乐观也不是同一变量。缺口可能在“哪个事实影响了这个家庭”，而非再给每个人加一句悲观/乐观。

**拟补E字段。** 经MCP回包和原始来源核对后，分开记录：

- 政策宣布、生效、暂停/撤销的日期与当时状态。
- 具体涉及的商品/投入/贸易对象；没有明细就标未知。
- 已发生的价格/就业事实，与官员预测、目标、承诺分别呈现。
- 公开消息的来源和日期；只给本次明确范围内的事实，不给“因此你的通胀预期必须升高”等结论。

先产出“旧E已有—新源实际新增—截点前可用”的差异清单。只有真实新增事实才进入下一候选；不能因换了官方源就把同一新闻当新增信息。

**拟联结P字段。** 优先本人截止前的就业状态转变、Q1财务变化、Q2家庭前景及有支持的价格暴露。Q1是滚动一年自评，其月间变化不是已测收入冲击；没有本人行业、商品购买或媒体接触就保持未知，不能按收入猜就业暴露。

**对照设计。** 第一步只增加经核验的新事件事实，其他输入相同。若有增量且同人暴露数据有支持，再比较保持P边际不变的真实联结与打乱联结。不要同时新增心理标签和解释指令；每步要能知道改的是事实、组织方式还是个人联结。

## 三、四类MCP数据各承担什么

- `ustr`：补贸易/关税事件的事实、时点和政策状态；事件数本身不等于消费者感受到的冲击。
- `google_trends`：补某时期公众关注变化；0—100是相对搜索兴趣，不是看过消息的人口比例。不能直接给每个Agent分配“注意力=80%”。
- `household_pulse`：若实际返回相应题目与分组，补家庭压力的群体背景。群体发生率不能冒充这个SCE家庭的实际困难；若服务只有全国均值，留在E，不回填个人P。
- `fred/UMCSENT`：补全国消费者情绪；不等于个人乐观、美联储信任或本人Q2。须核对题目构成、发布日期、修订及与通胀构念的重叠，宏观基线如比较也应获得相同可用信息。

所有源先验返回字段、覆盖、历史版本与许可。整月值可能含截点后信息，当前抓取日或缓存日期不能代替历史发布日期。后发资料可用于明示的A回顾背景，不能悄悄加入原冻结截止点或严格B输入。
