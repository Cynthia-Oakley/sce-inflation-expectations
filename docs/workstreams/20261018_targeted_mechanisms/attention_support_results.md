# 信息接触实验：数据依据、输入准备与预算

2026-10-18。用户已同意按计划推进。已完成外部数据检验、六个月库存核查、六组提示生成及72项官方引擎离线检查。**新增付费调用0；尚无本轮真实Sim回答，原主MAE仍为0.459pp，持续性基线0.239pp。**免费核查了两项MCP服务的目录及人群问卷能力，没有发送人口或问卷。

## 1. 外部调查给了什么依据

使用[Andre等公开复现包v1.0.1](https://zenodo.org/records/5838445)的2021年家庭样本，2,053人有六档新闻关注回答。排除专家；只用双方共有的年龄组、教育、收入档、地区。五折留出检验重复三个预设种子，所有编码与拟合只用训练折，没有调参。研究包本地使用按README的CC-BY-NC要求，不外发原记录。

结果：总体比例预测的对数损失1.6977，加入四类人口信息后1.6818，改善约**0.94%**；利用六档顺序的RPS改善约2.74%。辅助准确率27.52%→28.38%。三个种子方向一致，说明存在少量可预测差异，但不足以把某个人可靠地贴成高/低关注者，更不能换算成每月篇数。

四类冲击下，人口信息预测“成本/需求”四种联合选择的对数损失均未优于训练折总体分布；加入外部本人关注也没有使其优于总体分布。某个准确率局部上升并不抵消概率预测质量的下降。结论只限这组简单、固定的留出模型，不能证明经济联想没有真实作用。

供体支持也较弱：按四个人口字段精确交叉后，六个SCE候选月约13%—21%的设计加权人口，在关注供体中不足10人；按冲击再分，约80%—91%不足10人。因此本轮**不强制人口分配经济学流派或关注类型**，也不加入Andre原始记录。先直接检验信息量与统计展示是否会改变模型行为；以后迁移可保留概率与联合供体、放宽分组，并与打乱对照。

这些是外部2021样本内的留出预测，不是SCE同人匹配验证、年度心理分布或因果识别。SCE中的“低数理”也不能替代外部调查的新闻关注。

## 2. 六个月资料已经齐全

2020-09、2021-09、2022-06、2023-12、2024-10、2025-03，分别有166、182、219、148、163、351篇可分配的非头版经济新闻。原始窗口、粗筛标签、政策/统计、人口与真实历史均可复用，**无需新增新闻抓取或付费打标**。三篇共同头版沿用原选择；跨日期重复报道保留。

每月从原192人中按年龄×收入分层抽96人，收入缺失保留独立组；不根据本期答案或误差选人。调查权重除以两阶段入样概率，月份等权。样本加权有效人数约55—69，不把96人或两遍回答等同96/192个完全独立观察。不同月份不是固定同一96人的连续预测。

## 3. 六组究竟改变什么

每个人分别看到3／8／20篇新闻，搭配完整／精简统计，共六组。三篇共同头版不变，个人新闻分别0／5／17篇，沿用50%均匀＋50%相关抽取。一次抽17篇，前5篇就是原5篇，再按日期展示。不是给同一个会话轮流看六种材料。

完整组保留当前官方统计和六类12个月序列；精简组删去这两块及对应的统计发布日期标签，避免“表删了，信息仍在时间说明中”。新闻本身和公共政策摘要中的数字仍保留，所以它检验的是额外完整统计资料的作用，不是让居民看不到任何数字。

人口、本人真实上期Q8/Q9、更早历史均值/次数、合成CE支出和央行信心、政策事实、问卷与直接回答格式全部保持一致。**576份“8篇＋完整”对照与旧提示逐字一致，但本轮会同期重新生成回答**，以减少模型更新与机制变化混淆。没有同时加入心理、财务、频率、经济联想或新Event资料。

这是A路线回访者条件重建，使用真实上期信念；不是全国完整人口重建，也不是严格B预测。
