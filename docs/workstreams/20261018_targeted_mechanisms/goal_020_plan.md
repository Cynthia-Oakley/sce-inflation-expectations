# 持续目标：SCE模拟中位数MAE低于0.20个百分点

2026-10-18。来源：用户设置的持续目标；尚未达到。前一轮完成了人群差距与免费MCP目录，属于有实质进展的研究交付；本目标登记后的首项执行见下文。

## 成功的含义

- 延续现有主口径：个人Q9十档经冻结计分器派生均值，再取同一批受访者的加权中位数。模型和持续性基线使用相同月份、支持、权重及真值版本。
- 目标为MAE <0.20pp，并低于同支持持续性基线。全国官方首发指标、完整波次复算指标、所抽回访者指标分开报告，不能选择较有利的一套宣布达标。
- 当前十二期均已查看，仅作开发。还需要在另行预登记、未参与选择机制的时期核验；小样本或样本内最优权重不证明目标已实现。
- 区分原始LLM输出、程序行为层和宏观组合指标。程序校准可以研究，但不能把校准后的数值冒充原始LLM回答；微观分布、更新和群体误差继续保留。
- 不保证经济学机制或LLM一定能达到该误差。目标保持有效，所有支持、阴性结果与下一步判断均记录，不能为达标换目标、删月份或泄漏当期答案。

## 当前起点

十二期192人×两遍：同支持Q9中位数MAE约0.459，照抄本人上期0.239pp。完整波次参照0.376/0.213；全国首发目标另为0.361/0.233。现有简单总体加权的时间前推增量有限，历史个人均值改善部分RMSE但未同步改善中位数和分布。

## 第一项：过去资料能否提前判断“保持/改变”？

这一步检验可观察的更新规律，不再加入无数据依据的心理标签。使用已缓存2017—2025年连续SCE记录；不扫描原大工作簿、不调用API、不改评分和运行配置。

执行前固定：

1. 标签：本期官方公开微观派生Q9均值相对上期变化≤0.5pp；另报告原十档完全相同。标签是观察到的回答稳定，不等于没有注意或没有经济变化。
2. 特征只来自本人的严格更早记录：上期预期、概率宽度/填法、过去变化次数与稳定比例，再分别增加上期人口特征、上期财务/风险字段。本期Q1/Q2/答案不进特征。
3. 六个时间前推：分别用2017至上一年拟合，评价2020—2025当年；训练不使用该年或以后答案。历史资料为现在获得的回顾资料，不因此变成当时已公开的严格B输入。
4. 对照：此前月份总体稳定率、个人过去稳定率向总体收缩；候选三组正则逻辑回归：历史／历史+人口／历史+人口+处境。正则系数固定0.01，不按十二期效果调参。
5. 先看月等权Brier分数、对数损失、AUC和校准。再将概率用于零API的标量诊断：预测个人均值 = 上期值 + (1−预测稳定概率)×(原Sim−上期值)。它不生成新十档，也不是已完成新Simulation。
6. 本轮官方派生标签与项目冻结拟合标签可能有差异，量化并披露；十二期主误差仍用冻结真值评价。缺失特征显式处理、短历史不删除、不能只保留有利人群。
7. 结果若不具跨期预测力，不将其写入行为层；若有，仅作为下一项可区分对照的依据。学习到的是预测规律，不是因果注意力或真实学习率。

## 理论依据

信息刚性框架区分偶尔更新与每次小幅吸收，但概率取整也会产生表面稳定，不能从标签直接识别心理。[Coibion–Gorodnichenko](https://www.aeaweb.org/articles?id=10.1257/aer.20110306)；[ECB对黏性信息框架的说明](https://www.ecb.europa.eu/press/research-publications/resbull/2019/html/ecb.rb191204~8873a505ff.en.html)。

美国随机信息研究还发现住房身份与信息反应存在异质性，因此下一步应核验实际特征—反应关系，而非给所有人相同更新强度。[Piccolo–Gorodnichenko，NBER33595，2026-07修订摘要](https://www.nber.org/papers/w33595)。该研究用于现在的方法设计，不回填为2020年受访者可见信息，也不照搬效应系数。

个体不确定性与收入、教育、财务及当地失业有关，但不等于这些变量都应直接决定通胀方向。[Ben-David等，NBER25336](https://www.nber.org/papers/w25336)。本轮优先检验本人历史，P与处境块分开衡量增量。
