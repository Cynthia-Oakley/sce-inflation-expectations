# 新闻量与宏观资料展示：六期实验结果

2026-10-19。A路线回访家庭条件历史重建；六个已参与开发的月份，不是独立验证。**发现了较明确的人群分布改善，也发现其代价：个人判断更有持续性，但容易漏掉真人实际发生的变化。没有配置通过预先登记的整体筛选，不升级默认方案。**

## 1. 实际做了什么

2020-09、2021-09、2022-06、2023-12、2024-10、2025-03，每月按年龄×收入从原192人中抽96人；新闻3／8／20篇，分别搭配完整／精简统计，共六组，各生成两遍。每人三篇共同头版相同，个人新闻分别0／5／17篇，沿用50%均匀＋50%相关抽取。8篇完整组的576份提示与原配置逐字一致，但回答同期重跑。

精简组仅删额外官方统计、12个月序列及对应统计发布时间标签，保留相同的新闻、政策、人口、本人真实上期Q8/Q9、更早历史、合成CE和央行信心。它没有消除新闻中的数字、模型预训练知识或共同政策影响。完整/精简是整块展示对照，不能进一步归因于某一个CPI数或某一张表。

使用DeepSeek官方`deepseek-flash`，官方当前标示Flash-1017；温度0.5、关闭思考、最多1024输出token、无自动重试。72实跑单元、6912次请求全部完成；6904份格式有效，8份无效保留，无接口错误。所有组和两遍共同可评分567人月，涉及558名不同受访者；没有补抽替代无效回答。

真实调用从北京时间10月18日23:29至19日00:05，约36.94分钟；统一计分143.97秒，聚合与区间计算约1.27秒。费用按用量和预留高峰单价估算**$6.559922／上限$30**，不是独立账单；实际优惠/缓存/非高峰可能更低。未动用平台$70，没有新增付费MCP。5,265种新增概率向量只计分一次；216项独立聚合对账一致。

## 2. 六组的群体中位数误差

主指标：先由十档概率拟合每人的密度均值，再取跨人设计加权中位数，计算与相同真人的MAE；月份和生成重复等权。采用固定近似计分器，不冒称精确纽约联储官方拟合。

- 同期参照：8篇＋完整统计，**0.355pp**。
- 3篇＋完整：0.406；20篇＋完整：0.451。
- 3篇＋精简：**0.303**；8篇＋精简：0.392；20篇＋精简：0.376。
- 相同家庭、相同权重的上期照抄：**0.338**。

3篇精简组的六期平均最低，但只在2／6个月优于同期参照，未过“至少4期不恶化”等筛选。去掉2025-03后，平均误差反而比参照高0.058pp；两遍自身MAE分别0.373／0.234，也说明这项局部收益不够稳定。不能据0.303宣布跨时期达到0.3，更没有达到独立0.20目标。

例如2025-03，参照误差0.864→3篇精简0.264；但2021-09由0.235→0.461，2022-06由0.374→0.425。好坏时期都必须保留。等权敏感性下，参照0.444、3篇精简0.431，收益更小；不换权重挑结论。本轮六期96人与原十二期主结果0.459支持不同，不能当作十二期版本从0.459直接降到0.303。

## 3. 最清楚的发现来自微观分布

只比较**8篇完整与8篇精简**，新闻内容相同，能较清楚地观察宏观展示块的作用：

- 跨人W1距离：**2.457→1.754pp**，约减少28.6%，六个月均改善。
- 个人均值MAE：**3.224→2.895pp**。
- 人际IQR：**2.263→3.679pp**，更接近真人4.732，但仍偏窄。
- 群体中位数MAE：**0.355→0.392pp**，反而变差。

W1改善在教育、数理、收入、地区的大部分可报告组均同向，不能据此断言恢复了某个人的真实心理。分组至少3人单元才报告；缺失收入和稀疏格仅描述。

在三个新闻数量下，精简相对完整的W1均改善，配对家庭重抽区间都在0以下；例如8篇差值−0.704，95%区间约[−0.820,−0.443]。三个数量等权平均，W1改善0.764，个人MAE改善0.368；中位数MAE差值约−0.047，区间[−0.309,+0.212]，没有稳定方向。

这些区间把已选六个月固定，对同一家庭配对重抽、保留两遍及重复月份；多个对照未作多重检验校正。它们不能被解读为跨时期有效或确认性显著结论。

## 4. 为什么更有差异，却没有解决总体误差

8篇精简相对8篇完整，真人保持者被模型错误改动的比例从**60.9%降至46.2%**，但真人实际改变者被模型漏掉的比例从**35.1%升至55.5%**。这两个方向在六个月都成立。变化分布W1由1.455变成1.541，并未同步改善。

直观地说：完整公共统计更容易把不同人的回答拉到共同判断附近；减少这块资料后，更多个人差异和原有信念被保留下来。但有些月份真人确实在更新，减少信息也可能使模型反应不足。因此，**所有人都看完整统计**和**所有人都删统计**都过于统一。

这是本轮受控模型对照支持的解释，尚未识别真人是否实际阅读这些资料。展示长度、数字和发布时间元数据同时变化，且模型仍能根据日期调用预训练知识；不能把W1改善全归为某一个认知过程。

人类调查的理论依据与该方向一致：[Coibion等的随机信息实验](https://www.nber.org/papers/w25482)发现不同沟通形式引发不同幅度的预期修订；[Armantier等信息实验](https://www.newyorkfed.org/medialibrary/media/research/staff_reports/sr543.pdf)强调信号与先验精度、响应异质性。它们支持研究信息如何被吸收，不提供本项目新闻篇数或个人更新率的现成参数，也不保证信息越少就越像真人。

## 5. 新闻篇数还不是主要杠杆

完整统计下，3篇／20篇均未优于8篇。把两种统计展示等权平均，3相对8的中心差−0.019，20相对8为+0.040，区间均跨0；W1变化也较小、区间跨0。当前没有证据支持单纯加到20篇就能改善拟合，也没有依据据此给每个人硬分阅读档位。

外部Andre调查已在运行前做留出检查：共同人口字段只给新闻关注带来很小预测收益，事件渠道未优于总体概率。因此暂不依据学历/收入硬贴“高关注”或某种经济学流派。Household Pulse、USTR/Trends增量及平台模型桥接继续后置分开处理，不与本轮混为一个成功机制。

## 6. 下一步如何收束

1. 保留本批及原默认方案；没有配置通过整体筛选，不自动扩大独立验证，不在同六个月反复调3/8/20篇。
2. 将“个人信息吸收/更新的差异”作为下一项问题。先用已有两种视图回答和严格过去的个人更新记录，做零API诊断：哪些人在完整资料下获益，哪些人只被过度改动。不能用本期答案决定给他哪种信息。
3. 如果按过去资料得到的规则确有可迁移收益，先冻结，再登记另外四个月；区分这是一项合成机制，而非已观测本人阅读量。新的付费调用仍另报范围与预算。
4. 正式论文同时报告宏观门槛、W1/人际差异、变化误差及信息展示的取舍；不把本轮分布改善写成最终预测成功。
