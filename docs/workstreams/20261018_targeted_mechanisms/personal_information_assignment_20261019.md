# 根据人口特征分配信息：证据与实施边界

2026-10-19。按用户最新澄清，目标是在同一群体中表现不同人的信息接触广度，以及购物、驾驶等生活角色带来的接触内容差异。本次核查已有结果和一手文献，**新增模拟/API调用为0，没有更改运行配置或分配真实家庭的新标签**。

## 1. 先把三类问题分开

1. **接触多少：**一个人通常关注多少经济消息。优先依据本人新闻关注回答；没有时，才考虑外部调查中的条件概率。
2. **接触什么：**购物、驾驶、租房、照顾子女等活动，使人接触不同价格。生活角色主要影响信息内容和重复接触，不意味着知道该类别完整的官方统计。
3. **如何理解：**数理和金融知识关系到百分比、概率、政策等信息的处理。学历和认知题可用于研究理解及表达，不能直接当作新闻阅读量。

一个人可以不读经济新闻，却经常买菜；也可以经常读财经新闻，却不负责采购。当前没有资料支持把三者压成一个统一的“高关注/低关注”标签。

## 2. 文献能支持什么

### 购物角色：有较直接的机制依据

D’Acunto、Malmendier、Weber（2021），[Gender roles produce divergent economic expectations](https://eml.berkeley.edu/~ulrike/Papers/pnas202008534_Published_Paper.pdf)，尤其第1—2页及SCE延伸部分：同一家庭的购物分工与预期差异有关，个人购物体验通过当前物价感知联系未来预期；共同购物家庭的性别差距更小。角色未随机指派，因此不能直接把观察关系当成每个人的因果系数。

这支持优先研究“谁实际接触哪类价格”，不支持女性必购物、就业者必开车。主购物者也不是专家，不宜据此额外提供整套食品CPI数据表。可优先调整有来源的食品价格信息的出现和细分程度；真实购物角色与本人收据缺失时，必须标合成/未知。

### 新闻关注：经济决策相关性值得研究，但不是现成的分配比例

[Pew 2009年经济新闻调查](https://www.pewresearch.org/politics/2009/02/19/most-feel-a-personal-stake-in-tracking-economic-news/)发现，认为新闻与本人财务决策有关的人更关注经济新闻，同时关注与背景知识、收入存在关联。这是危机期横截面自报关联，不能推出财务决策负责人一定多读新闻，更不能用于直接标定2020—2025年的3篇或40篇。

[Chahrour、Shapiro、Wilson，2025修订稿](https://www.frbsf.org/research-and-insights/publications/working-papers/2024/10/news-selection-and-household-inflation-expectations/)研究媒体选题与居民接收到的涨价/降价新闻，说明内容选择本身会影响预期。它不提供本项目按学历分配阅读篇数的参数。

以上为理论/经验依据，均不是已经识别的SCE本人信息接触记录；文献核查日2026-10-19。

## 3. 已有数据给出的约束

### 不能直接按学历分新闻量

此前使用Andre等[公开复现包v1.0.1](https://zenodo.org/records/5838445)的2,053名家庭，年龄、教育、收入、地区联合预测六档经济新闻关注。固定模型五折留出、三个种子，对数损失从1.6977降到1.6818，相对改善约0.94%。这不是R²，也不是“只有1%的人受人口特征影响”；它表明本次共享字段的预测增量有限。

该问题问是否通常关注全国经济新闻，不是每月阅读篇数。因此学历只能作为弱概率信息，不能规定“本科每月40篇，高中每月3篇”。详[支持检验](attention_support_results.md)。

### 旧模拟显示展示方式重要，尚未识别人类阅读习惯

六期实验中，同为8篇新闻，删除额外完整统计后，高数理组W1从2.076降至1.266pp，低数理组从3.257降至2.749pp；三个学历组也均改善。这些是既有聚合的描述性读数，分组并非随机形成，不是正式交互检验，不能据此给个人选择误差最低的输入。

它说明问题涉及不同人接触怎样的公共资料，不能简单归结为低学历看得太多。旧3/8/20篇实验每个组内部篇数一致，**尚未检验同一群体中不同人接触不同篇数**。

权威来源：`outputs/sce_information_exposure_readout_20261019_v1/summary.json`的`group_metrics`；本次仅读取既有统计，没有重新计分或生成答案。

### 本人的生活角色仍有缺口

已有SCE历史覆盖核查的192个人月中，Q46家庭财务决策分工181个有效；它问财务决策，不能改称主要买菜者，也不直接测量经济新闻阅读。该覆盖数不代表最新六期567人月均已核查。

目前没有已核验可用于这些SCE个体的购物责任、驾驶频率字段。CE现有家庭支出/记录日数不能判断哪位成员采购或驾驶；家庭有汽油支出也不证明受访者本人开车。不得将缺失角色静默赋值。详[字段覆盖](../20261014_mechanism/coverage_age_results_20261015.md)和[70个月人口关联](../20261014_mechanism/population_association_results_20261015.md)。

## 4. 建议怎样落实，先不运行

1. **新闻量：**先复用外部关注的条件概率，保留较大组内随机差异，个人基础关注倾向跨月保留。精确篇数只是实验档位；概率迁移和篇数换算分别登记，不冒充实际阅读量。现有数据不支持把Q46与高阅读量直接绑定。
2. **生活价格：**优先核实购物/驾驶角色的联合资料及可共享字段。有实测角色则按角色改变有来源的信息内容；没有则保留未知，外部概率合成另立对照，不能把CE合成家庭当成本人生活史。年龄、家庭构成、细收入可改善生活阶段匹配，现有证据不支持它们唯一决定角色。
3. **理解与表达：**教育、数理、金融知识另作机制问题。对照中不要因低数理而故意给错数据或预设高通胀；既有认知注入未形成稳定升级，不作为本轮既定有效机制。
4. **先用已有答案预检：**3/8/20档已有回答可供离线组合诊断；固定宏观展示、尽量保持平均新闻量，并与相同数量分布的随机分配比较。规则必须由过去资料/外部关注决定，不用本期答案挑档。该诊断是事后开发，不能称新LLM回答或独立验证；30—40篇没有旧回答可复用，不能伪造。
5. **再判断是否新模拟：**只有明确分配依据和可辨识的对照后，再准备真实输入和单独预算。不同时叠加新闻量、购物角色、驾驶角色、认知指导，以免无法解释结果。

当前可交付的是有依据的分配方案，而不是已经证实能降低MAE的新配置。预期检验包括群体中心、跨人W1、分组误差及真实更新/保持的表现，不以单纯扩大方差为成功。

## 5. A/B信息边界

A线回顾重建可使用后发外部资料作明确标记的结构性合成假设。B线只使用截止前已发布的人口资料、外部调查和新闻版本；不能把历史记录月份早于目标月当作当时已公开。个人关注或生活角色不由当期SCE通胀答案、误差或未来记录推断。
