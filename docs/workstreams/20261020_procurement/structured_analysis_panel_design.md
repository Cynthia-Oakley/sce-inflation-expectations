# 自动结构化评价与实验面板：设计草案

2026-10-20。状态：**框架设计，尚未实现自动入口或交互面板**。本轮未新增模拟、未改变参考配置、未重新计算旧成绩。目标是让每轮实验都回答：总体差多少，差在哪个月和哪类人，概率与更新哪里失真，结论能否跨配置比较。

## 1. 一个统一入口，两类评价

在现有评分缓存之后增加共用分析层，保留“固定基础分析＋该机制专用分析”。新面板不另建Simulation引擎，不改官方Core，不重写W1/分位数，不替换冻结Q9计分器。

- 基础分析：总体、月份、人口、个人先验、概率结构、缺失及重复波动，每轮自动生成。
- 专用分析：新闻数量/主题、采购角色/可见价格、Q1/Q2或心理字段等，只根据本批实际输入元数据启用。没有某字段时标记未提供，不当作零、不从输出理由猜输入。
- 原始模拟、程序校准/宏观加权组合分别展示。组合参数需有独立的拟权期/验证期记录，不能每轮在评价期自动选最优权重。

## 2. 面板顶栏：先说明这批是什么

始终显示研究线A/B、任务对象（回访者条件模拟/全波次/合成人口）、月份、信息截止及版本、模型/供应商/返回标识、温度、模板/后处理版本、各组规模、实际调用/成本与运行状态。

比较时核查人口、权重、月份、新闻、统计信息块、个人历史、问卷、格式示例和归一化规则，标注：

1. 同模型、单项机制变化；
2. 同输入、仅模型/采样参数变化；
3. 多项配置变化，只能描述整套配置差异。

仅缺来源元数据时写“无法确认”，不能自动归入同输入。同一温度并不保证不同模型输出方差相同。统计分数一致不能证明信息边界合规。

## 3. 六个固定页面

### 页面一：总体结果

真人、所有实验组、同支持照抄本人上期及合适历史基线并列。Q8与Q9分开切换；宏观组合另列。

- 中心MAE、RMSE及带符号偏差；不只显示绝对误差。
- 跨人W1、去中心后的W1、跨人IQR与真人IQR。
- 个人误差/秩相关只在同一真人一对一对应时启用；Normal供体或纯合成人口不能凭编号做逐人评价。
- 每项注明支持人数、月份数、权重与评分版本。不能跨不同支持或评分版本自动排榜。

### 页面二：时间与环境

逐月真人/模型/基线中心、带符号偏差、分布W1和相对基线误差；自动列出贡献最大月份，以及逐一删月的敏感性。

同时显示该月实际提供了哪些信息：总体CPI、食品、汽油/能源、趋势、新闻数量和主题、政策与可见价格；给出参考期、发布时点和“未提供”状态。例如可直接看到2021-09食品3.0%与总体5.3%的差异，以及哪组提示保留了各信号。

连续6/12个月滚动指标仅在真实连续月份齐全时计算。六个非连续开发月不能当作连续半年。删月仅用于定位问题，不能自动删除坏月份重报成绩。

### 页面三：人口结构

候选基础网格沿用“高中及以下/部分大学/大学及以上 × 在职/未在职”六格；未知另池。在职包含employed/on_leave，“未在职”不是BLS失业口径。六格用于稳定覆盖和将来抽样，不认定其解释力最强，也不因此更改Core/Normal。

年龄、收入、数理、四大地区、住房、原始就业类别作独立切片。当前每月96人，不默认展开50州热图或把全部维度交叉。点击一个格，联动显示：

- 人数/ESS/最大权重占比、缺失和覆盖月份；
- 真人、模型、照抄的组中位数、偏差与W1；
- 组内分布/CDF、P10/P25/P50/P75/P90及高低端缺口；
- 组内与组间方差、先验与本期变化。

按现有计量函数进行组内/组间方差分解，只分解方差，不把各格的中位数MAE相加当作总体MAE。分组重叠时也不能把误差相加称贡献。

### 页面四：个人信念与更新

单独设置“上期预期<2%、2—4%、4—8%、≥8% × 高/低数理”的八格诊断，必要时仅展开单一维度。这是状态网格，不与六个人口格继续全交叉；阈值承接已有诊断、标为开发期选择，未来实验前固定。

显示原有信念、本期真人/模型条件均值和分位数、变化分布W1、变化方向及幅度、历史记录数/常态预期可用性。没有上期记录的新参与者单列，不能填零或因缺先验从所有指标中消失。

- 前置特征分组：上期信念、画像、合成角色等，可用于描述输入机制。
- 事后诊断分组：真人本期上调/稳定/下调，只用于评价；页面明确标注“用了本期真值”，不可用于分配输入。
- 控制变量诊断可复用WLS：月份、本人先验、主要P；输出支持、秩/列数与删月/极端值敏感性。小样本或类别过多时不解释高维系数。系数不自动变成校准值或人的结构参数。

### 页面五：回答结构与异质性

把三件事清楚分开：

1. 跨人的预期分布：宽度、尾部与秩关系；
2. 每个人十档概率：非零档数、最大概率、通缩概率/全零通缩比例、概率TV距离、密度内部IQR及Q8/Q9差异；
3. 同一输入重复生成：人内波动与较稳定的人际差别。

采用同一评分版本；原始概率与派生概率并存。生成遍数不当作新增人，Normal复制不增加独立信息。两遍只能给有限的波动诊断；噪声扣除后的方差估计若为负，保留并解释，不截为零。不能把扩大随机性自动标为异质性改善。

### 页面六：输入、质量与结论边界

按组/月显示：计划槽、尝试、回包、结构可解析、原概率合法、归一化后可用、密度可计分、Q8可用、共同支持、缺失/归一化比例和费用。

对跨组/跨批比较，同时保留主共同支持和可选的支持敏感性；说明基线为何随支持变化。原始合法支持的结果不是归一化效果的因果估计。

输入字段标明本人实测/外部合成/公开环境/缺失/未发送，附数据来源、版本与时点。可比较的配置差异先由元数据和信息块哈希判断，不用LLM对理由文字打分。未核验历史版本、知识截止、当期宏观约束、开发/验证期身份须可见。

## 4. 稀疏格与统计纪律

第一版建议的展示门槛需在新分析配置中固定：

- n<10：只显示覆盖与缺口，不渲染分布判断；
- 10≤n<20：灰色探索展示；
- n≥20且ESS≥10：正常色阶，仍附样本信息；权重集中或覆盖不完整时提示。

这是展示门槛，不是统计功效证明。旧契约/专用分析使用过20、10、8等不同门槛，旧结果和manifest保留原规则；新面板不能静默覆盖旧成绩。缺月/未知/不适用均不填零。

基础分组固定，探索性交叉单独标记。常规自动区间只用于预先指定的主比较，不为数十格自动做显著性筛选或挑赢家。按人聚类保留其跨月与重复结构；固定开发月份的区间不能推广为时间外验证。时间块方法只在满足真实连续月份和既定条件时使用。

## 5. 工程结构：统一数据，不统一重写所有旧脚本

建议建立只读的规范记录，一条是“实验×月×人×组×生成遍数”：

- 实验/输入/源码/评分/后处理版本与信息块摘要；
- 本地匿名身份、画像、抽样概率和设计权重；
- 先验来源（真人上期/模型递推/合成初始化）、可用历史摘要；
- 本期Q8/Q9原答、派生概率、已缓存评分与质量状态；
- 输入接触元数据及费用/时间；真值仍仅在评价层联结。

本地规范记录可含受控匿名联结键；发布面板只嵌入聚合，不含人口记录或完整回复。未来B真值尚未公开时仅展示封存预测/输入和技术状态；真值公开后追加新评价版本。

共用统计输出使用长表：实验、问题、月份、分组、组别、遍数、指标、数值、n/ESS/覆盖、支持版本。复用现有metrics、cognition/frozen_trial、response_gap_controls、temperature、stratification与procurement_gap等能力。现有旧入口不统一重构；为旧案例结构写薄适配层。

流程：

`冻结实验与分析配置 → 真实模拟 → 结束/停止后封存 → 原评分缓存 → 规范记录 → 共用分析 → 聚合JSON/长表 → 面板与摘要`

运行中只显示进度、技术状态与费用；不一边查看真值一边调整本轮提示。分析和页面渲染完全离线，不使用Simulation或Chat额度。输入/评分/分析配置哈希不变时复用缓存，换筛选或画图不重新拟合Q9。

## 6. 面板形态与自动摘要

建议是本地HTML，聚合数据内嵌，浏览器直接打开即可，不依赖服务器、登录或file://跨文件请求。建议未来稳定入口`docs/reports/experiment_panel/index.html`，**该路径目前未创建**；每个实验保留不可覆盖的结果快照。

顶部选择实验、对照、Q8/Q9、月份/时期和分组；默认同时展示全部预定月份。点击月或网格联动，随时显示当前筛选支持。导出PNG/聚合CSV，不导出个人记录。

固定模板自动产生三类事实摘要：差距最集中的月份、有足够支持且偏差较大的组、结果对重复/删月/支持是否敏感。摘要链接到具体指标，不自动写“年龄造成”“心理机制无效”等因果解释。理由文字只作额外人工研究线索。

## 7. 最小落地顺序与验收

1. **统一缓存适配与统计**：先接现有12期参考、六期新闻量、六期Qwen采购，确定字段缺失/版本兼容与支持；建立人口六格、单变量切片和先验四档。暂不接所有旧实验。
2. **生成首版六页视图**：先覆盖比较资格、总体/逐月、网格、更新、概率结构与质量；自动摘要和筛选共享同一统计，不在前端另算一套口径。
3. **接新实验完成后的自动分析**：通过新包装入口接评价结果，不破坏旧冻结runner；停止/部分完成也可出明确标注的描述报告，不伪称完整成功。
4. **逐渐加入机制专用页面**：用小适配器读取新闻量、角色/价格等暴露元数据；宏观组合使用已冻结权重与验证安排，不自动训练到最佳误差。

验收以已知实例为准：应自动呈现Qwen采购的2021-09主要退步、553/552支持差异和低预期端改善；新闻随机组与匹配组结论不能混淆；12期与6期不按原均值直接排名。重算0 API，旧源码/manifest不动，缺失不补零，改变展示不重新拟合密度。

当前已有总体/分月、W1/分位数、更新、回归、重复方差和网格支持等多数计算能力；缺的是共同数据适配、分析配置、自动编排和统一交互展示。这个工程方向能减少逐轮另写报告脚本的时间，但不能保证模型误差因此下降。
