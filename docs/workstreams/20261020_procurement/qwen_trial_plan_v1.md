# Qwen采购角色—可见价格实验

2026-10-20。输入与离线引擎检查完成，**尚未新增真实模型调用，等待本批数据范围和预算批准**。这是新的机制对照，不重启旧Qwen迁移包，也没有升级默认模型。

## 研究问题与三组

研究家庭采购分工是否通过改变可见价格信息，使模拟回答更接近真人。已有理论、ATUS迁移和BLS分类数据见[输入设计](README.md)。

- 共同背景：每人看到相同的在家食品总体价格信息。
- 角色匹配：按年龄、住所人数和有无未成年人迁移ATUS采购责任概率，抽取合成角色，再分配食品类别信息。
- 同月打乱：交换完整的“角色＋类别信息”包，控制权重下的信息量及类别比例，重新生成接收者的信息发布时间标签。

主要比较角色匹配相对同月打乱的跨人Q9派生预期分布W1。共同背景帮助判断增加食品信息本身的作用。打乱是在相邻权重块内受限交换，不是完全随机；角色不是SCE本人实测。角色到0/1/3/6/6条信息是实验假设，全国分类CPI不是本人收据。

三组统一移除完整宏观表和十二期趋势表，使用同样的8篇新闻、本人真实上期Q8/Q9及更早摘要、CE支出和美联储信心。不能将旧完整统计表下的DeepSeek回答当作本轮共同背景对照。

## 评价约定

主指标：设计调查权重下，匹配减打乱的跨人W1；按同人配对重抽样，跨月身份和重复放在一起。月份固定，区间不能证明对所有时期有效。

开发信号要求：三组原答合法/可计分比例均达到99%，主W1差值区间上界低于0，匹配组更新分布W1点值不劣于打乱。任一条件不满足，仍保留描述结果，不称机制通过。无论结果如何均不自动升级默认；下一步仍需独立月份和额外分配种子。

同时报告总体中心MAE/RMSE、逐月和删一月结果、跨人IQR、个人密度内宽度、变化分布、秩相关、保持比例和重复噪声。按年龄、学历、数理、地区及家庭构成作描述，标明稀疏格。真人、三组和照抄本人上期使用相同月份、人和权重。失败原答保留、不归一化；合法Q8独立保留。宏观组合拟权另立训练/验证安排，本轮不在这六期拟权后称独立成绩。
