# 实验面板 v1 改造方案

2026-10-20。依据：用户对辨色、图数结合、重点与实验分区的反馈，以及[统计审阅](experiment_panel_review_20261020.md)。**本文件为整合方案，尚未改造页面或重算成绩。**

## 1. 阅读顺序：先找实验，再看结论，需要时进入诊断

稳定入口继续使用`docs/reports/experiment_panel/index.html`，本地直接打开。将当前六区长页改为“实验目录＋单实验分页”；原六区的统计能力继续保留。

### 实验目录

- 顶部固定“当前参考实验”和“最近完成实验”，各列名称、研究问题、模型、月份数、每月人数、生成遍数及结果说明。两者支持不同，不直接比较原始MAE。
- 实验按研究用途分区：技术检查、小样机制对照、扩大验证、独立验证、未来预测封存；历史或不兼容版本另列。
- 同一机制放入同一组，例如“新闻接触量→统一条数对照→差异化分配对照→独立验证（若已完成）”。只链接实际存在的实验，不能把计划显示为已执行。
- 研究用途由协议/人工登记确定，不能按人数自动判定；小样、大样规模另显示。扩大样本不自动成为独立验证。
- 每条显示可分别筛选的“运行状态”和“证据阶段”：完成/部分完成/停止；开发/独立验证/待复核。未分类缓存归入“待登记”，不猜模型与研究条件。
- 支持按机制、模型、月份、规模和状态查找；中文简称优先，长ID和路径放详情。未运行、阴性或技术失败记录保留。

### 单实验的五个页签

1. **结果概览**：这轮改了什么，整体表现怎样，最值得注意的三项发现。
2. **月份与人群**：误差集中在哪个月、哪类家庭，点击后看条件分布。
3. **先验与回答结构**：旧信念如何保留、谁改变了判断、十档概率与重复波动怎样失真。
4. **输入与配置**：各组究竟收到了哪些人口、历史、新闻、价格与政策信息。
5. **质量与复现**：缺失、归一化、支持、费用、版本与复算入口。

目录到详情保留返回位置；页签/实验选择可用本地URL片段保存。每次只显示所选页签，不把全部图表一次堆在长页。

## 2. 颜色与辨识：颜色、线型和符号同时区分

统一白色或浅暖色底，正文深色。图表建议固定角色：

- 真人：黑色`#202733`，实线、方形标记。
- 参考配置/所选对照：蓝色`#0072B2`，实线、圆形标记。
- 候选配置：橙色`#D55E00`，实线、三角标记。
- 持续性基线：中灰`#6B7280`，虚线、菱形标记。

这些是下一版候选颜色，需实际页面检查；不能仅凭色值宣布所有人都能辨识。同一角色跨页保持一致，图例可点选，线尾尽可能直接标名称。默认比较真人、参考、一个候选及基线；更多实验组通过切换/小图并列，避免十条线挤在一张图。

“组别颜色”和“误差含义”分开：带符号偏差用以零为中心的发散色阶；W1等非负距离用单向色阶。改善同时写明数值、方向与指标名，不靠红绿判断。不能因单一指标下降就把整轮实验染为“成功”。

中文按既有偏好采用楷体，英文与数字Times New Roman；表格数字适当对齐。轴、单位、图例和图题均显示；选中状态、灰阶打印和窄窗口也要能辨认。

## 3. 概览只保留四项主读数、两张图和三条发现

固定顶栏：研究任务（A回访者条件重建/B等）、具体月份、人数×遍数、模型/温度、比较组、支持口径。截止规则和输入版本可展开。先说明评价对象，再解释成绩。

四项主读数：

1. **群体中位数MAE**：模型值、同支持基线值和两者差额。
2. **跨人分布W1**：模型与真人的完整分布距离，并列基线。
3. **跨人分歧宽度**：模型与真人IQR并排显示，不把接近真人IQR独立当作成功。
4. **更新分布W1**：相对上期的变化分布差多少。

两张主图：

- **逐月中心**：真人/参考/候选/基线；显示完整YYYY-MM、单位%，非连续月份不暗示中间月份有模拟。
- **逐月误差差额**：候选MAE减对照MAE，以零线展示哪些月份改善、哪些退步；原始误差可悬停或展开明细。

最多三条自动事实，每条可点开证据，例如“中心误差退步主要集中在2021-09”“低先验端更接近真人，但高端仍被压缩”“匹配与打乱差异小，不能认定身份匹配有效”。按固定规则计算，不让LLM生成因果结论，也不把事后发现变成输入规则。

中心RMSE、带符号中心偏差、个人MAE、秩相关等放“更多指标”，默认不与四项主读数争夺注意力。个人绝对误差中位数使用完整名称。Q8与Q9独立视图，所选题目对所有适用图表和支持生效；暂不支持的区域明确标注，不继续展示另一题的数据。

宏观加权组合独立开关，仅在有已登记的拟权期、验证期和冻结权重时启用；显示系数和信息来源。原始模拟成绩始终可见，不在当前评价月自动寻找最佳权重。

## 4. 用图回答具体诊断问题

### 月份与人群

- 默认学历×是否在职六格；年龄、收入、数理、地区和住房作独立切片。
- 六格图按所选指标显示带符号偏差或W1，附数值、n与稀疏标记；颜色范围在同一比较内固定，避免各组自动缩放掩盖差距。
- 点击格子/月份，联动出现真人、模型、基线的加权CDF和横向分位区间：P10—P90外段、P25—P75内段、中位数标记。它是明确的加权分位图，不冒称Tukey箱线图；若现有聚合不足，先补聚合再画。
- 分组指标按月按遍计算后汇总，覆盖月份与权重信息随筛选显示；跨月混合分布如需展示，另标为混合分布。
- 组内/组间方差放次级诊断，不能把分组中位数MAE相加作为总体误差贡献。

### 先验与回答结构

- 先验四档用真人/模型/先验条件均值点线图，直观看到低端抬高、高端压缩和旧信念保留。
- 真人人群“上调/稳定/下调”用变化幅度对比图，持续标注“事后真值分组，不能用于输入分配”。
- 概率形状用非零档数、最大档概率及通缩概率的分布图；与跨人的预期分布分开。
- 重复波动用规范的人内/人际方差图，显示真实遍数和局限；区间只有在既定方法可用时显示，不能给每个稀疏格自动做显著性排名。

### 输入、质量与复现

- 输入页用组间差异清单：哪些内容相同、哪些变了、哪些未接入。按月显示CPI/食品/能源、趋势、新闻数量/主题、政策与本人历史来源及发布时间。后续机制信息采用插件，不依赖理由文本反推输入。
- 质量页用漏斗和月×组缺失图，明细表折叠；费用区分已报告、估计、失败预留和未接入。
- 每张图配简短解释、准确数值悬停和可展开明细，导出聚合CSV/图片。表格用于核数，图用于比较；不能只把原表格改成一堆柱子。

## 5. 统计修正是首个交付的前置条件

沿用审阅中四项必须修正：

1. 群体中心MAE、个人MAE和个人绝对误差中位数分开，补RMSE/偏差。
2. 所选臂与重复使用明确共同支持；每月每遍先算，再汇总；各臂可用支持只作另列敏感性。
3. 以有效个人单位计算ESS，区分独立人数、个人月和回答条数；稀疏格按月显示覆盖，不用全年人数掩盖月内缺口。
4. 规范重复方差分解，删除与实际读数冲突的固定说明。

输入/评分/后处理元数据不足时写“比较条件未核实”。Q9失败不连带丢弃合法Q8。继承旧实验的评分与结果定义，不静默重写旧manifest。

## 6. 工程安排：先把三个代表实验接正确，再扩展

保留已有adapter、统计插件和渲染模块，统计只在Python公共层计算，前端读聚合、切换和画图；不在前端另算一套成绩。

- 实验目录用薄登记表补用途、机制组、父批次、中文名和有效版本；只补面板元数据，不改冻结实验。
- 优先接十二期参考、六期固定/匹配/随机新闻量、六期Qwen采购；早期新闻条数×统计详略六臂另外命名，避免混淆。
- 本地逐人中间文件移至被忽略的outputs目录；reports仅存允许发布的聚合与展示。面板生成不覆盖不可变实验快照，稳定首页指向当前展示版本。
- 新实验先评分，结束/停止后再离线汇总与更新目录；运行中只看技术进度与费用，不能边看真值边调本轮参数。
- 继续支持本地自包含HTML，不引入服务器、账户或新的模拟引擎；此次改造不需要付费API。

## 7. 分三次交付

**第一批：统计正确＋找得到。** 修正四项统计问题、补实验目录/阶段登记/比较条件、核三个代表实验的冻结成绩。完成后才更新正式成绩显示。

**第二批：看得懂重点。** 新配色与符号、概览四指标/两图/三发现、分页导航、清晰题目切换、折叠明细和中文名。

**第三批：定位得到问题。** 月份/人群下钻、条件分布、输入暴露、质量漏斗、导出与实验结束后的一条离线更新入口。

每批检查实际页面，避免先把所有图表开发完再集中改版。第一版不同时扩展全部旧契约、不增加人口网格维度、不自动重跑模拟。

## 8. 验收从用户能否完成任务出发

- 打开首页能找到当前参考、最新实验，以及某个机制由小试到扩验的实际历史。
- 进入实验后，首屏看清这轮改了什么、中心/分布/分歧/更新怎样；图例无需靠深蓝深绿辨色。
- 通过月份和人群选择，能解释2021-09的差距及低先验/高先验端的不同表现，并明确样本是否足够。
- 三个代表实验的主读数/支持与原冻结报告对齐；换颜色、切页、导出不改变成绩。
- 稀疏、缺失、未核实比较、开发期与独立验证有明显区分；任何图不会把随机性增加自动说成微观结构改善。

本方案融合用户阅读需求与统计审阅，替代“把所有统计都放在一页”的呈现方式；不改变项目的研究边界或参考配置。

## 9. 后端评价与改造要求

2026-10-20补充。以下是代码层面的判断与后续要求，尚未实施。

### 当前程度

- **自动化：已能批量构建，尚是半自动。** CLI可扫描缓存、转换、汇总、生成HTML，原始Q9分数直接复用；但未接实验结束后的步骤，也没有按批次指纹复用分析结果，每次全量读取并计算。运行中、停止和完成的发布规则还不完整。
- **兼容性：支持一类现有缓存，尚无正式版本契约。** 14批接入、5批旧契约明确跳过是合理的保护。当前主要检查首条记录是否有若干键；相同键名并不能保证权重、评分、归一化和历史来源语义一致。没有完整的逐条校验、唯一键校验与版本迁移，也不支持没有真值的未来预测展示。
- **可拓展性：模块方向正确，插件边界还需明确。** adapters/regimes/sections/render和SECTION_PLUGINS可保留。目前增加分析仍需理解私有函数及修改渲染逻辑，插件没有统一声明所需字段、支持口径和不适用条件。全局依赖一份旧parquet及固定哈希来生成剧烈月份，使缺少该资料时整个构建失败；该项宜成为可选诊断，来源与哈希仍严格登记。
- **可复用性：通用统计部分复用，统计编排仍有重复。** W1和分位数复用已有模块；共同支持、ESS、月份/遍数汇总、重复分解和质量处理仍在面板中单写了一套，已出现审阅中的差异。这部分应当进入共享分析层，供面板与命令行报告共同调用；旧冻结入口保持原样。

### 目标后端的五步

`登记实验 → 适配并验证记录 → 确定评价样本与公共统计 → 保存聚合及来源凭证 → 渲染面板`

1. **实验登记。** 记录用途/机制系列/有效批次，以及评价缓存、协议、评分与后处理版本、权重字段、人口与历史来源、信息截止、成本账本。自动发现新目录只产生待登记项，不能凭相同键名认定科学上可比。
2. **规范记录与适配器。** 明确schema版本，一行对应实验×月×人×组×遍数。验证唯一性、数值/概率状态、权重含义与可用字段。旧格式用有名字、有测试的小适配器转换；缺失维持缺失，不能猜成零或真实值。原答与派生答保留各自来源。本地身份联结保留在受控层，公开聚合不带个人记录。
3. **公共分析。** 将题目、所选对照、月份、权重、评分版本、重复和共同支持写入显式分析配置。先确定分析支持，再调用共享指标，产出固定结构的指标长表和图表聚合。每项带名称、单位、支持、样本/ESS、版本与限制；有条件的区间和回归独立启用，缺字段明确不适用。
4. **按批次缓存和保存。** 缓存键包含输入内容哈希、评分来源、分析配置和代码版本；不只看文件名或修改时间。缓存未变时复用聚合，只改颜色无需重算统计。增加候选/改变共同支持时，相应比较缓存也必须失效。每次分析有新结果快照；页面成功生成后再原子替换稳定入口，失败保留上一版与错误清单。
5. **可选分析与统一输出。** 新闻暴露、采购角色、财务/心理等插件声明所需字段和适用条件，缺少可选来源只关闭该项并说明原因。核心数据损坏则排除该批并提示，不能假装成功；某一批损坏不应阻断其余已核实批次。输出公共聚合JSON/CSV、分析凭证和HTML，私有中间数据只进被忽略目录。

### 与现有实验流程的连接

在已封存的运行结束/停止后，调用既有评价器，再调用新的离线分析与渲染包装入口。模型调用、真值评价和页面构建继续隔离。重复执行同一包装命令不能重复调用模型，也不能覆盖冻结回答；没有真值的B线仅登记封存预测与技术质量，真值公开后创建新评价版本。

不需要为当前本地规模引入数据库服务、后台常驻进程或账户系统。先按批次加载与缓存，避免每次把全部原始记录装入内存；达到实际性能瓶颈后再决定是否增加存储工具。

### 以三个动作验收可复用性

- **新增同格式实验：** 增加登记/配置并运行命令，自动获得基础分析，无需改六个统计函数和前端。
- **新增一个机制字段：** 只扩展适配和对应插件，已有基础分析及旧批次结果保持不变。
- **只改展示：** 从同一公共聚合重新渲染；不重算Q9、无模型调用、指标不变。

首批仍只接三个代表实验，加入冻结成绩对账、重复键/混合版本、部分失败、缺来源与缓存失效测试。研究人员仍负责确定比较范围和解释结论，自动化负责执行已确定的口径。
