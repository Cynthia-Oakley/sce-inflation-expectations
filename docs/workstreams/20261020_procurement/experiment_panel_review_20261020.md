# 实验面板 v0 审阅：结构可保留，统计口径需先对齐

2026-10-20。审阅对象：`docs/reports/experiment_panel/index.html`、`panel/`四个模块与构建入口。仅检查已有页面、代码和缓存，运行现有10项合成测试（全部通过）；没有调用API、重拟合Q9、重跑实验或修改Kimi实现。本记录不是新的模拟结果。

## 结论

**六区结构和离线工程方向符合设计，但尚不能替代冻结实验报告作为统一成绩入口。** 当前主要缺口在统计定义、共同支持和重复生成处理，不能仅靠补图表解决。保留现有适配器、插件和HTML渲染，先修共用统计，再补交互。

## 已经实现的部分

- 自动发现19批缓存，14批接入、5批旧契约显式排除；没有强行猜旧字段。
- 六区覆盖总览、月份、人群、先验、回答结构和质量；学历×在职六格与单变量切片、先验四档、真值变化方向分组均已呈现。
- 浏览器实测实验/组别切换、图表和Q8简表可工作；HTML无网络依赖，嵌入数据为聚合，未嵌入逐人原答。
- 复用已有加权分位数和W1函数，原实验轨迹、评分器和manifest没有被改写。
- 事后变化方向和剧烈月份已标注为评价信息。剧烈月份查表实际包含106个连续日历月，没有用六个非连续实验月直接相减。

## 必须先修的四项

### 1. 恢复主统计量，分开标注三种误差

位置：`panel/sections.py:107–129,157–207`；`panel/render.py:171–193`。

当前`mae_pp`为逐人绝对误差的加权均值，`median_abs_error_pp`为这些个人绝对误差的加权中位数。后者被显示为“中位MAE”，但它不是本项目的群体中位数MAE。

- 主指标：每月、每遍分别计算模型跨人加权中位数与真人对应中位数之差的绝对值，再对月/遍等权平均。
- 个人MAE：逐人绝对误差的加权均值，另列。
- 个人绝对误差中位数：可保留，但必须用完整名称。

十二期冻结报告主指标为 **0.459191pp**；页面目前显示的 **1.881386pp“中位MAE”** 是另一统计量，不能作前者的替代。页面的逐月MAE、剧烈月技能值目前也使用逐人MAE；若关注宏观变化能力，需另列群体中心误差，不能直接沿用现有数值作宏观结论。补上中心RMSE和中心带符号偏差。

### 2. 先固定共同支持，再逐月逐遍算分

位置：`panel/sections.py:134–204,266–363`。

当前各臂独立筛可评分行，且同月两遍混入一个分布后才算中位数/W1/IQR。均分权重能避免总权重简单翻倍，却不能保证非线性分布统计与“每遍计算后平均”等价。

- Qwen采购原主分析为三臂、两遍都可评价的 **552个人月**；面板各臂分别显示572/573个人月，不能当作原主成绩的复现。
- 仅有上期回答的基线被筛了先验，但模型行未必同筛；有缺先验时，“同支持”文字并不成立。
- 建议分为明确的“全部所选臂/遍共同支持”主表和“各臂可用支持”敏感性表。Q8独立取支持，不能被Q9失败连带删除；基线也按问题单独对齐。
- 人口、先验和概率形状同样沿用所选支持；分月分组后再汇总。跨月混合分布可以作为附加描述，须明确命名，不能冒充月内异质性。

### 3. 修正ESS与稀疏格显示

位置：`panel/adapters.py:99–127`；`panel/sections.py:134–141,266–290`。

当前ESS直接使用所有重复行的权重，且包含部分无有效模型结果的行。把每人权重平分到两遍，仍会把ESS放大：十二期页面为 **n=2,286个人月、ESS=2,781.9**。这不是以个人月为单位的Kish ESS。

先在有效分析支持内合并同一人的重复，再按相应月/格报告n、ESS、最大权重份额和覆盖月份；跨月同一真人的独立人数另列，不能把个人月当独立个体数。按设计草案固定n<10仅覆盖、10–19探索显示、n≥20且ESS≥10正常显示；这是展示规则，不是功效证明。现有只检查跨月合计n≥10，可能掩盖每月格子很稀疏的情况。

### 4. 重复波动分解采用方差层计算

位置：`panel/sections.py:396–427`。

当前“扣除噪声后方差”是“跨月平均的人际标准差的平方−跨月平均的人内标准差的平方”。这不等于重复测量的方差分解，也没有正确处理重复均值中的噪声缩减和实际遍数。

建议复用`evaluation/temperature.py`已声明的方法，必要时另明确加权版本：在同月、完整重复支持下计算人内样本方差及重复均值的人际方差，后者扣除相应的人内方差/R，再按月汇总。四遍批次不能统一称“两遍”；负估计保留。删除硬编码的“模型普遍不足1pp”说明——当前面板自己显示的人际标准差已有约3pp，说明必须随数据生成。

## 下一版功能与呈现

1. **月份/格子下钻。** 当前只有批次、arm和Q8简表切换，没有月份筛选、点击网格联动、组内CDF/尾部分位数、组内/组间方差。优先补“选月→选格→真人/模型/基线条件分布”，再考虑更多指标。
2. **Q8切换范围。** 实测切换只改总览，下面五区仍是Q9。将按钮明确写成“总览Q8简表”，或让所有适用区联动并明确标题。当前“无上期Q8存档”应收紧为“本适配器未接入上期Q8”，不能据当前缓存字段缺失推断项目没有资料。
3. **输入与比较资格。** 当前是静态提醒和summary部分字段，并未核对人口/新闻/历史/问卷/格式/归一化的哈希；实际提供的CPI、食品、能源、新闻主题/数量及发布时间也未显示。缺元数据标“无法确认”，同输入的模型比较也应允许；不能只因不同模型就拒绝公平比较。
4. **运行质量。** 增加计划→尝试→回包→原始合法→归一化可用→可评分的分组/月漏斗。费用来源需接实际账本；Qwen当前显示`null USD`，应显示“未接入”，并保留已知费用与失败预留的区别。
5. **注册与可读性。** “新闻量6期”目前登记的是早期3/8/20篇×完整/精简统计六臂，后来的固定/匹配/随机三臂反而为未登记；两者都应有清楚不同的名称。长批次ID放次要位置、arm显示中文、主指标用摘要卡，完整表折叠，减少首屏横向滚动。图加单位和完整日期；正文按此前偏好使用楷体/Times New Roman。
6. **可复算输出。** 补分析配置版本/输入与评分版本、聚合长表、不可覆盖快照及自动事实摘要；当前一条命令是手动重建面板，尚未接入每轮实验结束后的自动步骤。导出、专用暴露页可以随后完成。

## 本地逐人文件的存放

HTML本身未发现逐人记录嵌入。但同目录`panel_data_private.json`约27MB，仍含逐行人口特征、先验和十档回答；去掉ID不等于变成聚合。它目前不在.gitignore覆盖内。后续实现应移至被忽略的outputs目录，或添加明确的私有文件忽略规则；不要将整个reports目录打包发布。

## 建议的最小验收

- 用现有冻结缓存复现十二期0.459pp、六期新闻三臂既有成绩、Qwen三臂552支持；不新增模型或密度拟合调用。
- 加入“个人绝对误差中位数≠群体中位数误差”的反例测试。
- 加入两遍分布不同、各臂/遍缺失不同、Q8合法但Q9失败、先验缺失、极端权重的测试。
- 重复遍数翻倍不增加个人数或ESS；主指标按月/遍计算；样本及评分版本变化有提示。
- 用已知实例检验2021-09退步、低先验端改善、553/552支持区别、新闻匹配与随机的区别。

现有10项测试全部通过，证明当前代码可运行和部分约定得到执行；它们没有覆盖上述非线性统计与冻结结果对齐，因此不能替代这些验收。
