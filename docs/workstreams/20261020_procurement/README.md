## 1. 本轮解决什么问题

此前加入购买频率，主要是在共同宏观信息旁增加一个标签。它没有让不同家庭真正得到不同的价格信息。本轮先把中间一环做实：

**家庭构成与年龄 → 采购责任的概率 → 可见的食品类别 → 模型结合原有信念回答Q8/Q9。**

这是一项可检验的输入机制，尚无新的拟合结果。目标是改善分组分布和信念更新，而不是人为指定某类人应该报高几个点。

## 2. 理论支持与不能照搬的地方

- [D’Acunto等的原论文](https://eml.berkeley.edu/~ulrike/Papers/paper_DMOW.pdf)用同户购买记录与预期调查研究价格接触：商品购买频率、涨价方向与预期有关。它研究的是本人购买的商品，不能把全国食品CPI直接等同于个人体感。
- [购物分工研究](https://eml.berkeley.edu/~ulrike/Papers/pnas202008534_Published_Paper.pdf)支持生活角色影响接触的信号，而不支持按性别硬指定采购者或预期水平。
- **商品购买频率、个人采购次数、采购责任是三件事。**某类商品经常买，不意味着负责购物越多的人必然对一次涨价反应越强。本轮用角色改变信息广度，不设置预期高低或更新系数。
- [ATUS原问卷](https://www.bls.gov/tus/questionnaires/ehmquestionnaire2223.pdf)问承担多少家庭食品采购。它不直接测量清洁用品采购、服装采购、驾驶，也没有给出应展示几个CPI类别的参数。

上述来源于本日重新核查。它们支持研究路径，不证明下面的合成分配就是SCE本人的真实状态。

60条同比与同份PDF的表7核对；其中42条食品数据的同比/环比另与表1核对，并核在家食品同比与冻结E完全一致。表间对账能发现错列，不能证明BLS样本就是本人的购物篮子。

现有新闻库存的补充词项扫描只用于查缺，不改变标签或路由。六期食品路由原有3/8/12/1/2/10篇，日用品补充词项均未命中。后者提示该词表下库存薄弱，不能证明库里完全没有相关报道；也不能只加几个关键词就补齐个人价格体验。

## 5. 三组具体如何比较

**共同背景组**：每个人都有同样的在家食品价格背景，不加采购角色和食品细分类。

**角色匹配组**：加合成采购角色，并给相应的食品类别信息。暂定责任五档对应0/1/3/6/6条细分。类别从六类中按固定个人种子排序取前缀，不按哪个商品涨得多、也不按SCE真值挑类别。这是待检验的接触广度规则，不是ATUS估出的真实条数。

**同月打乱组**：把整套“角色＋类别信息”换给同月其他人。角色和信息一起交换，避免一边说完全不购物、一边给全套详细价格。接收者的信息发布时间标签重新按他本人的上期作答时点生成，不沿用供体标签。

匹配/打乱严格保留未加权的信息包多重集。为限制调查权重造成的信息总量差异，候选交换在相邻权重排序的约12人块内进行，取第一个满足条件的分配：加权细分条数与文本字节数相对差不超过1%，各角色/类别接触比例绝对差不超过2个百分点。没有看答案或模型结果选分配。

因此它检验的是**控制权重和信息量后的身份分配增量**。它不是毫无限制的随机交换；约25%—43%的人打乱后仍在同一角色档，负对照并非彻底消除所有人口关系。文档和结果须保留这一限制。

本次18个分配的实际渲染复核：加权价格片段字节数最大相差0.662%，完整提示最大相差0.104%。这些是输入平衡指标，不是SCE拟合改善。即使后续对照显著，也只识别模拟器内这套分配变化的效果，不直接识别真人采购角色的因果效应。

## 6. 其他输入如何控制

三组都用原固定8篇新闻，正文、新闻发布时间标签、CE合成支出、央行信心与政策、本人真实上期Q8/Q9及更早摘要、问卷都保持一致。不同时研究新闻数量或强制外推规则。

三组**统一去掉原完整宏观统计与十二期趋势表**，避免它绕过个人视图；新闻/政策里原有的价格数字仍保留。新的价格片段有清楚的发布日期和相对上期作答的标签。

这改变了三组共同底座，所以原来完整统计表下的模型回答不能冒充新共同背景组；真正比较需要同期新对照。角色匹配与打乱是主要对照，共同背景组帮助判断整体加信息的作用。
