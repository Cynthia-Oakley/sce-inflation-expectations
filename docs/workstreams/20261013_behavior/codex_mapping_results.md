# 个人概率填法：形式改善，信念差异仍未恢复

2026-10-13。零新增API、费用$0。先登记规则，再复用旧回答；不是新LLM模拟，也不是全国预测。

## 结论

程序映射确实改变了概率刻度和小尾部。主种子下中心MAE 1.318→1.222pp、人群分布W1 3.102→3.027pp；改善小且区间跨0。本人填法与打乱填法的中心误差仅差0.005pp，没有清晰的身份增量证据。

人际IQR 1.06→1.08pp，真人6.25pp。报告层没有解决同质化，不作为主机制升级，也不据此自动开启新API实验。下一重点仍是个人信念保留与更新。

## 输入和实现

四期2022-03/09、2023-03、2024-03各12人、两次生成、三组既有回答。96条Q9配对记录中94条共同有效，即47人月、三组共282份模型问卷；1个真实人月无效在两遍均排除，映射额外失败0。384配对行包含四类指标，不能当384份问卷。所有组用同一有效集。

模式参考只用2017—2019已经拟合的表和本人严格早于目标月的合法问卷。本批每人有1—11次历史，没有新入组冷启动样本；无历史回退机制只经单元检查，未在这批数据得到实证检验。个人分布为 `(3×训练期参考＋本人历史计数)/(3＋历史次数)`，参考包含上次信念形状，因此它不是纯粹识别出的报告人格。

每个种子为每个人分配一个模式，三组及两次生成共享；精细模式保留原概率，5%/10%模式用最大余数法补齐100%。约38.7%的5%/10%变体在补齐的截断处出现余数并列。既定规则按原档位顺序处理，会把部分质量优先放在较高通胀档，可能贡献中心上移；没有据结果换另一规则，不能视为中性的人类认知机制。同月12人的分配打乱50次，保留完整名单的模式比例；1个评价排除者仍在名单内，故11人有效子集的比例可能小幅变化。

种子42为主结果，另四个事先登记种子全部报告，未挑最佳。已看到这些月份与旧统一取整实验，属于回顾开发诊断，不能称未见过的项目测试。

## 实际变化

原模型有93.6%回答含非5%倍数，本人映射后为14.6%；同批真人12.7%。通缩五档合计0的占比9.5%→51.1%，真人65.9%。这说明表达格式可改善，不能说明模型获得了更像真人的通胀信念。

![概率刻度与零概率](../../../outputs/sce_reporting_mapping_reading_20261013_v2/mapping_format.png)

总体中心平均有符号偏差0.391→0.651pp，向上移动0.260pp；其条件差值区间[0.095, 0.462]。一些月份绝对误差减小与平均偏差增加可以同时出现。概率合计守恒不保证拟合均值或聚合中位数守恒；本次主结果拟合家族没有切换。

统一5%/10%只是敏感性参照。10%情景中心MAE 1.194pp，但变化分布W1 1.838pp，高于原1.786pp，且仍远小于真人宽度；不能因一个指标更低就挑它作为最优机制。

## 统计学解释

中心和IQR都用项目经验CDF的左逆分位数；本页真人IQR 6.25pp，与之前插值IQR约5.50pp定义不同，样本没有因此改变。每月×生成单元等权，不用SCE全国权重。变化量统一相对本人真实上月中心；无先验组的差值不是模型自身状态的连续更新。

按整个人配对重抽1000次，保留其所有时期和两次生成，在每月重新归一权重，再重新计算中位数和W1。不能把两遍生成、五个分配种子或50次打乱当新真人。区间条件于固定历史、分配和四个时期，不包含全国抽样、未来时期或训练表估计的全部不确定性。

- 本人减原回答：中心误差差值-0.095pp，95%区间[-0.300, 0.210]；人群W1差值-0.075pp，区间[-0.152, 0.057]。
- 本人减50次打乱的平均评分：中心误差差值-0.005pp，区间[-0.115, 0.108]；W1差值-0.013pp，区间[-0.091, 0.043]。
- 五种分配种子下，本人中心MAE 1.190—1.245pp；W1 3.004—3.042pp；人际IQR 1.08—1.21pp。部分种子的变化分布距离略恶化。

区间包含0，表示当前数据既容许小幅改善，也容许恶化，不能判定稳定增益；不等于证明机制绝对无效。置换保持模式比例，但未控制所有信念与人口差异，不是心理因果实验或置换检验p值。
