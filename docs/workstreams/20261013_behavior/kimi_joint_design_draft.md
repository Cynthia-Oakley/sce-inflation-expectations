## 1. 设计

两个因子各两档：

- **更新层 U**：U0 = 现状（既有先验试验臂：提示含本人先验，无显式状态/更新规则）；U1 = 显式个人状态（上期概率回答隐含的近似均值 + 上期不确定度 + 个人长期锚），v2 起拆为两臂——**U1s**（U0 + 状态摘要）与 **U1g**（U1s + "半程回弹"更新假设句，无锚者关闭该句）。锚采用**个人历史均值**而非共同中位数（详见 `kimi_anchor_results.md`），靠拢强度 λ=0.50（训练期选定）仅以"待检验假设"文字呈现，冻结后不改。规范细节：`kimi_u1_input_spec.md`（v2）。
- **报告层 R**：R0 = 模型原生十档输出；R1 = 程序报告映射（Codex 候选 2：按训练期个人报告模式分布，把原生回答映射为带个人填法风格的十档；映射规则预登记，不按当期真值或误差选档）。

关键效率：**报告映射是后处理**。每个更新臂只需跑一次 LLM，R0/R1 从同一份原生输出离线派生。因此所需新调用只有更新层的两个新臂：

| 格子 | 来源 | 新 API |
|---|---|---|
| U0R0 | 既有先验试验本人先验臂（96 条 Q9 回答） | 0 |
| U0R1 | 对既有原生回答离线施加 R1（已完成，`codex_mapping_results.md`） | 0 |
| U1sR0 | **新批次臂 1**：U0 + 状态摘要 | 48 人月 × 2 遍 = 96 次 |
| U1gR0 | **新批次臂 2**：U1s + 更新假设句 | 48 人月 × 2 遍 = 96 次 |
| U1sR1 / U1gR1 | 对新原生回答离线施加 R1 | 0 |

合计 **192 次**（48 个人月 = 每期 12 人 × 4 期；每臂每例生成 2 遍）。两臂拆分使"状态摘要"与"更新指导"的贡献可分离：U0→U1s isolates 摘要，U1s→U1g isolates 指导，U0→U0R1 isolates 报告层。R1 按汇合共识降为离线敏感性分析，不作为已通过的主机制。

## 2. 待汇合评审定的三个决策点

1. **状态来源口径**：第一轮建议沿用先验试验的 A 线诊断口径（个人状态由真实历史初始化），先把机制效应测出来；B 线闭环（状态仅来自本人模拟历史）作为第二轮，避免一次改两个口径。
2. **R1 实现归属**：映射规则属 Codex 表达线模块（`reporting_behavior/`），建议由他实现、我复算；或我按他登记的规则实现、他复核——汇合时定。
3. **样本**：第一轮维持既有名册（每期 12 人 × 4 期 = 48 个人月，与既有臂可比，机制检验够用）；不做全国推断。扩大样本留到机制确认之后。

## 3. 预登记评价指标（对照 Codex 互评意见，禁止单指标宣布成功）

主指标：Δ 分布 W1、截面 W1、跨人中心 IQR（主口径为左逆经验 CDF，该名册真人约 6.25pp；插值口径约 5.50pp 仅作敏感性并列）。
辅助：中心 MAE、逐人 MAE、身份弹性、|Δ|≤0.5 占比。
纪律：截面 W1 与 ΔW1 的张力必须同时报告；若一格改善 ΔW1 但恶化截面宽度，记为"未通过"而非"部分成功"。

## 4. 预算估算（DeepSeek，供用户决定）

每次调用：输入约 3–4k token（E 环境 + 新闻层 + 显式状态块），输出约 0.5k token。
