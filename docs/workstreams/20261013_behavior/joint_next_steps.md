# 下一阶段计划：先验证个人信念与概率填法

更新：2026-10-13。状态：两条研究线首次交付及交叉复核完成；第2项个人填法离线验证已交付，第3项及后续仍是计划。尚未冻结新Simulation配置。

## 当前的位置

模拟、计分和评价流程已跑通。现在的主要问题是模型没有充分保留真人之间的差异；总体指标也未证明优于简单基线。本阶段检验两件事：居民如何形成和更新预期，以及怎样把预期填成问卷概率。P/E先沿用现有版本，以便分清改进来自哪里。

- Kimi首次交付：[结果](kimi_results.md)、[聚合汇总](kimi_summary.json)。严格相邻对106351、有效对103630；59月训练/46月评价，主要数值由Codex独立复算一致。
- Codex首次交付：[结果](codex_results.md)、[聚合汇总](codex_summary.json)。本人历史能预测后续概率填法，但不能唯一识别心理风格；机械取整不足以恢复人际差异。

## 1. 合并判断与复核记录（已完成）

计算结果可保留，以下解释边界记录在此，原交付文件保持原样：

1. 真人“变化量对上期水平”的斜率−0.439，与模型“输入先验差对输出差”的斜率0.118是不同统计量，不能直接比较。前者还含数学耦合与测量误差，不直接作为心理更新率。
2. 逐人MAE从2.986降至2.979pp，属于小幅数值改善，尚无相应区间支持，不能称预测误差已经见底。
3. 使用当月真实共同中位数的更新器是A条件诊断；低中心误差不能当B预测成绩，也不能与未获得该条件的原生Agent成绩直接比较。
4. 不确定度未改善当前指定更新公式，不等于所有不确定度机制无用。
5. 模型使用本人先验较弱，支持把表达提示降为小样本候选，但不证明表达提示必然无效。程序映射更可控，其真实性仍待验证。

## 2. Codex：个人概率填法的离线验证（已完成，零API）

结果见[codex_mapping_results.md](codex_mapping_results.md)。格式改善，中心MAE1.318→1.222pp，但主要区间跨0；人际IQR1.060→1.081pp/真人6.249pp，未恢复个人差异。本人与打乱接近，暂不升级为主机制或自动开新API。下列保留执行前设计。

目标：检验有历史依据的个人填法能否改善问卷分布，而不只是移动总体中位数。

- 复用四期本人先验实验的已保存回答，保留无先验/置换先验参照；不将12人和48人实验拼成一个样本。
- 沿用已登记的训练期参考和本人过去填法，形成“精细、5%网格、10%网格”的概率分配。它们是观测模式，不是确证的心理类型；无本人历史者回退历史参考。
- 在计算新映射结果前登记：历史输入截止、分配规则、种子、概率守恒算法、共同有效集与指标。不能按本期真实答案或已看到哪种映射更准选择个人填法。
- 比较原回答、本人历史分配、置换分配；已有统一5%/10%取整作为敏感性参照。不强制通缩概率为0或规定非零档数。
- 原回答与映射回答分别保存，用同一冻结近似计分器评价。Q8保持原值，防止误称概率映射同时解决点回答问题。
- 验收：合法概率、合计100、固定种子可复算、当期真值扰动不改变映射、原始文件哈希保持；同时报中心MAE、截面W1、人际IQR、更新分布W1，以及按人配对的误差差值和不确定性。

若仅改善取整形状或移动中位数，仍不能升级为恢复真人异质性的主机制。提示式表达说明保留为可选小样本预检，其范围与成本后续单列。

交付位置：Codex的`reporting_behavior/`及本目录`codex_*`文件；逐人结果只在新建outputs目录。

## 3. 建议Kimi：个人信念保留与更新的离线验证（可并行，零API）

目标：保留个人差异，再研究怎样响应新信息，避免把所有人拉向同一个数。

- 检验本人上期预期、仅过去问卷形成的个人长期基准，与本期变化之间的关系；历史不足者用训练期条件参考，不能用本人未来回答补历史。
- 与原样延续、已交付共同平移/收缩参照比较；不要把当前小样斜率或选出的0.3自动当作通用心理参数。
- 共同真值已知的A诊断与共同水平需要估计的候选分开记录。B可用性后续另审，不直接逐月读取未发布真实微观。
- 同时报截面分布、变化分布与总体中心，量化改善区间；不能通过人为增加方差宣布成功，剩余变化也不能先全部认定为随机噪声。

此项为建议分工，实际启动和交付由Kimi记录确认。文件继续在Kimi的`belief_dynamics/`及`kimi_*`范围。

## 4. 汇合后登记对照输入（待上述结果）

先选择有离线证据的候选，再确定组别。如果两层都有支持，可比较原模型、只改更新、只改填法、两者结合；若一层没有支持，缩减组别。正式组数、人数、月份、重复次数尚未冻结。

固定同一P/E、模型、温度与评价口径。事先选定未参与本轮调整的月份；过去看过的全期汇总和开发月份继续声明，不称全项目盲测。仅总体误差下降或方差增加均不够，需同时检验微观分布与变化是否更接近真人。
