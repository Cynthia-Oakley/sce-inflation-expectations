# 扩大实验前的诊断计划

2026-10-14。用户授权继续本地分析和扩大实验准备；本任务不进行新增付费调用，也不改变正式配置。分析前记录以下方法，结果不用于回改本轮U1判定。

## 顺序与交付

1. 复用已核验的U1评价行：分开看当月共同水平、个人上期位置、个人更新；保留协方差，不把差别直接叫噪声或心理因果。
2. 使用2017-01至2025-10现有真人微观缓存，按严格相邻月份识别回访者。分别抽12/24/48/96/192人，每月每规模200次，不放回、固定种子20261014。并列等权与原调查权重。完整有效月与回访者池的差别另报。
3. 用官方个人Q9_mean计算长跨度抽样误差；当前模型对照沿用冻结计分器。这两种结果分别命名，不混算、不称官方headline或实时路线B。
4. 当月中位数相对上月的绝对变化按≤0.25、(0.25,0.75]、>0.75个百分点作描述分组；阈值是本次探索约定，不是学界标准或拟合出来的参数。不按模型输赢选择月份。
5. 理论笔记区分P（个体状态）、E（被接触的信息）和更新/表达机制；文献只能支持候选路径，不能替代本项目识别。

## 已知限制

- 四期每期12人，48位不同受访者；两次生成不是两倍真人。月份不连续，不估计这些人的长期随机效应。
- 回访者条件样本不含首次参加者。原调查权重在该条件池中重新归一，只作条件描述，不自动代表全体家庭。
- 抽样练习是当前微观资料的有限总体子样本实验，不是官方抽样设计置信区间或机制检验的统计功效计算。
- 模型与真人按同一批人比较时，小样本不自动解释两者差距；抽样练习主要帮助判断总体代表性和下一轮人数。
- 观察到输出与先验的相关，不能据此认定模型对先验的因果响应；变化量对上期值的回归含数学耦合与测量误差。
- 现有数据无法单独识别真实信念、生活经历、认知更新和问卷测量误差。不会承诺一个可实现的微观误差下限。

实现仅新增evaluation模块/薄入口/定向验证；输出新目录，个人行留outputs，公开文档仅含聚合值和图。最终提出人数与月份准备建议，正式模型、平台、发送范围和预算另冻结。
