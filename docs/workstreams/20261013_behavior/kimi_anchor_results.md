## 2. 按预登记成功标准的判定：**未通过（但张力显著缓解）**

预登记要求同时满足 ΔW1 ≤ 2.0 且截面 W1 ≤ 0.60：

- ΔW1：✅ 1.848–1.950，达到 B2/B3 的 ~1.78 量级，远低于 B0 的 2.986——**响应新信息的渠道保留**。
- 截面 W1：❌ 0.723–0.733，超过 0.60 门槛——但比同 ΔW1 水平的 B2/B3（1.24）明显收窄。**口径澄清**："收复约七成"指的是相对 B0 的**超额 W1 距离**从 +0.75pp 降到 +0.23pp（(0.75−0.23)/0.75≈0.70），W1 同时受位置、形状与尾部影响，**不能直接读作"恢复了七成人际宽度"**。Codex 互检补算的解释性注记（非预登记指标，不改变判定）：C1 的加权跨人经验 IQR 约 5.318pp、真人约 5.592pp——中间宽度已接近，剩余差距在完整分布形状/尾部。该补算口径与四期 12 人 LLM 小样不可直接比较。

按预登记纪律记为未通过；实质进展是：锚的位置（个人 vs 共同）确实是截面压缩的主要来源之一，把锚还给个人能拿回大部分超额 W1 距离，且 Δ 拟合几乎不掉。

## 3. 附带事实

- 验证期 88.9% 的相邻对有 ≥2 条有效历史（锚项生效）；其余退化为共同平移。
- 个人锚本身有真实的人际分散度：验证期锚的跨人 IQR 月均 4.62pp（3.87–5.45）——锚不是变相的共同中位数。
- 逐人 MAE 2.849–2.904，比 B2/B3 的 2.979 和 B0 的 2.986 略低。幅度小（~3%），不足以推翻 Codex"简单规则对逐人误差改善有限"的提醒，但方向首次为正。
- 训练期截面 W1（0.527–0.541）满足门槛、验证期超门槛（0.723–0.733）。**剩余差距的来源本轮未做分解**：验证期 B1 共同平移的截面 W1（0.468）并不高于 B0（0.497），故不能归因于共同平移项；也不能在未检验前归因于"个人冲击"缺口——该归因只是第 4 节的候选假设，需另作分解检验。

## 4. 对 U1 规范的含义

1. **显式状态采用"个人长期锚"而非共同中位数锚**——本轮直接证据支持。
2. λ≈0.5（个人锚）可作为 U1 更新规则的初始参数，最终值在 U1 正式预登记时冻结。
3. 残留的截面损失（0.73 vs 0.50）说明仅靠确定性规则还差一截；缺口的一个**候选解释**是**个人特异的月度冲击**（与第一轮"低参数规则对逐人误差改善有限"一致），但该归因尚未做分解检验，仅为待检验假设——若成立，这正是留给 LLM 供给的部分，与 2×2 草案中"LLM 负责异质冲击、规则负责校准"的分工一致。
4. 下一步候选（未登记、未运行）：锚与不确定度联动（高不确定度时 λ 更大）、共同平移项的 B 线可得替代物。
