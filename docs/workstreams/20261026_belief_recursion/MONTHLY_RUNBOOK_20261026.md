# 固定家庭的月度信念连续递推

本轮依据用户2026-10-26指令：开始月度个人信念递推，暂不设置受访者进入和退出。下述执行包已离线验收。用户已明确同意精确发送范围与$10共享上限，authorization已记录；随后要求由其在本地Terminal手动启动。Codex尚未代启动，新增真实调用0。

## 研究的问题

原B每个月从公开旧人口框架准备代理，再用截止前公开的全国历史值校准合成先验，回答的是“一步模拟能否接近当月SCE”。本轮改为固定同一批家庭：首月之后只使用本人上一步的模拟回答作为信念起点，观察连续更新是否产生水平漂移、分歧收缩或逐渐脱离原有信念。

这对应预期形成中的信念持续性与信息更新问题。它是自主状态演化的诊断，不预设能提高MAE，也不作为A/B主线的成立门槛。固定家庭及起始代表权重适合隔离身份变化，不声称代表以后每月实际SCE轮换人群。就业、收入、年龄组等本轮也保持起始画像，不虚构家庭经历。

## 本批冻结配置

- 时间：2025年11月至2026年9月，11个连续月份；固定首月512户。
- 首月：精确复用已完成新版B的512份回答。逐条核对原消息哈希、主批/补批原答及字段合并，没有新增调用。
- 后10个月：5,120次新主请求。每户只能读取本人紧邻上一个月的已封存状态；不能换匿名供体、借用独立B该月起点或用目标真值刷新。
- 固定项：家庭ID、人口画像、分析权重、合成CE篮子、采购角色和首月新闻关注档。四档4/8/16/32篇首月各128户，之后档位固定、新闻内容逐月更新。
- 环境：接入Kimi统一新闻修复manifest，包含修复后的2026年1月档案。沿用前一年同月的历史作答日期分布，按固定ID生成合成作答日；信息截止为“合成作答日前一天纽约时间末”与原共同D的较早者。价格、政策、新闻和信心均经过对应个人截止过滤。CPI相关新闻相关度1.5，警示倍数1。
- 行为：Q8点预期、Q9十档概率仍直接填写。上一步答案的来源明确标为模拟；历史摘要只追加自己的模拟结果。Q9非负有效概率按已确认规则等比例归一化，原始响应保留。
- 模型：OpenRouter → 固定SiliconFlow FP8 → `deepseek/deepseek-v3.2`；温度0.5、JSON、关闭思考、最多1024输出token。
- 不加入月度全国SCE新锚来重新校准个人状态；也不额外向模型广播这个数值。因此是自主递推链，而不是持续获得官方调查反馈的居民模型。
- 不做新旧受访者进出、Normal代答或周度模拟。Normal展示行不是具有独立LLM历史的家庭，不能作为额外接续状态。若以后需要规模展示，可另对已封存快照离线积分，不改变本链。

旧计划曾建议128户以压低探索成本；本轮保留完整512根，是为了复用全部原答、保持已有网格支持并避免再引入子样本偏移。人数和新请求已在审批卡明确列出，并非自动扩大的付费授权。

## 运行与故障处理

每个月按顺序执行：读取上一月checkpoint → 冻结本月512份消息 → 主批 → 最多一次技术补跑 → 合并成功字段 → 原子封存本月checkpoint → 进入下个月。前一个月尚未结束，程序不能提前生成下月请求。

每月技术段32次、最多8并发，格式检查通过后32→64并发；补批16→32。共享预算按全链已报费用、未知费用预留及在途预留累计，不因进入新月份而重置。主批约$5.04，主补共享硬上限$10，不预扣款；理论最大新尝试10,240次。精确预算已由本批审批确认，旧B预算不延用。

零星网络错误保留后继续；连续连接、502、429等按已有容错策略有界冷却，只续从未发送位置。认证、余额、预算或供应商异常保存停止。未知已发送但未回包的位置不自动重发。已知技术失败每个位置最多补一次；成功原字段不被补答覆盖。补后仍失败的字段保留该家庭自己的更早状态，明确登记来源月份，不换人、不按误差补跑。

checkpoint采用先写暂存目录、完整校验再原子改名，保存前驱状态、实际提示、请求/响应与哈希。显式恢复时跳过已封存月份，不重跑已尝试位置，不把断点恢复当成新实验。

启动后使用本机独立后台程序；不依赖Codex逐批调度，也不消耗Codex来完成每个请求。Mac运行时使用防空闲睡眠；物理断网、系统关机等仍会影响网络，原始账本保留。

## 评价与解释边界

主要报告**首月之后10期**，另列完整11期，因为首月复用不能当成新增验证。沿用共同Q9计分器：十档概率拟合个人连续密度并取均值，再按起始人口权重计算跨人的中位数。

1. 全国原始MAE、RMSE、偏差及逐月误差；对照最后公开SCE的持续性基线和“始终保留根月模拟回答”的基线。
2. 辅助列A线固定13.3976%模拟权重组合，不在这11期重新拟权。组合是生成后的外部公共锚校正，不能用来掩盖原始自主链漂移。
3. 模拟家庭之间IQR、每月更新幅度/比例、相对根月漂移、分组轨迹与技术保留情况。近期真人微观数据缺失，不报告真人W1或IQR误差，不把合成家庭差异称真实结构恢复。
4. 原独立初始化B可作描述性参照，但其后续月份名单不同，差别同时包含人口与初始化方式；不是同人同输入的因果对照。本轮不再增加一组付费控制。

这是结果公布后的回顾性时点诊断。新闻/政策历史文本版本、人口文件逐期历史字节版本及模型知识边界仍有限制，不改称严格事前预测。
