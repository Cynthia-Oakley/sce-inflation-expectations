## 人口与起点如何固定

取已准备B线2025年11月的512个匿名代理，沿用54格抽样的起始名单、人口画像和代表权重。源人口波次为2025年1月，其历史可得性仍按既有九个月滞后规则推定，未认证精确的当时文件版本。

家庭的学历、年龄组、收入档、就业、住房、地区和数理标签，以及合成CE支出占比、食品采购角色，都固定在起始状态。代理ID不变、不设进出，不用之后每月重新抽样的B名单冒充同一批家庭。代表权重单独保存，模型侧每个代理的执行权重仍为1。

这是一批固定家庭的动态诊断样本，权重代表起始源人群。它不自动代表以后每个月实际SCE人口的构成，也不替代主线B逐月更新人口框架。就业、收入等后续变化暂不虚构；如果以后需要更新，必须另定规则和版本。

起始Q8/Q9直接复用11月B的合成联合起点：旧匿名供体的完整答卷，按当时已公开的历史全国Q9进行分配校准，保留其供体观测月份与合成参考月份的区别，不冒称本人真实上期答卷。**整个包只有一份根起始信念文件**，之后月份不再保存独立初始化。

## 环境如何逐月更新

沿用现有B每月的共同截止日，2025年11月保持11月13日纽约时间末；没有个人真实作答日，也不借用A的个人截止。每月从上月1日至截止日的合格新闻池重新抽取文章，并使用截止前可得的食品价格、政策和信心波次。

新闻机制采用四档4/8/16/32篇、CPI相关度1.5、个人警示倍数1，三篇共同显著性新闻加个人部分。本底包在首月分配四档，各128人，并按身份保持关注档不变；文章内容按月更新。这是供后续确认的准备约定，不表示已经验证了关注档应长期固定。共同新闻原有警示措辞加1分的排序项保留。

食品采购角色和类别范围固定，类别价格按月更新。价格是全国分类CPI的信息代理，不是家庭真实购物小票。信心继续使用截止前现有来源，当前各期均沿用已登记的Gallup 2025年4月波次，不能称为2026年家庭信心实测。政策和原始文本版本限制保持原有披露。

环境容器保存原公开宏观资料作为宿主/备查；未来实际提示应从每户的可见信息视图接线，不能因容器中有完整宏观数表，就无意改变现有食品视图口径。当前尚未制作最终提示。

## 信念接续预留了什么

依赖图包含512个首月根节点和5,120条“上月同一家庭→本月”的连接。后续的`resolve_prior`接口必须读取该家庭前一个模拟月保存的状态；缺前驱就报错，不改用别人的答案或该月独立B的合成先验。

根字段必须来自合成起点。后续若因技术失败保留某个合成字段，它必须与该家庭原种子完全一致，不能换一个新供体；有效模拟字段则保留其模拟月份。接口拒绝真实个人答卷刷新、串人、跳月和当期/未来状态。技术失败怎样记账、补一次以及保存仍待最终运行器接线，本包不执行这些操作。

本包不把之后已公开的全国SCE历史值再注入个人状态，也不包含这些数值的额外广播。未来比较递推与按月校准时，是否让两组同样接触这些公共历史信号，要先明确；否则差异同时包含“个人接续”和“获得公共校准信息”的差异。
