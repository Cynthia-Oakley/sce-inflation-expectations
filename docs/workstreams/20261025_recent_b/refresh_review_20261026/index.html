3．环境和答题模型怎么设？

保留已就绪食品价格、政策、CE支出和合成美联储信心。新闻每月随机分4/8/16/32篇四档，各128户，平均15篇；3篇共同显著新闻，个人新闻一半均匀、一半按兴趣和相关度抽取，CPI相关度乘1.5，个人警示倍数1，不加Fox。P、先验与非新闻E和旧B逐字节保持一致。

OpenRouter→固定SiliconFlow FP8的DeepSeek V3.2，温度0.5、JSON、关闭思考、最多1024输出token，直接填Q8/Q9。有效非负概率不合计100时按原规则归一化。新提示与旧B全部不同，旧回答保留作控制，不能冒充新答复；新闻标签和匹配准备可以复用。

主指标为官方全国Q9首发值的11期MAE；同时看RMSE、偏差、逐月误差、胜出月份，比较旧B／新B、原始／组合／宏观控制／宏观联合。重点区分新闻带来的变化、统计后处理的变化和模拟本身的增量，不能把三者合并归功。
