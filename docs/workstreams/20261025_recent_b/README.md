## 合成起点怎样构造

先在旧资料内部按年龄、学历和收入寻找相似供体，稀疏时按既有顺序放宽。这里的“最近1—3个月”是旧供体库末端的源月份，不是预测时点前1—3个月。源日期、公开证据日期和合成起点代表的历史月份分别登记。

使用截止前最后公开的全国Q9指标，对合成供体分配的概率做原有有界倾斜。Q9目标区间为已公布的一位小数值±0.05pp；它是历史起点约束，不是待预测期真值。Q8没有同等公开锚，因此不把Q9的全国值强加给Q8，只保留联合供体的Q8。

独立抽一次供体会留下有限样本中位数偏移，且接近50%的CDF微小残差可能跨越经验中位数的跳点。因此v1原抽取结果保留，v2在同一人的同一匹配供体池中，对必要的少量合成分配再选择完整供体：优先较大人口质量的槽位，使用固定顺序与固定条件随机流，不搜索种子、不改写数值、不修改权重。没有可行供体时明确报不可行，不能以剪裁答案替代。

这一步会让供体分配相互依赖，也会改变个别人的边际分配概率。第一步概率倾斜的4倍界，**不能**扩张解释为最终受约束分配的概率界。需在最终方法中披露这一条件化设计；它尚未成为已授权付费配置。

## 用户审阅后的澄清与下一步（2026-10-25）

### 旧快照不是“当时最新一期”的证明

纽约联储[官方FAQ](https://www.newyorkfed.org/microeconomics/sce/sce-faq)说明核心微观数据滞后九个月。按这一规则，2025年11月应优先核查2025年初的微观波次，不能因为已核验的2025年7月快照止于2024年8月，就把后者称为2025年11月实际最新数据。月份减九也不能单独证明具体在11月13日已更新到哪一期；一般规则、具体发布日期和历史文件版本是不同证据。

本轮补查官方数据目录及2025-07-03—2025-11-13核心微观下载链接的版本变体，未找到新的期间存档；空结果只说明存档证据有缺口，不说明当时没有更新。当前可证明的旧版本上限仍为2024-08，2025年初波次在该截止的具体可得性尚未确认。记录在`outputs/sce_recent_b_micro_availability_probe_20261025_v1/`。后续优先采用截止前最新有据波次；若采用九个月发布规则推定，必须另列假设及输入版本，不能称历史字节版本已认证，也不能悄悄替换冻结v2。

### 校准的是供体分配概率，不是人口权重或本期模拟结果

1. 在同类家庭的供体池内，先按原调查权重构造基础抽取概率p0。人口代表权重w另行确定，两者不同。
2. 每个供体的Q9十档按冻结算法得到个人密度均值x。公开上期全国值m按一位小数构成区间[L,U]=[m-0.05,m+0.05]pp。
3. 对p0作指数倾斜，压低加权CDF的约束违反程度，并以很小的KL项避免不必要的偏离。中位数约束写为F_w(L-)≤0.5≤F_w(U)。第一步设有概率比保护，但不要求每个人接近m。
4. 以固定随机流抽取完整Q8/Q9答卷。若512人的实际抽取仍未达标，在各自原匹配池内做必要的完整供体替换，检查最终加权中位数。它会改变最终分配规律，不能再声称保留第一步的4倍概率比界。

这一过程不修改供体数值、不把Q8强行设成Q9、不搜索种子，也不利用目标月真值。当前11期最大先验中心偏差0.0498735pp；±0.05是对公开一位小数读数的兼容带，不是近期真实微观结构的精确恢复。当前用项目冻结经验分位数检查；不能将其精确等同于官方每个插值细节。

### 评价与人口机制

用户认可本批先评价全国指标：MAE为主，RMSE、偏差、逐月轨迹及相对最后公开值的基线为辅；无近期个人真值，不报告真人W1或微观IQR拟合。模拟IQR仅可作内部描述。暂不新增代理人的进入/退出机制，连续递推仍是后置扩展。这些与现有评价接线相容，不需新增API。

### 就业有候选证据，收入暂不机械更新

复用已有`outputs/sce_macro_population_v3_20261007/summary.json`，其两份源数据及两份代码哈希本轮均相符；未重复运行模型或读取近期个体真值。70个特征月份的描述性关系中，公开失业率相对旧人口基准月的变化与SCE就业占比变化相关系数为-0.672，非农三月累计变化差的相关系数为+0.453。相关不等于因果，也不单独决定采用。

2022-10—2025-10共37个月的延迟标签滚动回测：保持旧波次的就业占比MAE为1.466pp，加入失业率OLS后为1.323pp（约下降9.7%），三分类平均TVD为0.01708→0.01644；但SCE失业标签占比MAE为0.786→0.816pp。相对仅历史漂移的就业MAE1.397pp，宏观信息的额外收益较小。这些是人口构成预测误差，不是SCE通胀中心误差；疫情冲击参与描述/训练，未参与该37月的预测评价；历史标签可得日按t-10假设，不能直接认证本批15—25个月旧源外推。

后续如做就业校正，应先只用当时可得的微观标签拟合，再以已公开BLS首发信息预测SCE口径的就业构成；不能把CPS劳动力失业率直接当作全体SCE受访者的失业比例。可先考虑温和的代表权重校准，不任意改写某个人的就业事实；54格与就业目标是否可同时满足须检查。顺序必须是先确定人口/权重，再匹配信念，最后重新校准上期全国中位数，避免权重变化破坏原先验约束。

收入只有旧候选资料准备，尚无相同程度的预测验证。SCE过去12个月家庭税前收入档与BEA当月个人收入、税后可支配收入不同；平均收入增速无法识别各档人数迁移。没有同口径的留后期收益前，不把宏观收入增长机械转换成个人收入档变化。就业/收入本轮均未接入运行包，也没有授权新调用。
