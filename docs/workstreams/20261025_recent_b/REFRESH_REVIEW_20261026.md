## 本轮研究的问题

微观资料滞后时，能否利用公开旧人口、已公布历史全国预期和截止前环境，生成近期全国SCE指标？本轮使用A阶段已完成的新闻配置，比较它相对旧B三档新闻的改变。新旧B应保留同一512户名单、权重、先验、食品/政策/信心、全国真值版本及共同截止。不是再次改变LLM模型，不把联合新闻规则的变化解释为单个参数的因果效应。

时序模型未必更好，只说明这个任务存在持续性强、样本少、结构变化等困难；**它本身不能证明模拟有贡献**。贡献要看同信息、同训练规则的SCE＋CPI模型加入模拟后是否改善，同时报告原始模拟的失败时期。报告可同时呈现机制实验、测量误差对账、有限增量与失败边界。

## 时间、人口与先验

- **范围：**2025-11—2026-09，共11个月；每月512户，每人一遍，共5,632主请求。不是从当前日期向前封存的未知月份预测。
- **截止：**沿用每月已经登记的共同截止日，11月为用户确认的2025-11-13纽约时间末；其他期为登记CPI发布日期末。B没有近期真人作答日期，不套A完成日前一天，也不随机添加晚于截止的日期。
- **人口：**保留既有54格分层及小格过采样、抽样概率和格质量校准。源波次按“调查月末＋九个日历月严格早于截止”的假设选择：202511→202501，逐月更新，202608/09均止于202510。实际源框架为989—1099人，512加权LLM代理代表该旧框架，不是近期实际调查者。
- **先验：**在相应旧源库末端1—3个月内，按相似人口选择完整联合Q8/Q9供体；通过分配概率倾斜及少量完整供体替换，使实际512户的加权Q9先验中位数落入已公布历史全国值±0.05pp。最大偏差0.046918pp。旧供体确实距目标10—11个月，但全国历史中心已更新到截止前公开值；不能把旧供体称为本人真实上月回答。
- **Q8：**与Q9保留联合供体关系，不用公开Q9中心强制校准Q8。
- **不新增：**本轮不设人口出入、不接个人连续递推、不用Normal代替LLM。没有近期真实人数及人口边际，不能声称扩展后恢复了当期真实全调查。512加权已代表声明的旧人口质量；若另做Normal，只能作为旧框架的统计扩展敏感性，必须单列目标框架和重新对应校准。

九个月规则是可得性假设，精确历史文件字节版本尚未认证。就业/收入随源记录，本轮不机械按CPS/BEA改写。历史文本版本与模型知识截止也未完全认证，因此仍称回顾性时点回测。

## 统计后处理：沿用结构，按口径固定参数

答题LLM与统计后处理是两层。后者不再调用LLM，能够用同一批模拟数据离线计算。

1. **原始模拟S：**按冻结Q9算法将十档概率拟合为个人密度均值，再按代理人口权重求月中位数。保留原始性能，不用后处理遮盖。
2. **持续性A：**截止前最后公开的官方全国Q9首发值。
3. **主简单组合：**Z＝(1−λ)A＋λS，λ固定为201901—202212早48月、原共同参考口径的MSE拟权0.133976257。MAE拟权0也列出。B11不重新拟权，不根据新B表现选择损失函数。A个人日期输出与公共参考锚的时点差异已记录，不能保证该权重能迁移。
4. **辅助时序对照：**固定两个已登记的岭回归家族，分别为SCE＋CPI，以及SCE＋CPI＋模拟。采用y−A作为响应，使用A水平、CPI同比与A的差、两次CPI发布变化；联合组额外使用S−A。正则强度沿用早36训练/随后12验证所得α100，在首个B截止前用201901—202510共82期A重估系数，随后B11全程固定、不吸收B结果重新训练。最新训练标签202510的公开日2025-11-07，早于首个截止11/13。

以上参数已写入`macro_parameters.json`。辅助模型的“动态”结构表示使用时间信息和外生变量；本轮实际系数固定，不声称是逐月更新系数，也没有MA/ARIMA残差过程。旧B与新B均要用这同一套参数重新计算，不能把旧B原先λ0与新版λ0.134混比当成新闻收益。

刚才的差分/触发器比较使用**月末宏观对照＋CoreNormal**。本轮B使用**共同截止＋未作Normal扩展的Core**，不能直接搬其0.2阈值及回归系数。先用简洁且有同结构宏观控制的家族完成主线；差分或触发器若追加，须按本批截止与Core口径另登记、重估，并保留完整控制，不把2021最优者自动升级。该追加不影响本轮LLM答题，可以在同批答卷上离线做，不需要再付一次模拟费。

## 日期随机化的澄清（审阅问答，未改变配置）

用户询问能否连续随机模拟日期。当前B输入仍为每月共同截止D；A已采用真实完成日前一天，B的经验日期抽样仅是此前候选，尚未接入本批。随机的受访/信息接触日期与预测者的全局信息截止是两个变量：即使抽到D以后的作答日，也不能使用D以后真实新闻。可令个人环境截止为min(合成作答日前一天,D)，并同步过滤新闻、价格、政策及提示中的时间说明；人口与先验的分析者可得信息仍按D管理，合成先验的参考日期/公开信息叙述另做一致性检查，不能把统计校准误称为该受访者实际读过某条信息。

日期未知时优先固定种子抽取截止前历史完成日的经验分布，不默认整月连续均匀，不用随机小时制造不存在的精度。若要完整使用各合成受访日前实际发生的全月新闻，应另设月底截止的即时回测/回顾性版本，不能沿用原月中截止的预测名称和基线。当前未决定采用随机版、未移动任何as_of或修改输入包。
