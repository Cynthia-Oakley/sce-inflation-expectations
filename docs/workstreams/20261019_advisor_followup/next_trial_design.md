# 下一项候选：Q8回答变化值，Q9仍直接填概率

## 为什么选择这一项

十二期网格诊断说明，同类家庭内部仍过度集中；仅增加类型或Normal人数不足以解决这一缺口。旧差值实验的Q8独立复算显示：完整支持下，个人误差与分布距离有所改善，但中心收益很小、两遍排序反转；旧提示同时改变Q8/Q9，不能确定改善来自哪一处。

因此，下一项只检验**表达本期水平，还是表达相对本人上期的变化，会不会改变模型利用先验的方式**。这是回答接口的机制检验，不预设人一定这样思考，不强制改动方向或大小，也不估计“正确更新权重”。平台目前不具备已确认的同输入模型替换条件，采购角色—价格材料还需要补齐，暂不同时并入。

## 对照与候选

- 对照：Q8直接填本期点预期，Q9直接填本期十档概率。
- 候选：Q8只填“本期点预期减本人上期点预期”；程序相加恢复本期Q8。Q9与对照相同，仍填合法绝对概率。
- 两组共同的画像、上期回答、更早摘要、环境、新闻及先验说明逐字相同。只替换最后的回答格式说明；草稿已核对共同前缀哈希。
- 一个人月缺上期Q8，两组均直接填本期Q8，不合成上期值，也不拿Q9均值替代。

Q8变化可以为负，例如3%降到2%时变化为−1个百分点；Q8本期值为负也可以表示通缩。**这与Q9概率为负完全不同**：概率仍必须在0—100之间且合计100。不裁剪差值、自动归一化或用回退值掩盖失败。

候选结尾的主要说明如下，英文全文与完整私有提示保存在草稿包：

> Q8：给出你本期的点预期减去上期点预期，单位为通胀的百分点。+1表示3%变4%，−1表示3%变2%，负变化允许。Q9：仍给出本期十个区间的绝对概率，不是相对上期的概率变化；各档0—100，总和100。
