# 师兄建议与现有研究计划的衔接

2026-10-19。依据用户当日下午汇报后的反馈。本文登记研究候选和执行顺序，不更换当前参考配置、不启动新的真实调用。旧实验和汇报保持原结论；本轮新增API调用与费用为0。

## 1. 更新每月变化值：先复用旧Q8，区分数值和概率

**建议的价值：**让模型从已有信念出发判断新信息带来什么变化，而非每次从公共信息重新给出一个水平。它与目前“个人位置保留不足”的观察相关，但报告差值不等于已实现真实更新机制。

已经做过的[直接/差值实验](../20261014_mechanism/revision_format_results_20261015.md)包含四期各24人、两组各两遍；直接回答192/192有效，完整差值118/192有效。69份还原后负概率、5份概率改动和非0。不能把剩余合法子样本的较低误差当成全样本收益。

注意三种负数不同：Q8点预测为负表示预期通缩；Q8改动为负表示较上期下调，均不因此自动非法。Q9某档改动为负也可合法，例如30%减10个百分点得到20%；只有还原概率低于0或超过100、总和不合要求才不合法。旧67份在原为0的档位继续减概率，属于具体边界约束失败。

**先做零API预检：**从旧原始回包按Q8自身合法性恢复全部可用点回答，比较Q8中心、个人误差和变化，不因Q9失败而一并丢掉Q8。保留Q8缺失/失败计数。它仍受“原提示同时改变Q8/Q9”的影响，只能作为是否值得小试的线索。

如有线索，新候选仅把Q8改为“相对上月变化”，Q9继续直接填合法十档；固定P/E、先验和其他参数，和直接回答作对照。当前尚未准备或授权。

**不默认裁剪再归一化：**仅除以总和不能消除负概率；截负数后归一化或softmax会改变答案，也可能把原本的零档变成正数。若将来使用有界概率转移等程序机制，应另立协议、报告改动幅度和全部原答。跨人标准化也不作为修复概率的默认方式；任何缩放只可由开发资料确定，不用评价期真值计算均值/标准差。

## 2. 人口网格化：先改变评价与抽样对象，再讨论扩人

**建议的价值：**研究同类家庭的条件分布，降低对“精确猜中某个真人”的依赖。网格内仍需多个人、不同历史信念和生成重复，不能把每格压成一个同质代表人。

项目已有[Core/Normal开发实现](../../CORE_NORMAL_ACCEPTANCE_20261005.md)，并曾完成[两月300 Core真实模拟与扩展](../../CORE_NORMAL_LLM_RECEIPT_20261005.md)。这不是全新工程；旧开发稿的500人固定全年设想也不自动恢复为现行配置。

**先用现有十二期轨迹做零API支持审查：**

- 从已有年龄、教育、收入、就业中选少量粗维度；按画像覆盖、格子人数及权重有效样本量确定可用交叉，不按预测误差选择分组。
- 对模型、同类真人及同类上期延续同时报告组中心、组内W1和IQR，以及跨期变化；同时报告未覆盖和稀疏格，不只保留表现好的组。
- 全国汇总必须合并各格的完整个人均值分布及人口权重后取中位数，不能平均各格中位数，也不能先平均十档后当作代表人。
- Core产生的分布可按组扩展Normal；扩展人数不增加独立信息，不能补出Core里没有的差异或消除共同偏差。新增真实LLM样本只优先补支持不足的格。

A可使用明确声明的当期真实人口构成；B须用截止前人口分布外推，并处理新入组者先验。回访者、新加入者和Normal分别报告。若用当期目标指标校准，约束检查与独立评价必须分开。

## 3. 模型对照：先核平台能否支持同输入

用户希望优先利用平台资助额度，避免Chat Agent编排。已有[本地平台接口记录](../../LOCAL_HARNESS_RUN_PLAN.md)及[10月17日核查](../20261018_targeted_mechanisms/next_experiment_plan_20261018.md)显示：问卷MCP当时默认登记为`gpt-4o-mini`，不是已确认的GPT-4o；工具未提供逐人自带P/E/本人先验及模型/温度参数。能力目录里的模型别名不等于问卷工具允许自由选择。当前状态需在执行前再核，不以旧记录认定永久不支持。

先核实际服务、可调用模型及版本、是否支持自带人口/问卷/逐人E和旧信念、原始回答导出、调用计价。无付费试跑前只查文档和免费能力；不使用平台Chat代替运行接口。

若支持，优先做一个GPT-4o（或实际可用的不同模型）与DeepSeek的同输入小对照，先覆盖少量不同经济阶段。固定画像、先验、新闻、问卷和评价；记录参数差异及实际返回身份。不能同轮换人口池、E和答题格式后把结果归因于模型。

若只能使用平台池，登记为“平台人口＋平台模型”的另一种方法对照，不能替换当前同人试验。Qwen/LLaMA已有[年度对照](../../SCE_ANNUAL_MODEL_COMPARISON_20261008.md)，优先复用；不默认同时铺开多模型。候选选型与独立扩大验证分开，新外发范围和预算另行确认。

## 4. 相关指标扩展：优先同一调查，不立即另起项目

先评估SCE已有的**家庭财务前景Q2**，次选家庭收入增长预期或失业相关概率；先核题意、字段覆盖、真值口径与基线。Q2五档与十二个月期限已有本地资料，能复用P、E和运行链，比立即转到另一份美国调查更省工程。

此前Q2试验将上期财务前景作为通胀输入；它未稳定改善通胀，不代表“预测Q2”这项新目标已经试过或失败。

扩展目标须有独立输入白名单：预测Q2时不能输入本期Q2或其派生标签；历史可得性照A/B区分。五档类别先评价完整类别分布、类别占比误差及概率评分，再与照抄/经验转移基线比较，不能照搬通胀pp误差。只有主线与复用条件允许，才做一个次要指标的最小验证，不同时扩展多个目标。

## 5. 与采购角色方向的关系及执行顺序

已有ATUS匹配和价格信息菜单保留；其任务仍是检验家庭角色如何改变接触的内容。网格化负责“对哪类家庭评价与抽样”，采购角色负责“同类家庭怎样接触价格”，模型对照负责“同样输入由谁作答”，三者不能互相替代。

1. **先不花API：**单独复算旧Q8变化值，审查十二期人口网格支持，并确认平台模型接口的实际能力。
2. **再选一项真实对照：**根据预检结果，优先在“可公平接入的另一模型”或“简化Q8更新格式”中确定一项；若两者无条件，继续已准备的采购角色—价格对照。每轮只改变一个主要设计，不把三项同时叠加。
3. **再做固定方案的独立月份验证：**每次先看同支持基线、中心和组内分布，分别报告抽样与生成重复。开发期好结果不直接升级默认。
4. **最后决定一个相关指标扩展：**复用已稳定的链路；不挤掉主线验证、研究报告和研究包验收。

本顺序是候选筛选安排，不冻结人数、月份、模型或新预算；不能把用户对方向的认可当成新数据外发授权。具体日程继续只在ROADMAP维护。

Kimi六项真人更新事实继续列为待复核，F3a解释、F3b工具有效性和CPI覆盖未审定前，不从其点估计直接设置更新权重。本轮不改历史实验或汇报快照。
