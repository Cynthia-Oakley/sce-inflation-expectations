# Qwen2.5同输入迁移：三期已完成结果

2026-10-19启动，2026-10-20完成本轮补齐与结果整理。**已接通并完成部分比较，未显示相对旧DeepSeek的整体优势；未升级默认模型。**原计划四期，实际三期完整，2022-03因第二次连接错误停止。没有继续补发。

## 1. 比较的是什么

原计划2020-04、2021-05、2021-11、2022-03各24人、各生成两遍；P/E、本人真实上期Q8/Q9、更早摘要、原提示、直接回答方式、温度0.5及输出上限1024均固定。Qwen2.5-72B经OpenRouter固定DeepInfra `deepinfra/fp8`；旧DeepSeek温度0.5前两遍直接复用，不再调用。不是人口网格化或新行为机制实验，也未拟合宏观组合权重。

实际纳入2020-04、2021-05、2021-11：72位受访者、72个人月、每模型144份回答。Q9共同支持65个人月，Q8为72；5份Qwen概率合计错误及2份真人Q9不可计分记录，使Q9支持少于72。某人任一遍Q9无效，其两遍都退出Q9共同支持，Q8合法点值继续保留。

- 144份均能解析JSON；139份Q9合法，5份概率合计错误（105%三份，99%两份），合法率96.5%。不归一化、不修补，未达到事前99%技术门槛。
- 供应商报告成功请求合计$0.191888；2次未收到回包是否计费未知，含其保守预留的使用量估$0.200809，原合计上限$1。
- 模型与供应商回包身份均匹配。模型调用两阶段跨度约191秒和276秒，评价约5秒；保存全部原答、参数、失败与费用。

## 3. 同一有效样本上的指标

以下Q9先按每月/每遍计算，再等权平均；模型、真人和照抄基线使用相同65个人月与设计调查权重，单位为百分点。Q8另按人等权，不混为同一个指标。

- **Q9样本中心MAE：**DeepSeek 1.563 → Qwen 1.644；同支持照抄上期1.317。
- **跨人分布W1：**2.748 → 2.868；照抄上期2.002。越低越好，本批没有改善。
- **个人变化分布W1：**2.345 → 2.506；更新分布没有更接近真人。
- **跨人IQR：**1.866 → 1.651，真人5.791。Qwen的回答仍偏集中，没有恢复更多人际差异。
- **Q8样本中心MAE：**0.850 → 0.933；Q8没有因Q9不合法而一并删除。

这些数值来自较小的三期共同支持，不是十二期全国误差，也不能与旧四期四遍的1.037或十二期0.459直接拼比。少量样本失效就会改变加权中位数；本轮两模型均在新共同支持重算。

## 4. 有哪些局部信息

**2021-11的中心有改善，2021-05则变差。**11月两遍平均中心绝对误差约1.584→0.962；5月约1.751→2.481；4月约1.355→1.489。因此没有跨三期一致的模型优势。

**概率填法存在模型差别。**通缩各档全部填0%的比例：DeepSeek5.2%、Qwen39.7%、真人77.2%。Qwen在这一项更接近真人，但逐人十档概率距离、整体分布和中心未同步改善。某一种填法相似不等于整个微观结构更准确。

两遍等人分解下，Q9人内重复方差为0.245→0.156，扣除重复噪声后的跨人方差为1.485→1.432。Qwen既没有更随机，也没有恢复更多稳定跨人差异；只有两遍，方差分解精度有限。

学历/数理分组只作描述：低数理组W1局部下降，但只有9个人月且逐月更少；高中组仅5个人月，不据此制定分组模型选择规则。完整分组及稀疏提示保留在公共聚合。

## 5. 从方法上怎么理解，下一步怎么办

这次保持同人、同信息，减少了输入不一致的干扰；但旧DeepSeek不是同期随机对照，两模型同一温度也不代表同等随机性。失败的Q9可能不是随机缺失，且四期未完成、有效样本小，所以本轮只报告描述值，不作显著优劣或全国推广结论。

当前证据说明：**在现有P/E与直接作答框架下，只换Qwen2.5未解决回答过度集中。**不能据此认定所有Qwen无效，也不能从这次模型对比单独确定P、E或理解方式哪一项是根因。

暂不追加Qwen扩样或继续网络重试，保留该模型作为有待修复数值输出的备选；也不自动重新启用新DeepSeek调用。下一项回到已准备的“采购角色—可见价格”离线工作：先让不同家庭真正看到不同的价格类别与细节，而不是仅附加频率标签；平台同输入接口未确认，不盲发付费问卷。模型最终选择、格式修复及下一项机制应分开验收。
