## 本批配置

- 月份：2020-04、2021-05、2021-11、2022-03；每期24人，各生成两遍，新增192次调用。
- 模型：`qwen/qwen-2.5-72b-instruct`；OpenRouter，固定`deepinfra/fp8`，禁止供应商回退。原消息逐字复用，温度0.5、最多1024输出token、无自动重试。
- 对照：复用温度试验中0.5组前两遍的192份DeepSeek回答；不新调用DeepSeek。既有对照不是同期随机分派，两家服务的同一温度也不表示同等随机性。
- Population：去标识年龄组、学历、收入档、地区/州、住房、就业、数理标签，合成CE四类支出占比与美联储信心。
- Environment及历史：原公开价格/新闻/政策，本人真实上期Q8/Q9十档、更早问卷均值/次数及信息先后标签。直接填写本期Q8/Q9。
- 不发送：原始ID、权重、当前真人答案、实际作答日、Q1/Q2、心理或ATUS/GSS原始记录。
- 费用：输入$0.36/百万token，输出$0.40/百万token；粗估$0.2123，保守预留$0.9063，硬上限$1。使用自购OpenRouter余额。

公开目录当次为status=0；这只代表路由目录健康，实际格式能力仍须本批检验。每个运行单元开始时重新验目录/价格，回包逐条记录模型、供应商与费用；身份或费用异常停止，不静默换模型/供应商。

## 如何评价

先验收技术迁移：192条完成、模型自身回答至少99%合法可计分、身份一致、0重试。真人Q9缺失不算模型格式失败，Q8/Q9分别报告共同支持。

科学比较优先看跨人W1、IQR、旧信念保留与更新分布，配合学历/数理等既定分组及两次生成的一致性。原始中心MAE与个人概率宽度同时披露；不会以中心下降替代微观结构，也不因中心未下降自动抹去微观收益。四个已看开发月、每期24人仅作迁移/筛选；不宣称全国或独立验证成功，不按本批真值改默认配置。

最终宏观组合另拟权、冻结后验证。本批不拟合或挑选组合权重，不把原始模型MAE等同最终组合误差。
