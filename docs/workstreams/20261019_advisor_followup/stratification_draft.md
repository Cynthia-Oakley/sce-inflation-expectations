# 人口网格草案：三档学历×是否在职

2026-10-19。用户认可先设计网格并推进Q8格式对照。本稿只确定候选规则、支持和未来抽样示例，**没有替换旧人口，没有扩样，没有接入新的Normal扩展**。

## 1. 六格具体是什么

学历沿现有三档：高中及以下／部分大学教育／大学及以上。每档再分：

- 在职：原字段为`employed`或`on_leave`。
- 未在职：失业、退休、残障、学生、家务或其他原类别。它不是“失业率”，也不是BLS/CPS劳动状态的重新计算。

两项任一未知，放独立未知池，不默认退休、低学历或未在职。保留原始完整画像；“退休”和“失业”等仍是不同标签，只在此次粗分层中合并。六格不是六个代表人，每格仍有不同收入、历史信念和环境接触。

依据是现有观察性关联：学历更关联个人不确定性，就业有预期水平的附加信息。它们相对稳定、可测、能用于人口抽样，优于把当期主观Q1直接定义成固定人口类型；不是已证明最优的交互模型。ConsumerSim四维分层作为方法参考，不照搬SCE没有的字段。

## 2. 其他重要变量放哪里

- 年龄、收入、地区：检查抽样前后加权边际覆盖，继续保留在每个人画像里；不再全部交叉成数十上百个格。
- 数理：作为独立的概率表达诊断分组，不在每个基础格继续切两半。
- 财务Q1：若研究该机制，再将差／相同／好／未知作为随时间变的状态。当前只用于未来诊断安排，不加入本轮Q8提示。
- 退休、失业、家务等：在未在职池内分别描述；条件允许再细分，不将它们解释为同一种经济处境。
- 本人先验与过去常态：继续作为个人状态，不用本期答案或其派生高低决定格子。

## 3. 已有数据支持多少

用十二期每期192人的原始入样画像检查，未根据模型/真人误差筛人，生成两遍只计一个人月。六格×十二期共72个格月，63个同时达到n≥10且ESS≥10；7个n不足，另2个权重集中导致ESS不足。主要缺口仍在高中及以下，特别是未在职组：2022-06只有2人、ESS约1.44。

n≥10、ESS≥10只是展示支持筛查，不能当作充分统计功效。未知画像另报。此前年龄×学历九格的格内方差诊断仍有效，但不能将89%的比例直接套到这套新网格；本轮不为新网格重新看误差挑优胜者。

## 4. 未来Core怎样抽：只作规则示例

从已有微观缓存读取**画像、权重、相邻回访和上期有效性标记**，不读取本期通胀答案作为入样条件。十二期可准备的回访先验池约794—1,058人/期，仍不是全国全部受访者，也不是已经完成运行可用性验收的人口包。

给出每期192 Core的示例：

1. 每个非空基础格先分配至少12人；未知池人数不足12时全部纳入。
2. 余量按原调查权重汇总的人口质量分配，受该格可用人数限制；不按模型误差多抽或少抽。
3. 真正执行时在格内简单随机不放回，记录格内人数N、抽取数n及概率π=n/N，使用原调查权重/π。最低数无法满足时明确调整设计，不偷偷删除一格。
4. 检查实际样本ESS、年龄/收入边际；不事后换人直到结果看起来好，否则原概率不再成立。

最低12是透明的开发覆盖起点，不是估计出的最优值。示例分配已算出，但没有抽出或外发任何新家庭。**本轮Q8实验仍是旧四期各24人，不能把192示例理解为本轮规模。**

## 5. Normal以后怎样扩展

保留原来的整份Q8/Q9联合回答供体思路，避免分别拼概率档或把每格压成一个均值。旧扩展器仍使用旧分组，未在本轮改写；新适配需记录本格供体、同学历回退、总体回退的质量与权重占比，再按人口权重汇总完整分布取中位数。Normal数量不增加独立Core信息，也不会凭空恢复个体信念。

A可明确使用历史当期画像和真实过去回答；B还需截止前人口外推及新入组者初始化，不能把A池和真实先验直接搬过去。本稿不宣称解决B或全国代表性。
