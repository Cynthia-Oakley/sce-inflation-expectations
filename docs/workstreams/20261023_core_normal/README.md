## 当前主线：统一缺失先验

**用户已确认：当前不采用Core＋Normal补缺失信念；未来确有扩大模拟人口的需要时再考虑。**原问题是A线新人缺本人上期信念，后续B线也可能普遍缺少近期个人微观。此前将这个问题推进为全人群Core规模优化，扩大了研究范围。960及1728位置提案均未真实调用，当前不继续准备其付费执行；已有方法、名册和离线结果保留。

两种环节要明确区分：

- **缺失先验初始化：**历史资料→某人的合成上期Q8/Q9→该人结合本期E由既有LLM作答。它解决输入状态不可观测。
- **Core＋Normal当期扩展：**部分人的当期LLM答卷→统计预测其余人的当期答卷。它主要节省调用，同时引入近似误差；不能自动得知新人的真实先验。

当前采用前一种处理思路：补好先验后，样本内每个模拟居民仍由既有LLM结合环境作答。最终抽样人数与预算另定，本次不改既有参考配置；Core＋Normal留到未来扩大模拟人口时另议。

### A/B尽量共用的方法

共用“来源及时间筛选→按人口/新老类型构造历史信念条件分布→抽取完整Q8/Q9起点→可用历史总体约束→LLM＋当期环境”流程。保留合成来源、时效、抽样种子与不确定性。能取到本人合法历史时优先保留，不把其替换成他人均值；新人没有真实答题次数，不虚构过往问卷经历。合成信念只代表可能的起始状态，不能当作已找回的本人真值。

- **A线：**回访者使用允许的本人历史；新人、缺字段或过旧者，沿现有近1—3个月匿名供体及软校准。已有实现及小试可复用，不重做整套初始化。新人/回访者身份保留，不能假设两者给定画像后完全可互换。
- **B线：**历史库和人口都要满足截止前已公开。若近期微观尚未公布，现有固定1—3个月窗口无法直接套用；先研究如何用已公开的旧信念库、截止前最后公开的历史SCE汇总等，将状态更新到预测起点，再交给同一个初始化/作答接口。不能把2021年的原答直接改称2025年上期信念，也不能借尚未公开的上期微观。
- **校准边界：**两线都不用目标月真人答案调本期输入。A可用其已声明的历史条件；B只能用截止前已公开的历史统计。单一全国中位数只能约束总体中心，不能识别完整微观分布；B的群体差异、离散及旧库更新还需验证，当前未实现。以共同框架复用为目标，不声称同一组固定参数可无条件跨A/B使用。

用户提出的“整体中位数与真值一致”明确作用于**初始化所代表的历史时点及相同统计口径**：A校准到允许使用的历史参考，B校准到截止前可得历史统计；更近尚未公开月份只能估计，不能称已知真值。校准保留真实历史字段，只调整合成部分的抽取概率，事先登记容差、可行性与残差；离散抽样不能精确达到时如实报告。不能拿目标月SCE真值调整当期输出来保证本期MAE。中位数对齐后仍需检查分布和分组差异。

### 下一步限于什么

1. 梳理现有A线初始化的输入/输出、已验证条件和失败边界，作为共用接口；不另造同义模块。
2. 补B线最新可用微观的版本/发布时间与截止前最后公开SCE值，明确旧库时效和最少的更新假设；先零API准备。
3. 优先用历史微观做“隐藏本人上期信息”的离线验证；为模拟B的滞后场景再隐藏整段近期微观。只在评价层使用真值，分别评估初始化分布与本期模型回答。回访者遮蔽检验不能证明已恢复新人的真实先验，新人原本就没有可观察的本人上期答卷。已有新人小试保留，不追求重新抽样拿到好看结果。

以上是收束后的待办，不表示B初始化已经实现或离线验证已经完成。Core＋Normal规模、τ搜索以及更大Normal人口数后置，未来扩大模拟人口时再作为单独方案审阅。

## 统计模型与权重

同一月给定有效权重人口P及Core，细格采用学历×数理×年龄×收入；部分未知保留其已知特征。新人/回访者不跨池借答卷。对目标细格，局部经验分布p只来自同格有效Core。经验先验H只来自同入组类型、细格不同且已知人口特征匹配数最多的Core；可同时向只差年龄或只差收入的格借信息，不任意优先某一维。局部与父池答卷严格不重叠。

局部有效人数n_eff＝(Σd)²/Σd²，α＝n_eff·p＋τ·H，预测分布为α/Σα。局部无人时显式回退H；整个入组池无有效Core时报告不支持，不静默跨新老类型。τ为固定或开发期选择的强度。调查设计权重与经验先验使它是**加权经验贝叶斯／伪Dirichlet估计**，不是精确的多层抽样似然或逐项复制ConsumerSim。未给出可当完整频率学覆盖保证的后验区间。

有限人口主汇总：

`F̂(x)＝[Σ有效Core w_i·1{x_i≤x}＋ΣNormal w_j·F̂_g(j)(x)＋Σ无效字段Core w_k·F̂_g(k)(x)]／Σ目标人口w`

Core的w/π及格内校准权重只用于估计条件分布；保留Core的实际人口份额时用原始w，不再把w/π作为另一整份人口加进来。全员都是合法Core时，F̂必须精确等于原答卷分布。Q9个人值仍是冻结计分的密度均值，再取跨人加权经验CDF左逆中位数；Q8另保留现有中分布插值规则。所有Normal只抽完整供体答卷，不复制“平均十档概率”，缺失的配对Q8不捏造。

## 为什么留有v1/v2

第一版采用全细格后验预测，包括重新估计已知Core；这本身是一个总体分布估计器，但不满足本项目有限人口“已生成Core保留、只补Normal”的目标。v2增加这一结构约束和全员Core还原测试，不增加新人口变量或重新搜索网格。

v1源码在`outputs/sce_core_normal_before_finite_20261023_v1/`，原真人/缓存LLM结果均保留。主结果改用下列v2，不覆盖原协议或声称第一版已经通过该极限测试。

v2是在查看第一版输出后按有限人口边界作出的结构修正，同一数据重算，不能当独立确认性验证；τ的开发期选择规则未因后期结果改变。

## 离线设计与主要结果

协议：`evaluation/core_normal_protocol_20261023.json`。本轮是开发验证，协议在计算前保存，不称公开预登记。方法变体仅Core加权、τ＝0/8/24；每月Core256/384/512、各两个固定分配种子。τ在2019—2022的Normal留出上以W1为主、中心MAE相对τ0代价不超过0.05pp的既定规则选择；三规模均选24，随后冻结。后期已经研究过，不冒称新盲测。

### 真人Core统计参照

2019-01—2025-10，82月。人口/权重先确定抽样，之后才投影被抽Core的当前答卷作**评价用理想参照**；Normal当前答案不进入扩展器。使用已有官方Q9均值/IQR，无新拟合。原98,382人月中30条无有效原始权重的记录未参与本次加权检查，不补1，也不据此从生产P删除居民。

2025年1—10月，256/384/512真人Core＋Normal的全波次中位数近似MAE分别约0.124/0.102/0.078pp，对应W1约0.549/0.361/0.239pp。仅Core设计加权约0.099/0.086/0.077pp，W1约0.526/0.344/0.232pp。早期有部分分布收益，后期未稳定超过Core加权。**这些不是LLM拟合成绩，也不是LLM误差下限，不能从模型MAE中扣除。**

Core与Normal在当月不重叠；同一人可跨月出现，未假设人月独立。此轮以逐月/种子和时间检查描述差异，没有凭扩展人口数构造显著性或宣称置信区间已覆盖真实模型误差。

### 已有V3.2答卷留出

八个月、两遍分别保留；旧框架96人抽64Core、192人抽128Core，保底1。权重包含旧框架设计权重与本次抽样概率，不能当完整SCE波次54格的最终Core规模验证。总体拟合、分布保留与Normal局部损失分别计算。

- 相对完整已保存LLM分布：仅Core加权→τ24扩展，中位数绝对偏移0.123→0.130pp，W1 0.314→0.286pp；只看Normal时W1 1.631→1.284pp。分布收益不等于中心无代价。
- 对同一已保存人群的真人：完整LLM的中心MAE约0.229pp；缩小Core加权约0.325pp；Core＋Normal约0.353pp。W1约1.206/1.287/1.288pp。此轮不支持把Normal称为拟合改进或直接升级全量。
- Normal目前按人口特征和入组类型推断，未按Normal本人的历史信念进一步条件化。因此只能检验群体分布近似，不能宣称恢复个人惯性、逐人排序或真实轨迹；人口网格不能代替这些动态信息。

## 后续LLM小试已准备到哪一步

2021-09／2022-06／2025-06，各256Core＋64个Normal留出审计者，共最多960次新请求、单遍。核心问题是减少LLM调用后，对实际人群与LLM全调用参考分别损失多少。审计者的LLM答案不用于估计Core分布；Core同一份回答可离线比较所有预定τ，避免重复调用。

名册包：`outputs/sce_core_normal_pilot_preparation_20261023_v1/`。已输出每月正权重人口、Core／审计名册、π与两层权重。当前仅**roles_ready_not_prompt_or_api_ready**。需要依据接口契约接近期本人/供体起点、既有E/新闻/价格/政策提示，做精确缓存去重、官方Core干跑和token预算后，另申请具体发送范围与预算。尚未向API发送任何新个人资料，没有授权文件。

鉴于缓存结果显示代价，不预先承诺采用Normal或256Core。小试前保留“仅Core加权”作为宏观参照，明确能接受的调用节省和误差代价；不能继续根据同一评价月份无止境微调。
