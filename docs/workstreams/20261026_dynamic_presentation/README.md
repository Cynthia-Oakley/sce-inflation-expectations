## 模型类型

当前实现是扩展窗口岭回归，具有ARX式条件均值结构：使用最后公开SCE水平、最新已发布CPI同比与锚的差、CPI同比相对前次发布的变化、模拟相对锚的差，以及可选CPI≥4状态及其与模拟差的交叉项。最新公开SCE偶尔跳过一个调查月，不能严格标为固定ARX(1)。动态是逐月用已公开标签重新估计系数，不是卡尔曼状态模型、Markov switching或个人信念递推。

没有加入滞后预测误差，未拟MA或ARIMA(p,d,q)误差过程。响应y−A是相对公开锚的修正，并有A水平项，不等于确认ARIMA的d=1；CPI差分只是两次已公布同比值之差。简单凸组合也不是统计术语中的MA模型。术语参考[Hyndman与Athanasopoulos动态回归](https://otexts.com/fpp3/dynamic-regression.html)。

## 呈现层级

- 主衍生指标保留简单凸组合；原早48月拟权、后34月评价的MSE与MAE两目标都披露。原共享参考下模拟权重约13.5%、后34MAE .184980/持续性.194118；MAE拟权0。原始模拟全国MAE、W1/IQR等不能被隐藏。
- 辅助指标为动态回归，至少同时报官方持续性、SCE＋CPI、不含模拟但含同状态项的控制，再报加入模拟/交叉项。训练、发布过滤、参数更新和验证规则一致。0.146475仅是原口径2021下半年；全年0.274024，上半年0.401572。
- 贡献必须以相对宏观同结构对照的增量为准，不能只用复杂模型比照抄上期。尚不写成“大幅提高异常初期预测能力”。

## 本轮补查发现：公共截止仍影响基线强度

旧辅助对照虽已有SCE＋CPI，均按原共享月中截止构造宏观信息；A模拟却按个人完成日，最晚到月底。因此增加月末纽约时间截止的宏观敏感性对照，完全保留原结果。例如2021-06的原6/10只知4月SCE3.4，月末已知6/14发布的5月SCE4.0；2021-12也有同类差异。仅新增比较，未替换正式as_of。

按相同2019—2020的18/6选参程序、同一α网格、同特征家族，扩展窗口更新只纳入真实已公开标签。同一规则继续至2025-10，共58个后期月；2021不再另选参数。月末主结果：

- 2021全年：持续性.250000，动态SCE＋CPI .244727，加入模拟.241566，增量.003161pp；非状态家族均选择相同α100。
- 2021下半年：持续性.200000，SCE＋CPI .186894，加入模拟.185162，增量.001731。
- 状态控制2021 .239545，加入模拟交叉反为.363905；原口径该组.274024的较好结果不够稳健，不升级交叉项组。
- 2022无状态宏观控制.390067、加入模拟.390727，略退；持续性.383333。
- 后34月无状态宏观控制.174058、加入模拟.173162；全58月.233371/.232328。配对区块区间均跨零，增量小。

额外把月末锚代入原早48/后34的凸组合公式，MAE/MSE拟得模拟权重均0，后34结果.176471，即月末持续性。原口径13.5%和.184980没有改写；不跨截止比较，也不只展示有利时点。最终研究应清楚说明任务是共享月中参考还是月末回顾性重建。真实当期P、个人真实历史及模型知识边界仍在，月末宏观对照并未认证严格B预测。
