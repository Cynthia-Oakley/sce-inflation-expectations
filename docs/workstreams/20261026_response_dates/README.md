## 数据与比较规则

- 原日期源覆盖201701—202510共106个月，130,216行。只投影date、survey_date、weight三列。
- 描述与历史比较为201901—202510的82个月，98,382行；日期无缺失，42份在标称月外，单列排除，留下98,340份月内日期。加权敏感性再排除30份非法/缺失权重。
- 各月先归一化，跨月等权，不让人数较多月份自动主导。30天/31天月份分开绘制每日频率；2月仍进入完整指标。
- 四候选：全月均匀、前一年同月、最近6个可得月、过去最多3年同月。历史来源资格按目标月15日及既定九个月滞后假设选择，不能使用目标月或尚不可得的较近波次。
- 来源日概率按“在月内的比例位置”与目标日区间重叠作质量守恒映射。月份等权混合，无额外拟合星期/节假日/人口条件；这是简单基准，并不精确还原邀请日历。
- 量化每日TVD、最大CDF差、日期W1（单位天），并比较在档案CPI发布日期之后完成调查的比例。日期W1复用共用评价函数，不能与通胀W1百分点混称。
- 512人条件抽样噪声：对真实经验日期PMF独立多项抽样500遍、固定种子，仅给规模参照，不当成复杂调查／面板总体置信区间。

## 已观察结果

82月等权平均：1—10日29.81%、11—20日41.58%、21日至月底28.61%。均匀分布的月中比例约32.9%。12日与19—21日前后有明显集中，但不能把它理解为每月完全相同的固定三峰。

主日期W1平均：均匀1.474789天，前一年同月0.938983天，最近6可得月0.883675天，最多3年同月0.955792天。调查加权敏感性依次1.567698、1.033370、0.947570、1.050789天，结论方向一致。512人的条件抽样噪声约0.390948天。

均匀方案平均最大CDF差11.31个百分点；CPI发布后完成比例的平均绝对误差5.645个百分点，前一年同月5.266、最近6月5.049、最多3年同月5.006个百分点。日期分布有可见差异，但不能把这些变化直接换算成SCE MAE改善。最近6月与前一年同月的日期W1仅差约0.055天，不值得为此继续反复调模型。

建议经验日期作为优先候选，均匀作为简化对照；目前没有二者几乎等价的证据。经验抽样只需一组不超过31个概率，不显著增加工程量或LLM成本。全月作答日分布与经全局D封顶后的有效信息日期分布不同：后者会在D处有集中质量，不能称其仍为连续均匀。

机制依据：纽约联储2017方法说明3.2节与附录A，分批邀请及提醒会形成响应峰。[官方原文](https://www.newyorkfed.org/medialibrary/media/research/epr/2017/epr_2017_survey-consumer-expectations_armantier.pdf)。该历史说明解释机制；当前具体日期比例以本地2019—2025记录为准，不假定邀请制度每年完全相同。
