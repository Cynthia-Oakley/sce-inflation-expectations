# 新版路线A全82月：离线评价与新旧比较

更新：2026-10-26。生成和一次技术补跑均完成；本轮只读封存回答、沿用原评分口径，新增API为0。原始运行与旧报告/研究包保留。

## 主要发现

全国Q9中位数MAE由旧版0.317093降为新版0.298407pp，下降5.89%；RMSE由0.469650降为0.415121pp。公开历史参照MAE仍为0.223171pp，新版尚未在全期胜出。旧回答放到新版相同名单和权重后MAE为0.317508，14份预设排除不是改善的主要来源。

2021年MAE由0.822126降为0.577424pp，下降29.76%；9/12个月改善，但全年12个月仍低估，尤其6—10月偏差仍较大。同期历史参照为0.325pp。2020年0.150203→0.231420、2025年1—10月0.156775→0.276287变差，不能说新版在所有时期更优。全期39/82个月改善；6月块重采样的MAE差区间为[-0.094083,+0.049286]pp，跨零，是固定本批样本和模型条件下的回顾性不确定性，不覆盖所有随机性。

按2019—2022早48个月拟权、2023-01—2025-10后34个月评价：MAE目标拟得模拟权重0，组合等于历史基线0.194118pp；MSE目标拟得权重0.133976，后34月组合MAE为0.184125、RMSE为0.256272pp，低于相应基线0.194118/0.270076。纯新版同段MAE为0.214613。该顺序与旧版一致，但晚期结果曾参与探索，不能重新命名为未触碰的独立盲测。全82月样本内拟权另列描述结果，不替代这项时间切分比较。

同名单、同权重且真人Q9合法的41,042个人月上，Q9中心MAE0.313926→0.310110，W1 2.121269→2.219218；跨人IQR 2.347834→2.247712，真人为5.260960。Q8有41,777个有效共同个人月，中心MAE0.818293→0.721951，但个人MAE8.172607→8.214558；宏观进步不代表个人分布更逼真。真实相邻上期Q9可得的33,715个人月另评：新模型中心MAE0.309421/本人上期0.211198，W1 2.064200/0.511713，仍未赢过本人上期。

## 改了什么与不能推断什么

新版T0按实际完成日前一日纽约时末同步过滤新闻、价格、政策等，采用随机4/8/16/32档新闻和CPI相关度1.5，个人警示权重为1。旧版是共同月中截止和随机3/8/20篇；人口、既有信念、主模型、温度、评分器沿用。多个环节同时改变，新旧总体差异不能识别单个机制的因果效应，也不能排除模型随机生成的贡献。

全国指标使用全部可运营模型输出；微观比较按相同合法真人支持。全国公开历史基线沿用旧截止登记的固定比较锚，新版个人日期各异，不能把它写成逐人同一as_of的严格事前预测竞争。路线A本身为历史重建。路线B仍保留已完成旧B11，未在本轮自动运行或更改。
