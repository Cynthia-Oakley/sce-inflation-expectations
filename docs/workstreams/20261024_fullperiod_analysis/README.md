日期：2026-10-24。用途：先明确问题、对象和比较方法，再展开全时段分析。本文是结果到齐后的分析安排，不冒称实验前预注册；已见技术质量与少量汇总读数。正式口径沿用冻结的`evaluation_recipe.json`及运行协议，新的探索分析另行标明。

**已完成本轮分析：**[图文报告（正式v2）](../../reports/20261024_fullperiod_v2/index.html) · [结果解释与复算](results.md)。全期全国MAE0.317/基线0.223pp；后34月纯模型0.176/基线0.194pp，冻结组合λ=0故组合0.194pp。人际IQR仍明显收缩，个体条件增量小。0新增API/0Q9拟合/0配置修改；详结果页的支持与解释边界。

## 一、这次分析要回答什么？

按顺序回答五个问题：

1. **总体表现：**模型能否重建整段历史，而非只在个别抽样月份表现好？
2. **增量信息：**相比沿用上月值，模型究竟提供了多少额外信息？与历史值组合后，较晚时期是否仍有收益？
3. **微观结构：**总体中心之外，人群分布、个人排序、概率表达和信念变化是否接近真人？
4. **误差位置：**哪些时期、哪些家庭、哪类初始信念出现偏差？差距来自组间水平还是组内收缩？
5. **下一步行动：**哪些发现足以支持报告结论，哪些提示必要工程或下一轮机制验证？

前四项使用现有回答和评价缓存，不新增模型API调用。先整理证据，再决定新增模拟的必要性。

## 二、先固定分析对象

### 数据范围与版本

- **历史范围：2019-01至2025-10，82个月，每月512人。**共41,984个逻辑人月；包含回访者、新受访者和其他历史缺失者。
- 主批次每人一次独立月度生成；不是82步自主递推。技术补跑是修复失败字段，不是额外的独立生成遍数。
- 54格为学历3×数理2×年龄3×收入3，未知画像另池。采用冻结的设计与格内校准权重；512人代表整月抽样框，未使用Normal代答。
- 原始一遍、361份技术补齐、后续6份定点补齐均单独保留。主报告使用技术修复后的版本，并附原始一遍敏感性。合并仅看技术合法性，不根据预测误差选择回答。
- 原始调用、逐字段合并、有效回包、后备、概率归一化和连续密度计分异常分别计数。技术成功率与可计分率分开。
- 当前已知29份密度计分边界保留原始概率；6份再次补跑后，如新增计分异常，按同一规则登记。不得把合法问卷重抽到计分器支持的形状。

### Q8与Q9分别评价

- **Q8：**本人直接填写的有符号点预期，单独评价；不因Q9失败而删除合法Q8。
- **Q9：**十档概率经冻结计分器拟合连续密度，取每人密度均值；每月中心再取跨人的设计加权中位数。
- 跨人IQR衡量不同人的中心分歧；个人Q9内部IQR衡量该人自己的不确定性。二者不能混称“方差”或相互替代。

### 三种比较对象分开报告

1. **同一批人：**模拟与相同512人中相同真人有效支持比较，用于观察模拟误差。
2. **完整微观波次：**模拟与该月全部可用真人答卷、同一冻结计分器的结果比较，包含抽样代表性影响。
3. **官方全国发布值：**模拟聚合与归档的纽约联储发布指标比较，同时披露官方指标和本地微观计分/支持的差异。

宏观模型聚合不依据本期真人回答是否合法筛选模拟人群。同支持微观评价为另一张表，不能混用两者的MAE。

全国误差可以先做标量分解：

`模拟Core − 完整真人波次 = (模拟Core − 真人Core) + (真人Core − 完整真人波次)`。

三个量必须使用明确、兼容的支持与权重。官方发布值与完整微观波次之间再单列口径差，不把抽样或计分差全部归因于LLM。

## 三、第一层：全时段的总体表现

### 主要比较

- 原始模型、相应持续性基线，以及已冻结的历史值—模拟值凸组合。
- 同支持全人群基线是“保留分配的起点”，其中真人与合成起点分开；“照抄本人真实上月”只用于真实相邻回访者。
- 全国基线使用截止前最后公开的全国SCE值，逐月标明其实际参考月份。不能把未公开的上月微观记录当成严格B可用资料。

### 指标与图

- 主指标：Q9月度中心MAE；同时报告RMSE、平均有符号误差、逐月误差及胜出月份比例。Q8另列。
- 月份在总体MAE中等权；每个月内部按人口设计权重聚合，不能把人月混在一起算成另一个目标。
- 一张全82月时间线展示真人/模型/基线；逐月误差图定位偏差集中期；年度及预先划定时期摘要帮助阅读。
- 时期概览先采用2019、2020—2021、2022、2023—2024、2025年截至10月，不依据模型赢输重新切段。不同期间长度和月份数一并披露。
- 大变化/小变化月份的比较作为描述性诊断；若按本期真值变化分组，明确这是事后分类，不能作为预测时可用的切换规则。

## 四、第二层：模型增加了什么信息？

### 1. 先看可比的加权组合

沿用已登记的公式：`组合 = (1−λ) × 截止前公开历史值 + λ × 本月模拟值`，`0≤λ≤1`。

- **2019-01至2022-12（48个月）拟合λ；2023-01至2025-10（34个月）评价。**不在全82月拟权后将同段拟合误差当预测成绩。
- MAE最优与MSE最优权重分别保留，对应评价MAE、RMSE和大误差月份表现；不临时挑一个最好看的损失函数。
- 同时展示纯历史、纯模拟和组合；报告模拟权重、相对基线的误差变化、偏差与最大误差。小权重但稳定有收益，也有实用价值；权重大本身不是成功指标。
- 使用既有按月配对、6月移动区块区间估计，保留时间相关性。区间与实际改善幅度共同解释；全样本逐月胜率不代替留后期表现。
- 34月是组合权重的时间外评价，但部分月份此前参与机制开发，不能称整套机制的盲测，也不能证明模型无训练知识污染。

### 2. 再做个人层面的信息诊断

在真实相邻回访者上，比较“只用过去信息”的统计模型与“再加入本期模拟判断”的模型；同时报告模拟单独进入、历史单独进入与两者联合的结果，避免只用一种变量进入顺序解释贡献。

- 变量包括真实上期值、更早常态/次数、冻结人口特征及月份共同因素；未来或本期真人答案只作被解释变量。
- 用增量/部分R²、残差化后的模拟信号与系数判断信息重叠；共线性较高时不把一个系数不显著等同于无信息。
- R²属于解释性诊断；新增校准若要成为预测方法，必须单独按时间拟合和评价。含月份固定效应的事后拟合不直接作为未来预测器。
- 月度层面只有82个观测，48/34划分下不堆大量宏观自变量；个人层面虽有人月数，也不能当作彼此独立的41,984人。

## 五、第三层：微观结构有没有复现？

### 横截面与概率表达

- Q9个人中心的加权W1、跨人IQR、个人中心MAE及模型—真人秩相关。
- 个人概率分配：十档概率距离、Q9内部IQR、零通缩概率占比和取整/集中表达习惯。使用既有统计实现，暂不另换计分器。
- 区分“整个人群一起偏高/偏低”和“中心接近但分布太窄”。可在评价层把月度中心差对齐后重算W1作为诊断，但对齐使用了真值，不能列为模型预测成绩。

### 跨期变化与旧信念保留

只在**本期与真实相邻上期均有效的同一真人**上比较：

- 真人更新＝本期真人回答−本人真实上期回答。
- 模型更新＝本期模拟回答−其输入的本人真实上期回答。

本批是独立月重建，不能把上一个月独立模拟人的回答混进来，误称自主递推。新人或供体起点不构成真实个人更新真值。

重点看更新W1、保持不变比例、方向一致性、更新幅度与上期高低的关系，以及模型是否比真人更强地向共同中心收缩。回归关系先作描述，不据单一斜率直接设定行为参数。

稳定个人差异、月份共同变化与个人特有变化的进一步分解列为第二轮深入分析：先核对面板支持，再选择双向效应/方差分量方法；不平衡面板下不声称各方差天然正交，残余也包含测量误差。

## 六、第四层：误差集中在哪些人？

固定分组沿用已登记项：学历、数理能力、年龄、收入、四大地区、真实入组状态、初始信念来源，以及54格联合画像。先看单维及有足够支持的联合格，避免一开始展示大量稀疏数字。

- 每个格同时显示N、权重ESS、权重质量、真人/模型中心、中心偏差、W1及IQR比。
- 沿冻结门槛：**N<20或权重ESS<10仅作描述，明确标注，不排名机制。**跨月汇总同时说明每月支持与重复受访者情况，不能靠合并人月掩盖月内稀疏。
- 回访者、新人、其他历史缺失者分开；“首次进入Core”不等于“首次参加SCE”。合成起点的质量另看，不归为真人上期基线。
- 先验高低可按当月输入的加权分位点作补充描述，并处理并列；不利用本期答案挑阈值。
- 总体W1不是各组W1的加权平均；总体中位数也不是各组中位数的加权平均。组间/组内差异需要另写明分解对象和算法，不能直接相减当作因果贡献。
- 关联到收入、教育、新闻量或采购角色时，先核查分配规则和共同因素。全量运行主要评价整体配置，机制效应仍应结合早期同输入对照，或后续另做对照。

## 七、质量、稳健性与边界

1. 原始一遍与技术补齐版比较，固定名册后备与实际有效输出敏感性比较；Q8/Q9分别处理，披露29类计分边界及补跑后变化。
2. 按月检查原抽样真人与完整波次的差异，区分抽样代表性与模型偏差；统一设计权重主口径，等人权重仅为敏感性。
3. 区间估计按比较对象选择：宏观按月份保留序列相关；个人回归考虑同一人重复与月份共同冲击。选择前说明估计对象，不用简单人月独立bootstrap。
4. 单次主生成不能识别LLM重复生成方差。技术补跑只针对失败者，不能将其与原答当成全人群重复实验。
5. 2025-11至2026-09不在这82月微观重建内。近期阶段需先核可得P/E、起点与发布时间；没有公开微观真值的月份只能先评价全国指标，不能捏造微观验证。
6. 模型预训练知识风险、A线使用真实个人历史与严格B的差别单独保留。事后归因、校准及对齐不冒充智能体原始预测。

## 八、具体推进顺序和交付

### 第一步：收齐技术补跑并固定分析版本

仅处理六份残余，不改人口/E/模型/提示。记录实际是否补齐，成功Q8保留。固定主分析路径、计分哈希、数据字典和质量表；原始版本保留敏感性。

### 第二步：做总体与组合结果总览

先交付全时段曲线、三种比较对象、48/34月组合比较和时期摘要。回答“总体到什么水平，模型增量在哪里”。使用已有readout，不重新调用模型。

### 第三步：做微观、更新与分组诊断

再交付分布图、更新图和有支持的分组图；优先定位共同偏差、组内收缩和旧信念保留不足。回归增量与进一步方差分解作为解释层，避免替代基础图形事实。

### 第四步：形成报告结论与剩余工程清单

汇总已支持结论、局限、近期11月资格、复算入口和成本/许可。只有当结果指向明确缺口且预计有信息价值时，再讨论新模拟。

**展示原则：**正文围绕上述五个问题组织，核心图约六张；每张先有一句结论，再给支持和边界。详细月份、54格及敏感性放附录/既有面板。沿用中文楷体、英文Times New Roman及高对比配色，明确区分真人、模拟、基线和组合。
