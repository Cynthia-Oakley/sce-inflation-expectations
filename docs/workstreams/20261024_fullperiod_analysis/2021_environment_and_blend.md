# 2021年低估：环境定向检查与加权组合

## 2. 环境文件有没有错月、丢失或没有送进去？

针对2021年12个月、每月512人的全部 **6,144份原始请求**，逐份重新渲染并与实际发送的messages比对，**全部一致**。检查了：

- 食品总体及实际显示的细项，与归档文件中同比、环比、参考月份的文字逐项一致；12个月食品原始PDF哈希吻合。
- 选中新闻48,222次曝光、政策与食品的登记发布日期未超过各自截止时点；个人起点的来源月份严格早于目标月。
- 6,144份都有食品视图，0份保留完整的宏观统计表。这是先前冻结的采购角色价格视图设计，并非这次运行时丢了某个环境文件。

**日期和文件一致，不代表信息视图已经充分。** 本次检查也不证明新闻标题/摘要的历史文本版本已认证，不改变此前严格路线B的资格限制。

### 关键线索：食品信号与总体通胀在2021年上半年分离

5月、6月、7月提示中的居家食品同比依次为 **1.2%、0.7%、0.9%**；同一截止日已经公布的总体CPI同比是 **4.2%、5.0%、5.4%**。完整环境文件保存了后者，但实际提示没有把总体CPI和能源涨幅作为独立统计条目呈现；新闻中仍可能提及这些事实。

例如6月10日可得的5月数据：食品0.7%、总体CPI5.0%、能源28.5%。数字确实来自当时的[BLS初始发布](https://www.bls.gov/news.release/archives/cpi_06102021.htm)，不是把食品涨幅算小了。因此，模型接收到的明确价格数字，可能低估了当时广泛的涨价压力。

与此同时，5—12月政策摘要保留当时美联储关于暂时性通胀的表述；[2021年4月28日FOMC声明](https://www.federalreserve.gov/newsevents/pressreleases/monetary20210428a.htm)确有该判断。原始2021回包中2,211份理由出现“transitory”，4,712份出现“Fed”（关键词可重叠）。这些自述与模型偏重政策锚的解释相容，但不能证明该因素造成了多少误差。

**经济学解释的当前地位是待验证假设：** 食品局部信号偏温和、政策强调暂时性，模型可能据此把家庭较高的先验向较低中心拉回；真人当时的价格感受与信念持续性未被充分复现。这是环境选择与信息解释共同作用的候选解释，不能将其归结为DeepSeek的固定人格，也不能认为加回总体CPI就必然改善。此前Qwen的价格背景实验不能直接给出V3.2的因果结论。

## 3. 是不是新人或抽样造成的？

现有证据不足以支持这种解释：

- 2021年按相同可计分人群进行有符号误差分解，平均模型—真人差为 **−0.769pp**，抽样项 **−0.064pp**、模型支持项 **+0.001pp**、微观计分与官方定义项 **+0.009pp**，合计−0.822pp。这里相加的是有符号偏差，不是四种MAE相加。
- 只看2021年本人真实相邻上期可用的4,934个回访人月，模型月度中位数偏差平均仍为 **−0.715pp**。该支持要求真人本期、本人上期、模型Q9均有效且权重为正，不额外要求合成起点基线有效。
- 例如6月这400名回访者：真实上期中位数 **4.000%**，本期真人 **4.364%**，模型却是 **3.262%**。即便已经拿到本人真实先验，模型也可能把整个横截面的中心向下拉。

这不是仅仅“没有及时上调”的现象，也包含对既有较高信念保留不足。单次生成和抽样仍有不确定性；上述结果不能识别每个机制的因果贡献。

## 4. 加权组合能改善多少？

采用同一形式：

**组合 =（1−λ）×截止前最后公开的全国SCE值 + λ×本月模拟中位数**。

0≤λ≤1，两项权重和为1，无截距，月份等权。公开锚有时是t−2，不强行使用截止时还未发布的t−1值。这里只调整全国聚合指标，不改变个体Q9或微观分布。

### 全部82个月一起拟合：事后描述

- 最小化MAE：模型 **0%**、历史 **100%**；MAE **0.223171pp**，与持续性基线完全相同。
- 最小化MSE：模型 **2.897%**、历史 **97.103%**；MAE **0.224117pp**，RMSE **0.317022pp**。
- 对应基线：MAE **0.223171pp**、RMSE **0.317190pp**。MSE目标下RMSE仅下降约 **0.000169pp**，MSE相对下降约0.106%，同时MAE略升，没有实质改善。

原因尤其清楚：2021年每月都满足 **模拟值 < 历史锚 ≤ 真值**，所以任何正的模型权重都会使该月组合离真值更远。凸组合无法弥补两个分量都低估的情况。

### 已冻结的48月拟权、后34月评价

用2019—2022年拟权，2023—2025年10月评价：MAE/MSE都选λ=0；后34月组合 **MAE0.194118pp、RMSE0.270076pp**。这一结果才对应原先约定的按时间留后评价。后34月纯模型MAE0.176362pp不能写成冻结组合的成绩。

### 只在后34个月重新拟合：时期敏感性描述

- MAE拟权：模型 **78.380%**、历史 **21.620%**；MAE **0.175114pp**，RMSE0.248932pp。
- MSE拟权：模型 **71.881%**、历史 **28.119%**；MAE0.175700pp，RMSE **0.248750pp**。
- 同期基线MAE0.194118pp、RMSE0.270076pp；MAE最优组合比基线低约9.8%。

**这些权重使用了后34个月自己的真值，只说明关系随时期变化，不能报告为独立验证或据此替换原权重。** 当前证据支持“模型有时期差异”，不支持“一个固定组合已在全期稳定超过基线”。

## 5. 对当前工作的含义

已完成数据仍应完整保留并报告2021年的失败。此次未找到需要修复的错月、数值格式或提示接线bug。最值得记录的机制缺口是：广泛价格冲击与当前食品视图不一致，以及模型在上升阶段对较高个人先验的收缩。这些结论用于解释与后续验证设计，不能用当期真值事后调整本批回答。

## 补充：真人是否也比模型更接近未来实际CPI？

2026-10-24用户追问后，使用本地CPI-U NSA月度水平（2024-03-12数据版本）直接对齐：预测形成月t的实现值为`100×(CPI[t+12]/CPI[t]−1)`。比较对象是全国SCE预期中位数、模拟全国中位数，不是每个家庭的准确度。

- 2021年形成的12次预测，对应2022年同月实际同比：真人中位数MAE **3.466pp**、模拟 **4.288pp**。两者全年均低估未来实际CPI，模型更低，因而更不准确。
- 例如2021年6月：真人4.8%、模拟3.232%、此后2022年6月实际约9.060%（官方一位小数9.1%）。前两项是未来预期，最后一项是后来实现的价格变化。
- 本地CPI版本最多支持2019-01—2023-02形成的50次预测：真人MAE **2.212pp**、模拟 **2.486pp**。尚不能外推到全部82个月。
- 分年并非一律如此：2019年模型1.122pp/真人1.355pp；2020年模型2.308/真人2.222；2022年模型2.319/真人1.928。2023年该版本仅有1—2月可评价，不给全年结论。

实现值只进入事后评价，未送入模型。以上是补充的预测准确度诊断，不替代本项目复现人类预期的主目标。对于2021年，两者都低于实现值且模型低于真人，因此这个准确度差距在算术上与前述模拟—真人差距一致，不能将其当作新的独立机制证据。
