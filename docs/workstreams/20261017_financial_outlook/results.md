# 上期家庭财务前景Q2：总体误差基本不变，尚无稳定增量

2026-10-17完成。768次真实调用全部有效，无接口错误、无重试；token价估算约$0.863，低于授权$4上限，非服务商账单。模拟约277.5秒，评价约20.4秒。

## 研究问题与对照

在同样人口、环境和本人既往通胀信念下，增加本人上期对家庭未来财务的判断，是否使模型更接近真人？

- 四期2020-03、2022-06、2023-12、2025-09各48人；原输入／仅增加上期Q2，两组各生成两次。共同Q9与Q8支持均192个人月。
- Q2是上月预计随后一年财务会变差、相同或变好的五档回答。不是本期Q2，不是Q1过去财务变化，也不是稳定人格乐观。
- 只加入实际回答的文字，不规定通胀方向或调整幅度。其余提示逐字不变；对照组同期运行，避免直接用旧批次替代。
- 调查权重÷两阶段入样概率为主；每个月、每次生成等权。四期此前已看过，只是A条件机制探索，非全国代表性、独立盲测或严格B预测。

## 主要结果

以下为原输入 → 加上期Q2；单位为通胀百分点，误差/距离越小越好。

- **同样本Q9中位数MAE：0.4591 → 0.4593，几乎不变。**
- 个人Q9派生均值MAE：3.581 → 3.673。
- 跨人分布W1：2.505 → 2.660。
- 个人更新分布W1：2.268 → 2.493。
- 人际IQR：2.818 → 2.985，真人5.282；宽了一点，不代表整个分布更准确。
- 个人概率密度IQR的误差：2.750 → 2.882。
- Q8点预测的样本中位数MAE：1.05 → 1.00，个人MAE6.292 → 6.091；保留小幅点值收益，不代替Q9主要结论。

这不是“加入财务前景让模型明显变好”，也不是证明财务前景普遍无用。当前事实输入版本尚无稳定收益，不升级默认配置。

### 分月中心误差

- 2020-03：0.517 → 0.459。
- 2022-06：0.564 → 0.308。
- 2023-12：0.622 → 0.750。
- 2025-09：0.133 → 0.321。

两个月改善、两个月恶化；不能只保留高通胀月的收益。按人整簇配对重抽1000次，中位数MAE差的探索性95%区间为[-0.120,+0.250]pp；个人均值MAE差[-0.453,+0.570]、跨人W1差[-0.363,+0.637]，均跨0。区间以这些月份为条件，不覆盖换月份、模型训练知识或全部抽样不确定性。

等人权重下，Q9中心0.377→0.457、W1 2.036→2.074，同样没有改善；不事后替换主权重宣布成功。

## 如何解释、下一步如何做

前期回归表明Q2还有关联信息，但“关联存在”不保证把一句事实加到提示里就能恢复真实判断。Q2与通胀预期可能共同反映经济担忧，也可能有反向影响。不同Q2档的人又具有不同原有信念、收入和信息接触；本试验不能将这些关联直接解释为真人心理的因果机制。

模型对文字有响应，仍可能把财务较差解释为需求疲弱，也可能解释为物价挤压购买力；本轮没有单独操纵解释渠道，理由文字不能证明哪条路径造成结果。当前不继续在同四月调语气，不将回归系数写成统一通胀偏移。按既定顺序，下一项准备单独心理状态对照，与Q2和Q1分开。
