## 2. 五个复审问题的回答

### 2.1 分层与 300/500 人的充分性

**500 可作拟议主规模，300 可作开发规模；现有统计不能证明“统计功效充分”。** 我们主要要控制的是估计精度；功效还需要指定欲检出的效应、显著性水平、相关结构和重复次数。

原 employment × education × age 切得过细。实测每月 56–62 个非空格，其中 28–36 格在全调查中已不足 5 人；若按当月比例分配 500 人，42–50 格期望不足 5 人，300 人则为 46–52 格。给每格硬塞最低人数会明显改变抽样率，需要相应设计权重，不能继续等权。employment 的最大组间差还包含如 2021-01 on_leave 仅 3 人、other 9 人的稀小组，不能凭 6.3pp 极差判它为“最有效维度”。

建议首版用 **age × education 的 9 个主要层**，缺失值单独登记或预先规定合并；income、region 和粗就业分类用于配额/校准检查。就业细类继续留在 persona 和描述分析中；不预先保证每个稀小组都可报告稳定效果。更细的 27 格方案可作候选，要先检查每月支持。

冻结规模前，Kimi 做零 LLM 的抽样精度试验：在开发月真实调查上按拟采用设计抽 300/500，固定至少 200 个种子，以真实回答代替模拟回答，比较抽样聚合与整月调查聚合，报告中位绝对误差、p90、加权 ESS、空格率。它只估计“抽样+投影”的误差，不证明 LLM 准确。容许精度（例如 0.2 或 0.3pp）须在看结果前选定；不能直接拿均值标准误推断中位数精度。

本轮完整调查每月 Kish ESS 约 672–899，明显小于名义约 1,250；core 的 ESS 也必须实际计算。Normal 复制一千人不会增加独立信息量。按现有 876 调用账本线性估算，6,000 调用约 $2.21（非供应商报价、不含额外重跑）；费用并非主要约束，运行时间和估计偏差更值得优先考虑。

### 2.2 Normal estimator 与方差估计

**先有可检查的调查权重基线，再决定贝叶斯投影的增益。** D046 的贝叶斯外推方向可保留，但草案的“后分层/raking/向格贝叶斯收缩”是不同方法，当前还没有一个定义完整的 estimator。

A 线从当月 SCE 样本二阶段抽 core，记录抽入概率 π_it。若目标是加权 SCE 全国统计量，基础分析权重为 `w_it / π_it`，w 是官方调查权重；不是先等权投影回原始 1,300 人就能叫全国代表性。权重不必给 LLM，但用于抽样与聚合的版本必须可追溯。[Statistics Canada：两阶段抽样与校准权重](https://www150.statcan.gc.ca/n1/pub/12-539-x/2009001/weighting-ponderation-eng.htm)

首版基线：有支持的粗格后分层，或以基础权重为起点做 raking，校准到同一目标人口的 age/education/income/region 等**加权边际**。边际匹配并不恢复真实联合分布；空格也不会被 raking 凭空补齐。记录收敛、最大残差、权重范围和 ESS，过大权重的截断/重新校准规则须先定。[校准方法与约束](https://www150.statcan.gc.ca/n1/pub/12-001-x/2021002/article/00003/02-eng.htm)

若落实贝叶斯 normal：为同一月各格的**个人密度均值分布**建立部分汇聚模型，再按目标格份额混合。例如以格内经验分布向同月父组分布收缩，可写 `F_h=(n_h F_core,h + κ F_parent)/(n_h+κ)`；必须明确权重/有效计数、父组、先验与 κ 的选定方法。这是可实现的经验贝叶斯候选，尚未验收。只用 core 内部留出检验其投影误差，不用当月全国 SCE 答案选择 κ。更一般的 MRP 需要模型与联合格信息，不能仅靠相关系数证明可用。[方法参考](https://arxiv.org/abs/2102.09052)

全国量应从 `F_t(z)=Σ_h W_ht F_ht(z)` 求中位数；不要平均各格中位数，也不要先平均 Q9 十档后拟合一条密度冒充全国 headline。需要导出 normal 个体时，可按事先确定规则抽 donor/后验样本，但这些是生成值，不能当独立观测降低标准误。

不确定性至少分两部分：按 userid 成簇、保留跨月轨迹的重抽样，每次重新做校准/投影；在固定 P/E 下另做少量 LLM 重复运行衡量生成波动。只有 12 个月，不能把 6,000 人月当 6,000 个独立宏观时间点。贝叶斯可信区间也不会自动覆盖 LLM 模型偏差。

### 2.3 固定 core 与轮换

**不接受“人口边际校准足以吸收轮换，影响只是二阶”的断言。** 本轮描述性复算中，新入组与上月继续者的加权 Q9 中位数差在 2021 年约 −0.32 至 +1.98pp；这还混有人口构成/选择差异，不是轮换因果效应，但足以说明不能直接忽略。报告的 0.597 是把相邻月份配对后合并的相关，不是控制个体固定差异、月份冲击后的记忆系数，更不证明“提醒上月回答”能正确复现行为。

建议采用 **固定身份登记表 + 逐月在册/入组状态 + 持续 core 的自身模拟记忆**：

- A 线以每月实际调查 frame 为准抽样，保留跨月入选者的 ID；用固定随机优先序在层内选当月配额，可以降低无谓换人，同时记录每月 π。入/退组与重新入选是三种不同事件。
- B 线以可得的旧微观 frame/合成 cohort 为准，轮换计划和画像更新由截止前材料确定，不用未来真实 ID 或当期 SCE 构成。
- 当月未在册者不计入当期样本；新进入者没有此前调查作答，但并非“没有通胀信念”。首轮不塞真实历史答案；返回者的旧模拟回答注明真实月份，不能把两个月前说成“上个月”。
- SocioVerse 固定 roster 不等于每人每步必须有效作答：可在 study provider/decision/collector 增加 active 标志、inactive 不调用 LLM且不聚合。需做返回者/缺月/记忆时标验收，先不改上游核心。

这样“每月约 500 个 core”对应约 6,000 次调用，但一年独立 ID 通常超过 500。若工期不够，也可保留固定 500 个原型全年运行，明确叫**固定合成人口反事实面板**，不能一面声称逐月真实受访者复刻，一面给尚未入组者造过去调查史。至少保留无记忆对照与新入组/继续者分组诊断。

### 2.4 B 线校准判据

**TVD 的 .02/.05 不是已验证通用阈值，年均 TVD 也推不出“每年校准一次足够”。** 当前报告 weighted education lag-12 均值约 .032，不能同时称接近可忽略；age/region 加权后几乎不变，可能体现官方校准约束，不能反推样本或真实人口没变。住房漂移更先受只问新进入者的选择机制影响，不能全归为小样本噪声。

B 线应实行以下可执行判据：

1. 每目标月保存人口源文件的 `reference_period / published_at / vintage / as_of`。`M−12` 是保守滞后约定，不是历史公开证据；无历史上线证明时标注可得性假设，不能直接叫严格事前。
2. 每月检查**当时可得**的可比外部目标，只有新发布时更新校准；绝不读当期 SCE 微观边际来决定 B 的调整。CPS/BLS 失业率的分母是劳动力，SCE household-head 的就业分类（含“想工作但未工作”）并不等价，不能直接把 6% 填成所有 persona 的失业占比。收入档也不能由 CPI 机械平移。
3. 校准是否启用以预先选择的开发期重抽样精度、共同支持和 ESS 规则为依据；TVD 可作告警，不作自动“合格章”。可预先规定 ESS/名义 n<0.5 或目标格无支持时回退到更粗分层；数值属项目拟议容差，尚未批准冻结。
4. 给出“旧 P 不校准”与“按可得外部画像校准”两个固定对照；用同一批 core 输出检查再加权对月度结果的敏感度，不能用当期答案选择最好的一套权重。旧信息的制度变化和联合关系变化不由单维 TVD 保证。

**A/B 口径提醒**：A 用当期微观画像与权重，属于事后信息较完整基准，不能概括成两线都“P/E 时点合规”。A−B 同时受 frame、人员身份、画像、权重及生成随机性影响，建议称“人口信息方案差异”，不能未经控制称纯粹的信息时效因果效应。需尽量固定其余设置并重复配对比较。Normal 属于预测估计器的一部分；放进“评价层”文件夹并不会让其使用当期真值自动无泄漏。

### 2.5 指标与登记文本

三层评价保留，但**全国月度指标为主、个体与分组为诊断**，避免把不可识别的同画像个体心理当成能精确恢复的标签。

- 主指标：每月个人 Q9 冻结密度均值的加权经验中位数，报告预测序列、月误差、跨月 MAE、bias、RMSE；并列官方 headline、全样本同冻结算法真值、共同有效样本指标及拟合/覆盖差。开发月 05/06 在曲线中可展示，但按 D045 不纳入主评分平均数；登记实际纳入月份。
- 微观：同人在册月 Q8 signed point 与 Q9 density mean 的 MedAE/MAE/bias、有效样本与失败率。Q9 十档可用 TV 距离或 Jensen–Shannon 距离作分布相似度。与真实主观概率相似不等于对未来 CPI 的概率校准；若评价未来 CPI，需另定义 horizon、事件及概率评分。
- 分组：预先固定 age/education/income、粗就业、新入组/继续者；同时报 n/ESS与误差区间，样本太少仅描述。分开报告个人密度宽度（不确定性）与个人均值的横截面离散度（分歧）。
- 最小基线：截止前最后已公布 SCE 全国值、同 E 直接 LLM、无记忆版本、旧 P 不校准。截止前最后公布值不一定是 M−1 调查月，按真实 release timestamp 选。

## 5. 2.24pp 实验：已验证什么，先诊断什么

本轮读取实际 run `sce-local-openai-20261003T055121Z-1dc7cd15`：73 人×12 月，876 条有效回答，requested/returned 别名 deepseek-flash，temperature=.5。使用冻结计分器复算：相对官方个人 Q9_mean 的 MedAE **2.24273pp**，确实复现用户数字；这是个体指标且含计分近似差，不等于全国月度 MAE。

同批 73 人的模拟个人密度均值月内标准差只有 **0.27–0.81pp**，真实同批为 **5.53–7.59pp**。样本加权后的模拟月中位数对官方全国 headline 的诊断性 MAE 约 **2.15pp**，所以全国层面也确实有系统性偏低；但73人样本有完访选择且未重做全国代表性校准，此值不作最终报告分数。

因此目前至少有两个可分离问题：人口/权重代表性，以及 B 的回答过于集中。增大到500人只可能降低抽样波动，不能保证解除模型共识偏差。Q9 比 Q8 更低可能与概率填法和尾部质量有关，需以 raw bins 对照，而非直接给计分器加补偿项。

建议按以下顺序诊断（均先固定方案，不能按全年答案反复追拟合）：
