# SCE 居民通胀预期：研究与实施方案

2026-09-29 执行方式更新：按 [云端预试验方案](CLOUD_PILOT_PLAN.md)，优先让托管研究助手创建/运行小规模 study，本地负责数据准备、独立计分和版本归档。下文技术职责仍有效，但不是要求先本地实现全部模块；完整本地部署仅在云端能力或规模受限时启动。

核查日期：2026-09-28。状态：用户已同意作为主线开展调研；以下时间窗口、实验规模和评测设计是待冻结方案，尚无 Agent 实验结果。

补充参考：[Case 6 PMI 与 Event/Population MCP 的适用性](SOCIOVERSE_MCP_AND_PMI.md)。优先验收平台取数能力；按实际缺口补采。当前 MCP 文档的观测月份截断不能替代本方案的发布时间与历史版本检查。

## 1. 研究问题与范围

建议题目：**基于异质家庭 Agent 的美国居民通胀预期重建：预期水平、分歧与不确定性**。

研究问题：在控制输入信息可得时间后，人口特征与价格暴露能否帮助 Agent 重建 SCE 的一年期通胀预期，并解释不同人群之间的预期差异？

- 主目标：美国 SCE 一年期通胀预期中位数，即个人概率密度均值的跨人加权中位数，单位为百分比。
- 次目标：一年期点预测中位数；它有独立官方序列，不能用来替代主目标却仍沿用主目标名称。
- 诊断：个人预期均值的跨人 IQR（分歧）、个人主观密度 IQR 的跨人中位数（不确定性），以及年龄、教育、收入组表现。
- 地理范围：先美国全国。四大 Census region 可做组别检验，不要求先扩展到多国。
- 企业 BIE：保留为附加调研，取得数据、完成主线后再决定是否增加企业响应模块。

经济动机可以使用当前政策背景：2026-09-16 FOMC 官方声明将目标利率上调 25bp 至 3.75%–4%，并指出通胀仍高。但本项目的价值不依赖某一次加息；不要据此推断模拟必定有效。[S7]

SCE 未在原候选表中以独立条目找到。用户本次已授权以它为主线研究，这更新了早先“只审计清单内候选”的工作范围；向导师介绍时说明它是新增的调查统计量。尚未代替导师作出认可或报名承诺。

## 2. 调查机制中直接影响实现的事实

SCE 面向美国 household heads，方法论文将其定义为拥有、正在购买或承租该住房的人；不能把全部美国成年人等同于目标人口。采用线上轮换面板，通常最多连续参与 12 个月。官网主页面及方法论文写约 1,300 人，FAQ 写约 1,200 人，项目按实际文件逐月人数记录，不固定为 1,300。[S1–S3]

调查在一个月内分批进行，FAQ 说明尽量均匀覆盖各周。2026 年 8 月调查的新闻稿给出田野期 8 月 3–31 日，9 月 8 日发布。发布日期须逐期收集，不能统一假定每月 8 日。核心微观数据的官方发布政策为滞后九个月，但实际文件覆盖与历史版本仍要核实；当前下载的文件不能凭这个政策自动变成历史时点版本。[S2, S6]

**回答顺序与含义：**先回答通胀或通缩方向及幅度（Q8v2、Q8v2part2），再对未来十二个月的十个通胀/通缩区间分配概率（Q9）。从高到低的区间分界为 +12、+8、+4、+2、0、−2、−4、−8、−12%，两端开放。概率总和为 100%。公开微观数据已有带符号的点预测，导入时核查方向和符号，不能再次对通缩值取负。[S4]

**ConsumerSim 的迁移边界：**其概率向量描述正面/中性/负面回答，SCE 的概率向量描述同一受访者对未来通胀的主观分布。迁移 P/E/B 架构与结构化输出方式；重新定义问题、概率语义和计分器。LLM 多次调用间的差异不能直接当成居民的主观不确定性。[S8]

## 3. 先验证计分器，再模拟回答

计算链为：

`十区间概率 → 个人拟合密度 → 个人密度均值/分位数 → 按调查权重计算跨人统计量`。

官方方法论文的附录 C 区分：三个及以上正概率区间用广义 beta；两个相邻区间用等腰三角；一个区间用均匀分布。两个不相邻区间、概率不合计为 100 等有专门处理，开放尾部也有边界设定。附录 B 给出基于 mid-distribution 的加权插值分位数；本轮实测中点预测适用插值，而主指标以加权经验中位数精确匹配官方值，详见数据审计。**不能用区间中点加权和、普通 numpy median 或先把全体人的概率平均再拟合来冒充官方算法。**[S3]

按两道门槛实现：

1. 使用公开 `Q9_mean`、`Q9_iqr`、点预测与 `weight` 复核官方图表统计量。这只验证跨人聚合。
2. 用真实 `Q9_bin1`–`Q9_bin10` 重新拟合，逐人对照官方派生字段，再验证聚合。覆盖单区间、双区间、开放尾部与异常概率。没有通过这一步，不能声称完整复现了概率回答到官方指标的机制。

如果第二步短期难以精确复现，可先跑点预测副线并报告其真实名称；概率副线可以先评价区间分布，不把近似值命名为官方 headline。该降级须记录决策，不能根据测试结果挑选更好看的目标。

版本注意：官方 chart 工作簿 Notes 记录 2016 年密度算法修订；商品价格预期曾在 2022 年回溯修订，2025-08 至 2026-06 的商品系列还存在设备覆盖说明。商品预期和核心总体通胀预期须分别管理，不能将一条系列的改版外推到全部系列。[S5]

## 4. P：如何构建人群

### 首版优先级

1. **历史已公开 SCE 样本**：优先保留与目标调查匹配的联合结构和分类。挑选一个有可得性证据、早于预测窗口的基期；先用固定人口池，记录近似误差。
2. **ACS/CPS 校准**：需要修正年龄、教育、地区、收入或就业结构时，再使用当时已公开的相应版本；SCE 历史权重方法本身以 ACS 的年龄、收入、教育和地区边际为依据。[S3]
3. **CE 消费支出调查**：若检验价格暴露机制，从可得版本的公开分组支出表入手，给人口组匹配食品、交通/汽油、住房等支出占比。完整 CE 微观数据是进一步精细化选项。[S10]
4. **SIPP/GSS**：SIPP 在需要资产负债、家庭经济细节时增加；GSS 在已有明确可检验的信任/态度机制时增加。两者都不作为首版前置条件。跨调查匹配属于统计插补，不是同一个人的真实联合记录。

### 字段与处理规则

- 基础 P：年龄组、教育组、收入组、地区、住房状态、就业状态；数理能力可作为有真实测量基础的扩展。
- 实测发现 `_AGE_CAT`、`_EDU_CAT`、`_HH_INC_CAT`、`_REGION_CAT`、`_NUM_CAT` 等分类，以及 `userid`、`tenure`、`survey_date`。住房 Q43 和就业 Q10 各选项的长期完整性还需独立审计。
- 一些题只向首次入组者提问，重复受访者使用 D 系列更新。空值可能由问卷跳转导致。按 `userid` 串联时只允许从过去向后带入，禁止拿未来访次倒填。
- 收入是家庭过去十二个月收入区间，不应直接理解为当月工资。就业是可多选的现状题，需按原始题意编码。[S4]
- 汇集多个历史月份时，避免将同一人在每个访次重复计算为不同家庭；可先每个 userid 保留可用的最近画像，再制定抽样/权重方案。不能既按权重抽样，又不经调整重复应用同一权重。
- 在真实历史预测中，同期人口信息、同期真实调查权重、同期个人其他预期回答都不能由尚未发布的微观文件进入 P。年龄或教育变化较慢，也不豁免其来源时间限制。
- 在“给定当期真实人群的事后回答重建”实验中，可以使用同期人口特征作为条件，但必须独立标注这个实验；它不等同于发布前预测。

不强制初版复制真实轮换面板。固定加权合成人口先验证机制；后续才增加每月轮入轮出及 Agent 自身记忆。模拟者拿不到上个月真实个人答案时，可以保存上个月**模拟**信念，但不能偷用真实个人回答更新记忆。

## 5. E：参考信息集与时间协议

真实调查未提供每位受访者完整的新闻阅读和生活体验日志。因此 E 是有证据约束的信息代理，其构造需接受消融检验。

### 最小信息集

- 价格：当时已发布的 CPI 总体/核心/食品/能源/住房分项，记录同比、必要的近期变化及参考月份；汽油零售价格可用 EIA 周数据补充高频体验。
- 劳动与收入：当时已发布的失业率、工资增长。首版不建设完整个人就业转移模型。
- 政策：FOMC 决定和当时已发布的官方说明；加入少量供给、能源、关税等事件。
- 价格暴露扩展：以历史 CE 分组支出份额与可得价格变化形成组别压力代理。它并不等于测到了这个家庭实际支付的价格或真实主观通胀。
- 新闻扩展：固定来源与检索式、固定时间窗口与篇数上限、版本去重。先比较“结构化宏观资料”与“增加新闻”两版，不引入大量可调的人工注意力系数。

所有信号保留 `reference_period / observed_at / published_at / vintage / source / as_of`。ALFRED 支持查询历史可得版本，但不自动保证每个目标序列或日内时间都有档案，仍须逐序列核查。[S9]

### 三种不同任务，分别评测

**A. 建议主实验：月初预测该月调查统计量。** 对月份 t，`as_of` 固定为 t−1 月最后一天 23:59:59，美国东部时间。优点是规避当月作答日期未知及月内未来信息；代价是不能响应该月突然发生的事件。通常上月 SCE 此时尚未公布，持续性基线必须取截止时点最近已公布值，往往是 t−2 月，不能机械用 t−1。

**B. 附加实验：月底、结果公布前 nowcast。** 使用月底以前信息预测整月调查统计量；这是合法的发布前 nowcast，但晚月信息发生在部分真实作答之后，所以不称为逐人作答时的历史信息重建。

**C. 行为诊断：按实际作答日期回放。** 微观文件里的 `survey_date` 支持作答前截断 E；若只有日期没有时分，采用前一天末作为保守截止。同期 P/日期来自事后公开文件时，这是事后条件重建，单独报告。若想在实时流程模拟周内批次，应从历史调查日分布预先安排虚拟时间，不能使用尚未公开的真实当期作答日程。

**目标泄漏：**ConsumerSim 的 E 曾包括 SCE 信息，迁移时必须移除当期 SCE 结果及复述其结果的报道。已公开的过去 SCE 聚合值可设为透明的 AR 辅助对照；当期其他家庭预期也不从微观文件带入。

**模型知识泄漏：**给 prompt 写历史日期无法删除预训练知识。2021 年后的训练内容可能包含当时尚未公布的 CPI、新闻和 SCE 结果；即使外部 E 严守 `as_of`，真实 LLM 回放仍可能利用模型参数里的未来信息。当前 v2 是 0 真实 LLM 的 scripted 流程试验，但编写 scripted B 的研究助手也可能将事后知识写成代码。真实 LLM 回放前须登记基础模型与完整训练/后训练时间证据；未知或晚于 `as_of` 时，只称回顾性条件模拟。移除日期、无 E/错月 E 和结果回忆只能做诊断，不构成无泄漏证明。可核实的历史时间快照模型或事前封存的未公布月份预测才支撑更强的事前主张；详细规则见[模型时间泄漏协议](MODEL_TEMPORAL_LEAKAGE.md)。

## 6. B：行为核与成本

每个 Agent 接收结构化 P、可得 E、问卷原题语义及预测期限。先生成带符号点预测，再生成十区间概率；若同一次调用完成，用明确顺序字段，另以小样本顺序调用检验题序敏感性。

输出保留：`agent_id, target_month, as_of, point_prediction, bin_probabilities, evidence_ids, model_version, prompt_version, seed, status`。不要求保存冗长思维过程，理由限可追踪的证据摘要。

验证概率非负、各项不超过 100、总和为 100，区分百分数与 0–1 比例。失败可有限次请求修正，记录原回答和失败率；不要通过大幅静默归一化改写模型信念。点预测与密度均值不强制相等，真实人类也未必相等。[S2]

先 100–200 个加权 Agent、6–12 个开发月份跑通。正式规模建议通过 200→500→1,000 左右的收敛检查确定，并非因为真实调查约 1,300 人就必须模拟同样数量。

示例预算仅用于规划：500 人 × 60 个月 × 1 次调用 = 30,000 次；若每次约 2,000 输入 token、300 输出 token，则约 6,000 万输入、900 万输出 token。按所选模型价格另算；两次分题调用、重复种子、消融与重试会增加成本。首版不复制 ConsumerSim 的 5,000 核心 Agent 和人口扩张工程。

## 7. 窗口、对照与评价

建议优先建 2020–2024 年的 60 个月数据，再补 2017–2019 年人口与背景资料。候选切分为 2020–2021 开发、2022 验证、2023–2024 连续测试；最终需在数据时点审计后、查看 Agent 测试效果前冻结。此切分的测试期不能单独支持“在通胀急升阶段同样有效”的主张。需要覆盖多种阶段时，另预先规定滚动评测方案。

数据审计可以查看真实问卷字段和验证官方聚合，它不构成模型调优；所有方法选择仍只依据开发/验证期。各阶段不得根据哪段拟合更好来更换测试窗口。

最低对照组：

1. 截止时点最近公布的目标值；以当时可得版本建立 AR/线性宏观基线。
2. 同样 E 的单次直接 LLM 聚合预测，判断多 Agent 是否有额外价值。
3. 历史人口组均值/分布加简单宏观更新规则，检验 LLM 是否超越低成本异质性模型。
4. Agent 消融：相同 E 下同质 P vs 异质 P；基础 E vs 增加价格暴露/新闻；不加校准 vs 仅开发期拟合的校准。

主评价：按月 MAE/RMSE，单位百分点；次评价：分歧、不确定性、预先指定年龄/教育/收入组的误差与分布距离。合成 Agent 与实际受访者没有一一配对关系时，只做总体/组别分布对照。重复种子用于量化模型随机性；真实轮换面板的推断需要考虑同一人的跨月依赖，不能把数万条人月当成数万个独立月份。

目标真值是居民报告的预期。未来实际 CPI 可以辅助研究预期偏差，但不是本任务唯一正确答案。未做真实信息干预实验时，“去掉某条新闻”的模拟变化是模型敏感性，不足以证明真实因果效应。

## 8. 工程顺序与报名之前的交付

1. 数据适配器：下载来源清单、文件散列、字段映射、调查期/发布日期表、跳题和版本记录。
2. 计分器：真实微观回答到官方统计量；再实现概率密度拟合。
3. P/E 构建器：可得性过滤、固定人口、宏观快照、目标结果隔离。
4. 离线 study：按已核验的 SocioVerse2 原生接口接 P/E/B、规则式响应、输出及计分，记录确切平台版本。
5. 基线与实验配置：冻结主次目标、截止规则、时间切分、人口来源、预算；随后才调用 LLM。
6. 提案：写明题目、创新点、已取得数据与已验证计分环节、尚未验证的性能假设。

具体阶段、日期、依赖与验收统一维护在 [ROADMAP](ROADMAP.md)，任务完成状态维护在 [NEXT_ACTIONS](NEXT_ACTIONS.md)。本文件只解释研究与实现方法，不另维护一套时间表。

报名前不要求学校新闻数据全部到齐。提案应承诺公开数据最小版本，授权新闻库作为明确的扩展；人员、邀请码、导师署名按现有报名清单处理。

## 9. 当前未解决的问题

- 当期官网下载文件的统计覆盖、缺失和聚合对账：见 [数据审计](SCE_DATA_AUDIT.md)。
- 官方密度拟合的完整数值复现及算法版本尚未完成。
- 历史微观文件真正的发布日/版本证据，不能只用“调查月 + 九个月”填成事实。
- 历史新闻获取权限、首次发布时间与更新版本是否可导出。
- 尚未检查 SCE 人口分布跨期稳定程度，不能先认定住房/教育完全稳定。
- 平台集成、完整滚动实验和任何效果优势尚未验证。
