## 1. 做了什么

A历史重建；2021-05/06各50人，Q1五类各10人。每月两个组为原v2标题＋摘要基线、同一提示增加一段当月自报家庭财务变化。人口、公共信息、问卷和计分相同；不使用CE篮子、幸福度或Normal扩展。抽样在读取评价答案前已固定；不是全国代表样本。

请求模型`deepseek-flash`、temperature=0.5、thinking disabled、max_tokens=1024，无自动重试。两组重新同期运行，未复用旧基线。200条原始Q8/Q9回答全部合法，无接口错误或重试；实际200份提示均与冻结预览一致。

所有回包模型名`deepseek-flash`、同一system_fingerprint `aeb56401ca74e127821c4f9126dcb669`。这能检查可见标记的一致性，不能证明精确权重版本或训练截止。请求温度已记录，不把参数请求等同于供应商内部执行证明。

费用按现有高峰缓存未命中参考价自记估算：输入493,516 tokens、输出26,573 tokens，合计**$0.179942**，低于$1上限。供应商独立账单未获取，缓存/低峰等可能使实际扣费更低，不能称这是已核对账单的实际费用。

## 2. 主要结果

真实与模拟Q9均以同一冻结项目近似计分器，从原始十档概率拟合个人预期均值后比较。以下均为本次选定人群、等人权重、严格完整配对。

### 2021-05：50个完整配对

- 个人平均绝对误差：基线3.5244 → 加Q1 3.6038个百分点，**恶化0.0794个百分点**。
- “财务明显变差－财务不变”的预期中位数差：真人0.7829；基线0.0137；加Q1 1.2058个百分点。差距绝对偏离0.7692 → 0.4229，改善，但本次Q1组略超过真人差距。
- 跨人分散度IQR：真人3.9015；基线0.7809 → 加Q1 0.8859个百分点。略增加，仍明显窄于真人。

### 2021-06：49个完整配对

- 选定的50位真人中有1条原始Q9概率不合法；从两组对应评价同时排除，未补抽、未按模型误差删人。模型两组全部50条合法，模型无失败。
- 个人平均绝对误差：基线3.7108 → 加Q1 3.7260个百分点，**恶化0.0152个百分点**。
- “财务明显变差－财务不变”的预期中位数差：真人4.0022；基线0.1079；加Q1 0.5879个百分点。差距绝对偏离3.8943 → 3.4143，改善幅度有限。
- 跨人分散度IQR：真人4.5559；基线1.1330 → 加Q1 0.5929个百分点，**更集中**。

需要区分“总体水平接近”和“微观重建好”：例如6月选定样本的中位数，加Q1后4.1695，更接近真人4.1891；但个人误差仍略恶化，分布更窄。所以不能据一个聚合数字接近就认为机制成功。

各组每月原先仅10人，6月明显变差组实际配对9人；真实人群存在极端回答。5月该小样本的明显变差组中位数3.6392，不能拿此前完整月加权8.77直接作此处对照。小样本、等额分层、不同统计口径和生成随机性都限制推广；没有报告显著性、因果或全国headline。本轮主要行为判据为Q9，Q8原始回答已保存，没有宣称已验证Q8准确度改善。

## 3. 如何理解、下一步做什么

本次加入Q1后，模型更区分财务变差与不变的人；但仍未还原真人的个人差异，主误差在两月都略升，未达到预先设定的“主误差和群体关系均改善”扩样条件。仅看差异变大、总体平均更接近都不足以升级配置。

- 保留本轮为研究对照与失败/局部收益证据，既有主配置保持原样，不据这两月调固定加减系数。
- 优先准备一个**财务信息未知的占位对照**，检查是否仅仅新增一段家庭背景就改变整体水平，区分信息本身与提示表达的影响；这是解释性补充方案，尚未实现或调用。
- 已准备的外部幸福/财务满意合成画像仍可单独检验；它们不是真人已知属性，也不与Q1同时新增后宣称某一项有效。先完成来源内留出/匹配审查和提示预览，再决定真实试验。
- 新月份、新模型、重复生成或额外对照均属于新的试验，不在这次已用完的200调用范围内；本轮没有继续调用或扩大预算。
