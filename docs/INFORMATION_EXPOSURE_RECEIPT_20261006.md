# E/P 信息接触机制：验收与运行卡

日期：2026-10-06。研究解释与公式见 [专题方案](literature/sce/information_exposure/README.md)。

## 配置

- 路线：A 历史重建开发诊断；目标月 2021-05、2021-06，当前 E 截止点不变。
- 人口：各 48 人，食品/汽油/住房通道各 16 人，从完整月人口按固定 hash 选；三组同人、同篮子。
- 组别：`shared / shuffled / matched`，共 288 次调用，关闭所有组新闻；无 Q1、GSS、Normal 扩展。
- 模型：DeepSeek 官方 `deepseek-flash` 别名，记录实际回包标识和 fingerprint，不假定精确训练截止。
- 请求温度 0.5，seed 42，输出最多 1,024 tokens，不自动重试。
- 预算：总上限 $1；每个“月×组”上限 $0.16。参考计价 input $0.30、output $1.20/百万 tokens，费用按实际 usage 保守估算，不称账单。2026-10-06 已通过官方价格页检索复核峰值价，缓存/非峰时折扣不计入保守估算。
- 用户本轮已确认“同意，开始实验，上限$1”；按该范围执行。原有 Q1 授权不沿用。

## 实现范围

新增独立机制/评价模块及两个 CLI；`run_sce_local.py` 增加显式 `--information-exposure` 入口，默认配置不变；SocioVerse 观察层实际裁剪可见信号、新闻和广播，原始台账不变。问卷沿用 v2，新的渲染器为每条序列独立标记参考月与单位。

人口与消费 donor ID、权重、真实问卷答案、路径不进入模型消息。用于匹配的篮子是合成的；不是对应 SCE 受访者的真实支出。按消费占比抽取通道是未估计的研究假设。
