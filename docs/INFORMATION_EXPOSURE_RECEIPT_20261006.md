# E/P 信息接触机制：验收与运行卡

日期：2026-10-06。研究解释与公式见 [专题方案](literature/sce/information_exposure/README.md)。

## 本轮结论

**真实实验完成；暂不升级为主方案。** 不同的信息包增加了回答的分散度，但匹配组的个人误差在两个月都更大，也未稳定优于随机分配。

5 月 Q9 的个人平均绝对误差：共享 **4.05pp**、随机 **4.56pp**、匹配 **4.66pp**。同一批人的回答 IQR：**0.66 / 1.54 / 1.76pp**；真人 **5.98pp**。

6 月个人平均绝对误差：共享 **4.74pp**、随机 **4.72pp**、匹配 **5.10pp**。回答 IQR：**1.30 / 2.22 / 2.88pp**；真人 **5.81pp**。

这里 IQR 表示跨人回答中间 50% 的跨度，不是某个人自身预测的不确定性，也不是最大最小之差。两月分布距离仍比共享组更差，预设筛查未通过。匹配相对随机的个人误差变化均值为 +0.108/+0.387pp，配对 bootstrap 区间均包含 0；不能声称匹配显著更好或更差。

匹配组的汽油通道中位数明显高于食品、住房通道，说明模型对输入价格类型有反应。它不证明三类接触规则符合真实居民，更不证明 CE 背景与 SCE 答案已正确连接。

## 配置

- 路线：A 历史重建开发诊断；目标月 2021-05、2021-06，当前 E 截止点不变。
- 人口：各 48 人，食品/汽油/住房通道各 16 人，从完整月人口按固定 hash 选；三组同人、同篮子。
- 组别：`shared / shuffled / matched`，共 288 次调用，关闭所有组新闻；无 Q1、GSS、Normal 扩展。
- 模型：DeepSeek 官方 `deepseek-flash` 别名，记录实际回包标识和 fingerprint，不假定精确训练截止。
- 请求温度 0.5，seed 42，输出最多 1,024 tokens，不自动重试。
- 预算：总上限 $1；每个“月×组”上限 $0.16。参考计价 input $0.30、output $1.20/百万 tokens，费用按实际 usage 保守估算，不称账单。2026-10-06 已通过[官方价格页](https://api-docs.deepseek.com/quick_start/pricing/)检索复核峰值价，缓存/非峰时折扣不计入保守估算。
- 用户本轮已确认“同意，开始实验，上限$1”；按该范围执行。原有 Q1 授权不沿用。

## 实现范围

新增独立机制/评价模块及两个 CLI；`run_sce_local.py` 增加显式 `--information-exposure` 入口，默认配置不变；SocioVerse 观察层实际裁剪可见信号、新闻和广播，原始台账不变。问卷沿用 v2，新的渲染器为每条序列独立标记参考月与单位。

人口与消费 donor ID、权重、真实问卷答案、路径不进入模型消息。用于匹配的篮子是合成的；不是对应 SCE 受访者的真实支出。按消费占比抽取通道是未估计的研究假设。

## 接力顺序

1. 定向测试、真实观察与 288 条提示核验；保留输入/代码哈希、样例。
2. 新授权后执行准备包；每组实际提示与预览逐条比较，模型身份或回答校验变化即停止，失败不自动重跑。
3. 完成后用评价 CLI 复算。预设判据见专题方案，不能用回答后调参掩盖失败。

上述三步已完成。下一步建议先做离线设计：保留所有人的基本经济背景，在此基础上增加不同价格接触；对新闻也做“相同主题数量、匹配与置换”的对照。当前单通道遮罩过强，以及 CE 代理不能测量接触，都是待查解释。先明确频率/权重的数据依据和真实提示样例，再为新实验独立冻结配置，不直接扩大当前机制。E/P 接触仍值得研究，但此次没有提供有效性证据。
