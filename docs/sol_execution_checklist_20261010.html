一、方向不变，先把问题收窄

我们要重建美国居民如何回答 SCE 一年期通胀问卷。当前真实运行、计分和保存轨迹已经跑通；最主要的不足是总体偏低、居民之间的差异太小。加入篮子或换模型，尚未稳定解决这两个问题。

接下来同时检查三件事：家庭接触了什么信息（P 与 E）、如何理解并更新看法（B）、如何把看法填进问卷（B）。 不要求先构造完整的心理模型，也不把“补更多数据”当作默认答案。

  • 比赛仍为赛道 A。内部路线 A 是历史重建；路线 B 是只用预测起点可得资料预测后续调查，两者分开报告。
  • A 可以明确使用事后资料或宏观约束，但须说明研究条件。未约束的总体拟合仍须评价；已作为约束的量不能再充当独立验证成绩。
  • 目前先攻克 A 的机制与验证。B 的资料准备继续保留，是否进入正式实验依赖后续验收，不把 A 的成绩写成 B 的预测能力。
  • 优先用一个固定模型；暂不扩大模型名单，也不自动重跑全部历史实验。

同时准备第二轮的理论依据，暂不全都运行：

  • 家庭接触：用 CE Diary、原生 SCE 支出和文献说明类别接触的差异。支出份额、购买频率、看到价格的频率分别处理；缺实测的频率采用明确先验，并比较合理的高/低设定。

四、如果比赛前仍然模拟得不像，如何处理

可以提交诚实、有实证内容的成果，但不能保证获奖，也不能把“失败了”本身包装成理论贡献。 官网强调经验有效性、基线、适用边界和可复现性；不意味着负结果自动满足高分要求。依据为当天官网核查记录。

情况1：部分机制有帮助，仍未整体超过简单方法

以“哪一环有所改善、哪一环仍失真”为结论。例如近期价格是否改善中心，却仍无法恢复居民分歧。完整报告没有改善的Q8或其他时期；若改善区间仍包含零，就写有限迹象。项目贡献可以是经过验证的局部机制及其边界，不宣称完整重建成功。

情况2：总体依然偏差大，但失败在多个时期重复出现

把研究重点收束为“LLM居民模拟的经验检验与失真来源”。需要排除主要技术错误、有共同信息对照、观察原始回答并做独立时期检查，才能说某种具体设计存在稳定问题。只能推到实际测试的模型、输入与时期，不能推成“所有LLM都无法模拟居民”。如果连失败是否稳定也不确定，就明确这是探索性证据。

情况3：只有经过校准，总体才接近

若使用过去已知指标校准，应把原始模拟、校准后模拟与“只有校准/历史信息”的基线分开；额外收益需要独立检验。若A直接使用当期全国值约束，则转为有条件的历史结构重建，并检验未被约束的分布、尾部和人群关系。不能因为全国中位数被对齐，就说微观结构真实或B预测成功。此分支必须先明确研究设计，不能临时套真值美化旧结果。

无论哪种结果，最后都应留下什么

  1. 可解释的 P/E/B 设计，明确证据与合成假设。
  2. 完整的基线、对照、失败记录和适用范围，不筛掉不利月份。
  3. 能重算核心结论的研究包及费用说明。
  4. 基于证据的后续方向，而非继续添加属性的愿望清单。

主攻目标仍是改善模拟；收束安排是防止最后只剩一堆没有验证的尝试。停止条件是证据和剩余时间，不是把误差调到某个任意数字。 ConsumerSim的CCI指数点不能变成SCE的百分点及格线；“MAE相对下降约10%”只是内部努力目标。

先完成00与01，推进02、03的离线准备，并同步启动07的依赖清点。交付差距分解、三组真实提示预览和具体运行卡；如果证据不支持三组设计，先解释并缩减候选，不机械耗费调用。每完成一个可复核节点更新任务板，使用明确路径提交；旧15份待审文件保持原样。本清单没有启动新API、改变正式配置或生成新实验结果。
