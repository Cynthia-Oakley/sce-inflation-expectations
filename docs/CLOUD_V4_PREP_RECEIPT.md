## 文档调查结论（零费用，官方文档站 + 开源仓库）

- **切换机制**：`simulation.json` 的 `decision_args.llm_kind`（`scripted`/`"openai"`），开源参考研究 opinion_diffusion 钉 `gpt-4o-mini`、campus_dining_choice 钉 `gpt-4o`；托管版 provider 由平台接好，用户不能也不需配置 key。
- **计费**：文档《额度与计费》——Agent 平面按轮计费（与读写量成正比），Sim 平面按 模拟跑批（每 agent 每步一次 LLM 调用）+ 外部数据服务计费；**scripted 不消耗 Sim**；"20 个 agent 跑 4 步是几美分"为文档给出的唯一数量级示例；**无公开单价表**；"花钱前有确认卡"。
- **模型身份**：**刻意不公开**（《限制与公平使用》明载拒答政策）；正式获知渠道为邮件 contact@socioverse.fudan-disc.com；间接渠道：人群问卷模拟（user-pool MCP）响应带 `llm_model` 字段——但该字段不覆盖 study 决策模型。
- 文档写默认额度 $10+$10 / 邀请码 $50+$50，与我们账号实际 $30 池不一致，以工作台读数为准。
