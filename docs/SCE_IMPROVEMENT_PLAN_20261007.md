# SCE：距离成功模拟还缺什么，怎样推进

2026-10-07。队伍“水上挽月”，比赛赛道 A。依据截至本日保存的实验记录，区分已经实现、尚未验证与下一步建议；不为研究进度编造完成百分比。本页是后续设计建议，不冻结新运行配置，也不授权新增 API 调用。

用户已在本次会话确认开题报告提交。项目以研究和实验推进为主；平台回执尚未在本地归档，不影响“用户已确认提交”的状态。

## 1. 当前阶段与成功标准

**基础流程已经贯通，经验有效性尚未建立。** 我们已有真实人口、历史环境、模型作答、计分、轨迹及分析。现在要解决的，是家庭 Agent 能否生成接近真实 SCE 的预期水平、群体分布与人群差异。

最近主基线是 2021-05/06 两个开发月，每月 300 Core，再扩展到完整人口。用同一项目近似 Q9 计分器：

- 模拟月度指标为 2.965% / 3.858%，真实问卷复算为 4.000% / 4.802%，分别偏低约 1.04 / 0.94 个百分点。
- 模拟个人预期均值的跨人标准差约 0.59 / 0.65 个百分点，真人约 6.87 / 7.11。标准差受尾部影响，需结合中间 50% 跨度及分位数看；不能把标准差的倍数当作整体拟合距离。
- 两月变化方向一致，但只有两个开发月，不足以证明动态机制或未来预测能力。
- 消费篮子与排序、Q1 财务经历、单类价格信息接触的三轮小试，都没有稳定改善整体拟合。它们提供诊断信息，不作为已成功的组件。

“成功”需要分别回答两个问题：

**A 历史重建**：利用声明的历史资料与可选宏观约束，重建未直接给定的人群分布、群体差异和个人不确定性。若把当月全国中位数作为约束，就用其他未约束的量验证，不能再以这个中位数贴合为独立成绩。

**B 下一期预测**：只用截止时点可得资料预测下一期 SCE，在未参与调试的时期与简单基线比较。预测的是下一期居民对未来一年通胀的预期，不是下一月实际 CPI。A/B 是本项目两条线，均属于比赛赛道 A。

## 2. literature：已有理论，需要变成能验证的机制

**现状**：已整理价格体验、预期形成、心理/家庭状态、Agent 方法和平台案例；资料缺口已不是首要障碍。

**距离**：理论还没有充分转化成可检验的 P/E/B 关系。论文支持某种关系，不等于我们的具体合成分配和 LLM 响应就符合现实。

**改进**：每个机制只写清四件事：依据什么研究；使用什么可观测资料；预期改变哪种分布或群体关系；哪种结果会使我们放弃它。优先是价格接触、共同信息与信念更新，心理属性后置。

**验收**：一张机制说明能直接对应一组输入、一个对照与一个评价量，且来源证据与项目假设分开。

## 3. study：开题已提交，研究问题还要拆成实验

**现状**：研究对象、赛道、A/B 两线与 P/E/B 主框架已明确，开题已由用户确认提交。

**距离**：主实验、可选模块、开发数据与正式验证数据尚未形成完整冻结方案。此前用过的月份不能再称从未看过的留出。

**改进**：建立数据使用登记，分别标记问卷/计分诊断、机制开发、验证与最终评价。以 2021-05/06 为机制开发，不自动把所有 2021 年或其他已看月份当新留出。A 的约束重建与未经约束的模拟并列；B 另设输入时点与基线。

**验收**：每个实验说清“已知什么、生成什么、检验什么”，不把已知条件当成待预测结果。

## 4. population：人口覆盖改善了，生活体验仍是代理

**现状**：开发月完整人口为 1,234/1,297 人，已按月更新画像，不再只选全年完访者。Core/Normal 用同一消费篮子合成规则；CE Interview 已匹配，GSS 幸福/财务满意候选属性已离线生成。GSS 尚未进入真实模拟验证。

**距离**：人口标签能说明生活处境，却不能直接证明某人购物、开车、关注新闻的频率。CE 与 SCE 是不同家庭，GSS 又是另一调查，三者没有已观测的完整联合关系。Q1 小试有局部群体收益，但没有稳定解决总体问题。

**改进**：

1. 保留真实画像与当前篮子；先检查匹配回退、缺失、消费类别映射和多套抽样的差异。
2. 从 Diary 研究分商品类别的购买日/频率分布，再考虑条件分配。短期日记不是全年习惯，零购买也不一定代表从不接触。
3. 支出份额先用于描述家庭消费背景，不直接作为注意力概率；把“买多少”和“接触多频繁”分开。
4. 幸福等属性作为独立候选，先检查源调查内部匹配表现和跨调查假设，再单独对照；不与篮子、新闻同时新增。

**验收**：不仅覆盖所有人，还要说明每项合成属性的来源、匹配支持与不确定性；在多套分配下，关键结论不能只由某一次抽样决定。B 使用此前可得的人口/CE 资料，另验证人口构成变化，不使用目标月事后画像。

## 5. environment：有真实信息，需要形成居民的信息视图

**现状**：开发 E 有经济指标历史与新闻标题/摘要；BLS 首发稿已归档。汽油和新闻文本的历史版本证据仍有限。差异化价格小试能改变回答，但只看一种全国价格过于简化，匹配未稳定优于随机。

**距离**：大量共同数字不等于居民实际接触的信息；全国价格也不等于个人账单。问题可能同时来自信息内容、接触分配和解释方式，目前不能归因于某一个原因。

**改进优先级最高：共同经济背景 + 个体价格接触。**

- 所有人保留相同的基础经济背景和价格历史；在此之上增加由家庭背景支持的重点信息，避免让部分人只有食品、完全不知道其他经济情况。
- 首轮只改价格视图，新闻保持相同。比较共同背景、共同背景加匹配信息、共同背景加置换信息；后两组使用相同的信息包总体，检验匹配关系。
- 新闻之后单独检验：固定经济相关性规则，记录筛选的原始候选、发布时间、标题与摘要。区分事实与作者/专家观点；若删去观点或事实，这属于内容干预，不能称只改表达。
- 购买频率与消费类别粒度完善后再接入，不能用“加了更多数据”代替机制检验。

**验收**：实际观察日志证明各人看到了预定内容；匹配效果可重复，且群体分布、人群关系有收益。A 可使用明确声明的回顾性资料；B 另补历史版本或剔除未核验输入。

## 6. dataset 与计分：较为成熟，但不是精确官方复刻

**现状**：多年 SCE 微观数据、问卷、来源材料和评价真值已经验收；真实与模拟十档概率用同一冻结近似计分器。新月份计分复查支持候选算法，相对原版有明显改善。

**距离**：开放尾等个案仍有拟合偏差，少量合法问卷属于算法不支持情形；不是所有排除项都等于真人答错。极端回答可能同时影响标准差与计分差异。

**改进**：保持计分版本不因模拟效果而更换；区分原始概率非法、近似算法不支持、数值拟合异常。分别报告完整真实数据、共同可计分集和与官方派生量的差异；对尾部结论补敏感性检查。

**验收**：主要结论不能仅由某类排除或某个拟合约定造成。计分误差的量级需与模拟偏差比较，但不能用计分平均误差较小推断其在所有尾部都无影响。

## 7. simulation 与 B：能作答，尚缺可信的预期形成过程

**现状**：本地真实调用、输入隔离、合法 Q8/Q9 作答已贯通。最新大规模开发运行按月独立初始化，没有跨月状态。模型返回标识可保存，但别名不是不可变权重版本，训练截止仍未知。

**距离**：不同画像常给出相近判断；“模型像专家”及“共同信息使预期收敛”是待验证解释，不能只凭文字理由确认内部机制，也未证实是训练记忆造成低估。

**改进**：

1. 用相同 P/E 和问卷，小规模比较模型；与同信息的直接问答、简单经验规则并列。先检验集中是否只发生于当前模型。
2. 在居民信息视图后，另测最小中间状态：接触的价格、近期体验代理、对涨价持续性的判断，再回答问卷。这些是模型状态，不冒称真人已观测心理；同时保留直接作答对照。
3. 重复少量相同输入，分开测“同一人的生成波动”和“不同人之间的差异”。温度只调生成方式，不是修复人口方差的依据。
4. 有支持后才研究跨月经验更新。可以保存经历或信念状态，不默认注入上月问卷答案；状态初值和更新规则需要数据依据。

**验收**：模型对信息的响应、群体关系及跨期效果在独立数据上可重复；不能只靠更换模型或加一句“请像普通居民”就宣称完成机制。

## 8. Core/Normal：成本路径可用，不能补出 Core 缺失的行为

**现状**：已有联合回答经验收缩扩展，能把 300 Core 扩为完整人口；尚未稳定优于 Core 直接加权。当前扩展主要依据教育、就业、年龄，尚未使用新增篮子等属性。

**距离**：Normal 借用 Core 已生成的回答，无法创造 Core 中不存在的高预期/低预期行为；更多 Normal 也不是更多独立 LLM 证据。

**改进**：先改善 Core，再用支持充足的价格接触特征检验条件扩展；新增条件越多，组内支持越稀疏，必须检查回退。用留出的 Core 模拟回答测试扩展，再报告直接加权与扩展的差别；不据当前目标月真人答案挑扩展参数。

**A 可选分支**：显式使用已知宏观统计约束重建，调整统计权重/投影而不是隐藏修改个人答案；同时做简单非 Agent 约束重建基线。宏观中位数无法唯一恢复微观结构，验收看未约束量。

**B 分支**：若使用偏差校准或与简单模型组合，只在截止前历史数据上估计，保存校准前后结果，与同信息简单基线比较。不能让目标月真值或人口边际通过 Normal 后处理进入预测。

## 9. analysis：评价需要与重建目标一致

评价对象、A/B主指标及非Agent/规则Agent基线的具体建议见 [评价与基线方案](SCE_EVALUATION_BASELINES_20261007.md)。该稿尚未冻结，不替代旧实验的预设筛查。

**现状**：已有月度、配对、人群、分布与调用审计，发现了低估、集中和扩展收益不稳。正式跨期基线比较尚未完成。

**距离与一项改进建议**：此前价格接触试验要求逐人 MAE 与分布指标同时改善。这是该次预设筛查，结果仍按原规则保留。今后应把人群分布与群体关系设为主要重建评价，逐人误差作辅助；这是新设计建议，不能追改旧试验为成功。

原因是合成篮子并非该真人真实篮子，许多影响信念的个体经历也不可观测。仅追求对每个真人的绝对误差，可能奖励所有人接近条件中位数；这与恢复真实分歧并不总是一致。能还原群体分布也不代表知道某一个人当月的准确答案。

**下一版评价建议**：

- 主要：全国/分组的预期水平与完整分布距离，辅以分位数、尾部和人群差距。
- 分开报告：人与人之间的分歧、一个人 Q9 内部的不确定性、相同输入重复生成的波动。
- 辅助：逐人误差、Q8/Q9 关系、圆整数值和概率模板、非法/不支持回答比例。
- 对照：Core 直接加权、简单经验规则、同信息直接模型问答；B 再加最后已公开一期 SCE 和简单时间序列基线。
- 统计：报告抽样、合成分配和 LLM 重复三种波动；Normal 的重复 donor 不按独立人计算置信程度。

**验收**：开发阶段收益超过合理的重复运行波动；冻结后在未参与选择的时期检验。具体主要指标、容许退化与样本规模先写进新实验卡，不在看结果后挑最有利者。

## 10. trajectory 与 reports：可审计基础较好，独立交付仍有缺口

**现状**：本地保存实际请求、回答、观察、配置哈希、DuckDB、调用和自记费用；开题已提交，研究记录较完整。

**距离**：原始数据和自动产物被 Git 忽略，GitHub 没有备份这些文件。Kimi 待审批次仍影响当前运行源码；干净 checkout 的完整独立复现尚未验收。旧云端缺失记录不能事后补造。

**改进**：

- 归档提交回执；对现有运行原档制定本地之外的安全备份，不上传受限个体记录到公开仓库。
- 明确依赖锁、源码快照和数据获取说明。待用户审阅原待审批次后，按独立文件范围处理；不得直接纳入其他提交。
- 最终包区分已有结果复算和真实模型重新生成；展示原始 Core、扩展、校准各层，不只输出最好的一条曲线。
- 从新的干净目录验收一键离线复算；真实调用重跑另列费用和授权。

**验收**：其他人凭说明能在允许的数据和凭证条件下复算关键结果，知道哪些步骤联网、花费多少、结果为什么可能有随机差异。

## 11. 推荐执行顺序

### 第一步：先完成零 API 的设计收口

明确主要评价目标，登记数据使用历史；整理同一套人口与共同背景，审阅新价格视图的实际提示；补问卷语义、价格口径和来源检查。交付新的实验卡、提示预览和离线验收。心理与大规模 Normal 暂后置。

### 第二步：分开回答两个诊断问题

先固定输入做少量模型/重复生成检查，判断同质化的模型依赖；再固定模型，做共同背景、匹配附加价格信息、置换附加价格信息对照。重复规模和样本量依据既有波动及目标指标规划，不把 20/48/300 当作功效保证。两项分别冻结，不同时换模型与机制后归因。

### 第三步：有效分支扩样，无效分支保留负结果

若匹配没有稳定收益，就不继续按同一假设堆更多属性；检验接触代理或信息处理状态，必要时研究明确的 A 约束重建、B 历史校准。扩大到 300 Core 后才检验 Normal 的增量与稀疏支持。

### 第四步：独立月份与 B 预测验证

方法冻结后使用未参与选择的验证资料；建设 B 的历史可得输入，比较简单基线，并视条件封存下一期真实预测。另完成干净包复算、报告与演示。

**最值得现在投入的方向：评价目标对齐 → 共同背景下的 P/E 交互 → 模型响应及信念更新 → 独立验证。** 这条顺序旨在找出有效机制，不保证拟合一定改善；即使没有改善，清楚的边界发现也能构成研究结果。

理论支撑：购物价格研究发现购买频率与涨价显著性的重要性，但未为本项目的 CE 注意力规则提供参数；信息实验发现更新取决于信息与初始信念精度，支持进一步拆解信息集和处理过程。这些机制不能直接证明我们失败的原因。[D’Acunto 等作者稿](https://eml.berkeley.edu/~ulrike/Papers/paper_DMOW.pdf)、[Armantier 等纽约联储研究](https://www.newyorkfed.org/research/staff_reports/sr543)，2026-10-07 复核。

SocioVerse 的 PMI 案例可借鉴“先更新主体状态、再回答问卷”的结构与独立对照；企业的经营状态不是家庭价格体验，其参数和效果不直接迁移。[技术报告 §5.4.2](https://arxiv.org/html/2609.24911v1)。
