# 赛事后公开GitHub：单独的发布检查

当前仓库保持私有；本轮同步不改变可见性，不重写Git历史，也不代表已经向赛事提交。

- 当前树、Git全部历史及附件都需检查：密钥、真实SCE人口/历史答卷/权重、供体链接、个人模型轨迹、NYT文本及可回溯新闻标签。只加gitignore不会删除早期提交中的资料。
- 已有若干population历史文件被版本追踪，仍有本地真实资料改动；本轮不提交这些改动。公开前须逐文件判定，并讨论清理历史或建立干净的公开发布仓库；未取得明确授权不自动重写历史。
- 对代码及依赖标清许可/署名，不擅自给第三方代码重新许可；对数据分别核研究使用、外发处理、再分发权限。脱敏不自动产生公开许可。
- 只把有文件级放行记录的国家聚合、充分支持的分组摘要和手工合成工程fixture纳入；小格/原文/个人行继续留在受控本地。
- Git备份、赛事研究包和未来公开版可不同：备份保存完整研究代码历史，提交ZIP使用确定白名单，公开版再做历史及版权检查。
- 发布版本应从新目录独立安装并运行默认0API入口，核对主图、成本/模型/种子、来源取得时间与真值隔离；说明受控微观缺口。
- 公开之前再确认署名、团队授权、赛事提交是否结束及可公开内容；本清单不代替这次确认。
