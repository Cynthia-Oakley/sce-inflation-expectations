# SCE study：装配、实证与复现

本目录使用SocioVerse标准study布局。`study.yaml`和标准P/E/simulation配置指向**20人两步的规则工程示例**，固定seed42。完整主研究有不同P/E快照和运行协议，不能把默认小示例叫作41,970人月的正式模拟。

## 入口及目录

从包根执行 `python studies/sce_inflation_expectations/run.py --mode all`。

- `population/`：手工合成工程人群；真实SCE人口不随包分发。
- `environment/`：示例公共BLS数字；不含原文新闻。
- `simulation/`：示例模型与主研究配置引用。
- `trajectory/`：实际运行后产生的工程DuckDB位置说明；真实模型账本不伪造为官方DuckDB。
- `reports/`：导读、论文/本地视频计划、下游冻结协议。
- `reproduction_data/`：无个人记录的月级/周级国家聚合、下游宏观预测与核对期望值。
- `model.py`：本研究四个官方接口的实现；`submission_tools/`：打包和复算适配；其他模块保留原研究实现。

## 主研究的P/E/B

P从SCE历史框架按学历3×数理2×年龄3×收入3的54格分层，未知项另池；选择依据包括126套候选的监督分析、变量冗余和长尾支持，小格过采样后按人口质量降权。A原512/月，排除14份跨月完成后41,970人月；B512/月；周度固定300。年龄/收入等未决定每人读多少新闻：最终数量为四档随机分配，不能把它说成人口决定的确定性公式。

A用本人严格更早Q8/Q9和摘要；缺失由近1—3月匿名相似供体联合分配。B用当时推定可得的旧框架及联合供体，并对齐已公开全国历史Q9；周度在公开SCE变化时重置、发布间隔内传递个人模拟状态。校准使用历史锚，不能读取目标期真值。

E区分购物价格与新闻接触，采购角色、CE支出和Fed信心均为合成代理。T0采用四档4/8/16/32、CPI相关度1.5、警示权重1。A按完成日前一日纽约日末筛选；B按前一年同月作答日经验分布；周度按周五末筛选、月额度逐周累计、跨周去重。不同版本不互相覆盖。

B由OpenRouter→固定SiliconFlow FP8的DeepSeek V3.2直接填写Q8/Q9；temperature0.5、JSON、关闭思考、最多1024输出token。有限正概率合计非100可按比例归一化；负数、零总和和缺档不是可随意修复的答案。主/补逐条留账、保留成功字段，不依据真值补跑。种子控制抽样/环境分配，不保证服务端逐字重现。

## 扩展、组合和评价

Normal为完整Q8/Q9答卷的联合加权经验贝叶斯式收缩；τ8由早48月遮蔽既有LLM答卷选出，不用后期人类答案调参。保持Core真实质量，只预测剩余质量，不重复套用抽样膨胀。A扩到实际98,382人口行；B扩到1300代理，月度自主链和周度未扩展。Normal不代表新增独立回答，也不代替新人先验。

Q9十档先计为个人连续密度均值，再取跨人的设计加权中位数；Q8独立统计。全国持续性用截止前最后公开SCE，微观配对照抄本人的真实上期；二者不能混名。官方密度细节未完整公开，本研究采用冻结近似并做同算法桥接。

主组合在2019—2022早48月拟合、2023—2025-10后34月评价。A扩展MSE权重0.134964；B/周度使用此前Core冻结的0.133976，不在11个月内重拟。更复杂ARX/交叉项和公平宏观基线为辅助，不取代主结果。开发曾查看历史后期，因此后34月不是整项研究从未见过的盲测。
