# SCE study：主研究与复现入口

本目录是SocioVerse标准study。默认`study.yaml`与`population/population.json`、`environment/environment.json`、`simulation/simulation.json`描述20人两步的合成工程示例，不能把它当作完整A82配置。主研究源码与聚合复算另行列明。

从包根运行：

```bash
python studies/sce_inflation_expectations/run.py --mode all
```

## 主研究配置

- 人群：历史月份原每月512人，学历3×数理2×年龄3×收入3共54个理论格，另留未知画像；小格过采样后使用代表权重汇总，不使用Normal代答。旧A82共41,984个人月；新A个人截止候选预先排除14份跨月记录，为41,970个人月，当前结果不混用。
- 信念：A用严格更早本人Q8/Q9与历史摘要，缺失时近期1—3月匿名供体初始化；B用旧联合供体与截止前已公开的历史全国Q9校准。没有用目标月答案初始化代理。
- 价格与新闻：按合成食品采购角色给可见价格类别，CE支出为合成匹配而非本人小票。旧已完成A/B使用随机3/8/20篇新闻；已完成新T0为4/8/16/32＋CPI相关度1.5。新A按本人完成日前一日截止，B按月共同截止；两个A版本分别重算，不以旧成绩代替新配置。
- 模型：DeepSeek V3.2，OpenRouter固定SiliconFlow FP8路由，温度0.5、JSON、关闭思考、最多1024输出token。成功字段保留，技术失败补跑各批有明确上限，不依据真值或误差补跑。
- 问卷与统计：Q8独立点预期；Q9十档有效非负概率按已授权规则归一化，再用冻结连续密度近似计算个人均值；按设计权重取跨人中位数。旧base `model.py`保留早期严格格式门，其注释不能替代主批适配器的后处理规则。
- 基线：A微观同支持比较本人上期；全国/B使用各截止前最后公开的SCE，未必恰好是上个月。不同基线不能混比。
- 组合：仅2019—2022的48月拟合凸组合权重，2023—2025年10月34月评价，MAE/MSE分别拟权。B不参与重新拟权。已看过的历史结果不再称完全独立盲测。

## 结果重算能验证什么

`reproduction_data/aggregate_cases.json`绑定完成的旧A82、新T0 A82与旧B11月级CSV和原评分期望值。`--mode replay`调用共享评价代码重新计算全国误差与48/34组合，新版还逐年核对，数值必须与封存期望一致；既没有重跑4万次LLM，也没有重新从真人Q9拟合密度。完整微观评分与条件分布复算仍需按合法取得方式恢复逐人资料。

`--mode dry-run`通过官方Core实际产生DuckDB面板和指标，使用确定性规则而非模型。规则成绩只说明工程能运行，不支持实证拟合结论。
