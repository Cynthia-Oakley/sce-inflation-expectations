## 真实演示命令

在新解压包根目录：

```bash
python studies/sce_inflation_expectations/run.py --mode verify
python studies/sce_inflation_expectations/run.py --mode all
```

第二条打印本次输出目录。打开其中 `index.html` 和 `receipt.json`；可展示 `dry_run/study.duckdb` 为本次工程示例新生成的存储。原始真实LLM用本地JSONL账本，不要用这份示例库冒充主运行。
