# 结果导读：SCE 通胀预期模拟

本报告导读 SCE 通胀预期研究的主要结果。它是研究包中的标准 reports/report.md，不是赛事要求的最终 8 页论文，也不替代完整的方法说明。

研究关注纽约联储消费者预期调查中家庭如何回答 Q8 和 Q9。各任务的样本与信息条件不同，结果分开报告，不合成一个总分。

## 主要结果

| 任务 | 结果 | 解读 |
|---|---|---|
| A82 历史重建 | 原始 Core 全国 MAE **0.298407 pp**；Normal 扩展后 **0.301422 pp** | 2021 年有所改善，但全期仍未胜过持续性。Normal 是统计扩展，不增加独立模型回答。 |
| 最新 B11 | 原始／冻结组合 MAE **0.348509／0.144277 pp**；持续性 **0.172727 pp**。Normal 后为 **0.346169／0.143964 pp**。 | 原始模型与后处理组合分列；组合不是原始模型 MAE。近期人口扩展不等于真实个人微观准确性。 |
| 月度自主递推 | 排除共用起点后 10 个月 MAE **0.305751 pp**；持续性 **0.190000 pp** | 后期出现上偏。此结果是跨月个人状态递推，与独立月度 B 任务分开。 |
| 周度发布后校准 | 固定 300 户、47 个周点，对应 11 份月度真值；原始 MAE **0.151581 pp**，持续性 **0.172727 pp** | 这里报告输出层组合前的原始值；另有固定组合 **0.156409 pp** 及宏观加模拟 **0.150171 pp** 对照。先验仍用已公布历史 SCE 校准，9 月漏报；47 个周点不是 47 份独立月度真值。 |
| 下游信贷用途 | 月度模拟相对同结构官方 SCE 模型，未来 1／2／3 个月循环信贷 RMSE 改善 **3.55%／8.17%／1.69%** | 这是月度结果的探索性用途，不是周度模型的下游验证。其他结局混合，简单基线仍强。 |

## 默认复现内容

运行 run.py --mode all 不调用模型 API，完成两项工作：

1. 运行 20 个合成家庭、两步的工程示例，检查接口和流程。该案例不是正式研究配置、512 人研究，也不是表中结果的生成来源。
2. 读取许可范围内封存的真实聚合结果，重算 A/B、递推、周度和下游误差及既有对照。

默认复现核对的是聚合数字和计算关系，没有重新生成个人回答。包内可重算 A 的已保存月度 W1/IQR 摘要以及下游预测误差；这不等于从完整个人答卷重算 W1、拟合个人密度或重训下游回归。

## 解释边界

- 研究对象是居民的问卷回答，不是未来 CPI。
- 四个最终任务的模型回复、有效答卷、评价权重与Normal重算已进入micro目录。原始身份键、完整提示、新闻全文及密钥不含在内；历史生成输入与严格预测资格限制保留。
- B 与周度的部分结果使用已公布历史 SCE 校准先验，应按回顾性设定解释。输入发布时间合格，也不能证明模型没有相关训练知识。
- 总体中心误差较小，不等于个人分布或人群差异已恢复；下游局部改善也不支持普遍优势结论。
- 研究包是复现载体；最终论文、视频及赛事提交状态另行确认。
