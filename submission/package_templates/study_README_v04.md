# SCE study：主线入口

这是提交包中的标准study。元信息与 `population/`、`environment/`、`simulation/`默认描述20人两步工程示例；不能把它当作512人正式配置或主实证成绩。

## 运行和阅读

从包根执行 `python studies/sce_inflation_expectations/run.py --mode all`。默认无密钥、0API；输出官方Core工程记录和封存聚合误差核对。完整安装、模式和限制先读包根README。

- [文件导读](FILE_GUIDE.md)：按研究问题定位算法，不要求读完所有源码。
- [方法依据](reports/REVIEW_GUIDE.md)：P/E/B、先验、时间、权重、Normal、指标及切分。
- [封存图表](reports/index.html)：快速看主结果；本次复算结果看运行打印的输出目录。
- `reproduction_data/aggregate_cases.json`及`extension_cases.json`：分别绑定旧主结果和最新扩展，数据是国家聚合，不是个人答卷。

## 当前机制

P按学历×数理×年龄×收入54格抽样，小格过采样后恢复人口质量；A512/月，近期B512/月，周度固定300。A优先本人更早信念，缺失用近1—3月匿名联合供体；B用推定可得旧框架与已公开历史全国Q9校准。周度只在新历史SCE公开后重置，间隔内自身状态递推。

E把新闻与购物价格分开；购物角色、CE支出及Fed信心为合成代理。T0新闻四档4/8/16/32、CPI相关度1.5、警示1；A个人完成日前一日截止，B按前一年同月日期经验分布，周度按周五截止累计/去重。

B用固定SiliconFlow FP8的DeepSeek V3.2，经OpenRouter；temperature0.5、JSON、关闭思考、1024输出token。Q8直接点预期，Q9十档非负正总和按已定规则归一化。旧示例model.py的严格格式门与生产适配器分版本保留。

Normal为完整答卷加权经验收缩，τ8从早48月LLM遮蔽检验选择，A扩到真实调查规模、B扩到1300代理；它不是独立新回答。月度自主链和周度未扩展。

## 统计、版本与证据

Q9个人连续密度均值→跨人设计加权中位数。全国MAE主、RMSE/bias辅；A同支持W1/IQR检查微观分歧，近期无微观真值不报对应准确率。官方密度优化未完整公开，使用冻结近似并披露桥接差异。

简单组合早48月拟权、后34月评价。A Normal λ0.134964，B/周度保留原Core λ0.133976；时间模型另有选参窗口，历史后期已被机制探索查看，不称全研究独立盲测。

当前可复现的是工程示例、真实聚合误差、组合及缓存月摘要/下游预测误差；完整个体生成、密度拟合、W1重算与回归重训不是本包默认模式的声明范围。

## 源码组织

`model.py`与公共兼容依赖保留原位置，`experiments/`准备/执行，`evaluation/`评价，`scoring/`计分，`submission_tools/`打包复算。包内主线是明确入口加静态导入闭包，不靠猜测文件名新旧。其余专题、历史实验和开发辅助源码进入包根archive的可核查补充ZIP；没有改原研究源码或冻结结果。正常阅读不需要解压归档。
