# 可复现性与提交范围声明

本文件对应赛道A的SCE研究包v12。论文PDF和演示MP4单独提交；包内报告是复现导读。v12补齐公开源快照、人口/先验与环境匹配、原始编码/日期/调用凭证、批量和新递推入口；保留原冻结答卷、密度缓存、参数和结果，封包不产生新API调用。

## 1. 评委可以直接执行什么

Python 3.11+，先按包根README安装requirements.lock.txt，再在包根执行：

```sh
python studies/sce_inflation_expectations/run.py --mode all
```

默认禁止Python网络访问，不需要密钥。三项工作分开记录：种子42的20户两步工程示例；封存全国与下游预测的误差复算；从四个正式任务的逐答卷资料重算计分、全国指标、A微观指标和A/B Normal后验质量。输出写入新目录，不覆盖旧结果。工程示例不是生成论文结论的实证样本。

默认微观计分查用精确概率向量的冻结密度缓存。执行`--mode micro --refit-density`可重新运行原数值密度拟合器，这使用CPU，不调用LLM。下游部分重算封存预测的误差，没有重新拟合回归。

## 2. 哪些操作需要额外条件

重新询问模型是一次新的随机生成，不等于对已有答卷复算。本包已提供66,822份实际输入投影和选中新闻摘录，全部66,822份A/B/月度/周度输入完整，包括公开调查派生的实际日期，支持自备Key条件单步生成。没有等待恢复的日期槽位；原始匿名SCE编号与内部代码映射在portable/evidence提供，仅Key等账号秘密不提供。`simulation/reviewer_request.py`默认离线预览，显式确认后只发一次完整样本。新的月度/周度自主链还须由新生成的前态重渲染后继输入；重新发送封存后月Prompt不能冒称新递推。

包内包含四个最终任务的脱敏模型原文、技术失败和补跑、有效字段及最小评价数据，不是所有开发期小实验的逐条原文全集。开发实验由experiment_logs/公开索引及归档源码追溯。快速复算层的全波次参考使用冻结分数和权重；原始公开工作簿及提取脚本另在portable源资料层提供，可重新构造。

## 3. 种子、模型、调用和成本

- 工程例固定seed=42；日期、供体、新闻分配和Normal使用冻结实现与输入约束，不能把展示抽样的波动当成新的LLM信息。B的合成作答日期种子为20261026。逐任务配置与协议哈希见simulation/research_runs.json；数据哈希见micro/manifest.json及PACKAGE_MANIFEST.json。
- 正式模型为OpenRouter→固定SiliconFlow FP8的deepseek/deepseek-v3.2，temperature=0.5、JSON、关闭思考、最多1024输出token。外部模型推理不承诺由单一seed逐字节重现；固定输入、保存原始输出与复算结果用于审查。
- 四个最终任务合计66,965次新增物理API尝试；原始输出记录67,147条，包含182份历史复用。有效状态67,334行还包含月度根月复用，不能据此反推新增调用数。
- 四任务已报告费用合计约50.94美元；全项目约108美元是作者账单估计，包括旧实验等其他范围。未知费用预留不等于实际扣款。本包默认复算新增调用和费用均为0。详reports/PAPER_METRIC_GUIDE.md与micro说明。

## 4. 真值取得时间与隔离

原始URL、下载字节哈希、可证实取得时间及缺口，完整保留于包根TRUTH_ISOLATION_EVIDENCE.json。不能将研究目录的日期作为取得时间，也不能把本地取得时间当作历史发布日期。

- 2017—2019微观来源的下载凭据为2026-09-29T09:50:18.898162Z；2020—2024为2026-09-28T02:16:33.994958Z。
- latest微观文件的相同字节分别在2026-09-28及2026-10-21有下载凭据；衍生资料中使用的是哪次复制，元数据无法区分，两次证据并列，不补造精确时间。
- 全国发布页账本注明2026-10-07批量获取，部分文件没有逐份取得时刻。2026-09首发全国值有2026-10-25T02:20:37.860958Z的获取收据。派生真值文件未记录创建时刻等缺口继续披露。

目标期真实答案只进入隔离评价；生成使用本人严格更早的历史，或符合约定的匿名历史供体。B及周度用于校准先验的是截止前已经公开的历史全国值，不能使用目标期真值。生成收据和协议保留truth_read=false与输入白名单声明，评价在生成后另进程运行。元数据声明不等于独立证明了所有历史时点均合格；B仍按回顾性回测解释，历史文本版本和模型预训练知识限制保留。
