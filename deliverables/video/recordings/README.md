# 视频录制与拼接

本目录独立于PPT版本，后续分段录制统一放在这里。

- `clips/`：原始分段录屏，按PPT页码命名；环境说明另命名为`environment_design.mp4`。第1段已从Downloads复制，原件保留。
- `exports/`：剪辑拼接后的成片，例如`SCE_demo_draft_v01.mp4`、最终的`SCE_demo_final.mp4`。
- `media_manifest.json`：本地片段哈希、时长、画面和音轨信息，供后续拼接核对。

重录时不要覆盖已保留的版本，可命名为`page_01_take02.mp4`；待作者确认后再选择采用哪一段，不把多个take都拼进去。录屏统一画面比例与区域，前后稍留静止画面，保留带声音的原始文件。

第2段由作者重新裁剪为38.5秒，使用[page_02_trimmed_38.5s.mp4](clips/page_02_trimmed_38.5s.mp4)。`page_02.mp4`原片保留。后续拼接采用作者的38.5秒版本，选择已记入本地清单，不再使用早前的38秒剪辑版。

待片段齐全后，按[最新录制操作单](../v05/录制操作单_v05.md)的内容顺序拼接：方法概览→人口设计→环境设计→作答设计→真实样本→信息匹配→概率计算→执行→结果→拓展。PPT页码保留，因此不要直接按文件名排序。后期统一音量，裁去准备时间并补必要字幕。不必重跑研究模型。当前片段为作者初录归档，尚未做最终视频验收。

录屏、音轨及本地来源清单默认不自动上传Git，也不自动装入研究包。提交成片另行确认。
