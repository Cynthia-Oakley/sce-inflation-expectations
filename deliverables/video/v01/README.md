## 内容顺序

1. 真实概率问卷与研究对象。
2. 家庭背景、历史信念、可见信息与统一计分。
3. 研究包执行与结果追溯，最终剪辑时插入真实操作录屏。
4. 82个月历史路径和2021年上行偏差。
5. 近期固定组合与历史微观分歧。
6. 月度漂移的启示与47周更新。
7. 循环信贷的局部用途。
8. 贡献、改进方向与研究边界。

主月度图沿用v10的512户直接模拟口径，统计扩展另述；周度没有统计扩展。近期组合沿用早48个月拟得的13.3976%模拟权重，不在近期重拟。下游8.17%是相对同结构官方SCE回归的RMSE降幅，不是胜过所有简单基线。全研究是回顾性检验。
